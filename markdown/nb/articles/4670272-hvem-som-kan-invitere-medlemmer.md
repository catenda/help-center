# Hvem som kan invitere medlemmer

1. Gå til innstillinger i hovedmenyen på venstre side.
2. Under tilgangskontroll på denne siden har du "Inviter nytt medlem". <br>Klikk på det.
3. En liste over hvem som kan opprette og redigere tilgang vises. <br>Klikk på knappen Rediger tilgang.
4. Definer tilgang for medlem(mer) eller team(s).
5. Under medlem(ene) eller Team(s) du har valgt vises.<br>Under tilgang velger du mellom Kan invitere og Ikke tillatt.
6. Trykk på lagre-knappen.
