# Solibri Topics-integrasjon

> **Viktig:** **Solibri versjon 9.13:** **Viktig:** BCF Connector-programtillegget er siden versjon 9.13 en egen fane kalt BCF Live connector i Solibri. Mye av den samme informasjonen gjelder fortsatt i denne fanen. **Solibri versjon 9.9:** Siden oppdatering 9.9 av Solibri er det nå mulig å synkronisere sakene dine med Catenda.

Dette dokumentet forklarer hvordan du setter opp BCF-koblingen med Catenda-prosjektet ditt. Dette gjør det mulig å kommunisere saker på tvers av de to programmene sømløst, og unngår manuelle eksport- og import BCF-trinn.

1\) Kjøp og last ned Solibri Model Checker fra Solibri Solution Center. Hvis du allerede har verktøyet, husk å oppgradere det.

2\) Du kan få/oppgradere BCF Connector fra Solibri Solution Center - [https://solution.Solibri.com/application/#!ProductsView](https://solution.solibri.com/application/#!ProductsView)

Gå til Solibri Extensions og velg BCF connector

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/01-intro.png)

> **Merknad:** For å aktivere BCF Connector må Solibri-administratoren aktivere det i brukeradministrasjonsskjermen i Solibri Solution Center.

3\) Åpne SMC, og gå til innstillingsskjermen. Velg deretter BCF connector

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/02-intro.png)

4\) Legg til server

1. Trykk først på Legg til server-knappen, og du blir sendt til den andre siden.
2. I dette trinnet kan du velge hvilken server du vil koble til, i dette tilfellet Catenda-en.
3. Her kan du lime inn nettadressen fra Catenda-prosjektet ditt. Hvor du finner denne nettadressen, forklares i neste bilde.
4. OK for å fullføre tilkoblingen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/03-intro.png)

6\) På sakssiden i Catenda-prosjektet ditt kan du finne nettadressen for prosjektet ditt. Den er plassert i Exchange-sakene.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/04-intro.png)

7\) Gå deretter til kommunikasjonsskjermen i Solibri, og velg presentasjoner. Derfra kan du opprette en ny presentasjon. Høyreklikk på kontekstmenyen for å kunne synkronisere med Catenda.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/05-intro.png)

8\) Herfra kan du også opprette en ny presentasjon og importere fra Catenda til Solibri.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/06-intro.png)

For å optimalisere arbeidsflyten din med BCF-serveren [Se her](https://support.bimsync.com/hc/en-us/articles/360011987619)
