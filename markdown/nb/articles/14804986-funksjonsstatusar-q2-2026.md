# Funksjonsstatusar Q2 2026

For å forhindre varslingsspam og for å sikre en reibeløs lansering kan ny oppførsel eller endringar av eksisterande oppførsel rullerast ut gradvis og utan varsel. Dei som legg merke til endringar i oppførselen til ein del av ei side dei brukar ofte, eller dei som lurarer på kva som er nytt, kan konsultere desse artiklane for oppdateringar om nylige endringar i oppførselen for alle brukarar.

Følgjande saker er beskrevne i denne artikkelen:

## 1. **Nye funksjonar**

Kvar brukar brukar plattformen annleis. Sjølv om ein ny funksjon vert gjeven ut eller endringar vert gjort på ein funksjon kan det vere at brukarar ikkje brukar den delen av funksjonen. For dei som er nysgjerrige på kva "den nye knappen" eller "den nye sida" er på plattformen inneheld denne artikkelen ei innleiing på kva endringa handlar om. For desse funksjonane er ofte berre grunnleggjande eller litt forelda støttemateriell tilgjengeleg då dette vert oppdatert undervegs. Saman med å hjelpe folk i støtte vert artiklane ofte oppdaterte, og viss spørsmål som vart stilte kan finnast forklarte raskt i ein artikkel neste veke.

## 2. **Oppdaterte funksjonar**

### 2.1 **Objektnamn i treepanel**

Til no vart namn for dei nestla nivåa viste, men for objektet på det lågaste nivået vart eit autogenerert namn vist som:

```
WallStandardCase1.0WallStandardCase1.1WallStandardCase1.2
```

Standardoppførselen av dette har no endra til i staden å vise verdien i namnet på objektet som kan sjåast i inspeksjonspanelet slik:

```
Basic Wall:Exterior - Insul Panel on Mtl. Stud:140707Basic Wall:Exterior - Insul Panel on Mtl. Stud:140832Basic Wall:Exterior - Insul Panel on Mtl. Stud:140972
```

Ein ny modelrevijon må lastast opp for å kunne sjå skilnaden.

Den tidlegare oppførselen med det autogenererte namnet, som kan vere nyttig, er bewart ved å klikke på tannhjulikonet mot øvre høgre hjørne av kvart modeltrjemeny.

## 3. **Aktivering av etterspørde funksjonar**

Kvar etterspørd funksjon er produksjonskvalitet og klar for ekte prosjektbruk. Sjølv om desse funksjonane har vorte testa for å fungere som dei skal, kan det vere variasjonar i kor mange prosjekt som har byrja å bruke desse funksjonane, så ukjende edge-case kan finnast. Medan endringar kan skje medan vi arbeider for å gjere desse funksjonane tilgjengelege for alle brukarar vil data som vert send inn i desse funksjonane ikkje bli sletta.

### 3.1 **Førespurnad om aktivering av etterspørde funksjonar**

Nokre funksjonar kan forespørsast aktiverte for eksisterande prosjekt av kontaktpersonen for Catenda-lisensen din medan andre kan aktiverast med ei innstilling i prosjektet. Når ein etterspørd funksjon forespørsast aktivert, vert eit møte sett opp med ein stødterepresentant for å diskutere gjeldande status for funksjonen. Viss eit prosjekt ikkje allereie er tilgjengeleg der den etterspørde funksjonen kan testast, kan eit dummyprosjekt opprettast for ei avgrensa tid der den etterspørde funksjonen kan testast for å vurdera om funksjonen er klar til bruk.

### 3.2 **Rapportredigerar**

Lag rapportmalar for saker og dokumenter slik at prosjektmedlemmar kan velja saker eller dokumenter frå tabellen og bruka rapporthandlinga for å generera ein rapport. Rapportsida er ein etterspørd funksjon som kan forespørsast aktivert for gjeldande prosjekt. Nye prosjekt som vert oppretta basert på eit malprosjekt der denne funksjonen er aktivert, har ikkje denne funksjonen aktivert. Separate malar kan opprettast for saker og dokumenter. Når ein mal er tilgjengeleg i eit prosjekt kan rapporthandlinga brukast med valde saker og dokumenter for å generera ein rapport basert på den valde malen. Støtte for korleis ulike verdiar kan visast på sida vert tilbode av Catenda. Viss du ønskjer ein tilpassa rapport skreiden til firmaet ditt kan vi få deg i kontakt med ein konsulent som kan hjelpa med dette.
