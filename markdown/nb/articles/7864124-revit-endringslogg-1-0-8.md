# Revit endringslogg - 1.0.8

Nye funksjoner i 1.0.8

- Revit 2024-tilgjengelighet
- Teams-filtrering
- Egendefinerte eksportinnstillinger er igjen tilgjengelige i plugin-modulen
- Sak-sidepanel
  - Inne i en sak er det nå mulig å åpne sidepanelet ved å klikke på relaterte elementer.
  - Se dokumenter som er lenket til saken
  - Velg objekter som er lenket til saken
  - Se hvilke saker som er relatert til denne saken
