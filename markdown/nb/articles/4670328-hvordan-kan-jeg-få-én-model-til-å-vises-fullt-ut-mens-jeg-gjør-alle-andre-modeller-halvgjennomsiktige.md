# Hvordan kan jeg få én model til å vises fullt ut, mens jeg gjør alle andre modeller halvgjennomsiktige?

1. Åpne alle modeller i 3D-visningsprogrammet
2. Åpne tre-panelet (snarvei er shift-3).
3. Velg modellen du vil se på («isoler»), og klikk på toppnoden i den listen. Dette gjør at alle elementer i denne modellen blir valgt.
4. Høyreklikk på toppnoden og velg «Isoler». Alle objekter i denne modellen vil nå vises fullt ut, mens alle objekter fra andre modeller blir halvgjennomsiktige.
