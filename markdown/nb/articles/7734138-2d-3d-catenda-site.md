# 2D / 3D - Catenda Site

2D / 3D-siden finnes i [menyen](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site) eller ved å trykke på saker-knappen i navigasjonslinjen nederst.

![2D / 3D](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/01-intro.png)

Slik kan 2D / 3D-siden se ut:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/02-intro.png)

Mot toppen av 2D / 3D-siden ser du issue board-velgeren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/03-intro.png)

Problemene som resulterer fra filteret på den valgte issue board er problemene som har markørene deres vises i 2D-visningen.

### Øvre halvdel

I den øvre halvdelen av 2D / 3D-siden vil du se [3D-viseren](https://support.catenda.com/en/articles/7744403-3d-viewer-catenda-site).

### Nedre halvdel

I den nedre halvdelen av 2D / 3D-siden vil du se [2D-viseren](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site).

### Delingslinje

Mellom de to viserne vil du se en delingsglider

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/04-dividing-bar.png)

Dra på denne glideren for å konfigurere hvor stor del av skjermen du vil at hver av viserne skal ta opp
