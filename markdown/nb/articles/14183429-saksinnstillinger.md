# Saksinnstillinger

Slik kan Saksinnstillinger-siden se ut:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9d18txpx/01-intro.png)

Saksinnstillinger-siden finnes som en underside til Saker-siden i den venstre navigasjonsmenyen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9d18txpx/02-intro.png)

Fra denne siden kan du få tilgang til [innstillingene for Sakslister](https://support.catenda.com/en/articles/4670277-topic-board-settings-page) (1). Administratorer kan også få tilgang til [innstillingene for Saker-maler](https://support.catenda.com/en/articles/14076010-topic-template-settings-page) (2):

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9d18txpx/03-intro.png)

## 1. **Saksliste-innstillinger**

Klikk på Saksliste-innstillinger for å gå til [Saksliste-innstillinger-siden](https://support.catenda.com/en/articles/4670277-topic-board-settings-page) for sist åpnede saksliste.

## 2. **Saker-mal-innstillinger**

Klikk på Konfigurer saker-maler for å gå til [Saker-mal-innstillinger-siden](https://support.catenda.com/en/articles/14076010-topic-template-settings-page). _Tilgang påkrevd:_ Prosjektadministrator På Saker-mal-innstillinger-siden kan maler konfigureres for hver av sakslisten. Når saker genereres, avhengig av hvilken liste saken genereres i, kan konfigurerte maler velges for automatisk å fylle inn tekst og felt.
