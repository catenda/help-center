# Er det mulig å gi en bruker skrivebeskyttet tilgang?

Det finnes ingen generisk "skrivebeskyttet" rolle, men du kan begrense tilgangen til kun lesing på både Dokumenter og saker. På denne måten kan en bruker nektes muligheten til å redigere eller kommentere på Dokumenter og saker i prosjektet. For Dokumenter kan du begrense mapper eller individuelle filer. For saker er begrensningen satt på tavlen selv og gjelder alle saker på denne tavlen.
