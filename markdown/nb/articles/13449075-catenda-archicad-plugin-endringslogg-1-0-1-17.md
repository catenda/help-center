# Catenda Archicad plugin endringslogg - 1.0.1.17

Denne endringsloggen dekker versjon 1.0.1.17 av Catenda Archicad-plugin-en.

## 1. **Oktober 2026: oversettelser lagt til**

Plugin-en viser nå grensesnittet sitt oversatt, inkludert på japansk. Dette endret ikke versjonsnummeret: det ble bare lagt til oversettelser.

## 2. **September 2026: nye funksjoner**

Støtte for Archicad 29 Det er nå mulig å velge mellom survey point og project origin i coordinates action menu. Viewpoints er nå plassert i forhold til koordinatinnstillingen konfigurert i coordinates action menu. Støtte for ny Status Workflow med publiserte og delte major og minor revisions.
