# メンバーページの右側メニュー

[メンバーとチームページ](https://support.catenda.com/en/articles/4670291-members-and-teams-page)上の要素を選択して、情報ボタンが検索またはフィルターバーの右側に表示されるようにします。このボタンはページ上のここにあります:

![メンバーページのメンバータブ。矢印が指している](https://raw.githubusercontent.com/catenda/help-center/main/images/kjpvqc84/01-intro.png)

情報ボタンは次のようなものです:

![メンバーページの右メニュー用ボタン](https://raw.githubusercontent.com/catenda/help-center/main/images/kjpvqc84/02-intro.png)

このアイコンをクリックして、選択した要素のフィールドを変更できるメニューを開きます。

この記事では、以下のトピックについて説明しています:

## 1. メンバータブの右メニュー

メンバータブの右メニューは以下のようになります：

![メンバーの詳細](https://raw.githubusercontent.com/catenda/help-center/main/images/kjpvqc84/03-right-menu-on-the-members-tab.png)

1つのメンバーが選択されている場合、そのメンバーのイニシャルまたはアバター、名前、メールアドレスがメニューの上部に表示されます。

次に、選択されたメンバーの数と総メンバー数が表示されます。

### 1.1 **メンバーロール**

このメンバーに管理者またはメンバーのステータスを付与します。プロジェクトオーナーのロールを変更することはできません。

![プロジェクトオーナーのロールを更新することはできません](https://raw.githubusercontent.com/catenda/help-center/main/images/kjpvqc84/04-member-role.png)

プロジェクトオーナーではないメンバーの場合、チームを変更できます。_必要なアクセス権：_ 管理者

### 1.2 **チームからメンバーを追加および削除**

追加チームフィールドと削除チームフィールドの両方は同じように動作します。フィールドをクリックして1つ以上のチームを選択します。ドロップダウンのチームをクリックして選択内容に追加します。フィールドに入力して選択可能なチームを絞り込みます。Enterキーを押してドロップダウンの最初のチームを選択内容に追加します。_必要なアクセス権：_ 管理者

### 1.3 **メンバーの設定を保存**

選択されたメンバーのロールが選択されたロールと異なる場合、そのメンバーのロールが更新されます。テーブルで選択されたメンバーのうち、チーム追加選択内のチームにまだ属していないメンバーは、それらのチームに追加されます。テーブルで選択されたメンバーのうち、チーム削除選択内のチームに属しているメンバーは、それらのチームから削除されます。

**削除が優先されます**メンバーがチームに属しているかどうかに関わらず、チームが「チーム追加」と「チーム削除」の両方の選択内に含まれている場合、メンバーは属しているチームから削除され、属していなかったチームには追加されません。

## 2. **チームタブの右メニュー**

チームタブの右メニューは以下のようになります：

![チームの詳細を表示する右メニュー。ロール設定とメンバーの追加および削除ができます](https://raw.githubusercontent.com/catenda/help-center/main/images/kjpvqc84/05-right-menu-on-the-teams-tab.png)

1つのチームが選択されている場合、そのチームのイニシャルまたはアバター、名前、メンバー数がメニューの上部に表示されます。

### 2.1 **チームロール**

このチームに管理者またはメンバーのステータスを付与します。_必要なアクセス権：_ 管理者

### 2.2 **チームへのメンバーの追加および削除**

メンバー追加フィールドとメンバー削除フィールドの両方は同じように動作します。フィールドをクリックして1つ以上のメンバーを選択します。ドロップダウンのメンバーをクリックして選択内容に追加します。フィールドに入力して選択可能なメンバーを絞り込みます。Enterキーを押してドロップダウンの最初のメンバーを選択内容に追加します。_必要なアクセス権：_ 管理者

### 2.3 **チームの設定を保存**

選択されたチームのロールが選択されたロールと異なる場合、そのチームのロールが更新されます。メンバー追加選択内のメンバーのうち、チームテーブルで選択されたチームにまだ属していないメンバーは、そのチームに追加されます。メンバー削除選択内のメンバーのうち、チームテーブルで選択されたチームに属しているメンバーは、そのチームから削除されます。

**削除が優先されます**メンバーがチームに属しているかどうかに関わらず、メンバーが「メンバー追加」と「メンバー削除」の両方のフィールドで選択されている場合、そのメンバーは選択されたチームのうち属しているチームから削除され、属していなかったチームには追加されません。
