# Model設定

Modelはtranslation，IFCファイルのrevisionのコンテナと見なすことができます。ドキュメントがファイルのコンテナであるのと同じです。Modelとドキュメントの違いは、Model内のIFCファイルの内容が完全に処理され、すべてのID、オブジェクトに接続されたデータを持ち、階層ごとに生成された2Dプランを持つことです。ユーザーは多くの場合、研究分野ごとに1つ以上のModelを持っています。Modelはコンテンツパネルの[Modelsページ](https://support.catenda.com/en/articles/4670270-model-overview-page)でアクセスおよび設定できます。また、3Dビューアパネルのrevisionセレクターにも表示され、コンテンツパネルを開かずにそれらをオン/オフにする簡単な方法があります。

## 1. ユーザーにModelの作成を許可する

管理者はmodelを作成できますが、時にはModelerがすべてのドキュメントを見ることなく新しいmodelを作成できるようにしたいことがあります。この場合、[プロジェクト設定](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3)でmodel作成を許可することができます。プロジェクト設定でmodelを作成するアクセス権を取得した場合、右上の[新しいmodelボタン](https://support.catenda.com/en/articles/4670270-model-overview-page#h_0c6f0e7347)をクリックして、エクスポートの横のドットをクリックし、[modelを削除](https://support.catenda.com/en/articles/4670270-model-overview-page#h_0c6f0e7347)をクリックすることで、modelを作成および削除できます。
