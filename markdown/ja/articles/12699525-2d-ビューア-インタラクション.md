# 2D ビューア インタラクション

> 2D ビューア とのインタラクション

[2D ビューア](https://support.catenda.com/en/articles/4854537-2d-viewer)のさまざまなコンポーネントは、異なる方法でインタラクションできます。2D ビューア のクリック可能な各部分について説明されています。2D ビューア はこのようになります:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/01-intro.png)

この記事では、次のトピックについて説明します: _[2D ボタン](#h_ddfb1f5837) - [トップ バー](#h_7996dde66c) - [キャンバス](#h_d564366bf9) -_ [ナビゲーション](#h_b384896c43) - [選択](#h_8916df6427) - [設定](#h_f9d34c17aa) - [ボトム バー](#h_15dafd8ad4)

## 1. **2D ボタン**

2D ビューア が開いていない場合は、3D ビューア の右下にある 2D ボタンをクリックして 2D ビューア を開きます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/02-2d-button.png)

## 2. **トップ バー**

### 2.1 **サイズ変更**

この 2 つの対角線をドラッグして、2D ビューア を 3D ビューア の任意の部分にサイズ変更します。カーソルが変わったら、このコーナーをドラッグできることがわかります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/03-resizing.png)

### 2.2 **タイトル**

トップ バー のタイトルはストーリーの名前になります。[ストーリー コンフィギュレーター](https://support.catenda.com/en/articles/6921756-storey-configurator-page)ビルのストーリーが選択されている場合、タイトルはビルの名前と現在のストーリーの名前を含みます。構成されていないモデルのストーリーが選択されている場合、タイトルはモデルの名前を含みます。

### 2.3 **2D ビューア の開閉**

**閉じる** 2D ビューア の右上のクロスをクリックして、2D ビューア を閉じます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/04-opening-and-closing-the-2d-viewer.png)

## 3. **キャンバス**

2D ビューア のキャンバスは、2D ビューが有効になっているさまざまなモデルのストーリーに接続された線が表示される 2D ビューア の部分です。

### 3.1 **マウス ボタンをクリック**

_左クリック_ モデルに対して 2D ビューが有効になっているストーリー内にスペースがある場合、それらをクリックして選択できます。スペース 2D ビュー内に名前が表示されているかどうかを確認することで、スペース内にスペースがあるかどうかを判断できます。

**スクロール** 2D ビューア をズームイン/ズームアウトします。

**右クリック**コンテキスト メニューを開く

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/05-click-mouse-button.png)

- _マーカーを追加_
  新しいマーカーを追加します。コンテンツ パネルでトピックを開くと、選択したマーカーを割り当てることができます。このマーカーは、問題に追加されるまで保存されず、他のユーザーに表示されません。
- _マーカー付きの新しいトピックを作成_
  マーカー付きの新しいトピックを作成します。このマーカーは、トピックが送信されるまで保存されず、他のユーザーに表示されません。
- _クエリを作成_
  - スペースと交差 - 選択されたスペースと交差するすべてのオブジェクトの[クエリ](https://support.catenda.com/en/articles/4854514-queries)を作成します
  - ストーリーと交差 - このストーリーと交差するすべてのオブジェクトの[クエリ](https://support.catenda.com/en/articles/4854514-queries)を作成します

### 3.2 **マウス ボタンを保持**

**左または右をクリックして保持** 2D ビューア をパンします

### 3.3 **ビューポイント インジケーター**

**ビューポイント インジケーターの左クリックを保持** 3D でカメラを移動します。カメラ角度は変わりません。

**ビューポイント インジケーターで右クリックを保持** 3D でカメラを移動します。カメラの角度に従います。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/06-viewpoint-indicator.png)

## 4. **ナビゲーション ツール**

### 4.1 **範囲にズーム**

ズームアウトして、すべての表示可能なオブジェクトを一度に表示します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/07-zoom-to-extents.png)

### 4.2 **回転**

回転ボタンを使用して 2D ビューア を回転させることができます。

**回転スライダー**初期回転は、[プロジェクト設定](https://support.catenda.com/en/articles/4670273-project-settings-page)で回転のある場所を設定することにより構成できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/08-rotation.png)

**スライダーの調整**スライダーをクリックして選択し、左右の矢印キーを使用して 0.1 度の調整を行います。これは、選択、セクション、クエリを作成するのに役立ちます。回転は、スペースを最初に選択する場合、回転時にスペースのエッジにスナップするため、簡単になります。スライダーの下のメニューに回転の度数を書き込むこともできます。

**True North**プロジェクト設定で初期回転が構成されていない場合、True North はリセット ボタンと同じになります。プロジェクト設定で初期回転が構成されている場合、True North は初期回転に対して角度になる可能性があります

**リセット**右上の [リセット] をクリックして、スライダーを初期回転にリセットします。

**下敷き描画の回転**ビルディングは[ストーリー コンフィギュレーター](https://support.catenda.com/en/articles/6921756-storey-configurator-page)で構成できます。ビルディング内の各ストーリーは、プロジェクト内のモデルに対して相対的に回転する下敷きとしての描画を持つことができます。

### 4.3 **カメラをロック**

3D ビューア でモデルが読み込まれている場合、3D ビューア カメラにカメラをロックできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/09-lock-camera.png)

この機能が有効になっている場合、ビューポイント インジケーターは 3D ビューア でカメラが移動されても、キャンバス上の中央に留まります。これは[ウォーク モード](https://support.catenda.com/en/articles/5784718-3d-viewer-settings#h_1c05dca226)と組み合わせて使用する場合に便利です。

## 5. **選択ツールと設定**

選択ツールと設定は、2D ビューア キャンバスの右上の方に配置されています。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/10-selection-tools-and-settings.png)

[こちら](https://support.catenda.com/en/articles/8035360-selecting-and-clipping-from-2d)をクリックして、2D ビューア でセクション ツールの使用方法について詳しく説明してください。

### 5.1 **選択**

スペースを選択し、ズームイン/ズームアウトします。

### 5.2 **セクション: オブジェクトを選択**

2D キャンバス上に矩形をドラッグして、2D/3D でのオブジェクト選択の体積を作成します。

### 5.3 **セクション: クリッピング平面を作成**

2D キャンバス上に矩形をドラッグし、高さを選択することで、4 ~ 6 のクリッピング平面を作成します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/11-section-create-clipping-planes.png)

### 5.4 **セクション: クエリを作成**

2D キャンバス上に矩形をドラッグし、高さを選択することで[クエリ](https://support.catenda.com/en/articles/4854514-queries)を作成します。

### 5.5 **ボタンを移動**

セクション ツールの矩形選択機能はカーソルの移動を禁止します。そのため、2D ビューア の右下で移動ボタンを使用できます。このボタンを使用すると、セクション化するためのキャンバスを簡単に再配置できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/12-br-move-button.png)

## 6. **2D ビューア 設定**

2D ビューア の設定は、歯車アイコンのドロップダウン ボタンにあります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/13-2d-viewer-settings.png)

**マーカー色分けモード** 2D ビューのマーカーの色を、以下のいずれかの色に変更します:

- ステータス
- タイプ
- 期日

**スペース名形式**ルームとスペースの長い名前を表示する

**半透明** 2D ビューア を透視にします

## 7. **ボトム バー**

### 7.1 **モデル ビュー**

ここをクリックしてストーリー メニューについてさらに詳しく読んでください。ストーリー メニューは次のようになります:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/14-model-view.png)

### 7.2 **レイヤー メニュー**

レイヤー ボタンを使用して、2D ビューア でさまざまなレイヤーを切り替えることができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5nvzd52j/15-layer-menu.png)

**マーカー**このボタンを使用して、マーカーをオン/オフに切り替えることができます。

**モデル**このボタンを使用して、モデルをオン/オフに切り替えることができます。

**描画** [ストーリー コンフィギュレーター](https://support.catenda.com/en/articles/6921756-storey-configurator-page)でビルディング ストーリーの下敷きとしてドローイングが配置されている場合、このボタンが表示されます。このボタンを使用して、配置されたドローイングをオン/オフに切り替えることができます。

**マップ** [プロジェクト設定](https://support.catenda.com/en/articles/4670273-project-settings-page)で場所が構成されている場合、このボタンが表示されます。このボタンを使用して、マップをオン/オフに切り替えることができます。
