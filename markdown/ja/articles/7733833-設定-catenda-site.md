# 設定 - Catenda Site

Catenda Site の設定は[メニュー](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site)にあります。アカウント設定は次回ログイン時に復元されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/an1f6vfe/01-intro.png)

この記事では以下のトピックについて説明しています：

## 1. **設定**

アカウントの設定を構成します。

### 1.1 **ホーム画面**

1\. プロジェクトホームページを変更: トピック / ダッシュボード

### 1.2 **絶対日付形式**

2\. Catenda Site の時間と日付についてより詳しい情報を取得します。

## 2. **テーマ**

3\. ダークモードのオン/オフを切り替える

## 3. **法務関係者**

4\. 利用規約

## 4. **アカウント**

5\. ログアウト ログアウトすると、プライバシーのため、ローカルに保存されたすべてのデータがデバイスから削除されます。たとえば、アウトボックスにトピックがあり、アウトボックスがまだ送信されていない場合、ログアウト時にこれらは失われます。
