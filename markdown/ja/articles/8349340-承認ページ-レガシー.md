# 承認ページ - レガシー

承認ページは、左側のナビゲーションメニューで[ドキュメントページ](https://support.catenda.com/en/articles/8204673-documents-page)のサブページとして表示されます。承認ページはデフォルトでは非表示となっており、[ドキュメント設定](https://support.catenda.com/en/articles/7831371-document-settings)でステータスワークフローが有効になると表示されます。すべての[ドラフトステータス](https://support.catenda.com/en/articles/7831371-document-settings#h_e6f3ffdbff)がアーカイブされ、公開済みステータスのみが削除されると、承認が作成されていない限り、ページは再び表示されなくなります。ここで、プロジェクト内の承認依頼の概要を確認できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xc0e4bsa/01-intro.png)

承認ページでは、以下のことを行うことができます：

- 各承認依頼は、最終確認の前にチームによってレビューおよび検証することができます。最終確認では、承認が要求された改訂を承認すべきかどうかを判断します。
- 承認の進行と結果の設定を行うことができます。
- 新しい承認を作成できます。

この記事で説明されるトピックは次のとおりです：

## 1. **新しい項目のアクション**

新しい項目のアクションはページの右上にあります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xc0e4bsa/02-new-item-actions.png)

### 1.1 **新規承認依頼**

新しい承認依頼を作成します。新しい承認依頼の作成の詳細については、[ここ](https://support.catenda.com/en/articles/12360159-creating-a-new-approval-request)をクリックしてください。

### 1.2 **新しいドラフト承認依頼**

新しいステータスワークフローがプロジェクトに対して有効化される前に残存していたドラフトを含む新しい承認依頼を作成します。新しいドラフト承認依頼の作成の詳細については、[ここ](https://support.catenda.com/en/articles/12360159-creating-a-new-approval-request#h_e06d6cce0d)をクリックしてください。

### 1.3 **承認設定**

承認検証の結果としてトピックがどのように作成されるかを設定します。承認設定の詳細については、[ここ](https://support.catenda.com/en/articles/12367293-approval-settings-page)をクリックしてください。_必要なアクセス権:_ 管理者

## 2. **検索またはフィルターオプション**

承認ページの検索またはフィルターメニューは次のようになります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xc0e4bsa/03-search-or-filter-options.png)

検索バーでは、承認ページで利用可能な任意の承認を検索できます。承認ページでのフィルタリングの詳細については、ここをクリックしてください

## 3. **承認リスト**

承認ページの情報は、一見して理解しやすいように間隔が設定されています。トピックボードを見たことがない人でも理解できます。検索バーの下には、現在のフィルターに一致する[承認](https://support.catenda.com/en/articles/8349418-approval-content)すべてのリストビューが表示されます。承認リストは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xc0e4bsa/04-approvals-list.png)

### 3.1 **行の内容**

**承認行**承認行の内容を開くと、その承認の承認ページが開きます。承認ページの詳細については、[ここ](https://support.catenda.com/en/articles/8349418-approval-content)をクリックしてください。

### 3.2 **カード**

承認リストの各行には、各承認の内容に関する視覚的な手がかりを含む承認カードが含まれています。必要なアクセス権：管理者ステータスに関係なく、以下のいずれかに該当します：

- 選択されたワークフロー用に可能な提出者チームのリストから選択され、その提出者メンバーが承認依頼を提出した提出者チームのメンバー。
- 選択されたワークフロー用のステップのいずれかをレビューするために設定されたレビュアーチームのメンバー。
- 選択されたワークフロー用の最終承認を提出するように設定されたパブリッシャーチームのメンバー。

承認で設定されたフィールドのみがカードに表示されます。したがって、一部のカードは他のカードよりも多くのフィールドを表示する可能性があります。

**タイトル**承認タイトル

**ステータス**承認ステータスはボックスの背景とステータスに応じたアイコンで表示されます。

**パブリッシャー**承認パブリッシャー パブリッシャーが設定されていない場合、書き込みアクセス権を持つ誰でも表示されます。

**期日**承認の期日。承認のカレンダーアイコンとテキストは：グレー - 日付が2週間以上先の場合。オレンジ - 日付が2週間未満先の場合。赤 - 承認が期日を超過した場合。

**作成者**承認作成者および承認が作成された日時。

**承認番号**承認の番号
