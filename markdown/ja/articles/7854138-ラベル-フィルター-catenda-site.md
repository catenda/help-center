# ラベル フィルター - Catenda Site

[Issues](https://support.catenda.com/en/articles/7734073-issues-page-catenda-site) および [ドキュメント](https://support.catenda.com/en/articles/7774637-documents-catenda-site) でラベルでフィルタリングすることが可能です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ge4vaaph/01-intro.png)

フィルタリングするラベルを選択し、「完了」をタップしてフィルターを適用します。

### 他のデバイスからのラベル変更

別のデバイスで行われたこのフィルターメニューのラベル変更を確認するには、[プロジェクトページ](https://support.catenda.com/en/articles/7733978-projects-page-catenda-site)に移動してプロジェクトを再度開いてください。同様に、プロジェクトをリロードするまで新しい外部ラベルを表示することができません。

### ラベルアイコンのリセット

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ge4vaaph/02-reset-label-icon.png)

左上のリセットボタンをクリックして、選択されたすべてのラベルを選択解除できます。(P.S. フィルターに素敵な絵文字を追加したい場合は、Catenda Hub のモバイルブラウザ版でラベル名を変更することで簡単に実行できます)
