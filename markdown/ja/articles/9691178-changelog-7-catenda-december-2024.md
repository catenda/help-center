## 2. **解決されたバグ**

皆さんの貴重なご意見のおかげで、多くの問題を解決することができました。以下は、ユーザーとの対話の結果として開発チームが行った小さな変更のリストです。

### 2.1 **ドキュメント**

- フィルターメニューを再度閉じることが可能になりました
- 削除されたフォルダ内にある場合、ドキュメントのアップロードが不可能になりました。過去には、アップロード ボタンはルート フォルダにデフォルト設定されていました。アップロード メニューはアップロード先のフォルダを表示しますが、フォルダ パスが無効な場合のアップロードは無効になり、ユーザーがプロジェクト全体にファイルを誤って共有することを防ぎます。
- ドキュメントをコレクションに追加することが再度可能になりました
- ドキュメントをスキャンできない場合(サイズが大きすぎる可能性があります)、ウイルスが検出された可能性があるというメッセージは表示されなくなります。
- ドキュメントの左上に注釈が付いたドキュメントをダウンロードすることが再度可能になりました(注釈を新しいリビジョンに保存する変更を加えたときに削除されます)
- ポイント クラウドは問題なく適切にアップロードできるようになりました。
- カスタム フィールド値を変更してもドキュメントは更新されなくなりました

### 2.2 **モデル**

- フィルターメニューを再度閉じることが可能になりました。
- 多くのモデルを持つプロジェクトのダッシュボード ページの読み込みが大幅に高速化されました。
  - コンテンツ パネルでモデル情報を読み込むのは、約 100 倍高速化されました。
- モデルを比較する際に以前のリビジョンを選択することが再度可能になりました。
- ブックマークの 3D ビューでモデルを読み込むことが再度可能になりました。
- 3D でグリッドを非表示にすることが再度可能になりました。
- ウィンドウ開口部は、曲線 IFC 4 壁の平らなセクションを適切に切り抜くようになりました。
- ツリー ビューから選択されたオブジェクトは、再度適切に強調表示されるようになりました。
- プロパティ ライブラリとリンク オブジェクトからオブジェクトを分離することが再度可能になりました。
- オブジェクトの色/マテリアル
  - 以前に表示された一部の色が、再度正しく表示されるようになりました。
  - オブジェクトは、その適切な色ではなく黒く表示されなくなりました。
  - 窓は再度透明になりました。
- 2D ビューは数個のモデルの処理が再実行されているため、欠落していません。
- 右側の情報パネルでオブジェクト プロパティを表示することが再度可能になりました。

### 2.3 **プロジェクト設定**

- カスタム フィールド設定の説明フィールドと長さフィールドで自由に入力することが再度可能になりました。
- メンバー招待フィールドに `;` で区切られたメール リストを貼り付けることが可能になりました
- メンバー招待フィールドのカンマで区切られた貼り付け文字列に `,` または `;` の後にスペースを含めることが可能になりました。

## 3. **ユーザーボイス完了**

### 3.1 **ドキュメント**

- ドキュメントをコレクションに追加する際に、上部のボックスをチェックして、フォルダ内のすべてのドキュメントを選択し、それらをコレクションに追加することが可能になりました。
- ボーナスの改善として、ドキュメントのどのリビジョンをコレクションに追加するかを選択することも可能になりました。これにより、コレクションを最新のリビジョンに従う代わりにドキュメント リビジョンにロックすると、正しいものが表示されます。
- ドキュメントへのフル アクセス権を持つユーザーは、ドキュメントの[リビジョンを取り下げ](https://support.catenda.com/en/articles/9711174-withdraw-revision)ることができるようになり、それが ifc ドキュメントの場合はモデルも取り下げることができるようになりました。
- トピック レポートにカスタム ロゴを追加してPDFにエクスポートすることが可能になりました。
  ロゴ設定は、プロジェクト ページにあります。
- プロジェクトを公開エリアと共有エリアに分割できるようになり、異なるユーザーに公開部分へのアクセスと、ドキュメントがまだ公開準備中の共有部分へのアクセスを提供できます。(プロジェクトでこれを有効にするようにお願いしてください) 公開ドキュメントのみが Catenda Site で表示されます

### 3.2 **モデル**

- 選択の一部であるオブジェクトのセットを更新できるようになりました。これにより、選択に含めたいオブジェクトのセットを変更するたびに新しい選択を作成する必要がなくなります。
- IFCCOLORRGB は IFC4 モデルで正しく表示されるようになりました
- IFC ファイル内の情報は検索可能になりました。(プロジェクト GUID など、オブジェクトに接続されていない情報も含む) これは、Product Query と呼ばれる新しい機能で実行できます。プロジェクトでこれを有効にするようにお願いしてください。
- プロジェクトを公開エリアと共有エリアに分割できるようになり、異なるユーザーに公開部分へのアクセスと、モデルがまだ公開準備中の共有部分へのアクセスを提供できます。(プロジェクトでこれを有効にするようにお願いしてください) 公開モデルのみが Catenda Site で表示されます
