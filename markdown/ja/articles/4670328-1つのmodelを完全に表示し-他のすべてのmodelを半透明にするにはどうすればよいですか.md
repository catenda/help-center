# 他のモデルを半透明にするにはどうすればよいですか？

1. 3Dビューアですべてのモデルを開く
2. tree-panelを開きます（ショートカットはshift-3）。
3. 表示したいモデルを選択（「isolate」）し、そのリストの最上位ノードをクリックします。これにより、このモデル内のすべての要素が選択されます。
4. 最上位ノードを右クリックして「選択以外を透過表示」を選択します。このモデル内のすべてのオブジェクトが完全に表示され、他のモデル内のすべてのオブジェクトが半透明になります。
