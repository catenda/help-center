# 1つのmodelを完全に表示し、他のすべてのmodelを半透明にするにはどうすればよいですか？

1. 3D-viewerですべてのmodelを開く
2. tree-panelを開きます（ショートカットはshift-3）。
3. 表示したいmodelを選択（「isolate」）し、そのリストの最上位ノードをクリックします。これにより、このmodel内のすべての要素が選択されます。
4. 最上位ノードを右クリックして「Isolate」を選択します。このmodel内のすべてのオブジェクトが完全に表示され、他のmodel内のすべてのオブジェクトが半透明になります。
