# ワークフロー ページ - ドキュメント設定

ワークフロー ページは、[ドキュメント設定ページ](https://support.catenda.com/en/articles/7831371-document-settings-page)の承認メニューにある「ワークフローを構成」ボタンをクリックすることで見つけることができます。これは、新しい検証ワークフローが有効になるよう要求されており、[ドキュメント設定](https://support.catenda.com/en/articles/7831371-document-settings-page)のステータスワークフロー メニューで共有ステータスが有効になっているプロジェクト内にあります。新しい検証ワークフローはオンデマンド機能であり、新しいプロジェクトの開始時に有効にするよう要求できます。テンプレート プロジェクトに新しい検証ワークフローが有効になっていない場合、テンプレート プロジェクトに基づいてプロジェクトを作成することは可能です。ワークフロー ページでは、異なる承認構成のワークフローを構成できます。_アクセスに必要な権限:_ 管理者

ワークフロー ページは、次のような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vnbxxjrb/01-intro.png)

以下のトピックについて説明します：

_[新規アイテム アクション](https://support.catenda.com/en/articles/8204673-documents-page#h_d0f4a44fb7) - [検索またはフィルター](https://support.catenda.com/en/articles/8204673-documents-page#h_bbf4dcad58) - [右側メニュー](https://support.catenda.com/en/articles/8204673-documents-page#h_fc89aaa1fe) - [表](https://support.catenda.com/en/articles/8204673-documents-page#h_54e8dfcac2) - [サブページ](https://support.catenda.com/en/articles/8204673-documents-page#h_5751ccd2b7)_

ワークフロー ページは承認ページのサブページであり、承認ページが強調表示されており、上部にあるブレッドクラム によってそれが明らかですが、このページはドキュメント設定の承認メニューからのみアクセス可能です。

## 2. **検索またはフィルター オプション**

これは、ワークフロー ページの検索またはフィルター メニューの外観です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vnbxxjrb/03-search-or-filter-options.png)

検索バーで、ワークフロー ページで利用可能なワークフローを検索できます。

以下のトピックについて説明します：

### 2.1 **左側フィルター パネル**

フィルター ボタンをクリックすると、左側にパネルが表示されます。ボックスをチェックして検索を絞り込みます。これらのフィルターが適用されると、フィルター テキストが URL に追加されます。フィルター処理されたページの URL が共有されている場合、それを開く人は、アクセス権がある限り、現在表示されているのと同じ結果を表示されます。

### 2.2 **フィルター**

> **注:** Web ページの URL は、適用されたフィルターに応じて変わります。これにより、現在フィルター処理されたドキュメント テーブルをプロジェクトの他のメンバーと共有できます。

同じフィルターが複数選択されている場合、それらは `,` または `%2C` で区切られます。複数のフィルターが選択されている場合、それらは `&` または `%26` で区切られます。異なるフィルターとその URL の同等物：

**ステータス**アクティブ - デフォルト - `status=active` アーカイブ済み - `status=archived`

> **注:** アクティブなワークフローとアーカイブ済みのワークフローの両方ではなく、どちらかのみを表示することができます

**検索**テキスト検索 - `search=test` デフォルトでは、テキスト検索はアクティブなワークフローのみに一致します。アーカイブ済みステータスを検索するには、最初にアーカイブでフィルター処理してから、テキスト検索を使用します。

## 3. **ワークフロー テーブル**

ワークフロー テーブルは、次のような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vnbxxjrb/04-workflows-table.png)

[ここ](https://support.catenda.com/en/articles/11748020-tables-on-catenda) をクリックして、Catenda でテーブルを操作する方法の詳細をご覧ください。ワークフローが作成されるとすぐに、ワークフロー テーブルの行として表示されます。

以下のトピックについて説明します：

### 3.1 **行内容**

**ワークフロー行**ワークフロー行の内容を開くと、そのワークフローのワークフロー ページが開きます。これは、ワークフロー ページが開かれたときの外観です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vnbxxjrb/05-row-content.png)

ワークフローのワークフロー ページで、ワークフローがどのように構成されているかを確認できます。

タイトル ワークフロー内で編集可能な唯一の部分は、ワークフローの名前です。

タイムゾーン ワークフローのタイムゾーンが選択されている場合、通年変わりません。ワークフローの地理的位置が選択されている場合、その地理的位置で現在アクティブなタイムゾーンに応じて GMT オフセットが変わります。

更新 更新をクリックして、タイトルを更新します。

### 3.2 **列**

ワークフロー テーブルの一部の列はデフォルトで有効になっており、その他の列は非表示にして有効にする必要があります。構成された列の順序に基づいて、最初の列が表示され、他の有効な列を表示するには、テーブルを横方向にスクロールする必要がある場合があります。ワークフロー ページの列のデフォルトの順序と表示設定は次のとおりです：

タイトル - _デフォルト_ ワークフローのタイトル

作成者 - _デフォルト_ ワークフローを作成したメンバー。

作成日時 - _デフォルト_ ワークフローが作成された日時

ステータス - _デフォルト_ ワークフローのステータス
