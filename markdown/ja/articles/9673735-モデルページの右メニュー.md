# モデルページの右メニュー

右側の情報メニューは、[モデルページ](https://support.catenda.com/en/articles/4670286-models-page)でモデルを選択するか、モデルの[コンテンツページ](https://support.catenda.com/en/articles/4670270-model-overview-page)に入ることで見つけることができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/01-intro.png)

右上の「i」アイコンをクリックして、右メニューを開きます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/02-intro.png)

単一のモデルの場合、メニューは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/03-intro.png)

または複数のモデル行が選択されている場合、このようになります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/04-intro.png)

このアーティクルで説明されているトピックは以下の通りです：

## 1. **モデルヘッダー**

モデルヘッダーには、モデルの最新リビジョンに関する情報が表示されます。

### 1.1 **画像**

モデルヘッダーの上部に、モデルの画像を追加できます。これは、画像が追加されていない場合の見方です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/05-image.png)

ローカル画像をアップロードするか、3Dビューアから直接スナップショットを追加するか、いずれかを選択できます。モデルに対して画像が構成されている場合、モデルページは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/06-image.png)

_右メニューのモデル画像_ 単一のモデルが選択されている場合、またはモデルのコンテンツページでメニューが開いている場合、追加された画像はモデルの右メニューの上部に表示されます。追加された画像は、モデルが選択されたときのモデルリビジョンの右メニュー、およびモデルテーブルの名前列のモデルのサムネイルに表示されます。

[ここ](https://support.catenda.com/en/articles/4670257-creating-a-thumbnail-for-your-model)をクリックして、モデルに画像を追加する方法の詳細を読んでください。

**モデルサムネイル**追加されると、画像はモデルページのモデルテーブルの名前列にモデルのサムネイルとして表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/07-image.png)

サムネイルをクリックして、画像のプレビューを開きます。これはサムネイルプレビューの見方です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/08-image.png)

上部のナビゲーションから、画像をダウンロードできます。スナップショットがモデルから取得された場合、プレビューは3Dプレビューであるため、モデルサムネイルの開始点からモデルの周りをナビゲートすることが可能です。

### 1.2 **ドキュメントリンク**

ドキュメントリンクはモデル画像の下のグレーボックスです。このボックスには、ファイル構造内のドキュメント-モデルの場所が表示されます。その下には、このモデル-ドキュメントにリンクされているドキュメント-モデルの名前が表示されます。このボックスをクリックすると、ドキュメントページのドキュメント-モデルのドキュメントプレビューページに移動します。

### 1.3 **ステータス**

最新の公開ドキュメント-モデルリビジョンのステータス。

### 1.4 **ラベル**

デフォルトでは、ラベルは任意のモデルに適用できます。共有リビジョンが有効化されている場合、ラベルを追加できるようにするには、モデル内に少なくとも1つの公開リビジョンが必要です。ラベルはモデルとモデルがリンクされているドキュメントの両方に保存されます。したがって、同じラベルを使用して、モデルページ上のモデルとドキュメントページ上のドキュメントをフィルタリングできます。

## 2. **共同編集者**

リビジョンをアップロードして、モデルに貢献した異なるメンバーはここに表示されます。

## 3. **モデル変換**

モデル変換を使用すると、モデルオブジェクトをCatenda Hub 3Dビューア内の異なる場所と向きで表示されるように構成できます。この変換はCatenda Hub内の3Dビューアのみに適用され、3Dビューアに読み込まれた3Dドキュメントには適用されません。[ここ](https://support.catenda.com/en/articles/12498975-add-context-to-your-projects-with-freely-accessible-ign-point-clouds-hd-lidar)をクリックして、3Dドキュメントの変換についての詳細を読んでください。

**外部ツールとのモデル交換**モデルはCatendaからダウンロードされ、サードパーティプログラムで開かれることがよくあります。したがって、ダウンロードされたファイルが正しい情報を含むようにアップロード前のIFCファイルに正しい座標を構成することが重要です。

**モデルはいつ変換する必要がありますか？**モデルが送信され、座標がまだ正しくない場合でも、ジオメトリがすでに協力するために使用されている期間がよくあります。これは、プロジェクトで共通のゼロポイントが決定されていない、またはIFCファイルが生成されたオーサリングプログラムで異なるエクスポート方法を検討する必要があるなど、さまざまな理由から発生する可能性があります。この期間中、モデル変換を使用してモデルをCatenda Hubでブラウザを通じてのみ変換することで、3Dスナップショットの再生が新しいリビジョン(更新された座標を持つ)でも一致し続けるように役立てることができます。

**共有リビジョンとの座標協力**共有リビジョンが有効化されているプロジェクトでは、IFCファイルに正しい座標がないまま、モデルリビジョンを公開することは推奨されません。

### 3.1 **モデル変換設定**

3Dビューアで移動するモデルを読み込みます。これはダッシュボードの3Dボタン、モデルページ、モデルコンテンツページ、またはリビジョンセレクターをクリックして実行できます。モデルページの右メニューでは、変換設定メニューがメニューの下部に表示されます。モデル変換設定は次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/09-model-transformation-settings.png)

**オフセット**X、Y、および/またはZ座標を入力してモデルをシフトします。単位-メートル

**回転**モデルを回転させるための角度を入力します。モデルは、モデルのすべてのオブジェクトを含むバウンディングボックスの中点を中心に回転します。このポイントはしばしば上から見たモデルの中央の周辺です。単位-度

**保存**保存をクリックして、変換設定を保存します。

### 3.2 **ブラウザのみ**

変換設定を保存すると、IFCファイルは変更されません。同じプロジェクト内または異なるプロジェクト内のいずれかでIFCファイルを使用して新しいモデルが作成された場合、IFCファイルはIFCファイルで構成された場所で再び表示されます。

短期間、または場合によってはプロジェクト全体の間、Catendaでモデルを移動することは問題ではないことがよくあります。最終的には、共通の座標系を決定して、モデルが作成後に調整を必要としないようにし、プロジェクトの過程での誤解を防ぐために、多くの時間を節約できます。

## 4. **複数選択**

複数のモデルが選択されている場合、右メニューは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/10-multi-select.png)

モデルの横にある赤いxをクリックして、選択から削除します。

### 4.1 **選択したドキュメントを更新**

これは選択したドキュメントメニューの更新の見え方です

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dcxbjfs1/11-update-selected-documents.png)

ラベルを追加および削除する領域をクリックし、複数のラベルを選択します。

_追加が優先_追加およびラベル削除フィールドの両方に入力されたラベルは、まだラベルを持たないモデルに追加され、既にラベルを持つモデルから削除されません。

### 4.2 **最新リビジョン**

入力されたステータスは、変更が保存されたときに、すべての選択されたモデルに対して構成されます。
