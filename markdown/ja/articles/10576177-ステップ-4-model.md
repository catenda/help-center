# ステップ 4 - Model

> フェデレーション model を移動して、オブジェクトを表示および選択できます

> **ヒント:** ヘルプセンターまたはヘルプメニューで[ステップ 3](https://support.catenda.com/en/articles/10576100-step-3-documents) を[はじめに](https://support.catenda.com/en/collections/2657208-getting-started)で見つけてください。

model 領域では、アクセス権に基づいて利用可能なすべての model のリストが表示されます。これらは 3D ビューアで選択してオンにでき、フェデレーション model を直感的に表示および移動できます。
