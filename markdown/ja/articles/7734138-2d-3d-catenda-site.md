# 2D / 3D - Catenda Site

2D / 3D ページは、[メニュー](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site)から、またはボトムナビゲーションバーの問題ボタンをタップすることで見つかります。

![2D / 3D](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/01-intro.png)

2D / 3D ページの例は以下の通りです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/02-intro.png)

2D / 3D ページの上部では、issue board セレクターが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/03-intro.png)

選択した issue board のフィルターから得られた問題は、2D ビューでマーカーが表示される問題です。

### 上半分

2D / 3D ページの上半分には、[3D ビューア](https://support.catenda.com/en/articles/7744403-3d-viewer-catenda-site)が表示されます。

### 下半分

2D / 3D ページの下半分には、[2D ビューア](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site)が表示されます。

### 区切りバー

2つのビューア間に区切りスライダーが表示されます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/04-dividing-bar.png)

このスライダーをドラッグして、各ビューアが占める画面スペースの大きさを構成します
