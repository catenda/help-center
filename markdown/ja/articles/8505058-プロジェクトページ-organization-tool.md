# プロジェクトページ - Organization tool

プロジェクトページは、[organizations profile page](https://support.catenda.com/en/articles/8497478-organization-profile-page)のサブページとして見つけることができます。

ここでは、このorganizationの一部であるすべてのプロジェクトの概要が表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9sr2253p/01-intro.png)

## 1. 検索とフィルター

プロジェクトページでは、以下の項目でフィルタリングできます：

### 1.1 該当なしのフィルタを非表示

"該当なしのフィルタを非表示"トグルはデフォルトでオフになっており、すべての利用可能なフィルターが表示されます。

このフィルターボタンをオンにすると、結果がないフィルターが非表示になります。

### 1.2 作成日 - createdAtFrom=\<UTC timestamp>&createdAtTo=\<UTC timestamp>

選択した日付の間に作成されたプロジェクト

### 1.3 期限切れ - expiration=expired

有効期限を過ぎたプロジェクト。

### 1.4 有効期限なし - expiration=not-expired

期限切れではないプロジェクト。

## 2. アクションボタン

プロジェクトリストから1つ以上のプロジェクト(s)をチェックボックスをクリックして選択すると、プロジェクトリストの上部に以下のアクションボタンが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9sr2253p/02-action-buttons.png)

### 2.1 新規メンバーを追加

追加したいユーザーがorganizationのメンバーである場合、メールによる招待なしでプロジェクトにメンバーを追加できます。

組織ツールのユーザーページで組織のメンバーの概要を確認してください。

"新規メンバーを追加"メニューから、プロジェクトの一部ではなく、メールアドレスで外部ユーザーを招待することもできます。

組織メンバーを複数のプロジェクトに追加したい場合は、ユーザーページでユーザーを選択し、そのページのアクションメニューで「プロジェクトに追加」アクションをクリックして実行することもできます。

### 2.2 移動

選択したプロジェクト(s)を別の組織に移動します

### 2.3 参加

選択したプロジェクト(s)に参加します

### 2.4 退出

選択したプロジェクト(s)から退出します

### 2.5 削除

選択したプロジェクト(s)を削除します

## 3. プロジェクトリスト

プロジェクトリストでは、昇順および降順でソートできる次の列を見つけることができます。

プロジェクトリストのソート順は、Catenda全体の[リストのソート順](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists)に従います。

リストの左上のチェックボックスをクリックして、すべてのプロジェクトを選択します。

### 3.1 チェックボックス

プロジェクトのチェックボックスをクリックして選択します。

プロジェクトを選択すると、リストの上部にアクションメニューが表示されます。

期限切れのプロジェクトを選択することはできません。

### 3.2 名前

プロジェクトの名前

プロジェクトの期限が切れていない場合、名前の横に新しいタブで開くリンクアイコンが表示されます。

**メンバー**

名前の下に、このプロジェクトのメンバー数と、このプロジェクトのメンバーであるかどうかが表示されます。

### 3.3 最終更新日

プロジェクトが最後に更新された日時

### 3.4 作成日

プロジェクトが作成された日時

### 3.5 有効期限

プロジェクトの有効期限の日時。

赤い場合は、プロジェクトの有効期限が切れていることを意味します。
