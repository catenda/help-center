# カスタムフィールドの作成

管理者は、[カスタムフィールドページ](https://support.catenda.com/en/articles/6550459-custom-fields-page)の「新しいカスタムフィールド」ボタンをクリックして、新しいカスタムフィールドを作成できます。「新しいカスタムフィールド」ボタンをクリックすると、作成するカスタムフィールドを選択できるウィンドウが開きます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vvzhr330/01-intro.png)

この記事で説明されている以下のトピック:

## 1. **フィールド名**

フィールドの名前

## 2. **タイプを設定**

_テキスト_ - 任意のテキストを含めることができます

_整数_ - 整数のみを含めることができます

**小数点以下の数字**小数点以下のフィールドは、小数点以下最大6桁まで表示されます。小数点以下が6桁を超える場合は、科学記法が使用されます。

**ドロップダウン**ドロップダウンカスタムフィールドを作成する場合は、ドロップダウンリストに[値を追加](https://support.catenda.com/en/articles/8445588-custom-field-page#h_45eefa3001)する必要があります

## 3. **説明**

カスタムフィールドの説明

> **注意:** 「**送信**」をクリックしてフィールドを保存することを忘れないでください。
