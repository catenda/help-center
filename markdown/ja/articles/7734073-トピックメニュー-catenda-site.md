# トピックメニュー - Catenda Site

トピックメニューは[メニュー](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site)から、またはボトムナビゲーションバーのトピックボタンをタップすることで見つけることができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/01-intro.png)

トピックメニューでは、上部に現在のプロジェクトの名前が表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/02-intro.png)

プロジェクト名の下にドロップダウンメニューが表示されます。このメニューまたは検索アイコンをタップすると、表示するトピックボードを選択できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/03-intro.png)

新しいトピックボードに切り替えると、切り替え先のボードの最新のトピック情報が更新されます。

## 1. **フィルター**

メニューの右側にフィルターボタンが表示されます。フィルターは各トピックボードごとに保存されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/04-filters.png)

以下の条件でフィルタリングできます：

- 自分のトピック
- ステータスと種類
  - ステータスまたは種類がプロジェクトに追加されたか、既存のステータスまたは種類の名前が変更された場合、このステータスを持つトピックはステータスと種類の名前を持ちますが、色は灰色になります。
  - [プロジェクトページ](https://support.catenda.com/en/articles/7733978-projects-page-catenda-site)に戻ってプロジェクトを再度開くまで、これらのステータスをフィルタリングして色を表示することはできません。
- [ラベル](https://support.catenda.com/en/articles/7854138-label-filter-catenda-site)
- 期日
- 場所

### 1.1 フィルターのリセットアイコン

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/05-reset-filter-icon.png)

フィルターをリセットアイコンをタップして、自分のトピック、期日、または場所のフィルター設定を削除します。このボタンをタップすると、選択されたステータス、種類、ラベルの選択も解除されます。

## 2. **トピックリスト**

このメニューでは、フィルターに従ったトピックが表示されます。

### 2.1 **トピックの更新**

トピックリストを下にドラッグして、トピックボード内の最新の変更を取得します。

### 2.2 **トピックエントリ**

各トピックについて、以下の情報が表示されます：

**左寄せ**トピック番号 トピック名 ステータス、種類、ラベル リクエスター 担当者 マイルストーン 期日 作成日

**右下**場所 コメント数

### 2.3 **新規トピック**

中央にプラスが付いた緑色の円をタップして、新しいトピックを作成します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/06-new-topic.png)
