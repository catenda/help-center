# Catenda for Power BI (On Demand) について

> Catenda for Power BI は、Catenda Hub プロジェクトデータを Power BI に取り込みます。ビジュアルと既製のレポートテンプレート付きの次のバージョンがオンデマンドで利用可能です。

Catenda for Power BI は、Catenda Hub プロジェクトのデータを Microsoft Power BI に取り込み、プロジェクトの model、ドキュメント、トピックに関するレポートを作成できるようにします。リリース済みの[Catenda Power BI Connector](https://support.catenda.com/ja/articles/5784721-catenda-power-bi-コネクタ)は、すべての Catenda のお客様にご利用いただけます。次のバージョンはオンデマンドで提供されており、一般公開に先立ち、どなたでもリクエストできます。

## 1. **それは何ですか**

次のバージョンでは、プロジェクトのデータをはるかに多く Power BI に取り込む新しいコネクタ、レポート内にプロジェクトの model とトピックを表示するビジュアル、および既製のレポートテンプレートが提供されます。まだ多くの変更が行われているため、長期にわたるレポートではなく、試用目的で提供されています。

## 2. **はじめに**

Catenda for Power BI は Catenda Hub のプロジェクトと連携します。これを使用するには、Catenda セールスに最初のプロジェクトで開始することについてお問い合わせください: [https://catenda.com/get-started](https://catenda.com/get-started) または [sales@catenda.com](mailto:sales@catenda.com)。

> **注:** Catenda ユーザーには、より多くの情報が利用可能です。[https://hub.catenda.com](https://hub.catenda.com) で Catenda にサインインし、ヘルプセンターのページを開くか再度読み込んでください。ヘルプセンターは、サインイン済みのユーザーにより多くの情報を表示します。[Catenda for Power BI (On Demand) の概要](https://support.catenda.com/ja/articles/17778865-catenda-for-power-bi-on-demand-の紹介)（サインイン済みユーザーのみ）から始まります。
