# 既存のトピックボードからのトピックボード

新しいトピックボードの作成は、[ボードページ](https://support.catenda.com/en/articles/9413644-boards-page)の新しいトピックボードアクションをクリックして行えます。このアクションは、右上の緑色のプラスボタンまたはその隣のアクションメニューから見つかります。必要なアクセス権：[プロジェクト設定ページ](https://support.catenda.com/en/articles/4670273-project-settings-page)のアクセスメニューで新しいトピックボードを作成するための書き込みアクセス権。

新しいトピックボードページは以下のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/01-intro.png)

この記事では、以下のトピックについて説明します：

## 1. **名前**

トピックボードに最小限の名前を付けて、トピックボードを追加します。トピックボードリストは、トピックボード名に従って、Catendaの一般的な[リストのソート順序](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists)に従ってソートされます。したがって、トピックボードに名前を付ける際に命名規約を使用することをお勧めします。以下は、トピックボードの呼び方の例です：

![トピックボードリスト 紹介 ドキュメント レビュー 承認 コメント付きで承認 却下 ドキュメント breeam socre 調整 コスト プロジェクト](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/02-name.png)

## 2. **説明**

トピックボードの説明はオプションであり、後ではトピックボードへのフルアクセス権を持つユーザーのみがトピックボード設定で表示できます。トピックボード説明は、Catenda上の[投稿のフォーマット](https://support.catenda.com/en/articles/8430847-formatting-of-posts)に関する一般的なルールに従います。

## 3. **既存のトピックボードから設定をコピー**

トピックボード作成時に既存のトピックボードから設定をコピーするには、「既存のトピックボードから設定をコピー」メニューをクリックして、設定をコピー元となるプロジェクト内の既存のトピックボードを選択します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/03-copy-settings-from-an-existing-topic-board.png)

トピックボードを選択した後、コピーする設定を選択することが可能です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/04-copy-settings-from-an-existing-topic-board.png)

### 3.1 **ステータスとタイプをコピー**

ステータスとタイプをコピーするラジオボタンをアクティブにして、作成するトピックボードで同じステータスをステータス名、色、メタステータスタイプとともに取得します。

### 3.2 **権限設定をコピー**

権限設定をコピーするラジオボタンをアクティブにして、作成するトピックボードで同じステータスを色とともに取得します。

## 4. **BCF 1.0 との互換性**

BCF バージョン 1.0 までのみをサポートする他のトピック管理ツールへのトピックのエクスポートに使用されるトピックボードは、互換性のためにロックされるべきであり、Catenda で生成されたトピックが相手側でエラーなく到着することを確認します。BCF 1.0 トピックは別の場所で生成されても、ボードが互換性のためにロックされているかどうかに関わらず、任意のトピックボードにインポートできます。

### 4.1 **ステータスまたはタイプの編集は不可**

トピックボードを互換性のためにロックすると、トピックボードで利用可能なステータスとタイプを編集することはできなくなります。トピックボードが互換性のためにロックされている限り、BCF 1.0 で指定された事前定義のステータスとタイプが利用可能になり、編集することはできません。_ステータス:_ "Open" および "Closed" _タイプ:_ "Error"、"Warning"、"Info" および "Unknown"

### 4.2 **作成後の BCF 1.0 互換性のロックとロック解除**

BCF 1.0 互換性チェックボックスは、トピックボード設定でいつでもオフにして、ボード内で可能なステータスの量を増やすことができます。トピックボードのステータスが BCF 1.0 と互換性がない場合、互換性のないステータスを削除して、作成後いつでもボードを BCF 1.0 互換性に再度ロックすることも可能です。

### 4.3 **ロックされているボードから設定をコピー**

別のトピックボードメニューから設定をコピーする際にトピックボードが選択されている場合、BCF 1.0 互換性チェックボックスはロックされ、設定をコピーする選択したトピックボードが BCF 1.0 互換性に対してロックされているかどうかに応じて、チェックされるかどうかが決まります。

## 5. **追加**

追加をクリックして、新しいトピックボードを追加します。

> **注：** トピックボードを追加できるには、少なくとも名前を持つ必要があります

トピックボード作成時に通知はありません。

## 6. **プロジェクト作成時のトピックボード作成**

新しいプロジェクト作成時、プロジェクトはデフォルトでトピックボード「Issues」で開始されます。プロジェクト作成時にテンプレートプロジェクトからのトピックボードのチェックボックスがチェックされている場合、プロジェクトは選択されたテンプレートプロジェクトからのトピックボードとトピックボード設定で開始されます。

> **注：** これらの新しいトピックボードの設定はテンプレート内のトピックボードと同じですが、トピックボード、ステータス、およびタイプの GUID はそれらが存在するプロジェクトに固有のものです。
