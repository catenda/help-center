# 承認依頼にリビジョンを追加

共有リビジョンが2025年10月2日以降に有効になったプロジェクトでは、承認依頼を表示できます。共有リビジョンが有効になると、すべての新しいリビジョンが共有リビジョンとしてアップロードされます。共有リビジョンは、[承認依頼の作成ダイアログ](https://support.catenda.com/en/articles/12360159-creating-a-new-approval-request)でリビジョン追加ボタンをクリックするか、ドラフト承認でリビジョン追加ボタンをクリックすることで、承認依頼に追加できます。共有リビジョンが有効になったプロジェクトの場合、以下のようなリビジョン追加から承認依頼ダイアログが表示される可能性があります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qk34ake7/01-intro.png)

2025年10月2日より前に共有リビジョンが有効になったプロジェクトには、代わりにレガシーのリビジョン追加から承認依頼ダイアログが表示されます。

この記事では、以下のトピックについて説明しています：

## 1. 検索またはフィルター

検索バーでは、ドキュメント内の最新公開リビジョン後にアップロードされたマイナーリビジョン番号(0.1、0.2、1.1など)を持つ共有リビジョンを検索できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qk34ake7/02-search-or-filter.png)

### 1.1 フィルター左パネル

フィルターボタンをクリックすると、左側にパネルが表示されます。チェックボックスをチェックして検索を絞り込みます。これらのフィルターはフィルターリストの上部に保存できます。これらのフィルターのいずれかが適用されると、フィルターテキストがURLに追加されます。フィルターされたページのURLが共有されている場合、それを開く人は、アクセス権がある限り、現在表示されているのと同じフォルダー内の同じフィルターが表示されます。左側のパネルのフィルターにマウスを合わせると、フィルターの右側の「のみ」をクリックして、他の以前に適用されたフィルターを削除できます。

### 1.2 保存済みフィルター

[ここ](https://support.catenda.com/en/articles/8551755-saving-filters)をクリックして、フィルターセットを保存する方法についてさらに詳しく読む

### 1.3 フィルター

**リンク済み**現在3Dビューアーで選択されているオブジェクトにリンクされている現在のフォルダーとサブフォルダー内のドラフト。フィルターの後ろの番号は、現在のフォルダーとサブフォルダー内でリンクされているドキュメント数を示します

**リンク未設定** 3Dオブジェクトにリンクされていない現在のフォルダーとサブフォルダー内のドラフト。フィルターの後ろの番号は、リンクされていないドキュメント数を示します

選択したオブジェクトにリンク済み 現在3Dビューアーで選択されているモデルからの3Dオブジェクトにリンクされている、現在のフォルダーとサブフォルダー内のドキュメント内の共有リビジョン。フィルターの後ろの番号は、現在のフォルダーとサブフォルダー内で選択したオブジェクトにリンクされているドキュメント数を示します

**ステータス**

公開ステータス名 選択した公開ステータス名で現在のフォルダーとサブフォルダー内の公開リビジョンと一致します。公開ステータスを持つリビジョンは承認に追加できないため、このフィルターでは結果が表示されません。フィルターの後ろの番号は、選択したオブジェクトにリンクされている現在のフォルダーとサブフォルダー内のドキュメント数を示します。

共有 現在のフォルダーとサブフォルダー内のすべての共有リビジョンと一致します

共有ステータス名 選択した共有ステータス名で、現在のフォルダーとサブフォルダー内のすべての共有リビジョンと一致します

**モデル**はモデル 現在のフォルダーとサブフォルダー内のモデルにリンクされている、ドキュメント内の共有リビジョン。

モデルではない 現在のフォルダーとサブフォルダー内のモデルにリンクされていない、ドキュメント内の共有リビジョン。

**ドキュメント作成者**ユーザー名により作成された、現在のフォルダーとサブフォルダー内のドキュメント内の共有リビジョン。フィルターの後ろの番号は、各ユーザーによって現在のフォルダーとサブフォルダー内に作成されたドキュメントとフォルダーの数を示します。

**リビジョン作成者** \<ユーザー名>により作成された、現在のフォルダーとサブフォルダー内のドキュメント内の共有リビジョン。フィルターの後ろの番号は、各ユーザーによって現在のフォルダーとサブフォルダー内のドキュメント内の共有リビジョン数を示します。

**日付フィルター**日付を選択をクリックして、検索する日付範囲を選択します [ここ](https://support.catenda.com/en/articles/6511685-date-filter)をクリックして、日付フィルターについてさらに詳しく学びます。

**ラベルグループ**ラベルグループ内のラベル名によるラベル付きの共有リビジョンを持つドキュメント。フィルターの後ろの番号は、現在のフォルダーとサブフォルダー内でラベルが適用されているドキュメント内の共有リビジョンを持つドキュメント数を示します。

**カスタムフィールド**カスタムフィールドによるカスタムフィールド値を持つ共有リビジョン。

**未解決の承認**承認依頼名で他の未解決の承認に含まれている共有リビジョン。

**削除済み**削除されたドキュメントでフィルタリングしてリストで選択することは可能ですが、承認に追加されても何も起こりません。フィルターの後ろの番号は、現在のフォルダーとサブフォルダー内の削除されたフォルダーとドキュメント数を示します。_必要なアクセス権_: 管理者

## 2. リビジョンテーブルの追加

これは追加リビジョンテーブルがどのように見えるかの例です

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qk34ake7/03-add-revision-table.png)

[ここ](https://support.catenda.com/en/articles/11748020-tables-on-catenda)をクリックして、Catendaのテーブルの操作方法についてさらに詳しく読んでください。

### 2.1 行内容

ドキュメントの確認テーブルの行は、確認されるドキュメント内の共有リビジョンへのアクセスに基づいて表示されます。_必要なアクセス権 -_ ドキュメントへの読み取りアクセスおよび共有リビジョンの表示チェックボックスがチェックされている。

**フォルダー行**フォルダー行の内容を開くと、テーブルが変わり、リビジョンの追加テーブルでそのフォルダーの内容が表示されます。

**ドキュメント行**ドキュメントリビジョン行の任意の場所をクリックすると、ドキュメントが選択され、承認に追加できます。

### 2.2 列

設定された列の順序に基づいて、最初の列が表示されますが、テーブルを横にスクロールして他の有効な列を表示する必要がある場合があります。ドキュメントページの列のデフォルトの順序と表示設定は以下の通りです：

チェックボックス - _デフォルト_ チェックボックスをチェックして、共有リビジョンを承認依頼に追加できるようにします

_名前_ - _デフォルト_ 共有リビジョンが含まれているドキュメントの名前。

リビジョン - _デフォルト_ リビジョン列では、ドキュメント内の最新共有リビジョンのリビジョン番号が表示されます。最新公開リビジョン後にアップロードされた複数の共有リビジョンがある場合、矢印がリビジョンボックスに表示されます。矢印が付いたリビジョンボックスをクリックして、このドキュメントのリビジョンドロップダウンテーブルを開きます。

> **ヒント:** リビジョンドロップダウンテーブルでは、以下の列が利用可能です: 名前 - _デフォルト_ リビジョンの名前。これはアップロードされたファイルの元のファイル名と同じです。 # - _デフォルト_ リビジョンの番号 ステータス - _デフォルト_ リビジョンに適用されたステータス ファイルサイズ - _デフォルト_ リビジョンのファイルサイズ 作成者 - _デフォルト_ リビジョンの作成者

ドキュメント当たり一度に追加できるリビジョンは1つのみです。選択したドキュメントから別のドキュメントリビジョンが以前に追加された場合、それは上書きされ、そのドキュメントからの新しいリビジョン選択のみが承認依頼に追加されます。

ステータス - _デフォルト_ 共有リビジョンに適用されたステータス。

アップロード者 - _デフォルト_ 共有リビジョンをアップロードしたメンバー。

## 3. 追加

リストでドキュメントを選択し、追加をクリックします

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qk34ake7/04-add.png)

ドキュメントから共有リビジョンが追加されるとすぐに、その人のドキュメンテーブルの行として表示されます。

### 3.1 制限事項

承認依頼の作成ダイアログを通じて承認依頼を送信するか、ドラフト承認依頼を送信すると、ドキュメントリストは編集できなくなります。リビジョン追加から承認依頼ダイアログに多くのドキュメントを追加することは可能ですが、承認依頼ダイアログを最大1000個のドキュメントリビジョンで送信することのみ可能です。1000を超えるドキュメントリビジョンを追加するには、まず承認依頼作成ダイアログで最大1000個のドキュメントを追加し、承認依頼をドラフトとして保存します。次に、送信前に、ドラフト承認依頼ページのドラフト承認依頼にドキュメント追加アクションで追加のドキュメントを任意の数だけ追加してから、承認依頼を送信します。
