# フロア設定ページ

> 2D ビューのオーバーレイとして PDF を使用する方法

プロジェクト内でフロアを設定することで、[2D ビューア](https://support.catenda.com/en/articles/4854537-2d-viewer)で準備されたビューをプロジェクトメンバー用に作成できます。フロア設定ページは、[モデルページ](https://support.catenda.com/en/articles/4670286-models-page)のサブページにあります。このページで使用されるフロアとビルディングの名前は IFC 標準から来ています。フロアとビルディングという用語は社会基盤でより多く使用されることがありますが、このツールは物理的またはデジタルインフラストラクチャプロジェクトにおいて、同様に有用であり、さらに有用である場合もあります。_アクセス権限:_ プロジェクト管理者

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/01-intro.png)

プロジェクト内のメンバーは、プロジェクトで利用可能なさまざまなモデルから生成されたジオメトリを使用して 2D ビューをオン/オフにすることでフロアを構成できます。モデルセットから生成された 2D ビューをプロジェクト内のメンバーが利用できるようにするために、フロアを設定して構成されたフロアを作成します。PDF ドキュメントをフロアにアンダーレイして、生成されたモデルジオメトリでは表示されない可能性のある線を表示します。

## 1. **アクション**

ストーリーコンフィギュレーターページのアクションメニューは、右上の緑色のプラスボタンの右にある3つのドットをクリックすることで見つけることができます。

![新しい建物を追加](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/04-actions.png)

### 1.1 **新しい建築物を追加**

[ここ](https://support.catenda.com/en/articles/12291366-storey-configurator-actions)をクリックして、新しい建築物を追加する方法の詳細をご覧ください。

### 1.2 **PDF**

この記事の手順を完了するには、アンダーレイとして PDF が必要な各フロアに対して PDF プランが必要です。

> **注：** 各フロアは別々のPDFに含まれている必要があります。1つのフロアに複数のPDFを含めることができます。

## 2. **セットアップ**

2D モデルとすべてのモデルが見えるようにビューを設定します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/05-setup.png)

## 3. **フロア設定**

ここでPDFプランを2Dビューと配置します。これは各フロアに対して1回実行する必要があります。

デフォルトでは、概要に1つのビルディングがあります。これには、インポートされたIFCのレベルも含まれます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/06-storey-configuration.png)

ビルディング名の設定は重要です。後に表示されるため、わかりやすい名前を選択してください。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/07-storey-configuration.png)

すべての IFC レベルはフロアで表されます。ここで名前と標高を設定できます。

> **注:** 標高を変更すると、2D ビューの表現が変更されます。

フロア内で、オーバーレイを設定してから、"詳細オプションを表示"をクリックできます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/08-storey-configuration.png)

"フロアに添付された図面"機能が表示されます。追加をクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/09-storey-configuration.png)

ダイアログが開き、アップロードされた PDF を求めるメッセージが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/10-storey-configuration.png)

必要な PDF を選択したら、"このドキュメントを追加"をクリックします。これにより、配置ダイアログが表示されます。

## 4. **配置ダイアログ**

ここでオーバーレイを定義して配置します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/11-alignment-dialogue.png)

ビルディングが選択されている必要があります。残っているのは、図面と配置するフロアを選択することだけです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/12-alignment-dialogue.png)

これで、選択した PDF と選択したフロアが画面に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/13-alignment-dialogue.png)

マーカーAとBを使用してオーバーレイの位置を定義します。選択するポイントが一致している必要があります。たとえば、2つのグリッドの交点を選択することが最適です。

マーカーをドラッグアンドドロップして配置します。図面をスクロールしてズームすることもできます。

配置後、"次へ: 結果を確認"をクリックします

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/14-alignment-dialogue.png)

### 4.1 **承認ダイアログ**

マーカーの位置を確認すると、承認ダイアログが開きます。ここでオーバーレイを確認して、目的に合っているかどうかを確認できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/15-approve-dialogue.png)

"前へ: モデルと図面ポイントを配置"をクリックして、いつでも変更を加えることができます。配置に満足したら、"承認"をクリックして確認します。

これでフロア設定ページに戻り、次のフロアを設定できるようになります。このダイアログでも図面の配置を変更できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/16-approve-dialogue.png)

**重要:** ここで保存構成をクリックする必要があります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/17-approve-dialogue.png)

## 5. **使用方法**

すべてのセットアップが完了したら、毎日の作業で使用できます。ビルディング設定の処理が完了したら、ページを更新できます。モデルビューにいる場合、2D ビューを開くと、ビルディングを選択するオプションがあります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/18-how-to-use-it.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/19-how-to-use-it.png)

名前が変更されたばかりのビルディングを選択します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/20-how-to-use-it.png)

PDF オーバーレイが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/21-how-to-use-it.png)

ストーリーコンフィギュレーターは常に配置された図面(複数)の最新リビジョンを表示します。
