# ナビゲーションメニュー - Catenda Site

メニューの外側の暗い領域をタップしてこのメニューを閉じることができます。メニューの上部またはメニュー内の他の場所から下にドラッグしてメニューを閉じることもできます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0q054pwc/01-intro.png)

1. _[プロジェクトページ](https://support.catenda.com/ja/articles/7733978-プロジェクトページ-catenda-site)_ - ここでプロジェクト間を切り替えることができます
2. _[ダッシュボード](https://support.catenda.com/ja/articles/7213817-ダッシュボード-catenda-site)_ - プロジェクトダッシュボード。
3. _[イシュー](https://support.catenda.com/ja/articles/7734073-トピックメニュー-catenda-site)_ - 最後に開いたissue board
4. _[2D / 3D](https://support.catenda.com/ja/articles/7734138-2d-3d-catenda-site)_ - [2Dビューア](https://support.catenda.com/ja/articles/7748370-2dビューア-catenda-site)と[3Dビューア](https://support.catenda.com/ja/articles/7744403-3d-ビューア-catenda-site)
5. [ドキュメント](https://support.catenda.com/ja/articles/7774637-ドキュメントメニュー-catenda-site) - ドキュメントセクション
6. _[設定](https://support.catenda.com/ja/articles/7733833-設定-catenda-site)_ - 設定ページ
