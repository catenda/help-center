# 承認依頼ドキュメント右メニュー

この記事には、以下のトピックに関する情報が含まれています: _[レビュー中](#h_b398f04f49) - [ステップ概要](#h_be2d5b96e1)_右メニューは、承認依頼ページの[ドキュメントタブ](https://support.catenda.com/en/articles/12495130-documents-tab-in-an-approval-request)でドキュメントを選択することで開くことができます。1つのドキュメントを選択するか複数を選択するかに応じて、メニューの表示は異なります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/01-intro.png)

### 複数選択：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/02-multiple-selection.png)

複数のドキュメントを選択すると、「ドキュメントをレビュー」ボタンをクリックして、選択内容を直接レビューできます。

### 単一選択：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/03-single-selection-br.png)

単一選択を行うと、右メニューに概要が表示されます。これは2Dビューアのドキュメント-レビューで開くメニューと同じですが、ドキュメントの視覚表示は表示されません。レビュアーは、ドキュメントを開かずに承認/却下または送信できます。

### ステップ進捗状況

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/04-steps-overview.png)

これはステップ進捗状況の例で、レビュアーチームのメンバーが、レビュアーチームに代わってドキュメントを承認すべきとの指示を送信した場合です。ステップステータスと、レビューと送信を行ったチームとメンバーが表示されます。
