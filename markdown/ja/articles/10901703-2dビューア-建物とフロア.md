# 2Dビューア - 建物とフロア

2Dビューアで、モデルオブジェクトを通す2Dカットと、それらのカットの下に敷かれた図面のどちらが表示されるかについての情報は、2Dビューアの右下にあります。建物とフロアのメニューは次のようなものです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/01-intro.png)

## 1. **フロアロック**

### 1.1 **ロック済み**

現在のフロアは常に表示されます

### 1.2 **ロック解除**

現在のフロアは、カメラの高さに最も近い高さのフロアになります。これは[ウォークモード](https://support.catenda.com/en/articles/5784718-3d-viewer-settings)で特に便利です。例えば、階段を上って歩くと、フロアが次のフロアに変わります。

## 2. **建物メニュー**

[フロア設定](https://support.catenda.com/en/articles/6921756-storey-configurator-page)で建物が設定されている場合、建物メニューが表示されます。建物メニューは次のようなものです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/02-building-menu.png)

### 2.1 **フロア設定の建物**

まず、フロア設定で作成された建物がリストされます。これらの建物には、複数の2Dモデルビューが組み合わされ、図面を敷くことができるフロアを含めることができます。

### 2.2 **モデル建物**

次に、2Dビューが有効になっている各モデルで利用可能な建物がリストされます。モデルの2Dビューが有効になると、その2Dボタンがアクティブになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/03-model-buildings.png)

モデル建物の名前は、現在のリビジョンのifcファイル内のIfcBuildingStoreyエンティティで設定されています。モデル建物に名前がない場合は、ここで「名前なし建物」として表示されます。

## 3. **フロアメニュー**

フロアメニューで、現在の建物のフロアが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/04-storey-menu.png)

メニューをクリックして、建物内で利用可能なフロアを確認します。建物に名前がある場合は、リストの上部に太字で表示されます。現在の建物にフロアがない場合、このメニューは利用できません。
