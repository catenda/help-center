# トピックページ - Catenda Mobile

> Catenda Mobileでトピックを閲覧、フィルター、作成します。

> **注記:** Catenda Mobileはアーリーアクセス段階であり、Co-creationプログラムの顧客と共に開発されています。アプリはまだ最終版ではなく、かなり変更される可能性があるため、ページやボタンは、ここに記載されている内容と異なる外観または動作をすることがあります。

トピックページは、[プロジェクトページ](https://support.catenda.com/ja/articles/17601629-プロジェクトページ-catenda-mobile)でプロジェクトを開いた後、画面下部のバーから開かれます。プロジェクトは常にトピックページで開かれます。メニューページの**プロジェクトを切り替え**で開かれた場合も同様です。

トピックページは、プロジェクトのトピックをすべてのトピックリストに表示します。トピックはブラウザーと同じように機能します。

![フィルター、トピックリストピッカー、トピックリストを表示するトピックページ](https://raw.githubusercontent.com/catenda/help-center/main/images/61k1j9km/01-intro.jpg)

## 1. **トピックを検索**

右上の検索ボタンはトピックを検索します。

## 2. **トピックをフィルターして並べ替え**

**担当者**はユーザーに割り当てられたトピックのみを表示します。**並べ替え**はリストの順序を設定します。**ステータス**はプロジェクトのトピックステータスのリスト(アクティブまたは進行中など)を開き、そこで選択されたステータスを持つトピックのみを表示します。

## 3. **トピックリストドロップダウン**

フィルターの下のトピックリストドロップダウンは、リストを特定のトピックリストでフィルターするか、**すべてのリスト**ですべてのリストのトピックに戻します。

## 4. **トピックを作成**

トピックは右下の**+**で作成されます。トピックの作成は、場所を選択し、フロアプランをタップしてピンをドロップし、トピックリストを選択することです。ステータス、タイプ、担当者、コメントはその後に設定されます。

## 5. **トピックリスト**

リストはトピックごとに1枚のカードを表示し、ステータス、番号、タイトル、トピックリスト、画像数、コメント数を表示します。カードをタップするとトピックが開きます。

## 6. **トピックを開く**

開いたトピックは、上部にタイトル、番号、ステータスを表示し、その後に説明とコメントが続きます。タイトルまたは説明の横の鉛筆アイコンでそれらを編集し、画面下部のフィールドでコメントを追加します。ドキュメントをトピックにリンクすることもでき、リンクされたドキュメントを削除することができます。
