# 新しいブックマークを作成する

新しいブックマークは、[ブックマークページ](https://support.catenda.com/en/articles/4670281-bookmarks-page)の[トップボタン](https://support.catenda.com/en/articles/4670281-bookmarks-page#h_e85b08bb62)または特定のブックマークのページで「新規ブックマーク」をクリックして作成できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/01-intro.png)

この記事では、以下のトピックについて説明します：

## 1. 新規ブックマーク

ナビゲーションメニューから3Dビューアを開きます。[ブックマークページ](https://support.catenda.com/en/articles/4670281-bookmarks-page)の右上にある[新規ブックマーク](https://support.catenda.com/en/articles/4670281-bookmarks-page#h_e85b08bb62)ボタンを押します。希望する画面ビューを取得するまでモデル内を移動し、準備ができたら「スナップショットを撮る」をクリックします。

> **注:**クエリを使用してブックマークを作成することはできませんが、クエリを使用して課題内にスナップショットを作成することは可能です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/02-new-bookmark.png)

## 2. 説明を追加（オプション）

希望する場合、ブックマークの説明を作成することができます。これはオプションであり、ブックマークをプライベートにするか、プロジェクト内のすべてのメンバーに表示するかを選択します。その後、作成ボタンを押すと、ブックマークが作成されます。

## 3. 共有

"**プライベートブックマーク / プロジェクトと共有**"を共有するかどうかを選択できます

## 4. モデルとリビジョン

2つのオプションがあります。選択したモデルの"**最新リビジョンに従う**"か、ブックマークを現在のリビジョンに永続的にロックする"**元のリビジョンにロック**"のいずれかです

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/03-models-and-revisions.png)

> **注:**完了するには、作成ボタンをクリックすることを忘れないでください。
