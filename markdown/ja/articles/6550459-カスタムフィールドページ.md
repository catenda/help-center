# カスタムフィールドページ

> トピックリストと命名規則をカスタマイズする

カスタムフィールドページは、[プロジェクト設定ページ](https://support.catenda.com/en/articles/4670273-project-settings-page)のサブページとして見つけることができます。カスタムフィールドを使用すると、テキストフィールド、数値、および値のリストを追加することで、トピックと命名規則をカスタマイズできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7c3te8t3/01-intro.png)

この記事で説明されているトピックは以下の通りです：

## 1. **新規アイテムアクション**

新規アイテムアクションはページの右上に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7c3te8t3/02-new-item-actions.png)

### 1.1 **新規カスタムフィールド**

管理者は、ここで緑色の「新規カスタムフィールド」ボタンを表示できます。カスタムフィールドの作成方法については、[ここ](https://support.catenda.com/en/articles/8445575-creating-a-custom-field)を参照してください

### 1.2 **アーカイブ済みカスタムフィールド**

すべてのユーザーは、アーカイブされており、使用されなくなったカスタムフィールドを表示できます。ここでは、アーカイブされたカスタムフィールドを復元できます。

## 2. **検索またはフィルター**

これはカスタムフィールドページの検索またはフィルターメニューがどのように見えるかです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7c3te8t3/03-search-or-filter.png)

### 2.1 **タイプ**

テキスト - `type=text` 整数 - `type=integer` 十進数 - `type=double` ドロップダウン - `type=enumeration` 日付 - `type=date`

### 2.2 **テキスト検索**

検索 - `search=<Text search>`

**検索可能なコンテンツ**カスタムフィールドのタイトル

**大文字と小文字の区別**テキスト検索は大文字と小文字を区別しません。

**文字数** 1文字以上 検索フレーズと一致するコンテンツは、結果に含まれます。

## 3. **カスタムフィールドテーブル**

カスタムフィールドが作成されるとすぐに、カスタムフィールドテーブルの行として表示されます。これはカスタムフィールドテーブルがどのように見えるかです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7c3te8t3/04-custom-field-table.png)

Catendaのテーブルの操作方法の詳細については、[ここ](https://support.catenda.com/en/articles/11748020-tables-on-catenda)をクリックしてください。

### 3.1 **行のコンテンツ**

カスタムフィールドを作成した後、そのタイプを変更することはできません。任意のフィールドをクリックして、そのカスタムフィールドの[カスタムフィールドページ](https://support.catenda.com/en/articles/8445588-custom-field-page)に移動してください。

### 3.2 **列**

名前 - カスタムフィールドの名前 タイプ - カスタムフィールドのタイプ 説明 - カスタムフィールドの説明

## 4. **カスタムフィールドの有効化**

カスタムフィールドを作成した後、そのフィールドを[トピックリスト内のトピック](https://support.catenda.com/en/articles/6563368-how-to-use-custom-fields-at-my-issues)に追加することも、[命名規則](https://support.catenda.com/en/articles/7869240-how-to-use-custom-fields-in-naming-convention)の値として追加することもできます。
