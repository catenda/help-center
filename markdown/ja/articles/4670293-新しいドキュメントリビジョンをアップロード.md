# 新しいドキュメントリビジョンをアップロード

新しいドキュメントを作成する代わりに、新しいリビジョンをドキュメントにアップロードすることで、ドキュメントのすべてのバージョンを1つの場所に集めることができます。アクションボタンで一度に1つのドキュメントに新しいリビジョンをアップロードすることが可能です。_必要なアクセス権:_ ドキュメントへの書き込みアクセス

この記事では、以下のトピックについて説明します：

## 1. **ドラッグアンドドロップ**

ドキュメントテーブル内のドキュメントの上にファイルをドラッグアンドドロップして、そのドキュメントに新しいリビジョンとしてアップロードします。

## 2. **アップロードメニュー**

アップロードダイアログを通じて、フォルダ内の最大100個のドキュメントに一度に新しいリビジョンをアップロードできます。1つまたは複数のファイルをドキュメントテーブルにドラッグアンドドロップするか、空のフォルダで参照をクリックするか、右上の緑色のプラスボタンをクリックして[ドキュメントアップロードメニューを開く](https://support.catenda.com/en/articles/4670278-uploading-a-document#h_00fa77db3e)ことができます。アップロードメニューでは、ファイルを認識して適切なドキュメントに新しいリビジョンとしてアップロードできます。アップロードダイアログの詳細については、ここをクリックしてください。

## 3. **Zipインポート**

[Zipインポートアクション](https://support.catenda.com/en/articles/7945410-upload-a-zip-file-structure)でインポートされたZipファイル内のファイルと同じ名前のドキュメントが存在する場合、それらは新しいドキュメントではなく新しいリビジョンとして追加されます。

## 4. **ドキュメント構造内のアクション**

単一のドキュメントが選択されている場合、新しいリビジョンアクションは、ドキュメントテーブルの上部に向かって要素が選択されたときに表示される[既存の要素アクションメニュー](https://support.catenda.com/en/articles/4670288-documents-table-actions#h_5785139ce3)にも表示されます。このアクションの利点は、ドキュメント名が何であるかについて混乱がないことです。ドキュメントが選択され、選択したファイルが選択されたドキュメントにアップロードされます。名前について心配する必要はありません。_必要なアクセス権:_ ドキュメントへの書き込みアクセス

## 5. **ドキュメントプレビュー内のアクション**

右上の[ドキュメントアクションメニュー](https://support.catenda.com/en/articles/9323521-document-revision-actions#h_ea6fb90f40)を開くか、新しいリビジョンアイコンをクリックします。新しいリビジョンアクションがシステムのファイルエクスプローラーを開きます。ファイルエクスプローラーから、新しいリビジョンとしてアップロードするファイルを選択できます。このアクションの利点は、ドキュメント名が何であるかについて混乱がないことです。ドキュメントが選択され、選択したファイルが選択されたドキュメントにアップロードされます。名前について心配する必要はありません。
