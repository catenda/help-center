# チームページ

チームのページは、[メンバーページ](https://support.catenda.com/en/articles/4670291-members-page)の右側に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bvhrpsv2/01-intro.png)

## 1. チームプロフィール

チームページの最初のメニューのタイトルには、チームの名前が表示されます。

管理者は、チーム名をクリックして変更することができます。

アバターのアップロードボタンをクリックすることで、チームプロフィール画像をアップロードできます。

## 2. メンバー

ここで管理者は、チームにメンバーを1人ずつ追加または削除できます。

メンバーは招待時にチームを割り当てることもでき、自動的に自分のチームに割り当てられます。

## 3. チームを削除

管理者のみがこのメニューを表示でき、チームを削除するオプションがあります。

## 4. トピック

このチームに担当者として割り当てられた問題

## 5. リビジョン

このチームのメンバーによってアップロードされたmodel revision。

## 6. 権限設定

管理者はこのチームに管理者設定を付与することができます。

この設定はメンバー設定を上書きするため、ユーザーメンバーページでこのユーザーが通常のメンバーとして表示されている場合でも、プロジェクト内では管理者である可能性があることに注意してください。
