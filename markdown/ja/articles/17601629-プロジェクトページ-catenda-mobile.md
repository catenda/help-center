# プロジェクトページ - Catenda Mobile

> Catenda Mobileでプロジェクトを検索して開き、アプリのページ間を移動します。

[Catendaにサインイン](https://support.catenda.com/ja/articles/17601630-catendaモバイルアプリをダウンロード#sign-in)した後、プロジェクトページが開きます。ユーザーがメンバーであるすべてのプロジェクトが一覧表示されます。

![プロジェクトフィルターとプロジェクト一覧が表示されたプロジェクトページ](https://raw.githubusercontent.com/catenda/help-center/main/images/gnhhmk48/01-intro.jpg)

## 1. **ログアウト**

右上の最初のボタンをタップすると、Catendaからログアウトできます。ログアウトすると、アプリがスマートフォンに保存したプロジェクトデータも削除されます。

## 2. **プロジェクトを検索**

右上の検索ボタン(ログアウトボタンの隣)を使用して、プロジェクトを名前で検索できます。

## 3. **プロジェクトをフィルター**

タイトル下のフィルターで、どのプロジェクトを一覧表示するかを選択します。**すべてのプロジェクト**はユーザーがメンバーであるすべてのプロジェクトを一覧表示し、**お気に入り**はお気に入りに登録されたプロジェクトのみを一覧表示します。**ソート**では一覧の順序を設定でき、例えば名前のA~Zの順序で並べることができます。

## 4. **プロジェクトを開く**

プロジェクトをタップするとプロジェクトが開きます。プロジェクトはメニューページの**プロジェクトを切り替え**で開く場合も含め、常にトピックページで開きます。

画面下部のバーはアプリの複数のページへのリンクで、それぞれに独自の記事があります:

- [トピック](https://support.catenda.com/ja/articles/17601633-トピックページ-catenda-mobile): トピックを参照、フィルター、作成します。
- [場所](https://support.catenda.com/ja/articles/17601635-ロケーションページ-catenda-mobile): ビル、階、部屋でプロジェクトをナビゲートします。
- [フォーム](https://support.catenda.com/ja/articles/17601640-フォームページ-catenda-mobile): 検査、チェック、レポートに記入します。
- [ドキュメント](https://support.catenda.com/ja/articles/17601649-ドキュメント-ページ-catenda-mobile): プロジェクトのドキュメントを参照して開きます。
- [メニュー](https://support.catenda.com/ja/articles/17601655-メニューページ-catenda-mobile): メニューページを開き、設定を変更したり、プロジェクトを切り替えたり、ログアウトしたりできます。

別のプロジェクトはメニューページの**プロジェクトを切り替え**で開きます。
