# ドキュメントをアップロード

ドキュメントセクションでは、フォルダにファイルをアップロードできます。Catenda Hubでは、ドキュメントはファイルの異なるバージョン(リビジョン)のコンテナです。ファイルをアップロードする際に、新しいドキュメントを作成するか、ファイルを既存のドキュメントのリビジョンとしてアップロードするかを選択してください。

## 1. **ファイルのアップロード**

ファイルは4つの異なる方法でアップロードできます。各アップロード方法で、ファイルは現在いるフォルダに保存されます。

### 1.1 **1. アップロードボタン**

新しいドキュメントまたはリビジョンをアップロードするには、右上の[+ボタン](https://support.catenda.com/en/articles/4670288-actions-in-the-document-structure#h_7c8e07223e)を押します。これにより[ドキュメントをアップロードメニュー](#h_00fa77db3e)が開きます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y90qfgry/01-1-upload-button.png)

この方法でファイルをアップロードすると、新規リビジョンまたは新規ドキュメントのどちらを作成するかを選択できます。

### 1.2 **2. 新規リビジョンボタン**

ドキュメント構造で選択されたドキュメントの[新規リビジョンアクション](https://support.catenda.com/en/articles/4670288-actions-in-the-document-structure#h_5785139ce3)は、ドキュメントテーブルの上部にある[選択項目ハンバーガーメニュー](https://support.catenda.com/en/articles/4670288-actions-in-the-document-structure#h_fb4e9ef375)にあります。ドキュメントプレビューでは、ページの右上にある[既存項目ハンバーガーメニュー](https://support.catenda.com/en/articles/9323521-actions-in-a-document)内の[新規リビジョンアクション](https://support.catenda.com/en/articles/9323521-actions-in-a-document#h_c18a9b8abf)を使用できます。この方法でファイルをアップロードすると、新規ドキュメントではなく新規リビジョンが作成されます。

### 1.3 **3. ドラッグアンドドロップ**

アップロードするフォルダに移動し、ドキュメントセクション内の任意の場所にドラッグアンドドロップするだけで、ファイルをアップロードできます。ファイルが削除準備ができると、ドキュメントセクションがグレーになり、その周りに点線の枠線が表示され、ファイルを削除できることを示します。この方法でアップロードする際に、新規リビジョンまたは新規ドキュメントを作成することを選択してください。

### 1.4 **4. 空のフォルダ内の参照ボタン**

空のフォルダの参照ボタンをクリックして、[ドキュメントをアップロードメニュー](#h_00fa77db3e)を開きます。この方法でアップロードする際に、新規リビジョンまたは新規ドキュメントを作成することを選択してください。

## 2. **ドキュメントをアップロードメニュー**

ファイルをアップロードすると、アップロード時に現在のフォルダに表示されます。

### 2.1 **参照**

「参照」ボタンをクリックするとシステムファイルエクスプローラーが開き、ここからアップロードするファイル（複数可）を選択できます。Shiftキーまたはコントロールキーを押しながら、[最大100個のファイルを選択でき、各ファイルは最大7GB\*](#h_09bc8fbe94)までです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y90qfgry/02-browse.png)

### 2.2 **ドラッグ&ドロップ**

ファイルエクスプローラーから[最大100個のファイルを各最大7GB\*](#h_09bc8fbe94)でドラッグ&ドロップできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y90qfgry/03-drag-drop.png)

### 2.3 **フォルダ**

このメニューでは、単一のドキュメントのみをアップロードできます。フォルダをアップロードするには、フォルダをzip形式に圧縮して、別の方法でアップロードする必要があります。[Zipをアップロード](https://support.catenda.com/en/articles/7945410-upload-a-zip-folder-structure)の記事を参照してください。

### 2.4 **アップロード制限**

**単一ファイルの制限：**一度に最大100個のファイルをアップロード可能、一度に1ファイルあたり最大7GBをアップロード可能。

**圧縮ファイルの制限:**より多くのファイルを一度にアップロードするか、より大きなサイズのファイルをアップロードするには、「[Zipをアップロード](https://support.catenda.com/en/articles/7945410-upload-a-zip-folder-structure)」機能を使用してください。

**点群の制限:**点群は大きなファイルサイズが多いため、その制限は25GBに引き上げられています。サイズ制限の詳細については[こちら](https://support.catenda.com/en/articles/4670324-is-there-a-size-limit-for-ifc-files)をクリックしてください。

## 3. **デスクトップコネクタ**

[Catendaデスクトップコネクタ](https://support.catenda.com/en/articles/8358861-catenda-desktop-connector)を使用すると、ドキュメントの最新バージョンをローカルシステムからCatenda Hubに自動的かつ定期的にアップロードできます。デスクトップコネクタは通常のアップロードプロセスよりも高速であり、1つの大きなドラッグアンドドロップまたはZipアップロードバッチではなく、ドキュメントをファイルごとにアップロードするため、障害のリスクを最小化します。

## 4. **ドキュメントプレビュー**

Catendaでファイルタイプの内容を表示できるかどうかを確認するには、[こちら](https://support.catenda.com/en/articles/4670320-what-file-types-does-catenda-support)をクリックしてください。

## 5. **ウイルススキャン**

ドキュメントのアップロード後、200MB以下のドキュメントはウイルスをスキャンされます。アップロードされたドキュメントが感染していることが判明した場合、すべてのユーザーに通知が送信されます。このタイプの通知を無効にする唯一の方法は、すべての通知を無効にすることです。ドキュメントが感染しているかどうかは、ドキュメント情報パネルのドキュメント名の下に赤いテキストが表示されるかどうかで確認できます。
