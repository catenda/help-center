# 既存のトピックリストからのトピックリスト

新しいトピックリストの作成は、[ボードページ](https://support.catenda.com/ja/articles/9413644-ボードページ)の新しいトピックリストアクションをクリックして行えます。このアクションは、右上の緑色のプラスボタンまたはその隣のアクションメニューから見つかります。必要なアクセス権：[プロジェクト設定ページ](https://support.catenda.com/ja/articles/4670273-プロジェクト設定ページ)のアクセスメニューで新しいトピックリストを作成するための書き込みアクセス権。

新しいトピックリストページは以下のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/01-intro.png)

## 1. **名前**

トピックリストに最小限の名前を付けて、トピックリストを追加します。トピックリストリストは、トピックリスト名に従って、Catendaの一般的な[リストのソート順序](https://support.catenda.com/ja/articles/8487788-リストのソート順序)に従ってソートされます。したがって、トピックリストに名前を付ける際に命名規約を使用することをお勧めします。以下は、トピックリストの呼び方の例です：

![トピックリストリスト 紹介 ドキュメント レビュー 承認 コメント付きで承認 却下 ドキュメント breeam socre 調整 コスト プロジェクト](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/02-name.png)

## 2. **説明**

トピックリストの説明はオプションであり、後ではトピックリストへのフルアクセス権を持つユーザーのみがトピックリスト設定で表示できます。トピックリスト説明は、Catenda上の[投稿のフォーマット](https://support.catenda.com/ja/articles/8430847-投稿フォーマットツールボックス)に関する一般的なルールに従います。

## 3. **既存のトピックリストから設定をコピー**

トピックリスト作成時に既存のトピックリストから設定をコピーするには、「既存のトピックリストから設定をコピー」メニューをクリックして、設定をコピー元となるプロジェクト内の既存のトピックリストを選択します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/03-copy-settings-from-an-existing-topic-board.png)

トピックリストを選択した後、コピーする設定を選択することが可能です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/00aszxqg/04-copy-settings-from-an-existing-topic-board.png)

### 3.1 **ステータスとタイプをコピー**

ステータスとタイプをコピーするラジオボタンをアクティブにして、作成するトピックリストで同じステータスをステータス名、色、メタステータスタイプとともに取得します。

### 3.2 **権限設定をコピー**

権限設定をコピーするラジオボタンをアクティブにして、作成するトピックリストで同じステータスを色とともに取得します。

## 4. **BCF 1.0 との互換性**

BCF バージョン 1.0 までのみをサポートする他のトピック管理ツールへのトピックのエクスポートに使用されるトピックリストは、互換性のためにロックされるべきであり、Catenda で生成されたトピックが相手側でエラーなく到着することを確認します。BCF 1.0 トピックは別の場所で生成されても、ボードが互換性のためにロックされているかどうかに関わらず、任意のトピックリストにインポートできます。

### 4.1 **ステータスまたはタイプの編集は不可**

トピックリストを互換性のためにロックすると、トピックリストで利用可能なステータスとタイプを編集することはできなくなります。トピックリストが互換性のためにロックされている限り、BCF 1.0 で指定された事前定義のステータスとタイプが利用可能になり、編集することはできません。_ステータス:_ "Open" および "Closed" _タイプ:_ "Error"、"Warning"、"Info" および "Unknown"

### 4.2 **作成後の BCF 1.0 互換性のロックとロック解除**

BCF 1.0 互換性チェックボックスは、トピックリスト設定でいつでもオフにして、ボード内で可能なステータスの量を増やすことができます。トピックリストのステータスが BCF 1.0 と互換性がない場合、互換性のないステータスを削除して、作成後いつでもボードを BCF 1.0 互換性に再度ロックすることも可能です。

### 4.3 **ロックされているボードから設定をコピー**

別のトピックリストメニューから設定をコピーする際にトピックリストが選択されている場合、BCF 1.0 互換性チェックボックスはロックされ、設定をコピーする選択したトピックリストが BCF 1.0 互換性に対してロックされているかどうかに応じて、チェックされるかどうかが決まります。

## 5. **追加**

追加をクリックして、新しいトピックリストを追加します。

> **注：** トピックリストを追加できるには、少なくとも名前を持つ必要があります

トピックリスト作成時に通知はありません。

## 6. **プロジェクト作成時のトピックリスト作成**

新しいプロジェクト作成時、プロジェクトはデフォルトでトピックリスト「Issues」で開始されます。プロジェクト作成時にテンプレートプロジェクトからのトピックリストのチェックボックスがチェックされている場合、プロジェクトは選択されたテンプレートプロジェクトからのトピックリストとトピックリスト設定で開始されます。

> **注：** これらの新しいトピックリストの設定はテンプレート内のトピックリストと同じですが、トピックリスト、ステータス、およびタイプの GUID はそれらが存在するプロジェクトに固有のものです。
