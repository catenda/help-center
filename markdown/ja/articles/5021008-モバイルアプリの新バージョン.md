# モバイルアプリの新バージョン

[モバイルアプリの新バージョン（1.5.0）が両ストアで利用可能になりました！](https://catenda.com/products/bimsync-mobile-app/) 🎉🎉

このバージョンの新機能は以下の通りです：

- より多くの統計情報を提供し、事前定義されたフィルターを使用して問題リストに直接ナビゲートする、まったく新しいインタラクティブなダッシュボード

- 新しい問題を作成する際に複数の画像とビューポイントを追加するためのサポート

- スワイプジェスチャーを使用して問題コメントを削除

- 設定画面が改善されました。これで優先するホーム画面を選択できます

- より有用な情報を提供するための新しいアプリ内通知システム

- すべてのAndroidデバイスのパフォーマンス向上
