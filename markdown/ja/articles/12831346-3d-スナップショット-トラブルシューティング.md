# 3D スナップショット - トラブルシューティング

この記事では以下のトピックについて説明します：

## 1. **ビューポイント設定**

### 1.1 **オブジェクト**

同じ ID を持ち、選択、非表示、または分離されたオブジェクトは、スナップショットが再作成されるときに選択、非表示、または分離されます。2つのモデルが同じ IfcProject GUID (グローバル識別子) を共有している場合、競合が発生して表示の問題が生じ、Catenda Hub がスナップショット再作成時にどのモデル要素を表示すべきかを判断できなくなる可能性があります。

### 1.2 **非表示オブジェクト**

モデル内のオブジェクトの半分以上が表示されている場合、新しい ID を持つオブジェクトは非表示になります。

つまり、トピックコメントスナップショット内でモデルピッカーを使用して新しいモデルを追加する場合、モデル内のオブジェクトの半分以上が表示されていると、追加されたモデルが完全に非表示になる可能性があります。新しい ID を持つオブジェクトを表示するには、スナップショットを再作成した後、「すべて表示」を使用してモデルを表示できます。トラブルシューティングを行い、非表示のモデルを強制的に表示するには、3D ビューア内の「すべて表示」オプションを使用できます。3D ビュー領域を右クリックし、コンテキストメニューから「すべて表示」を選択すると、構成の競合によって引き起こされた表示の問題が一時的に解決されるはずです。

## 2. **スナップショットを再作成**

トピックの 3D スナップショットを再生する場合、特定のモデルが表示されない可能性があります。この問題は、IfcProject GUID の重複など、プロジェクトの問題に起因する可能性があります。これを解決するには、プロジェクト内の各モデルが一意の識別子を使用していることを確認します。さらに、3D ビューア内の「すべて表示」オプションを一時的な解決策として使用します。

### 2.1 **スナップショットモデルピッカー**

このメニューでは、スナップショットを Catenda モデルにのみリンクします。正しいモデルが自動的に見つからなかった場合、ここで手動でリンクできます。複数のモデルが同じ GUID を持っている場合でも、最初のモデルだけではなく、すべてのモデルを選択して有効にすることができます。これは BCF の内容を変更しないため、外部ツールで開く場合、オブジェクトは依然として非表示のままの可能性があります。

スナップショットのオブジェクト表示設定によっては、追加されたモデルが完全に非表示になる可能性があります。リビジョンセレクターまたはモデルページを開いて、どのモデルが 3D ボタンを有効にしているか確認し、スナップショットを再作成した後、どのモデルが 3D ビューアに読み込まれているかを確認します。読み込まれていても、モデルのすべてのオブジェクトが非表示になる可能性があります。「すべて表示」アクションを使用して、非表示のオブジェクトを表示します。。

## 3. **スナップショットの BCF インポート**

BCF トピックがインポートされると、プロジェクト内のモデルの ID がスナップショット内で構成されたモデルの ID と比較されます。インポート時に存在する ID を持つモデルのみが、スナップショットが再作成されるときに 3D ビューアに読み込まれます。

2つのモデルが同じ ID を持つ場合、最初のモデルのみが有効になります。正しいモデルが有効になるようにするには、各モデルが独自の ID を持つことが重要です。

オーサリングソフトウェアから異なる複数のファイルをエクスポートしている場合、エクスポートする異なるモデルごとに一意の ID を使用することをお勧めします。スナップショット再作成中の競合を回避するため、プロジェクト内のすべてのモデルに一意の IfcProject GUID を割り当てることをお勧めします。これにより、Catenda Hub が 3D ビューア内の構成を正確に表示できることが保証されます。

これを Revit で行う方法について説明している BuildingSMART の記事はこちらです [https://user.buildingsmart.org/knowledge-base/ifcproject/](https://user.buildingsmart.org/knowledge-base/ifcproject/)

将来作成されるトピックが認識できるように、どの ID がどのモデルに使用されたかを追跡しておくことを忘れずに。
