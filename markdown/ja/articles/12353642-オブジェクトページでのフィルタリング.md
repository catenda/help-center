# オブジェクトページでのフィルタリング

オブジェクトページのフィルターパネルは、オブジェクトページの検索バーの左側にあるフィルターボタンをクリックすることで開くことができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/01-intro.png)
これは、検索またはフィルターメニューを開いたときの見た目です:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/02-intro.png)

## 1. **フィルター**

左上のフィルターボタンをクリックして、左側にパネルを表示させます。フィルターが適用されると、ブラウザに表示されるURLがそれに合わせて変更されます。このガイドでは、フィルターは以下のように表示されます。_メニュー内のフィルター名_ - `URL内のフィルター名=URL内のフィルターオプション`

**デフォルトフィルター**デフォルトフィルターは最初、URLに表示されません。ページが初めてナビゲートされるとき、次のフィルターが適用されます。

**フィルターなし**

### 1.1 **現在のフィルターを保存して共有する**

フィルターが適用されたページのURLに移動して、そのページをフィルターが適用された状態で読み込みます。適用されたフィルターはフィルターメニューの上部に保存できます。フィルターを保存して共有する方法については、[こちら](https://support.catenda.com/en/articles/11401493-saving-a-filter-link)をご覧ください。

### 1.2 **空のフィルターを非表示**

フィルター結果を制限することについて詳しく知るには、[こちら](https://support.catenda.com/en/articles/8551755-saving-filters)をご覧ください。

### 1.3 **モデル**

フィルターメニューのモデルカテゴリーの右側にある「3D」をクリックして、3Dビューアに現在読み込まれているすべてのモデルをフィルタリングします。

モデル名 - `model=<Model GUID>` プロジェクトモデルのセットをフィルタリングします。

### 1.4 **選択済み**

選択済み - `selected=true` 3Dビューアで選択されているオブジェクトの行のみを表示するようにフィルタリングします。

## 2. **フィルターパネルに表示されないフィルター**

### 2.1 **クエリ**

クエリ検索 - `query=<Product>,<Operator>,<Value>` 検索またはフィルターバーをクリックして、2つの値を比較するフィルターを構成します。

**プロダクト**最初の選択項目は、任意の種類のIFCプロダクトとなります。以下がプロダクトドロップダウンの例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/03-query.png)

**オペレーター**オペレーターは、プロダクトが選択された後にのみ選択できます。クエリフィルターのオペレーター部分は、プロダクトが値とどのように比較されるかを決定します。プロダクトが任意の値を持つことができるかどうか、またはプロダクトが限定された値のセットのみを持つことができるかどうかに応じて、異なるオペレーターから選択できます。

常に利用可能なオペレーター：等しい - `equals` 選択されたプロダクトが正確に入力された値を持つ場合

等しくない - `not-equals` 選択されたプロダクトが正確に入力された値を持たない場合

存在 - `exists` 存在が選択されると、値は選択できず、プロダクトのみ選択できます。すべての値がこのフィルターの一部となるためです。

存在しない - `not-exists` 存在しないが選択されると、値は選択できず、プロダクトのみ選択できます。すべての値がこのフィルターの一部となるためです。

限定された値のセットのオペレーター 以下は、選択されたプロパティが限定された値のセットを持つ場合のオペレータードロップダウンの例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/04-query.png)

含む - `contains`

含まない - `not-contains` 特定の値を含まないプロダクトに関する結果を取得するため

値を持つ - `has-value` 値を持つが選択されると、値は選択できず、プロダクトのみ選択できます。すべての値がこのフィルターの一部となるためです。

任意の値オペレーター 以下は、選択されたプロパティが任意の値を持つことができる場合のオペレータードロップダウンの例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/05-query.png)

範囲内 - `range-inclusive` 範囲内オペレーターが選択されると、2つの値フィールドがあります。以下は、範囲内フィルターを編集する場合のプレビュー例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/06-query.png)

範囲は最初の値から2番目の値までの任意のもになります。

以上 - `greater-than-equals`

より大きい - `greater-than`

以下 - `less-than-equals`

より小さい - `less-than`

**値**値フィールドは、選択されたプロダクトが持つことができる可能な値に応じて異なる動作をします。

数値 選択されたプロダクトが数値のみを持つことができる場合、値フィールドがクリックされるときに矢印が表示され、数字のみを入力できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/07-query.png)

推奨値 プロダクトがテキスト値を持つことができる場合、値フィールドに直接書き込むことができます。以下は、エンティティプロダクトが選択されている場合の値メニューの例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0470bggc/08-query.png)

値フィールドをクリックすると、フィールドの下に推奨要素のリストが表示されます。選択されたプロダクトが限定された値のセットのみを持つことができる場合、この限定された値のセットが推奨要素リストに表示されます。選択されたプロダクトが任意の値を持つことができる場合、推奨要素リストは、この種類の他のプロダクトが持つ値のリストを表示します。
