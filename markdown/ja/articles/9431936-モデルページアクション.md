# モデルページアクション

アクセス権と選択内容によって、モデルとその最新リビジョンのアクションが[モデルページ](https://support.catenda.com/en/articles/4670286-models-page)に表示されます。

この記事では、以下のトピックについて説明します。

## 1. **新規アイテムアクション**

プラスボタンとハンバーガーメニュー項目はページの右上付近にあり、次のようになります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/01-new-item-actions.png)

_アクセス必須:_ モデルの作成またはダウンロード、またはドキュメントセクションのドキュメント-モデルへのアクセス

### 1.1 **新規モデル**

プラスボタンと新規モデルアクションの両方が新規モデルダイアログを開きます。新規モデルダイアログは次のようになります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/02-new-model.png)

モデルページの新規モデルボタンを使用すると、ドキュメント-モデルを配置したいフォルダを選択するよう求められます。

**名前**モデルを作成する前に、モデルに名前を付ける必要があります。

**フォルダ**モデルを作成すると、このダイアログで選択したフォルダにリビジョンのないドキュメントが作成されます。ルートフォルダを選択した場合、ドキュメント-モデルはドキュメントセクションのトップレベルに配置されます。プロジェクトで最初のモデルを作成した後、アカウントのモデルフォルダ設定が保存されるため、毎回選択する必要はありません。後でフォルダをクリックして、モデルを別の場所に配置できます。

**送信時に開いたままにする**複数のモデルを作成する場合は、送信時に開いたままにするオプションを選択できます。このようにして、メニューが開いたままになるため、毎回新規モデルをクリックする必要はありません。一度に多くのモデルを作成する場合は、ドキュメントセクションにアップロードして、代わりにモデル選択アイテムアクション作成を使用することをお勧めします。

**作成**作成をクリックすると、新しく作成されたモデルの[モデル概要ページ](https://support.catenda.com/en/articles/4670270-model-overview-page)に移動します。

_アクセス必須:_ プロジェクト設定でモデルの作成と削除、およびドキュメントセクション内の場所への書き込みアクセス。

**ドキュメントセクションでのモデル作成**ドキュメントセクションに作成するモデルのファイルが既にある場合は、そこで選択して、モデル選択アイテムアクション作成を使用してモデルを作成できます。この方法では、インポートを処理する必要がないため、システムは大きなファイル(700MB以上)をより良くインポートできる可能性があります。ドキュメントセクションで一度に複数のモデルを作成できます。これは、ドキュメントをアップロードして選択し、モデル作成をクリックできるためです。ドキュメントセクションでモデルを作成する場合、モデルセクションのモデル名は、モデルにリンクされているドキュメント名と同じになります。

### 1.2 **エクスポート**

このアクションにより、[モデルエクスポートページ](https://support.catenda.com/en/articles/4670280-model-export)に移動します。ここでは、アクセス権のある各モデルに対して選択したリビジョンを含むzipファイルを作成できます。_アクセス必須：_ モデルセクションの少なくともドキュメント-モデルへのアクセス。

## 2. **選択されたアイテムアクション**

1つ以上のモデルを選択すると、ドキュメントテーブルの上部に次のアクションメニューが表示されます。既存のアイテムアクションメニューは次のようになります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/03-selected-item-actions.png)

### 2.1 **2Dビューア**

2Dビューアアクションを使用すると、上部の2Dアイコンをクリックするか、ハンバーガーメニューを開いて2Dビューアアクションをクリックすることで、選択したモデルを開くことができます。_アクセス必須：_ モデルセクションの少なくともドキュメント-モデルへのアクセス。

### 2.2 **3Dビューア**

3Dビューアアクションを使用すると、上部の3Dアイコンをクリックするか、ハンバーガーメニューを開いて3Dビューアアクションをクリックすることで、選択したモデルを開くことができます。_アクセス必須：_ モデルセクションの少なくともドキュメント-モデルへのアクセス。

### 2.3 **公開**

プロジェクトのドキュメント設定の[ステータスワークフローメニュー](https://support.catenda.com/en/articles/12495583-status-workflow-document-settings)で共有リビジョンが有効化されている場合、作成された新しいリビジョンは最初は共有リビジョンとして開始され、後で公開できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/04-publish.png)

ワークスペースタブでは、各モデルの最新共有リビジョンが行要素に表示されます。公開済みタブでは、各モデルの最新公開済みリビジョンが行要素に表示されます。共有リビジョンは、リビジョン列のアイコンと、マイナーリビジョン番号(0.1、0.2、1.1など)があるという事実によって、公開済みリビジョンと区別できます。_アクセス必須：_ ドキュメント-モデルアクセス設定で共有リビジョンを表示します。最新リビジョンが共有リビジョンであるモデルを選択して、アクションメニューに公開アクションを表示します。_アクセス必須：_ ドキュメント-モデルアクセス設定で公開可能

公開アクションを使用すると、最新の共有リビジョンを公開できます。最新の公開済みリビジョンの後にアップロードされた以前の共有リビジョンは、[モデル概要ページ](https://support.catenda.com/en/articles/4670270-model-overview-page)から公開できます。公開後、メジャー番号(1.0、2.0、3.0など...)の新しい公開済みリビジョンが追加されます。この公開済みリビジョンは、ワークスペースタブと公開済みタブの両方に表示されます。

### 2.4 **最新リビジョンのダウンロード**

モデルのダウンロードにアクセスできる場合は、ダウンロードボタンをクリックできます。これにより、モデルの最新リビジョンをifcファイルとしてダウンロードできます。このモデルの以前のリビジョンを探している場合は、その[モデルページ](https://support.catenda.com/en/articles/4670270-model-page)を参照してください。_アクセス必須：_ モデルセクションの少なくともドキュメント-モデルへのアクセス。

### 2.5 **新規リビジョン**

単一のモデルを選択して新規リビジョンアクションを使用するか、ファイルをリビジョンにドラッグアンドドロップして、そのモデルに新しいリビジョンをアップロードします。_アクセス必須:_ [プロジェクト設定](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3)でモデルの作成と削除、およびドキュメント-モデルへの書き込みアクセス。

リビジョンは、モデルページ上で一度に1つのモデルにのみアップロードできます。ドキュメント領域の「モデルです」フィルターを使用し、そこからアップロードして、一度に最大100個のドキュメントをアップロードします。Catenda Desktop Connectorを使用して、ローカルファイルが変更された場合は定期的なアップロードをスケジュールします。

**何をアップロードできますか?**新規リビジョンアクションで新しいリビジョンをアップロードする場合は、ローカルハードドライブから.ifcまたは.ifczipファイルを選択します。モデルとモデルにリンクされているドキュメントの両方が同じリビジョンを持ちます。ドキュメントセクションの他の3Dファイルタイプはモデルページからのモデルと一緒に3Dビューアに読み込むことができますが、モデルセクションではIFCファイルのみが受け入れられます。[ここ](https://support.catenda.com/en/articles/4670320-previewing-file-types-on-catenda-hub)をクリックして、Catendaでプレビューできるファイルタイプを確認してください。

**プラグインと統合のアップロード** Catendaの多くのプラグインと統合、およびAPIクレデンシャルを持つクライアントによって構築されたカスタムツールにより、新しいリビジョンの作成も可能になります。[ここ](https://support.catenda.com/en/articles/8396532-catenda-plugins-integrations)をクリックして、現在利用可能なプラグインと統合を確認してください。

**リビジョンコメントとその他のメタデータ**ブラウザ経由でCatenda Hubを使用する場合、リビジョンコメントを追加する最良の方法は、モデルにリンクされているドキュメントを設定済みフォルダに配置することです。フォルダにコメントと呼ばれるテキストフィールドを設定して、リビジョンがアップロードされた後、ドキュメントにメタデータとしてコメントを追加できるようにします。APIを使用して送信できるコメントフィールドが存在し、一部のプラグインと統合で利用可能です。送信されると、プラグインと統合からのコメントは、[モデルコンテンツページ](https://support.catenda.com/en/articles/4670270-model-contents-page)の表示コメントボタンで表示できます。

_IFCチェックイン処理_ アップロードプロセスが完了すると、Catenda Hubはifcファイルを分析し、バックグラウンドでジオメトリを生成します。大規模なモデルの場合、ファイルがビューアで作業できる状態になるまでに時間がかかる場合があります。この処理中は、Catenda Hubはジオメトリ生成が中断されずに続行されるため、終了できます。インポートが完了すると、Catenda Hubに通知がポップアップ表示され、さらに新しいバージョンがアクセス権のあるモデルにアップロードされたことを示す通知メールが送信される場合があります。

### 2.6 **リンクをコピー**

リンクをコピーアクションを使用すると、選択した表の行のみを表示するリンクをコピーできます。[ここ](https://support.catenda.com/en/articles/14323982-copy-link-action)をクリックして、リンクのコピーの詳細を確認してください。

### 2.7 **削除**

このアクションにより、モデルをモデルページから削除する前に確認するよう求められます。

> **注:** モデルを削除すると、モデルページからのみ削除されます。ドキュメント-モデルはドキュメントセクションに残り、削除も希望する場合は、選択したドキュメント削除アクションで削除する必要があります。モデルは、モデルセクション内の同じドキュメントから常に再作成できます。

_アクセス必須：_ プロジェクト設定でモデルの作成と削除を行い、削除を試みているモデルへの書き込みアクセスを有します。
