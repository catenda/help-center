# サポートボタンの位置と機能

Catenda Hubにログインした後、黒いメッセージボタンはプロフィール画像の隣の右上に表示されます：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/h6ccqbtd/01-intro.png)

サポートページでは、このボタンを右下に見つけることができます：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/h6ccqbtd/02-intro.png)

サポートバブルを開いた後、次のメニューを見つけることができます：

## 1. **ホーム**

これはサポートバブルを開くと表示されるデフォルトメニューです。右上には、現在アクティブなカスタマーサポート担当者の画像が表示されます。

### 1.1 **お問い合わせ**

お問い合わせボタンをクリックしてお問い合わせください。ここでは、ツール情報、見たい機能のご意見、問題のご報告、または既存/将来のCatendaアカウントに関するご質問など、ご不明な点がありましたらお気軽にお問い合わせください。

### 1.2 **Catenda Connections**

ここでは、外部プログラムのすべてのプラグインのインストールファイルを見つけることができます

### 1.3 **ヘルプを検索**

ここをクリックしてヘルプページの検索を開始してください。デフォルトでは、ブラウザで設定された言語で検索されます。多くの場合、英語でより多くの情報が利用可能です。英語の記事を見つけるには、support.catenda.comにアクセスしてください

### 1.4 **おすすめページ**

検索バーの下に、以下のおすすめページが表示されます: 複数言語のユーザーマニュアル [ハードウェア推奨事項](https://support.catenda.com/en/articles/6921941-hardware-recommendation) [最も重要なショートカットと基本的な操作の概要](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls) [最新のchangelog](https://support.catenda.com/en/collections/2683918-recent-updates)

### 1.5 **ステータス**

これは現在のサービスのステータスを表示します。これをクリックするとstatus.catenda.comに移動し、サーバーステータスに関する更新を購読できます。ここでは、Catenda Hub、Catenda API (Boost)、およびCatenda DUOのサーバーのアップタイムに関する情報を確認できます。また、過去のインシデントもここで確認できます。

## 2. **メッセージ**

ここをクリックして、私たちとの過去の会話を概覧します。任意の会話をクリックして開いてください。

### 2.1 **メッセージを送信**

ここで新しいメッセージを送信できます

## 3. **チケット**

このメニューはデフォルトでは表示されません。チケットを報告した場合、またはサポート担当者があなたのためにチケットを作成した場合、このメニューが表示されます。ここで、以前のフィードバック、バグレポート、または機能リクエストを追跡できます。ご依頼に進展がある場合は、こことメールで通知されます。

## 4. **ヘルプ**

ここでサポートページを検索できます。
