# Catenda Hubの新機能は何ですか？

> お気に入りのプラットフォームの新しいルック・アンド・フィールを発見する

ご覧の通り、当社は新しい製品を提供しています :) ルック・アンド・フィール、名前の他に、Catenda Hubで見つかるハイライトとアップグレードがあります。

## 1. **左側のナビゲーションメニュー**

機能のレイアウトを変更して、ツールに素早くアクセスしやすくしました。Catenda Hubのセクションはよく定義されており、理解しやすくなっています。

![Catenda Hub](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/01-left-navigation-menu.png)

各セクションには、ユーザーが二次機能にアクセスできるようにする折りたたみ可能なサブセクションが含まれています。

## 2. **IFC 4.3のサポート**

Catenda Hubは現在IFC 4.3ファイルのインポートと表示が可能であり、ユーザーはすでにこの形式に関連する新しい機能から利益を得ることができます。この詳細をカバーしている当社の記事を参照してください: [LINK](https://intercom.help/bimsync-arena/en/articles/4670320-previewing-file-types-on-catenda-hub#h_2edd1d4e9c)

## 3. **組織: ユーザーとプロジェクト管理 - ポートフォリオツールセット**

Catenda Hubの[組織](http://bimsync.com/orgs)セクションでは、プロジェクトのメンバー、ロール、プロジェクトメンバーシップを整理するための新しいツールセットが見つかります。ユーザーはプロジェクトから追加または削除でき、プロジェクトは組織間で移動できます…

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/02-organizations-users-and-projects-management-portfolio-toolset.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/03-organizations-users-and-projects-management-portfolio-toolset.png)

## 4. **新しいトピックテーブルビュー**

イシューの[テーブルビュー](https://support.catenda.com/en/articles/6941099-table-view-in-an-issue-board)を更新しました。ユーザーはより多くのコンポーネントをニーズに合わせて調整でき、リストから選択するときにイシュープレビューからも利益を得ることができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/04-new-topics-table-view.png)

## 5. **ドキュメント内の部分名前マッチング**

Catenda Hubに新しいドキュメントをアップロードする際、システムは自動的に同様のドキュメントを提案し、ポップアップウィンドウで提案を表示します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/05-partial-name-matching-in-documents.png)

マッチングエンジンは関連付けにスコアを付与し、最高の結果を提案します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/06-partial-name-matching-in-documents.png)

## 6. **命名規則**

ドキュメントセクションの下に表示される新しい機能「[命名規則](https://support.catenda.com/en/articles/7832559-naming-convention)」が見つかります。これは進行中の作業であり、2023年第4四半期の新機能として配信される予定です。デモおよび試用版を取得するために、Catenda Hubのチャットボタンを使用して当社にお問い合わせください。
