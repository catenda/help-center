# Catenda アーカイビング ポータルについて

> Catenda アーカイビング ポータルを使用すると、Catenda Hub から組織のアーカイブ システムに選択したドキュメントとトピックを転送できます。

Catenda アーカイビング ポータルを使用すると、Catenda Hub プロジェクトから選択したドキュメントとトピックを組織独自のアーカイブ システムに転送でき、プロジェクトの記録が組織が保管している場所に保存されます。これは Catenda Hub の隣にある別の製品です。

## 1. **それが何であるか**

アーカイビングは一方向で実行され、Catenda Hub からアーカイブ システムへ進みます。ポータルは Acos の WebSak+ などのアーカイブ システムに送信できます。

## 2. **はじめに**

アーカイビング ポータルは Catenda Hub のプロジェクトで機能します。これを使用するには、最初のプロジェクトの開始について Catenda セールスに問い合わせてください: [https://catenda.com/get-started](https://catenda.com/get-started) または [sales@catenda.com](mailto:sales@catenda.com)。

> **注:** Catenda のお客様はさらに多くの情報をご利用いただけます。[https://hub.catenda.com](https://hub.catenda.com) で Catenda にサインインし、ヘルプ センターのページを開くか再度読み込みます。ヘルプ センターは、サインインしたお客様にさらに多くの情報を表示し、[Catenda アーカイビング ポータルの概要](https://support.catenda.com/ja/articles/17778822-catendaアーカイブポータルの概要)_(サインインしたお客様のみ)_ から始まります。
