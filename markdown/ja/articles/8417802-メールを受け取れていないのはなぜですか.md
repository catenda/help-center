# メールを受け取れていないのはなぜですか？

Catendaの通知、招待状、または確認メールを受け取れていない場合、いくつかの可能な原因と解決策があります。以下は、メール配信の問題のトラブルシューティングと解決に役立つ包括的なガイドです。Catendaは通知と招待状のメールがユーザー提供のメールアドレスに正常に送信されることを保証します。これはシステムメールログによって確認されます。これにより、メールが処理および送信されたかどうかが検証されます。

この記事では、以下のトピックについて説明しています：

## 1. **メールを受け取れていない**

当社からメールを受け取れていない場合、メールが正しい場所に送信されていないか、またはアカウントがスパム防止のためにブロックされている可能性があります。

### 1.1 **スパムまたはジャンク**

スパムまたはジャンクフォルダをご確認ください。メールがそこに着信している可能性があります。見つかった場合は、「スパムではない」としてマークし、今後の誤分類を防ぎ、より一貫性のあるメール配信を確保してください。

### 1.2 **新しいメールアカウント**

受信ボックスがないか、ネットワークスパム保護がないためにメールがメールアドレスに到達しない場合、メールは当社によってブロックされます。一部のメールサーバーでは、新しいアカウントの受信ボックスを同期するのに最大24時間かかることにご注意ください。したがって、アカウントを作成する前に、メールアドレスを作成してから24時間待ってください。

### 1.3 **再度有効化されたメールアカウント**

メールアドレスが何らかの時点で非アクティブ化され、メールサーバーがメールを送信しようとした場合、このメールは到達できず、アドレスがブロックされている可能性があります。たとえば、会社を離職して後で再び入社した場合、メールアドレスがブロックされている可能性があります。

### 1.4 **MailInBlack**

ご使用の企業がMailInBlackを使用している場合、メールを手動でホワイトリストに登録する必要がある場合があります。ただし、システムログによってメールが正常に送信されたことが確認されている場合、Catendaからのメールのホワイトリスト登録は必須ではありません。MailInBlackの隔離フォルダまたは検証の認証要件を確認できます。

## 2. **リンクのみを受け取っている**

プロジェクト招待状、共有ドキュメント、またはブックマークは受け取っているが、通知を受け取っていない場合、アカウントが検証されていない可能性があります。サインインページでアカウントを作成した場合は、次のメールを受け取っているはずです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jw38grdf/01-only-receiving-links.png)

アカウントが作成されたか、このメールを何らかの理由で受け取らなかった場合、アカウントのメールは検証されません。アカウントのメールが検証されていない場合、すべてのページの上部に灰色のバーが表示されます。この灰色のバーは次のようなものです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jw38grdf/02-only-receiving-links.png)

メール通知を受け取るには、メールアドレスを検証してください。

### 2.1 **メールアドレスを検証**

「メールアドレスを検証」をクリックすると、アカウントに接続されているアドレスに次のメールが送信されます。Catendaでは、灰色のバーは次のようなものになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jw38grdf/03-verify-mail-address.png)

送信されたメールは次のようなものです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jw38grdf/04-verify-mail-address.png)

このメール内のリンクをクリックして、メールアドレスを検証してください。メール内の確認リンクをクリックすると、灰色のバーはCatendaセッションに表示されなくなるはずです。現在のセッションでは、灰色のバーの「検証」を再度クリックして、それを消すことができます。

## 3. **サポートに連絡**

メール受け取りについてサポートが必要な場合は、いつでも[support@catenda.com](mailto:support@catenda.com)のメール、またはこの記事を読んでいるページの右上のプロフィール写真の横にある黒いチャットボタンを使用してお問い合わせください。

サポートに連絡する前に、スパムまたはジャンクフォルダの確認やメールフィルタリングルールの確認など、トラブルシューティング手順を試して、より迅速に問題を解決することをお勧めします。
