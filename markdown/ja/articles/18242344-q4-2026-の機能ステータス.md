# Q4 2026 の機能ステータス

通知スパムを防ぎ、スムーズなローンチを保証するために、新しい動作または既存の動作への変更は、予告なしに段階的にロールアウトされることがあります。頻繁に使用するページの一部の動作の変更に気づいた場合、または新機能について知りたい場合は、すべてのユーザーの動作の最近の変更について更新情報を確認するために、これらの記事を参照できます。

## 1. **新機能**

各ユーザーは異なる方法でプラットフォームを使用しています。新しい機能がリリースされるか、機能に対して変更が行われた場合でも、ユーザーがその機能の一部を使用していない可能性があります。プラットフォーム上の「その新しいボタン」または「その新しいページ」が何であるかに興味のある方のために、この記事には変更内容についての紹介が含まれています。これらの機能については、基本的または若干古いサポートマテリアルのみが利用可能であることが多いですが、これは随時更新されます。サポートで人々を支援することと同様に、記事はしばしば更新され、尋ねられた質問が記事で素早く説明されるのが見つかれば、翌週には更新されます。

### 1.1 **3D での図面**

PDF 図面をモデルとともに [3D ビューア](https://support.catenda.com/ja/articles/8227211-3dビューア) に表示できるようになりました。図面は一度調整すれば、その後は何度でも 3D で開くことができます。

![3D ビューアでモデルの下に表示された PDF 図面、ドキュメント テーブルのビューア列に 3D ボタンがある](https://raw.githubusercontent.com/catenda/help-center/main/images/0j3jpvac/01-drawings-in-3d.png)

**図面を配置する** [ドキュメント ページ](https://support.catenda.com/ja/articles/8204673-ドキュメントページ) のドキュメント テーブルから単一の PDF を選択し、テーブルの上部のアクション メニューから「図面を作成」を選択します。図面に標高を設定し、マーカー A と B を配置してその位置と回転を設定します。これは [ストーリー コンフィギュレーター](https://support.catenda.com/ja/articles/6921756-フロア設定ページ) での方法と同じです。ストーリー コンフィギュレーターまたは IFC モデルからのストーリーで図面を配置します。

**3D で図面を開く**ドキュメント テーブルの上部にあるアクション メニューから 1 つ以上の配置済み図面を選択して、「3D」を選択します。単一の配置済み図面の 3D ビューは、[ビューア列](https://support.catenda.com/ja/articles/8204673-ドキュメントページ#h_face62c318)の「3D」ボタンでオン/オフにすることもできます。ビューア列が表示されていない場合は、「[ドキュメント ページの列](https://support.catenda.com/ja/articles/8466850-ドキュメントページのカラム)」で説明されている通り、最初に表示します。3D ビューアに読み込まれた図面は、ポイント クラウドと GML ファイルと同じ方法で、上部の model ドロップダウンにリストされています。3D での図面は PDF ファイルで機能します。📽️ **[チュートリアル ビデオ](https://eu.guidde.com/playbooks/devAaKxijzjkFmKW8xcgLq?mode=videoAndDoc)**

### 1.2 **アクセシビリティ**

**キーボードとスクリーン リーダー** Catenda Hub は、キーボード単独で、またはスクリーン リーダーで使用できるようになりました。メイン コンテンツにスキップするリンクと F6 キーは、画面の主要領域間を移動し、目に見えるアウトラインはフォーカスの場所を示します。トピック、ドキュメント、承認、モデルはすべて、テーブル、フォーム、ポップアップ、3D ビューア、PDF ビューアを含む、キーボードとスクリーン リーダーで機能します。アイコンのみを表示するボタンには、ユーザーの [インターフェース言語](https://support.catenda.com/ja/articles/4670248-推奨言語の変更) でスクリーン リーダーが読み上げる名前が付いています。エラーメッセージと成功メッセージも読み上げられます。

**色覚異常モード** [アカウント ページ](https://support.catenda.com/ja/articles/6880968-アカウントページ) の「色覚」の下で、色覚異常モードから選択できます。これらは、プロタノピア、デューテラノピア、トリタノピアです。各モードは、区別しやすい色パレットを使用しており、「標準」はデフォルトの色を保持しています。

![標準、プロタノピア、デューテラノピア、トリタノピアのパレットを使用した色覚設定](https://raw.githubusercontent.com/catenda/help-center/main/images/0j3jpvac/02-accessibility.png)

## 2. **更新された機能**

### 2.1 **承認の改善**

**クリック可能な承認ステップ**承認の上部にある [ステップ リボン](https://support.catenda.com/ja/articles/12495212-承認依頼のステップ-リボン) のステップをクリックできるようになりました。ステップをクリックすると、そのステータス、レビュー チーム、日付が表示されます。現在のステップは緑色のアウトラインのままなので、レビューが実際にどこにあるかは明確になります。

**切り替え後のクローズされたレガシー承認**レガシー承認から新しい承認ワークフローに切り替えたプロジェクトは、[承認ページ](https://support.catenda.com/ja/articles/12495047-承認ページ) でクローズされたレガシー承認を確認できるようになりました。これらの承認のドキュメント化と監査証跡は、切り替え後も維持されます。

### 2.2 **コレクション内の共有リビジョン**

[コレクション](https://support.catenda.com/ja/articles/6344318-コレクションページ) は共有リビジョンをサポートするようになりました。これはユーザーから長年リクエストされていた機能であり、コレクションで使用できる用途を広げています。

### 2.3 **Catenda AI Connect**

Catenda AI Connect が更新され、変更は [Catenda AI Connect チェンジログ](https://support.catenda.com/ja/articles/17778717-catenda-ai-connect-チェンジログ) に記載されています _(AI Connect 顧客のみ)_。

### 2.4 **3D ビューア**

**パフォーマンス** 3D ビューアの新バージョンは、特に読み込み中により高速にモデルを読み込み、より少ないメモリを使用します。これにより、以前よりも大規模なプロジェクトを開くことが可能になります。測定ツールはより高速に応答し、大規模なプロジェクトではあまりフリーズしません。モデルはブラウザのズームレベルに関係なく、常に鮮明です。[3D ビューア設定](https://support.catenda.com/ja/articles/5784718-3d-ビューア設定)の表示品質設定は名前が変更され、動作が異なります。デフォルトは現在、適応品質です。

**配置**配置テーブルから、[クリッピング平面](https://support.catenda.com/ja/articles/4670253-切断面)を[配置](https://support.catenda.com/ja/articles/4670327-スライディング-プレーン-ドロップダウン)上の特定のポイントに直接送信できるようになりました。平面を手動で作成してドラッグする必要がなくなりました。断面が配置に沿ってある位置の正確な距離も表示されます。距離を入力すると、断面がそこに直接移動します。

**公開ブックマーク**測定ツールと[クリッピング平面](https://support.catenda.com/ja/articles/4670253-切断面)は、[公開ブックマーク](https://support.catenda.com/ja/articles/8471481-ブックマークコンテンツページ)で使用できるようになりました。

### 2.5 **ドキュメント ビューア言語**

[ドキュメント ビューア](https://support.catenda.com/ja/articles/5001165-ドキュメントのプレビューと注釈)は、ユーザーアカウントで設定された[インターフェース言語](https://support.catenda.com/ja/articles/4670248-推奨言語の変更)に従うようになり、サポートされているすべての言語で動作します。

### 2.6 **通知**

[アカウント通知ページ](https://support.catenda.com/ja/articles/7439223-アカウント通知ページ)、[プロジェクト通知ページ](https://support.catenda.com/ja/articles/4670295-プロジェクト通知ページ)、および右上隅のベルから開くポップアップが再構築されました。

## 3. **オンデマンド機能の有効化**

各オンデマンド機能は本番環境対応で、実際のプロジェクト使用に対応しています。これらの機能は期待通りに動作するかどうかについてはテストされていますが、これらの機能を使用し始めたプロジェクトの数に応じて、未知のエッジケースが見つかる可能性があります。すべてのユーザーがこれらの機能を利用できるようにする過程で変更が発生する可能性がありますが、これらの機能に送信されたデータは削除されません。

### 3.1 **オンデマンド機能の有効化をリクエストする**

一部の機能は、Catenda ライセンスの連絡先によって既存プロジェクト用に有効化されるようリクエストできます。一方、プロジェクト内の設定で有効化できる機能もあります。オンデマンド機能の有効化がリクエストされると、サポート担当者とのミーティングが設定され、機能の現在のステータスについて議論されます。オンデマンド機能をテストできるプロジェクトが既に利用できない場合、限定された期間、機能が使用できる準備ができているかどうかを判断するためにテストできるダミープロジェクトを作成することができます。

### 3.2 **レポートエディター**

プロジェクトメンバーがテーブルからトピックまたはドキュメントを選択し、レポートアクションを使用してレポートを生成できるように、トピックとドキュメント用のレポートテンプレートを作成します。レポートページはオンデマンド機能で、進行中のプロジェクトに対して有効化することをリクエストできます。この機能が有効になっているテンプレートプロジェクトに基づいて作成された新しいプロジェクトには、この機能は有効になっていません。トピックとドキュメント用に個別のテンプレートを作成できます。[レポート作成アクション](https://support.catenda.com/ja/articles/13973721-レポート作成アクション)を使用して、承認からもレポートを作成できます _(レポートエディターの顧客のみ)_。プロジェクトでテンプレートが利用可能な場合、レポートアクションを選択されたトピックとドキュメントで使用して、選択したテンプレートに基づいてレポートを生成できます。ページにさまざまな値を表示する方法に関するサポートは、Catenda によって提供されます。会社に合わせてカスタマイズされたカスタムレポートが必要な場合、これを支援するコンサルタントとの連絡をとることができます。トピック、ドキュメント、承認のサンプルレポートが[既製レポートテンプレート](https://support.catenda.com/ja/articles/17778911-既製のレポートテンプレート)で利用できるようになりました _(レポートエディターの顧客のみ)_。レポートエディターの動作方法は、[レポートエディター](https://support.catenda.com/ja/articles/17778656-レポートエディター)で説明されています _(レポートエディターの顧客のみ)_。

### 3.3 **Catenda for Power BI（オンデマンド）**

Catenda for Power BI のオンデマンド版が利用可能になりました。他のオンデマンド機能と同じ方法でリクエストできます。その詳細は、[Catenda for Power BI（オンデマンド）の紹介](https://support.catenda.com/ja/articles/17778865-catenda-for-power-bi-on-demand-の紹介)で説明されています _(ログイン済み顧客のみ)_。設定方法は、[Catenda for Power BI（オンデマンド）](https://support.catenda.com/ja/articles/17778868-catenda-for-power-bi-オンデマンド)で説明されています _(リクエストに応じのみ)_。

### 3.4 **Catenda Desktop Connector for System Images（オンデマンド）**

Catenda Desktop Connector for System Images のオンデマンド版が利用可能になりました。他のオンデマンド機能と同じ方法でリクエストできます。その詳細は、[Catenda Desktop Connector for System Images の紹介](https://support.catenda.com/ja/articles/17778688-catenda-desktop-connector-for-system-images-の概要)で説明されています _(ログイン済み顧客のみ)_。設定方法は、[Catenda Desktop Connector for System Images（オンデマンド）](https://support.catenda.com/ja/articles/17778690-システムイメージ用-catenda-desktop-connector-オンデマンド)で説明されています _(リクエストに応じのみ)_。

## 4. **コクリエーションプログラム**

一部の機能は、開発中の少数の顧客グループと一緒に構築されます。これらの顧客はコクリエーションプログラムに参加しており、自分のプロジェクトで機能を使用し、フィードバックはそれがどのようになるかを形作ります。

コクリエーション機能はオンデマンド機能と異なります。オンデマンド機能は本番環境対応で、すべてのユーザーが利用できるようになるのを待っているだけですが、コクリエーション機能はまだ最終版ではありません。ページとボタンは、あるバージョンから次のバージョンに移動、名前変更、または置き換えられる可能性があり、それらを説明する記事は機能の変化に応じて更新されます。コクリエーション機能は、完全にリリースされると有料機能になります。

### 4.1 **コクリエーションプログラムへの参加**

Catenda ライセンスの連絡先は、コクリエーションプログラムに参加するよう求めることができます。Catenda 担当者とのミーティングが設定され、機能の現在のステータスと、プログラムに参加することが何を意味するかについて議論されます。

### 4.2 **Catenda モバイル**

[Catenda Mobile](https://support.catenda.com/ja/articles/17601630-catendaモバイルアプリをダウンロード) は、iPhone と iPad 用の TestFlight を通じて、Android 用は Google Play で利用可能な新しいモバイルアプリで、早期アクセスで提供されています。トピック、ロケーション、フォーム、ドキュメントを対象としており、時間の経過とともに [Catenda Site](https://support.catenda.com/ja/articles/6530821-モバイルアプリ-catenda-site-をダウンロード) のすべての機能、さらにそれ以上を提供します。トピックとドキュメントは、ユーザーがメンバーとなっているすべてのプロジェクトで動作します。フォームとロケーションは、機能がオンになっているプロジェクトでのみ使用でき、現在のところ、これはコクリエーションプログラムの顧客のプロジェクトのみです。

アプリはまだ最終版ではなく、かなり変更される可能性があります。Catenda Site は引き続き並行して使用でき、Catenda Mobile にまだない機能が必要な場合に使用するアプリです。
