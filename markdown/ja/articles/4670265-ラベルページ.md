# ラベルページ

ラベルページは、左のナビゲーションメニューの[プロジェクト設定](https://support.catenda.com/en/articles/4670273-project-settings-page)のサブページにあります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/01-intro.png)

ラベルページは以下のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/02-intro.png)

## 1. **上部のボタン**

ラベルページの右上にある緑色のボタンをクリックすると、アクティブなタブに応じて、新しいラベルまたは新しいグループを作成できます

### 1.1 新規ラベル

ラベルタブがアクティブな場合、"新規ラベル"ボタンをクリックすると、ラベルの追加メニューが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/03-new-label.png)

**色**新しいラベルの色を選択します

**グループ**新しいラベルのグループを選択します（オプション）。まだグループが存在しない場合は、ラベルグループ設定ドロップダウンに目的のグループ名を入力して、<グループ名>を作成をクリックできます。グループタブでグループの作成と編集も行えます

**ラベル**ラベル名を選択します

**複数インポート** Excelから最大3列までの表をコピーします。各行がラベル名、グループ名、色に対応します

例：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/04-new-label.png)

Excelから以下をペーストした場合の結果：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/05-new-label.png)

> **注:** ラベルに色を指定しない場合、ラベルは色ドロップダウンで指定された色が適用されます。

ラベルは"コンマ"または"改行"で区切られます。ラベルごとのグループ名は"タブ"、"コロン"、"セミコロン"または"パイプ"で区切られます。ラベルは name:groupname:color として記述されます。ラベルは**"コンマ"**または**"改行"**で区切られます。

`Electrical,Architecture`

以下のようになります

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/06-new-label.png)

---

ラベルごとのグループ名は、**「タブ」**、**「コロン」**、**「セミコロン」**、**「パイプ」**で区切られます。

`Electrical:Trade,Architecture:Trade`

以下のようになります

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/07-new-label.png)

---

第3引数にはhexカラーコードを指定できます

`Electrical:Trade,Architecture::#00ff00`

以下のようになります

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/08-new-label.png)

グループと色は任意です。空白を上書きするにはデフォルトを設定してください。

エラー ラベルにエラーがある場合は、赤く表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/09-new-label.png)

ラベルの上にマウスを重ねて、エラーの原因を確認してください。

考えられる原因：ラベルがプロジェクト内に既に存在する。

ラベル名は一意である必要があります。ラベルがプロジェクト内に既に存在する場合、または同じラベルを複数回追加しようとしている場合は、名前を変更する必要があります

新しいグループの作成 プロジェクト内にまだグループが存在しない場合は、適切な新しいグループを作成するか、それらを破棄するかを確認するメッセージが表示されます。

**送信時に開いたままにする**このチェックボックスをオンにすると、ラベルを送信した直後に新しいラベル追加メニューが開きます。このメニューから複数のラベルを手動で作成したい場合、このオプションを使用すれば、毎回新しいラベルボタンをクリックする必要がなくなり、時間を節約できます。少数のラベルを作成する場合は、新しいラベルボタンをクリックするのと同じくらい速いです

### 1.2 **新しいグループ**

グループタブがアクティブな場合、"新しいグループ"ボタンをクリックすると、ラベルグループの追加メニューが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/10-new-group.png)

**ラベルグループ**ラベルグループ名を選択します

**送信時に開いたままにする**このチェックボックスをオンにすると、ラベルグループを送信した直後に新しいラベルグループ追加メニューが開きます。このメニューから複数のラベルグループを手動で作成したい場合、このオプションを使用すれば、毎回新しいラベルボタンをクリックする必要がなくなり、時間を節約できます。少数のラベルグループを作成する場合は、新しいグループボタンをクリックするのと同じくらい速いです

## 2. **ラベルの変更**

複数のラベルを選択してその設定を上書きします

## 3. **ラベルの削除**

ラベルがトピックまたはドキュメントに接続されていない場合、右側の列の削除をクリックできます。
