# Zipダウンロードのトラブルシューティング

ドキュメントセクションでフォルダまたは複数のアイテムをダウンロードする場合、ダイアログがスクリーンの左下に表示されます。このダイアログには、ダウンロードするZipファイルの準備の進捗が表示されます。

## 1. **パスの予約文字**

フォルダ名に`/`という文字が含まれている場合、これはZipファイル内のパスとして認識され、フォルダは互いにネストされた複数のフォルダに分割されます。フォルダ内のアイテムは、これらのフォルダの最後のフォルダに配置されます。たとえば、ドキュメント`This-is-a-document.pdf`を含むフォルダ`This/is/a/folder`をダウンロードすると、以下のフォルダ構造のZipファイルにダウンロードされます: This is a folder This-is-a-document.pdf

## 2. **ダウンロード不可能なリビジョン**

### 2.1 **ドラフトリビジョン(レガシー)**

ドラフトリビジョンは、リビジョンの右側メニューからのみ個別にダウンロードできます。ドラフトリビジョンのみが選択されている場合、Zipが準備されますが、空になります。これを置き換えるリビジョンの新しいタイプは共有リビジョンであり、通常の公開リビジョンと同じように、ドキュメントテーブルのダウンロードアクションで問題なくダウンロードできます。

### 2.2 **取下げられたリビジョン**

選択内のいずれかのドキュメントの最新リビジョンが取下げられた場合、一部のファイルがダウンロードされないことをユーザーに通知する警告が表示される可能性があります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/169yxgzv/01-withdrawn-revisions.png)

続行を押して準備を続行するか、キャンセルを押してダウンロードを中止します。

## 3. **まだウイルススキャンが完了していない**

最近アップロードされたファイルをダウンロードしようとしている場合、ウイルススキャンがまだ完了していない可能性があります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/169yxgzv/02-not-yet-scanned-for-virus.png)

ダウンロード対象のファイルがアップロードされてから時間が経っている場合は、スキャンされていないファイルについてサポートにお問い合わせください。続行を押して準備を続行するか、キャンセルを押してダウンロードを中止します。

## 4. **ダウンロード準備エラー**

このZipファイルの準備中に問題が発生した場合、以下のエラーが表示される可能性があります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/169yxgzv/03-download-preparation-error.png)

この画面が表示された場合は、サポートにお問い合わせください。
