# Catenda Siteのオフラインモード

建設現場、鉄道トンネル、駐車場の地下など、インターネットに接続できない場所でも、Catenda Siteはポータブルデバイスでの協業に使用できます。この記事では、ネットワークアクセスなしでCatenda Siteを使用して協業する方法について説明します。

## 1. **オフラインモードのトピックメニュー**

ネットワークに接続していない場合でも、トピックメニューは利用可能です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/01-topics-menu-in-offline-mode.png)

> **注:** ネットワークに接続していない場合、**変更は自動的に送信されません。** ネットワークに再度接続した後、変更はアウトボックスからプロジェクトに送信できます。

### 1.1 **オフラインモードのトピックボード**

ネットワークに接続していない場合、トピックリストは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/02-topic-boards-in-offline-mode.png)

以前読み込まれたトピックは通常のトピックとして表示されます。

### 1.2 **オフラインアイコン**

ネットワークに接続せずに作成されたトピックには、オフラインアイコンが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/03-offline-icon.png)

トピックにオフラインアイコンがある限り、プロジェクトに同期されません。

### 1.3 **以前読み込まれたトピック**

以前読み込まれたトピックは、ネットワークに接続せずに開くことができます。トピックを開いた後、トピックタイトルの右側に黄色の"オフライン"ボックスが表示されている場合、オフラインモードで以前読み込まれたトピックを閲覧していることがわかります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/04-previously-loaded-topics.png)

> **注:** ネットワークへの接続が失われたときに読み込まれたトピック内の既存情報は編集できません。

**以前読み込まれたトピックへのコメント**以前読み込まれたトピックは、ネットワークに接続せずにコメントを付けることができます。カメラ/写真からの画像をコメントに追加できます。_必要なアクセス:_ デバイスへのフルアクセス

ログインしているユーザーが作成したコメントは、ネットワークに接続せずに編集および削除できます。

### 1.4 **新規トピック**

ネットワークに接続していない場合でも、新規トピックを作成することができます。作成後、トピックはまだプロジェクトに同期されません。まだプロジェクトに同期されていないトピックを開くと、トピックタイトルの左側にクラウドアイコンが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/05-new-topics.png)

ネットワークに接続できるようになると、これらのトピックは自動的にプロジェクトに同期されません。オフラインモード中に行われた新しい情報と変更は、ネットワークに接続できるようになったときにアウトボックスでプロジェクトに送信できます。

ネットワークに接続せずに作成された新規トピックに追加できる情報は以下のとおりです：

- タイトルを追加できます
- トピックのトピックリストを選択できます
- ステータス/タイプを変更できます
- マイルストーンを追加できます
- ラベルを追加できます
- 説明を書くことができます
- コメントを追加できます。
  - カメラ/写真からの画像をコメントに追加できます。

    _必要なアクセス:_ デバイスへのフルアクセス

- ネットワークへの接続が失われる前にモデルが読み込まれていた場合、これらのモデルの2Dビューにマーカーを配置することで、トピックに位置情報を追加できます。

**新規トピックの編集と送信**

- トピックの最上部に灰色のバーが表示されている場合、新しいオフライントピックを閲覧していることがわかります。
- [アウトボックス](#h_ff2a47f221)を通じてまだ送信されていないオフラインモードのトピックを編集することができます

### 1.5 **アウトボックス**

オフラインモード中にトピックボードで新しい情報と変更が行われた場合、アウトボックスアイコンがトピックボードの右上付近に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/06-outbox.png)

アイコンをタップしてアウトボックスを開きます。ネットワークに再度接続した後、このメニューで新しい情報と変更をプロジェクトに送信できます。

**ローカルドラフト**このリストのトピックは、送信されるまでローカルドラフトと見なすことができます。新しいトピックが作成されたり、既存のトピックにネットワークに接続せずにコメントが付けられた場合、このリストに含まれます。

**アウトボックスの送信**ネットワークに接続せずに行われたすべての新しい情報と変更は、アウトボックスが送信されるまでデバイスに保存されます。ネットワークに接続できるようになったとき、アウトボックスを送信できます。ネットワークに接続していなかった間に行われた新しい情報と変更は、プロジェクトに同期され、すべてのプロジェクトメンバーに表示されます。

## 2. **オフラインモードのモデル**

ネットワークへの接続が失われた場合でも、以前にデバイスに読み込まれたモデルを引き続き使用することができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/07-models-in-offline-mode.png)

### 2.1 **以前読み込まれたモデル**

ネットワークへの接続が失われる前に読み込まれたモデルの2Dビューで、ネットワークに接続せずに2Dビューの位置情報を持つトピックを作成できます。以前読み込まれたモデルは、機能を失うことなくオン/オフを切り替えることができます。

## 3. **オフラインモードのドキュメント**

ネットワークへの接続が失われた場合でも、ドキュメントを引き続き使用できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/08-documents-in-offline-mode.png)

### 3.1 **以前読み込まれたドキュメント**

接続が失われたときに開いていたフォルダまたはコレクション内のドキュメントは、引き続き表示できます。このフォルダまたはコレクションが開いたままである限り、フォルダ内のドキュメントは、アプリケーションの他の部分が使用されている間も表示され続けます。フォルダ内のドキュメントへのアクセスは、フォルダまたはコレクション内にいる場合にのみ利用可能です。別のフォルダまたはコレクションに移動するとドキュメントが読み込まれなくなります。同じフォルダにないドキュメントをコレクションにまとめることができます。こうすることで、ネットワークアクセスが失われる前に、すべてのドキュメントをオフラインで使用するために読み込むことができます。
