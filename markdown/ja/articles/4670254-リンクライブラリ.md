# リンクライブラリ

リンクライブラリは[ライブラリページ](https://support.catenda.com/en/articles/8065645-libraries-page)の2番目のライブラリとして見つけることができます。ここで左側の星をクリックして、プロジェクト内の左ナビゲーションメニューにリンクライブラリを常に表示できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/01-intro.png)

## 1. **トップボタン**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/02-top-buttons.png)

### 1.1 **新しいリンク**

緑色の新しいリンクボタンをクリックして新しいリンクを作成します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/03-new-link.png)

_URL_ - リンクライブラリ内のリンクとしたいURLを貼り付けます。_名前_ - リンクの名前を選択します

送信をクリックすることを忘れないでください

### 1.2 **ハンバーガーメニュー**

新しいライブラリ - ライブラリ作成ページに移動します

## 2. **リンクライブラリのフィルタリング**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/04-filtering-in-the-links-library.png)

フィルターボタンをクリックして、利用可能なさまざまなフィルターを表示します。リンクライブラリでは、以下でフィルタリングできます: _リンク済み_ - `link=linked` _リンク解除_ - `link=unlinked` _選択したオブジェクトにリンク_ - `link=backlink`

## 3. **列**

_チェックボックス_ - リンクを選択できるようにしてから、右側の情報パネルが表示されます。_名前_ - リンクの名前 _URL_ - クリックしてリンクのURLに移動できるボタンが表示されます

**リンク**このリンクにオブジェクトがリンクされている場合、ここにこのリンクにリンクされたオブジェクトの数が表示されます。この数をクリックすると、次のことが可能になります: [3Dビューア](https://support.catenda.com/en/articles/8227211-3d-viewer)でリンク済みオブジェクトを選択 [3Dビューア](https://support.catenda.com/en/articles/8227211-3d-viewer)でリンク済みオブジェクトを分離 [3Dビューア](https://support.catenda.com/en/articles/8227211-3d-viewer)で[クエリ](https://support.catenda.com/en/articles/4854514-queries)としてリンク済みオブジェクトを読み込み
