# 機能ステータス Q2 2026

通知スパムを防ぎ、スムーズなローンチを確保するため、新しい動作または既存の動作への変更は徐々にロールアウトされ、通知されないことがあります。頻繁に使用するページの一部の動作の変更に気づいた人や、新しい機能について知りたい人は、これらの記事を参照して、すべてのユーザー向けの最近の動作変更に関する更新を確認できます。

## 1. **新機能**

各ユーザーはプラットフォームを異なる方法で使用します。新しい機能がリリースされたり、機能に変更が加えられたりしても、ユーザーがその機能の部分を使用していない可能性があります。プラットフォーム上の「その新しいボタン」や「その新しいページ」が何であるかについて知りたい人のために、このアーティクルには変更が何についてであるかの紹介が含まれています。これらの機能については、基本的または若干古いサポート資料しか利用できないことが多いですが、それは私たちが進むにつれて更新されます。サポートで人々を助けることと一緒に、アーティクルはしばしば更新され、尋ねられた質問がアーティクルですぐに説明されているなら、翌週に見つけることができます。

## 2. **更新された機能**

### 2.1 **ツリーパネルのオブジェクト名**

これまでネストされたレベルの名前が表示されていましたが、最も低いレベルのオブジェクトについては、次のような自動生成名が表示されていました：

```
WallStandardCase1.0WallStandardCase1.1WallStandardCase1.2
```

このデフォルト動作は、次のようにインスペクトパネルで表示できるオブジェクトの名前の値を代わりに表示するように変更されました：

```
Basic Wall:Exterior - Insul Panel on Mtl. Stud:140707Basic Wall:Exterior - Insul Panel on Mtl. Stud:140832Basic Wall:Exterior - Insul Panel on Mtl. Stud:140972 
```

違いを確認するには、新しいモデル revision をアップロードする必要があります。

有用な場合がある自動生成名での以前の動作は、各モデルツリーメニューの右上にあるギアアイコンをクリックすることで保持されています。

## 3. **オンデマンド機能の有効化**

各オンデマンド機能は本番グレードであり、実際のプロジェクト使用に対応できます。これらの機能は正常に動作することがテストされていますが、これらの機能を使用し始めたプロジェクトの数は異なる可能性があるため、未知のエッジケースが見つかる可能性があります。これらの機能をすべてのユーザーが利用できるようにするために変更が発生する可能性がありますが、これらの機能に送信されたデータは削除されません。

### 3.1 **オンデマンド機能を有効にするためのリクエスト**

一部の機能は Catenda ライセンスの連絡先者によって既存プロジェクトに対して有効にするようリクエストできますが、他の機能はプロジェクトの設定で有効にできます。オンデマンド機能を有効にするようリクエストされた場合、サポート代表者との会議が設定され、機能の現在のステータスについて議論されます。オンデマンド機能をテストできるプロジェクトがまだ利用できない場合は、ダミープロジェクトを限定期間作成して、その機能がその機能がすぐに使用できるかどうかを検討するためにテストできます。

### 3.2 **レポート エディター**

プロジェクト メンバーがテーブルからトピックやドキュメントを選択し、レポート操作を使用してレポートを生成できるように、トピックとドキュメント用のレポート テンプレートを作成します。レポート ページはオンデマンド機能で、進行中のプロジェクトに対して有効にするようリクエストできます。このフィーチャが有効なテンプレート プロジェクトに基づいて作成された新しいプロジェクトは、このフィーチャが有効になりません。トピックとドキュメント用に個別のテンプレートを作成できます。テンプレートがプロジェクトで利用可能な場合、選択したトピックとドキュメントでレポート操作を使用して、選択したテンプレートに基づいてレポートを生成できます。ページに異なる値を表示する方法のサポートは Catenda によって提供されます。貴社にカスタマイズされたカスタム レポートをご希望の場合は、お手伝いできるコンサルタントにお繋ぎします。
