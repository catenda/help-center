# 2Dビューア

> 2Dツールバーのさまざまなツールについて説明します

2Dビューアを開くには、[3Dパネル](https://support.catenda.com/en/articles/8227211-3d-viewer)の右側の2Dボタンをクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5pdj535/01-intro.png)

この記事では、以下のトピックについて説明します：

## 1. **モデルストーリー**

2Dビューアには、モデルから3Dオブジェクトをスライスして表示します。新しいifcファイルをモデルまたはモデルにリンクされているドキュメントにリビジョンとしてアップロードすると、ifcファイル内のオブジェクトを各ストーリーでスライスした2D画像が生成されます。ストーリーコンフィギュレーターを使用してこれらのスライスを別の高さで表示するように設定することは可能ですが、生成後に各スライスの内容を変更することはできません。ストーリーが表示されている場合、2Dビューアは次のような外観になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5pdj535/02-model-storeys.png)

### 1.1 **デフォルトストーリー**

以前に2Dビューが選択されておらず、プロジェクトのモデルページにモデルがある場合、デフォルトモデルストーリーが表示されます。デフォルトストーリーは、最も関心のあるオブジェクトを持つモデルの最新リビジョンからのストーリーです。関心のあるオブジェクトには、壁、ドア、窓などのオブジェクトが含まれます。

**デフォルトストーリーの設定**ビルが[ストーリーコンフィギュレーター](https://support.catenda.com/en/articles/6921756-storey-configurator-page)で設定されている場合、作成された最初のビルの最初のストーリーが、関心のあるオブジェクトに基づいて選択されたデフォルトストーリーの代わりに表示されます。事前設定されたストーリーが予想どおりに表示されない場合はプロジェクト設定を二重チェックし、必要に応じてストーリーコンフィギュレーターの設定を再度確認してください。

### 1.2 **利用可能なストーリー**

さまざまなストーリーの2Dビューをモデルから2Dビューアにさまざまな方法で読み込みます。

**2Dボタン**モデルの2Dボタンをクリックします。モデルの2Dボタンは複数の場所にあります：

- [リビジョンセレクター](https://support.catenda.com/en/articles/4670279-revision-selector)（3Dビューアの右上）
- [モデルページ](https://support.catenda.com/en/articles/4670286-models-page)の[モデルテーブル](https://support.catenda.com/en/articles/4670286-models-page#h_bbc42c56bb)
- [ドキュメントページ](https://support.catenda.com/en/articles/8204673-documents-page)のビューアー列の[ドキュメントテーブル](https://support.catenda.com/en/articles/8204673-documents-page#h_54e8dfcac2)

**スナップショットの再生**トピックから[2Dまたは3Dスナップショット](https://support.catenda.com/en/articles/9184555-2d-and-3d-viewpoints)を再生するか、[ブックマーク](https://support.catenda.com/en/articles/8471481-bookmark)から[スナップショット](https://support.catenda.com/en/articles/10345863-snapshots)を再生して、スナップショットが作成されたときに有効になっていた2Dモデルを読み込みます。

**2D上のビューマーカー**ストーリーに配置されているマーカーを持つトピックのマーカーをクリックして、2D上で再生を選択できます。このボタンをクリックして、マーカーが作成されたときに有効になっていたモデルのストーリーを2Dビューアで利用可能にします。_アクセス権が必要:_ 各モデルに接続されているドキュメントへの読み取りアクセス。

**設定されたストーリー**ストーリーコンフィギュレーターでビルディングが設定されている場合、これらの各ビルディングで設定されたストーリーは常に利用可能です。_アクセス権が必要:_ 各モデルに接続されているドキュメントへの読み取りアクセス。

### 1.3 **ストーリーの結合**

複数のモデルの2Dビューが同時に有効になっている場合、それらは2Dビューアで一緒に表示されます。モデルの1つからストーリーを選択して、この高さで生成されたすべての有効なモデルのストーリーを2Dビューアで一緒に表示します。例えば、建築モデルと構造モデルの両方の2Dビューが有効になっており、建築モデルの1階が選択されている場合、構造モデルが建築モデルの1階と同じ高さのストーリーを持っていれば、建築モデルの壁と構造モデルのビームの両方が2Dビューアで一緒に表示されます。

**複数のモデルの2Dビューを一度に読み込む**複数のモデルの2Dビューを一度に読み込むには、モデルページでモデルを選択し、モデルページの上部にある2Dボタンをクリックします。

**設定されたストーリー** [ストーリーコンフィギュレーター](https://support.catenda.com/en/articles/6921756-storey-configurator-page)で設定されているビルディングからストーリーを選択して、そのストーリー用に設定されたすべてのモデルの2Dビューを自動的に2Dビューアに読み込みます。

## 2. **2Dビューアの外観**

2Dビューアの要素は以下のとおりです：

- オブジェクト
- 描画またはマップなどのアンダーレイレイヤー
- マーカー
- ルームラベル

ユーザーのニーズに合わせて表示するように設定できます。[こちら](https://support.catenda.com/en/articles/13615984-2d-viewer-appearance#h_73338e8c67)をクリックして、2Dビューア要素の外観について詳しく読むことができます。

## 3. **2Dビューアの操作**

以下のボタンと領域をクリックして、さまざまなアクションを実行できます。

- トップバー
- キャンバス
- ナビゲーションツール
- 選択ツールと設定
- ボトムバー

[こちら](https://support.catenda.com/en/articles/12699525-2d-viewer-interactions)をクリックして、これらのさまざまなアクションについて詳しく読むことができます。

## 4. **画像のエクスポート**

2Dビューアから画像をエクスポートする良い方法は、トピックで[2Dスナップショット](https://support.catenda.com/en/articles/8227211-3d-viewer#h_a1594324c8)を作成することです。`.svg`ファイル形式のベクターライン画像は、ブラウザーの開発者ツールの要素タブを使用してページを検査することで、ウェブページ要素から抽出できます。
