# 2Dトピック位置 - Catenda Site

位置は[2Dビューア](https://support.catenda.com/en/articles/4854537-2d-viewer)にマーカーをx、y、z座標に配置することでトピックに適用できます。色付きドットは2Dビューアでトピックの位置をマークし、トピックの位置、ステータス、およびタイプの即座の視覚的理解を提供します。トピック位置を使用することで、プロジェクトはトピックの配置に対する大幅に改善された制御を活用できます。この機能は、ブラウザアプリケーション[Catenda Hub](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site)の機能を補完しています。マーカーを使用することで、プロジェクトはフィールドで作成されたトピックの無理のない作成、監視、および管理をデスクから行うことができます。

これはCatenda Siteの2Dビューアでマーカーがどのように見えるかです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/01-intro.png)

## 1. **既存マーカー付きトピック**

### 1.1 **マーカーとの相互作用**

Catenda Siteのマーカーをタップして、そのマーカーに属するトピックのトピック番号とタイトルを表示します。これはCatenda Siteでタップされたマーカーがどのように見えるかです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/02-interacting-with-markers.png)

### 1.2 **マーカーの表示**

トピックと位置を操作するには、2D/3Dビューアメニューを開きます。

**トピックボードを選択**トピックボードを選択して、そのトピックボードの階層からマーカーを表示します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/03-displaying-markers.png)

階層が階層コンフィギュレータで設定されている場合、2D/3Dビューアメニューが開かれるとすぐに、最初の建物の最初の階層がデフォルトで開かれます。

**トピックボードをフィルター**フィルターを適用してトピックボードをフィルターすることで、画面上のマーカーの数を減らします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/04-displaying-markers.png)

> **警告1:** トピックメニューが開かれると、結果の最初の250個のトピックからのマーカーが更新されて保存されます。2Dビューアが開かれると、トピックメニューの結果に一致する以前に更新されたトピックからのマーカーが表示されます。トピックからのマーカーはアクティブな階層以外の階層に分散される場合があることに注意してください。**警告2:** トピックメニューの結果に250以上のトピックがある場合、マーカーが読み込まれていない可能性があるか、最新ではない可能性があります。リストを下にスクロールして、マーカーを表示/更新してください。ボードをフィルターして結果にトピックが少なくなるようにすることで、フィルターされた結果のトピックに属するマーカーが確実に更新および表示されるようにすることもできます。**警告3:** アプリケーションからサインアウトして再度サインインすると、読み込まれたトピックの履歴が失われ、以前に読み込まれたトピックを再度読み込む必要がある場合があります。

**2Dビューを展開** 2Dビューアと3Dビューア間の仕切りをドラッグして展開します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/05-displaying-markers.png)

左上のストーリメニューをタップして、IFCモデルまたは構成済みの建物から階層を選択します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/06-displaying-markers.png)

### 1.3 **マーカーからトピックを検索**

**2Dビューの階層からマーカーを使用してトピックを検索** 2Dビューのマーカーをタップして、属するトピックのトピック番号とタイトルを表示します。選択されたマーカーの矢印をタップして、選択されたトピックをトピックページのトピックボードに表示します。

**トピックから2Dビューアのマーカーを検索**位置フィールドに「位置あり」と表示されているトピックを検索してタップします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/07-finding-topics-from-markers.png)

開いたメニューで「2Dで位置を表示」をタップします：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/08-finding-topics-from-markers.png)

トピックがトピックボードで開かれると、そのマーカーの色は2D/3Dメニューのチェックマーク付きで緑で強調表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/09-finding-topics-from-markers.png)

### 1.4 **マーカーの編集**

**マーカーの移動**トピックの位置フィールドをタップして、開いたメニューで位置を置き換えをタップします。アンカー付きマーカーを新しい位置にドラッグして確認します。

**マーカーの削除**トピックの位置フィールドをタップして、開いたメニューで位置を置き換えをタップします。位置を削除をタップします。

### 1.5 **マーカー設定**

2Dビューアのギアアイコンをタップして、Catenda Site 2Dビューア[設定](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site#h_63e1728758)を開きます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/10-marker-configuration.png)

ここでは異なる2Dビューアオプションを構成できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/11-marker-configuration.png)

**マーカーの可視性**マーカーのオン/オフを切り替え

**マーカーの色付けモード**マーカーに設定する色のタイプを変更

**スペース名形式** IFCファイルでは、ルームは短いまたは長い名前を持つことができます

## 2. **新規マーカー付きトピック**

### 2.1 **マーカー付き新規トピックを作成**

トピックボード内の緑のプラスボタンは、トピックを作成する唯一の方法ではありません。2Dビューアの任意の場所をタップして、その位置にトピックを作成します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/12-create-a-new-topic-with-a-marker.png)

このようにして作成されたトピックは、その位置に自動的にマーカーが適用されます。

### 2.2 **トピックからマーカーを追加**

新規トピックを作成するか、マーカーのないトピックを開いて、「位置」をタップします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/13-add-marker-from-topic.png)

2D/3Dメニューが開かれ、アンカー付きの新しいマーカーが緑で表示されます：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/14-add-marker-from-topic.png)

2本の指で2Dビューアをピンチインしてマーカーを正しい位置に移動し、チェックマークをクリックして位置に固定します。
