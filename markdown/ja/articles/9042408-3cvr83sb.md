# あなたに合った通知を受け取る

Catenda Hubでのアクションに関する通知を受け取ることは、あなたが属するプロジェクトのアクティビティをフォローアップするために重要です。通知はCatenda Hub全体のいくつかの場所にあります。

## 1. **アカウント通知**

すべてのプロジェクトからのすべての通知は[アカウント通知ページ](https://support.catenda.com/en/articles/7439223-account-notifications-page)に表示されます。ここで[受け取ったすべての通知をフィルター](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages)することができます。

### 1.1 **アカウント通知ページ**

[アカウント通知ページ](https://support.catenda.com/en/articles/7439223-account-notifications-page)には、すべてのプロジェクトから受け取ったすべての通知が表示されます。

### 1.2 **アカウント通知設定ページ**

[アカウント通知設定ページ](https://support.catenda.com/en/articles/8272435-account-notification-settings)で、すべてのプロジェクトに対して受け取りたい通知を設定できます。

## 2. **プロジェクト通知**

プロジェクト内には、通知を確認できるいくつかの場所があります。

### 2.1 **ダッシュボード**

ここには、プロジェクト内のユーザーによって生成された[最新5件の通知](https://support.catenda.com/en/articles/8212646-dashboard-page#h_77effb806b)が表示されます

### 2.2 **プロジェクト通知ページ**

ここには、プロジェクト内のユーザーによって生成された[すべての通知](https://support.catenda.com/en/articles/4670295-project-notifications-page)が表示されます。このページではプロジェクト内のユーザーによって生成された[すべての通知をフィルター](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages)することができます。

### 2.3 **プロジェクト固有の通知設定**

ここで、[あなたが属するプロジェクトに対して受け取りたい通知を設定](https://support.catenda.com/en/articles/4670262-project-specific-notification-settings)できます。この設定はアカウント通知設定を上書きします。

### 2.4 **設定 - メンバー - メンバー**

メンバーのメンバーページに移動すると、プロジェクト内の[そのユーザーによって生成されたトピック](https://support.catenda.com/en/articles/8228836-member-page#h_6b76063480)が表示されます。

### 2.5 **設定 - メンバー - チーム**

メンバーページのチームページに移動すると、プロジェクト内の[そのチームに関連するトピック](https://support.catenda.com/en/articles/7891755-team-page#h_f91b3824f4)が表示されます。
