# 命名規則ページ

管理者は、[プロジェクト設定](https://support.catenda.com/en/articles/4670273-project-settings-page)のサブページとして命名規則ページを見つけることができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/01-intro.png)

この記事で説明されているトピックは以下の通りです：

## 1. **ローカルファイルの命名**

命名規則を使用して、元のファイルの名前に基づいて、フォルダにアップロードされるファイルを制限できます。これは、ローカルファイルの命名に対する一連のルールが既にある場合に非常に便利です。ファイルをCatenda Hubにアップロードするためにファイルの名前を変更する必要はありません。ローカルファイルの命名に対するルールがない場合、命名規則はお勧めできません。

## 2. **ドキュメント、改訂、および元のファイル**

開始する前に、Catenda Hub **ドキュメント**と**ファイル**の違いを理解することが重要です。Catenda Hubの**ドキュメント(およびドキュメント改訂)は、_ファイルのコンテナ_と考えることができます。このコンテナにファイルをアップロードでき、管理者の場合はその名前を変更できます。ファイル名は、アップロードしたい図面またはシートの同じバージョンであっても、多くの場合、互いに大きく異なります。命名規則により、ファイルの名前の一連のルールに基づいて、同じドキュメントに類似ファイルをアップロードできます。

## 3. **新しい命名規則**

ページの右上に、「新しい命名規則」ボタンが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/02-new-naming-convention.png)

これが新しい命名規則の外観です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/03-new-naming-convention.png)

### 3.1 **規則情報**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/04-convention-information.png)

**名前**ドキュメント設定で適用するときに表示される規則の名前

**説明**ドキュメント設定に表示される規則の説明

**区切り文字**ファイル拡張子ブロック以外のすべてのブロックを区切る文字。

### 3.2 **プレビュー**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/05-previews.png)

プレビューは、ローカルファイルシステムとCatenda Hubドキュメント構造の両方で規則が従うパターンを表示します。これらは異なる場合があり、ご覧のとおり、一方を他方にマッピングできます

**ドキュメント名**ファイルがアップロードされるときにCatenda Hubのドキュメントがどのように見えるか

**予想ファイル名**アップロードが許可されているファイルがどのように見えるはずか

### 3.3 **プレビュータイプ**

異なるプレビュータイプにマウスを合わせると、各プレビューの意味の詳細な説明が表示されます。_テキスト - 可変長:_ {X} _テキスト - 固定長:_ XXXX _カスタムフィールド:_ {カスタムフィールド名} _区切り文字:_ 3つ以上のブロックがある場合、設定した区切り文字が表示されます

### 3.4 **ブロック**

命名規則は一連のブロックで構成されています。各ブロックはファイル/ドキュメント名の一部を表します。「ブロックを追加」をクリックして、新しいブロックを追加します。

![ブロックを追加](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/06-blocks.png)

規則は常に最低2つのブロックを持っています: 1. ファイル/ドキュメントの名前。2\. ファイル/ドキュメント拡張子の名前。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/07-blocks.png)

**名前**ブロックを互いに区別できるように、命名規則設定内のブロックの名前

**説明**このブロックで何を行うことを期待しているかについての説明を入力できます

**ドキュメント識別子** Catenda Hubに表示したくないファイル名の一部が見える場合は、ドキュメント識別子をオフにすることができます。ファイル名のこの部分はファイルの受け入れに使用されますが、結果のCatenda Hubドキュメントには表示されません。

**オン**ドキュメント識別子がオンに切り替えられている場合、このブロックはドキュメントの名前を識別します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/08-blocks.png)

**オフ**ドキュメント識別子がオフに切り替えられている場合、このブロックはローカルファイルの名前を識別します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/09-blocks.png)

**無効**拡張子ブロックのドキュメント識別子は常にオフです。すべてのファイルに拡張子があるためです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/10-blocks.png)

**ソース**ファイル/ドキュメント名の識別を適格にするものは何ですか? _デフォルト:_ テキスト - このブロックには任意の文字を含めることができます _カスタムフィールド:_ - カスタムフィールドでブロックが受け入れる文字の種類を制限します

**長さ**このブロック内に含めることができる文字数。このフィールドが空白の場合、ブロックは可変長になります。

### 3.5 **規則の提出**

![キャンセル 命名規則を送信](https://raw.githubusercontent.com/catenda/help-center/main/images/kj97gd0a/11-br-submitting-a-convention.png)

命名規則を提出した後、[ドキュメント設定](https://support.catenda.com/en/articles/7831371-document-settings)で[フォルダごとに有効](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90)にできます。
