# Catenda SharePoint FAQ

この記事で説明されている次のトピック:

## 1. **SharePoint を Catenda と統合するにはどうすればよいですか?**

Catenda と統合する方法は 2 つあります。

### 1.1 **Catenda SharePoint アプリ**

SharePoint では、[このアプリケーション](https://support.catenda.com/en/articles/8396496-catenda-sharepoint-plugin)をテナントに対して有効にし、サイト所有者によってサイトに追加できます。その後、SharePoint ユーザーはドキュメントを Catenda に公開できるようになります。SharePoint 所有者は、Catenda プロジェクトドキュメント構造を SharePoint に表示することもできます。

### 1.2 **Catenda SharePoint ライブラリ**

Catenda では、SharePoint の共有フォルダの内容を SharePoint ライブラリで表示できます。Catenda プロジェクトのすべてのユーザーはフォルダの内容を表示し、それらをオブジェクトとトピックにリンクできます。

## 2. **Catenda と SharePoint で作業するにはどうすればよいですか?**

SharePoint 統合を有効にすることで、サイトメンバーは自分のドキュメントに対して Catenda 機能を使用できるようになります。

### 2.1 **コラボレーション**

Catenda で SharePoint サイトドキュメントに関するコラボレーションを行うことで、SharePoint メンバーは必ずしも SharePoint 環境へのアクセス権がない建設プロジェクトメンバーと協力することができます。

### 2.2 **クイックアクセスとファイルビューイング**

モデル、点群、図面の内容は Catenda で表示および管理できます。サイトから Catenda ファイルにアクセスすることで、メンバーは建設業界で使用されている任意のファイル形式に迅速にアクセスして表示できます。

### 2.3 **ドキュメント履歴**

SharePoint メンバーによって作成されたドキュメントバージョンは Catenda に公開できます。ドキュメントをバージョン管理することで、建設プロジェクトメンバーはドキュメント内の変更を追跡できます。

## 3. **ドキュメントを公開できるのは誰ですか?**

### 3.1 **Catenda SharePoint アプリ**

アプリケーションがサイトに対して有効になっている場合、すべてのサイトメンバーに公開オプションが表示されます。ドキュメントを Catenda に公開する場合、SharePoint ユーザーは Catenda アカウントへの SharePoint アクセス権を付与するよう求められます。

**ドキュメントの共有**権限を付与した後、SharePoint メンバーは SharePoint サイト内のドキュメント(複数可)を、Catenda の書き込みアクセス権を持つドキュメントセクションの一部に共有できます。

> **注:** 単一のドキュメント(複数可)を公開することのみが可能です

Catenda は SharePoint ユーザーによって Catenda に公開される際の方法以外の SharePoint ドキュメントに関する情報を取得しません。ドキュメントが公開後に SharePoint で変更された場合、ユーザーがドキュメントを再度公開することを選択しない限り、Catenda はそれについて知ることができません。

### 3.2 **Catenda SharePoint ライブラリ**

Catenda で SharePoint ライブラリを使用してドキュメントを公開、編集、または変更することはできません。Catenda プロジェクトメンバーは SharePoint ライブラリアイテムをプロジェクト内の Catenda の他の部分にリンクできます

## 4. **ドキュメントを読むことができるのは誰ですか?**

### 4.1 **Catenda SharePoint アプリ**

**SharePoint ユーザー**サイトに SharePoint アプリを追加した後、ユーザーは Catenda アカウントへの SharePoint アクセス権を付与できるようになり、SharePoint はユーザーが Catenda でアクセスできるドキュメントを表示して、ユーザーが SharePoint ドキュメントを公開する場所を選択できるようにします。WebPart が SharePoint のページに追加される場合、ユーザーは読み取りアクセス権を持つ構成されたプロジェクトのドキュメントセクションの部分を表示することもできます。

**Catenda ユーザー** SharePoint アプリを通じて Catenda アカウントへのアクセス権を付与した後、Catenda はユーザーによって共有されない限り、SharePoint 内のドキュメントへのアクセス権を取得しません。

### 4.2 **Catenda SharePoint ライブラリ**

SharePoint ライブラリを構成する場合、Catenda はすべての SharePoint ドキュメントへのアクセス権を付与するため、Catenda はこのプロジェクトと共有する公開フォルダを知ることができます。公開フォルダが構成されると、すべての Catenda プロジェクトメンバーはそのフォルダの内容への読み取りアクセス権を持ちますが、他の SharePoint ドキュメントへのアクセス権を持ちません。Catenda SharePoint ライブラリは読み取り専用であり、SharePoint ドキュメントを変更することはできません。Catenda プロジェクトメンバーは SharePoint ライブラリアイテムをプロジェクト内の Catenda の他の部分にリンクできます。Catenda SharePoint ライブラリの内容は Catenda で編集することはできず、トピックおよびオブジェクトに表示およびリンクすることのみができます。
