# コレクションページでのフィルタリング

ウィンドウの上部に表示される検索とフィルターのオプション。コレクションの名前を入力して検索できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/svz5chty/01-intro.png)

検索バーでアクセス権のあるコレクションを検索できます。

## 1. **フィルター左パネル**

フィルターボタンをクリックすると左側にパネルが表示されます。チェックボックスをオンにすると検索結果を絞り込めます。これらのフィルターはフィルターリストの上部で保存できます。フィルターを適用すると、フィルターのテキストがURLに追加されます。このURLを共有すると、受け取った人がアクセス権を持っている場合、あなたが見ているのと同じフィルターが表示されます。たとえば、「フォロー中」フィルターを有効にしてURLを共有した場合、受け取った人がURLを開くと、フォローしているフィルターが表示されます。左パネルのフィルターにマウスカーソルを置くと、フィルターの右側をクリックして、以前に適用されていた他のフィルターを削除できます。

## 2. **保存済みフィルタ**

[こちら](https://support.catenda.com/en/articles/8551755-saving-filters)をクリックして、フィルターセットの保存方法の詳細を確認してください

## 3. **フィルタ**

左上のフィルターボタンをクリックすると左側にパネルが表示されます。フィルターが適用されると、ブラウザーに表示されるURLが変わります。このアーティクルでは、フィルターは次のように表示されます: _Filter name in menu_ - `Filter name in URL=Filter option in URL`

**デフォルトフィルター**デフォルトフィルターは初期状態ではURLに表示されません。ページに初めてナビゲートすると、次のフィルターが適用されます。_自分とそれに属するチームがフォローしているコレクション_ - `followers=my-teams,me`

### 3.1 **現在のフィルターを保存して共有**

フィルター適用済みページのURLに移動して、そのページをフィルター適用状態で読み込みます。適用されたフィルターはフィルターメニューの上部に保存できます。[こちら](https://support.catenda.com/en/articles/11401493-saving-a-filter-link)をクリックして、フィルターの保存と共有方法の詳細を確認してください

### 3.2 **該当なしのフィルタを非表示**

[こちら](https://support.catenda.com/en/articles/8551755-saving-filters)をクリックして、フィルター結果の制限方法の詳細を確認してください。

### 3.3 **フォローしているコレクション**

_フォロー中_ - `followers=me` ユーザーがフォローしているコレクション。

_マイチームがフォロー中_ - `followers=my-teams` ユーザーが属するチームがフォローしているコレクション。

_すべてのコレクション_ - `followers=all` フォロワーの有無を問わず、すべてのコレクション。このフィルターは、検索バーの×ボタンがクリックされたとき、または「フォロー中」フィルターと「マイチームがフォロー中」フィルターの両方が無効になった場合に自動的に適用されます。

### 3.4 **自分が作成者**

作成者 - `createdBy=<Creator GUID>` このフィルターに対するユーザーインターフェースボタンはありません。プライベートまたはプロジェクト共有でフィルタリングすると、これは自動的に自分のユーザーに設定されますが、別のユーザーのGUIDに変更できます。

プライベート - `visibility=private` プロジェクトと共有 - `visibility=project-members`

### 3.5 **確定済み**

確定済み - `finalized=true` 未確定 - `finalized=false`

### 3.6 **外部共有**

外部共有 - `sharedBy=email,link`

> **注:** ここでメールまたはリンクのどちらかを入力することで、検索を絞り込むことができます

外部共有なし - `sharedBy=not-shared`

### 3.7 **日付フィルタ**

公開 - `publishedAtFrom=<UTC timestamp>&publishedAtTo=<UTC timestamp>` 日付を選択して、検索する日付範囲を選択してください [こちら](https://support.catenda.com/en/articles/6511685-date-filter)をクリックして、日付フィルタの詳細を確認してください

## 4. **テキスト検索**

ファイル名内で最低3文字以上のテキストの完全一致を検索できます

### 4.1 **テキスト検索**

_テキスト検索_ - `search=test`

**検索可能なコンテンツ**コレクション名

**大文字小文字の区別**テキスト検索では大文字と小文字を区別しません。

**文字数**任意の文数 検索フレーズを含むコンテンツがマッチします。

**空白文字**検索フレーズの開始時の空白文字は削除されます。
