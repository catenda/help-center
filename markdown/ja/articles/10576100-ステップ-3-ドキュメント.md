# ステップ 3 - ドキュメント

> プロジェクト ドキュメントのアップロード、ダウンロード、表示、コミュニケーション

> **ヒント:** ヘルプ センターまたはヘルプ メニューで[ステップ 2](https://support.catenda.com/ja/articles/10576075-ステップ-2-インターフェース) を[はじめに](https://support.catenda.com/ja/collections/2657208-スタートガ-イド)で見つけてください。

## 1. **アップロード**

これは Catenda Hub の配信エリアで、目的の場所を選択してドラッグ&ドロップするだけで、あらゆるファイル タイプをアップロードできます (Windows エクスプローラーと同じように)。右上隅のアップロード ボタンからもアップロードできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/mdxrvj2r/01-uploading.ja.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/mdxrvj2r/02-uploading.png)

フォルダ内でドキュメント マッチが見つかると、Catenda は新しい revision を作成し、すべての置き換えられた revision のレコードを保持します。

## 2. **ダウンロード**

検索バーまたはフィルター サイドバーを使用して必要なドキュメントを検索し、それらを選択するだけです。フィルターは今後の使用のために保存できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/mdxrvj2r/03-downloading.png)

ドキュメントを選択したら、ダウンロード ボタンをクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/mdxrvj2r/04-downloading.png)

ドキュメントは PC にダウンロードされます。

## 3. **表示**

Catenda のドキュメント ビューアは、PDF からさまざまな Microsoft ファイル (doc、ppt、xls など) およびポイント クラウド ファイルまで、多くのファイル タイプをサポートしています。ビューアは mp4 などのビデオ ファイルもサポートしています。検索バーまたはフィルター サイドバーを使用して必要なファイルを検索し、それをクリックしてビューアで開くだけです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/mdxrvj2r/05-viewing.png)

## 4. **マークアップ**

マークアップ ツールを使用して、他のプロジェクト メンバーと通信したい領域を識別します。マークアップを既存のトピックに追加することも、選択したトピックリストに配置できる新しいトピックを作成することもできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/mdxrvj2r/06-markups.png)
