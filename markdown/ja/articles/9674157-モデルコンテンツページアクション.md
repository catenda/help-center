# モデルコンテンツページアクション

アクセス権限によって、現在のモデルとその各リビジョンに対して異なるアクションをモデル概要ページで確認できます。

この記事では、以下のトピックについて説明します：

## 1. **モデルアクション**

モデル選択とアクセス設定に応じて、[モデル概要ページ](https://support.catenda.com/en/articles/4670270-model-overview-page#h_c10dbce6c8)の右上に異なるアクションボタンが表示されます。すべてのアクションボタンはアクションメニューに一覧表示され、次のようなものになります：

![mceclip0.png](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/01-model-actions.png)

モデル概要ページのアクションメニューは、次のようなものになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/02-model-actions.png)

### 1.1 **最新リビジョンのダウンロード**

リビジョンをアップロードするとすぐにここからダウンロードできます

### 1.2 **新規リビジョン**

新規リビジョンアクションをクリックするか、ファイルをモデルコンテンツリストにドロップして新しいリビジョンをアップロードします。新しいリビジョンのアップロードについて詳しくは、[こちら](#h_118c049d47)をクリックしてください。

### 1.3 **エクスポート**

[モデルエクスポートページ](https://support.catenda.com/en/articles/4670280-model-export)に移動します

### 1.4 **削除**

このアクションにより、モデルをモデルページから削除する前に確認を求められます。

> **注:** モデルを削除すると、モデルはモデルページから削除されるだけです。ドキュメント-モデルはドキュメントセクションに残り、削除したい場合は選択したドキュメント削除アクションで削除する必要があります。モデルはいつでもモデルセクションの同じドキュメントから再度作成できます。

_必要なアクセス権限:_ プロジェクト設定でのモデルの作成と削除、および削除しようとしているモデル(複数可)への書き込みアクセス権限。

## 2. **モデルリビジョンアクション**

各リビジョンの右側には、以下のアクションが表示されます：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/03-model-revision-actions.png)

### 2.1 ダウンロード

ダウンロードアクションをクリックして、このリビジョンをダウンロードします

### 2.2 公開

プロジェクトのドキュメント設定で[ステータスワークフローメニュー](https://support.catenda.com/en/articles/12495583-status-workflow-document-settings)で共有リビジョンが有効になっている場合、作成された新しいリビジョンは共有リビジョンとして開始され、後で公開できます。

共有リビジョンはマイナーリビジョン番号を持ちます。(0.1、0.2、1.1など) 公開アクションはモデル内の共有リビジョンで利用できます。最新の公開リビジョン以降の共有リビジョンのみを公開できます。公開リビジョンはマイナーリビジョン番号を持ちます。(1.0、2.0、3.0など) _必要なアクセス権限:_ ドキュメント-モデルアクセス設定で公開可能

**以前のリビジョンの公開**公開アクションでは、モデル内の最新公開リビジョン以降の共有リビジョンを公開できます。モデルコンテンツページでは、最新公開リビジョン以降に作成された限り、以前の共有リビジョンを公開できます。ここでは、ボタンをクリックすることで一度に1つのリビジョンのみを公開できますが、モデルページのモデルテーブルで複数のモデルから最新の共有リビジョンを選択し、公開アクションを使用すると、複数のリビジョンを一度に公開できます。

公開後、メジャー番号(1.0、2.0、3.0など)を持つ新しい公開リビジョンが追加されます。この公開リビジョンはワークスペースタブと公開タブの両方に表示されます。

### 2.3 2D

2Dアクションをクリックして、このリビジョンの2Dビューを開きます

### 2.4 3D

3Dボタンをクリックして、このリビジョンの2Dビューを開きます
