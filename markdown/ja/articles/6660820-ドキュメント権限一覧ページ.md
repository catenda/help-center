# ドキュメント権限一覧ページ

> ユーザーとチームのアクセス権の概要

ドキュメント権限一覧は、[ドキュメント設定ページ](https://support.catenda.com/en/articles/7831371-document-settings-page)の[アクセス制御メニュー](https://support.catenda.com/en/articles/7831371-document-settings-page#h_98a4be4ac9)にあるアクセス権限一覧ボタンをクリックすることで表示されます。ドキュメント権限一覧を使用すると、ドキュメントテーブル内のユーザーとチームのアクセス権の概要が表示されます。_必要なアクセス権:_ 管理者

ドキュメント権限一覧ページはこのような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/01-intro.png)

## 1. **ドキュメント権限一覧でのアクション**

ドキュメント権限一覧のアクションはこのような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/02-actions-in-the-document-access-overview.png)

### 1.1 **Excelへの書き出し**

ドキュメント権限一覧で有効になっているカラムをExcelに書き出すには、Excelへの書き出しアクションをクリックします。

## 2. **ドキュメント権限一覧の生成**

ドキュメント権限一覧ページが初めてプロジェクトで開かれる場合、このような表示になることがあります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/03-generating-the-access-overview.png)

ダイアログがページの左下に表示され、ドキュメント権限一覧の生成が開始されたことを示します。このダイアログを開いたまま他のページに移動して進捗を確認することもできますし、閉じることもできます。どちらの場合でも、一覧の生成は続行されます。

別のページに移動してドキュメント権限一覧の生成が完了すると、ダイアログはこのような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/04-generating-the-access-overview.png)

### 2.1 **生成完了**

生成されたドキュメント権限一覧の上部に、生成された日時と更新ボタンが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/05-generation-completed.png)

ドキュメント権限一覧の生成時点で、メンバーとチームがドキュメントに対して持つアクセス権が表示されます。これにより、管理者はアクセス設定が急速に変更されている場合でも、たとえばプロジェクトの開始段階で概要を保つことができます。

> **注記:** 生成されたドキュメント権限一覧は、生成時点での状況のみを表示し、動的ではありません。最新の変更を取得するには、新しい一覧を生成する必要があります。

### 2.2 **ドキュメント権限一覧を最新に更新**

ドキュメント権限一覧が2週間以上前に生成された場合、メッセージがオレンジ色に変わり、古い可能性があることを示します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/06-regenerate-access-overview.png)

ドキュメント権限一覧を最新に更新アクションをクリックして、プロジェクト内のドキュメントとアクセスの最新バージョンを取得します。

## 3. **ドキュメント権限一覧テーブル**

ドキュメントツリー内のフォルダーのアクセス権のみを表示することができます。特定のドキュメントのアクセス権を表示するには、ドキュメントを選択し、[ドキュメント改訂版の右メニュー](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision-revision-info)の[アクセスメニュー](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision-revision-info#h_8525de97c2)を参照してください。Catendaでテーブルを使用する方法の詳細については、[こちら](https://support.catenda.com/en/articles/11748020-tables-on-catenda)をクリックしてください。

### 3.1 **ドキュメント権限一覧テーブルでのフィルタリング**

ドキュメント権限一覧ページのフィルターバーはこのような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/07-filtering-in-the-access-overview-table.png)

フォルダーの名前を入力して、その名前のフォルダーでフィルタリングします。

> **注記:** フィルタリングはフォルダーカラムのヘッダー行のマイナスボタンでフォルダーが折りたたまれている場合のみ機能します。

**独自のACLを持つフォルダー**独自のACLを持つフォルダーをクリックして、特定のACLが設定されているフォルダーのみを表示します。

### 3.2 **カラムドロップダウン**

テーブルをカスタマイズしてユーザーやチームを有効/無効にします。ユーザーとチームの表示順序を変更します…

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/08-column-dropdown.png)

### 3.3 **フォルダーとアクセス継承元**

フォルダーとアクセス継承元カラムはこのような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/09-folders-and-access-inherited-from.png)

ドキュメントツリーを下にスクロールします。

**ヘッダー行**ヘッダー行のプラスボタンとマイナスボタンをクリックして、ドキュメントツリーを展開および折りたたみます。

**行ホバー**フォルダーの行にマウスカーソルを合わせるとリンクアイコンが表示されます。リンクアイコンをクリックして、ドキュメントテーブルでそのフォルダーを開きます。

**ロックアイコン**ロックアイコンは、このフォルダーに対して特定のアクセス権が設定されていることを示します。

**矢印アイコン**矢印アイコンは、このフォルダーが親フォルダーからアクセス権を継承していることを示します。

### 3.4 **ユーザーとチームカラム**

ツリー内の各フォルダーの各ユーザーとチームのアクセス権を確認します。アクセス権テーブルはこのような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/54j7njww/10-user-and-team-columns.png)

**ヘッダー行**ヘッダー行のアイコンを見て、カラムがメンバー、管理者、またはチームカラムかどうかを確認します。メンバーアイコン - 👤 管理者 - 👤（オレンジ色） チーム - 👥

メンバーの名前またはアイコンをクリックして、そのメンバーが属するチームを確認します。チームの名前またはアイコンをクリックして、そのチームに属するメンバーを確認します。

**行コンテンツ**アクセス権は、アクセスなし、読み取り、書き込み、またはフルアクセスに設定できます。アクセス設定をクリックして、設定されている設定に関する詳細情報を確認します。
