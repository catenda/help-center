# Changelog 11 Catenda - 2025年1月

皆様へ

この冬の間、当プラットフォームで多くの活動をしていただき、ありがとうございます。素晴らしい冬を過ごすことができ、前年と比較して、この時期のプラットフォーム安定性が向上していることを誇りに思います。同時に、前回のchangelogで新たに導入された承認ワークフローの大規模改革に関するご要望をお聞きし続けています。一部の管理者がワークフロー設定方法を学び、他の管理者がチームの代わりに承認を行っている一方で、すべてを結び付けるために完了すべきチェックボックスがいくつか残されています。今後の焦点は、異なるチーム間で実行される承認チェックの証拠として提供できるドキュメントを作成できるように、承認プロセスで発生した異なるアクションの監査証跡をロックダウンする方法を作成することになります。新しいメンバーページにより、チームメンバーシップの設定がかつてないほど簡単になりました。適切なチームに属していないと感じたり、プロジェクトにチームが不足していると感じたりする場合は、管理者にお知らせください！❄️⛄☃️🥶🧊🎿⛸️🏒⛷️🏂🏔️🌨️

## 2. **解決されたバグ**

貴重なフィードバックをいただき、多くのトピックを解決することができました。以下は、ユーザーとの会話の結果として開発チームによって行われた小さな変更のリストです。

### 2.1 **トピック**

- マークアップスナップショットの再生ボタンをクリックして、ドキュメント上の注釈を再生することが再び可能になりました。完全に白いスクリーンになることはありません。
- トピックページのテキスト検索の改善。

### 2.2 **ドキュメント**

- フォルダを開いた後に白いスクリーンが表示された場合でも、15分以内にフォルダを再度開くことが可能になりました。

### 2.3 **モデル**

- オブジェクトテーブルのフィルター行のExcelエクスポート生成に割り当てられたメモリが増加されたため、Excelエクスポートが正しく生成され、無限スピナーが表示されなくなります。
- オブジェクトテーブルで50000以上の要素を選択する場合、ページが高速化され、フリーズする可能性が低くなります。
- グリッドが有効で、Catenda Hub 3Dビューア(ブラウザのみ)でモデルが変換される場合、グリッドは常に追従していました。現在、ページをリフレッシュして変換されたモデルを変換されたロケーションで読み込むと、グリッドも同じく変換されたロケーションで正しく表示されます。

### 2.4 **プラグインと統合**

- MFAが有効になっているユーザーがプラグインと統合を介してプロジェクトのコンテンツを開くことが再び可能になりました。
- アプリケーションとしてのCatenda
  - 11インチのiPadで、一度に1つではなく、3Dビューアとコンテンツパネルの両方を同時に開くことが再び可能になりました

## 3. **完了したユーザーの声**

### 3.1 **トピック**

- トピックタイトルの部分的な単語、コメント内の説明で検索することが再び可能になりました。トピック番号検索はこの検索から分離され、Catendaでトピック番号で検索する際の粒度が向上しました。

### 3.2 **ドキュメント**

- 通知は、異なるカテゴリーに属するチームの一部であるユーザーに送信されるようになりました。
  承認提出者チームの一部として、ワークフロー手順のいずれかにあるチームの一部として、最終提出者チームの一部として。
  提出および編集された情報など、新しい情報に関する通知があります。
  レビューチームがレビューを行う時期、または最終レビュアーが承認リクエストでドキュメントを公開する時期など、責任に関する通知があります。
  ステップ内のすべてのレビューが異なるチームによって提出される、または最終レビュアーチームによる承認リクエストの最終クローズなど、実行されるアクションについての通知があります。
- 承認の最終ステップでは、承認と却下するだけでなく、最終承認者チームの誰かが承認にコメントを付けることが可能になりました。これは通常、最終承認者が承認者チームの代わりに承認したいが、ドキュメントについて懸念事項がある場合に使用されます。小さな変更が必要になる場合もあれば、ドキュメントに受け入れられる欠陥がある場合もあります。

### 3.3 **設定**

- リスト内の1人以上のメンバーを選択し、右側のメニューで変更を行ってそれらを更新することで、チームメンバーシップを構成することが可能になりました。チームに移動してメンバーを1人ずつ追加する必要はありません。
- 日付フィールド - タイプDate の新しいカスタムフィールドが利用可能になりました。
  このフィールドをトピックまたはドキュメント利用可能にした場合、トピック/ドキュメント利用可能にされた各日付フィールドは、それをクリックしてカレンダーで日付を選択することで、日付を指定できます。
  日付フィールドは命名規則では利用できませんが、APIを介して利用できます。

## 4. **新しいリリース** - プラグインと統合

**Catenda PowerBI Connector v1.0.0**オープンなメタステータスを持つトピックと、クローズドなメタステータスを持つトピックを取得することが可能になりました。

**Catenda Archicad Plugin v1.0.1.17** Archicad 29のサポート。座標アクションメニューでサーベイポイントとプロジェクトの原点の間で選択できるようになりました。ビューポイントは、座標アクションメニューで構成された座標設定に相対的に再生されるようになりました。公開および共有されたメジャーおよびマイナーリビジョンを使用した新しいステータスワークフローのサポート。

_Revitプラグイン v1.0.15_

- このプラグインは、Autodesk プラグインページから分離された独自の.MSIインストーラーを備えています。
- コメントまたは説明に@と入力すると、選択できるメンバーのリストが表示され、どのメンバーをメンションしたいかを選択できます。
- トピックコメント内の3Dスナップショットおよび他の画像の画像は現在、より速く読み込まれます。
- Revit 2026のサポート

> **注:** このプラグインを使用するには、前のバージョンをアンインストールし、新しいバージョンをインストールする必要があります。

**Tekla plugin v1.4.0**公開および共有されたメジャーおよびマイナーリビジョンを使用した新しいステータスワークフローのサポート。Tekla 2023、Tekla 2024、およびTekla 2025のサポート
