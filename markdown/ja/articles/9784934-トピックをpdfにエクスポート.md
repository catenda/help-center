# トピックをPDFにエクスポート

トピックは、[トピックエクスポートダイアログ](https://support.catenda.com/en/articles/4670289-exchange-topics#h_aa0b8d7789)のPDFオプションをクリックしてPDFにエクスポートできます。PDFエクスポートを使用すると、トピックのレポートをエクスポートできます。このエクスポートオプションは、トピックの読みやすいバージョンを取得する場合に便利で、アーカイブ目的または当局への報告に使用できます。

## 1. **PDFのすべてのページに影響する設定**

これらの設定はPDFのすべてのページに影響します

### 1.1 **ロゴ**

PDFの各ページの左上のロゴはデフォルトではCatendaロゴになります。ロゴまたは右上のhub.catenda.comをクリックすると、プロジェクトページに移動します。[プロジェクト設定ページ](https://support.catenda.com/en/articles/4670273-project-settings-page)でカスタムロゴをアップロードして、独自のロゴがここに表示されるようにすることができます。

### 1.2 **言語**

PDFエクスポートは、[アカウント設定](https://support.catenda.com/en/articles/6880968-account-page#h_4aa257b72f)で設定した言語になります。

### 1.3 **トピック順序**

トピックリストのトピックをいかなる方法でソートした場合、レポートに表示されるトピックの順序は、トピックリストをソートした順序を反映します。

## 2. **表紙**

ダウンロードされたPDFには表紙が含まれます。ここでプロジェクトのプロフィール写真と次のエクスポート詳細が表示されます。表紙は次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/nx64p9qh/01-front-page.png)

### 2.1 **プロジェクト名**

プロジェクトの名前

### 2.2 **エクスポート済み**

トピック数とエクスポート元のトピックリスト。トピックリスト名をクリックすると、そのトピックリストに移動します。

### 2.3 **エクスポートの時間**

PDFエクスポートが作成されたときのUTCタイムゾーンの時刻。

### 2.4 **トピックの一覧**

このエクスポートの一部であるトピックが以下にリストされます。トピックの名前をクリックすると、Catenda Hubのそのトピックに移動します。

## 3. **トピックページ**

各トピックの詳細を含む各トピックのページが表紙の後に追加されます。典型的なトピックページは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/nx64p9qh/02-topic-pages.png)

### 3.1 **タイトル**

トピックのタイトルとそれに続くCatenda上のトピック番号。

### 3.2 **含まれるメタデータ**

以下のヘッダーが含まれています：

**タイプ**トピックのタイプ

**ステータス**トピックのステータス

**担当者**トピックの担当者

**作成者**トピックの作成者

**作成**トピックが最初に作成された時刻

**クローズ時刻**トピックがクローズされている場合、トピックの最後のクローズ時刻がここに表示されます。

**期日**期日

**トピックリストのカスタムフィールド**各カスタムフィールドとその値が含まれています

**ラベル**ラベルは名前と色とともにリストされます。

### 3.3 **除外されるトピックヘッダー**

**マイルストーン**マイルストーンはPDFエクスポートに含まれません。

**マーカー** [ここ](https://support.catenda.com/en/articles/4854523-2d-location-of-topics)をクリックして、PDFへの2D位置のエクスポートについて詳しく読んでください。

### 3.4 **トピック関連**

CatendaのトピックリンクはPDFエクスポートに含まれます。関連要素は自動的にエクスポートされないため、この情報を別々にエクスポートすることを検討してください。

**トピック**トピックがエクスポートされたトピックにリンクされている場合、各トピックはCatenda上のそのトピックへのリンクとともにリストされます。

> **注:** これらのトピックは異なるトピックリストからのものであるため、必ずしもレポートに含まれる必要はありません。

**ドキュメント**トピックにリンクされたドキュメントがある場合、ここにリストされ、Catenda内の各ドキュメントへのリンクが表示されます。

### 3.5 **説明**

トピックの説明

### 3.6 **コメント**

トピックにコメントが投稿されている場合は、ここに表示されます。まずコメント投稿者のユーザー名とコメントを投稿した日付が表示され、その後に添付されたすべての画像とコメントのテキストが続きます。

## 4. **レポートページ**

レポートページを使用すると、トピックだけでなくドキュメントについてのカスタムレポートを作成することができます。レポートページはオンデマンド機能で、進行中のプロジェクトで有効にするようにリクエストできます。この機能が有効になっているテンプレートプロジェクトに基づいて作成された新規プロジェクトには、この機能は有効になっていません。これらのレポートは、ExcelおよびPDFだけでなく、多くのファイル形式にエクスポートできます。これらのレポートは複数のトピックリストから同時にトピックをエクスポートすることもできます。[ここ](https://support.catenda.com/en/articles/12303098-reports-page)をクリックして、レポートページについて詳しく読んでください
