# Catenda Desktop Connector for System Imagesについて

> オペレーティングシステムイメージにソフトウェアをインストールする組織向けのCatenda Desktop Connectorのバージョンで、リクエストして取得できます。

> **注:** この記事はサインアウトした読者向けです。このトピックの三つのレベルすべてへのリンクは、この記事の末尾にあります。

Catenda Desktop Connectorは、Catenda Hubとコンピューター間のアップロードとダウンロードをスケジュール設定するもので、[Catenda Desktop Connector](https://support.catenda.com/ja/articles/8358861-catenda-desktop-connector)で説明されています。オペレーティングシステムイメージにソフトウェアをインストールする組織向けのバージョンは、リクエストできます。

## 1. **概要**

通常のDesktop Connectorと同じアプリケーションですが、コンピュータ全体ではなくユーザーごとにインストールされるようにパッケージ化されています。これは、Citrixのゴールデンイメージなど、準備されたイメージから設定されたコンピュータと仮想デスクトップに適しています。

## 2. **はじめに**

Catenda Desktop ConnectorはCatenda Hub内のプロジェクトで機能します。使用するには、最初のプロジェクトで開始する方法についてCatenda営業に問い合わせてください: [https://catenda.com/get-started](https://catenda.com/get-started)または[sales@catenda.com](mailto:sales@catenda.com)。

> **注:** Catenda Desktop Connector for System Imagesは三つのレベルで説明されています。概要: この記事（サインアウトした読者向け）。[はじめに](https://support.catenda.com/ja/articles/17778688) _(システムイメージパッケージを調べているサインイン済みのお客様向け)_: 用途について。[詳細](https://support.catenda.com/ja/articles/17778690) _(システムイメージパッケージを提供されたユーザー向け)_: 設定方法と使用方法。はじめにを開くには、[https://hub.catenda.com](https://hub.catenda.com)でCatendaにサインインし、ヘルプセンターのページを開くか再読み込みしてください。
