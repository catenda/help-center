# Catenda Desktop Connector for System Imagesについて

> オペレーティングシステムイメージにソフトウェアをインストールする組織向けのCatenda Desktop Connectorのバージョンで、リクエストして取得できます。

Catenda Desktop Connectorは、Catenda Hubとコンピュータ間のアップロードとダウンロードをスケジュール管理し、[Catenda Desktop Connector](https://support.catenda.com/ja/articles/8358861-catenda-desktop-connector)に説明されています。オペレーティングシステムイメージにソフトウェアをインストールする組織向けのバージョンをリクエストできます。

## 1. **概要**

通常のDesktop Connectorと同じアプリケーションですが、コンピュータ全体ではなくユーザーごとにインストールされるようにパッケージ化されています。これは、Citrixのゴールデンイメージなど、準備されたイメージから設定されたコンピュータと仮想デスクトップに適しています。

## 2. **はじめに**

Catenda Desktop ConnectorはCatenda Hub内のプロジェクトで機能します。使用するには、最初のプロジェクトで開始する方法についてCatenda営業に問い合わせてください: [https://catenda.com/get-started](https://catenda.com/get-started)または[sales@catenda.com](mailto:sales@catenda.com)。

> **注:** Catendaの顧客向けに詳細情報が利用可能です。[https://hub.catenda.com](https://hub.catenda.com)でCatendaにサインインしてから、ヘルプセンターのページを開くか再読み込みしてください。ヘルプセンターは、[Catenda Desktop Connector for System Imagesの概要](https://support.catenda.com/ja/articles/17778688-catenda-desktop-connector-for-system-images-の概要)から始まるサインイン済みの顧客に詳細情報を表示します_(サインイン済みの顧客のみ)_。
