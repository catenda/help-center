# Catendaでの入札

入札の設定は建設プロセスの重要な部分です。当然のことながら、ドキュメントがCatenda Hubで既に利用可能であるため、ユーザーはプロジェクトを入札に使用するように設定したいと考えています。プロジェクトメンバーとのコラボレーションでのCatendaの通常の使用と比較すると、これはいくつかの課題をもたらします。入札を作成する当事者は公正な競争を確保したいと考えます。この記事には以下が含まれています

この記事では、以下のトピックについて説明します：

## 1. **アクセス権設定**

入札プロセスに参加する請負業者は、Catendaで実行できるアクションに制限を設けるべきです。入札ユーザーには、ベースとして使用できるプロジェクト内の特定のドキュメントセットへのアクセスのみを付与できます。プロジェクト内のすべての場所への読み取りアクセスを付与しながら、見てはいけない場所へのアクセスを付与しないようにできます。

## 2. **Catendaの匿名使用**

入札プロセスでは、提出当事者が互いに知らないことが重要です。Catendaではすべてのユーザーがプロジェクト内の他のすべてのユーザーを見ることができ、これは入札状況で問題を引き起こす可能性があります。Catendaでアカウントを作成できる方法に応じて、この問題を解決するいくつかの方法があります。

### 2.1 **メールエイリアス**

Catendaではすべてのアカウントがメールアドレスに接続されています。入札に使用されるアカウントが匿名のままであることを確認する方法の1つは、アカウントを作成するために使用されるメールエイリアスを作成することです。アカウントが接続されているメールアドレスを制御しているため、ユーザー名とメールアドレスの両方が匿名のままであることを確認できます。その後、アクセスが必要な当事者とアカウントのユーザー名とパスワードを共有できます。

### 2.2 **ユーザーごとのメールアカウント**

メールのエイリアスを作成することを許可しない企業もあります。ユーザーが互いに見ることが重要でない場合、ユーザーは通常の方法で招待できます。Catendaのメンバーページ以外のすべての場所で、あるメンバーが共有した情報が別のメンバーに見られないようにするための良い方法があります。

### 2.3 **外部ユーザー**

各入札提出者に対して個別のユーザーを作成できない場合、提出者を招待しないで、Catendaプロジェクトを入札情報を共有する場所として使用することもできます。[入札情報ベース](#h_9ab97bdd71)セクションに示されているように、[ドキュメントコレクション](https://support.catenda.com/en/articles/6344318-collections-page)と[3Dブックマーク](https://support.catenda.com/en/articles/4670281-bookmarks-page)を準備して外部当事者と共有し、提出のベースとして使用できます。このようにして、外部ユーザーはプロジェクトの一部ではなく、プロジェクト内のドキュメントと3Dビューにアクセスできます。ユーザーがプロジェクトの一部ではないため、ドキュメント配信は別の場所に提出する必要があります。提出されたドキュメントは、提出後に入札者によってプロジェクトにアップロードできます。

## 3. **入札情報ベース**

プロジェクトには、入札プロセスが始まるときに建物に関する多くの情報が既に含まれていることがよくあります。したがって、提出当事者を正しいドキュメントに案内することが重要です。これは、誤ったドキュメントを誤って見ないようにするためだけでなく、すべての提出者が同じ情報で作業していることを確認するためです。

### 3.1 **ドキュメントベース**

入札プロセスのベースとして使用したいドキュメントの[ドキュメントコレクション](https://support.catenda.com/en/articles/6344318-collections-page)を作成することは、入札者がどのドキュメントを見るべきかを示す簡単な方法です。[ドキュメントコレクション](https://support.catenda.com/en/articles/6344318-collections-page)をリビジョンにロックできるため、ドキュメントのどのバージョンが使用されるべきかについて混乱がないことを確認できます。提出者がプロジェクトの一部でない場合、ドキュメントコレクションを外部で共有することもできます。このようにして、各提出当事者と大きなファイルを共有でき、送信されたダウンロードリンクをクリックしたときに確認を見ることができます。

### 3.2 **3Dベース**

ドキュメントと同様に、[ブックマーク](https://support.catenda.com/en/articles/4670281-bookmarks-page)を使用して、入札提出者がどの3Dモデルを見るべきかを示すベースを作成できます。ブックマークは、プロジェクトのどの部分が3Dで意図されているかのビューポイントを入札者に示すための優れた方法です。

**プロジェクトと共有** [ブックマーク](https://support.catenda.com/en/articles/4670281-bookmarks-page)をプロジェクトと共有して、他のプロジェクトメンバーがそれらを見ることができるようにする必要があります。[ドキュメントとしてのモデル](https://support.catenda.com/en/articles/8064548-models-as-documents)を使用すると、入札ユーザーがアクセス権のあるモデルのみを見ることができるようにアクセスを構成できます。

**公開ブックマーク**公開ブックマークは、入札の一部として外部当事者と3Dビューを共有するための優れた方法です。公開ブックマークを使用すると、入札提出者がオブジェクトプロパティなしでブックマーク内のモデルのシンプルなバージョンを見ることができるリンクを生成できます。これは、これらのオブジェクトに含まれる可能性のある機密数量情報が誤って漏洩されないようにするためです。

## 4. **公開共有を無効にする**

入札プロジェクトは多くの場合プライベートであり、情報が他の当事者と共有されないことが重要です。ダウンロード以外にエクスポートする方法がないことを確認する方法の1つは、プロジェクトの公開共有機能を無効にするよう要求することです。このオプションが無効になると、ドキュメントコレクションやブックマークで共有可能なリンクを作成できなくなり、機密情報がダウンロード以外の方法でプロジェクトから流出することがなくなります。このオプションの詳細については、[ここ](https://support.catenda.com/en/articles/8224886-organization-options#h_1027778040)をご覧ください。
