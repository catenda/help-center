# 承認ページのトラブルシューティング

この記事では、以下のトピックについて説明します：

## 1. **新しい承認リクエストの送信**

1000を超えるドキュメントが「ドキュメント追加」ボタンで追加されるレビューのために新しい承認リクエストが送信されると、次のエラーが表示されます：

![新しい承認リクエストエラー ワークフロー デフォルトワークフロー 送信者 タイトル](https://raw.githubusercontent.com/catenda/help-center/main/images/atct6we8/01-submitting-a-new-approval-request.png)

新しい承認リクエストダイアログは、一度に最大1000のドキュメントで送信することのみが可能です。1000を超えるドキュメントで承認リクエストを送信するには、まず新しい承認リクエストダイアログに最大1000のドキュメントを追加し、ドラフトとして保存します。ドキュメントのドラフト承認ページにアクセスし、承認リクエストを送信する前に必要なだけドキュメントを追加します。

## 2. **概要タブ - 承認リクエストのクローズ**

承認をクローズする場合、公開が失敗する可能性があります。承認の[概要タブ](https://support.catenda.com/en/articles/12495126-overview-tab-in-an-approval-request)では、以下が表示されます：

![公開に失敗しました 1ドキュメント公開済み。1ドキュメントの更新に失敗しました 詳細を表示](https://raw.githubusercontent.com/catenda/help-center/main/images/atct6we8/02-overview-tab-closing-an-approval-request.png)

### 2.1 **既に公開済みのリビジョンが存在します**

最新のリビジョンが共有リビジョンであるドキュメント内で共有リビジョンを公開することのみが可能です。承認内のリビジョン、または前回公開されたリビジョンの後の他の共有リビジョンが公開され、新しいメジャーリビジョン番号が作成された場合、このリビジョンは既に存在するため、次のメジャーリビジョン番号にはなることができず、失敗します。共有リビジョンは、別の承認リクエストのクローズの結果として、またはドキュメントテーブルのパブリッシュアクション、またはリビジョンの右メニューのリビジョン情報を使用して公開されている可能性があります。

## 3. **ドキュメントタブ**

### 3.1 **ドキュメントが見つかりません**

承認の一部であるドキュメントが削除されると、それ以上見つけることができず、ドキュメントの内容はファイルレビューページに表示されなくなります。これは、承認の一部であるドキュメントが削除されたときのドキュメントタブの外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/atct6we8/03-document-not-found.png)

承認リクエストに追加され、その後削除されたドキュメントは、管理者によって回復するか、承認リクエストから破棄することができます。

### 3.2 **取下げられたリビジョン**​

承認の一部であるドキュメントリビジョンが取下げられると、リビジョン番号は取消線が引かれ、ドキュメントの内容はファイルレビューページに表示されなくなります。これは、承認の一部であるドキュメントリビジョンが取下げられたときのドキュメントタブの外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/atct6we8/04-withdrawn-revision.png)

承認リクエストに追加され、その後取下げられたドキュメントリビジョンは、承認リクエストから破棄できます。
