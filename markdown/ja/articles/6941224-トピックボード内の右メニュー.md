# トピックボード内の右メニュー

[トピックページ](https://support.catenda.com/en/articles/4670271-topics-page)の右メニューは、[トピックバナー](https://support.catenda.com/en/articles/7986346-topic-banner-navigating-topics)下の検索バーの右側にあるインフォアイコンをクリックして見つけることができます。アイコンをクリックするとメニューが開き、選択されたトピックとトピックリストに関する情報が表示されます。

これは[トピックバナー](https://support.catenda.com/en/articles/7986346-topic-banner-navigating-topics)のような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/01-intro.png)

これはインフォアイコンのような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/02-intro.png)

これは展開時の右メニューのような外観です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/03-intro.png)

## 1. **1. 選択情報**

これは右メニューの上部のような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/04-1-selection-info.png)

### 1.1 **1.1 選択されたトピック**

右メニューの最上部に、選択されたトピックの数が表示されます。

### 1.2 **1.2 トピックリスト情報**

**1.2.1 複数のリスト**すべてのトピックリストまたは複数のリストからトピックが選択されている場合、トピックリスト情報には「複数のリストが選択されました」と表示されます

**1.2.2 リスト名**特定のトピックリストに移動した場合、または選択されたすべてのトピックが同じリストからのものである場合、トピックリスト名がここに表示されます。

## 2. **2. トピックなし**

これはトピックが選択されていない場合の右メニューのような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/05-2-no-topics.png)

### 2.1 **1.1 選択されたトピックを更新**

トピックが選択されていない場合は「トピックが選択されていません（展開時）」と表示されます。このメニューでは、選択されたトピックを表示および更新できます。複数のトピックが選択されている場合、ここでトピックを一括更新できます。

### 2.2 **1.2 トピックリストのアクセス権設定**

トピックが選択されていない場合、トピックリストのアクセス権設定メニューは、単一のトピックリストに移動したときにのみ表示されます。すべてのトピックリストで、トピックを選択して、そのトピックが属するリストのアクセス権設定を確認します。トピックリストのアクセス権設定の詳細については、[こちら](https://support.catenda.com/en/articles/4670296-topic-board-access-control)をクリックしてください。

## 3. **3. 単一トピック**

単一のトピックが選択されている場合、トピック情報は、トピックをクリックしてコンテンツページを読み込む必要なく、右メニューで更新できます。これは単一のトピックが選択されている場合の右メニューのような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/06-3-single-topic.png)

### 3.1 **3.1 選択されたトピックを更新**

これは単一のトピックが選択されている場合の右メニューのような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/07-3-1-update-selected-topic.png)

**3.1.1 トピックヘッダー**これは[トピックヘッダー](https://support.catenda.com/en/articles/8400566-topic-header-the-subject-of-a-topic)のような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/08-3-1-update-selected-topic.png)

**3.1.2 トピックボディ**トピックヘッダーの下に、説明とコメント付きのトピックボディがあります。ここから説明とコメントを追加し、新しいコメントを作成できます。トピックボディの詳細については、[こちら](https://support.catenda.com/en/articles/8053352-topic-body-the-content-of-a-topic)をクリックしてください。

### 3.2 **3.2 ドキュメント**

関連ドキュメントの詳細については、[こちら](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic#h_b00b9c5150)をクリックしてください。

### 3.3 **3.3 オブジェクト**

関連オブジェクトの詳細については、[こちら](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic#h_758f17abbc)をクリックしてください。

### 3.4 **3.4 トピック**

関連トピックの詳細については、[こちら](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic#h_edf2cb07a8)をクリックしてください。

### 3.5 **3.5 トピックリストのアクセス権設定**

単一のトピックは常に1つのトピックリスト内にあるため、トピックリストのアクセス権設定メニューには、選択されたトピックが属するトピックリストへのアクセスが表示されます。トピックリストのアクセス権設定の詳細については、[こちら](https://support.catenda.com/en/articles/4670296-topic-board-access-control)をクリックしてください。

**アクセス権を設定**アクセス権を設定をクリックして、選択されたトピックが属するトピックリストへのアクセスを編集します。_必要なアクセス権:_ 管理者

> **注意:** ボードのアクセス権は選択されたトピックへのアクセスを反映していますが、このメニューに表示されるのはトピックが属するボード全体のアクセス権であり、選択されたトピック自体だけのアクセス権ではありません。

## 4. **4. 複数トピック**

複数のトピックが選択されている場合、トピック情報は、各トピックを開いてコンテンツページを読み込む必要なく、右メニューで一括更新できます。

### 4.1 **単一リストの選択されたトピックを更新**

これは、同じトピックリストから複数のトピックが選択されている場合の、選択されたトピックを更新メニューのような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/09-update-selected-topics-a-single-board.png)

**ステータス**複数のトピックのステータスを一度に設定または更新します。

**タイプ**複数のトピックのタイプを一度に設定または更新します。

**担当者**複数のトピックの担当者を一度に設定または変更するか、「割り当て解除」を選択して複数のトピックから担当者の割り当てを一度に解除します。

**依頼者**複数のトピックの依頼者を一度に設定または変更するか、「割り当て解除」を選択して複数のトピックから依頼者の割り当てを一度に解除します。

**期日 / マイルストーン**複数のトピックの期日/マイルストーンを一度に設定または変更します。期日/マイルストーンメニューで、「期日を削除」または「マイルストーンを削除」をクリックして、複数のトピックから期日/マイルストーンを一度に削除します。

**ラベルを編集**ラベルを追加 複数のトピックに一度にラベルを追加します。

ラベルを削除 複数のトピックから一度にラベルを削除します。

優先度 同じラベルが両方のメニューに追加されている場合、ラベルの削除が優先されます。

**カスタムフィールド**複数のトピックのカスタムフィールド値を設定するか、フィールドを値なしに設定します。

> **注意1:** トピックリスト設定で必須として設定されているフィールドは設定解除できません。**注意2:** テキスト、整数、小数フィールドの更新のみが可能で、それらを設定解除することはできません。ただし、整数フィールドと小数フィールドはnullに設定でき、テキストは単一のスペースに設定できます。

**コメント**複数のトピックに一度にコメントを追加します。複数のトピックに一度にコメントを追加することのみが可能で、コメントを編集または削除することはできません。

**値を設定解除**フィールドで値を選択した後、各フィールドの右側のxをクリックして値を削除します。

> **注意:** このxはフィールドをクリアするためではなく、値をクリアするためだけのものです。このメニューには、フィールドをクリアするための追加の値があるフィールドがあります

**保存**「保存」をクリックして変更内容をコミットします。

### 4.2 **複数リストから選択されたトピックを更新**

これは、異なるトピックリストから複数のトピックが選択されている場合の、選択されたトピックを更新メニューのような外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/10-update-selected-topics-from-multiple-boards.png)

複数のリストからトピックが選択されている場合、ステータスとタイプは更新できません。担当者とリクエスターで選択可能なユーザーは、選択されたすべてのトピックリストへのアクセス権を持つユーザーに限定されます。

**保存**「保存」をクリックして変更内容をコミットします。

**一括更新アクセス要件**ユーザーがトピックリストへの書き込みアクセス権を持つトピックに対してのみ一括更新が可能です。_必要なアクセス権:_ 選択されたトピックの各トピックリストへの書き込みアクセス権。

### 4.3 **トピックリストのアクセス権設定**

選択されたすべてのトピックが同じトピックリストからのものである場合、そのリストのアクセス権をトピックリスト設定に移動することなくこのメニューで確認できます。

**アクセス権を設定**アクセス権を設定をクリックして、選択されたトピックが属するトピックリストへのアクセスを編集します。_必要なアクセス権:_ 管理者

> **注意:** ボードのアクセス権は選択されたトピックへのアクセスを反映していますが、このメニューに表示されるのはトピックが属するボード全体のアクセス権であり、選択されたトピック自体だけのアクセス権ではありません。
