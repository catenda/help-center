# Catenda Site - トラブルシューティング

## 1. ネットワークに接続していない

以前に読み込まれていないプロジェクトは、ネットワークに接続していない状態で開こうとすると、以下のエラーメッセージが表示されます：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8pwddg4t/01-no-connection-to-the-network.png)

Catenda Site でネットワークに接続していない状態で Catenda プロジェクトを使用するには、最初にネットワークに接続した状態でプロジェクトを開いてください。

## 2. トピックが同期されない

Catenda Site で行われた変更が他のセッションで表示されない場合は、トピックボード右上の[送信箱](https://support.catenda.com/en/articles/7325268-offline-mode-in-catenda-site#h_ff2a47f221)で送信する必要があります。

## 3. MFAコードが必要

プロジェクトを開こうとしたときに多要素認証が必要であることを示すメッセージが表示される場合は、ブラウザで Catenda アカウントにログインし、アカウント設定で[コードペアリングを設定](https://support.catenda.com/en/articles/4969891-multi-factor-authentication)してください。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8pwddg4t/02-mfa-code-required.png)
