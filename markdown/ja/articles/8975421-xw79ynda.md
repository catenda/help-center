# Catenda Siteのファイルタイプのプレビュー

Catenda Site上のドキュメントは、[ドキュメントメニュー](https://support.catenda.com/en/articles/7774637-documents-menu-catenda-site)のドキュメントをタップすることで見つけることができます。

この記事では、以下のトピックについて説明します。

## 1. 右上のボタン

ドキュメントの上部には、次のオプションがあります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/01-top-right-buttons.png)

### 1.1 ハンバーガーメニュー

ドキュメントの右上のハンバーガーメニューをクリックすると、画面の下部にメニューが開きます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/02-1-hamburger-menu.png)

**開く**

開くオプションをタップして、デバイス上の別のアプリケーションでドキュメントを開きます。

このオプションは、ドキュメントプレビュー機能を備えたアプリケーションでドキュメントを開くために使用できます。例えば、画像を画像編集アプリで開いたり、コメントを追加できるアプリでPDFを開いたりできます。

**共有**

共有オプションをタップして、デバイス上の別のアプリケーションでドキュメントを共有します。

このオプションは、メールやメッセージなどの通信タイプでドキュメントを添付ファイルとして共有するために使用できます。

ハンバーガーメニューの外をタップするか、メニューをドラッグダウンして再度閉じます。

### 1.2 検索

ドキュメント内に検索可能なテキストがある場合、検索オプションを使用してこのテキスト内のフレーズを見つけることができます。検索ボタンをタップすると、検索バーが表示され、探しているフレーズを入力できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/03-2-search.png)

xを押して検索を削除します。

**マッチファインダー**

フレーズを入力した後、マッチボタンをタップすると、ドキュメント内でフレーズがマッチしたすべての場所の概要が表示されます。

**検索バーのハンバーガーメニュー**

ハンバーガーメニューをタップすることで、大文字を考慮するかどうかをマッチケースオプションで選択でき、フレーズが単語の一部ではなく全単語として検出されるかどうかを選択できます。

### 1.3 ページ

ページボタンをクリックすると、ドキュメント内のページの概要が表示されます。

ページの1つをタップして、そのページを開きます。

### 1.4 表示設定

表示設定ボタンをタップすると、表示設定ダイアログが開きます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/04-4-viewing-settings.png)

ここで、表示モードを次のように設定できます。

_シングルページ_ - デフォルト

一度に1ページずつ表示されます。

**ダブルページ**

2つのページが並んで表示されます。

**リーディング**

ドキュメントの簡略版が表示され、読みやすい太字のヘッダーとマージンが削除されています。

カバーモード

ダブルページと同じですが、最初の画面のみカバーが表示されます。

垂直スクロールをオフにすると、このモードは便利です。

**垂直スクロール**

デフォルトでは垂直スクロールはオンになっていますが、垂直ではなく水平にスクロールする場合はオフにすることができます。

**時計回りに回転**

ドキュメントを時計回りに90度回転させます。

各ページは個別に回転し、スクロール方向は位置に留まります。

モデルビューアーでは、IFCのみがサポートされています。

Catenda Siteで以下のファイルタイプをプレビューできます。

## 3. オープンファイル形式

Catendaでは、使用するソフトウェアに関係なく、誰もが一緒に作業できるようにオープンスタンダードで作業することを好みます。

_一般的に、誰もが本質的なオープンな性質のため、その開発に参加できます。([ウィキペディア](https://en.wikipedia.org/wiki/Open_standard#:~:text=Typically%2C%20anybody%20can%20participate%20in%20their%20development%20due%20to%20their%20inherently%20open%20nature.))_

これは、1つの組織だけが開発内容をコントロールしていないことを意味します。

### 4.1 IFCバージョン

IFCバージョンのステータスに応じて、異なる方法でバージョンをサポートしています。

_正式、廃止_ - 完全なサポート。すべての正式および廃止されたIFCバージョンがサポートされています。

_撤回済み_ - 部分的なサポート。モデルは最後の正式なバージョンに従って処理されます。

_開発中_ - サポートなし。公開される前にまだ変更される可能性があります。

IFCリリースが正式なものであることを確認できます[こちら](https://technical.buildingsmart.org/standards/ifc/ifc-schema-specifications/)

正式なBuildingSMARTサンプルIFCファイルは[こちら](https://github.com/buildingSMART/Sample-Test-Files)で見つけることができます。

ポイントクラウド内のポイントは、色または強度でプレビューできます。
