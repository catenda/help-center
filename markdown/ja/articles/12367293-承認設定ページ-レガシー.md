# 承認設定ページ - レガシー

承認設定ページは、[承認ページ](https://support.catenda.com/en/articles/8349340-approvals-page)の緑のプラスボタンの右側にあるアクションメニューで承認設定アクションをクリックすることで見つけることができます。_必要なアクセス権_: 管理者

承認設定ページのバナーは次のようなものになります:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/01-intro.png)

## 1. **承認設定ページ上のアクション**

承認設定ページのアクションは、承認設定ページの右上にあるアクションメニューをクリックすることで見つけることができます。承認設定ページのアクションは次のようなものになります:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/02-actions-on-the-approvals-settings-page.png)

[ここをクリック](https://support.catenda.com/en/articles/12367730-topic-templates-page)してトピックテンプレートページについて詳しく読みください。

## 2. **公開オプション**

承認における最終検証の結果としてドキュメント内に公開リビジョンが作成される場合に発生するデフォルトの動作を選択します。承認設定ページは次のようなものになります:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/03-publish-options.png)

各結果に対して公開ステータスが作成・設定され、トピックテンプレートも設定されたあとの承認設定ページは次のようなものになります:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/04-publish-options.png)

### 2.1 **ファイルレビューステータス**

次の承認検証結果は、最終検証時に異なるトピック作成動作を引き起こす可能性があります:

- 承認済み
- コメント付きで承認済み
- 承認待ち
- 却下

### 2.2 **ドキュメントステータス**

ドキュメントステータスドロップダウンをクリックして、プロジェクト内の公開ステータスのリストからステータスを選択するか、ステータスを設定しません。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/05-document-status.png)

プロジェクト内のステータスを編集するには、[ドキュメント設定ページ](https://support.catenda.com/en/articles/7831371-document-settings-page)のステータスワークフローメニューにアクセスします。

### 2.3 **トピックテンプレート**

トピックテンプレートが設定されると、承認における最終検証の結果として作成された公開リビジョンごとにトピックを作成できます。承認プロセス中にドラフトリビジョンにマークアップが作成された場合、作成されたトピックに、マークアップ内のアノテーションセットごとに1つのコメントが追加されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/06-topic-template.png)

**トピックを作成しない / マークアップを保存しない**デフォルトでは、この設定はトピックを作成しないに設定されており、ドロップダウンでマークアップを保存しないを選択することで、その設定に戻すことができます。

**新しいトピックテンプレートを作成** [ここをクリック](https://support.catenda.com/en/articles/12372007-creating-a-new-topic-template)してトピックテンプレートの作成について詳しく読みください。

**トピックプレビュー**トピックテンプレートが選択されている場合、テンプレートの横にある目のアイコンをクリックして、そのトピックテンプレートの内容を確認します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/07-topic-template.png)

### 2.4 **保存**

保存をクリックして変更を保存します

## 3. **新しい検証ワークフロー**

承認設定ページは、新しい検証ワークフローを使用して開始するプロジェクトでは利用できません
