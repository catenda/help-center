# Solibri Topics統合

> **重要:** **Solibriバージョン9.13:** **重要:** BCFコネクタプラグインはバージョン9.13以降、Solibriの「BCF Live connector」という別のタブになっています。このタブでも同じ情報の多くが適用されます。**Solibriバージョン9.9:** Solibriの更新9.9以降、Catendaとtopicを同期することが可能になりました。

このドキュメントでは、CatendaプロジェクトでBCFコネクタをセットアップする方法について説明します。これにより、2つのアプリケーション間でtopicをシームレスに通信でき、手動のエクスポートおよびインポートBCFステップを回避できます。

1\) Solibri Solution CenterからSolibri Model Checkerを購入してダウンロードします。すでにこのツールを持っている場合は、アップグレードしてください。

2\) Solibri Solution Center（[https://solution.Solibri.com/application/#!ProductsView](https://solution.solibri.com/application/#!ProductsView)）からBCFコネクタを取得/アップグレードできます

Solibri Extensionsに移動してBCFコネクタを選択します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/01-intro.png)

> **注:** BCFコネクタを有効にするには、Solibri AdminがSolibri Solution Centerのユーザー管理画面で有効にする必要があります。

3\) SMCを開き、設定画面に移動します。そこからBCFコネクタを選択します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/02-intro.png)

4\) サーバーを追加

1. まず「サーバーを追加」ボタンを押すと、2番目のページに移動します。
2. このステップで、接続するサーバーを選択できます。この場合はCatendaのサーバーです。
3. ここでCatendaプロジェクトのURLを貼り付けることができます。このURLの場所については、次の画像で説明されています。
4. 接続を完了するにはOKをクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/03-intro.png)

6\) Catendaプロジェクトのtopicsページで、プロジェクトのURLを見つけることができます。これはExchange topicsに配置されています。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/04-intro.png)

7\) 次に、Solibriのコミュニケーション画面に移動し、プレゼンテーションを選択します。そこから新しいプレゼンテーションを作成できます。右クリックしてコンテキストメニューを表示し、Catendaと同期できるようにします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/05-intro.png)

8\) ここから新しいプレゼンテーションを作成し、CatendaからSolibriにインポートすることもできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/06-intro.png)

BCFサーバーでワークフローを最適化するには、[こちらをご覧ください](https://support.bimsync.com/hc/en-us/articles/360011987619)
