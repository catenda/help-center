# 3Dビューアツールメニュー

> Catenda Hubの3Dビューアツールについて説明します

[3Dビューア](https://support.catenda.com/en/articles/8227211-3d-viewer)に3Dモデルを読み込んだ後、[ツールドロップダウンボタン](https://support.catenda.com/en/articles/8227211-3d-viewer#h_003a4c0a62)は右上に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/01-intro.png)

> **注:** ツールボタンは通常このような見た目ですが、選択したツールによって外観が変わることがあります。

ツールドロップダウンを開くと、次のような表示になります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/02-intro.png)

この記事で説明されているトピック：

## 1. **オブジェクトピッカー - デフォルト**

このツールを使用すると、オブジェクトをクリックして選択できます。このツールを選択するための[キーバインド](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=Object%20picker-,Space,-Laser%20measure)は「スペース」です

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/03-object-picker-default.png)

オブジェクトを選択した後、Controlキーを押しながら複数のオブジェクトを選択します。[2Dビューア](https://support.catenda.com/en/articles/4854537-2d-viewer#h_042dc145fa)で矩形選択を使用してオブジェクトを選択することもできます。

## 2. **切断面**

切断面を素早く作成するには、オブジェクトをポイントして、右クリックアクションメニューから切断面を作成します。ツールメニューの平面作成ツールは、異なる角度の表面をポイントときに作成しようとしている切断面のプレビューを表示するため、切断面の作成がより簡単になります。

### 2.1 **切断面を作成**

ここをクリックして、マウスをかざしたオブジェクトと平行な[切断面](https://support.catenda.com/en/articles/4670253-clipping-planes)を作成します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/04-create-clipping-plane.png)

[ここ](https://support.catenda.com/en/articles/4670253-clipping-planes)をクリックして、切断面の作成方法について詳しく学習してください。

### 2.2 **測定面の作成**

ここをクリックして、マウスをかざしたオブジェクトと平行な[測定面](https://support.catenda.com/en/articles/8360838-measure-plane)を作成します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/05-create-measure-plane.png)

## 3. **計測ツール**

レーザー計測は、表面と線を検出し、これら2つのポイント間の計測値を自動的に提供する機能です。一方、巻き尺は、ポイントAを選択してポイントBに線を引き、これらのポイント間の計測値を提供する機能です。

### 3.1 **レーザー計測**

レーザー計測を使用すると、オブジェクト間の距離を計測できます。これの[キーバインド](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=Laser%20measure-,m,-Tape%20measure)は「m」です

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/06-laser-measure.png)

計測中は情報パネルと計測メニューを開いておくことをお勧めします。ツールドロップダウンからレーザー計測ツールを選択した後、計測を開始できます。平面または表面の端をポイントして左クリックして、そこから計測を開始します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/07-laser-measure.png)

### 3.2 **計測メニュー**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/08-measurement-menu.png)

**計測をクリア**計測をクリアする方法については、[ここ](#h_7b050901dd)をクリックしてください

**単位**デフォルトでは、プロジェクト設定で管理者によって設定された計測単位が表示されます。計測単位（ミリメートル、センチメートル、メートル）を選択します。

**表示** 3Dビューに計測値を表示する異なる方法から選択します。これらは「長さ」「セグメント」「距離」です。

### 3.3 **計測値を非表示**

計測後、計測線は表面との水平および垂直交差点に沿って、および表面の法線に沿って表示されます。計測線を非表示にするには、非表示ボタンをクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/09-hiding-measurements.png)

### 3.4 **セグメントの追加または削除**

計測を確認してクリックすると、水平および垂直交差線が最初の交差オブジェクトまたは交差するオブジェクトがない場合は表面の端まで拡張されます。

> **ヒント:** 矢印は非常に便利です。特に、ウィンドウ、ドア、手すりなど間の計測値を見つけたい場合に便利です。

**セグメントの追加**計測の横にある矢印をクリックして、計測線を次の交差オブジェクトまで両方向に拡張します。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/10-add-or-remove-segments.png)

_セグメントの削除_ 計測線に複数のセグメントがある場合、マイナスをクリックして削除できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/11-add-or-remove-segments.png)

### 3.5 **計測情報**

各計測の計測情報が表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/12-measurement-information.png)

**セグメント情報**左側には、各セグメントの長さと対応するセグメント番号が表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/13-measurement-information.png)

> **注:** 上部の表示をセグメントに設定して、3Dビューアで各セグメント番号を見つけることができます

**距離情報**右側には、計測線の開始点から各セグメントの終点までの距離が表示されます。総長は、計測線の開始点から最後のセグメントの終点までの距離であり、下の画像のように表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/14-measurement-information.png)

### 3.6 巻き尺

ポイント間の距離を計測します。これの[キーバインド](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=Tape%20measure-,Shift%20%2B%20m,-Point%20measure)は「Shift+m」です

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/15-tape-measure.png)

Catenda Hubの巻き尺機能を使用すると、3Dビューア内の選択されたポイント間を自由に計測できます。計測テープは線と表面も検出します。これにより、何を計測しているのか、また何から計測しているのかを簡単に把握できます。斜め計測を行うと、画像に表示されているように垂直計測と水平計測も追加されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/16-tape-measure.png)

レーザー計測ツールと同様に、目のアイコンをクリックして、異なる計測線を非表示にできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/17-tape-measure.png)

### 3.7 **ポイント測定**

座標を計測します。これの[キーバインド](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=Point%20measure-,Ctrl%20%2B%20m,-Content%20panel)は「Ctrl+m」です

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/18-point-measure.png)

## 4. **測定をクリア**

ツールドロップダウンの最後の要素をクリックして、ビューアにある計測値をクリアします。3Dビューの計測値を削除するには、「測定をクリア」を押します

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/19-clear-measures.png)

計測メニューで、上部の「計測をクリア」をクリックするか、「x」ボタンを押して各計測値を個別にクリアすることができます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/10m0pcfa/20-clear-measures.png)
