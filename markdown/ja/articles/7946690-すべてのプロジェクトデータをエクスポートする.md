# すべてのプロジェクトデータをエクスポートする

> Catenda Hubのプロジェクトデータ、ドキュメント、model、およびトピックのエクスポート方法の概要。利用可能なオプションには、Desktop Connectorの同期、PDF/Aレポート作成、アクセス許可監査、およびAWS S3またはAzure Blobストレージへの自動クラウドバックアップが含まれます

Catenda Hubは、日々のダウンロードから自動エンタープライズアーカイブまで、様々なプロジェクト要件に合わせたフレキシブルなエクスポート方法を提供します。特定のプロジェクト要件に応じて、Desktop Connectorを使用して大規模なフォルダ構造を同期し、Reports Pageを介してカスタムドキュメント配送チェックリストおよびPDF/Aアーカイブを生成し、またはプロジェクトアクセス許可を文書化して監査証跡を作成することが可能です。継続的なクラウド間バックアップが必要な組織の場合、Catenda Data Exportはおよため自動転送を直接AWS S3またはAzure Blobストレージに提供します。

## 1. **エクスポート理由**

プロジェクトオーナーおよびプロジェクト参加者は、プロジェクトのライフサイクル中およびその後、プロジェクトドキュメントのローカルコピーを保持する必要があることがよくあります。

### 1.1 **データ提出とフェーズ変更**

プロジェクトデータは、様々なプロジェクトマイルストーンで必要とされることがあります：

**フェーズ変更**計画、設計、および建設の間の遷移には、特にプロジェクトが保留または新しい関係者に引き継がれる場合、データスナップショットの抽出が必要になることがよくあります。

**政府への問い合わせ**プロジェクト中またはプロジェクト完了時に、公式な当局への提出が頻繁に必要とされます。

**入札**入札用のドキュメント提出パッケージの準備。

### 1.2 **独立したデータ保持およびアクセス保護**

エクスポートはプロジェクト完了に限定されません。メインプロジェクトデータを所有しないプロジェクトメンバーは、自分の作業への継続的なアクセスを確保するために、独自のコピーを必要とすることがよくあります。

プロジェクトメンバーは、プロジェクトアクセスがいつ終了するかについて常に事前に通知されるわけではなく、アクセスが予想より早く取り消される場合があります。警告なしにアクセスが失われる可能性があるため、**Catenda Data Export**または**Catenda Desktop Connector**などの**スケジュール設定された定期的なエクスポート**を構成することが重要です。これらの定期的なツールは、プロジェクトメンバーがアクセスを失う前の最後のスケジュール実行までのローカルまたはクラウドバックアップを保持することを確保します。

### 1.3 **データアーカイブおよびコンプライアンス**

規制および業界標準は、責任ある関係者が長期間(多くの場合、数年から数十年にわたる)プロジェクトレコードを保存することを頻繁に義務付けています。システムドキュメント、製品レコード、およびコンプライアンスファイルは、会社のサーバーまたは指定されたリポジトリに保存する必要がある場合があります。

### 1.4 **プロジェクト終了**

アクティブなプロジェクトが完了するか、ライセンス期間が終了する場合、Catendaはプロジェクトデータを安全に保存された状態に保ちます。プロジェクトアクセスが終了した場合でも、データはCatendaサーバー上で最大3年間回復可能です。

### 1.5 **フローズンアーカイブオプション**

アーカイブオプションにより、プロジェクトは選定されたメンバーのためにアクセス可能な読み取り専用リポジトリとして凍結された状態で残ります。

## 2. **標準エクスポートオプション**

これらのビルトインエクスポートツールは、標準インターフェース内で、すべての認可されたプロジェクト参加者に直接利用可能です。

### 2.1 **modelのエクスポート**

Catenda内のすべてのモデルはドキュメントセクション内のドキュメントにリンクされているため、標準ドキュメントエクスポート機能もモデルに適用されます。さらに、モデル用の専用エクスポートオプションが利用可能です：

**選択したモデルのダウンロード** [モデルページ](https://support.catenda.com/ja/articles/4670286-モデルページ)で1つ以上のモデルを選択し、ダウンロードアクションを使用して最新版を抽出します。

**個別revisionダウンロード** [modelsページ](https://support.catenda.com/ja/articles/4670286-モデルページ)でmodelを選定し、右情報パネルの各revisionの隣のダウンロードボタンを使用します。これにより、完全な[modelコンテンツページ](https://support.catenda.com/ja/articles/4670270-モデルコンテンツページ)をロードする必要なく、特定のrevisionを直接ダウンロードする効率的な方法が提供されます。別の方法として、individual revisionsはmodelのコンテンツページから直接ダウンロードすることもできます。

**高度なmodelエクスポート** [modelエクスポートページ](https://support.catenda.com/ja/articles/4670280-モデルエクスポートページ)にアクセスして、複数のmodel全体で選定されたrevisionをダウンロード可能なZIPファイルにパッケージ化します。この方法には、タグ、ユーザー定義プロパティ、またはライブラリ情報をベイク・インすることにより、エクスポートされたmodelファイルを拡張するための高度なオプションが含まれています。

### 2.2 **トピックのエクスポート (3つの方法)**

トピックデータは、情報がどのように表示、分析、または保存されるかに応じて、[トピックの交換](https://support.catenda.com/ja/articles/4670289-トピックの交換)を介して3つの主要フォーマットを使用して抽出できます：

**BCF (BIM Collaboration Format)**トピック作成タイムスタンプを含め、公式BCF仕様に厳格に準拠するトピック情報をキャプチャおよび転送するために設計されたオープンスタンダード。このフォーマットは、幅広いクロスプラットフォーム相互運用性を保証し、他のBCF互換ソフトウェアでシームレスにトピックデータを再度開く、編集、または交換するのに理想的です。直接ファイルプレビューが必要な一般的な長期ドキュメントリポジトリの場合、通常PDFまたはExcelフォーマットが推奨されます。

**Excel**トピックパラメータをスプレッドシートフォーマットにエクスポートして、フィルタリング、ソート、およびデータ操作を行います。このフォーマットは、データの選定およびコピーに理想的な構造化された行と列を提供し、Excelファイルはほとんどのアーカイブプラットフォーム内で簡単にプレビューできます。アーカイブ目的では、より多くの情報が含まれているため、一般的にPDFエクスポートがExcelより推奨されます。

**PDF**標準PDFフォーマット(v1.4)で、専門的なソフトウェアなしでアクセス可能なクリーンで読みやすいサマリーレポートを生成します([トピックをPDFにエクスポート](https://support.catenda.com/ja/articles/9784934-トピックをpdfにエクスポート)を参照)。標準PDFエクスポートには、公式機関への報告とアーカイブのための統合ダウンロードタイムスタンプが含まれ、Excelエクスポートより多くの情報を提供します。基本エクスポートは標準PDF(v1.4)ファイルを生成しますが、多くのアーカイブシステムはアップロード時にPDF/Aに自動変換して長期プレビューを可能にします。オプトインの[レポートページ](https://support.catenda.com/ja/articles/12303098-レポートページ)を有効にしたプロジェクトは、[レポートでプロジェクトデータをエクスポート](https://support.catenda.com/ja/articles/17779017-レポートでプロジェクトデータをエクスポート)で説明されているようにアーカイブ形式でトピックをエクスポートすることもできます_(レポートエディタ顧客のみ)_。

### 2.3 **ドキュメントおよびコレクションのエクスポート**

**バッチおよびフォルダダウンロード**個別のフォルダ、特定のドキュメントバッチ、またはすべての表示テーブルアイテムを一度に選定して、ダウンロード可能なZIPアーカイブを生成します。大規模なデータセットで作業する場合、スムーズな転送のため、特定のサブフォルダまたは対象ファイルグループを選定して管理可能なバッチでダウンロードすることを推奨します。

- **公開タブ**<br>選択したドキュメントごとに最新の公開版を抽出します。
- **ワークスペースタブ**<br>選択したドキュメントごとに最新の共有版を抽出します(「共有版の表示」権限が必要です)。レガシドラフト版はZIPアーカイブに一括ダウンロードできず、個別にダウンロードされることに注意してください。

**個別revisionダウンロード** [ドキュメントページ](https://support.catenda.com/ja/articles/8204673-ドキュメントページ)でドキュメントを選定し、右情報メニューにリストされた各revisionの隣のダウンロードボタンをクリックします。ドキュメントプレビューページをロードする必要がないため、個別または過去のrevisionをダウンロードするより簡単な方法です。テーブル内の別のドキュメントを選定し、新しいプレビューページを開く必要なく右メニューのrevisionをダウンロードできます。

**公開コレクション** [コレクション](https://support.catenda.com/ja/articles/6344318-コレクションページ)を使用して、選定されたドキュメントサブセット用の公開リンクを作成し、Catendaアカウントを要求せずに外部パーティがファイルをダウンロードできるようにします。公開revisionのみがコレクションに追加できることに注意してください。

**削除されたファイル**ドキュメント検索バーで「削除済み」を検索して、以前に削除されたドキュメントを見つけてエクスポートします。このフィルタは言語固有であり、現在の言語設定の「削除済み」という用語に対応することに注意してください。

### 2.4 **Desktop connector (自動ローカルバックアップ)**

[Catenda Desktop Connector](https://support.catenda.com/ja/articles/8358861-catenda-desktop-connector)は、新しいドキュメントrevisionを定期的にダウンロードしてローカルドライブに直接保存するバックグラウンド同期を有効にします。バッチウェブエクスポートと異なり、ダウンロードされたドキュメントはシステムに直接未圧縮ファイルとして到着し、手動アーカイブ抽出を必要としません。

**スケジュール設定および即時バックアップ**タスクは定期的な間隔で自動実行されるようにスケジュール設定することも、オンデマンドで実行することもでき、プロジェクトメンバーがプロジェクトアクセスが予期せず取り消された場合でもドキュメントの最新ローカルコピーを保持することを確保します。

**直接API転送**ブラウザメモリの制限またはオーバーヘッドなしで直接API接続を活用することで、ウェブブラウザダウンロードより有意に大規模なデータセットをより高速に転送します。

**階層オプション**完全な階層がそのまま保持された選定フォルダ構造をダウンロードするか、個別に選定されたファイルを指定されたローカルフォルダにフラットリストとして直接抽出します。

### 2.5 **メンバーアクセスおよびアクティビティログ**

**トピックリスト** 2つの利用可能なビューを使用してボードアクセス許可を文書化します：

- **ユーザーごとのアクセスビュー**<br>トピックリストまたは選択されたトピックの右側の情報メニューから、個別のユーザーのアクセスレベルを直接表示します。<br>_必要なアクセス権:_ トピックリストへの読み取りアクセス
- **チーム全体の構成**<br>トピックリストのアクセス設定内の完全なチームレベルの権限設定のスクリーンショットをキャプチャします。<br>_必要なアクセス権:_ トピックリストまたはプロジェクト管理者へのフルアクセス

**ドキュメント&Model アクセス** [アクセス概要](https://support.catenda.com/ja/articles/6660820-ドキュメント権限一覧ページ)をエクスポートして、メンバーおよびチームのアクセス許可を記録します。必須アクセス: プロジェクト管理者。Catenda内のすべてのmodelはドキュメントセクション内のドキュメントにリンクされているため、modelのアクセス許可は基盤となるドキュメントアクセス許可により管理され、同じドキュメントアクセス概要またはアクセス許可メニューを使用して記録されます。

**ドキュメント&Model revision アクセス** [ドキュメント revisionの右メニュー](https://support.catenda.com/ja/articles/8302244-リビジョンの右メニュー-リビジョン情報)からアクセス許可を表示し、必要に応じてスクリーンショットをキャプチャします。

**プロジェクト全体のアクション権限** [プロジェクト設定ページ](https://support.catenda.com/ja/articles/4670273-プロジェクト設定ページ)にプロジェクト全体のアクセス許可を文書化します（トピックリスト作成、新しいメンバー招待、ドキュメントステータス設定、モデル作成または削除など）。2つの利用可能なビューを使用します：

- **ユーザーごとのアクセスビュー**<br>プロジェクトメンバーはアクセス制御の各メニューを展開して、各アクションを実行する権限を持つ個別ユーザーを確認できます。
- **完全な構成**<br>管理者は編集アクセスダイアログを開いて、チームレベルの権限構成を表示および管理できます。<br>_必要なアクセス権:_ プロジェクト管理者

**ユーザープロファイル＆メンバー詳細**プロジェクトメンバーおよびチームに関する情報は、抽出または文書化するために利用可能で、以下を含みます：

- ユーザー名およびメールアドレス ([カスタムメンバー情報](https://www.google.com/search?q=https://support.catenda.com/ja/articles/11769670-カスタムメンバー情報)参照)。
- チームメンバーシップ、割り当てられたトピック、アップロードされたmodelrevision、およびアクセス許可設定 ([メンバーページ](https://www.google.com/search?q=https://support.catenda.com/ja/articles/4670291-メンバーとチームページ)または[チームページ](https://www.google.com/search?q=https://support.catenda.com/ja/articles/4670291-メンバーとチームページ)経由でキャプチャ)。

### 2.6 **通知**

[プロジェクト通知ページ](https://support.catenda.com/ja/articles/4670295-プロジェクト通知ページ)からのスクリーンショット経由で通知ページをキャプチャし、[制限フィルター](https://support.catenda.com/ja/articles/8304417-通知ページでのフィルタリング)を使用してページあたりの表示可能なアイテムを最大化します。

[プロジェクト特定通知設定](https://support.catenda.com/ja/articles/4670262-プロジェクト固有の通知設定)を有効にして検索可能な通知ログを維持するための電子メールサマリーで専用管理アカウントを設定します。

### 2.7 **Reports Page (オプトイン機能)**

[レポートページ](https://support.catenda.com/ja/articles/12303098-レポートページ)はオプトイン機能で、進行中のプロジェクトでリクエストできます。有効にされたプロジェクトは、ドキュメントとトピックデータを書式付きレポートとしてエクスポートすることもでき、長期アーカイブ用の形式を含みます。

**テンプレートベースの管理**有効にすると、プロジェクト管理者は[レポートテンプレートページ](https://support.catenda.com/ja/articles/12380837-レポートテンプレートページ)を使用して独自のレポートテンプレートを設定し、選択されたドキュメントまたはトピックの書式付きエクスポートを生成します。

エクスポート可能な内容と対応するファイル形式については、[レポートでプロジェクトデータをエクスポート](https://support.catenda.com/ja/articles/17779017-レポートでプロジェクトデータをエクスポート)で説明されています_(レポートエディタ顧客のみ)_。

## 3. **Catenda Data Export**

Catenda Data ExportはCatenda Hubとは別に販売されています。上記のダウンロードと異なり、プロジェクトデータをCatenda Hubから組織独自のクラウドストレージ(Amazon S3またはAzure Blob storage)に自動的にコピーします。プロジェクトに対応するバックアップを維持したい、または独自のストレージに保存されたプロジェクトレコードを保持したい組織に適しています。プロジェクト所有者だけが対象ではありません。プロジェクト所有者はプロジェクトの完全なバックアップをエクスポートでき、プロジェクト参加者は参加しているプロジェクトでアクセス可能な内容をエクスポートできます。詳細については、[Catenda Data Exportについて](https://support.catenda.com/ja/articles/17779020-catenda-data-exportについて) (サインインしていない読者向け)および[Catenda Data Exportの概要](https://support.catenda.com/ja/articles/17779027-catenda-data-export-の紹介) (サインイン顧客向け)を参照してください。Catenda Data Exportを所有しているお客様は[Catenda Data Export](https://support.catenda.com/ja/articles/17779052-catenda-data-export) (Data Exportのお客様のみ)でセットアップを見つけることができます。
