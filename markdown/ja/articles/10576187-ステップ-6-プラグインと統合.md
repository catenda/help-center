# ステップ 6 - プラグインと統合

> Catenda をあなたの好みのツールに接続

> **ヒント:** [ステップ 5](https://support.catenda.com/en/articles/10576182-step-5-topics) を[はじめに](https://support.catenda.com/en/collections/2657208-getting-started)でヘルプセンターまたはヘルプメニューから見つけます。

## 1. **([ダウンロードリンク](https://support.catenda.com/en/articles/8396532-catenda-connections))**

## 2. **デスクトップ コネクタ**

- デスクトップを Catenda に接続
- Catenda のドキュメントリポジトリからお使いの PC 上の指定した場所にダウンロードをスケジュール
- お使いの PC 上の指定した場所から Catenda のドキュメントリポジトリにアップロードをスケジュール
- これらのスケジュール済みダウンロードとアップロードを日単位で実行

## 3. **Navisworks**

- すべての Catenda プロジェクトにアクセス
- Catenda と Navisworks の間でトピックを交換
- Navisworks でクラッシュ オブジェクトを検索
- Navisworks のクラッシュから BCF トピックを作成
- Catenda 上のドキュメント ライブラリにアクセスして、Navisworks がサポートするファイル形式を開く
- すべてのモデル リビジョン (最新版のみではない) にアクセス
- NWD ファイルを直接 Catenda に保存
- トピックをグループまたは複数のクラッシュから作成する際にビューポイントを統合します (すべてのクラッシュを含む1つのビューポイントを作成)

## 4. **Revit**

- すべての Catenda プロジェクトにアクセス
- Catenda と Revit の間でトピックを交換
- IFC モデルを Catenda にエクスポート
- Revit でクラッシュ オブジェクトを検索
- Revit で BCF トピック (2D および 3D) を作成
