# Catenda から Power BI にサインインする

> Catenda コネクタが Power BI から Catenda にサインインする方法と、サインインが失敗または期限切れになった場合の対処方法。

Power BI 用 Catenda コネクタは、ユーザー自身の Catenda アカウントを使用して Catenda にサインインします。この動作は、リリース版の[Catenda Power BI Connector](https://support.catenda.com/ja/articles/5784721-catenda-power-bi-コネクタ)と、[Catenda Power BI Connector (On Demand)](https://support.catenda.com/ja/articles/17778871-catenda-power-bi-コネクタ-オンデマンド)のどちらでも同じです。

## 1. **初めてサインインする**

1. Power BI Desktop で、**データの取得** > **その他** > **その他** > **Catenda** に移動し、**接続** を選択します。
1. ブラウザ ウィンドウが Catenda サインイン ページで開きます。
1. Catenda アカウントでサインインします。

Catenda サインイン自体は、[サインイン ページ](https://support.catenda.com/ja/articles/7891486-サインインページ) に説明されています。

Power BI Desktop はサインインを記憶しているため、後の更新と新しい接続は再度質問されません。ナビゲーターには、アカウントがアクセスできるすべてのプロジェクトが表示されます。

## 2. **アップグレード後に再度サインインする**

Catendaコネクタは、以前はPower BIでは_Bimsync_と呼ばれていました。Power BI Desktopは各名前に対して個別のサインインを保持しているため、_Bimsync_コネクタからのアップグレード後の最初の接続は新しいサインインを要求します。

## 3. **サインインが失敗したか、期限切れになった場合**

サインインが失敗し続ける場合、再度質問し続ける場合、またはロードが _Catenda サインイン期限切れ_ で停止する場合、Power BI Desktop に保存されているサインインをクリアする必要があります:

**ファイル** > **オプションと設定** > **データ ソースの設定** に移動します。

![Power BI Desktop のファイル メニューの 「オプションと設定」 ページ。「オプションと設定」 から 「データ ソースの設定」 への矢印](https://raw.githubusercontent.com/catenda/help-center/main/images/8jvrzkes/01-when-the-sign-in-fails-or-has-expired.png)

Catenda エントリを選択して、**アクセス許可をクリア** をクリックします。

![Catenda エントリが選択され、「アクセス許可をクリア」 ボタンが表示された Power BI Desktop の 「データ ソースの設定」 ダイアログ](https://raw.githubusercontent.com/catenda/help-center/main/images/8jvrzkes/02-when-the-sign-in-fails-or-has-expired.png)

再度接続してサインインします。

## 4. **長時間の読み込みの前に**

多くのテーブルを一度に読み込むと時間がかかる場合があり、その間にサインインが更新されます。長時間の読み込みは、新しいサインイン直後に開始するのが最適です: 上記のようにアクセス許可をクリアしてサインインしてから、読み込みを開始します。
