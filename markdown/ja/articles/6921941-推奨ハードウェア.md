# ハードウェア推奨仕様

> Catenda Hubで最高のエクスペリエンスを得るために、推奨されるハードウェア仕様と最適化のヒントをご覧ください。

## 1. **ハードウェア推奨仕様:**

このハードウェア推奨は、ブラウザアプリケーションとしての Catenda Hub のみを対象としています。これには、タブレットのブラウザで開かれた Catenda Hub、または [iPad および他のタブレット](#ipad-and-other-tablets) で説明されているようにホーム画面に追加されたものが含まれます。3D オブジェクトの詳細レベルによって異なる要件がある可能性があります。詳細レベル (LOD) は、AIA のドキュメント G202 で LOD 100、200、300、400、500、および 600 として定義されています。LOD の定義は [ここ](https://assets.aiacontracts.com/ctrzdweb02/zdpdfs/aia-g202-2013-free-sample-preview.pdf) で確認できます。

## 2. **モニター**

1つ以上の外部モニターがデバイスに接続されている場合、Catendaがそのモニターに表示されていなくても、デバイスがモニターの数と、モニターが持つディスプレイ解像度の組み合わせおよびオペレーティングシステムで設定されている解像度をサポートしていることを確認してください。

## 4. **iPad および他のタブレット**

Catenda Hub は iPad または別のタブレット上で、ブラウザで、または [ホーム画面に追加](https://support.catenda.com/ja/articles/10741601-ホーム画面に追加) してアプリとして使用することもできます。ホーム画面に追加されている場合でも、デバイスのブラウザで実行されている Catenda Hub のままなので、完全な機能が利用可能であり、以下の推奨事項は両方に適用されます。

### 4.1 **グラフィックスメモリが読み込める 3D の量を決定する**

3D ビューアに表示されるモデルは、グラフィックスプロセッサのメモリに保持されます。タブレットでは、グラフィックスプロセッサがデバイスの残りのメモリを共有し、専用グラフィックスカードを備えたコンピューターよりもメモリが少ないです。タブレットが同時に表示できるジオメトリの量は、したがってストレージスペースではなく、そのチップとメモリに依存します。ストレージが多いタブレットでは、より多くのモデルが読み込まれません。

### 4.2 **推奨タブレット**

通常のプロジェクト (LOD 300 まで) の場合、最新バージョンの iPadOS を実行している最近の iPad が推奨されます。高密度ジオメトリプロジェクト (LOD 400 以上) または多くのモデルを一緒に表示する必要がある場合は、M シリーズチップを搭載した iPad Pro または iPad Air が推奨されます。Android タブレットでは、最新バージョンの Android を搭載した最近のハイエンドチップモデルが推奨されます。iPadOS および Safari を最新の状態に保つことが重要です。更新はしばしばブラウザが 3D グラフィックスを処理する方法を改善するためです。

### 4.3 **タブレットから最大限の利益を得る**

タブレットでは、手元のタスクに必要なもののみを読み込むことが役に立ちます。

- プロジェクト内のすべてのモデルではなく、必要なモデルのみをオンにします。
- [クエリ](https://support.catenda.com/ja/articles/4854514-クエリ) を使用して、作業しているモデルの一部のみを表示します。
- [3D ビューア設定](https://support.catenda.com/ja/articles/5784718-3d-ビューア設定) でインクリメンタルレンダリングをオンにします。

詳細なヒントは [3D ビューア最適化](https://support.catenda.com/ja/articles/13927321-3dビューア最適化) で説明されています。

建設現場での作業の場合、Catenda Siteモバイルアプリがより適切であることが多く、詳細は[画面スペースが限られたアクセス](https://support.catenda.com/ja/articles/10695677-画面スペースが限られている場合のアクセス)に記載されています。Catenda Siteのデバイス推奨事項は[ハードウェア推奨 - Catenda Site](https://support.catenda.com/en/articles/17596478-hardware-recommendation-catenda-site)に記載されています。
