# 2Dビューアの外観

2Dビューアのコンテンツを設定して、ニーズに合わせてカスタマイズする方法はいくつかあります。

## 1. **ビューアオブジェクト**

### 1.1 **選択したオブジェクトを強調表示**

モデルが処理されるときに各ストーリーに対して生成された線は、線が生成されたときにスライスされた3Dオブジェクトにリンクされたままです。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3bzb6a32/01-highlighting-selected-objects.png)

3Dビューアでオブジェクトが選択されている場合、そのモデルのストーリーが2Dビューアで有効になっている場合、そのオブジェクトが存在する高さで生成された2Dビューアで、オブジェクトも強調表示されます。オブジェクトスライスは、ifcファイルの各ストーリーに対して設定された高さから1メートル上に生成されます。IFCSiteの標高などの標高オフセットは考慮されません。

以下の例では、ストーリー「Ground Floor」は0メートルに位置しています。ベース高さが0で、異なる上部高さを持つ壁が表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3bzb6a32/02-highlighting-selected-objects.png)

ご覧のとおり、1メートル以上の壁のみが2Dビューアに表示されます。

### 1.2 **ドアスイング**

ドアスイングはIFCファイルで指定されています。以下のBuildingSMARTの記事でこの仕組みをご覧いただけます：[IFC 2x3](https://standards.buildingsmart.org/IFC/RELEASE/IFC2x/FINAL/HTML/ifcsharedbldgelements/lexical/ifcdoorstyle.html) [IFC 4](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_1/FINAL/HTML/schema/ifcsharedbldgelements/lexical/ifcdoortypeoperationenum.htm) ドアスイングが指定されていない場合、ドアは右に向かって開きます。

## 2. **アンダーレイとしての図面**

[ストーリーコンフィギュレーター](https://support.catenda.com/en/articles/6921756-storey-configurator-page)を使用して、ドキュメントセクションからPDFをアンダーレイすることが可能です。これは、3Dオブジェクトがスライスされた高さの上または下に、2Dビューアに表示されないオブジェクトがある場合に特に役立ちます。例には、ダクトとパイプ、電気コンセント、天井平面図、道路と鉄道が含まれます。

## 3. **2Dビューアのマーカー**

[マーカーが有効](https://support.catenda.com/en/articles/4854537-2d-viewer#h_381a9d4098)な場合、位置情報付きのトピックは、x-y座標に色付きの円として表示されます。以下は、ブラウザーで異なるマーカーを持つ2Dビューがどのように見えるかです：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3bzb6a32/03-markers-in-the-2d-viewer.png)

トピックの2D位置の詳細については、[こちら](https://support.catenda.com/en/articles/4854523-2d-location-of-issues)をクリックしてください。

### 3.1 **既存のマーカーを持つトピック**

**マーカーインタラクション -** マーカーの上にマウスを置くと、マーカーが由来するトピックの番号とタイトルが表示されます。マーカーをクリックして、コンテンツパネルの各トピックボードでトピックを開きます。開かれたトピックに属するマーカーが緑で強調表示されます。

**マーカーの表示 -** トピックボードをフィルタリングおよび検索します。準備された2Dビューアにマーカーがあるフィルタリング結果からのトピックが表示されます。

### 3.2 **新しいマーカーを持つトピック**

マーカーを使用して作業する前に、2Dビューアが設定されていることを確認してください。

- **モデル2Dビューのストーリー -** 有効な2Dビューからストーリーを選択して、ベース高さとします。その他の2Dビューを有効にして、そのストーリーの横に表示します。
- **ビルから得たストーリー -** 事前に設定されたビルから、ストーリーを選択します。
  設定されたモデルからのベース高さと有効な2Dビューが有効になります。

**マーカーの配置 -** キャンバスを右クリックして、マーカー付きの新しいトピックを作成します。コンテンツパネルのトピックヘッダーの位置追加をクリックして、マーカーを追加する場所をクリックします。

## 4. **2Dビューアのルームラベル**

2Dビューアのルーム中心に表示されるルームラベルは、IFCルームオブジェクトで利用可能なデータを使用して決定されます。これらのルームオブジェクトには短い名前と長い名前の両方が含まれており、Catendaの**ルーム名形式**設定を介してラベル形式を定義するように設定できます。IFCデータにルーム番号と領域が正確に含まれていることを確認してください。属性がない場合、目的のルームラベルの表示が制限される可能性があります。

### 4.1 ルームラベルのトラブルシューティング：

- IFCデータファイルに、ルーム番号と領域のような必要な属性が含まれていることを確認してください。
- 「ルーム名形式」設定を確認して調整し、推奨されるラベル設定に合わせてください。この設定は、2Dビューアの右隅の「設定ホイール」で見つけることができます。
