# トピックの交換

トピックボードの右上の[新規アイテムアクションメニュー](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board#h_8c642e051a)から、トピック交換アクションを見つけることができます。トピック交換メニューは次のようになります：

![ファイルベースの交換 新しいtopic exchange topics 履歴 import bcf export topics connect to a bcf client synchronize topics directly with any BCF-compatible client by using the URL below](https://raw.githubusercontent.com/catenda/help-center/main/images/8qf7d3yv/01-intro.png)

## 1. **BCFをインポート**

BCFインポートアクションを使用して、BCFファイルをインポートします。BCFインポートダイアログは次のようになります：

![Import BCF upload bcf file: select file browse selct board generate new types and statuses from the BCF-file](https://raw.githubusercontent.com/catenda/help-center/main/images/8qf7d3yv/02-import-bcf.png)

Catendaはオープンスタンダードに100%コミットしています。これに基づいて、BCF(BIM協業フォーマット)のインポートとエクスポートを実装しました。これにより、ユーザーはこのフォーマットに対応している他のソフトウェア(例えばSolibri、Navisworksなど)からトピックをインポート/エクスポートできます。例えば、別のソフトウェアアプリケーションで作成された同じモデルの衝突制御データを含むファイルをインポートできます。この方法で、Catenda内でワークフローを続行できます。

**BCFあたり複数のトピック** 1つのBCFファイルに複数のトピックを含めることができます

**最大ファイルサイズ**インポート可能な最大BCFファイルサイズは500 MBです。

### 1.1 **BCFファイルをアップロード**

参照をクリックして、アップロードするBCFファイルを選択します

### 1.2 **ボードを選択**

トピックをインポートするトピックボードを選択します。

### 1.3 **BCFファイルから新しいタイプとステータスを生成**

BCFファイルがトピックボードに存在しないステータスとタイプを持つ場合、このボックスをチェックすることでこれらを自動的に作成できます。_必要なアクセス権:_ トピックボードへのフルアクセス

BCFファイルがトピックボードに存在しないステータスとタイプを持つ場合、このボックスがチェックされていないままだと、存在しないステータス/タイプはリンク解除されます。インポートが完了した後、リンク解除されたステータス/タイプを既存のステータス/タイプにマップできます。

_複数のステータス/タイプを一度にリンク_ トピックボードにリンク解除されたステータス/タイプがある場合、トピックボードにリンク解除されたフィールドがあることを示す橙色の警告メッセージが表示されます。_必要なアクセス権:_ プロジェクト管理者

![Topics there are unlinked fields in this topic board click here to リンク](https://raw.githubusercontent.com/catenda/help-center/main/images/8qf7d3yv/03-generate-new-types-and-statuses-from-the-bcf-file.png)

リンクをクリックすると、[リンク解除されたフィールド](https://support.catenda.com/en/articles/4670277-topic-board-settings#h_3bd7e3e759)領域の[topic board設定](https://support.catenda.com/en/articles/4670277-topic-board-settings)に移動し、1種類のすべてのフィールドを一度に既存の値にリンクできます。

## 2. **トピックをエクスポート**

トピックボードの右上の[新規アイテムアクションメニュー](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board#h_8c642e051a)でトピックのエクスポートを選択するか、トピックボードの上のトピックのリストからトピックを選択して[選択されたアイテムアクションメニュー](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board#h_b5c00c149b)でエクスポートオプションを選択することで、トピックをエクスポートできます。トピックのエクスポートダイアログは次のようになります：

![Export topics all topics from the current topic board current フィルター selected topics bcf excel pdf v3.0](https://raw.githubusercontent.com/catenda/help-center/main/images/8qf7d3yv/04-export-topics.png)

> **注意：** トピックは一度に1つのtopic boardからのみエクスポートできます。

### 2.1 **フィルターオプション**

**現在のボードのすべてのトピック**

**現在のフィルター**

**選択されたトピック**

### 2.2 **BCFエクスポート**

選択するBCFのバージョンによって、異なるファイルタイプを取得できます。BCF v3.0とv2.1は.bcfを生成し、v2.0は.bcfzipを生成します

### 2.3 **Excelエクスポート**

トピックをExcelにエクスポートすることが可能です。topic boardのテーブルビューでは、トピックあたり1行、列ごとに1列があります。列の順序は、デフォルトのtopic board [テーブルビュー](https://support.catenda.com/en/articles/6941099-table-view-in-an-topic-board#h_3102328063)の列の順序と同じになります。

> **注意:** 画像がなく、トピック内の最後のコメントのみがエクスポートされます。

### 2.4 **PDFエクスポート**

トピックをPDFにエクスポートする方法の詳細については、[ここ](https://support.catenda.com/en/articles/9784934-exporting-topics-to-pdf)をクリックしてください

## 3. **レポートページ**

レポートページを使用すると、トピックだけでなくドキュメントについてもカスタムレポートを作成することが可能です。レポートページはオンデマンド機能であり、継続中のプロジェクトに対して有効化をリクエストできます。この機能が有効になっているテンプレートプロジェクトに基づいて作成された新しいプロジェクトには、この機能は有効になっていません。これらのレポートは、ExcelとPDFだけでなく、多くのファイル形式にエクスポートできます。レポートページの詳細については、[ここ](https://support.catenda.com/en/articles/12303098-reports-page)をクリックしてください

## 4. **BCFクライアントに接続**

Catenda HubをBCFサーバーとして使用する場合、他のソフトウェアに直接接続できます。ここでトピックをインポート/エクスポートする必要なく、Catendaからトピックを送受信できます。これはbuildingSMART International（から）標準化されたBCF APIを使用します。これをサポートするソフトウェアの例は、Navisworks、Revit、ArchicadおよびSolibriです。これらのソフトウェアでは、サーバーへの一般的なURL [https://api.catenda.com/](https://api.catenda.com/)を使用できます。その後、すべてのプロジェクトからすべてのtopic boardを取得します。これはスクロールするのに時間がかかる長いリストになる可能性があるため、お客様をサポートするために、このメニューで現在のtopic boardへのリンクを提供しています。代わりにこのリンクを使用すれば、探しているトピックを簡単に見つけることができます。
