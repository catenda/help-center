# プロジェクトメンバー - 組織ツール

プロジェクトページは、[組織のプロフィールページ](https://support.catenda.com/en/articles/8497478-organization-profile-page)のサブページで見つけることができます。ここでは、この組織に属するプロジェクトに含まれるすべてのメンバーの概要が表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/01-intro.png)

## 1. **検索とフィルター**

メンバーページでは、以下の条件でフィルターできます：

### 1.1 **該当なしのフィルタを非表示**

「該当なしのフィルタを非表示」トグルはデフォルトではオフになっており、すべての可能なフィルターが表示されます。このフィルターボタンをオンにすると、結果のないフィルターを非表示にできます。

### 1.2 **プロジェクト -** `project=<Project GUID>`

このフィルターを使用すると、プロジェクトのすべてのエントリでフィルターできます

### 1.3 **ロール -** `role=administrator,member`

このフィルターを使用すると、ユーザーがプロジェクトの管理者またはメンバーであるかどうかでフィルターできます

### 1.4 **ユーザー -** `user=<User GUID>`

このフィルターを使用すると、複数のユーザーに属するすべてのエントリでフィルターできます

## 2. **アクションボタン**

プロジェクトメンバーリスト内の1人以上のメンバーをチェックボックスをクリックして選択すると、プロジェクトリストの上部に次のアクションボタンが表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/02-action-buttons.png)

### 2.1 **プロジェクトに追加**

プロジェクトの一部である必要なく、組織プロジェクトに1人以上のユーザーを追加します

### 2.2 **プロジェクトのロール(複数)を変更**

プロジェクトの一部である必要なく、1人以上のユーザーのプロジェクトロールを変更します

### 2.3 **プロジェクト(複数)から削除**

プロジェクトの一部である必要なく、1人以上のユーザーを削除します

## 3. **プロジェクトメンバーリスト**

プロジェクトメンバーリストでは、プロジェクトごとにメンバーごとに1つのエントリが表示されます。メンバーが多くのプロジェクトの一部である場合、すべてのプロジェクトに対して多くのエントリが表示される場合があります。特定のプロジェクト内でそのメンバーを見つけるには、プロジェクトフィルターを使用して検索を絞り込むことができます。メンバーリストは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/03-project-membership-list.png)

### 3.1 **チェックボックス**

上部のチェックボックスを使用して、組織が所有するプロジェクトの一部であるすべてのメンバーを選択できます。もう一度クリックするとすべてのチェックを外します。メンバーの横のチェックボックスを使用すると、メンバーを選択から追加または削除できます

### 3.2 **ユーザー**

各メンバーのプロフィール画像、ユーザー名、メールアドレス。メンバーは、属しているプロジェクトごとに表示されます。

### 3.3 **ロール**

メンバーが通常のメンバーであるか管理者であるかを示します

### 3.4 **プロジェクト**

このメンバーが属しているプロジェクト

### 3.5 **組織**

メンバーが組織のユーザーであるかどうか
