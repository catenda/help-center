# ロケーションページ - Catenda Mobile

> Catenda Mobileでプロジェクトを建物、階、室で移動します。

ロケーションページは、[プロジェクトページ](https://support.catenda.com/ja/articles/17601629-プロジェクトページ-catenda-mobile)でプロジェクトを開いた後、画面下部のバーから開きます。

ロケーションページは、建物、階、室など、プロジェクトのロケーション構造を表示します。ロケーション構造はブラウザで作成する必要があります。トピック、フォーム、ドキュメントは、ブラウザとアプリの両方でロケーションに追加できます。

> **注：** ロケーションは、有効にされているプロジェクトでのみ使用でき、現在のところ、Co-creationプログラムのお客様のプロジェクトのみです。その他のプロジェクトでは、ロケーションページは空です。

![建物、階、2つの室があるロケーションページ](https://raw.githubusercontent.com/catenda/help-center/main/images/7z5qbekw/01-intro.jpg)

## 1. **ロケーションを参照**

ロケーションはツリーとして表示されます。建物は階を保持し、階は室を保持します。ロケーションの横のマイナス記号は、その下のロケーションを折りたたみます。ロケーションの下の画像アイコンは、平面図があることを意味します。

## 2. **ロケーションを開く**

ロケーションをタップすると、すべてのピンを含む平面図が表示され、必要な場所にズームとパンが可能です。画面下部のドロワーが上に引き上げて、そのロケーションに関連付けられているすべてのトピック、フォーム、ドキュメントを表示し、平面図とリストを切り替えます。ロケーションから作成されたトピックまたはフォームは、自動的にそのロケーションを取得します。
