# ドキュメントページの右側メニュー

1つ以上のドキュメントを選択すると、ドキュメントページの検索バーの右側に情報アイコンが表示されます。このアイコンをクリックすると、選択したフォルダ（複数可）やドキュメント（複数可）、または入力したフォルダに関する情報を含む情報メニューが開きます。情報アイコンは以下のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/01-intro.png)

このパネルは、選択した内容に応じて異なる場合があります [​_フォルダ（1つ）_ ](#h_cad792004b) _- [ドキュメント（1つ）](#h_2fac53531d) - [フォルダ（複数可）やドキュメント（複数可）](#h_58d67056f7)_

## 1. フォルダ（1つ）

フォルダが1つ選択されている場合の右側メニューの表示例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/02-one-folder.png)

### 1.1 **フォルダ情報**

フォルダが空の場合、アイコンは白色で表示されます。フォルダアイコンの右下には、そのフォルダ内のドキュメント数が表示されます。アイコンの右側には、フォルダの名前が表示されます。鉛筆アイコンをクリックして、フォルダ名を変更できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/03-folder-information.png)

_必要なアクセス権:_ フォルダへの書き込みアクセス権。

### 1.2 **アクセス権設定**

ドキュメントセクションでのアクセス権設定の詳細については、[こちら](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl)をご覧ください。

### 1.3 **コレクション**

ドキュメントが任意の[コレクション](https://support.catenda.com/en/articles/6344318-collections-page)に含まれている場合、ここに一覧表示されます。

## 2. **ドキュメント（1つ）**

ドキュメントが1つ選択されている場合の右側メニューの表示例です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/04-one-document.png)

ドキュメントが1つ選択されている場合、そのドキュメント内の最新の公開版に関する情報が表示されます。利用可能な情報については[こちら](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision)をご覧ください。

## 3. **複数のフォルダ（複数可）やドキュメント（複数可）**

複数のフォルダ（複数可）やドキュメント（複数可）が選択されている場合の右側メニューの表示例です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/05-multiple-folder-s-and-or-document-s.png)

複数のドキュメントまたはフォルダが選択されている場合、ドキュメント情報が変更されます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/06-multiple-folder-s-and-or-document-s.png)

赤い十字をクリックして、選択からそのフォルダまたはドキュメントを削除できます。

### 3.1 **選択したドキュメントを更新**

このメニューを使用して、複数のフォルダ（複数可）やドキュメント（複数可）の値を一度に変更できます。

### 3.2 **アクセス権設定**

このメニューを使用して、複数のフォルダ（複数可）やドキュメント（複数可）のアクセス権を一度に変更できます。ドキュメントセクションでのアクセス権設定の詳細については、[こちら](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl)をご覧ください。

### 3.3 **コレクション**

フォルダ（複数可）やドキュメント（複数可）が任意の[コレクション](https://support.catenda.com/en/articles/6344318-collections-page)に含まれている場合、ここに一覧表示されます。

### 3.4 **リンクされたオブジェクト**

このメニューを使用して、複数のフォルダ（複数可）やドキュメント（複数可）に対して、オブジェクトをリンク/リンク解除できます。
