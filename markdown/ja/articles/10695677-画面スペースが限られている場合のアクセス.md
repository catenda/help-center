# 画面スペースが限られている場合のアクセス

画面サイズが限られている場合、いくつかの機能は当社のモバイルアプリでユーザーフレンドリーな方法でアクセスできます。アクセシビリティよりも機能全体へのアクセスが重要な場合は、ブラウザを通じていつでもご利用いただけます。ブラウザページはホーム画面/ダッシュボード/ドックに追加して、画面サイズが限られた状態でCatendaにアクセスする体験を改善できます。

## 1. **モバイルアプリ -** サイトでアクセス可能

画面サイズが限られたデバイスでは、指で操作する内容が見えるように、ボタンをより大きくする必要があります。このような場合、当社のモバイルアプリであるCatenda SiteとCatenda Mobileが最適なツールです。

### 1.1 **Catendaサイト**

[Catenda Site](https://support.catenda.com/ja/articles/6530821-モバイルアプリ-catenda-site-をダウンロード)は当社の公式モバイルアプリで、iPhone、iPad、およびAndroidでご利用いただけます。

- 機能は制限され、シンプルに保たれているため、必要なボタンを簡単にタップできます。
- コンテンツは[インターネット接続なし](https://support.catenda.com/ja/articles/7325268-catenda-siteのオフラインモード)でダウンロードおよび送信できます。

### 1.2 **Catendaモバイル**

[Catenda Mobile](https://support.catenda.com/ja/articles/17601630-catendaモバイルアプリをダウンロード)は当社のモバイルアプリで早期アクセス版であり、iPhone、iPadは[TestFlight](https://testflight.apple.com/join/xj6WppjQ)で、Androidは[Google Play](https://play.google.com/store/apps/details?id=com.catenda.apex)でご利用いただけます。トピック、ロケーション、フォーム、ドキュメントをカバーしており、時間をかけてCatenda Siteのすべての機能を備えるようになります。

## 2. **ホーム画面 / ダッシュボード / ドック -** 全機能

Catenda Hub の全機能は常にブラウザを通じて利用できます。Catenda はブラウザ経由でインストールすることで、[ホーム画面に追加](https://support.catenda.com/ja/articles/10741601-ホーム画面に追加)、ダッシュボード、またはドックに追加される方法をサポートしています。ショートカットを作成する代わりにブラウザ経由で Catenda をインストールすると、以下の利点が得られます：

- Catenda はより使いやすくなります。これはモバイルデバイスでコンテンツにアクセスするための最も一般的な方法です。
- ブラウザバーが非表示になるため、画面スペースが節約されます。
- 特にタブレットでは、画面スペースを有効活用しながら Catenda の全機能を使用したいでしょう。
