# 画面スペースが限られている場合のアクセス

画面サイズが限られている場合、いくつかの機能は Catenda Site で使いやすい方法でアクセスできます。アクセシビリティよりも全機能へのアクセスが重要な場合は、ブラウザを通じていつでも利用できます。ブラウザページをホーム画面/ダッシュボード/ドックに追加して、画面スペースが限られている場合の Catenda へのアクセス体験を向上させることができます。

## 1. **Catenda Site -** アクセスしやすくオフライン対応

画面サイズが限られたデバイスでは、指で何をタップしているかが見えるように、ボタンはより大きくする必要があります。このような状況では、当社のモバイルアプリ [Catenda Site](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site) があなたにとって最適なツールです。

- 機能は制限され、シンプルに保たれているため、必要なボタンを簡単にタップできます。
- インターネット接続がなくても、コンテンツをダウンロードして送信できます

## 2. **ホーム画面 / ダッシュボード / ドック -** 全機能

Catenda Hub の全機能は常にブラウザを通じて利用できます。Catenda はブラウザ経由でインストールすることで、[ホーム画面に追加](https://support.catenda.com/en/articles/10741601-add-to-home-screen)、ダッシュボード、またはドックに追加される方法をサポートしています。ショートカットを作成する代わりにブラウザ経由で Catenda をインストールすると、以下の利点が得られます：

- Catenda はより使いやすくなります。これはモバイルデバイスでコンテンツにアクセスするための最も一般的な方法です。
- ブラウザバーが非表示になるため、画面スペースが節約されます。
- 特にタブレットでは、画面スペースを有効活用しながら Catenda の全機能を使用したいでしょう。
