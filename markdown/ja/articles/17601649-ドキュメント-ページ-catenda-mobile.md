# ドキュメント ページ - Catenda Mobile

> Catenda Mobile でプロジェクトのドキュメントを参照して開きます。

ドキュメント ページは、[プロジェクト ページ](https://support.catenda.com/ja/articles/17601629-プロジェクトページ-catenda-mobile)でプロジェクトを開いた後、画面下部のバーの **ドキュメント** をタップして開きます。

ドキュメント ページにはプロジェクトのドキュメントがフォルダに表示されます。

![ラベル フィルターとスコープ フィルターおよびフォルダ リストが表示されたドキュメント ページ](https://raw.githubusercontent.com/catenda/help-center/main/images/0mhxhsb0/01-intro.jpg)

## 1. **ドキュメントを検索**

右上の検索ボタンはドキュメントを検索します。

## 2. **ドキュメントをフィルタ**

タイトルの下のフィルターは、どのドキュメントがリストされるかを選択します。

### 2.1 **ラベル**

**ラベル**は、選択されたラベルを持つドキュメントのみを表示します。

### 2.2 **スコープ**

**スコープ**は、プロジェクトの公開ドキュメントと共有ドキュメント間で切り替わります。

## 3. **ドキュメントをアップロード**

ドキュメントと写真は、右下の**+**を使用してプロジェクトにアップロードされます。

## 4. **ドキュメントリスト**

リストには、プロジェクトのフォルダーとドキュメントが表示されます。各ドキュメントには、その名前とファイルタイプが表示されます。

![ドキュメントのリスト、各ドキュメントのファイルタイプ、およびそれぞれの横にあるメニューボタン](https://raw.githubusercontent.com/catenda/help-center/main/images/0mhxhsb0/02-the-document-list.png)

フォルダーをタップするとそれが開き、そのフォルダー内のドキュメントがリストされ、ドキュメントをタップするとそれが開きます。ドキュメントの横の**…**は、別のアプリで開くための**外部で開く**、**共有**、およびそれを場所に結び付けるための**場所を追加**を提供します。

## 5. **ドキュメントを開く**

開かれたドキュメントは、その名前を上部に表示し、共有ボタンと**…**の横に表示されます。図面はズームおよびパンして、必要な位置に移動できます。

![上部に共有ボタンとメニューボタンが付いた開かれたPDF図面](https://raw.githubusercontent.com/catenda/help-center/main/images/0mhxhsb0/03-open-a-document.png)
