# topic board内のテーブルビュー

topics tableの右上にあるテーブルビュー(**4**)をクリックします。デフォルトでは、リストビューがテーブルに表示されます。topics tableビュー設定はグローバル設定です。好みのビューが選択されると、任意のプロジェクト内の任意のtopic board内のtopics tableがそのビューで表示されます。

## 1. **Topics table**

テーブルビューが設定されている場合、topics tableは次のようなものになります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/01-topics-table.png)

[ここをクリック](https://support.catenda.com/en/articles/11748020-tables-on-catenda)してCatendaのテーブルの操作方法を詳しく確認してください。topicが作成されてtableが読み込まれるとすぐに、そのtopicはtopics tableの行として表示されます。デフォルトでオープンフィルターが有効になっており、クローズドtopicはフィルターされるまで非表示になる場合があることに注意してください。

### 1.1 **表示中に行われた変更**

表示されているtopicのいずれかに変更が加えられると、変更が加えられたことを示す通知がtableの下部に表示される場合があります。この通知の「fetch changes」をクリックして、表示中のtopicに対して加えられた変更を読み込みます。変更を取得すると、新しいtopicの行がtableにスライドして入り、削除されたtopicの行がtableからスライドして出るアニメーションが再生されます。

### 1.2 **選択されたアイテムアクション**

topicの行を選択すると、topics tableの上部に選択されたアイテムアクションメニューが表示されます。以下は、選択されたアイテムアクションメニューの一例です:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/02-selected-item-actions.png)

[ここをクリック](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board)して、選択されたアイテムアクションメニューについて詳しく確認してください。

### 1.3 **行の内容**

tableが最初に読み込まれるとき、最大100行が表示されます。tableに100行以上ある場合は、下にスクロールして次の100行を読み込みます。

**Topic行** topicの行の内容を開くと、tableがtopicsページにそのtopicの内容を表示するように変更されます。

### 1.4 **列**

topics tableの一部の列はデフォルトで有効になっていますが、他の列は非表示にすることができ、有効にする必要があります。設定された列の順序に基づいて、最初の列が表示され、tableの他の有効な列を表示するために横方向にスクロールが必要な場合があります。documentsページの列のデフォルトの順序と表示設定は次のとおりです:

## 2. **Topic選択**

### 2.1 **1. 選択ボックスでtopicsを選択**

チェックボックスをクリックしてリストからtopicを選択します。リンクがない行のtopic内の任意の場所をクリックして選択することもできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/03-1-selecting-topics-with-selection-box.png)

**行選択** topicを選択した後、`shift + click`で間にあるすべてのtopicsを選択できます。

**選択の編集** `ctrl + click`でtopicを選択に追加/削除することもできます

### 2.2 **2. すべてを選択**

topic board(s)内のすべてのtopicsを選択します。topic boardを開くと100個のtopicsが読み込まれます。100個のtopics以下にスクロールするとさらに多くのtopicsが読み込まれます。このボックスを初めてチェックすると、読み込んだすべてのtopicsが選択されます。boardに多くのtopicsがあり、すべてを読み込むためにスクロールしたくない場合は、フィルターの「すべてを選択」をクリックすると、選択ボックスをチェックしたときに「topicsが選択されました」の直後に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/04-2-select-all.png)

## 3. **6. 列ドロップダウン**

topics tableの右上に「Columns」ドロップダウンがあります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/05-6-columns-dropdown.png)

このドロップダウンでは、tableの列の並べ替えと切り替えができます。列の並べ替えと切り替えの設定は、topic boardとプロジェクト全体で記憶され、アカウントに保存されます。これは、ブラウザーを閉じて再度開いても、その順序が保持されることを意味します。列をtableの外にドラッグして誤って非表示にした場合は、ここで再度オンにできます。デフォルトではすべての列がオンで、この順序です:

## 4. **3. ヘッダー行**

### 4.1 **ソート**

列のヘッダーをクリックすると、その列でソートできます。もう一度クリックすると、別の方法でソートされます。デフォルトでは、「Created」列がソートされます。ソート設定を変更した場合、次回topic boardを開くまで記憶されます。

### 4.2 **列ヘッダーのドラッグ**

列ヘッダーは左右にドラッグして並べ替えられます。列ヘッダーをtableの外にドラッグして列を無効にできます。右上の[列ドロップダウン](#h_9e88dec7ef)で列を再度有効にできます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/06-dragging-column-headers.png)

### 4.3 **列幅**

2つの列の間の線の上にマウスを移動すると、ドラッグして列の幅を変更できます。列の幅の設定は、topic boardとプロジェクト全体で記憶され、アカウントに保存されます。2つの列の間の領域をダブルクリックして、列内のテキストに自動フィットさせることができます。

_カーソルの変更_ 適切な場所の上に移動するとカーソルがリサイズポインターに変わります

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/07-column-width.png)
