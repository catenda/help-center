# サインインページ

[hub.catenda.com/signin](http://hub.catenda.com/signin)にアクセスすると、このページが表示されます:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/z7whdt00/01-intro.png)

この記事では、以下のトピックについて説明しています:

## 1. **メールアドレス**

既存のアカウントに接続されているメールアドレスを入力してください。メールアドレスのアカウントがまだ存在しない場合は、代わりに新しいアカウントにサインアップしてください。[ここ](https://hub.catenda.com/signup)をクリックして新しいアカウントにサインアップしてください。

### 1.1 **シングルサインオンアカウント**

Catendaプロジェクトを所有する企業は、組織内のCatendaユーザーのSSO(シングルサインオン)を構成できます。シングルサインオン(SSO)は2つの方法で構成できます:

- ホワイトリスト - ドメインからの特定ユーザー
- ブラックリスト - 指定されたリスト上のユーザーを除く、ドメインからのすべてのユーザー

挿入されたメールアドレスがSSO対応アカウントとして認識される場合、パスワードフィールドは表示されなくなり、以下が代わりに表示されます: このアカウントはSSOを使用しています。続行をクリックしてサインインしてください。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/z7whdt00/02-single-sign-on-accounts.png)

続行をクリックすると、組織のサインインページにリダイレクトされます。SSOユーザーは、MFAが必須である組織内のプロジェクトでMFA要件はありません。

> **注:** ユーザーが期待どおりにリダイレクトされない場合はCatendaサポートが手伝うことができますが、組織のサインインページに関する質問は組織のIT部門に問い合わせる方が良いでしょう。

間違ったメールアドレスが入力された場合は、アドレスを変更するだけでパスワードフィールドが再び利用可能になります。

## 2. **パスワード**

ここに、提供されたメールアドレスで登録されているアカウントに一致するパスワードを入力できます。パスワードのトラブルシューティングについては、[ここ](https://support.catenda.com/en/articles/10798891-sign-in-and-passwords)をクリックしてください。

## 3. **サインイン**

サインインをクリックして、入力された認証情報を確認します。確認プロセスを正常に完了すると、ユーザーは[プロジェクトページ](https://support.catenda.com/en/articles/4670260-projects-page)にリダイレクトされます。

## 4. **MFA**

アカウントに対してMFAコードが構成されている場合、ユーザーはまず、アカウントにコードを登録したデバイスの認証アプリケーションからMFAコードを入力するよう求められます。コードに問題がある場合、またはコードがあったデバイスが紛失した場合は、Catendaとの主な連絡先を持っているプロジェクト所有者(通常はプロジェクトの管理者)に、このページのサポートバブル、Catenda、または[support@catenda.com](mailto:support@catenda.com)経由でアカウントの認証コードのリセットをリクエストするよう依頼してください。

## 5. **パスワードを忘れました**

メールアドレスを[ここ](https://hub.catenda.com/forgot-password)に入力してパスワードをリセットしてください。2分以内にメールを受け取らない場合は、このページのサポートバブル、Catenda、または[support@catenda.com](mailto:support@catenda.com)でサポートに連絡してください。

## 6. **新規ユーザーの招待**

[サインアップ](https://hub.catenda.com/signup)をクリックすると、サインインページの上部から、ユーザーはプロジェクトへの招待がなくても無料アカウントを作成できます。アカウント登録の手順を完了した後、これらのユーザーは自分のアカウントが空であり、プロジェクトがないことを確認できます。

**招待を受け入れて新しいアカウントを作成**まだアカウントを持っていない新規ユーザーは、プロジェクト管理者または組織所有者によってメール経由でCatendaプロジェクトに招待されることができます。まだアカウントを持っていないユーザーが招待メールを受け取ってリンクをクリックすると、アカウント登録ページが開き、アカウント登録の手順に従うよう求められます。手順を完了すると、プロジェクト招待がまだ有効である場合は受け入れることができ、ユーザーは自動的にプロジェクトの一部になることができます。

**既存のアカウントで招待を受け入れる**以前にアカウントを作成したユーザーがメール招待リンクをクリックしてまだサインインしていない場合、プロジェクト招待を受け入れるかどうかを尋ねられる前に、認証情報でサインインするよう求められます。

招待が送信される前にアカウントが作成された場合、ユーザーは登録済みの認証情報でサインインし、プロジェクト招待通知をクリックして招待を受け入れ、プロジェクトの一部になることができます。

**招待なしでプロジェクトに新規ユーザーを追加** Catendaプロジェクトを所有する組織に属するユーザーは、組織所有者によってアカウントが組織のプロジェクトの1つに追加されていることに気付く場合があります。
