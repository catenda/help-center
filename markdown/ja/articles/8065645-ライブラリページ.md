# ライブラリページ

ライブラリページはプロジェクト内の左ナビゲーションメニューの5ページ目にあります。このページはコンテンツパネルの一部です。ここでは、アイテムのセットを含むライブラリを見つけることができます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/01-intro.png)

## 1. **新規アイテムアクション**

新規アイテムボタンをクリックすると、新しいライブラリを追加できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/02-new-item-actions.png)

### 1.1 **ドキュメントライブラリ**

[ドキュメント](https://support.catenda.com/en/articles/8204673-documents-page) - ドキュメントセクションのドキュメントライブラリ [リンクライブラリ](https://support.catenda.com/en/articles/4670254-links-library) - オブジェクトと問題にリンクを接続 _Dropbox_ - Dropboxのファイルをプロジェクト内のオブジェクトにリンク

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/03-document-libraries.png)

ライブラリに名前を付けた後、Catendaはあなたを Dropbox にリダイレクトして、Dropbox アカウントへのアクセス権限を得ます。その後、Dropbox を閲覧してプロジェクトと共有するフォルダを選択できます。ご希望に応じて、同じ Dropbox アカウントを使用していても、複数の Dropbox ライブラリを作成できます。

> **注**: 認証に OAuth 2.0 を使用しているため、Catenda はあなたの Dropbox パスワードにはアクセスできません。

_[SharePoint](https://support.catenda.com/en/articles/5744548-sharepoint-library)_ - SharePoint ライブラリをプロジェクトに追加します。これにより、メンバーはファイルを表示し、他のメンバーに接続できます。

> **注：** これは、メンバーがSharePointからCatendaにドキュメントを投稿できる[SharePointアプリケーション](https://support.catenda.com/en/articles/8396496-catenda-sharepoint-application)とは異なります

_coBuilder Pro_ - ドキュメント - coBuilder Pro からのドキュメントでオブジェクトにタグを付けます。このライブラリはレガシープロジェクトでのみ利用可能です。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/04-document-libraries.png)

coBuilderPROユーザー名とパスワードを入力して接続してください。

### 1.2 **汎用ライブラリ**

_[分類](https://support.catenda.com/en/articles/4670255-classification-library)_ - CSV ファイルからカスタム分類でオブジェクトにタグを付ける _coBuilder Pro_ - coBuilder Pro から製品情報でオブジェクトにタグを付ける _検索_ - 外部ウェブサイトをライブラリとして含める _[プロパティ値](https://support.catenda.com/en/articles/4670252-property-value-library)_ - プロパティ値に基づいてエントリを作成

### 1.3 **推奨ライブラリ**

プロジェクト内のモデルに分類が含まれている場合、その分類用の組み込みライブラリがここで提案されます。推奨ライブラリをクリックして有効化します。提案されたライブラリは、その分類のコードをオンラインで検索し、ファイルで指定されたコードと照合しようとします。これらの公開分類ライブラリは編集不可であり、そのコードが分類に従って正しい場合にのみ、分類コードでタグ付けされたオブジェクトを検索します。

## 2. **ライブラリリスト**

ここでは、構成したすべてのライブラリのリストが表示されます。ライブラリはドキュメントライブラリまたは汎用ライブラリとして表示されます

### 2.1 **スター付け**

ライブラリの1つにスターを追加して、右の情報メニューのライブラリページのサブページとして表示させます。

### 2.2 **ドキュメントライブラリ**

ここでは、常にドキュメントとリンクライブラリが上部に表示されます。ドキュメントライブラリをクリックするとドキュメントページに移動します。リンクライブラリをクリックするとリンクライブラリに移動します。構成されている Dropbox や SharePoint ライブラリもここに表示されます。

### 2.3 **汎用ライブラリ**

ここでは buildingSMART Data Dictionary ライブラリが上部に表示されます。その下には、分類、組み込み分類、coBuilder Pro、検索、およびプロパティ値ライブラリが追加された順序で表示されます。
