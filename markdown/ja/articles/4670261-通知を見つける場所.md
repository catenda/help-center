# 通知を見つける場所

通知ボタンはメインメニュー、またはスクリーンの右上にあるプロフィール画像をクリックして表示されます。

スクリーン右上隅の通知は、[あなたが属しているすべてのプロジェクトの通知](https://bimsync.com/notifications)を表示します。左側のナビゲーションメニューの通知は

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bwfkbb29/01-intro.png)

現在いるプロジェクトの通知を表示します。

設定 -> メンバーでそのメンバー/チームに移動することで、プロジェクトのすべてのメンバー/チームのプロジェクト通知を見つけることも可能です。

## 1. 通知の使用方法

通知システムは、建物やサイトで発生していることを追跡するのに役立ちます。新しいことがあったかどうかを知らせます。たとえば、建物の新しいリビジョンがアップロードされた場合や、誰かがあなたに問題を割り当てた場合などです。

**通知設定:**通知の設定は、通知へのサブページとして見つけることができます。ここでは、受け取りたい通知のフィルターリストが表示されます。<a class="intercom-content-link" href="" target="_blank">こちらを参照</a>
