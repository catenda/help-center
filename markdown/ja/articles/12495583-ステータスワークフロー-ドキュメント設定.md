# ステータスワークフロー - ドキュメント設定

[ドキュメント設定ページ](https://support.catenda.com/en/articles/7831371-document-settings-page)のステータスワークフローメニューは、2025年10月2日以降に共有リビジョンを有効にしたプロジェクトの場合、このように表示されます。新しいプロジェクトでは、ステータスワークフローはデフォルトで無効になっています。ステータスワークフローメニューは以下のように表示されます:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g7ntz7r8/01-intro.png)

[テンプレートプロジェクト](https://support.catenda.com/en/articles/4670245-creating-a-new-project#h_5db32e5398)に基づいて作成されたプロジェクト、および2025年10月2日前に共有リビジョンを有効にしたプロジェクトには、従来のステータスワークフローメニューが表示されます。

## 1. **共有ステータス**

ISO 19650に準拠するために共有ステータスを有効にし、ワークフローを構成します。共有ステータスを有効にした後、ステータスワークフローメニューは以下のように表示されます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g7ntz7r8/02-shared-statuses.png)

### 1.1 共有ステータスを有効にする

デフォルトでは、"shared"という名前の共有ステータスが1つ設定されています。追加される一般的な公開ステータスは以下の通りです:

- WIP - 青
- 作業中 - 青
- 内部検証 - 青

**プロジェクトの変更**

- 情報はマイナーリビジョン番号で開始します:0.1、0.2、1.1など...
- 情報を公開して、メジャーリビジョン番号を受け取ることができます:1.0、2.0、3.0など...
- ドキュメントページのアクセス制御メニューには、共有リビジョンへのアクセスと公開権を設定できる追加の列があります。
- 共有および公開ステータス - 共有ステージで送信された新しい情報。
- デフォルトステータスは「共有」に設定されています。
- ドキュメント設定に承認メニューが表示されます。
- ドキュメントページに承認サブページが表示されます。

### 1.2 **共有ステータスを無効にする**

**プロジェクトの変更**

- 公開ステータス - 公開ステージで送信された新しい情報。
- デフォルトステータスは「ステータスなし」に設定されています。
- ドキュメント設定の承認メニューは無効になっています。
- ドキュメントページの承認サブページは無効になっています。

## 2. **公開ステータス**

デフォルトでは、"published"という名前の公開ステータスが1つ設定されています。「ステータスを追加」をクリックして、さらにステータスを追加します。追加される一般的な共有ステータスは以下の通りです:

- 公開済み、コメント付き - 薄い緑色
- 待機中 - 黄色
- 却下 - 赤

## 3. **ステータスを追加**

「ステータスを追加」をクリックしてステータスを追加できます。新しいステータスは色と名前を持つことができます。ステータスは、共有ステータスのリストまたは公開ステータスのリストのいずれかに追加できます。

## 4. **ステータスを変更**

ステータスの右側の鉛筆ボタンをクリックして、ステータスを編集できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g7ntz7r8/03-changing-statuses.png)

ステータスの色と名前を変更できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g7ntz7r8/04-changing-statuses.png)

### 4.1 **ソート順序**

編集後、矢印をクリックして、ステータスをそのステージ内のステータスリストで上下に移動します。

### 4.2 **ステータスをアーカイブ**

ステータスの右側のゴミ箱ボタンをクリックしてステータスをアーカイブできます。同じステージ内でのみステータスのアーカイブと復旧が可能です。アーカイブされたステータスが情報に適用された場合、ステータスは表示されますが、取り消し線が引かれます。

### 4.3 **ステータスを復元**

アーカイブされたステータスは、「アーカイブされたステータスを表示」をクリックすることでいつでも復元できます。ここでは、アーカイブされたすべてのステータスが表示され、復元できます。

## 5. デフォルトステータス

共有リビジョンに対して公開アクションが使用されたときにデフォルトで表示されるステータス。公開前に別のステータスを選択できます。共有リビジョンは、[承認リクエスト](https://support.catenda.com/en/articles/12494960-open-or-closed-approval-request-page)経由で公開することもできます。提出者が提出者チームに代わって選択したワークフローに応じて、メンバーが最終検証チームに代わって最終検証を行う場合、公開されたリビジョンのドキュメントのステータスは、ワークフロー設定に基づいて変更されます。

## 6. アップロードメニュー

### 6.1 **共有ステータスが有効**

公開および共有ワークフローがプロジェクトで有効にされるように要求されたときのアップロードメニューは、以下のように表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g7ntz7r8/05-shared-statuses-enabled.png)

デフォルトでは、デフォルトの共有ステータスは「共有」です。アップロード前に、共有ステータスのリストからステータスを選択できます。

### 6.2 **共有ステータスが無効**

共有ステータスが無効になっている場合、アップロードメニューは以下のように表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g7ntz7r8/06-shared-statuses-disabled.png)

デフォルトでは、デフォルトの公開ステータスはステータスなしです。アップロード前に、公開ステータスのリストからステータスを選択できます。
