# フォームページ - Catenda Mobile

> Catenda Mobileでサイト上のフォームに入力します。一度に1つの質問ずつ入力します。

フォームページは、[プロジェクトページ](https://support.catenda.com/ja/articles/17601629-プロジェクトページ-catenda-mobile)でプロジェクトを開いた後、画面下部のバーから開きます。

フォームページにはプロジェクトのフォームが一覧表示されます。フォームテンプレートはブラウザでのみ作成できますが、フォームはブラウザとアプリの両方で入力できます。

> **注意:** フォームはプロジェクト内でオンになっているプロジェクトでのみ使用でき、現在のところCo-creationプログラムの顧客のプロジェクトのみです。他のプロジェクトではフォームページは空です。

![ステータスフィルターとフォームリストを備えたフォームページ](https://raw.githubusercontent.com/catenda/help-center/main/images/b679p300/01-intro.jpg)

## 1. **フォームを検索**

右上の検索ボタンでフォームを検索します。

## 2. **フォームをフィルター**

**ステータス**は選択されたステータスのフォームのみを表示します。

## 3. **フォームを開始**

フォームは右下の**+**で開始します。すべてのフォームはプロジェクトのフォームテンプレートのいずれかから開始され、その質問が設定されます。新しいフォームには名前が付けられ、場所とピン、担当者、期日を指定することもできます。場所はフォーム作成後に後で追加することもできます。その後、フォームは一度に1つの質問を表示し、現場でタップしやすい大きなボタンを備えています。

## 4. **フォームリスト**

リストにはフォームごとに1枚のカードが表示され、**提出済み**または**完了**などのステータス、番号、名前が表示されます。

## 5. **フォーム概要**

概要はすべての質問を表示し、答えられたものをマークし、タップされたときに質問にジャンプします。写真またはドキュメントが必要な質問は赤でマークされます。フォームは複数のトピックと複数のドキュメントにリンクできます。**ドキュメント**タブと**トピック**タブはフォームにリンクされたすべてのドキュメントとトピックを収集するため、フォローアップは質問をスクロールして確認する必要がありません。

![進捗、答えられた質問、写真またはドキュメントが必要な質問を示すフォーム概要](https://raw.githubusercontent.com/catenda/help-center/main/images/b679p300/02-the-form-overview.png)

### 5.1 **項目**

フォームの各質問は項目であり、フォームテンプレートで設定された項目タイプによって回答方法が決まります。現在の項目タイプは次のとおりです:

- 1行テキスト
- 複数行テキスト
- 数値
- 単一選択
- 複数選択
- はい/いいえ
- 署名

トピック、写真、メモ、またはドキュメントは、下のボタンを使用して任意の項目に添付できます。**前へ**と**次へ**は項目間を移動し、上部の**概要**はフォーム概要に戻ります。

![トピック、写真、メモ、ドキュメントボタン、前へ、次へを含むはい/いいえ項目](https://raw.githubusercontent.com/catenda/help-center/main/images/b679p300/03-fields.png)
