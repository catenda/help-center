# メニューページ - Catenda Mobile

> Catenda Mobileでアプリ設定を変更したり、プロジェクトを切り替えたり、ログアウトしたりできます。

メニューページは、[プロジェクトページ](https://support.catenda.com/ja/articles/17601629-プロジェクトページ-catenda-mobile)でプロジェクトを開いた後、画面下部のバーの最後のアイテムである**メニュー**をタップして開きます。

メニューページはアプリの設定を保持し、別のプロジェクトまたはCatendaの外に移動できます。

![設定、プロジェクトを切り替え、ログアウト表示のメニューページ](https://raw.githubusercontent.com/catenda/help-center/main/images/8rbcp4pd/01-intro.jpg)

## 1. **設定**

**設定**はアプリとそのアップデートの環境設定を保持します。

## 2. **プロジェクトを切り替え**

**プロジェクトを切り替え**はプロジェクトページに戻り、別のプロジェクトが開かれます。

## 3. **ログアウト**

**ログアウト**によってユーザーはCatendaからサインアウトし、アプリがスマートフォンに保存したデータが削除されます。
