# 3D ビューア - Catenda Site

[2D/3D ページ](https://support.catenda.com/en/articles/7734138-2d-3d-catenda-site)を開いて、Catenda Site の画面上部の 3D ビューアを確認してください。これが Catenda Site の 3D ビューアの外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/01-intro.png)

Catenda プロジェクトのモデルセクションからの 3D モデルは、Catenda Site の 3D ビューアで有効/無効にできます。

この記事では、以下のトピックについて説明します：

## 1. **モデルセレクター**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/02-model-selector.png)

モデルセレクターボタンをタップして、モデルセレクターメニューを開きます。各モデルの横のボックスをチェックして、そのモデルを 3D ビューアで有効にします。モデルを有効/無効にした後、"**完了**" をタップします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/03-model-selector.png)

## 2. **ツールバー**

ツールバーは 3D ビューアの右上に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/04-toolbar.png)

### 2.1 **ズーム全体表示**

3D ビューアのカメラ位置を調整して、すべてのオブジェクトが表示されるようにします。

### 2.2 リセットオプション

リセットオプションメニューの外観は次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/05-reset-options.png)

リセットオプションメニューで、以下を選択できます：

- _すべてのオブジェクトを表示_ - 非表示にしたオブジェクトを再表示します
- _計測をクリア_ - すべての計測を削除します
- _切断面を削除_ - すべての切断面を削除します

3D リセットオプションの設定が完了したら、"**完了**" をタップします

## 3. **3D ビューア設定**

3D ビューア設定メニューの外観は次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/06-3d-viewer-settings.png)

### 3.1 **ナビゲーションモード**

**ピンチ** 2本の指を近づけたり離したりしてピンチします。3D ビューアをピンチするとカメラが前後に移動します。

**パン** 1本の指で 3D ビューアをドラッグしてパンします。ナビゲーションモードは、3D ビューアがパンされるときに何が起こるかに影響します。

_モバイル_ - デフォルト カメラの角度を調整します

**タブレット** 3D ビューアで指を押したままにするとドラッグアンカーが表示されます。オブジェクトを押したままにするとドラッグアンカーがそのオブジェクトに表示されます。空白スペースを押したままにするとドラッグアンカーがカメラからドラッグ位置への方向の固定距離に表示されます。3D ビューアをドラッグすると、ドラッグアンカーはドラッグの方向を示し、カメラの角度と位置がドラッグアンカーの周りを回転し始めます。画面から手を離してカメラを新しい位置と角度にロックします。

### 3.2 **ジョイスティック表示**

ジョイスティックを有効または無効にします。ジョイスティックをドラッグしてカメラを上下左右に移動できます

## 4. **3D ビューア操作**

オブジェクトをタップするとそのオブジェクトが選択され、コンテキストメニューが開きます。コンテキストメニューは次のようになります：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/07-3d-viewer-interaction.png)

### 4.1 **タイトル**

コンテキストメニューのタイトルは、選択されたオブジェクトの名前で構成されます。

### 4.2 **非表示**

非表示ボタンをタップしてオブジェクトを非表示にします。オブジェクトは右上のツールボックスのリセットボタンで再び表示できます。

### 4.3 **レーザー計測**

レーザー計測をタップして、X、Y、Z 方向の最も近いサーフェスエッジまたは交差するオブジェクトまでの距離を測定します。計測は右上のツールボックスのリセットボタンでクリアできます。

### 4.4 **ポイント測定**

ポイント測定ボタンをタップして、オブジェクト上のタップされた位置の X、Y、Z 座標を確認します。計測は右上のツールボックスのリセットボタンでクリアできます。

### 4.5 **切断面**

切断面ボタンをタップして、タップされたサーフェスに沿って切断面を作成します。これが 3D ビューアが切断面を作成した後の外観です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/08-clipping-plane.png)

切断面を作成した後、スライダーが画面の下部に表示されます。このスライダーを調整して、切断面を通常の方向にスクロールして微調整します。切断面は右上のツールボックスのリセットボタンでクリアできます。

### 4.6 **情報**

情報ボタンをタップして、タップされたオブジェクトの情報ページを開きます。

**オブジェクト情報**オブジェクト情報では、以下を確認できます：

- 名前
- エンティティ
- GUID
- タグ
- タイプ
- 定義済みタイプ

**プロパティ**デフォルト IFC プロパティおよびオブジェクトの異なるプロパティセットが表示されます。ここでは通常、計測、数量、材質などの情報が表示されます。

**ドキュメント**選択されたオブジェクトにリンクされたドキュメントのタイトルと作成日が表示されます。ドキュメントをタップして、ドキュメントページでドキュメントを開きます。

**トピック**選択されたオブジェクトにリンクされたトピックのタイトルとトピック番号が表示されます。トピックをタップして、トピックページでトピックを開きます。
