# 別のメンバーの引き継ぎ

新しいメールアドレスを取得した場合、またはプロジェクト内の別のメンバーの引き継ぎを行う場合、そのユーザーと同じすべての通知を受け取るようにするために実施する必要があるいくつかの手順を以下に示します。

## 1. **トピックのフォロー**

新しいユーザーが古いユーザーのトピックをフォローしていることが重要です。

### 1.1 **フォローとはどういう意味ですか?**

トピックをフォローすると、トピックの作成だけでなく、コメントやステータスの変更などのすべてのアクションに関する通知が届きます。

### 1.2 **担当者/リクエスター の変更**

ユーザーに割り当てられたトピックでフィルターし、すべてを選択して、[右側の情報メニュー](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic)の複数選択オプションを使用して割り当てられたユーザーを新しいユーザーに変更します。その後、新しいユーザーは自動的にそれらのトピックをフォローします。リクエストについても同じことが言えます。

### 1.3 **トピックごとにフォローする**

また、トピックを一度に選択して[フォローアクション](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board#h_1b91729715)を使用することで、トピックを手動でフォローすることもできます。ユーザーがコメントしたり、コメントまたは説明に記載されたりした場合、そのユーザーもトピックをフォローしています。ユーザーがコメントした、または記載されたすべてのトピックを見つけることは少し複雑な場合があります。ユーザーのGUIDをフィルターする方法については、[こちら](https://support.catenda.com/en/articles/8370693-filtering-in-a-topic-board#h_7fc30a16f0)をご覧ください。トピックリストでユーザーのGUIDを検索した後、フォローアクションで各トピックをフォローできます。

古いユーザーがフォローしていたすべてのトピックをフォローすれば、そのユーザーと同じ通知が届くようになります。

## 2. **アクセス権設定**

引き継ぎ元のユーザーと同じアクセス権を持っていることを確認するには、そのユーザーと同じチームに属していることが重要です。アクセス権はしばしばチームを通じて配布されます。
