# アプリケーションソフトウェアの推奨事項

Catenda Hubの体験を低下させる可能性のあるブラウザー拡張機能または他のプログラムがないか確認してください。

## 1. **ブラウザー設定**

**Windows上のメモリ使用量別の最高のブラウザー（2026年3月）:**

1. Firefox
1. Chrome
1. Microsoft Edge

### 1.1 **ズームスケール**

Catendaは100%のズームスケールで使用することをお勧めします。Catendaは75%～150%のズームスケールで正常に動作します。

**大きなズームスケール**大きなズームスケールにより、一部のメニューが必要なメニューをカバーするほど大きくなる可能性があります。幅と高さで定義されたグラフィックスはブラウザースケールでスケーリングされる可能性がありますが、ピクセルで定義されたグラフィックスは、ズームスケールが増加するとより粗くなる可能性があります。ズームスケール125%または150%は、会議でスクリーンを共有する場合に推奨されます。これにより、スクリーンを追跡している人がより簡単に進行を追跡できるようになる可能性があります。

**小さなズームスケール**小さなズームスケールにより、グラフィックスが非常に小さくなり、見えなくなる可能性があります。スケールダウンされたリソースを正確に表示すると、デバイスに対してより多くの負荷がかかります。ズームスケール80%または75%は、デバイスが対応できる場合、3Dビューアと相互作用するときに推奨されます。

### 1.2 **ハードウェアアクセラレーション**

ハードウェアアクセラレーションを使用していることを確認してください。異なるブラウザーのハードウェアアクセラレーションオプションは、ここで確認できます：

**Chrome:** <a class="intercom-content-link" href="" target="_blank">chrome://settings/?search=hardware+acceleration</a>

_Firefox:_ [https://support.mozilla.org/en-US/kb/performance-settings?as=u&utm\_source=inproduct](https://support.mozilla.org/en-US/kb/performance-settings?as=u&utm_source=inproduct)

_Microsoft Edge:_ <a class="intercom-content-link" href="" target="_blank">edge://settings/?search=hardware%20acceleration</a>

**Safari:** [https://support.apple.com/en-us/102894](https://support.apple.com/en-us/102894)

_Opera:_ [https://blogs.opera.com/news/2015/07/advanced-settings-in-opera/](https://blogs.opera.com/news/2015/07/advanced-settings-in-opera/)

_Vivaldi:_ [https://forum.vivaldi.net/topic/1207/hardware-acceleration](https://forum.vivaldi.net/topic/1207/hardware-acceleration)

### 1.3 **Cookie**

Cookieに保存されたデータにより、ブラウザーはログインしているかどうかとCatendaプロジェクトでの一部のユーザー設定を知ることができます。プロジェクト固有の設定もあれば、すべてのプロジェクトで同じ設定もあります。たとえばメニューを閉じることでユーザー設定を変更する場合、このユーザー設定はブラウザーウィンドウとタブ全体で記憶されます。たとえば、1つのタブのフィルターメニューを閉じ、別のタブで同じページを更新した場合、そのタブでもフィルターメニューが閉じられます。同様に、ブラウザーはログインしているかどうかを記憶しています。1つのタブでログアウトして別のアカウントにログインし、別のタブのページを更新する場合、別のアカウントでログインしたことになります。このアカウントは、自分がいるプロジェクトにアクセスできない場合があります。

**Cookieを検索** Chromeでは、以下のようにCookieを管理できます：Cookieとサイトデータをクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/01-cookies.png)

デバイス上のサイトデータを管理をクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/02-cookies.png)

_Cookieを許可_ Catenda Hubを使用するには、セッション中にhub.catenda.comのデータストレージを少なくとも許可する必要があります。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/03-cookies.png)

すべてのウィンドウを閉じるときにデータを削除することを選択した場合、Catendaを使用するたびにデータがリセットされます。すべてのウィンドウが閉じられるたびにデータを削除すると、ブラウザーのすべてのウィンドウを閉じた後、ユーザー設定がリセットされます。

_Cookieを削除_ Cookieデータは、ごみ箱アイコンをクリックして手動で削除できます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/04-cookies.png)

ページをリロードするよう求められます。リロード後、ログイン情報を削除したため、Catendaに再度ログインする必要があります。
