# Catenda AI Connectについて

> Catenda AI Connectは、組織が既に使用しているClaude、Microsoft Copilot、ChatGPTなどのAIを、Catenda Hubプロジェクトに接続します。それが何であるか、どのように機能するか、そして始める方法を説明します。

> **重要:** Catenda AI Connectは早期アクセス段階です。機能とセットアップ手順は頻繁に変更されます。この記事は現在のバージョンについて説明しています。

建設プロジェクトの利益は、契約内容、設計内容、実際の施工内容、そして途中でのやり取りと書かれた内容のどこかに存在します。これらを一致させることは、レビュー会議、納品物の確認、コメントと古いメールスレッドの検索を意味します。

この製品は、組織が既に使用し信頼しているAIをCatenda Hubのモデルдокументとトピックに直接接続します。プロジェクトに関する質問は自然言語で行われ、ライブプロジェクトデータから回答され、レポートと証拠になる準備ができています。組織がそのAIアプリに変更を許可する場合、調査結果もCatenda Hubのトピックになります。

## 1. **それが何であるか**

Catenda Hubは、組織が既に選択したAIツールにプロジェクトデータを公開するため、チームは知っているアシスタントで作業を続けることができます。AIアプリが作成または変更するすべては、他の調整作業と同様にCatenda Hubに記録されます。

接続ではMCP(Model Context Protocol)を使用します。これはAIアプリを他のシステムに接続するためのオープン標準です。これにより、AIの選択は組織に留まり、今日も後で考え直すときも同じです。

## 2. **チームがそれを何に使用するか**

### 2.1 **質問**

質問はライブプロジェクトデータから回答され、ソースが提供されます。例えば:

```
今週プロジェクトで何が起きましたか？何が遅延していますか？どこにリスクがありますか？
```

### 2.2 **確認**

納品物、モデル、ドキュメントはプロジェクトの要件に対して確認されます。例えば:

```
このBIM実行計画に対して、この納品物の命名とメタデータを確認してください。失敗した内容にフラグを付けてください。
```

### 2.3 **委任**

構造化された定型業務は、人が承認するドラフトとして実行されます。例えば:

```
クライアントがこのスプレッドシートを送信しました。行ごとにトピックを作成し、所有者と期限を設定します。
```

## 3. **どのように機能するか**

組織のITは、AIアプリが既にサポートしているオープン標準を通じて、CatendaコネクタをそのAIアプリに一度追加します。これにより、そのAIアプリを使用する従業員に利用可能になります。各従業員は通常のAIアカウントでAIアプリにサインインし、コネクタを使用してAIアプリを自分のCatendaアカウントに接続します。

AIアプリはその後、サインインしたユーザーとして機能します。ユーザーがCatenda Hubで持つアクセスと正確に同じアクセス権で機能し、プロジェクトのアクセス権は変更されないままです。

AIアプリが提案し、人が決定します。トピック、レポート、リンクなど作成されたものは、書き込まれる前にレビューされ、他の調整作業と同じ履歴でCatenda Hubに保存されます。

## 4. **プロジェクトデータの制御**

組織は、どのAIがプロジェクトデータを処理するかを決定し、接続がサポートするAIアプリが使用できるオープン標準であるため、後でその決定を変更することができます。

Catenda Hubはプロジェクト情報の単一の情報源のままです。AIアプリはサインインしたユーザーがアクセスを許可されているデータに到達し、アクセス権は1か所で管理されたままです。

## 5. **始める**

Catenda AI Connectは早期アクセスで利用可能です。

Catenda AI Connectは、Catenda Hubでプロジェクトを所有している組織のみ向けではありません。他の組織のプロジェクトに招待されている組織もCatenda AI Connectを取得できます。そのような組織は、プロジェクトを所有する必要はありません。Catenda AI Connectは、複数の種類のプロジェクトで機能します。1つ目の種類は、組織が自ら実行するプロジェクトです。2つ目の種類は、組織が招待されるプロジェクトであり、そのプロジェクトを実行している組織がそこでCatenda AI Connectを許可する限りです。組織がプロジェクトでCatenda AI Connectを許可する場合、すべての招待されたユーザーがそこでCatenda AI Connectを使用できるわけではありません。各ユーザー自身の組織は、プロジェクトでAIを使用することに対する方針を持つ可能性があります。[Catenda AI ConnectとプロジェクトアクセスL](https://support.catenda.com/ja/articles/17778745-catenda-ai-connectとプロジェクトアクセス)では、これについてより詳しく説明しています。

Catenda AI Connectの使用を開始するには、Catenda営業に問い合わせてください: [https://catenda.com/get-started](https://catenda.com/get-started)または[sales@catenda.com](mailto:sales@catenda.com)。

> **注:** Catendaの顧客は、より多くの情報が利用可能です。[https://hub.catenda.com](https://hub.catenda.com)のCatendaにサインインし、ヘルプセンターのページを開くか再読み込みしてください。ヘルプセンターは、サインインした顧客にさらに多くの情報を表示し、[Catenda AI Connectの概要](https://support.catenda.com/ja/articles/17778901-catenda-ai-connectの概要)_(サインインした顧客のみ)_から始まります。
