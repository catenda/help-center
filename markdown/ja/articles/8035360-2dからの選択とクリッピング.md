# 2Dからの選択とクリッピング

### **2Dからのモデルのクリッピング**

まず[回転ツール](https://support.catenda.com/en/articles/4854537-2d-viewer#h_c70412a63f)を使用して、2Dプランを必要に応じて配置します。次に[セクション：クリッピング平面を作成](https://support.catenda.com/en/articles/4854537-2d-viewer#h_2265eef562)を選択し、垂直クリッピング平面を示すために矩形をドラッグします。現在の階/床の高さまたは完全な高さを選択します。クリップ領域をクリックします。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xyh08ptx/01-clipping-in-the-model-from-2d.png)

これで[クリッピング平面を移動](https://support.catenda.com/en/articles/4670253-clipping-planes#moving-the-clipping-plane)できます。クリッピングウィジェット（左下）で関連する平面を選択するか、"Shift"を押しながらビューア内の平面をクリックすることで、通常どおり移動できます。平面は、平面を選択して"Del"キーを押すことで個別に[削除](https://support.catenda.com/en/articles/4670253-clipping-planes#remove-clipping-planes)するか、3Dビューアの任意の場所を右クリックして"クリッピング平面を削除"を選択することですべて一度に削除できます

### **2Dからのオブジェクトの選択**

[セクション：オブジェクトを選択](https://support.catenda.com/en/articles/4854537-2d-viewer#h_9ba868389c)は同様の方法で機能し、選択矩形と高さで定義される"仮想ボックス"に触れているすべてのものを選択します。2Dで通常の選択に戻るには、[選択](https://support.catenda.com/en/articles/4854537-2d-viewer#h_6e9b382c42)をクリックします。
