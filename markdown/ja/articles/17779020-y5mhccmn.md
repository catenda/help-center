# Catenda Data Exportについて

> Catenda Data Exportは、Catenda Hubプロジェクトのデータを組織独自のクラウドストレージに自動的にコピーします。

Catenda Hubにはプロジェクトデータをダウンロードするいくつかの方法があり、[すべてのプロジェクトデータをエクスポート](https://support.catenda.com/ja/articles/7946690-すべてのプロジェクトデータをエクスポートする)に説明されています。Catenda Data Exportは自動化されたものです。プロジェクトデータを組織独自のクラウドストレージ、Amazon S3またはAzure Blob storageに直接コピーします。これはCatenda Hubとは別に販売されています。

## 1. **概要**

Catenda Data Exportは、組織が管理するストレージにプロジェクトのドキュメント、モデル、およびトピックのコピーを保持します。スケジュールに従って、または一度だけ実行され、誰も手動でファイルをダウンロードする必要がありません。

## 2. **プロジェクトオーナーと参加者**

Catenda Data Exportは、Catenda Hubでプロジェクトを所有する組織だけのためのものではありません。エクスポートされるものは、各プロジェクトにおける組織の役割によって異なります。

### 2.1 **プロジェクトオーナー**

プロジェクトを所有している組織は、そのプロジェクトのすべてのデータの完全なバックアップをエクスポートできます。

### 2.2 **プロジェクト参加者**

他の組織が所有するプロジェクトに参加している組織も、プロジェクト自体を所有せずにCatenda Data Exportを利用できます。これらのプロジェクトでは、参加者がアクセスできるもの、つまりプロジェクトの限定的な部分のみをエクスポートします。このようにして、参加者はプロジェクトへのアクセスが終了しても、自分の作業の独自のコピーを保持できます。

## 3. **始め方**

使用するには、最初のプロジェクトを開始するためにCatendaセールスに問い合わせてください: [https://catenda.com/get-started](https://catenda.com/get-started) または [sales@catenda.com](mailto:sales@catenda.com)。

> **注:** Catendaカスタマーはさらに利用できます。[https://hub.catenda.com](https://hub.catenda.com)でCatendaにサインインしてから、ヘルプセンターのページを開くか再度読み込んでください。ヘルプセンターは、サインイン済みのカスタマーに対してさらに表示され、[Catenda Data Exportの概要](https://support.catenda.com/ja/articles/17779027-catenda-data-export-の紹介)から始まります _(サインイン済みのカスタマーのみ)_。
