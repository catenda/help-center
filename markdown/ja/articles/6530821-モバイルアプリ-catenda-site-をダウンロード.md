# モバイルアプリ Catenda Site をダウンロード 📲

> **注意:** アプリケーションのインストールファイルは[この記事](https://intercom.help/bimsync-arena/ja/articles/8396532-catenda-プラグイン-統合)に記載されています。Google Playで「Catenda Site」がお使いのデバイスで利用できないと表示される場合は、[Catenda Site - トラブルシューティング](https://support.catenda.com/ja/articles/11926914-catenda-site-トラブルシューティング#not-available-for-your-device-in-google-play)をご覧ください。

[デモをご予約](https://catenda.com/get-started)いただけます

![](https://raw.githubusercontent.com/catenda/help-center/main/images/p552jtap/01-intro.png)

## 1. **Catenda Site について**

Catenda は、建設およびインフラプロジェクトをサポートします。Catenda Site を使用すれば、建設現場でもそのサポートが継続されます。

### 1.1 **トピック管理**

[トピックを管理する](https://support.catenda.com/ja/articles/7734073-トピックメニュー-catenda-site)：どこからでも作成、整理、トピックを通じて協働できます。

### 1.2 **2D および 3D ビュー**

[2D 図面](https://support.catenda.com/ja/articles/7748370-2dビューア-catenda-site)と[3D モデル](https://support.catenda.com/ja/articles/7744403-3d-ビューア-catenda-site)の両方をアプリケーション内で検索し、プロジェクトの包括的な概要を把握できます。

### 1.3 **オフラインアクセス**

[オフライン中も作業を続ける](https://support.catenda.com/ja/articles/7325268-catenda-siteのオフラインモード)：プロジェクトにアクセス、トピックを表示および作成でき、インターネット接続がなくても利用できます。

### 1.4 **ドキュメントライブラリアクセス**

プロジェクトドキュメントを表示：[ドキュメントライブラリにアクセスする](https://support.catenda.com/ja/articles/7774637-ドキュメントメニュー-catenda-site)と、すべての情報が手元にあります。

### 1.5 **位置情報ベースのナビゲーション**

[2D](https://support.catenda.com/ja/articles/7748370-2dビューア-catenda-site) と [3D](https://support.catenda.com/ja/articles/7744403-3d-ビューア-catenda-site) の両方のモデルと平面図を使用してトピックを正確に特定し、現場でのナビゲーションを簡素化できます。

## 2. **サインイン**

モバイルアプリケーションをダウンロードしてインストールした後、通常のメールアドレスとパスワードを入力してください：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/p552jtap/02-sign-in.png)

接続されました。🎉 サインイン後、[プロジェクトページ](https://support.catenda.com/ja/articles/7733978-プロジェクトページ-catenda-site)に移動し、プロジェクトを選択できます。
