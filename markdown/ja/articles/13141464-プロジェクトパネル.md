# プロジェクトパネル

プロジェクトレベルでは、メインパネルボタンは常にプロジェクトページに関係なく右上に表示されます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/01-intro.png)

これがパネルアイコンが右上に表示される場合の例です：

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/02-intro.png)

画面スペースが限られているデバイスでは、代わりに「ビュー」というボタンが表示されます。「ビュー」をクリックして、異なるパネル間を切り替えます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/03-intro.png)

この記事では、以下のトピックについて説明します：

## 1. **パネルを開く**

パネルはさまざまな方法で開くことができます。

### 1.1 **自動的に開く**

デフォルトでは、プロジェクトがプロジェクトページから開かれると、コンテンツページが開かれ、ダッシュボードページが表示されます。モデルビューア/3Dパネルが自動的に開く状況がいくつかあります。

### 1.2 **手動でパネルを開く/閉じる**

**大きい画面を持つデバイス**パネルが開いている場合、緑色でハイライトされます。まだアクティブでないパネルを選択して、他のアクティブなパネルと並べて開きます。アクティブなパネルを選択して無効にします。常に少なくともひとつのパネルがアクティブである必要があります。例えば、コンテンツパネルから3Dパネルに切り替えるには、最初にコンテンツパネルと共に3Dパネルを有効にしてから、コンテンツパネルを無効にして3Dパネルのみをアクティブにします。

異なるパネル間を簡単に切り替えるためにキーバインドを使用できます。メインコンテンツパネルの場合はShift+1、モデルビューアパネルの場合はShift+2、モデルツリーパネルの場合はShift+3、モデル情報パネルの場合はShift+4

**画面スペースが限られているデバイス**開いているパネルは灰色の背景を持っています。別のパネルを選択してそのパネルに切り替えます。画面スペースが限られている場合、一度にひとつのパネルのみを開くことができます。

## 2. **メインコンテンツパネル**

メインコンテンツパネルは最初のパネルで、最も多くの情報を含んでいます。一部のユーザーはコンテンツパネルでのみ作業します。このパネルはコンテンツパネルとも呼ばれます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/04-main-content-panel.png)

コンテンツパネルには、以下のメインページが含まれる場合があります：

ダッシュボード モデル トピック ドキュメント ライブラリ レポート 通知 設定

コンテンツパネルの詳細については、[ここ](https://support.catenda.com/en/articles/8212646-dashboard-page)をクリックしてください。

## 3. **モデルビューアパネル**

モデルビューアパネルはセカンドパネルです。このパネルは3Dビューアパネルとも呼ばれます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/05-model-viewer-panel.png)

モデルビューアパネルには、以下のメインページが含まれる場合があります：

3Dビューアツール 2Dビューア

3Dパネルの詳細については、[ここ](https://support.catenda.com/en/articles/8227211-3d-viewer)をクリックしてください。

## 4. **モデルツリーパネル**

モデルツリーパネルはサードパネルです。このパネルはツリーパネルとも呼ばれます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/06-model-tree-panel.png)

ツリーパネルには、以下のメインページが含まれる場合があります：

内包ツリー コンポーネントツリー タイプツリー レイヤーツリー システムツリー

ツリーパネルの詳細については、[ここ](https://support.catenda.com/en/articles/4670290-trees-panel)をクリックしてください。

## 5. **モデル情報パネル**

モデル情報パネルはフォースパネルで最後のパネルです。このパネルはインスペクトパネルとも呼ばれます。

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/07-model-info-panel.png)

インパネルには、以下のメインページが含まれる場合があります：

インスペクト QTO(数量算出) 4D選択 測定

コンテンツパネルの詳細については、[ここ](https://support.catenda.com/en/articles/4670285-inspect-menu)をクリックしてください。
