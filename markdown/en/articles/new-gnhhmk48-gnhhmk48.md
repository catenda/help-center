# Projects page - Catenda Mobile

> Find and open a project in Catenda Mobile, and move between the pages of the app.

After [signing in to Catenda](https://github.com/catenda/help-center-ops/blob/article/download-mobile-app-catenda/content/203-product-features/214-catenda-plugins-and-integrations/202-catenda-as-an-application/103-download-your-mobile-app-catenda/EN_DRAFT_download-your-mobile-app-catenda-nxat4mfq.md#sign-in), the projects page opens. It lists every project the user is a member of.

![The projects page with the project filters and the project list](https://raw.githubusercontent.com/catenda/help-center/main/images/gnhhmk48/01-intro.jpg)

## 1. **Log out**

The first button at the top right logs the user out of Catenda. Logging out also removes the project data the app stored on the phone.

## 2. **Search for a project**

The search button at the top right, next to the log out button, searches for a project by name.

## 3. **Filter projects**

The filters under the title choose which projects are listed. **All projects** lists every project the user is a member of, and **Favorites** only the projects marked as a favorite. **Sort** sets the order of the list, for example by name from A to Z.

## 4. **Open a project**

Tapping a project opens it. A project always opens on the Topics page, also when it is opened with **Switch project** on the Menu page.

The bar at the bottom of the screen leads to the five pages of the app, and each has its own article:

- [Topics](https://github.com/catenda/help-center-ops/blob/article/download-mobile-app-catenda/content/203-product-features/214-catenda-plugins-and-integrations/202-catenda-as-an-application/113-topics-page-catenda-mobile/EN_DRAFT_topics-page-catenda-mobile-61k1j9km.md): browse, filter and create topics.
- [Locations](https://github.com/catenda/help-center-ops/blob/article/download-mobile-app-catenda/content/203-product-features/214-catenda-plugins-and-integrations/202-catenda-as-an-application/114-locations-page-catenda-mobile/EN_DRAFT_locations-page-catenda-mobile-7z5qbekw.md): navigate the project by building, floor and room.
- [Forms](https://github.com/catenda/help-center-ops/blob/article/download-mobile-app-catenda/content/203-product-features/214-catenda-plugins-and-integrations/202-catenda-as-an-application/115-forms-page-catenda-mobile/EN_DRAFT_forms-page-catenda-mobile-b679p300.md): fill in inspections, checks and reports.
- [Docs](https://github.com/catenda/help-center-ops/blob/article/download-mobile-app-catenda/content/203-product-features/214-catenda-plugins-and-integrations/202-catenda-as-an-application/116-documents-page-catenda-mobile/EN_DRAFT_documents-page-catenda-mobile-0mhxhsb0.md): browse and open the documents of the project.
- [Menu](https://github.com/catenda/help-center-ops/blob/article/download-mobile-app-catenda/content/203-product-features/214-catenda-plugins-and-integrations/202-catenda-as-an-application/117-menu-page-catenda-mobile/EN_DRAFT_menu-page-catenda-mobile-8rbcp4pd.md): opens the Menu page, to change settings, switch project or log out.

A different project is opened with **Switch project** on the Menu page.
