# About Catenda Desktop Connector for System Images

> A version of the Catenda Desktop Connector for organizations that install software in an operating system image, which can be requested.

The Catenda Desktop Connector schedules uploads and downloads between Catenda Hub and a computer, and is described in [Catenda Desktop Connector](https://support.catenda.com/en/articles/8358861-catenda-desktop-connector). A version for organizations that install software in an operating system image can be requested.

## 1. **What it is**

It is the same application as the regular Desktop Connector, packaged so that it installs per user instead of for the whole computer. That suits computers and virtual desktops set up from a prepared image, such as a golden image in Citrix.

## 2. **Getting started**

The Catenda Desktop Connector works with projects in Catenda Hub. To use it, contact Catenda sales about getting started with a first project: [https://catenda.com/get-started](https://catenda.com/get-started) or [sales@catenda.com](mailto:sales@catenda.com).
