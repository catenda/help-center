# Sign in to Catenda from Power BI

> How the Catenda connector for Power BI signs in to Catenda, and what to do when the sign-in fails or expires.

The Catenda connector for Power BI signs in to Catenda with the user's own Catenda account. This works the same way in the released [Catenda Power BI Connector](https://support.catenda.com/en/articles/5784721-catenda-power-bi-connector) and in the [Catenda Power BI Connector (On Demand)](https://support.catenda.com/en/articles/17778871-catenda-power-bi-connector-on-demand).

## 1. **Sign in for the first time**

1. In Power BI Desktop, go to **Get data** > **More** > **Other** > **Catenda**, and select **Connect**.
2. A browser window opens on the Catenda sign-in page.
3. Sign in with the Catenda account.

The Catenda sign-in itself is described in [Sign in page](https://support.catenda.com/en/articles/7891486-sign-in-page).

Power BI Desktop then remembers the sign-in, so later refreshes and new connections do not ask again. The navigator shows every project the account has access to.

## 2. **Sign in again after an upgrade**

The Catenda connector used to be called _Bimsync_ in Power BI. Power BI Desktop keeps a separate sign-in for each name, so the first connection after an upgrade from a _Bimsync_ connector asks for one new sign-in.

## 3. **When the sign-in fails or has expired**

When the sign-in keeps failing, keeps asking again, or a load stops with _Catenda sign-in expired_, Power BI Desktop's stored sign-in has to be cleared:

Go to **File** > **Options and settings** > **Data source settings**.

![The Options and settings page of the File menu in Power BI Desktop, with an arrow from Options and settings to Data source settings](https://raw.githubusercontent.com/catenda/help-center/main/images/8jvrzkes/01-when-the-sign-in-fails-or-has-expired.png)

Select the Catenda entry and click **Clear permissions**.

![The Data source settings dialog in Power BI Desktop with the Catenda entry selected and the Clear Permissions button](https://raw.githubusercontent.com/catenda/help-center/main/images/8jvrzkes/02-when-the-sign-in-fails-or-has-expired.png)

Connect again and sign in.

## 4. **Before a long load**

A load of many tables at once can take a long time, and the sign-in renews itself during it. A long load is best started right after a fresh sign-in: clear the permissions as described above and sign in, then start the load.
