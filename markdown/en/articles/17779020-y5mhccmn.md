# About Catenda Data Export

> Catenda Data Export copies the data of Catenda Hub projects to an organization's own cloud storage, automatically.

Catenda Hub has several ways to download project data, described in [Exporting all project data](https://support.catenda.com/en/articles/7946690-exporting-all-project-data). Catenda Data Export is the automated one: it copies project data straight to an organization's own cloud storage in Amazon S3 or Azure Blob storage. It is sold separately from Catenda Hub.

## 1. **What it is**

Catenda Data Export keeps a copy of a project's documents, models and topics in storage the organization controls. It runs on a schedule or once, without anybody downloading files by hand.

## 2. **Project owners and participants**

Catenda Data Export is not only for organizations that own projects in Catenda Hub. What it exports depends on the organization's role in each project.

### 2.1 **Project owners**

An organization that owns a project can export a full backup of all of that project's data.

### 2.2 **Project participants**

An organization that takes part in projects owned by others can get Catenda Data Export too, without owning a project itself. In those projects, it exports only what the participant has access to, which can be a limited part of the project. That way the participant keeps its own copy of its work, even if its access to a project ends.
