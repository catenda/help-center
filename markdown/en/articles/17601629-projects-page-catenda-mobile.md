# Projects page - Catenda Mobile

> Find and open a project in Catenda Mobile, and move between the pages of the app.

After [signing in to Catenda](https://support.catenda.com/en/articles/17601630-download-your-mobile-app-catenda#sign-in), the projects page opens. It lists every project the user is a member of.

![The projects page with the project filters and the project list](https://raw.githubusercontent.com/catenda/help-center/main/images/gnhhmk48/01-intro.jpg)

## 1. **Log out**

The first button at the top right logs the user out of Catenda. Logging out also removes the project data the app stored on the phone.

## 2. **Search for a project**

The search button at the top right, next to the log out button, searches for a project by name.

## 3. **Filter projects**

The filters under the title choose which projects are listed. **All projects** lists every project the user is a member of, and **Favorites** only the projects marked as a favorite. **Sort** sets the order of the list, for example by name from A to Z.

## 4. **Open a project**

Tapping a project opens it. A project always opens on the Topics page, also when it is opened with **Switch project** on the Menu page.

The bar at the bottom of the screen leads to the five pages of the app, and each has its own article:

- [Topics](https://support.catenda.com/en/articles/17601633-topics-page-catenda-mobile): browse, filter and create topics.
- [Locations](https://support.catenda.com/en/articles/17601635-locations-page-catenda-mobile): navigate the project by building, floor and room.
- [Forms](https://support.catenda.com/en/articles/17601640-forms-page-catenda-mobile): fill in inspections, checks and reports.
- [Docs](https://support.catenda.com/en/articles/17601649-documents-page-catenda-mobile): browse and open the documents of the project.
- [Menu](https://support.catenda.com/en/articles/17601655-menu-page-catenda-mobile): opens the Menu page, to change settings, switch project or log out.

A different project is opened with **Switch project** on the Menu page.
