# Hardware recommendation

> Find recommended hardware specifications and optimisation tips for the best experience with Catenda Hub.

## 1. **Hardware recommendation:**

This hardware recommendation is only intended for Catenda Hub in a browser application. That includes Catenda Hub opened in the browser of a tablet, or added to its home screen, as described in [iPad and other tablets](#ipad-and-other-tablets). There can be different requirements depending on the detail level of your 3D objects. Levels of detail (LOD) are defined by AIA in document G202 as LOD 100, 200, 300, 400, 500 and 600. The LOD definition can be seen [here](https://assets.aiacontracts.com/ctrzdweb02/zdpdfs/aia-g202-2013-free-sample-preview.pdf).

## 2. **Monitor**

If one or more external monitors are connected to a device, even if Catenda is not displayed on that monitor, make sure the device supports the amount of monitors and the combination of display resolutions that the monitors have and that are configured in the operating system.

## 4. **iPad and other tablets**

Catenda Hub can also be used on an iPad or another tablet, in the browser or [added to the home screen](https://support.catenda.com/en/articles/10741601-add-to-home-screen) as an app. Added to the home screen, it is still Catenda Hub running in the browser of the device, so the full functionality is available and the recommendations below apply to both.

### 4.1 **Graphics memory decides how much 3D you can load**

Models shown in the 3D viewer are held in the memory of the graphics processor. On a tablet the graphics processor shares its memory with the rest of the device, and there is less of it than on a computer with a dedicated graphics card. How much geometry a tablet can show at the same time therefore depends on its chip and its memory, not on its storage space. A tablet with more storage does not load more models.

### 4.2 **Recommended tablets**

For regular projects (up to LOD 300), a recent iPad on the latest version of iPadOS is recommended. For dense geometry projects (LOD 400 and above), or when many models have to be shown together, an iPad Pro or an iPad Air with an M-series chip is recommended. On an Android tablet, a recent model with a high-end chip on the latest version of Android is recommended. Keep iPadOS and Safari up to date, because updates often improve how the browser handles 3D graphics.

### 4.3 **Getting the most out of a tablet**

On a tablet it helps to load only what you need for the task at hand:

- Turn on only the models you need, rather than every model in the project.
- Use a [query](https://support.catenda.com/en/articles/4854514-queries) to show only the part of the model you are working in.
- Turn on incremental rendering in the [3D viewer settings](https://support.catenda.com/en/articles/5784718-3d-viewer-settings).

More tips are described in [3D Viewer optimization](https://support.catenda.com/en/articles/13927321-3d-viewer-optimization).

For work on the construction site, the Catenda Site mobile app is often a better fit, as described in [Access with limited screen space](https://support.catenda.com/en/articles/10695677-access-with-limited-screen-space).
