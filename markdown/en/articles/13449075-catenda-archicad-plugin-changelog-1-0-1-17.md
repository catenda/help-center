# Catenda Archicad plugin changelog - 1.0.1.17

This changelog covers version 1.0.1.17 of the Catenda Archicad plugin.

## 1. **October 2026: translations added**

The plugin now serves its page translated, including in Japanese. This did not change the version number: only the translations were added.

## 2. **September 2026: new features**

Support for Archicad 29 It is now possible to choose between survey point and project origin in the coordinates action menu. Viewpoints are now played relative to the coordinate setting configured in the coordinates action menu. Support for new status workflow with published and shared major and minor revisions.
