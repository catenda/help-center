# About the report editor

> Catenda Hub creates reports from a project's topics, documents and approvals. With the report editor, a project can have report templates of its own.

On the [reports page](https://support.catenda.com/en/articles/12303098-reports-page), Catenda Hub creates reports from the topics, documents and approval requests of a project, ready to save and share as a document. Every report is built from a report template, which decides what the report looks like and which project information it shows. The report editor, where report templates are designed, can be requested for the projects that need it.

## 1. **What it is**

The report editor gives a project report templates of its own, from the title block to the tables and charts. Ready-made templates for topics, documents and approvals are available as a starting point, in different languages.

## 2. **Getting started**

The report editor works with projects in Catenda Hub. To use it, contact Catenda sales about getting started with a first project: [https://catenda.com/get-started](https://catenda.com/get-started) or [sales@catenda.com](mailto:sales@catenda.com).
