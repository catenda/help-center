# Hoe kan ik één model volledig weergeven terwijl ik alle andere modellen semi-transparant maak?

1. Open alle modellen in de 3D-viewer
2. Open het structuurpaneel (sneltoets is shift-3).
3. Selecteer het model dat je wilt bekijken ("isoleren") en klik op het bovenste knooppunt van die lijst. Dit selecteert alle elementen in dit model.
4. Klik met de rechtermuisknop op het bovenste knooppunt en selecteer "Isoleren". Alle objecten in dit model worden nu volledig weergegeven, terwijl alle objecten van andere modellen semi-transparant worden.
