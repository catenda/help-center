# Over Catenda Data Export

> Catenda Data Export kopieert de gegevens van Catenda Hub-projecten automatisch naar de eigen cloudopslag van een organisatie.

Catenda Hub heeft verschillende manieren om projectgegevens te downloaden, beschreven in [Alle projectgegevens exporteren](https://support.catenda.com/nl/articles/7946690-alles-projectgegevens-exporteren). Catenda Data Export is de geautomatiseerde: het kopieert projectgegevens rechtstreeks naar de eigen cloudopslag van een organisatie in Amazon S3 of Azure Blob-opslag. Het wordt apart van Catenda Hub verkocht.

## 1. **Wat het is**

Catenda Data Export houdt een kopie van de Documenten, modellen en Topics van een project in opslag die de organisatie controleert. Het wordt uitgevoerd volgens een schema of eenmalig, zonder dat iemand handmatig bestanden downloadt.

## 2. **Projecteigenaren en deelnemers**

Catenda Data Export is niet alleen voor organisaties die projecten in Catenda Hub bezitten. Wat het exporteert, hangt af van de rol van de organisatie in elk project.

### 2.1 **Projecteigenaren**

Een organisatie die een project bezit, kan een volledige back-up van alle gegevens van dat project exporteren.

### 2.2 **Projectdeelnemers**

Een organisatie die deelneemt aan projecten die door anderen worden beheerd, kan ook Catenda Data Export krijgen, zonder zelf een project te bezitten. In die projecten exporteert het alleen wat de deelnemer toegang tot heeft, wat een beperkt deel van het project kan zijn. Op deze manier behoudt de deelnemer een eigen kopie van zijn werk, zelfs als de toegang tot een project eindigt.
