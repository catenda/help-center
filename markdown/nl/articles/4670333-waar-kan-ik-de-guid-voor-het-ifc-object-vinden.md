# Waar kan ik de GUID voor het IFC-object vinden?

Om de GUID van een object te vinden, open eerst een model in de 3D-viewer en open het inspectie-instrument. Selecteer een object en in de rechterbovenhoek van het "Identification"-segment is er een knop, druk erop en meer informatie over het object verschijnt, inclusief de GUID.
