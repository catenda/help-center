# Revit changelog - 1.0.8

Nieuwe functies in 1.0.8

- Revit 2024 beschikbaarheid
- Teams Filters
- Aangepaste exportinstellingen zijn opnieuw beschikbaar in de plugin
- Issue zijpaneel
  - Binnen een issue is het nu mogelijk het zijpaneel te openen door op gerelateerde items te klikken.
  - Bekijk Documenten die aan de issue zijn gekoppeld
  - Selecteer objecten die aan de issue zijn gekoppeld
  - Bekijk welke issues aan deze issue zijn gerelateerd
