# Een project binnengaan

Om een project te binnengaan, moet een van de beheerders van het project u uitnodigen. U ontvangt een uitnodiging en kunt het project binnengaan. Als dit uw eerste Catenda Hub-project is, kiest u uw wachtwoord de eerste keer dat u zich aanmeldt.
