# 2D / 3D - Catenda Site

De 2D / 3D-pagina is te vinden in het [menu](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site) of door op de knop voor problemen op de onderste navigatiebalk te tikken.

![2D / 3D](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/01-intro.png)

Zo kan de 2D / 3D-pagina eruitzien:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/02-intro.png)

Bovenaan de 2D / 3D-pagina ziet u de issue board selector.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/03-intro.png)

De problemen die uit het filter op de gekozen issue board voortvloeien, zijn de problemen waarvan de markers in de 2D-weergave worden weergegeven.

### Bovenste helft

In de bovenste helft van de 2D / 3D-pagina ziet u de [3D viewer](https://support.catenda.com/en/articles/7744403-3d-viewer-catenda-site).

### Onderste helft

In de onderste helft van de 2D / 3D-pagina ziet u de [2D viewer](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site).

### Scheidingsbalk

Tussen de twee viewers ziet u een schuifbalk om te verdelen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/04-dividing-bar.png)

Sleep deze schuifregelaar om in te stellen hoeveel ruimte op het scherm elk van de viewers in beslag mag nemen
