# Pagina met inhoud van opgeslagen views

Opgeslagen views zijn te vinden op de [pagina met opgeslagen views](https://support.catenda.com/en/articles/4670281-bookmarks-page). Dit is hoe een opgeslagen view eruit kan zien:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/01-intro.png)

## 1. **Actiemenu**

Het actiemenu is te vinden in de rechterbovenhoek van de pagina

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/02-action-menu.png)

### 1.1 **Nieuwe opgeslagen view**

Klik hier om een [nieuwe opgeslagen view](https://support.catenda.com/en/articles/4670269-creating-a-new-bookmark) te maken.

### 1.2 **Opgeslagen view verwijderen**

Om een opgeslagen view te verwijderen, klikt u op opgeslagen view verwijderen in het actiemenu in de rechterbovenhoek. _Vereiste toegang:_ Maker van opgeslagen view

## 2. **Snapshot**

De afbeelding van het viewport is gegenereerd toen de snapshot voor het laatst werd bijgewerkt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/03-snapshot.png)

Klik [hier](https://support.catenda.com/en/articles/10345863-snapshots) voor meer informatie over snapshots.

## 3. **Titel**

De titel van de opgeslagen view. Dit kan gefilterd worden met een tekstfilter op de [pagina met opgeslagen views](https://support.catenda.com/en/articles/4670281-bookmarks-page).

### 3.1 **Gemaakt door**

De gebruiker die deze opgeslagen view heeft gemaakt en wanneer deze werd gemaakt. Het is niet mogelijk om opgeslagen views te verwijderen die met het project zijn gedeeld door gebruikers die niet langer deel uitmaken van het project

## 4. **Kopie en originele opgeslagen view**

Als deze opgeslagen view is gemaakt door een opgeslagen view te kopiëren die door een ander gebruiker met het project is gedeeld, kunt u naar de originele opgeslagen view gaan door hier op "Open de originele opgeslagen view" te klikken. Op dezelfde manier kunt u, als u naar een opgeslagen view kijkt waarvan u een kopie hebt gemaakt, hier op "Mijn kopie openen" klikken.

## 5. **Delen**

Wanneer een opgeslagen view met het project wordt gedeeld, kunnen alle projectleden de opgeslagen view in hun lijst met opgeslagen views zien.

### 5.1 **Privé**

Alleen u kunt deze opgeslagen view zien. U moet mogelijk de openbaar gedeelde URL uitschakelen om een opgeslagen view weer privé te maken, omdat opgeslagen views met een openbare URL met het project moeten worden gedeeld.

### 5.2 **Delen met project**

Projectleden kunnen deze opgeslagen view filteren en kopieën ervan maken. Opgeslagen views met een openbare URL worden altijd met het project gedeeld.

### 5.3 **Openbare URL delen**

In het gedeelte openbare URL delen van een opgeslagen view kunt u een openbare URL maken. Openbare URL's worden doorgaans gebruikt om een cliënt, externe aannemer of ambtenaar te laten zien waaraan mensen in het project werken zonder hen uit te nodigen voor het project.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/04-public-url-sharing.png)

Om een openbare URL te maken, moet de opgeslagen view eerst [met het project worden gedeeld](#h_5c9944a45e).

**Openbare URL inschakelen** Om een openbare opgeslagen view in te schakelen, klikt u op Delen bewerken en schakelt u het selectievakje "Openbare URL inschakelen" in. _Vereiste toegang:_ Projectbeheerder

Wanneer een URL is gemaakt, kan iedereen in het project deze met mensen buiten het project delen. De openbare opgeslagen view kan op versies worden vergrendeld of de nieuwste versie volgen, net als een normale opgeslagen view. Als u de nieuwste versie volgt, kunnen linkhouders volgen hoe het project voortgaat. Als u op versies vergrendelt, kunnen linkhouders de huidige status van de modelversies in de opgeslagen view zien. Zorg ervoor dat u de opgeslagen view bijwerkt als er nieuwe modellen worden toegevoegd.

**Vervaldatum** Een vervaldatum kan worden ingesteld waarna de URL de opgeslagen view niet meer opent. Als er modellen met 4D werkplannen in het project zijn, kunnen deze op de opgeslagen view worden toegepast.

**Werkplan (4D)** Wanneer een 4D-werkplan wordt toegevoegd, zien kijkers van de snapshots objecten verschijnen naarmate ze op de plaats worden geïnstalleerd.

**Na het inschakelen van een openbare URL** Dit is hoe het menu voor openbare URL delen er kan uitzien nadat de openbare URL is ingeschakeld:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/05-public-url-sharing.png)

Klik opnieuw op Delen bewerken om de export bij te werken.

Gedeeld door Zolang er een actieve koppeling is, geeft het menu aan wie de koppeling heeft gedeeld en wanneer deze werd gedeeld.

**Openen in nieuw tabblad** Zolang er een actieve koppeling is, geeft het menu aan dat u de knop "Openen in nieuw tabblad" hebt om de openbare URL in een nieuw tabblad te openen

**Koppeling kopiëren** Zolang er een actieve koppeling is, geeft het menu aan dat u de knop "Koppeling kopiëren" hebt om de koppeling naar de openbare URL te kopiëren

**QR-koppeling afdrukken** Zolang er een actieve koppeling is, geeft het menu aan dat u de knop "QR-koppeling afdrukken" hebt om het afdrukdialoogvenster van de browser te openen, waarmee u een document met de QR-code met een koppeling naar de openbare URL kunt afdrukken. Dit is hoe het afdrukdialoogvenster van de browser er in Google Chrome op Windows kan uitzien:

![Google Chrome print QR code Microsoft Print to PDF Catenda](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/06-public-url-sharing.png)

Het document bevat de QR-code zelf, de datum en tijd van afdrukken en de titel van de opgeslagen view.'

**Oog** Klik op het oog naast de knop QR-koppeling afdrukken om de QR-code met een koppeling naar de URL weer te geven.

_Vervaldatum_ Onder aan het menu wordt de vervaldatum weergegeven. Als geen vervaldatum is ingesteld, staat daar dat de gedeelde koppeling niet verloopt. Nadat de vervaldatum is verstreken, verdwijnen de knoppen in dit menu en wordt weergegeven dat de koppeling is verlopen, samen met de datum waarop deze is verlopen. Een verlopen koppeling kan er als volgt uitzien:

![Public URL sharing Edit sharing Link has expired](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/07-public-url-sharing.png)

**Openbare delen uitschakelen** Organisatie-eigenaren kunnen aanvragen dat alle openbare deelfuncties voor al hun projecten worden uitgeschakeld. Sommige projecten vereisen dit om veiligheidsredenen. Als u alle openbare deelfuncties wilt uitschakelen, neemt u contact op met de ondersteuning via de zwarte chatknop naast uw profielfoto in de rechterbovenhoek of via [support@catenda.com](mailto:support@catenda.com)

## 6. Modellen en versies

Nadat een opgeslagen view is gemaakt, kunnen nieuwe versies ervan worden geüpload, waardoor de opgeslagen view verouderd raakt. Soms is dit gewenst omdat u wilt zien hoe het op het moment van aanmaak was, en soms wilt u de opgeslagen view met de nieuwste versies zien.

**Nieuwste versie volgen** De nieuwste gepubliceerde versie van de modellen in de opgeslagen view wordt geladen wanneer deze wordt afgespeeld.

> **Gedeelde versies:** Gedeelde versies worden niet weergegeven omdat deze nog in de werkruimte staan. Als er een gepubliceerde versie in het model van de gedeelde versie is, wordt in plaats daarvan de nieuwste gepubliceerde versie weergegeven.

**Vergrendelen op originele versies** De originele versies van de modellen in de opgeslagen view worden geladen wanneer deze wordt afgespeeld.

> **Gedeelde versies:** Met deze optie worden gedeelde versies ook weergegeven.

Hieronder worden de modellen vermeld met de versie van het model die wordt weergegeven wanneer de opgeslagen view wordt afgespeeld. Zorg ervoor dat u de opgeslagen view bijwerkt als er nieuwe modellen worden toegevoegd.

## 7. **Documenten**

Hier ziet u alle documenten die mogelijk in de 3D-viewer zijn geladen toen de opgeslagen view werd gemaakt. Dit kunnen het volgende zijn: - IFC-documenten die niet met een model zijn verbonden (Legacy) - Pointclouds - GML Hier ziet u de locatie van het document in de bestandsstructuur, de naam van het document en de versie van het document die wordt weergegeven. Deze documenten zijn ook zichtbaar met openbare opgeslagen views.
