# Hoe kan ik een document aan een object in Catenda Hub koppelen?

1. Open de 3D-viewer en selecteer een (of meer) objecten door erop links te klikken (ctrl-links klikken opent om meer dan een object te selecteren).
2. Klik op het menu Documenten in de menubalk linksboven
3. Selecteer een (of meer) documenten door op de selectievakjes links van elk daarvan te klikken
4. Klik op de knop "Koppeling" die aan de rechterkant van de documentweergave wordt weergegeven.
