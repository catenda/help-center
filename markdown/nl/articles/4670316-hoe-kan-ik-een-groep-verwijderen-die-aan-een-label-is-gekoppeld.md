# Hoe kan ik een groep verwijderen die aan een label is gekoppeld?

U kunt een groep van een label verwijderen door: 1\. Selecteer het label met behulp van het selectievakje links van het label. 2\. Druk vervolgens op "Groep instellen" 3\. Selecteer "Groep verwijderen" 4\. Bijwerken
