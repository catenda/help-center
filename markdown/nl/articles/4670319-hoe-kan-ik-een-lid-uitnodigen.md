# Hoe kan ik een lid uitnodigen?

U kunt nieuwe leden uitnodigen voor het project op de [pagina leden uitnodigen](https://support.catenda.com/en/articles/4670263-invite-members-page).

_Vereiste toegang:_ Toegang tot [leden uitnodigen](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3) op de pagina met projectinstellingen.

Volg de onderstaande stappen om een nieuw lid uit te nodigen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/203nmrp5/01-intro.png)

1\. E-mailadres invoeren

2\. Druk op Enter

3\. Optioneel - Kies de rol/toegang

_Vereiste toegang:_ Projectbeheerder

4\. Optioneel - Kies de Teams waarvan het lid deel uit moet maken.

_Vereiste toegang:_ Projectbeheerder

5\. Klik op de knop Toevoegen

6\. Optioneel - Kies taal

7\. Optioneel - Schrijf een bericht

8\. Uitnodiging verzenden

Klik [hier](https://support.catenda.com/en/articles/4670263-invite-members-page) voor meer informatie over de pagina leden uitnodigen.
