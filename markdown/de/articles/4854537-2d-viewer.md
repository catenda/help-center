# 2D-Viewer

> Beschreibt die verschiedenen Tools in der 2D-Symbolleiste

Um den 2D Viewer zu öffnen, klicken Sie auf die 2D-Schaltfläche auf der rechten Seite im [3D-Fenster](https://support.catenda.com/en/articles/8227211-3d-viewer).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5pdj535/01-intro.png)

## 1. **Modellgeschosse**

Im 2D-Viewer wird ein Schnitt durch 3D-Objekte aus einem Modell angezeigt. Wenn eine neue IFC-Datei als Überarbeitung entweder zu einem Modell oder zu einem Dokument, das mit einem Modell verknüpft ist, hochgeladen wird, werden 2D-Schnitte durch die Objekte in der IFC-Datei auf jeder der Geschosse generiert. Während es möglich ist, diese Schnitte mit dem Geschosskonfigurator auf eine andere Höhe einzustellen, ist es im Fall eines Zwischengeschosses nicht möglich, den Inhalt jedes Schnitts nach seiner Generierung zu ändern. Dies ist das Aussehen des 2D-Viewers, wenn ein Geschoss angezeigt wird:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5pdj535/02-model-storeys.png)

### 1.1 **Standardgeschoss**

Wenn bisher kein 2D-Ansicht ausgewählt wurde und es Modelle auf der Seite Modelle des Projekts gibt, wird das Standard-Modellgeschoss angezeigt. Das Standardgeschoss ist das Geschoss aus der neuesten Überarbeitung eines der Modelle, das die meisten Objekte von Interesse hat. Objekte von Interesse sind Objekte wie Wände, Türen und Fenster.

**Konfigurieren des Standardgeschosses** Wenn ein Gebäude im [Geschosskonfigurator](https://support.catenda.com/en/articles/6921756-storey-configurator-page) konfiguriert wurde, wird das erste Geschoss des ersten erstellten Gebäudes anstelle des Standardgeschosses angezeigt, das auf der Grundlage von Objekten von Interesse ausgewählt wird. Überprüfen Sie die Projektkonfigurationen doppelt, wenn das vorkonfigurierte Geschoss nicht wie erwartet angezeigt wird, und überprüfen Sie die Einstellungen im Geschosskonfigurator, falls erforderlich.

### 1.2 **Verfügbare Geschosse**

Laden Sie 2D-Ansichten verschiedener Geschosse in Modellen auf verschiedene Weise in den 2D Viewer.

**2D-Schaltfläche** Klicken Sie auf die 2D-Schaltfläche für ein Modell. 2D-Schaltflächen für Modelle finden Sie an mehreren Stellen:

- [Revisionsauswahl](https://support.catenda.com/en/articles/4670279-revision-selector) oben rechts im 3D Viewer
- [Modelltabelle](https://support.catenda.com/en/articles/4670286-models-page#h_bbc42c56bb) auf der [Seite Modelle](https://support.catenda.com/en/articles/4670286-models-page)
- Viewer-Spalte in der [Dokumenttabelle](https://support.catenda.com/en/articles/8204673-documents-page#h_54e8dfcac2) auf der [Dokumentseite](https://support.catenda.com/en/articles/8204673-documents-page)

**Wiedergabe eines Schnappschusses** Spielen Sie einen [2D- oder 3D-Schnappschuss](https://support.catenda.com/en/articles/9184555-2d-and-3d-viewpoints) von einem Thema ab oder spielen Sie einen [Schnappschuss](https://support.catenda.com/en/articles/10345863-snapshots) von [einem Lesezeichen](https://support.catenda.com/en/articles/8471481-bookmark) ab, um die 2D-Modelle zu laden, die zum Zeitpunkt der Erstellung des Schnappschusses aktiviert waren.

**Marker auf 2D anzeigen** Ein Marker eines Themas mit einem Marker, der auf einem Geschoss platziert ist, kann angeklickt werden, um die Wiedergabe auf 2D auszuwählen. Klicken Sie auf diese Schaltfläche, um die Geschosse von Modellen, die beim Erstellen des Markers aktiviert waren, im 2D Viewer verfügbar zu machen. _Erforderlicher Zugriff:_ Lesezugriff auf das Dokument, das mit jedem der Modelle verbunden ist.

**Konfigurierte Geschosse** Wenn Gebäude im Geschosskonfigurator konfiguriert sind, sind die in jedem dieser Gebäude konfigurierten Geschosse immer verfügbar. _Erforderlicher Zugriff:_ Lesezugriff auf das Dokument, das mit jedem der Modelle verbunden ist.

### 1.3 **Kombination von Geschossen**

Wenn 2D-Ansichten mehrerer Modelle gleichzeitig aktiviert wurden, werden diese zusammen im 2D Viewer angezeigt. Wählen Sie ein Geschoss von einem der Modelle aus, um die Geschosse von allen aktivierten Modellen, die für diese Höhe generiert werden, zusammen im 2D Viewer anzuzeigen. Wenn beispielsweise 2D-Ansichten von sowohl dem architektonischen als auch dem Konstruktionsmodell aktiviert sind und das erste Geschoss des architektonischen Modells ausgewählt ist, und wenn das Konstruktionsmodell ein Geschoss auf der gleichen Höhe des ersten Geschosses des architektonischen Modells hat, werden sowohl die Wände des architektonischen Modells als auch die Balken des Konstruktionsmodells zusammen im 2D Viewer angezeigt.

**Laden Sie 2D-Ansichten mehrerer Modelle auf einmal** Um 2D-Ansichten mehrerer Modelle auf einmal zu laden, wählen Sie die Modelle auf der Seite Modelle aus und klicken Sie auf die 2D-Schaltfläche oben auf der Seite Modelle.

**Konfigurierte Geschosse** Wählen Sie ein Geschoss von einem Gebäude aus, das im [Geschosskonfigurator](https://support.catenda.com/en/articles/6921756-storey-configurator-page) konfiguriert ist, um die 2D-Ansichten aller Modelle, die für dieses Geschoss konfiguriert sind, automatisch in den 2D Viewer zu laden.

## 2. **2D Viewer-Erscheinungsbild**

2D Viewer-Elemente wie:

- Objekte
- Unterlagerungsschichten wie Zeichnungen oder Karte
- Marker
- Raumbeschriftungen

Können konfiguriert werden, um je nach Bedarf des Benutzers angezeigt zu werden. Klicken Sie [hier](https://support.catenda.com/en/articles/13615984-2d-viewer-appearance#h_73338e8c67), um mehr über das Erscheinungsbild von 2D Viewer-Elementen zu erfahren.

## 3. **2D Viewer-Interaktionen**

Die folgenden Schaltflächen und Bereiche können angeklickt werden, um verschiedene Aktionen auszuführen.

- Obere Leiste
- Leinwand
- Navigationswerkzeuge
- Auswahlwerkzeuge und Einstellungen
- Untere Leiste

Klicken Sie [hier](https://support.catenda.com/en/articles/12699525-2d-viewer-interactions), um mehr über diese verschiedenen Aktionen zu erfahren.

## 4. **Exportieren eines Bildes**

Eine gute Möglichkeit, ein Bild aus dem 2D Viewer zu exportieren, besteht darin, einen [2D-Schnappschuss](https://support.catenda.com/en/articles/8227211-3d-viewer#h_a1594324c8) in einem Thema zu erstellen. Vektorlinienbilder in Form von `.svg`-Dateien können aus dem Seitenelement extrahiert werden, indem die Seite mit den Entwicklertools des Browsers auf der Registerkarte Elemente überprüft werden.
