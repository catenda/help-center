# Über Catenda Desktop Connector für Systemimages

> Eine Version des Catenda Desktop Connector für Organisationen, die Software in einem Betriebssystem-Image installieren, die angefordert werden kann.

Der Catenda Desktop Connector plant Uploads und Downloads zwischen Catenda Hub und einem Computer ein und wird in [Catenda Desktop Connector](https://support.catenda.com/de/articles/8358861-catenda-desktop-connector) beschrieben. Eine Version für Organisationen, die Software in einem Betriebssystem-Image installieren, kann angefordert werden.

## 1. **Was es ist**

Es ist dieselbe Anwendung wie der reguläre Desktop Connector, verpackt so, dass es pro Benutzer installiert wird, anstatt für den gesamten Computer. Das eignet sich für Computer und virtuelle Desktops, die aus einem vorbereiteten Image eingerichtet sind, z. B. ein Golden Image in Citrix.

## 2. **Erste Schritte**

Der Catenda Desktop Connector funktioniert mit Projekten in Catenda Hub. Um ihn zu nutzen, kontaktieren Sie den Catenda-Vertrieb, um mit einem ersten Projekt zu beginnen: [https://catenda.com/get-started](https://catenda.com/get-started) oder [sales@catenda.com](mailto:sales@catenda.com).

> **Hinweis:** Mehr ist für Catenda-Kunden verfügbar. Melden Sie sich bei Catenda unter [https://hub.catenda.com](https://hub.catenda.com) an, öffnen oder laden Sie dann eine Seite des Help Center neu. Das Help Center zeigt dann mehr für angemeldete Kunden an, beginnend mit [Einführung in Catenda Desktop Connector für Systemimages](https://support.catenda.com/de/articles/17778688-einfuhrung-in-catenda-desktop-connector-fur-systemabbilder) _(nur angemeldete Kunden)_.
