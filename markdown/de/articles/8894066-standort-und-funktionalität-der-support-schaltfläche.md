# Standort und Funktionalität der Support-Schaltfläche

Die schwarze Nachrichtenschaltfläche befindet sich oben rechts neben Ihrem Profilbild nach der Anmeldung bei Catenda Hub:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/h6ccqbtd/01-intro.png)

Auf unseren Support-Seiten finden Sie diese Schaltfläche unten rechts:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/h6ccqbtd/02-intro.png)

Die folgenden Menüs können nach dem Öffnen der Support-Blase gefunden werden:

## 1. **Startseite**

Dies ist das Standardmenü, das sich öffnet, wenn Sie die Support-Blase öffnen. Oben rechts werden Bilder der Kundenunterstützungsvertreter angezeigt, die derzeit aktiv sind.

### 1.1 **Kontaktieren Sie uns**

Kontaktieren Sie uns, indem Sie auf die Schaltfläche "Kontaktieren Sie uns" klicken. Hier können Sie uns alles fragen, das Sie über ein Tool erfahren möchten, Feedback zu Dingen geben, die Sie gerne sehen würden, über etwas berichten, das nicht funktioniert, oder Fragen zu Ihrem bestehenden/potenziellen Catenda-Konto stellen.

### 1.2 **Catenda Connections**

Hier finden Sie die Installationsdateien für alle unsere Plugins in externen Programmen

### 1.3 **Hilfe suchen**

Klicken Sie hier, um mit der Suche in den Hilfeseiten zu beginnen. Standardmäßig wird in der Sprache gesucht, auf die Sie Ihre Browsersprache eingestellt haben. Es gibt oft mehr Informationen in Englisch. Um englische Artikel zu finden, können Sie auf support.catenda.com gehen

### 1.4 **Empfohlene Seiten**

Unterhalb der Suchleiste finden Sie die folgenden empfohlenen Seiten: Benutzerhandbücher in verschiedenen Sprachen [Hardwareempfehlung](https://support.catenda.com/en/articles/6921941-hardware-recommendation) [Zusammenfassung der wichtigsten Tastenkombinationen und grundlegenden Steuerelemente](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls) [Das neueste Änderungsprotokoll](https://support.catenda.com/en/collections/2683918-recent-updates)

### 1.5 **Status**

Dies zeigt den Status unserer aktuellen Dienste an. Wenn Sie darauf klicken, gelangen Sie zu status.catenda.com, wo Sie sich für Updates zum Status unserer Server anmelden können. Hier finden Sie Informationen zur Verfügbarkeit unserer Server für Catenda Hub, Catenda API (Boost) und Catenda DUO. Sie können hier auch vergangene Vorfälle finden.

## 2. **Nachrichten**

Klicken Sie hier, um einen Überblick über Ihre bisherigen Gespräche mit uns zu sehen. Klicken Sie auf eines der Gespräche, um es zu öffnen.

### 2.1 **Senden Sie uns eine Nachricht**

Hier können Sie eine neue Nachricht senden

## 3. **Tickets**

Dieses Menü ist standardmäßig nicht sichtbar. Wenn Sie ein Ticket gemeldet haben oder wenn ein Ticket für Sie von einem Supportmitarbeiter erstellt wurde, wird dieses Menü angezeigt. Hier können Sie Ihre bisherige Rückmeldung, Fehlermeldungen oder Funktionswünsche verfolgen. Wenn es Fortschritte bei einem Ihrer Anliegen gibt, werden Sie hier und per E-Mail benachrichtigt.

## 4. **Hilfe**

Hier können Sie unsere Support-Seiten durchsuchen.
