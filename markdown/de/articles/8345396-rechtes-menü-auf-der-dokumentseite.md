# Rechtes Menü auf der Dokumentseite

Nachdem Sie ein oder mehrere Dokument(e) ausgewählt haben, wird das Infosymbol rechts neben der Suchleiste auf der Dokumentseite angezeigt. Wenn Sie auf dieses Symbol klicken, wird ein Informationsmenü geöffnet, das Informationen über den/die ausgewählten Ordner und/oder Dokument(e) oder den eingegebenen Ordner enthält. Das Infosymbol kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/01-intro.png)

Dieses erweiterte Bedienfeld kann je nach Auswahl unterschiedlich aussehen [_Ein Ordner_ ](#h_cad792004b) _- [Ein Dokument](#h_2fac53531d) - [Mehrere Ordner (und/oder Dokumente)](#h_58d67056f7)_

## 1. Ein Ordner

So könnte das rechte Menü aussehen, wenn ein Ordner ausgewählt ist.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/02-one-folder.png)

### 1.1 **Ordnerinformationen**

Wenn der Ordner leer ist, wird das Symbol weiß dargestellt. Unten rechts des Ordnersymbols wird die Anzahl der Dokumente in diesem Ordner angezeigt. Rechts neben dem Symbol sehen Sie den Namen des Ordners. Sie können den Namen des Ordners ändern, indem Sie auf das Stiftsymbol klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/03-folder-information.png)

_Erforderlicher Zugriff:_ Schreibzugriff auf den Ordner.

### 1.2 **Zugangskontrolle**

Weitere Informationen zur Zugangskontrolle im Bereich Dokumente finden Sie [hier](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl).

### 1.3 **Sammlungen**

Wenn Ihr Dokument Teil von [Sammlungen](https://support.catenda.com/en/articles/6344318-collections-page) ist, werden diese hier aufgelistet.

## 2. **Ein Dokument**

So könnte das rechte Menü aussehen, wenn ein Dokument ausgewählt ist:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/04-one-document.png)

Wenn Sie ein Dokument ausgewählt haben, werden Informationen zur neuesten öffentlichen Version in diesem Dokument angezeigt. Siehe [hier](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision), welche Informationen verfügbar sind.

## 3. **Mehrere Ordner (und/oder Dokumente)**

So könnte das rechte Menü aussehen, wenn mehrere Ordner und/oder Dokument(e) ausgewählt sind.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/05-multiple-folder-s-and-or-document-s.png)

Wenn mehrere Dokumente oder Ordner ausgewählt sind, ändern sich die Dokumentinformationen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/06-multiple-folder-s-and-or-document-s.png)

Wenn Sie auf das rote Kreuz klicken, können Sie diesen Ordner oder dieses Dokument aus Ihrer Auswahl entfernen.

### 3.1 **Ausgewählte Dokumente aktualisieren**

Mit diesem Menü können Sie Werte für mehrere Ordner (und/oder Dokumente) gleichzeitig ändern.

### 3.2 **Zugangskontrolle**

Mit diesem Menü können Sie den Zugriff auf mehrere Ordner (und/oder Dokumente) gleichzeitig ändern. Weitere Informationen zur Zugangskontrolle im Bereich Dokumente finden Sie [hier](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl).

### 3.3 **Sammlungen**

Wenn Ihr Ordner (und/oder Dokument) Teil von [Sammlungen](https://support.catenda.com/en/articles/6344318-collections-page) ist, werden diese hier aufgelistet.

### 3.4 **Verknüpfte Objekte**

Mit diesem Menü können Sie Objekte mit mehreren Ordnern (und/oder Dokumenten) gleichzeitig verknüpfen/entverknüpfen.
