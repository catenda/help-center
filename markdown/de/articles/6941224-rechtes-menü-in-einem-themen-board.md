# Rechtes Menü in einem Themen-Board

Das rechte Menü auf der [Seite "Themen"](https://support.catenda.com/en/articles/4670271-topics-page) können Sie öffnen, indem Sie auf das Info-Symbol rechts neben der Suchleiste unterhalb des [Themen-Banners](https://support.catenda.com/en/articles/7986346-topic-banner-navigating-topics) klicken. Klicken Sie auf das Symbol, um ein Menü zu öffnen, das Informationen über ausgewählte Themen und Themen-Boards enthält.

So kann das [Themen-Banner](https://support.catenda.com/en/articles/7986346-topic-banner-navigating-topics) aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/01-intro.png)

So kann das Info-Symbol aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/02-intro.png)

So kann das rechte Menü bei Erweiterung aussehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/03-intro.png)

## 1. **1. Informationen zur Auswahl**

So kann der obere Teil des rechten Menüs aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/04-1-selection-info.png)

### 1.1 **1.1 Ausgewählte Themen**

Ganz oben im rechten Menü wird die Anzahl der ausgewählten Themen angezeigt.

### 1.2 **1.2 Informationen zum Themen-Board**

**1.2.1 Mehrere Boards** Auf dem Board "Alle Themen" oder wenn Themen aus mehreren Boards ausgewählt werden, werden in den Informationen zum Themen-Board "Mehrere Boards ausgewählt" angezeigt

**1.2.2 Board-Name** Nach der Navigation zu einem bestimmten Themen-Board oder wenn alle ausgewählten Themen aus demselben Board stammen, wird hier der Name des Themen-Boards angezeigt.

## 2. **2. Keine Themen**

So kann das rechte Menü aussehen, wenn keine Themen ausgewählt sind:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/05-2-no-topics.png)

### 2.1 **1.1 Ausgewählte Themen aktualisieren**

Zeigt "Keine Themen ausgewählt" an, wenn erweitert, wenn keine Themen ausgewählt sind. In diesem Menü können ausgewählte Themen angezeigt und aktualisiert werden. Bei mehreren ausgewählten Themen können diese hier als Batch aktualisiert werden.

### 2.2 **1.2 Zugriffskontrolle für das Themen-Board**

Wenn keine Themen ausgewählt sind, wird das Menü "Zugriffskontrolle für Themen-Board" nur angezeigt, wenn Sie zu einem einzelnen Themen-Board navigieren. Wählen Sie auf dem Board "Alle Themen" ein Thema aus, um die Zugriffskontrolle des Boards zu sehen, in dem sich dieses Thema befindet. Klicken Sie [hier](https://support.catenda.com/en/articles/4670296-topic-board-access-control), um mehr über die Zugriffskontrolle für Themen-Boards zu erfahren.

## 3. **3. Ein einzelnes Thema**

Wenn ein einzelnes Thema ausgewählt ist, können Themeninformationen im rechten Menü aktualisiert werden, ohne das Thema anklicken zu müssen, um seine Inhaltsseite zu laden. So kann das rechte Menü aussehen, wenn ein einzelnes Thema ausgewählt ist:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/06-3-single-topic.png)

### 3.1 **3.1 Ausgewähltes Thema aktualisieren**

So kann das rechte Menü aussehen, wenn ein einzelnes Thema ausgewählt ist:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/07-3-1-update-selected-topic.png)

**3.1.1 Themen-Header** So kann der [Themen-Header](https://support.catenda.com/en/articles/8400566-topic-header-the-subject-of-a-topic) aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/08-3-1-update-selected-topic.png)

**3.1.2 Themen-Text** Unterhalb des Themen-Headers befindet sich der Themen-Text mit Beschreibung und Kommentaren. Von hier aus können Beschreibungen und Kommentare hinzugefügt und neue Kommentare erstellt werden. Klicken Sie [hier](https://support.catenda.com/en/articles/8053352-topic-body-the-content-of-a-topic), um mehr über den Themen-Text zu erfahren.

### 3.2 **3.2 Dokumente**

Klicken Sie [hier](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic#h_b00b9c5150), um mehr über zugehörige Dokumente zu erfahren.

### 3.3 **3.3 Objekte**

Klicken Sie [hier](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic#h_758f17abbc), um mehr über zugehörige Objekte zu erfahren.

### 3.4 **3.4 Themen**

Klicken Sie [hier](https://support.catenda.com/en/articles/8053299-right-menu-in-a-topic#h_edf2cb07a8), um mehr über zugehörige Themen zu erfahren.

### 3.5 **3.5 Zugriffskontrolle für Themen-Board**

Da ein einzelnes Thema sich immer in einem Themen-Board befindet, zeigt das Menü "Zugriffskontrolle für Themen-Board" den Zugriff auf das Themen-Board an, in dem sich das ausgewählte Thema befindet. Klicken Sie [hier](https://support.catenda.com/en/articles/4670296-topic-board-access-control), um mehr über die Zugriffskontrolle für Themen-Boards zu erfahren.

**Zugriff konfigurieren** Klicken Sie auf "Zugriff konfigurieren", um den Zugriff auf das Themen-Board zu bearbeiten, in dem sich das ausgewählte Thema befindet. _Erforderlicher Zugriff:_ Administrator

> **Hinweis:** Der Zugriff auf das Board spiegelt den Zugriff auf das ausgewählte Thema wider, aber in diesem Menü wird der Zugriff auf das gesamte Board angezeigt, in dem sich das Thema befindet, und nicht nur auf das ausgewählte Thema selbst.

## 4. **4. Mehrere Themen**

Bei mehreren ausgewählten Themen können Themeninformationen im rechten Menü als Batch aktualisiert werden, ohne jedes Thema öffnen zu müssen, um seine Inhaltsseite zu laden.

### 4.1 **Ausgewählte Themen aus einem einzelnen Board aktualisieren**

So kann das Menü "Ausgewählte Themen aktualisieren" aussehen, wenn mehrere Themen aus demselben Themen-Board ausgewählt sind:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/09-update-selected-topics-a-single-board.png)

**Status** Legen Sie den Status mehrerer Themen auf einmal fest oder aktualisieren Sie ihn.

**Typ** Legen Sie den Typ mehrerer Themen auf einmal fest oder aktualisieren Sie ihn.

**Zugewiesen an** Legen Sie den Bevollmächtigten für mehrere Themen auf einmal fest oder ändern Sie ihn, oder wählen Sie "Nicht zugewiesen", um den Bevollmächtigten mehrerer Themen auf einmal zu entfernen.

**Angefordert von** Legen Sie die Person fest, die mehrere Themen auf einmal anfordert, oder ändern Sie sie, oder wählen Sie "Nicht zugewiesen", um die Person zu entfernen, die mehrere Themen auf einmal anfordert.

**Fälligkeit / Milestone** Legen Sie ein Fälligkeitsdatum/einen Milestone für mehrere Themen auf einmal fest oder ändern Sie es. Klicken Sie im Menü "Fälligkeitsdatum/Milestone" auf "Fälligkeitsdatum entfernen" oder "Milestone entfernen", um das Fälligkeitsdatum/Milestone sofort aus mehreren Themen zu entfernen.

**Etiketten bearbeiten** Etiketten hinzufügen Fügen Sie mehreren Themen gleichzeitig ein Etikett hinzu.

Etiketten entfernen Entfernen Sie mehreren Themen gleichzeitig ein Etikett.

Priorität Wenn das gleiche Etikett in beiden Menüs hinzugefügt wird, hat das Entfernen des Etiketts Vorrang.

**Benutzerdefinierte Felder** Legen Sie einen Wert für ein benutzerdefiniertes Feld fest oder stellen Sie das Feld auf keinen Wert für mehrere Themen auf einmal ein.

> **Hinweis 1:** Felder, die in den Einstellungen des Themen-Boards als erforderlich konfiguriert sind, können nicht deaktiviert werden. **Hinweis 2:** Es ist nur möglich, Text-, Integer- und Dezimalfelder zu aktualisieren und sie nicht zu deaktivieren, obwohl Integer- und Dezimalfelder auf Null gesetzt und Text auf ein einzelnes Leerzeichen gesetzt werden können.

**Kommentar** Fügen Sie mehreren Themen auf einmal einen Kommentar hinzu. Es ist nur möglich, Kommentare zu mehreren Themen auf einmal hinzuzufügen, und nicht möglich, sie zu bearbeiten oder zu entfernen.

**Wert deaktivieren** Nachdem Sie einen Wert in einem beliebigen Feld ausgewählt haben, entfernen Sie den Wert, indem Sie auf das x auf der rechten Seite jedes Feldes klicken.

> **Hinweis:** Dieses x dient nicht zum Löschen des Feldes, sondern nur zum Löschen des Wertes. Einige Felder haben zusätzliche Werte zum Löschen des Feldes in diesem Menü

**Speichern** Klicken Sie auf "Speichern", um Ihre Änderungen zu übernehmen.

### 4.2 **Ausgewählte Themen aus mehreren Boards aktualisieren**

So kann das Menü "Ausgewählte Themen aktualisieren" aussehen, wenn mehrere Themen aus verschiedenen Themen-Boards ausgewählt sind:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/azwgqsc0/10-update-selected-topics-from-multiple-boards.png)

Wenn Themen aus mehreren Boards ausgewählt sind, können Status und Typ nicht aktualisiert werden. Die wählbaren Benutzer in "Zugewiesen an" und "Anforderer" sind auch auf die Benutzer beschränkt, die Zugriff auf alle Themen-Boards der ausgewählten Themen haben.

**Speichern** Klicken Sie auf "Speichern", um die Änderungen zu übernehmen.

**Anforderung für Batch-Update-Zugriff** Es ist nur möglich, Themen als Batch zu aktualisieren, wenn ein Benutzer Schreibzugriff auf das Themen-Board hat. _Erforderlicher Zugriff:_ Schreibzugriff auf das Themen-Board für jedes der ausgewählten Themen.

### 4.3 **Zugriffskontrolle für Themen-Board**

Wenn alle ausgewählten Themen aus demselben Themen-Board stammen, können Sie die Zugriffskontrolle dieses Boards in diesem Menü anzeigen, ohne zu den Einstellungen des Themen-Boards wechseln zu müssen.

**Zugriff konfigurieren** Klicken Sie auf "Zugriff konfigurieren", um den Zugriff auf das Themen-Board zu bearbeiten, in dem sich die ausgewählten Themen befinden. _Erforderlicher Zugriff:_ Administrator

> **Hinweis:** Der Zugriff auf das Board spiegelt den Zugriff auf die ausgewählten Themen wider, aber in diesem Menü wird der Zugriff auf das gesamte Board angezeigt, in dem sich die Themen befinden, und nicht nur auf die ausgewählten Themen selbst.
