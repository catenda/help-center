# Seite "Projekte" - Organisationstool

Sie finden die Seite "Projekte" als Unterseite auf Ihrer [Organisationsprofilseite](https://support.catenda.com/en/articles/8497478-organization-profile-page).

Hier erhalten Sie einen Überblick über alle Projekte, die Teil dieser Organisation sind.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9sr2253p/01-intro.png)

## 1. Suchen und Filtern

Auf der Seite "Projekte" können Sie nach Folgendem filtern:

### 1.1 Leere Filter ausblenden

Die Schaltfläche "Leere Filter ausblenden" ist standardmäßig deaktiviert, d. h. Sie sehen alle verfügbaren Filter.

Sie können diese Filterschaltfläche aktivieren, um alle Filter auszublenden, die keine Ergebnisse haben.

### 1.2 Erstellt - createdAtFrom=\<UTC timestamp>&createdAtTo=\<UTC timestamp>

Projekte, die zwischen zwei von Ihnen gewählten Daten erstellt wurden

### 1.3 Abgelaufen - expiration=expired

Projekte, deren Ablaufdatum überschritten wurde.

### 1.4 Nicht abgelaufen - expiration=not-expired

Projekte, die nicht abgelaufen sind.

## 2. Aktionsschaltflächen

Nachdem Sie ein oder mehrere Projekt(e) in der Projektliste ausgewählt haben, indem Sie auf das Kontrollkästchen klicken, werden die folgenden Aktionsschaltflächen oben in der Projektliste angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9sr2253p/02-action-buttons.png)

### 2.1 Neue Mitglieder hinzufügen

Wenn der Benutzer, den Sie hinzufügen möchten, ein Mitglied Ihrer Organisation ist, können Sie das Mitglied ohne E-Mail-Einladung zu einem Projekt hinzufügen.

Eine Übersicht der Mitglieder Ihrer Organisation finden Sie auf der Benutzerseite im Organisationstool.

Im Menü "Neue Mitglieder hinzufügen" können Sie auch externe Benutzer per E-Mail-Adresse einladen, ohne Teil des Projekts zu sein.

Wenn Sie ein Organisationsmitglied zu mehreren Projekten hinzufügen möchten, können Sie dies auch tun, indem Sie den Benutzer auf der Benutzerseite auswählen und im Aktionsmenü auf dieser Seite auf die Aktion "Zu Projekten hinzufügen" klicken.

### 2.2 Verschieben

Verschieben Sie die ausgewählten Projekt(e) in eine andere Organisation

### 2.3 Beitreten

Werden Sie Teil der ausgewählten Projekt(e)

### 2.4 Verlassen

Verlassen Sie die ausgewählten Projekt(e)

### 2.5 Löschen

Löschen Sie die ausgewählten Projekt(e)

## 3. Projektliste

In der Projektliste können Sie die folgenden Spalten finden, die Sie in auf- und absteigender Reihenfolge sortieren können.

Die Sortierreihenfolge der Projektliste folgt der [Sortierreihenfolge von Listen](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists) bei Catenda.

Klicken Sie auf das Kontrollkästchen oben links in der Liste, um alle Projekte auszuwählen.

### 3.1 Kontrollkästchen

Aktivieren Sie das Kontrollkästchen eines Projekts, um es auszuwählen.

Nach der Auswahl eines Projekts wird das Aktionsmenü oben in der Liste angezeigt.

Es ist nicht möglich, abgelaufene Projekte auszuwählen.

### 3.2 Name

Der Name des Projekts

Wenn das Projekt nicht abgelaufen ist, wird neben dem Namen ein Symbol zum Öffnen in einem neuen Tab angezeigt.

**Mitglied**

Unter dem Namen können Sie sehen, wie viele Benutzer Mitglieder dieses Projekts sind und ob Sie ein Mitglied dieses Projekts sind oder nicht.

### 3.3 Zuletzt aktualisiert

Der Zeitpunkt und das Datum der letzten Aktualisierung des Projekts

### 3.4 Erstellt

Der Zeitpunkt und das Datum der Projekterstellung

### 3.5 Läuft ab

Der Zeitpunkt und das Datum, zu dem das Projekt abläuft.

Wenn dies rot ist, bedeutet das, dass das Projekt abgelaufen ist.
