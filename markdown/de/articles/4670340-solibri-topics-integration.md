# Solibri Topics-Integration

> **Wichtig:** **Solibri Version 9.13:** **Wichtig:** Das BCF Connector-Plugin ist seit Version 9.13 ein separater Tab namens BCF Live Connector in Solibri. Viele der gleichen Informationen gelten weiterhin für diesen Tab. **Solibri Version 9.9:** Seit Update 9.9 von Solibri ist es nun möglich, Ihre Topics mit Catenda zu synchronisieren.

Dieses Dokument erläutert, wie Sie den BCF Connector mit Ihrem Catenda-Projekt einrichten. Dies ermöglicht es, Topics nahtlos zwischen den beiden Anwendungen auszutauschen und vermeidet die manuellen BCF-Export- und -Importschritte.

1\) Kaufen und laden Sie Solibri Model Checker aus dem Solibri Solution Center herunter. Falls Sie das Tool bereits haben, denken Sie daran, es zu aktualisieren.

2\) Sie können den BCF Connector aus dem Solibri Solution Center beziehen/aktualisieren - [https://solution.Solibri.com/application/#!ProductsView](https://solution.solibri.com/application/#!ProductsView)

Gehen Sie zu Solibri Extensions und wählen Sie BCF Connector

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/01-intro.png)

> **Hinweis:** Um den BCF Connector zu aktivieren, muss Ihr Solibri-Administrator ihn im Benutzerverwaltungsbildschirm des Solibri Solution Centers aktivieren.

3\) Öffnen Sie SMC und gehen Sie zum Bildschirm Einstellungen. Wählen Sie von dort den BCF Connector

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/02-intro.png)

4\) Server hinzufügen

1. Drücken Sie zunächst die Schaltfläche Server hinzufügen und Sie werden zur zweiten Seite weitergeleitet.
1. In diesem Schritt können Sie wählen, mit welchem Server Sie sich verbinden möchten, in diesem Fall mit Catenda.
1. Hier können Sie die URL aus Ihrem Catenda-Projekt einfügen. Wo Sie diese URL finden, wird im nächsten Bild erläutert.
1. OK, um die Verbindung abzuschließen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/03-intro.png)

6\) Auf der Topics-Seite in Ihrem Catenda-Projekt können Sie die URL für Ihr Projekt finden. Sie befindet sich in den Exchange Topics.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/04-intro.png)

7\) Gehen Sie dann zum Kommunikationsbildschirm in Solibri und wählen Sie Präsentationen. Von dort aus können Sie eine neue Präsentation erstellen. Klicken Sie mit der rechten Maustaste auf das Kontextmenü, um die Synchronisierung mit Catenda durchführen zu können.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/05-intro.png)

8\) Von hier aus können Sie auch eine neue Präsentation erstellen und von Catenda in Solibri importieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/06-intro.png)

Um Ihren Workflow mit dem BCF Server zu optimieren, [siehe hier](https://support.bimsync.com/hc/en-us/articles/360011987619)
