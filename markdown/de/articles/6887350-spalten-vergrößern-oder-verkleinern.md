# Spalten vergrößern oder verkleinern

Sie wissen, dass Sie eine Spalte vergrößern oder verkleinern, wenn Sie ein hellgraues Feld sehen, das an der Linie zwischen zwei Kopfzeilen hängt. Wenn Sie Ihre Maus über die Linie zwischen zwei Spaltenkopfzeilen bewegen, können Sie ziehen, um die Breite einer Spalte zu ändern.

**Cursorbeschriftung:** Sie befinden sich an der richtigen Stelle, wenn sich Ihr Cursor in einen Größeänderungszeiger ändert

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dysbq1me/01-intro.png)

**Doppelklick:** Wenn Sie auf den Ziehpunkt doppelklicken, wird die Spalte automatisch auf die Größe ihres Inhalts erweitert.
