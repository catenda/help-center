# BCF-Arbeitsablauf mit Markup-Tool in Archicad

**BCF von Archicad zu Bimsync** Wählen Sie in Archicad das Markup-Tool aus, um ein BCF zu erstellen. Hier können Sie das zugehörige Element hervorheben und verschiedene Ansichten an das BCF anhängen usw. Exportieren Sie die ausgewählten Markup-Einträge als bcfzip-Datei.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/01-intro.png)

Gehen Sie zu Probleme und Probleme austauschen, um das BCF hochzuladen. Importieren Sie das BCF und wählen Sie das gespeicherte BCF aus Archicad aus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/02-intro.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/03-intro.png)

Das BCF wird nun in den Abschnitt "Probleme" geladen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/04-intro.png)

Sie können dann die verschiedenen Einstellungen im Problem ändern, indem Sie darauf klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/05-intro.png)

**BCF von Bimsync zu Archicad** Filtern Sie das Problem heraus, das Sie abrufen möchten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/06-intro.png)

Exportieren Sie das gefilterte Problem.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/07-intro.png)

Laden Sie das ausgewählte BCF herunter. Die Datei wird als bcfzip-Datei ausgegeben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/08-intro.png)

Gehen Sie zum Markup-Tool in Archicad und importieren Sie das BCF über die Importfunktion für Markup-Einträge. Das ausgewählte BCF wird in der Markup-Symbolleiste angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/09-intro.png)
