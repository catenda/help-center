# Filterergebnisse begrenzen

Wenn Sie einen Satz von Filtern häufig verwenden, können Sie diese oben in der Filterleiste speichern. Jedes Mal, wenn Sie zu einer Seite navigieren, werden die Standardfilter angezeigt. Es kann mühsam sein, jedes Mal nach den richtigen Filtern zu filtern. Mit gespeicherten Filtern können Sie ganz einfach mit einem Klick nach einem Satz von Filtern suchen, ohne sie jedes Mal eingeben zu müssen.

## 1. **Filtererscheinung**

**Einrückung** Wenn Filter zusammen gruppiert sind, werden sie oft unter einem Hauptschalter mit nach rechts eingerückten Optionen angezeigt. Der Hauptschalter aktiviert und deaktiviert alle Filter dieses Typs. Um alle Filter dieses Typs zu deaktivieren, fügen Sie zunächst alle verbleibenden Optionen zum Filter hinzu, damit alle angewendet werden, und schalten Sie dann den Hauptfilter aus, um alle zu deaktivieren.

**Umschalter** Aktivieren Sie die Filter-Umschalter, um die Suche einzugrenzen. Ein quadratischer Schalter bedeutet, dass mehrere Filter dieses Typs angewendet werden können. Ein runder Schalter bedeutet, dass nur ein Filter dieses Typs angewendet werden kann.

## 2. **Leere Filter ausblenden**

Die Schaltfläche „Leere Filter ausblenden

_Zeilenergebnisse, die durch Filter begrenzt werden_ Filter, die in einer Tabelle angewendet werden, grenzen die resultierenden Zeilen ein. Wenn der Schalter eingeschaltet ist, zeigt das Filtermenü nun Filteroptionen an, die auf die Zeilen im gefilterten Ergebnis zutreffen. Es scheint, dass einige Filteroptionen, die zuvor verfügbar waren, weil sie auf Zeilen zutreffen, die sich nicht mehr in den Suchergebnissen befinden, verschwinden, aber es ist einfach eine Eingrenzung der Optionen. Um auch Filter zu sehen, die nicht auf die gefilterten Ergebnisse zutreffen, schalten Sie die Schaltfläche „Leere Filter ausblenden

## 3. **Speichern eines neuen Satzes von Filtern**

Um einen Filter zu speichern, müssen Sie mindestens einen Filter aktiviert haben. Wenn Sie einen Satz von Filtern aktiviert haben, klicken Sie auf die Schaltfläche Speichern, um den aktuellen Filter zu speichern. Dieser Filter ist das nächste Mal verfügbar, wenn Sie Catenda Hub verwenden, und ist für andere Benutzer nicht sichtbar.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y0zwxw2k/01-saving-a-new-set-of-filters.png)

Gespeicherte Filter sind nur für Sie sichtbar und nicht für andere Mitglieder des Projekts.

## 4. **Bearbeitung gespeicherter Filter**

Nachdem Sie einen Filter gespeichert haben, können Sie auf Bearbeiten klicken, um Ihre gespeicherten Filter zu bearbeiten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y0zwxw2k/02-editing-saved-filters.png)

Im Bearbeitungsmodus können Sie: Den Namen des Filters bearbeiten - Stift Aktualisieren Sie den Filter mit dem aktuellen Filter - Aktualisierungssymbol Löschen Sie den Filter - Papierkorbsymbol.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y0zwxw2k/03-editing-saved-filters.png)

Denken Sie daran, auf Fertig oben rechts zu klicken, wenn Sie fertig sind.

## 5. **Aktivierung eines gespeicherten Filters**

Um nach dem Satz gespeicherter Filter zu filtern, klicken Sie einfach auf Ihren gespeicherten Filter im Filtermenü auf der linken Seite und Sie sehen die Filter in der Suchleiste angezeigt.

## 6. **Austausch gespeicherter Filter mit Projektmitgliedern**

Wie bereits erwähnt, werden gespeicherte Filter nur für Sie gespeichert. Wenn Sie den Filter aktivieren, sehen Sie die Filter in der Suchleiste angezeigt. Wenn Sie dies tun, ändert sich auch die URL der Seite, um die Filter zu enthalten. Eine einfache Möglichkeit, Ihre gespeicherten Filter mit Benutzern zu teilen, ist daher das Versenden der gefilterten Seite in einer Nachricht oder über [Sharelink](https://support.catenda.com/en/articles/4728886-sharelink-notify-people-about-catenda-hub-content). Wenn Sie möchten, dass Personen im Projekt Zugriff auf diese Filter haben, ohne sie einzeln an jedes Mitglied senden zu müssen, können Sie einen Link in der [Links-Bibliothek](https://support.catenda.com/en/articles/4670254-links-library) erstellen. Dies ist besonders nützlich, da der Link mit den Filtern dann mit Themen und Objekten verlinkt werden kann.

## 7. **Voreinstellung zum Erweitern und Zurückziehen von Filtern**

Ihre Einstellungen zum Erweitern und Zurückziehen von Filtermenüs auf verschiedenen Seiten werden projektübergreifend angewendet und in den Cookies Ihres Browsers gespeichert. Wenn Sie beispielsweise zwei Projekte im selben Browser geöffnet haben und das Menü Etiketten auf der Seite Themen in einem Projekt zurückziehen, wird dieses Menü auch zurückgezogen, wenn Sie die Seite Themen des anderen Projekts aktualisieren.
