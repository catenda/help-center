# Geschosskonfigurator-Seite

> So haben Sie eine PDF als Überlagerung in Ihrer 2D-Ansicht

Durch das Konfigurieren von Geschossen können in einem Projekt vorbereitete Ansichten im [2D-Viewer](https://support.catenda.com/en/articles/4854537-2d-viewer) für Projektmitglieder erstellt werden. Die Geschosskonfiguratorseite befindet sich als Unterseite der [Modellseite](https://support.catenda.com/en/articles/4670286-models-page). Die Begriffe Geschoss und Gebäude stammen aus dem IFC-Standard. Während die Begriffe Geschoss und Gebäude in der Sozialinfrastruktur häufiger verwendet werden, ist dieses Tool für physische oder digitale Infrastrukturprojekte ebenso nützlich, wenn nicht sogar nützlicher. _Erforderlicher Zugriff:_ Projektadministrator

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/01-intro.png)

In einem Projekt können Mitglieder Geschosse zusammenstellen, indem sie 2D-Ansichten mit generierter Geometrie aus verschiedenen im Projekt verfügbaren Modellen ein- und ausschalten. Konfigurieren Sie ein Geschoss, um ein konfiguriertes Geschoss mit generierten 2D-Ansichten aus einer Reihe von Modellen verfügbar zu machen für Mitglieder im Projekt. Unterlagern Sie ein PDF-Dokument in einem Geschoss, um Linienzeichnungen anzuzeigen, die in der generierten Geometrie aus dem Modell sonst möglicherweise nicht sichtbar sind.

So kann die Geschosskonfiguratorseite in einem neuen Projekt aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/02-intro.png)

So kann ein konfiguriertes Geschoss mit einer untergelegten Zeichnung aussehen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/03-intro.png)

## 1. **Aktionen**

Das Aktionsmenü auf der Geschosskonfiguratorseite kann durch Öffnen der drei Punkte rechts neben der grünen Plus-Schaltfläche oben rechts gefunden werden.

![Neues Gebäude hinzufügen](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/04-actions.png)

### 1.1 **Neues Gebäude hinzufügen**

Klicken Sie [hier](https://support.catenda.com/en/articles/12291366-storey-configurator-actions), um mehr über das Hinzufügen eines neuen Gebäudes zu erfahren.

### 1.2 **PDF**

Um die Schritte in diesem Artikel abzuschließen, benötigen Sie einen PDF-Plan für jedes Geschoss, bei dem Sie eine PDF-Unterlagerung wünschen.

> **Hinweis:** Jedes Geschoss muss sich in einem separaten PDF befinden. Ein Geschoss kann mehrere PDFs haben

## 2. **Einrichtung**

Stellen Sie Ihre Ansicht so ein, dass Sie Ihr 2D-Modell und alle Ihre Modelle sehen können.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/05-setup.png)

## 3. **Geschosskonfiguration**

Hier richten Sie Ihren PDF-Plan mit Ihrer 2D-Ansicht aus. Dies muss für jedes Geschoss einmal durchgeführt werden.

Standardmäßig haben Sie ein Gebäude in Ihrer Übersicht. Dies enthält auch die Ebenen des importierten IFC.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/06-storey-configuration.png)

Das Festlegen eines Namens für das Gebäude ist wichtig, da dieser später angezeigt wird. Wählen Sie daher etwas Aussagekräftiges.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/07-storey-configuration.png)

Jede IFC-Ebene wird in einem Geschoss dargestellt. Hier können Sie den Namen und die Höhe einstellen.

> **Hinweis:** Das Ändern der Höhe ändert die Darstellung Ihrer 2D-Ansicht.

Innerhalb des Geschosses können Sie die Überlagerung einstellen, klicken Sie auf „Zusätzliche Optionen anzeigen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/08-storey-configuration.png)

Hier sehen Sie die Funktion „An das Geschoss angehängte Zeichnungen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/09-storey-configuration.png)

Ein Dialog wird geöffnet und fragt Sie nach der hochgeladenen PDF-Datei.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/10-storey-configuration.png)

Wenn Sie die gewünschte PDF ausgewählt haben, klicken Sie auf „Dieses Dokument hinzufügen.

## 4. **Ausrichtungsdialog**

Hier legen Sie die Überlagerung fest und positionieren sie.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/11-alignment-dialogue.png)

Ihr Gebäude sollte jetzt ausgewählt sein. Sie müssen lediglich das Geschoss auswählen, mit dem Sie Ihre Zeichnung ausrichten möchten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/12-alignment-dialogue.png)

Jetzt sollten Sie die ausgewählte PDF und das ausgewählte Geschoss auf Ihrem Bildschirm sehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/13-alignment-dialogue.png)

Mit Markierung A und B bestimmen Sie die Position der Überlagerung. Die Punkte, die Sie auswählen, müssen übereinstimmen. Wählen Sie am besten beispielsweise den Schnittpunkt zweier Gitter.

Verwenden Sie die Markierung über Drag & Drop, um sie zu positionieren. Sie können auch durch Scrollen in der Zeichnung zoomen.

Nachdem Sie diese platziert haben, klicken Sie auf „Weiter: Ergebnis bestätigen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/14-alignment-dialogue.png)

### 4.1 **Genehmigungsdialog**

Nach dem Bestätigen der Position der Markierungen wird das Genehmigungsdialog geöffnet. Hier können Sie sich die Überlagerung ansehen, um zu sehen, ob sie für Sie funktioniert.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/15-approve-dialogue.png)

Hier kann jederzeit eine Änderung vorgenommen werden, indem Sie auf „Zurück: Modell- und Zeichnungspunkte positionieren

Dies bringt Sie zurück zum Geschosskonfigurator, und Sie können jetzt das nächste Geschoss einrichten. Die Platzierung von Zeichnungen kann auch in diesem Dialog geändert werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/16-approve-dialogue.png)

**Wichtig:** Hier müssen Sie auf „Konfiguration speichern

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/17-approve-dialogue.png)

## 5. **So verwenden Sie es**

Da nun alles eingerichtet ist, können Sie es in Ihrer täglichen Arbeit verwenden. Nachdem Ihre Gebäudekonfiguration verarbeitet wurde, können Sie die Seite aktualisieren. Wenn Sie sich in Ihrer Modellansicht befinden und die 2D-Ansicht öffnen, besteht die Möglichkeit, das Gebäude auszuwählen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/18-how-to-use-it.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/19-how-to-use-it.png)

Wählen Sie das gerade umbenannte Gebäude

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/20-how-to-use-it.png)

Und Ihre PDF-Überlagerung wird sichtbar.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hn8gfwtp/21-how-to-use-it.png)

Der Geschosskonfigurator zeigt immer die neueste Version der ausgerichteten Zeichnung(en)
