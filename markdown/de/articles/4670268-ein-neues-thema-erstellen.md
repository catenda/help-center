# Ein neues Thema erstellen

> Dies beschreibt alle Schritte zur Erstellung eines Themas

Ein neues Thema kann vom Themen-Bildschirm oder vom Dashboard-Themen-Viewer aus erstellt werden. Um ein neues Thema zu erstellen, klicken Sie auf die Schaltfläche "Neues Thema" oben rechts auf dem Bildschirm. Dies öffnet das Fenster Neues Thema.

So kann die Seite zur Erstellung neuer Themen aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/01-intro.png)

Auf dieser Seite finden Sie Informationen zu folgendem:

## 1. Obere Leiste

Klicken Sie auf "Zurück zu Themen", um zum zuletzt besuchten Themen-Board zurückzukehren.

## 2. Kopfzeile

So kann die Themen-Kopfzeile aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/02-2-header.png)

### 2.1 Titel

Geben Sie den Titel/Betreff ein. Dies ist normalerweise das Einzige, das erforderlich ist, um das Thema einzureichen.

### 2.2 Themen-Board

Es gibt verschiedene Themen-Board-Listen, aus denen Sie wählen können, und diese unterscheiden sich von Projekt zu Projekt.

### 2.3 Status

Sie können zwischen "Offen" oder "Geschlossen" wählen. Normalerweise wählen Sie "Offen", wenn Sie ein neues Thema erstellen.

### 2.4 Typ

Hier wählen Sie den Typ des Themas, das Sie erstellen. Die Typen, zwischen denen Sie wählen können, sind "Fehler", "Warnung", "Info" und "Unbekannt". Dies sind die Standardtypen, Sie können aber auch Ihre eigenen Typen erstellen.

### 2.5 Standort

2D-Markierung hinzufügen

### 2.6 Fälligkeitsdatum

Legen Sie ein Fälligkeitsdatum fest oder lassen Sie es leer. Es wird empfohlen, ein Fälligkeitsdatum hinzuzufügen, auch wenn Sie den genauen Zeitrahmen des Themas nicht kennen. Dies gewöhnt Sie daran, Fälligkeitsdaten festzulegen. Jede Information kann hilfreich sein für das Projekt. Das Fälligkeitsdatum kann später jederzeit geändert werden.

### 2.7 Meilenstein

Heften Sie es an einen Meilenstein an oder lassen Sie es leer. Dies kann helfen, nachzuverfolgen, wie viele Themen vor einem Projekttermin bearbeitet wurden.

### 2.8 Verantwortung

**Zugewiesen** Hier können Sie das Thema einem bestimmten Mitglied oder einem Team zuweisen. Es wird empfohlen, ein Mitglied als Verantwortliche Person anstelle eines Teams festzulegen, da gemeinsame Verantwortung dazu führt, dass sich keines der Teammitglieder persönlich verantwortlich fühlt. Wenn Sie andere Teammitglieder trotzdem wissen lassen möchten, dass ihr Team verantwortlich ist, können Sie member@team festlegen. Wenn ein Mitglied als Verantwortliche Person festgelegt ist, folgt es dem Thema automatisch. Wenn ein Team als Verantwortliche Person festgelegt ist, folgen die Teammitglieder dem Thema nicht automatisch.

**Angefordert von** Hier können Sie das Mitglied oder Team festlegen, das das Thema anfordert. Sie werden standardmäßig als Anforderer festgelegt, können aber hier jedes beliebige Mitglied auswählen. Wenn ein Mitglied als Anforderer festgelegt ist, folgt es dem Thema automatisch. Wenn ein Team als Anforderer festgelegt ist, folgen die Teammitglieder dem Thema nicht automatisch.

### 2.9 Etiketten

Fügen Sie relevante Etiketten für das Thema hinzu oder erstellen Sie ein neues Etikett. Ein neu erstelltes Etikett wird erst nach der Übermittlung des Themas mit dem Projekt geteilt.

### 2.10 Benutzerdefinierte Felder

Wenn benutzerdefinierte Felder zum Themen-Board hinzugefügt wurden, auf dem das Thema erstellt wird, werden möglicherweise Dropdown-, Text- oder Integer-Felder angezeigt. Wenn das Feld eine rote Fehlermeldung hat, bedeutet dies, dass das Feld als erforderlich festgelegt ist und Sie etwas eingeben müssen, um das Thema einreichen zu können.

## 3. Rechtes Informationsfeld

So kann das rechte Informationsfeld aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/03-3-right-information-panel.png)

### 3.1 Dokumente

Klicken Sie [hier](https://support.catenda.com/en/articles/4670250-linking-a-document-to-an-issue), um zu erfahren, wie Sie ein Dokument mit einem Thema verknüpfen.

## 4. Text

So kann der Textkörper eines Themas aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/04-4-body.png)

### 4.1 Beschreibung

Fügen Sie eine Beschreibung für das Thema hinzu. Kennzeichnen Sie Personen, die in die Diskussion einbezogen werden sollen, mit @. In der Symbolleiste darunter finden Sie verschiedene Optionen, zum Beispiel: [Checklisten in Themen](https://intercom.help/bimsync-arena/en/articles/5036461-check-lists-within-issues)

### 4.2 Kommentar

Das Textfeld neben der Schaltfläche "Hinzufügen" dient zum Schreiben eines Kommentars. Erwähnen Sie Personen, indem Sie @name eingeben, oder verknüpfen Sie andere Themen, indem Sie #link eingeben.

### 4.3 Anlage

**Schaltfläche "Hinzufügen"** Durch Klicken auf die Schaltfläche "Hinzufügen" können Sie einen 2D/3D-Schnappschuss oder ein Bild von Ihrer Festplatte hinzufügen.

Der 2D/3D-Schnappschuss stammt aus dem neuesten Kamerawinkel im 3D/2D-Viewer. Durch Öffnen der 3D-Schaltfläche im Navigations-Viewer. Sie können sich durch das Modell zum fraglichen Thema navigieren, die Schaltfläche "Hinzufügen" drücken, den 2D/3D-Schnappschuss auswählen und der Schnappschuss wird angezeigt.

**Schnappschuss** Wenn Sie die 2D-Ansicht eines Modells geladen haben, wird automatisch ein 2D-Schnappschuss Ihrer aktuellen 2D-Ansicht hinzugefügt. Wenn Sie die 3D-Ansicht eines Modells geladen haben, wird automatisch ein 3D-Schnappschuss Ihrer aktuellen Kameraposition hinzugefügt. Wenn Sie beim Einreichen des Themas 3D-Objekte im 3D-Schnappschuss ausgewählt haben, werden diese Objekte mit dem Thema verknüpft. Sie können Schnappschüsse vor dem Einreichen entfernen, aktualisieren oder neue hinzufügen.

Wenn Sie auf den Schnappschuss klicken, den Sie aufgenommen haben, haben Sie die Möglichkeit, Anmerkungen zum Bild hinzuzufügen. Unter dem Bild wird eine Symbolleiste mit Tools angezeigt, um den bestimmten Punkt des Themas genauer zu zeichnen.

> **Hinweis:** Wenn Sie ein mobiles Gerät verwenden, können Sie entweder ein gespeichertes Bild verwenden oder ein neues mit der integrierten Kamera aufnehmen. _Alle Bildschirme sind dynamisch ("responsiv") und passen sich an die Bildschirmgröße des verwendeten Geräts an._

### 4.4 Einreichen

**Offen halten zum Einreichen** Aktivieren Sie dieses Kontrollkästchen, wenn Sie sofort ein weiteres Thema erstellen möchten.

**Einreichen** Wenn Sie alle relevanten Informationen für das Thema ausgewählt haben, klicken Sie rechts unten auf "Einreichen". Die Mindestinformation, die erforderlich ist, um ein Thema einzureichen, ist der Titel.
