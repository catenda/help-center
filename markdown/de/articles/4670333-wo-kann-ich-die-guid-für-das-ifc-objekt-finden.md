# Wo kann ich die GUID für das IFC-Objekt finden?

Um die GUID eines Objekts zu finden, öffnen Sie zunächst ein Modell im 3D-Viewer und öffnen Sie das Inspektionstool. Wählen Sie ein Objekt aus. In der oberen rechten Ecke des Segments "Identifikation" befindet sich eine Schaltfläche. Drücken Sie diese und es werden weitere Informationen zum Objekt angezeigt, einschließlich der GUID.
