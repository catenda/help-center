# 3D-Viewer

Den 3D-Viewer finden Sie als eines der vier Hauptfenster, die oben rechts auf Ihrem Bildschirm geöffnet werden können. Sie können entweder auf das 3D-Symbol klicken, um dieses Fenster zu öffnen, oder Sie können [Umschalt+2](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=3D%20viewer-,Shift%20%2B%202,-Trees%20panel) drücken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/01-intro.png)

Mit einem geladenen Modell kann der 3D-Viewer so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/02-intro.png)

## 1. **Modelle laden**

Modelle können auf mehrere Arten in den 3D-Viewer geladen werden. Auf der Modellseite kann neben dem zu öffnenden Modell auf 3D geklickt werden, oder es können mehrere Modelle ausgewählt und oben in der Liste auf 3D geklickt werden. Im Dokumentbereich können Sie Vorschauen von IFC-Dateien und Point-Cloud-Dokumenten öffnen, indem Sie in der Dokumentlistenansicht oder im rechten Informationsfenster auf 3D klicken. Sie können den 3D-Viewer auch öffnen, ohne Modelle zu laden, indem Sie oben rechts auf 3D klicken, um das 3D-Viewer-Fenster zu öffnen.

### 1.1 **Revisionsselector**

Wenn Sie noch keine Modelle geladen haben, können Sie Modelle laden und entladen, indem Sie die Dropdown-Liste des Revisionselektors öffnen. Klicken Sie [hier](https://support.catenda.com/en/articles/4670279-revision-selector), um mehr über den Revisionsselector zu erfahren

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/03-revision-selector.png)

### 1.2 **Gitter-Dropdown**

Wenn es in Ihren Projekten Modelle gibt, die Gitter enthalten, können Sie diese über diese Dropdown-Liste in den Viewer laden. Klicken Sie [hier](https://support.catenda.com/en/articles/4670327-showing-grids), um mehr über Gitter im 3D-Viewer zu erfahren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/04-grid-dropdown.png)

## 2. **Sichtbarkeit**

Mit der Sichtbarkeitsliste können Sie Objekte anzeigen, ausblenden und durchsichtig machen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/05-visibility.png)

Wenn Sie die Sichtbarkeitsliste öffnen, kann es so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/06-visibility.png)

Hier können Sie die folgenden Aktionen ausführen:

### 2.1 **Objekte anzeigen**

**Alle anzeigen** Alle Objekt(e) anzeigen Dies kann nützlich sein, nachdem Sie einen Schnappschuss oder ein Lesezeichen wiedergegeben haben, das Geometrie verborgen hat, die Sie sehen möchten.

**Ausgewählte anzeigen** Das ausgewählte Objekt anzeigen Wenn Sie ein ausgewähltes Objekt ausgeblendet haben, ist es immer noch ausgewählt, aber verborgen, bis Sie etwas anderes auswählen und es aus Ihrer Auswahl entfernen. Im Informationsfenster können Sie verborgene Objekte aus dem Objektbaum und über Auswahl auswählen. Im Inhaltsfenster können Sie Objekte aus Eigenschaftsbibliotheken und Objekte auswählen, die mit Problemen oder Dokumenten verknüpft sind.

### 2.2 **Objektdurchsichtigkeit**

Es ist nicht möglich, durchsichtige Objekte anzuwählen, indem man im 3D-Viewer darauf klickt.

**Durchsichtig machen** Das ausgewählte Objekt durchsichtig machen Im Informationsfenster können Sie verborgene Objekte aus dem Objektbaum und über Auswahl auswählen. Im Inhaltsfenster können Sie Objekte aus Eigenschaftsbibliotheken und Objekte auswählen, die mit Problemen oder Dokumenten verknüpft sind. Ausgewählte durchsichtige Objekte können durch Anzeigen ausgewählter oder Anzeigen aller wieder auf Standardsichtbarkeit zurückgesetzt werden.

**Objekte halbtransparent machen** Macht alles außer das/die ausgewählte Objekt(e) halbtransparent Klicken Sie auf "Alle anzeigen", um die Objekte auf die Standardsichtbarkeit zurückzusetzen.

### 2.3 **Objekte ausblenden**

Verborgene Objekt(e) werden weiterhin im Speicher des Systems geladen.

**Ausblenden** Blendet ein Objekt aus dem Viewer aus

**Andere ausblenden** Alle Objekte außer dem ausgewählten ausblenden Dies ist ähnlich wie das Isolieren von Objekten. Die verborgenen Objekte werden weiterhin im Speicher geladen.

## 3. **Kameraoptionen**

Mit dem Kameraoptionen-Dropdown können Sie Ansichtspunkte, Kameratypen und Ansichten auswählen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/07-br-camera-options.png)

### 3.1 **Ansichtspunkt**

So kann das Ansichtspunkt-Menü aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/08-viewpoint.png)

_Startseite_ - Setzen Sie den Viewer auf die Standardposition zurück Dies kann einen Überblick über alle im Viewer geladenen Modelle geben.

Die folgenden Ansichten ermöglichen es Ihnen, das Modell von verschiedenen Seiten zu sehen:

**Zurück** Zeigen Sie das Modell von hinten

**Links** Zeigen Sie das Modell von links

**Front** Zeigen Sie das Modell von vorne

**Rechts** Zeigen Sie das Modell von rechts Diese Ansichten können hervorragend zum Erstellen von Schnitten durch Erstellen vertikaler Schnittebenen verwendet werden.

**Oben** Zeigen Sie das Modell von oben Diese Ansicht kann hervorragend zum Erstellen von Grundrissen durch Erstellen einer horizontalen Schnittebene verwendet werden.

### 3.2 **Kameratyp**

So kann das Kameratyp-Menü aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/09-camera-type.png)

_Perspektive_ - Standard Ermöglicht es Ihnen, das Modell so zu sehen, wie es ein Mensch tut. Dieser Kameratyp ist großartig, um zu verstehen, wie es sich anfühlen könnte, im Modell zu sein. Da sich die Kamera im menschlichen Auge befindet, können Sie durch Wände schneiden. Das Sichtfeld für den Perspektivkameratyp kann in den Viewer-Einstellungen angepasst werden.

**Orthografisch** Ermöglicht es Ihnen, das Modell so zu sehen, als wären Sie unendlich weit weg. Dieser Kameratyp ist großartig zum Planen, da Entfernungen leichter zu beurteilen sind. Da sich die Kamera unendlich weit weg befindet, kann sie nicht durch Objekte schneiden und Sie müssen Objekte ausblenden oder transparent machen, um zu sehen, was dahinter ist.

### 3.3 **Ansicht**

So kann das Ansichtsmenü aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/10-view.png)

> **Hinweis:** Stellen Sie sicher, dass die Hardware und Software, auf der Catenda geöffnet ist, [wie empfohlen](https://support.catenda.com/en/articles/6921941-hardware-recommendation) konfiguriert ist, da dies sich auf die Anzeige des Viewers auswirken kann.

**Regulär** Standardmäßig ist die reguläre Ansicht ausgewählt. Dünne Linien für präzise Objektanzeige. Großartig für Messungen.

Wenn keine Farbe für ein Objekt in der IFC definiert ist, wird dem Objekt basierend auf der für das Objekt konfigurierten Entität eine Farbe zugewiesen. Die Entität finden Sie im Inspektionsmenü des Informationsfensters.

Da es im Catenda Viewer keine Sonne oder künstliches Licht gibt, werfen Objekte keinen Schatten aufeinander. Oberflächen werden durch ihre flache Farbe dargestellt, verdunkelt je nachdem, ob die Kamera direkt auf sie schaut oder ob die Oberfläche von der Kamera abgewinkelt ist.

**Kontur** Cell Shading verwandelt Linien an Ecken mit Winkeln, die von Ihnen weg zeigen, in dickere Linien, während Linien an Ecken, die zu Ihnen zeigen, dünner werden. Dies erzeugt eine zusätzliche Tiefenebene, aber die dicken Linien könnten genaue Messungen verdecken. Kontur ist eine großartige Ansicht zum Exportieren von Bildern.

> **Hinweis:** Stellen Sie sicher, dass die Hardware und Software, auf der Catenda geöffnet ist, [wie empfohlen](https://support.catenda.com/en/articles/6921941-hardware-recommendation) konfiguriert ist, da dies beeinflussen kann, wie scharf die Linien aussehen.

**Skizze** Großartig für Treffen mit externen Parteien, die eine einfache Anzeige des Modells benötigen. Objekte ohne im IFC angegebene Farbe werden in Grautönen und mit einer Textur gefärbt, damit die Oberflächen nicht so perfekt flach aussehen. Fenster behalten ihre gewöhnliche durchsichtige blaue Farbe.

> **Hinweis:** Stellen Sie sicher, dass die Hardware und Software, auf der Catenda geöffnet ist, [wie empfohlen](https://support.catenda.com/en/articles/6921941-hardware-recommendation) konfiguriert ist, da dies beeinflussen kann, wie scharf die Linien aussehen.

## 5. **Joystick-Funktion**

Wenn Sie auf diese Schaltfläche klicken, wird der Joystick auf dem Bildschirm angezeigt. Der Joystick ermöglicht es Ihnen, reibungslos durch das Modell im Perspektivmodus zu fliegen und in orthografischem Modus um einen zentralen Punkt zu rotieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/13-joystick.png)

Wenn Sie den Joystick einschalten, sehen Sie, dass sich die Schaltfläche ändert und ein Dropdown erhält.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/14-joystick.png)

Mit dem Dropdown neben dem Joystick können Sie den Joystick-Standort konfigurieren:

- Mitte links
- Unten links
- Unten in der Mitte
- Rechts unten
- Mitte rechts

## 8. **Objektinformationsfußzeile**

Standardmäßig wird eine Fußzeile unten im Viewer angezeigt, wenn Sie ein Objekt auswählen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/17-object-information-footer.png)

Diese Fußzeile kann Informationen über Themen und Bibliothekselemente enthalten, die mit dem Objekt verknüpft sind.

### 8.1 **Identifikation**

Objektname - Objektentität - Objekttyp Wenn mehrere Objekte ausgewählt sind, wird dies als nicht definiert angezeigt.

### 8.2 **Themeninformationen**

**Offen** Anzahl der offenen Probleme (Rot) Klicken Sie auf "Offen", um alle offenen Probleme zu sehen, bei denen dieses Objekt im rechten Fenster verknüpft ist.

**Geschlossen** Anzahl geschlossener Probleme (Grün) Klicken Sie auf "Geschlossen", um alle geschlossenen Probleme zu sehen, bei denen dieses Objekt im rechten Fenster verknüpft ist.

### 8.3 **Bibliotheken**

Wenn Sie Ihr ausgewähltes Objekt mit Bibliotheken in Catenda Hub verknüpft haben, können Sie die Bibliothek mit der Anzahl der Links in der Informationsfußzeile sehen.

**SharePoint** Wenn Sie Ihr ausgewähltes Objekt mit SharePoint-Dokumenten verknüpft haben, sehen Sie hier den Namen der SharePoint-Bibliothek mit der Anzahl der verknüpften Dokumente

**Dokumente** Wenn Sie Ihr ausgewähltes Objekt mit Dokumenten auf der Dokumentseite verknüpft haben, können Sie diese unter Dokumente und mit der Anzahl der verknüpften Dokumente hier sehen.

**Klassifikation** Wenn Sie Ihr ausgewähltes Objekt mit Klassifikationen verknüpft haben, können Sie hier den Namen der Klassifikation und die Anzahl der verknüpften Klassifikationen sehen.

**Links** Wenn Sie Ihr ausgewähltes Objekt mit Links aus der Links-Bibliothek verknüpft haben, können Sie "Links" und die Anzahl der verknüpften Links hier sehen.

**Dropbox** Wenn Sie Ihr ausgewähltes Objekt mit Dropbox-Dokumenten verknüpft haben, sehen Sie hier den Namen der Dropbox-Bibliothek mit der Anzahl der verknüpften Dokumente.

### 8.4 **Objektinformationsfußzeile ausblenden**

Klicken Sie auf das x, um die Objektinformationsfußzeile aus dem 3D-Viewer auszublenden.

### 8.5 **Objektinformationsfußzeile anzeigen**

Wenn Sie sich entschieden haben, die Informationsfußzeile zu schließen, können Sie sie mit der Schaltfläche "i" unter dem 2D-Viewer oder der 2D-Schaltfläche wieder öffnen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/18-showing-the-object-information-footer.png)

## 9. **Optionsmenü**

Wenn Sie im 3D-Viewer mit der rechten Maustaste klicken, wird das [Optionsmenü](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=Double%20click-,Options%20menu,-Show%20all) angezeigt.

## 10. **Bild exportieren**

Die beste Möglichkeit, ein Bild aus dem 3D-Viewer zu exportieren, besteht darin, einen [3D-Schnappschuss](https://support.catenda.com/en/articles/8053352-issue-body#h_1ba7f8873f) zu erstellen.
