# Neue Dokumentenrevision hochladen

Indem Sie eine neue Revision zu einem Dokument hochladen, statt ein neues Dokument zu erstellen, können alle Versionen eines Dokuments an einem Ort zusammengefasst werden. Es ist möglich, neue Revisionen zu einem Dokument auf einmal mit der Aktionsschaltfläche hochzuladen. _Erforderlicher Zugriff:_ Schreibzugriff auf das Dokument

## 1. **Drag und Drop**

Ziehen Sie eine Datei auf ein Dokument in der Dokumenttabelle, um sie als neue Revision zu diesem Dokument hochzuladen.

## 2. **Upload-Menü**

Eine neue Revision kann mit dem Upload-Dialogfeld auf einmal zu bis zu 100 Dokumenten in einem Ordner hochgeladen werden. Ziehen Sie eine oder mehrere Dateien per Drag-and-Drop in die Dokumenttabelle, klicken Sie auf Durchsuchen in einem leeren Ordner, oder klicken Sie auf die grüne Schaltfläche oben rechts, um das [Dokument-Upload-Menü zu öffnen](https://support.catenda.com/en/articles/4670278-uploading-a-document#h_00fa77db3e). Im Upload-Menü können Dateien erkannt und als neue Revision zu den richtigen Dokumenten hochgeladen werden. Klicken Sie hier, um mehr über den Upload-Dialog zu lesen.

## 3. **Zip-Import**

Wenn Dokumente mit dem gleichen Namen wie die Dateien in einer Zip-Datei, die mit der [Zip-Import-Aktion](https://support.catenda.com/en/articles/7945410-upload-a-zip-file-structure) importiert wird, vorhanden sind, werden sie als neue Revision statt als neues Dokument hinzugefügt.

## 4. **Aktion in Dokumentstruktur**

Mit einem ausgewählten Dokument kann die neue Revisionsaktion auch im [vorhandenen Elementaktionsmenü](https://support.catenda.com/en/articles/4670288-documents-table-actions#h_5785139ce3) gefunden werden, das oben in der Dokumenttabelle angezeigt wird, wenn ein Element ausgewählt ist. Ein Vorteil dieser Aktion besteht darin, dass keine Verwechslung über den Dokumentnamen entsteht. Das Dokument ist ausgewählt und die von Ihnen gewählte Datei wird zu dem ausgewählten Dokument hochgeladen, ohne sich Gedanken über den Namen machen zu müssen. _Erforderlicher Zugriff:_ Schreibzugriff auf das Dokument

## 5. **Aktion in Dokumentvorschau**

Öffnen Sie das [Dokumentaktionsmenü](https://support.catenda.com/en/articles/9323521-document-revision-actions#h_ea6fb90f40) oben rechts, oder klicken Sie auf das Symbol für neue Revision. Die neue Revisionsaktion öffnet den Datei-Explorer auf Ihrem System. Im Datei-Explorer kann die Datei ausgewählt werden, die als neue Revision hochgeladen werden soll. Ein Vorteil dieser Aktion besteht darin, dass keine Verwechslung über den Dokumentnamen entsteht. Das Dokument ist ausgewählt und die von Ihnen gewählte Datei wird zu dem ausgewählten Dokument hochgeladen, ohne sich Gedanken über den Namen machen zu müssen.
