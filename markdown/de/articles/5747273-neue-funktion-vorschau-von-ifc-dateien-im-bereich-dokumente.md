# Neue Funktion: Vorschau von IFC-Dateien im Bereich "Dokumente".

> IFC-Dateien können wie jedes andere Dokument angezeigt werden.

Das Hochladen einer IFC-Datei im Bereich "Dokumente" ermöglicht eine Vorschau des Modells einzeln. Darüber hinaus können Sie dieses Modell an den Viewer senden, indem Sie auf die Schaltfläche "3D" klicken.
