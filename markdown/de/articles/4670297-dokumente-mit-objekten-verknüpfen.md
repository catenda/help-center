# Dokumente mit Objekten verknüpfen

## 1. Verknüpfung

Um ein Dokument mit einem Objekt zu verknüpfen, öffnen Sie den 3D Viewer, wählen Sie das/die Objekt(e) aus, an das/die Sie das/die Dokument(e) anheften möchten, und klicken Sie auf die Schaltfläche "Verknüpfung".

> **Hinweis:** Sie können einen Ordner nicht verknüpfen
