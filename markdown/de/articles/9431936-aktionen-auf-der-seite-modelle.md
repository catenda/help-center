# Aktionen auf der Seite "Modelle"

Abhängig von Ihrem Zugriff und Ihrer Auswahl können Aktionen für Ihre Modelle und deren neueste Revisionen auf der [Seite "Modelle"](https://support.catenda.com/en/articles/4670286-models-page) angezeigt werden.

## 1. **Neue Elementaktionen**

Die Plus-Schaltfläche und die Hamburger-Menü-Elemente befinden sich oben rechts auf der Seite und können etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/01-new-item-actions.png)

_Erforderlicher Zugriff:_ Erstellen oder Herunterladen von Modellen oder Zugriff auf ein Dokument-Modell im Dokumente-Bereich

### 1.1 **Neues Modell**

Die Plus-Schaltfläche und die Aktion "Neues Modell" öffnen beide den Dialog "Neues Modell". Der Dialog "Neues Modell" kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/02-new-model.png)

Mit der Schaltfläche "Neues Modell" auf der Modellseite werden Sie aufgefordert, einen Ordner auszuwählen, in dem das Dokument-Modell landen soll.

**Name** Das Modell muss einen Namen erhalten, bevor Sie es erstellen können.

**Ordner** Wenn Sie das Modell erstellen, wird ein Dokument ohne Revisionen in dem Ordner erstellt, den Sie in diesem Dialog auswählen. Wenn Sie "Stammordner" auswählen, landet das Dokument-Modell auf der obersten Ebene des Dokumente-Bereichs. Nach der Erstellung Ihres ersten Modells in einem Projekt wird die Modellordner-Einstellung für Ihr Konto gespeichert, sodass Sie diese nicht jedes Mal auswählen müssen. Sie können später auf den Ordner klicken, wenn das Modell woanders landen soll.

**Offen lassen beim Absenden** Wenn Sie mehrere Modelle erstellen, können Sie die Option "Offen lassen beim Absenden" auswählen. Auf diese Weise müssen Sie nicht jedes Mal auf "Neues Modell" klicken, da das Menü offen bleibt. Wenn Sie viele Modelle auf einmal erstellen, wird empfohlen, diese in den Dokumente-Bereich hochzuladen und stattdessen die Aktion "Modell erstellen" zu verwenden.

**Erstellen** Nach dem Klicken auf "Erstellen" werden Sie auf die [Modellübersichtsseite](https://support.catenda.com/en/articles/4670270-model-overview-page) des neu erstellten Modells weitergeleitet.

_Erforderlicher Zugriff:_ Erstellen und Löschen von Modellen in den Projekteinstellungen und Schreibzugriff auf einen Ort im Dokumente-Bereich.

**Erstellen von Modellen im Dokumente-Bereich** Wenn Sie bereits die Datei, mit der Sie ein Modell erstellen möchten, im Dokumente-Bereich haben, können Sie diese dort auswählen und die Aktion "Modell erstellen" verwenden, um das Modell zu erstellen. Das System kann große Dateien (700 MB+) auf diese Weise möglicherweise besser importieren, da es sich nicht mit Importen befassen muss. Sie können mehrere Modelle gleichzeitig im Dokumente-Bereich erstellen, da Sie sie hochladen, auswählen und dann auf "Modell erstellen" klicken können. Wenn Sie Modelle im Dokumente-Bereich erstellen, ist der Name des Modells im Modelle-Bereich derselbe wie der Name des mit dem Modell verknüpften Dokuments.

### 1.2 **Exporte**

Diese Aktion führt Sie zur [Modellexportseite](https://support.catenda.com/en/articles/4670280-model-export), wo Sie eine ZIP-Datei mit einer ausgewählten Revision für jedes der Modelle erstellen können, auf die Sie Zugriff haben. _Erforderlicher Zugriff:_ Zugriff auf mindestens ein Dokument-Modell im Modelle-Bereich.

## 2. **Aktionen für ausgewählte Elemente**

Nach der Auswahl eines oder mehrerer Modelle können Sie das folgende Aktionsmenü oben in der Dokumenttabelle sehen. Das Menü für vorhandene Elementaktionen kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/03-selected-item-actions.png)

### 2.1 **2D-Viewer**

Mit der Aktion "2D-Viewer" können Sie Ihr ausgewähltes Modell oder Ihre ausgewählten Modelle öffnen, indem Sie oben auf das 2D-Symbol klicken oder das Hamburger-Menü öffnen und auf die Aktion "2D-Viewer" klicken. _Erforderlicher Zugriff:_ Zugriff auf mindestens ein Dokument-Modell im Modelle-Bereich.

### 2.2 **3D-Viewer**

Mit der Aktion "3D-Viewer" können Sie Ihr ausgewähltes Modell oder Ihre ausgewählten Modelle öffnen, indem Sie oben auf das 3D-Symbol klicken oder das Hamburger-Menü öffnen und auf die Aktion "3D-Viewer" klicken. _Erforderlicher Zugriff:_ Zugriff auf mindestens ein Dokument-Modell im Modelle-Bereich.

### 2.3 **Veröffentlichen**

Wenn freigegebene Revisionen im [Statusworkflow-Menü](https://support.catenda.com/en/articles/12495583-status-workflow-document-settings) der Dokumenteinstellungen im Projekt aktiviert sind, beginnt jede neue Revision, die erstellt wird, als freigegebene Revision, die später veröffentlicht werden kann.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/09fxhve6/04-publish.png)

Im Register "Workspace" zeigen Zeilenelemente die neueste freigegebene Revision für jedes Modell an. Im Register "Veröffentlicht" zeigen Zeilenelemente die neueste veröffentlichte Revision für jedes Modell an. Freigegebene Revisionen können von veröffentlichten Revisionen anhand des Symbols in der Revisionsspalte und der Tatsache unterschieden werden, dass sie eine untergeordnete Revisionsnummer haben (0,1, 0,2, 1,1 usw.). _Erforderlicher Zugriff:_ Freigegebene Revisionen in den Zugriffseinstellungen des Dokument-Modells anzeigen. Wählen Sie ein oder mehrere Modelle aus, bei denen die neueste Revision eine freigegebene Revision ist, um die Aktion "Veröffentlichen" im Aktionsmenü anzuzeigen. _Erforderlicher Zugriff:_ Kann in den Zugriffseinstellungen des Dokument-Modells veröffentlicht werden

Mit der Aktion "Veröffentlichen" kann die neueste freigegebene Revision veröffentlicht werden. Vorherige freigegebene Revisionen, die nach der neuesten veröffentlichten Revision hochgeladen wurden, können auf der [Modellübersichtsseite](https://support.catenda.com/en/articles/4670270-model-overview-page) veröffentlicht werden. Nach dem Veröffentlichen wird eine neue veröffentlichte Revision mit einer Hauptversionsnummer (1.0, 2.0, 3.0 usw.) hinzugefügt. Diese veröffentlichte Revision ist sowohl im Register "Workspace" als auch im Register "Veröffentlicht" sichtbar.

### 2.4 **Letzte Revision herunterladen**

Wenn Sie Zugriff auf das Herunterladen von Modellen haben, können Sie auf die Download-Schaltfläche klicken. Auf diese Weise können Sie die neueste Revision eines Modells als IFC-Datei herunterladen. Wenn Sie nach einer vorherigen Revision dieses Modells suchen, besuchen Sie bitte die [Modellseite](https://support.catenda.com/en/articles/4670270-model-page). _Erforderlicher Zugriff:_ Zugriff auf mindestens ein Dokument-Modell im Modelle-Bereich.

### 2.5 **Neue Revision**

Wählen Sie ein einzelnes Modell aus und verwenden Sie die Aktion "Neue Revision" oder ziehen Sie eine Datei auf eine Revision, um eine neue Revision in diesem Modell hochzuladen. _Erforderlicher Zugriff:_ Erstellen und Löschen von Modellen in [Projekteinstellungen](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3) und Schreibzugriff auf das Dokument-Modell.

Revisionen können auf der Modellseite nur nacheinander in ein Modell hochgeladen werden. Verwenden Sie den Filter "ist Modell" im Dokumente-Bereich und laden Sie von dort aus hoch, um bis zu 100 Dokumente gleichzeitig hochzuladen. Verwenden Sie den Catenda Desktop Connector, um regelmäßige Uploads zu planen, wenn sich die lokale Datei geändert hat.

**Was kann hochgeladen werden?** Wenn Sie eine neue Revision mit der Aktion "Neue Revision" hochladen, wählen Sie eine .ifc- oder .ifczip-Datei von Ihrer lokalen Festplatte aus. Sowohl das Modell als auch das mit dem Modell verknüpfte Dokument haben dieselben Revisionen. Obwohl andere 3D-Dateitypen aus dem Dokumente-Bereich zusammen mit den Modellen von der Modellseite im 3D-Viewer geladen werden können, werden nur IFC-Dateien im Modelle-Bereich akzeptiert. Klicken Sie [hier](https://support.catenda.com/en/articles/4670320-previewing-file-types-on-catenda-hub), um zu sehen, welche Dateitypen auf Catenda in der Vorschau angezeigt werden können.

**Plugin- und Integrationsupload** Viele von Catendas Plugins und Integrationen sowie von Clients mit API-Anmeldedaten erstellte benutzerdefinierte Tools ermöglichen ebenfalls die Erstellung neuer Revisionen. Klicken Sie [hier](https://support.catenda.com/en/articles/8396532-catenda-plugins-integrations), um zu sehen, welche Plugins und Integrationen derzeit verfügbar sind.

**Revisionskommentar und andere Metadaten** Die beste Möglichkeit, einen Revisionskommentar bei Verwendung von Catenda Hub über den Browser hinzuzufügen, besteht darin, ein Dokument, das mit dem Modell verknüpft ist, in einem konfigurierten Ordner zu platzieren. Konfigurieren Sie ein Textfeld namens "Kommentar" für den Ordner, damit ein Kommentar als Metadaten zum Dokument nach dem Hochladen der Revision hinzugefügt werden kann. Ein Kommentarfeld, das über die API eingereicht werden kann, existiert und ist in einigen Plugins und Integrationen verfügbar. Nach der Einreichung können Kommentare von Plugins und Integrationen mit der Schaltfläche "Kommentare anzeigen" auf der [Modellseite](https://support.catenda.com/en/articles/4670270-model-contents-page) angezeigt werden.

_IFC-Einchecken-Verarbeitung_ Wenn der Upload-Prozess abgeschlossen ist, analysiert Catenda Hub die IFC-Datei und generiert die Geometrie im Hintergrund. Bei großen Modellen kann es eine Weile dauern, bis die Datei im Viewer bearbeitet werden kann. Während dieser Verarbeitung kann Catenda Hub beendet werden, da die Geometrieerzeugung ununterbrochen stattfindet, unabhängig davon, ob Catenda Hub geöffnet ist oder nicht. Nach Abschluss des Imports wird eine Benachrichtigung in Catenda Hub angezeigt und zusätzlich kann eine Benachrichtigungs-E-Mail gesendet werden, die besagt, dass eine neue Version in ein Modell hochgeladen wurde, auf das Sie Zugriff haben.

### 2.6 **Link kopieren**

Mit der Aktion "Link kopieren" kann ein Link, der nur die ausgewählten Tabellenzeilen anzeigt, kopiert werden. Klicken Sie [hier](https://support.catenda.com/en/articles/14323982-copy-link-action), um mehr über das Kopieren von Links zu erfahren.

### 2.7 **Entfernen**

Mit dieser Aktion werden Sie aufgefordert, zu bestätigen, bevor das Modell von der Modellseite entfernt wird.

> **Hinweis:** Das Entfernen des Modells entfernt es nur von der Modellseite. Das Dokument-Modell bleibt im Dokumente-Bereich und muss mit der Aktion "Ausgewähltes Dokument löschen" gelöscht werden, wenn Sie es auch löschen möchten. Das Modell kann jederzeit im Modelle-Bereich aus demselben Dokument neu erstellt werden.

_Erforderlicher Zugriff:_ Erstellen und Löschen von Modellen in den Projekteinstellungen und Schreibzugriff auf die Modelle, die Sie zu entfernen versuchen.
