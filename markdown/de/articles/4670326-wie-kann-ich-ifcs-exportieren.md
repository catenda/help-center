# Wie kann ich IFCs exportieren?

Sie können eine IFC-Datei exportieren, indem Sie zu **Modelle** (1) gehen und dann die Schaltfläche **Exporte** (2) wählen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/01-intro.png)

Auf der nächsten Seite können Sie die Historie der vorherigen Downloads einsehen und diese einzeln erneut herunterladen.

Wenn Sie mehrere Modelle in eine Datei zusammenführen möchten, muss ein "Neuer Export" erstellt werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/02-intro.png)

Der nächste Schritt besteht darin, die Exportoptionen auszuwählen. Wählen Sie, ob die Datei als .zip- oder .xls-Datei archiviert werden soll. Wählen Sie dann aus, welche Modelle und welche Revisionen dieser Modelle in den Export einbezogen werden sollen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/03-intro.png)

Zum Exportieren scrollen Sie die Seite nach unten und finden Sie Punkt 6.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/04-intro.png)
