# Neue Etiketten erstellen

Etiketten sind in vielen Bereichen in Catenda HUB nützlich. Sie können sowohl für Dokumente als auch für Aufgaben verwendet werden. Zugewiesene Etiketten helfen Ihnen, Ihre Aufgaben und Dokumente besser zu organisieren und zu filtern.

Im folgenden Artikel finden Sie Anweisungen zum Erstellen neuer Etiketten, zum Erstellen von Etikettengruppen und zum Importieren einer Gruppe von Etiketten aus einer Excel-Tabelle.

## 1. Neue Etiketten erstellen

Klicken Sie dazu auf "Etiketten" im Bereich "Einstellungen". Sie haben jetzt die Möglichkeit, ein neues Etikett zu erstellen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/01-create-new-label.png)

Ein Ansichtsfenster wird geöffnet, in dem Sie einen Etikettenamen zuweisen, eine Farbe dem Etikett zuweisen oder eine Gruppe dem Etikett zuweisen können.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/02-create-new-label.png)

## 2. Etikettengruppe erstellen

Es ist eine gute Idee, Etiketten in Gruppen zu gruppieren / organisieren.

Wenn Sie verschiedene Etiketten gruppieren möchten, gehen Sie wie folgt vor. Klicken Sie dazu auf "Neue Gruppe" im Bereich "Gruppen"

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/03-create-label-group.png)

Geben Sie auch hier einen Namen ein. Die Gruppe wird erstellt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/04-create-label-group.png)

## 3. Aus Excel importieren

Wenn Sie mehrere Etiketten gleichzeitig aus einer Excel-Datei erstellen möchten, gehen Sie wie folgt vor. Wir befinden uns im Bereich "Etiketten" und erstellen ein neues Etikett:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/05-import-from-excel.png)

Das folgende Fenster wird geöffnet:

Sie müssen jetzt keine Farbe oder Gruppe auswählen, sondern können diese Datei direkt aus einer Excel-Tabelle mit "Kopieren" und "Einfügen" einfügen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/06-import-from-excel.png)

Hier ist eine Beispieltabelle. Die Farbcodes finden Sie auf den entsprechenden Websites. Geben Sie einfach "Farbcode" in Google ein.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/07-import-from-excel.png)

Jetzt können wir diese Tabelle in die Namensspalte einfügen. Wählen Sie dazu einfach alles von Etikett1 bis zum letzten Farbcode aus, kopieren Sie es und fügen Sie es ein.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/08-import-from-excel.png)

Fügen Sie jetzt einfach die ausgewählten Zellen im Namensbereich ein. Die Namen, Gruppen und Farben werden automatisch zugewiesen. Achten Sie darauf, dass Sie die richtige Schreibweise und einen vollständigen Farbcode verwenden. Klicken Sie auf "Absenden", um die neuen Etiketten zu erstellen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/09-import-from-excel.png)

Ihre Ansicht sollte nun so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/10-import-from-excel.png)

Sie haben Ihre Etiketten erfolgreich erstellt.
