# Catenda Revit-Plugin

> **Hinweis:** Die Installationsdatei für das Plugin finden Sie in [diesem Artikel](https://intercom.help/bimsync-arena/en/articles/8396532-catenda-plugins-and-integrations).

Das Catenda Revit-Plugin ist ein Plugin, das für Autodesk Revit installiert werden kann. Mit diesem Plugin können Sie mit anderen Mitgliedern des Bauprojekts an 3D-Viewpoints, Themen und Dokumenten zusammenarbeiten

## 1. **Installation**

Wenn das Catenda Revit-Plugin unter Windows installiert wird, werden die Installationsdateien im folgenden Ordner angezeigt.

`C:\ProgramData\Autodesk\ApplicationPlugins\CatendaHub.bundle`

### 1.1 **Deinstallation**

Um das Plugin zu deinstallieren, gehen Sie zu folgenem Windows-Menü:

`Windows-Einstellungen -> Apps -> Installierte Apps`

Suchen Sie Catenda für Autodesk® Revit® in der Liste und klicken Sie auf das Aktionsmenü auf der rechten Seite zum Deinstallieren.

### 4.2 **Projekt- und Themen-Board-Auswahl**

Sie können die angezeigten Themen sortieren, um die relevantesten zuerst anzuzeigen.

![sort.png](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/10-sort-topics.png)

1. Bringt das zuletzt erstellte Thema zuerst
1. Bringt das älteste Thema zuerst
1. Das zuletzt aktualisierte Thema zuerst anzeigen. Das Aktualisieren eines Themas kann das Ändern beliebiger Eigenschaften wie Titel, Kommentare usw. beinhalten…
1. Bringt das am wenigsten zuletzt aktualisierte Thema zuerst
1. Bringt das jüngste Fälligkeitsdatum zuerst
1. Bringt das älteste Fälligkeitsdatum zuerst

### 4.6 **Themen filtern**

Mit der Filterleiste können Sie beliebige Filtertypen kombinieren, um nur die relevantesten Themen anzuzeigen.

Aktuelle Filter werden als kleine Chips in der Filterleiste angezeigt. Hier werden nur Themen mit dem Status "Offen" angezeigt. Klicken Sie in die Filterleiste, um alle verfügbaren Filter anzuzeigen (1).

![AvailableFilters.png](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/11-filter-topics.png)

Auf der linken Seite (2) ist der Name des Filters, jeder Filter gehört zu einem auf der rechten Seite angezeigten Typ (3).

Verfügbare Filtertypen umfassen:

- Angefordert von: Alle Themen abrufen, die von einem bestimmten Benutzer angefordert wurden
- Zugewiesen an: Alle Themen abrufen, die einem bestimmten Benutzer zugewiesen sind
- Fälligkeitsdatum: Alle überfälligen Themen oder Themen, die in weniger als einem Monat, zwei Wochen, einer Woche oder einem Tag fällig sind, abrufen
- Status: Alle Themen mit einem bestimmten Status (Offen, Geschlossen, ...) abrufen
- Typ: Alle Themen eines bestimmten Typs (Fehler, Warnung, Info, ...) abrufen
- Etikett: Alle Themen mit einem bestimmten Etikett abrufen
- Meine Themen: Alle Themen abrufen, die Ihnen zugewiesen oder von Ihnen angefordert wurden

Sie können diese Filter durchsuchen, indem Sie Text in die Filterleiste eingeben (1). Sie können dies auch verwenden, um einen Textfilter zu erstellen, um nach bestimmtem Text im Thementitel oder in der Beschreibung zu suchen (2).

![TextFilter.png](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/12-filter-topics.png)

## 5. **Themendetails**

In dieser Ansicht können Sie ein bestimmtes Thema überprüfen und bearbeiten.

### 5.1 **Schnittstelle**

![IssueDetailView.png](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/13-interface.png)

1. Gehen Sie zurück zur [Themenliste](#h_642fa61854)
1. Aktualisieren Sie den Inhalt dieses Themas
1. Navigieren Sie zwischen Themen
1. Legen Sie den Themenstatus fest (Offen, Geschlossen, ...)
1. Legen Sie den Thementyp fest (Fehler, Warnung, Info, ...)
1. Legen Sie das Fälligkeitsdatum des Themas fest
1. Legen Sie das Mitglied fest, dem das Thema zugewiesen ist. Sie können ein Thema einem einzelnen Benutzer oder einem Team zuweisen.
1. Legen Sie das Mitglied fest, das dieses Thema anfordert. Sie können einen einzelnen Benutzer oder ein Team festlegen.
1. Bearbeiten Sie die Thema-Etiketten
1. Die Liste der Kommentare im Thema

### 5.2 **Themeneigenschaften**

Sie können jede Eigenschaft des Themas bearbeiten: Status, Typ, Zugewiesener, Anforderer, Fälligkeitsdatum, Etiketten. Jedes Menü zeigt eine Liste verfügbarer Eigenschaften an. Sie können jedoch keinen neuen Status, Typ oder ein neues Etikett direkt im Plugin erstellen. Sie müssen dazu die Weboberfläche von Catenda Hub verwenden.

Sie können auf den Titel klicken, um ihn zu bearbeiten:

![editTitle.gif](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/14-topic-properties.gif)

Sie können auf das Stiftsymbol klicken, um die Beschreibung zu bearbeiten:

![editDescription.gif](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/15-topic-properties.gif)

Sie können auch Text in die Etikett-Leiste eingeben, um die Liste der Filter zu filtern:

![editLabels.gif](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/16-topic-properties.gif)

### 5.3 **Kommentare**

Alle Kommentare werden unter dem Thema angezeigt. Ein Kommentar kann Text, ein Bild, einen Schnappschuss aus Ihrer aktuellen Revit-Ansicht oder einen Viewpoint enthalten.

![CommentDetail.png](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/17-comments.png)

1. Der Autor des Kommentars
1. Wann der Kommentar erstellt wurde. Sie können den Mauszeiger über das Datum bewegen, um das vollständige Datum und die Uhrzeit der Aktualisierung anzuzeigen.
1. Die [Zoom-Schaltfläche](#h_d873968c27) (siehe Kapitel unten)
1. Das mit dem Kommentar verknüpfte Bild
1. Der Text des Kommentars

### 5.4 **Zoom**

Wenn der Kommentar einen Viewpoint enthält, können Sie zu diesem Viewpoint zoomen. Das Zoomen erstellt eine neue 3D-Ansicht in Ihrem Revit-Modell, die auf den gleichen Viewpoint konzentriert ist.

![zoom.gif](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/18-zoom.gif)

Damit der Viewpoint relevant ist, müssen Sie das gleiche Modell geöffnet haben, in dem der Kommentar erstellt wurde. Das Plugin geht davon aus, dass gemeinsame Koordinaten beim Exportieren des Modells nach IFC verwendet wurden.

Wenn der Viewpoint aus einer Perspektivansicht erstellt wurde, wird die neue 3D-Ansicht den Projektionsmodus auf "Perspektive" gesetzt haben. Ansonsten wird der Projektionsmodus "Orthografisch" sein.

Das Add-in erstellt nur eine Perspektivansicht und eine orthografische Ansicht. Nach ihrer Erstellung wird es sie für jeden nachfolgenden Einsatz der Zoomfunktion wiederverwenden. Sie können dies im [Einstellungsmenü](#h_b02502c589) ändern. Sie können auch das Einstellungsmenü verwenden, um den Namen dieser Ansicht zu ändern.

### 5.5 **Verwandte Elemente**

Wenn das Thema verwandte Elemente enthält, wählt das Add-in diese in Revit aus, wenn Sie zu einem Viewpoint zoomen.

![relatedElements.gif](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/19-related-elements.gif)

Damit diese Funktion funktioniert, muss Ihr Revit-Modell nach IFC mit der Option "IFC-GUID nach dem Export in einem Elementparameter speichern" exportiert worden sein. Dadurch wird der Parameter IFCGuid für jedes Objekt hinzugefügt, sodass das Plugin die verwandten Elemente auswählen kann.

### 5.6 **Kommentar hinzufügen**

Sie können Kommentare zu einem Thema hinzufügen, indem Sie in das Textfeld schreiben und auf "Senden" klicken.

Sie können auch ein Bild von Ihrem Computer hinzufügen, indem Sie auf die Schaltfläche "Plus" klicken. Sie können dieses Bild mit Anmerkungen versehen, indem Sie auf das Vorschaubild klicken, nachdem Sie es ausgewählt haben.

![createComment.gif](https://raw.githubusercontent.com/catenda/help-center/main/images/xjh922f7/20-add-comment.gif)

### 5.7 **3D-Schnappschuss hinzufügen**

Sie können auch Ihre aktuelle Revit-Ansicht als Viewpoint und einen Schnappschuss hinzufügen, der mit Ihrem Kommentar verbunden ist. Wie bei jedem Bild können Sie den Schnappschuss mit Anmerkungen versehen, indem Sie auf das Vorschaubild klicken.

Wenn der Parameter IFCGUID vorhanden ist, werden ausgewählte Elemente in Revit als verwandte Elemente zu Ihrem Thema hinzugefügt.
