# Etiketten-Filter - Catenda Site

Es ist möglich, nach Etiketten in [Issues](https://support.catenda.com/en/articles/7734073-issues-page-catenda-site) und in [Dokumente](https://support.catenda.com/en/articles/7774637-documents-catenda-site) zu filtern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ge4vaaph/01-intro.png)

Wählen Sie die Etiketten, die Sie filtern möchten, und tippen Sie auf "Fertig", um Ihren Filter anzuwenden.

### Etiketten-Änderungen von anderen Geräten

Um Änderungen der Etiketten in diesem Filtermenü anzuzeigen, die auf einem anderen Gerät vorgenommen wurden, wechseln Sie zur [Projektseite](https://support.catenda.com/en/articles/7733978-projects-page-catenda-site) und öffnen Sie das Projekt erneut. Ebenso können Sie ein neues externes Etikett erst sehen, nachdem das Projekt neu geladen wurde.

### Symbol zum Zurücksetzen von Etiketten

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ge4vaaph/02-reset-label-icon.png)

Sie können auf die Schaltfläche "Zurücksetzen" oben links klicken, um alle ausgewählten Etiketten abzuwählen. (P.S. Wenn Sie coole Emojis in Ihren Filtern haben möchten, können Sie dies ganz einfach tun, indem Sie die Etikett-Namen in der mobilen Browserversion von Catenda Hub ändern)
