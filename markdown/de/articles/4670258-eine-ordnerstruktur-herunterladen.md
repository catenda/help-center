# Eine Ordnerstruktur herunterladen

Sie können Ordner und deren Inhalt auf der Seite "Dokumente" herunterladen.

Gehen Sie zu Dokumente und verwenden Sie die Kontrollkästchen auf der linken Seite, um auszuwählen, welche Ordner heruntergeladen werden sollen.

Wenn ein Ordner aktiviert ist, wird ein neues Fenster auf der rechten Seite der Seite angezeigt. Drücken Sie "Herunterladen".

Eine gezippte Datei der Ordnerstruktur und Dateien wird heruntergeladen.
