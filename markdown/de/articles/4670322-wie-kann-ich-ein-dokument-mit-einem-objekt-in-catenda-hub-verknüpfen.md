# Wie kann ich ein Dokument mit einem Objekt in Catenda Hub verknüpfen?

1. Öffnen Sie den 3D-Viewer und wählen Sie ein (oder mehrere) Objekte durch Linksklick aus (Strg+Linksklick öffnet die Auswahl von mehr als einem Objekt).
2. Klicken Sie auf das Menü Dokumente in der Hauptmenüleiste auf der linken Seite
3. Wählen Sie ein (oder mehrere) Dokumente aus, indem Sie auf die Kontrollkästchen links neben jedem anklicken
4. Klicken Sie auf die Schaltfläche "Links", die auf der rechten Seite der Dokumentansicht angezeigt wird.
