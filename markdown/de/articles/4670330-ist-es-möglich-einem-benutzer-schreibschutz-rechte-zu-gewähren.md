# Ist es möglich, einem Benutzer Schreibschutz-Rechte zu gewähren?

Es gibt keine generische "Schreibschutz"-Rolle, aber Sie können den Zugriff auf Lesen beschränken, sowohl für Dokumente als auch für Issues. Auf diese Weise kann einem Benutzer die Möglichkeit verweigert werden, Dokumente und Issues im Projekt zu bearbeiten oder zu kommentieren. Bei Dokumenten können Sie Ordner oder einzelne Dateien einschränken. Bei Issues wird die Einschränkung auf dem Board selbst festgelegt und gilt für alle Issues auf diesem Board.
