# Genehmigungsanfrage-Dateiüberprüfung rechtes Menü - Legacy

Wenn die [Dateiüberprüfung einer Genehmigungsanfrage](https://support.catenda.com/en/articles/12507422-file-review-in-an-approval-request-legacy) zum ersten Mal geöffnet wird, kann das rechte Menü geschlossen sein. Klicken Sie auf die Informationsschaltfläche rechts, um dieses Menü zu erweitern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zt2p953n/01-intro.png)

So kann das rechte Menü in der Dateiüberprüfung einer Genehmigungsanfrage für Projekte aussehen, die gemeinsame Revisionen vor dem 2. Oktober 2025 aktiviert haben:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zt2p953n/02-intro.png)

## 1. **Dateiübersicht**

### 1.1 **Dokument**

Der Dateipfad der Dokumentseite und der Dokumentname des Dokuments. Wenn das Dokument eine zuletzt veröffentlichte Revision hat, wird sie mit folgenden Informationen angezeigt:

- Revisionsname
- Veröffentlichendes Mitglied
- Dateigröße
- Veröffentlichungsdatum

### 1.2 **Datei zur Genehmigung**

Die Datei, die derzeit überprüft wird mit:

- Revisionsname
- Veröffentlichendes Mitglied
- Dateigröße
- Veröffentlichungsdatum

### 1.3 **Validierungsvorschau**

Der Status der Validierung wird in der Vorschau angezeigt. Wenn nicht alle Prüfer ihre Validierung eingereicht haben, wird sie gelb angezeigt und sagt "ausstehend". Wenn ein Prüfer seine Validierung einreicht, wird die Leiste für dieses Mitglied entweder grün oder rot hervorgehoben, je nachdem wie die Validierung ausfällt.

Wenn ein Prüfer eine Ablehnung eingereicht hat, wird das Feld rot und zeigt "abgelehnt".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zt2p953n/03-validation-preview.png)

Wenn die Mindestanzahl von Mitgliedern, wie in der Genehmigung angegeben, Genehmigungsvalidierungen eingereicht haben, wird das Feld grün und zeigt "genehmigt".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zt2p953n/04-validation-preview.png)

**Hovern** Fahren Sie mit der Maus über das Validierungsvorschau-Feld, um zu sehen, welcher Prüfer an welcher Aktion beteiligt ist, und ob er seine Validierung eingereicht hat und wann er diese eingereicht hat.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zt2p953n/05-validation-preview.png)

## 2. **Kommentar**

### 2.1 **Kommentarfeld**

Geben Sie einen Kommentar ein, um einen Kommentar zur Überprüfung dieser Datei hinzuzufügen. Kommentare folgen den allgemeinen Regeln der [Formatierung von Beiträgen](https://support.catenda.com/en/articles/8430847-formatting-of-posts) auf Catenda. Validierungen können eingereicht werden, ohne einen Kommentar einzugeben.

### 2.2 **Kommentar**

Klicken Sie auf Kommentar, um einen Kommentar einzureichen, ohne abzulehnen oder zu genehmigen.

### 2.3 **Ablehnen**

Klicken Sie auf "Ablehnen", um eine Ablehnung zusammen mit dem Kommentar einzureichen, der im Kommentarfeld geschrieben ist.

### 2.4 **Genehmigen**

Klicken Sie auf "Ablehnen", um eine Ablehnung zusammen mit dem Kommentar einzureichen, der im Kommentarfeld geschrieben ist.

**Mit Kommentar genehmigen** Öffnen Sie das Genehmigungsaktionsmenü und klicken Sie auf "Mit Kommentar genehmigen", um den Status "Mit Kommentar genehmigen" zu anwenden, der Auswirkungen darauf haben kann, wie das Dokument veröffentlicht wird. Diese Option kann nur ausgewählt werden, wenn etwas im Kommentarfeld geschrieben ist.

## 3. **Dateiüberprüfungsverlauf**

Immer wenn eine Aktion in einer Dateiüberprüfung auftritt, wird sie im Dateiüberprüfungsverlauf angezeigt. So können die verschiedenen möglichen Aktionen aussehen:
