# User Voice @ Catenda

> Catendas Verpflichtung, unseren Benutzern Wert zu liefern

Wir nutzen Catenda Hub seit 2021 für Benutzerfeedback. Dieses Feedback wird in einem Themen-Board namens User Voice verwaltet. Durch direkte Gespräche mit unseren Kunden, Benutzern und Wiederverkäufern notieren wir uns und fördern bei unserem Produktteam Verbesserungen und neue Funktionen, die den täglichen Betrieb in ihrer Catenda-Erfahrung verbessern könnten.

Unten finden Sie die Liste dessen, was unser Team bisher geliefert hat. Und es kommt noch mehr. Bleiben Sie dran!

## 1. **User-Voice-Pyramide**

Die User-Voice-Pyramide besteht aus 6 Stufen, durch die sich Themen auf und ab bewegen können

### 1.1 **Implementierung**

Wenn es Zeit zwischen größeren Aufgaben gibt, können Entwickler mit der Arbeit an einem der Themen aus der [Shortlist](#h_72d21b37fa) beginnen.

### 1.2 **Shortlist**

Themen, die vom Kundenerfolgsteam [qualifiziert](#h_7c19a7e0e3) wurden, werden von Entwicklern überprüft. Sie werden sich das Thema ansehen und die Durchführbarkeit dieser Änderung diskutieren.

Die Entwickler führen eine Shortlist von Themen, die klar definiert und abgegrenzt sind. Ob ein [Thema ausgewählt](#h_fab9c7fb3a) wird oder nicht, kann von verschiedenen Faktoren abhängen:

- Verfügbare Zeit und Ressourcen
- Thempriorität
- Themenübereinstimmung mit aktuellen Änderungen (Plattformlandschaft)

### 1.3 **Produktqualifizierung**

Vor jedem Entwicklungszeitraum durchsuchen Entwickler die User-Voice-Themen, die vom Kundenerfolgsteam qualifiziert wurden. Sie werden das Thema diskutieren, um ein Gefühl dafür zu bekommen, wie lange diese Änderung dauern könnte, und etwaige unvorhergesehene technische Herausforderungen beschreiben, die während der Entwicklung dieser Änderung auftreten könnten. Wenn ein Thema vom Produktteam qualifiziert wird und sein Zeitrahmen die Änderung im Zeitraum zwischen größeren Aufgaben ermöglicht, kann es zur [Shortlist](#h_61cf4dbdbd) hinzugefügt werden. Wenn von einem User-Voice-Thema erwartet wird, dass es einen oder mehrere vollständige Entwicklungszeiträume dauert, wird das Thema dem [Roadmap](#h_de051c0252) zugewiesen.

### 1.4 **Kundenerfolgsteam-Qualifizierung**

Alle 3 Monate werden neue Themen qualifiziert. Der Status von unklar formulierten Themen wird auf Clarification geändert. Themen, die ausreichend Informationen haben und qualifiziert wurden, werden dann vom [Produktteam qualifiziert](#h_e996ac7362).

### 1.5 **Themenclarification**

Wenn ein Thema weitere Informationen benötigt, kann es für die Clarification markiert werden. Dann werden weitere Informationen hinzugefügt oder weitere Informationen vom Benutzer angefordert, der diese Frage stellt. Wenn dies geschieht, kann es länger dauern, bis ein Thema den Prozess durchläuft. Je mehr Informationen in Form von Informationen oder Anwendungsfällen zu den Themen hinzugefügt werden, desto wahrscheinlicher ist es, dass ein Thema qualifiziert wird.

### 1.6 **Eine Anfrage einreichen**

Ein User-Voice-Thema beginnt als Frage an einen unserer Mitarbeiter durch einen Benutzer. Fragen können persönlich, per E-Mail oder über die schwarze Chat-Schaltfläche neben Ihrem Profilbild oben rechts auf der Seite gestellt werden. Sie werden am besten gestellt, indem Sie auf die Blase klicken, auf das Menü "Nachrichten" klicken und dann auf die Option "Feedbackformular 🎫" klicken. Dann wird ein Thema erstellt, das die Situation erklärt. Wenn ein Thema bereits vorhanden ist, wird der Benutzer zur Liste der Personen hinzugefügt, die dieses bestimmte Thema fragen. Customer-Success-Vertreter werden dann ihre Priorität für dieses Thema durch die Verwendung von benutzerdefinierten Feldern angeben, die beeinflussen, wie wahrscheinlich es ist, dass ein Thema [qualifiziert](#h_15e2288bf8) wird.

## 2. **Große oder nicht durchführbare Anfragen**

Dies sind Anfragen, die nicht dem Muster eines regulären User-Voice-Themas entsprechen

### 2.1 **Roadmap**

Wenn von einem User-Voice-Thema erwartet wird, dass es einen oder mehrere vollständige Entwicklungszeiträume dauert, wird das Thema der Roadmap zugewiesen. Wenn genug Benutzer ein Roadmap-Thema fragen, können wir dieses Thema priorisieren, um es in einem unserer zukünftigen Entwicklungszeiträume anzugehen.

### 2.2 **Abgelehnt**

Wenn in irgendeiner Phase des Prozesses entschieden wird, dass ein Thema nicht durchführbar ist, wird es als abgelehnt markiert.

## 3. **Semi-privat**

Das Catenda-Projekt bleibt ein internes Projekt. Dies bedeutet, dass wir diese Themen nicht öffentlich anzeigen können. Wir möchten jedoch so transparent wie möglich sein. Wenn Sie sich also jemals über den Status eines User-Voice-Themas wundern, können Sie gerne den Support um ein Update bitten!
