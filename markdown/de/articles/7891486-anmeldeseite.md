# Anmeldeseite

Wenn Sie zu [hub.catenda.com/signin](http://hub.catenda.com/signin) gehen, wird Ihnen diese Seite angezeigt:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/z7whdt00/01-intro.png)

## 1. **E-Mail-Adresse**

Geben Sie eine E-Mail-Adresse ein, die mit einem bestehenden Konto verbunden ist. Wenn noch kein Konto für diese E-Mail-Adresse vorhanden ist, registrieren Sie sich stattdessen für ein neues Konto. Klicken Sie [hier](https://hub.catenda.com/signup), um sich für ein neues Konto zu registrieren.

### 1.1 **Single-Sign-On-Konten**

Unternehmen, die Catenda-Projekte besitzen, können SSO für Catenda-Benutzer aus ihrer Organisation konfigurieren. Single Sign On (SSO) kann auf zwei Arten konfiguriert werden:

- Whitelist – Bestimmte Benutzer aus einer Domäne
- Blacklist – Alle Benutzer aus einer Domäne außer denen auf einer angegebenen Liste

Wenn die eingegebene E-Mail-Adresse als SSO-aktiviertes Konto erkannt wird, wird das Passwortfeld ausgeblendet und Folgendes wird stattdessen angezeigt: Dieses Konto verwendet SSO. Klicken Sie auf "Weiter", um sich anzumelden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/z7whdt00/02-single-sign-on-accounts.png)

Wenn Sie auf "Weiter" klicken, werden Sie zur Anmeldeseite der Organisation weitergeleitet. SSO-Benutzer haben keine MFA-Anforderung für Projekte ihrer Organisation, wenn MFA erforderlich ist.

> **Hinweis:** Catenda Support kann helfen, wenn Benutzer nicht wie erwartet weitergeleitet werden, aber Fragen zur Anmeldeseite der Organisation sollten besser an die IT-Abteilung dieser Organisation gestellt werden.

Wenn die falsche E-Mail-Adresse eingegeben wurde, ändern Sie einfach die Adresse und das Passwortfeld wird wieder verfügbar.

## 2. **Passwort**

Hier können Sie das Passwort eingeben, das dem unter der angegebenen E-Mail-Adresse registrierten Konto entspricht. Klicken Sie [hier](https://support.catenda.com/en/articles/10798891-sign-in-and-passwords) um Hilfe bei der Passwortverwaltung zu erhalten.

## 3. **Anmelden**

Klicken Sie auf "Anmelden", um die eingegebenen Anmeldedaten zu überprüfen. Nach erfolgreichem Abschluss des Verifizierungsprozesses werden Benutzer auf die [Seite "Projekte"](https://support.catenda.com/en/articles/4670260-projects-page) weitergeleitet.

## 4. **MFA**

Wenn ein MFA-Code für ein Konto konfiguriert wurde, werden Benutzer zunächst aufgefordert, den MFA-Code von der Authentifizierungsanwendung auf dem Gerät einzugeben, auf dem sie den Code bei ihrem Konto registriert haben. Wenn es ein Problem mit dem Code gibt oder das Gerät, auf dem sich der Code befand, verloren gegangen ist, bitten Sie den Projektinhaber, der die Hauptkontaktperson bei Catenda hat (normalerweise ein Administrator im Projekt), den Authentifizierungscode für Ihr Konto über die Support-Blase auf dieser Seite, auf Catenda oder unter [support@catenda.com](mailto:support@catenda.com) zurücksetzen zu lassen.

## 5. **Ich habe mein Passwort vergessen**

Geben Sie Ihre E-Mail-Adresse [hier](https://hub.catenda.com/forgot-password) ein, um Ihr Passwort zurückzusetzen. Wenn Sie innerhalb von 2 Minuten keine E-Mail erhalten, wenden Sie sich mit der Support-Blase auf dieser Seite, auf Catenda oder unter [support@catenda.com](mailto:support@catenda.com) an den Support.

## 6. **Neue Benutzer einladen**

Durch Klicken auf [Registrieren](https://hub.catenda.com/signup) oben auf der Anmeldeseite können Benutzer ein kostenloses Konto erstellen, auch ohne zu einem Projekt eingeladen zu werden. Nach Abschluss der Kontoverifizierungsschritte wird diese Benutzer feststellen, dass ihr Konto leer ist und keine Projekte enthält.

**Eine Einladung akzeptieren und ein neues Konto erstellen** Neue Benutzer, die noch kein Konto haben, können von einem Projektadministrator oder einem Organisationsinhaber per E-Mail zu einem Catenda-Projekt eingeladen werden. Wenn ein Benutzer, der noch kein Konto hat, eine Einladungs-E-Mail erhalten hat und auf den Link klickt, wird die Kontoverifizierungsseite geöffnet und der Benutzer wird aufgefordert, die Kontoverifizierungsschritte zu befolgen. Nach Abschluss der Schritte kann die Projekteinladung akzeptiert werden, wenn sie noch gültig ist, und der Benutzer kann automatisch Teil des Projekts werden.

**Eine Einladung mit einem bereits existierenden Konto akzeptieren** Benutzer, die bereits ein Konto erstellt haben und auf den E-Mail-Einladungslink klicken und sich noch nicht angemeldet haben, werden aufgefordert, sich mit ihren Anmeldedaten anzumelden, bevor sie gefragt werden, ob sie die Projekteinladung annehmen möchten.

Wenn das Konto vor dem Versand der Einladung erstellt wurde, können sich Benutzer mit ihren registrierten Anmeldedaten anmelden und auf die Benachrichtigung zur Projekteinladung klicken, um die Einladung anzunehmen und Teil eines Projekts zu werden.

**Neue Benutzer zum Projekt ohne Einladung hinzufügen** Benutzer, die einer Organisation angehören, die Catenda-Projekte besitzt, könnten feststellen, dass ihr Konto von einem Organisationsinhaber zu einem der Organisationsprojekte hinzugefügt wurde.
