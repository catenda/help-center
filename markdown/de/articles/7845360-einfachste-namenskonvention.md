# Einfachste Namenskonvention

Dieser Artikel zeigt, wie eine [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) im [Dokumente-Bereich](https://support.catenda.com/en/articles/4670292-documents-page) aussehen kann. Bevor Sie diesen Artikel lesen, ist es wichtig, dass Sie die Grundlagen von [Namenskonventionen](https://support.catenda.com/en/articles/7832559-naming-conventions-page) verstehen. Sie können erfahren, wie Sie [benutzerdefinierte Felder](https://support.catenda.com/en/articles/6550459-custom-fields-setup) verwenden, [eine Namenskonvention einrichten](https://support.catenda.com/en/articles/7832559-naming-conventions-page) und [die Konvention](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90) einem Ordner zuweisen. Zunächst möchte ich mit der [einfachsten möglichen Konvention](#h_667e7d43ef) beginnen, um zu erklären, was diese [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) bei Anwendung auf einen Ordner bewirkt. Später im Artikel können wir zu komplexeren Konventionen übergehen.

Die folgenden Themen werden in diesem Artikel beschrieben:

[Ordner und Konventionen](http://Folders%20and%20conventions) - [Ein Dokument hochladen](#h_5a4a3f35ef) - [Dokumente und Konventionen](#h_eb4ed69f2b)

## 1. **Dateiname.Erweiterung**

Lassen Sie uns mit der einfachsten möglichen Konvention beginnen, um zu sehen, wie eine Konvention aussehen kann, wenn sie aktiviert ist. Auf diese Weise wissen Sie, wie Sie erkennen können, wann eine Konvention aktiv ist. Die einfachste mögliche Konvention wird erstellt, indem Sie eine neue Konvention erstellen und sofort auf „Senden

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/01-filename-extension.png)

Diese Konvention akzeptiert Dateien mit beliebigem Namen und beliebiger Erweiterung. Obwohl dies sich nicht vom regulären Upload-Prozess unterscheidet, wird dies in diesem Artikel gemacht, um zu zeigen, wie eine Konvention aussehen kann.

_[Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) auf einen Ordner anwenden_ [Namenskonventionen](https://support.catenda.com/en/articles/7832559-naming-conventions-page) werden pro Ordner in den [Dokumenteinstellungen](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90) aktiviert. Nach Anwendung dieser Konvention auf einen Ordner werden Sie bemerken, dass dieser ein Zahnrad-Symbol hat.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/02-filename-extension.png)

**Informationsbereich:** Wenn Sie den Ordner auswählen, werden Sie auch eine Änderung im Informationsbereich auf der rechten Seite bemerken. Hier wird die [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) des erwarteten Dokumentnamens unter dem Namen des Ordners angezeigt. Wie immer können Sie den Mauszeiger über die [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) bewegen, um Informationen zu den verschiedenen Blöcken anzuzeigen.

### 1.1 Ordner und Konventionen

Wenn Sie einen neuen Ordner in einem Konventionsordner erstellen, werden Sie bemerken, dass dieser ein grau geringeltes Zahnrad-Symbol hat. Dies bedeutet, dass er eine [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) von einem übergeordneten Ordner geerbt hat.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/03-folders-and-conventions.png)

Wenn Sie einen Ordner mit einer angewendeten [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) auswählen, werden Sie eine [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) der Namenskonvention unter dem Namen des Ordners im Informationsbereich auf der rechten Seite sehen. Diese [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) zeigt das Dokumentnamenmuster, das neue Dokumente in diesem Ordner befolgen müssen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/04-folders-and-conventions.png)

### 1.2 Ein Dokument hochladen

Wenn Sie eine Datei in einen Ordner hochladen, auf den eine [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) angewendet wird, werden Sie sehen, dass sie je nach Kriterien der [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) entweder akzeptiert oder abgelehnt wird. Im obigen Beispiel können Name und Erweiterung der Datei beliebige Zeichen beliebiger Länge haben.

Unten sehen Sie, wie es aussieht, wenn eine Datei mit dem Namen test.txt hochgeladen wird:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/05-uploading-a-document.png)

_[Blockvorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc)_ Wie Sie im grauen Bereich unter "Dokument hochladen" sehen können, werden Sie zusätzlich zum Namen des Ordners, in den Sie Ihr Dokument hochladen, auch eine [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) des Dateinamens sehen, den die [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) erwartet. Wenn Sie den Mauszeiger über einen der Blöcke in der [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) bewegen, werden Sie sehen, dass es sich um Dokumentblöcke handelt, die Text mit variabler Länge erwartet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/06-uploading-a-document.png)

Sie können jetzt auf "Hochladen" klicken und die Datei wird hochgeladen.

### 1.3 Dokumente und Konventionen

In einem Ordner, auf den eine [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) angewendet wird, werden Sie sehen, dass Dokumente ein Zahnrad-Symbol auf ihrem Symbol haben. Dieses Symbol bedeutet, dass das Dokument in einem Ordner mit einer angewendeten [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) vorhanden ist. Es ist möglich, dass das Dokument hochgeladen wurde, bevor die [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) angewendet wurde, aber dies bedeutet nicht, dass es die Namensregeln befolgt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/07-documents-and-conventions.png)

Wenn Sie das Dokument öffnen, um es anzuzeigen, werden Sie zunächst feststellen, dass der Dokumentname ausgegraut ist. Dokumentnamen in einem Ordner mit einer [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) befolgen die Regeln der Konvention. Es ist daher nicht möglich, den Namen eines solchen Dokuments zu bearbeiten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/08-documents-and-conventions.png)

_Dieses Dokument entspricht nicht der [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page)_ Wenn eine [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) auf einen Ordner angewendet wird, der bereits Dokumente enthielt, besteht die Möglichkeit, dass der Name der Revision nicht der Konvention entspricht. Sie werden sehen, dass dies der Fall ist, wenn dahinter ein Ausrufezeichen steht.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/09-documents-and-conventions.png)

Dies kann zwei Gründe haben.

1. Der Name der Revisionsdatei stimmt nicht mit dem erwarteten Dateinamen der [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) überein.
1. Der Name der Revisionsdatei stimmt nicht mit dem erwarteten Dokumentergebnis gemäß der [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) überein.
