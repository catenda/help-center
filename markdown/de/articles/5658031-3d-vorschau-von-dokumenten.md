# 3D-Vorschau von Dokumenten

> Zeigen Sie Ihr Modell direkt im Dokumentbereich von Bimsync in der Vorschau an.

Wenn Sie eine IFC- oder [Punktwolke](https://support.catenda.com/en/articles/5606625-point-clouds-in-catenda-hub) in den Dokumentbereich hochladen, wird eine Vorschau generiert, mit der Sie das 3D-Modell im [Dokumentbereich](https://support.catenda.com/en/articles/8204673-documents-page) anzeigen können. Diese Vorschau wird schnell generiert, da nur die Formen der Objekte verarbeitet werden, ohne dass damit verbundene Daten verarbeitet werden. Wenn es ein Problem mit Ihren Daten gibt, können Sie die Vorschau daher auch dann sehen, wenn ein Fehler bei den Eigenschaften Ihrer Objekte vorliegt. Da die Objekte keine ID haben, können Sie diese nicht mit Problemen und Dokumenten verknüpfen. Wenn Sie auf Revisionen klicken, können Sie diese Vorschau auch im [3D-Viewer](https://support.catenda.com/en/articles/8227211-3d-viewer) laden. GUIDs, Eigenschaften und Materialien sind daher im Inspektionsbereich nicht sichtbar. Es ist auch nicht möglich, Eigenschaftsbibliotheken mit diesen Vorschauansichten zu verwenden.
