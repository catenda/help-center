# Benachrichtigungen, die zu Ihnen passen

Es ist wichtig, Benachrichtigungen über Aktionen in Catenda Hub zu erhalten, um den Aktivitäten in den Projekten, an denen Sie beteiligt sind, folgen zu können. Benachrichtigungen finden Sie an mehreren Stellen in Catenda Hub.

## 1. **Kontobenachrichtigungen**

Alle Benachrichtigungen aus allen Projekten sind auf der [Seite Kontobenachrichtigungen](https://support.catenda.com/en/articles/7439223-account-notifications-page) sichtbar. Hier können Sie [alle Benachrichtigungen filtern](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages), die Sie erhalten haben.

### 1.1 **Seite Kontobenachrichtigungen**

Auf der [Seite Kontobenachrichtigungen](https://support.catenda.com/en/articles/7439223-account-notifications-page) sehen Sie alle Benachrichtigungen, die Sie von all Ihren Projekten erhalten haben.

### 1.2 **Seite mit Kontobenachrichtigungseinstellungen**

Sie können auf der [Seite mit Kontobenachrichtigungseinstellungen](https://support.catenda.com/en/articles/8272435-account-notification-settings) konfigurieren, welche Benachrichtigungen Sie für alle Ihre Projekte zusammen erhalten möchten.

## 2. **Projektbenachrichtigungen**

Innerhalb eines Projekts gibt es mehrere Stellen, an denen Sie Benachrichtigungen sehen können.

### 2.1 **Dashboard**

Hier sehen Sie die [5 neuesten Benachrichtigungen](https://support.catenda.com/en/articles/8212646-dashboard-page#h_77effb806b), die von Benutzern im Projekt generiert wurden

### 2.2 **Seite Projektbenachrichtigungen**

Hier sehen Sie alle [von Benutzern generierten Benachrichtigungen](https://support.catenda.com/en/articles/4670295-project-notifications-page) im Projekt. Auf dieser Seite können Sie alle [Benachrichtigungen filtern](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages), die von Benutzern im Projekt generiert wurden.

### 2.3 **Projektspezifische Benachrichtigungseinstellungen**

Hier können Sie [konfigurieren, welche Benachrichtigungen](https://support.catenda.com/en/articles/4670262-project-specific-notification-settings) Sie für das Projekt erhalten möchten, in dem Sie sich befinden. Diese Einstellung überschreibt die Kontobenachrichtigungseinstellung.

### 2.4 **Einstellungen - Mitglieder - Mitglied**

Wenn Sie auf eine Seite mit Mitgliederdaten gehen, sehen Sie die [von diesem Benutzer generierten Themen](https://support.catenda.com/en/articles/8228836-member-page#h_6b76063480) im Projekt.

### 2.5 **Einstellungen - Mitglieder - Team**

Wenn Sie auf einer Mitgliedersseite zu einer Team-Seite gehen, sehen Sie die [Themen, die sich auf dieses Team beziehen](https://support.catenda.com/en/articles/7891755-team-page#h_f91b3824f4) im Projekt.
