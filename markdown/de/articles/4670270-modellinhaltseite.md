# Modellinhaltseite

Um einen Überblick über die Revisionen in einem Modell zu erhalten, gehen Sie zur [Modellseite](https://support.catenda.com/en/articles/4670286-models-page) und klicken Sie auf ein Modell. Sie werden dann zur Übersichtsseite dieses Modells weitergeleitet. Die Modellrevisions-Übersicht zeigt uns die im Projekt vorhandenen Modellrevisionen. Wenn Sie auf eine Modellrevision klicken, werden Sie zur Revisionsseite weitergeleitet. Anschließend können Sie auf "Importieren" klicken und ein neues Revisionsmodell hochladen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/01-intro.png)

## 1. **Vorhandene Elementaktionen**

Die folgende Aktion wird oben rechts auf der Modellübersichtsseite angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/02-existing-item-actions.png)

Die folgenden Aktionen sind für jede Revision verfügbar.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/03-existing-item-actions.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/9674157-actions-on-the-model-overview-page), um mehr darüber zu lesen, was jede Aktion bewirkt.

## 2. **Rechtes Informationsmenü**

Sie können Informationen über das Modell in seinem rechten Informationsmenü finden. Dieses Menü kann durch Klicken auf das Symbol "i" oben rechts auf der Seite aufgerufen werden. Klicken Sie [hier](https://support.catenda.com/en/articles/9673735-right-menu-on-the-models-page), um mehr über die verfügbaren Modellinformationen zu erfahren.

## 3. **Modellname**

Klicken Sie auf das Stiftsymbol, um den Namen des Modells zu ändern

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/04-model-name.png)

## 4. **Revisionen**

### 4.1 **Revisionsimport**

Wenn sich noch keine Revisionen in Ihrem Modell befinden, können Sie auf "Durchsuchen" klicken, um Ihre erste Revision zu importieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/05-revision-import.png)

Sie können auch Drag & Drop verwenden, um eine neue Revision zu importieren, oder die neue Revisionsaktionen im Menü "Vorhandene Elementaktionen" verwenden. _Erforderlich:_ Hochladen von Modellrevisionen aus den [Projekteinstellungen](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3)

Dies geschieht durch Auswahl einer IFC-Datei von Ihrer Festplatte. Obwohl andere Dateitypen in der Rubrik "Dokumente" angezeigt werden können, werden nur IFC-Dateien in der Rubrik "Modelle" akzeptiert. Klicken Sie auf "Senden", um den Upload-Vorgang zu starten.

Nach Abschluss des Vorgangs analysiert Catenda Hub die IFC-Datei und generiert die Geometrie im Hintergrund. Bei großen Modellen kann es einige Zeit dauern, bis die Datei im Viewer zur Bearbeitung bereit ist. Falls gewünscht, können Sie Catenda Hub beenden, die Geometrieerstellung läuft trotzdem ungestört weiter. Nach Abschluss des Imports wird eine Benachrichtigung in der Menüleiste in Catenda Hub angezeigt, und zusätzlich wird Ihnen eine E-Mail gesendet, die angibt, dass eine neue Version in ein Modell hochgeladen wurde, auf das Sie Zugriff haben.

### 4.2 **Kommentare anzeigen**

In der Vergangenheit konnten Sie Kommentare (kurze Erklärung für die Projektbeteiligten darüber, was in der hochgeladenen Revision neu ist) zu Modellrevisionen hinzufügen. Falls diese Kommentare hinzugefügt wurden, können Sie sie immer noch sehen, indem Sie auf "Kommentare anzeigen" klicken.

### 4.3 **Revision im Viewer öffnen**

Es ist möglich, bestimmte Modelle in 2D und 3D zu öffnen, indem Sie auf die entsprechenden Schaltflächen klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/06-open-revision-in-viewer.png)

### 4.4 **Revision herunterladen**

Klicken Sie auf die Download-Schaltfläche, um die neueste Revision eines Modells herunterzuladen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/07-downloading-a-revision.png)

_Erforderlich:_ Lesezugriff auf das Dokument-Modell

## 5. **Modell entladen**

Wenn Sie Catenda Hub öffnen, starten Sie mit frischem Arbeitsspeicher. Sobald Sie ein Modell in 3D laden, sei es über den Bereich "Modelle", den Bereich "Dokumente" oder die Revisionsauswahl des 3D-Viewers, wird das Modell in den Speicher geladen. Auch wenn Sie den 3D-Viewer schließen oder auf 3D klicken, um das Modell erneut zu deaktivieren. Dies führt dazu, dass Sie beim nächsten Mal, wenn Sie auf 3D klicken, Ihr Modell viel schneller aktiviert wird! Beim ersten Mal kann es eine Weile dauern, bis es in den Speicher geladen wird, aber dann können Sie es leicht ein- und ausschalten. Das Modell bleibt im Speicher, bis Sie die Seite aktualisieren, woraufhin alle Modelle entladen werden.

Ein Nachteil ist, dass der Browser, wie Sie bei vielen intensiven japanischen Projekten bemerkt haben, nicht immer alle diese in den Speicher geladenen Modelle verarbeiten kann. Wenn Sie feststellen, dass die Leistung langsamer wird, weil sich Ihr Browser dem Speicherlimit nähert, können Sie die Modellübersicht für Modelle öffnen, die Sie zuvor deaktiviert haben, und sehen die folgende Meldung: "Dieses Modell ist ausgeblendet, aber immer noch im Speicher geladen. Um Speicher freizugeben, klicken Sie hier, um das Modell zu entladen:" Hier können Sie auf "Entladen" in der Nachricht Ihres Screenshots klicken.

Es kann schwierig sein, sich zu merken, welche Modelle Sie zuvor geladen haben, und es ist ziemlich schnell, Modelle zu laden. Wenn Sie sich also dem Limit nähern, würde ich Ihnen empfehlen, die Seite zu aktualisieren und die Modelle zu öffnen, die Sie möchten, anstatt in jede einzelne zu gehen und sie zu entladen.
