# Sharepoint-Bibliothek

> In diesem Artikel wird beschrieben, wie Sie eine Verbindung zu Sharepoint einrichten

Um eine SharePoint-Bibliothek zu erstellen, klicken Sie auf die [Schaltfläche "Neue Bibliothek"](https://support.catenda.com/en/articles/8065645-libraries-page#h_c6d56f227c) oben rechts auf der [Seite "Bibliotheken"](https://support.catenda.com/en/articles/8065645-libraries-page). Diese Bibliothek kann verwendet werden, um Dokumente aus einer SharePoint-Instanz eines Benutzers mit den anderen Mitgliedern des Catenda-Projekts zu teilen. Wenn die SharePoint-Bibliothek aktiviert ist, kann sie etwa wie folgt aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/01-intro.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/9800091-sharepoint-library-short-video), um ein kurzes Video zur Konfiguration der SharePoint-Bibliothek anzusehen.

Nach Eingabe eines Namens für die Bibliothek wird eine neue Registerkarte in Ihrem Browser geöffnet, in der Sie sich mit Ihrem SharePoint-Konto anmelden müssen. Nach der Anmeldung werden Sie zur Seite "Bibliothekseinstellungen" Ihrer SharePoint-Bibliothek weitergeleitet, auf der Sie den SharePoint-Ordner konfigurieren können, den Sie in Catenda anzeigen möchten.

## 1. **Kopfzeile –** Bibliotheksname

Auf der linken Seite der Kopfzeile wird der Name der aktuellen Bibliothek angezeigt. Wenn die Bibliothek synchronisiert ist, wird neben dem Namen ein Häkchen angezeigt. Wenn Sie die Bibliothek synchronisieren, bleibt sie 3 Monate lang synchronisiert. Danach wird möglicherweise ein Ausrufezeichen mit einem Tooltip angezeigt, das besagt, dass die Synchronisierung fehlgeschlagen ist. Gehen Sie in diesem Fall zu den Bibliothekseinstellungen und erteilen Sie den Zugriff erneut.

## 2. **Kopfzeile** – Bibliothekseinstellungen

Auf der rechten Seite der Kopfzeile wird ein Aktionsmenü angezeigt, das etwa wie folgt aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/02-header-library-settings.png)

In den Bibliothekseinstellungen können Sie Ihre SharePoint-Bibliothek konfigurieren. _Erforderlicher Zugriff:_ Bibliothekserstellung

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/03-header-library-settings.png)

### 2.1 **Verbindung**

Wenn Sie Ihr Konto verbunden haben, können Sie auf "Zugriff widerrufen" klicken, um den Zugriff zu widerrufen, den Sie Catenda auf Ihr SharePoint-Konto gewährt haben. Wenn Sie keinen Zugriff gewährt haben, können Sie hier auf "Zugriff erteilen" klicken, um den Zugriffsprozess zu durchlaufen und Catenda Zugriff auf Ihr Konto zu gewähren.

### 2.2 **Details**

Klicken Sie auf das Stiftsymbol, um den Namen dieser Bibliothek zu ändern.

### 2.3 **Geteilter Ordner**

Öffnen Sie dieses Menü und klicken Sie auf "Bearbeiten", um einen geteilten Ordner von einer Ihrer SharePoint-Websites auszuwählen, den Sie in dieser SharePoint-Bibliothek anzeigen möchten.

> **Hinweis:** Damit ein Ordner in dieser Liste angezeigt wird, muss er in SharePoint als öffentlich eingestellt sein

### 2.4 **Zugriffskontrolle**

Hier können Sie festlegen, wer Zugriff auf diese Bibliothek in Ihrem Projekt hat.

### 2.5 **Löschen**

Öffnen Sie dieses Menü und klicken Sie auf "Löschen", um diese SharePoint-Bibliothek aus Ihrem Catenda-Projekt zu entfernen

## 3. **Kopfzeile - Bibliothekseinstellungen -** Neue Bibliothek

Klicken Sie auf die Schaltfläche "Neue Bibliothek", um eine neue Bibliothek zu erstellen

## 4. **Filtermenü**

### 4.1 **Gespeicherte Filter**

Klicken Sie [hier](https://support.catenda.com/en/articles/8551755-saving-filters), um mehr darüber zu erfahren, wie Sie einen Satz von Filtern speichern

### 4.2 **Nicht verknüpft -** `link=unlinked`

Mit diesem Filter können Sie nach allen Dokumenten filtern, die nicht mit Objekten verknüpft sind.

### 4.3 **Mit ausgewählten Objekten verknüpft -** `link=backlink`

Wenn Sie Objekte im 3D-Viewer ausgewählt haben, die mit SharePoint-Dokumenten verbunden sind, können Sie hier nach ihnen filtern.

## 5. **SharePoint-Dokumentliste**

Hier können Sie alle Dokumente und Ordner im gemeinsamen Ordner navigieren, der für diese Bibliothek konfiguriert ist.

### 5.1 **Aktionen**

Nachdem Sie ein oder mehrere Dokument(e) oder Ordner ausgewählt haben, wird ein Aktionsmenü oben in der Dokumentenliste angezeigt. Das Menü "Aktionen für vorhandene Elemente" kann folgendermaßen aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/04-actions.png)

**Verknüpfen/Verknüpfung aufheben** Wenn Sie ein Objekt aus einem model in 3D auswählen, können Sie es mit Ihren ausgewählten Elementen verknüpfen/die Verknüpfung aufheben.

**Vorschau** Öffnen Sie eine Vorschau des Dokuments, ohne die Dokumentenseite laden zu müssen. Dies kann besonders in einem Ordner mit vielen Bildern nützlich sein. Nur sichtbar, wenn ein einzelnes Dokument ausgewählt ist

**Herunterladen** Klicken Sie auf Herunterladen, um Ihr ausgewähltes Dokument herunterzuladen. Nur sichtbar, wenn ein einzelnes Dokument ausgewählt ist

### 5.2 **Name**

Klicken Sie auf den Namen eines Ordners, um seinen Inhalt anzuzeigen. Klicken Sie auf den Namen eines Dokuments, um seinen Inhalt anzuzeigen

### 5.3 **URL**

Klicken Sie auf die Download-Schaltfläche in dieser Spalte, um das Dokument herunterzuladen.

### 5.4 **Links**

Wenn Objekte mit Ihren Dokumenten verknüpft wurden, können Sie hier die Anzahl der verknüpften Objekte sehen. Wenn Sie auf diese Nummer klicken, können Sie:

**Objekte auswählen**

**Objekte isolieren**

**Als Suche laden**

## 6. **Recht-Informationsmenü**

Wenn Sie zum ersten Mal ein Dokument in der Dokumentliste öffnen, ist das rechte Menü möglicherweise geschlossen. Sie können auf die Schaltfläche Informationen unten rechts auf dem [Dokumentbanner](https://support.catenda.com/en/articles/8461918-document-banner-actions-navigation) klicken, um dieses Menü zu erweitern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/05-right-information-menu.png)

### 6.1 **Verknüpfte Objekte**

Hier können Sie Objekte mit Ihren SharePoint-Dokumenten verknüpfen.

### 6.2 **Themen**

Nach dem Öffnen eines Dokuments können Sie das Menü Themen sehen. Hier können Sie Ihre SharePoint-Dokumente mit Themen verknüpfen.

## 7. **Berechtigungen**

Wenn Dokumente aus einer SharePoint-Dokumentbibliothek zu Catenda hochgeladen werden, wird die SharePoint-REST-API verwendet (über die [pnpjs](https://pnp.github.io/pnpjs/)-Bibliothek). Da diese Berechtigungen standardmäßig für spfx-Lösungen erteilt werden, ist keine zusätzliche Genehmigung erforderlich. Die folgenden Genehmigungen sind erforderlich, damit die App auf das Catenda-Backend zugreifen kann. Es werden nur delegierte Berechtigungen mit den folgenden Bereichen verwendet: _[User.Read](https://graphpermissions.merill.net/permission/User.Read) [offline\_access](https://graphpermissions.merill.net/permission/offline_access) [Files.Read](https://graphpermissions.merill.net/permission/Files.Read)_ _[Sites.Read.All](https://graphpermissions.merill.net/permission/Sites.Read.All)_ Der oben genannte Zugriff wird nur verwendet, um die Freigabe von Dokumenten für das Catenda-Projekt des Benutzers zu genehmigen.
