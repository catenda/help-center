# Themen-Vorlagen mit Genehmigungen verwenden

> Wenden Sie eine Genehmigungsthemen-Vorlage auf eine Genehmigungsworkflow-Vorlage an

Genehmigungsthemen-Vorlagen können sowohl auf der [Seite "Themenvorlagen-Einstellungen"](https://support.catenda.com/en/articles/14076010-topic-template-settings-page) konfiguriert werden als auch durch Klicken auf das Dropdown-Menü für Themenvorlagen im Menü "Endgültige Genehmigung" der neuen Genehmigungsworkflow-Seite und Auswahl zum Erstellen einer neuen Themenvorlage. _Erforderlicher Zugriff:_ Projektadministrator Seite mit Themenvorlagen-Einstellungen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2dv1747h/01-intro.png)

ODER Workflows konfigurieren

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2dv1747h/02-intro.png)

Erstellen Sie eine neue Themenvorlage auf der neuen Workflow-Seite.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2dv1747h/03-intro.png)

> **Wichtig:** ℹ️ Damit ein Thema als Ergebnis des Abschlusses einer Genehmigung generiert wird, muss die Genehmigung **eine Markierung enthalten**. Nach dem Abschluss der konfigurierten Genehmigung wird für jede Markierung in der Genehmigung ein separates Thema generiert.

1. Wenn ein neuer Genehmigungsworkflow erstellt wird.
   Sie [erstellen einen neuen Genehmigungsworkflow](https://support.catenda.com/en/articles/12313251-creating-a-new-workflow) Vorlage, navigieren Sie zum unteren Ende der Seite, bis Sie den Abschnitt "Endgültige Genehmigung" erreichen.
   Hier können Sie eine Genehmigungsthemen-Vorlage für jeden Überprüfungsstatus verknüpfen (und den endgültigen Dokumentstatus zuordnen).

    <div class="intercom-container intercom-align-center"><img height="254" src="https://raw.githubusercontent.com/catenda/help-center/main/images/2dv1747h/inline-e90e5114173a.png" style="height: auto;" width="500"/></div>

1. Stellen Sie sicher, dass Sie alle vorherigen erforderlichen Felder aus der Genehmigungsworkflow-Vorlage ausgefüllt haben, und klicken Sie auf die Schaltfläche "Absenden".
1. Führen Sie einen Genehmigungsworkflow durch.
   Nachdem alle Überprüfungen durchgeführt wurden und sobald der Genehmigungsworkflow geschlossen ist, werden die zugeordneten Genehmigungsthemen automatisch generiert und automatisch mit allen Feldern gefüllt, die in den zugeordneten Themenvorlagen-Einstellungen festgelegt wurden, auf die über die [Seite "Themenvorlagen-Einstellungen"](https://support.catenda.com/en/articles/14076010-topic-template-settings-page) zugegriffen werden kann.
   Damit ein Thema als Ergebnis des Abschlusses einer Genehmigung generiert wird, muss die Genehmigung eine Markierung enthalten.
   Wenn eine Genehmigungsthemen-Vorlage für den Workflow konfiguriert ist, dem die Genehmigung folgt, werden Themen generiert, wenn die Genehmigung geschlossen wird.
   Für jede Markierung in der Genehmigung wird ein separates Thema generiert.
