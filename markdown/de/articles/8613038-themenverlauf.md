# Themenverlauf

Sie können die Schaltfläche für den Themenverlauf oben in der [Themenseite](https://support.catenda.com/en/articles/8053352-issue-body) finden. Durch Anklicken dieser Schaltfläche werden alle Änderungen angezeigt, die am Thema während seiner Zeit in Ihrem Catenda-Projekt vorgenommen wurden.

Im Themenverlauf können Sie Informationen zu den folgenden Themen finden:

## 1. **Titel**

_Titel festgelegt auf: \<Title> -_ Dies wird immer festgelegt, wenn ein neues Thema erstellt wird

## 2. **Status und Typ**

### 2.1 **Status**

_Status auf \<Status> gesetzt -_ Der Status, der auf das Thema angewendet wurde _Status geändert zu \<Status> -_ Wenn sich der Status geändert hat, wird er hier angezeigt.

### 2.2 **Typ**

_Typ auf \<Type> gesetzt -_ Der Typ, der auf das Thema angewendet wurde _Status geändert zu \<Type> -_ Wenn sich der Typ geändert hat, wird er hier angezeigt.

## 3. **Zeitplan**

### 3.1 **Meilensteine**

_Meilenstein geändert zu \<Milestone>_ - Sehen Sie, welcher Meilenstein hinzugefügt wurde

### 3.2 **Fälligkeitsdatum**

_Fälligkeitsdatum geändert zu \<Due date>_ - Sehen Sie, welches Fälligkeitsdatum hinzugefügt wurde _Fälligkeitsdatum geändert zu \<Due date>_ \<Due time> Sehen Sie, welches Fälligkeitsdatum und welche Fälligkeit hinzugefügt wurden

## 4. **Beiträge**

### 4.1 **Beschreibung**

_Beschreibung geändert -_ Klicken Sie auf dieses Feld, um zu sehen, wie die vorherige Beschreibung aussah.

**Beschreibung festgelegt** Klicken Sie auf dieses Feld, um zu sehen, wie die Beschreibung des Themas bei der Erstellung aussah

### 4.2 **Bemerkungen**

_Kommentar gelöscht_ - Sehen Sie, ob ein Kommentar gelöscht wurde _Kommentar geändert_ - Dies hat kein Feld, aber Sie sehen die Zeit der ursprünglichen Aktion und die Zeit der letzten Bearbeitung.

## 5. **Etikett**

_Etikett hinzugefügt \<Label name>_ - Das hinzugefügte Etikett Alle Etiketten, die zum Thema hinzugefügt wurden. Wenn das Etikett gelöscht wurde, wird es durchgestrichen.

_Etikett hinzugefügt \<Label name>_ - Das Etikett, das entfernt wurde

## 6. **Benutzerdefiniertes Feld**

**\<Custom field> auf \<Custom field value> gesetzt** Wenn ein benutzerdefiniertes Feld zugewiesen wurde, wird es hier angezeigt

**\<Custom field> geändert zu \<Custom field value>** Sehen Sie, wie sich der Wert des benutzerdefinierten Feldes geändert hat

## 7. **Bild**

_Bild hinzugefügt_ - Wenn ein Bild hinzugefügt wurde, wird es hier angezeigt _Bild entfernt_ - Wenn ein Bild, das an einen Kommentar angehängt war, aus dem Thema entfernt wurde.

## 8. **Verantwortung**

### 8.1 **Zugewiesener Benutzer**

Zugewiesener Benutzer auf \<User> gesetzt Zugewiesener Benutzer auf \<User> \<Team> gesetzt Zugewiesener Benutzer geändert zu \<New user> Zugewiesener Benutzer geändert zu \<New user> \<New Team> Zugewiesenes Team auf \<Team> gesetzt Zugewiesenes Team geändert \<New team> Zugewiesener Benutzer entfernt

### 8.2 **Anfordernder Benutzer**

Anfordernder Benutzer auf \<User> gesetzt Anfordernder Benutzer auf \<User> \<Team> gesetzt Anfordernder Benutzer geändert zu \<New user> Anfordernder Benutzer geändert zu \<New user> \<New Team> Anforderndes Team auf \<Team> gesetzt Anforderndes Team geändert \<New team> Vom Benutzer angefordert entfernt

## 9. **Themenbewegung**

Thema _wurde von \<_Topic _board>_ verschoben - Sehen Sie, welches Themen-Board dieses Thema ursprünglich war

## 10. **Dokument-Links**

_Dokument verknüpft \<Document name>_ - Sehen Sie, welches Dokument mit diesem Thema verknüpft wurde _Dokument nicht verknüpft \<Document name>_ - Sehen Sie, welches Dokument von diesem Thema nicht verknüpft wurde
