# Boards-Seite

Sie finden die Boards-Seite als Unterseite der [Themen-Seite](https://support.catenda.com/en/articles/4670271-topics-page). Die Boards-Seite gibt Ihnen einen Überblick über Ihre verfügbaren topic boards.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zq777cpq/01-intro.png)

## 1. **Boards-Aktionen**

### 1.1 **Neues topic board**

Mit der neuen Topic-Board-Aktion können Sie das Fenster zum Erstellen eines neuen Topic Boards öffnen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zq777cpq/02-new-topic-board.png)

Die neue Topic-Board-Seite könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zq777cpq/03-new-topic-board.png)

Geben Sie den Namen und die Beschreibung ein und klicken Sie auf "Hinzufügen". Klicken Sie [hier](https://support.catenda.com/en/articles/6379614-topic-board-from-an-existing-topic-board), um mehr über das Erstellen neuer Topic Boards zu erfahren. _Erforderlicher Zugriff:_ Schreibzugriff zum [Erstellen neuer Topic Boards](https://support.catenda.com/en/articles/4670299-topic-board-creation-acl) in [Projekteinstellungen](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3).

## 2. **Topic Board-Liste**

Von hier aus haben Sie einen vollständigen Überblick über alle Topic Boards. Die Topic Board-Liste könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zq777cpq/04-topic-board-list.png)

### 2.1 **Topic Board-Name**

Durch Anklicken des Topic Board-Namens können Sie direkt zum Topic Board springen. _Erforderlicher Zugriff:_ Lesezugriff auf das Topic Board.

### 2.2 **Einstellungen**

Klicken Sie auf die Schaltfläche "Einstellungen", um zu den [Einstellungen dieses Boards](https://support.catenda.com/en/articles/4670277-topic-board-settings) zu wechseln. Sie können auch das Board öffnen und das Einstellungsmenü im linken Navigationsmenü auswählen. _Erforderlicher Zugriff:_ Vollständiger Zugriff auf das Topic Board

### 2.3 **Statistiken**

Klicken Sie auf "Statistiken", um die Statistikseite für dieses Board zu öffnen. _Erforderlicher Zugriff:_ Lesezugriff auf das Topic Board.

### 2.4 **Archiviert**

Wenn Sie unten in der Liste auf "Archivierte anzeigen" klicken, können Sie archivierte Topic Boards öffnen. _Erforderlicher Zugriff:_ Projektadministrator
