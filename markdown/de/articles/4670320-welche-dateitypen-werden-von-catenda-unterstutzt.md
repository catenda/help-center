# Vorschau von Dateitypen auf Catenda Hub

Für unseren Modell-Viewer unterstützen wir nur IFCs. Alle Dateitypen können in unserem Dokumentenbereich hochgeladen werden.

> **Hinweis:** IFC-, Punktwolken- (e57, las) und GML-Vorschauen können im 3D-Viewer geladen werden.

## 1. **Herstellerneutrale Formate**

Bei Catenda arbeiten wir gerne mit offenen Standards, damit jeder unabhängig von der verwendeten Software zusammenarbeiten kann.

_Typischerweise kann jeder an ihrer Entwicklung teilnehmen, weil sie von Natur aus offen sind ([Wikipedia](https://en.wikipedia.org/wiki/Open_standard#:~:text=Typically%2C%20anybody%20can%20participate%20in%20their%20development%20due%20to%20their%20inherently%20open%20nature.))_

Das bedeutet, dass nicht nur eine Organisation kontrolliert, was entwickelt wird.

### 2.1 **IFC-Versionen**

Je nach Status der IFC-Version unterstützen wir die Version auf unterschiedliche Weise: _Offiziell, Veraltet_ - Vollständige Unterstützung. Alle offiziellen und veralteten IFC-Versionen werden unterstützt. _Zurückgezogen_ - Teilweise Unterstützung. Modelle werden nach der letzten offiziellen Version verarbeitet. _In Entwicklung_ - Keine Unterstützung. Diese könnten sich vor der Veröffentlichung noch ändern.

Sie können hier finden, welche IFC-Versionen offiziell sind [hier](https://technical.buildingsmart.org/standards/ifc/ifc-schema-specifications/) Offizielle BuildingSMART-Beispiel-IFC-Dateien finden Sie [hier](https://github.com/buildingSMART/Sample-Test-Files)

### 2.2 **Punktwolken**

Punkte in Punktwolken können entweder mit Farbe oder Intensität angezeigt werden.
