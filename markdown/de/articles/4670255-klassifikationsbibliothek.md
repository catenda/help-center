# Klassifikationsbibliothek

Klassifikationsbibliotheken sind eine einfache und praktische Möglichkeit, vorhandene Daten in das BIM einzubringen. Sie können verwendet werden, um Objekte mit Informationen zu taggen.

Benutzerdefinierte Bibliotheken können als einfache Tabellen (csv) hochgeladen werden. Solange der "Code" beibehalten wird, bleibt die Verknüpfung zwischen einem oder mehreren Bibliothekelemente(n) und dem/den Objekt(en) erhalten. Wenn die Zeichenkette in der Spalte "Sort" hierarchisch ist, wird eine Überordnungs-Unterordnungs-Beziehung erstellt (so wird 1.1 ein Unterelement von 1).

Beginnen Sie damit, eine neue Klassifikationsbibliothek zu erstellen und zu speichern. Gehen Sie dann zur Bibliothek und laden Sie eine CSV-Datei hoch, indem Sie die Schaltfläche + drücken und die hochzuladende CSV-Datei auswählen.

Im folgenden Beispiel wurde eine Bibliothek mit mehreren Status verwendet, um ein Objekt mit dem aktuellen Stand des Fensters im Produktionsprozess zu markieren/taggen.

Um ein Bibliothekelementelement aus einer benutzerdefinierten Bibliothek allen ausgewählten Objekten zuzuweisen, klicken Sie auf das Kontrollkästchen links neben dem Inhaltselement. Dies funktioniert genauso wie das Taggen von Dokumenten zu Objekten. Der Inhalt, der einem Objekt zugewiesen wurde, wird auf der Registerkarte "Inspizieren" angezeigt.

Alle Bibliothekeninhalte und Attribute, die in Catenda Hub hinzugefügt wurden, können in die IFC-Dateien zusammengeführt werden, wenn Sie das Projekt exportieren.
