# Status-Workflow – Dokumenteinstellungen – Legacy

Das Menü für den Status-Workflow finden Sie auf der [Seite Dokumenteinstellungen](https://support.catenda.com/en/articles/7831371-document-settings-page). In neuen Projekten ist der Status-Workflow standardmäßig deaktiviert. Es ist möglich, ein Projekt mit vorkonfigurierten Status zu starten, wenn das Projekt auf einem [Vorlagenprojekt](https://support.catenda.com/en/articles/4670245-creating-a-new-project#h_5db32e5398) basiert.

So kann das Menü für den Status-Workflow nach der Aktivierung des Status-Workflows aussehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/j19gh65w/01-intro.png)

Wenn der Status-Workflow aktiviert wird, ändern sich die folgenden Dinge im Projekt:

- Die Phasen Entwurf und Veröffentlicht werden verfügbar.
  - Veröffentlicht – Der Status Veröffentlicht befindet sich standardmäßig in der Liste.
  - Entwurf – Die Status In Bearbeitung und Geteilt befinden sich standardmäßig in der Liste
- Neue Informationen, die in der Entwurfsphase eingereicht werden, standardmäßig.
  - Kann mit Kontrollkästchen in der veröffentlichten Phase hochgeladen werden.
- Der Standardstatus ist auf Kein Status festgelegt.
- Ein Genehmigungsmenü in den Dokumenteinstellungen wird angezeigt.
- Eine [Genehmigungen](https://support.catenda.com/en/articles/5784717-document-approval)-Unterseite auf der Seite Dokumente wird angezeigt.

## 1. **Status hinzufügen**

Sie können einen Status hinzufügen, indem Sie auf Status hinzufügen klicken. Ein neuer Status kann eine Farbe und einen Namen haben und kann entweder eine veröffentlichte oder eine Entwurfsphase sein.

## 2. **Status ändern**

Der Status kann bearbeitet werden, indem Sie auf die Schaltfläche mit dem Stiftsymbol rechts neben dem Status klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/j19gh65w/02-changing-statuses.png)

Die Farbe und der Name eines Status können geändert werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/j19gh65w/03-changing-statuses.png)

### 2.1 **Sortierreihenfolge**

Klicken Sie nach dem Bearbeiten auf die Pfeile, um den Status in der Liste der Status in der Phase nach oben und unten zu verschieben.

### 2.2 **Status archivieren**

Status können archiviert werden, indem Sie auf die Schaltfläche mit dem Papierkorbsymbol rechts neben dem Status klicken. Es ist nur möglich, den Status in derselben Phase zu archivieren und wiederherzustellen. Wenn der jetzt archivierte Status auf Informationen angewendet wurde, wird der Status sichtbar, aber durchgestrichen. Um nur veröffentlichte Status zu verwenden, archivieren Sie alle Entwurfsstatus. Um den Status-Workflow zu deaktivieren, archivieren Sie alle Entwurfs- und veröffentlichten Status.

### 2.3 **Status wiederherstellen**

Archivierte Status können immer wiederhergestellt werden, indem Sie auf "Archivierte Status anzeigen" klicken. Hier werden alle archivierten Status angezeigt und können wiederhergestellt werden.

## 3. **Standardstatus**

Wenn eine neue veröffentlichte Version entweder durch Hochladen oder durch Veröffentlichung von Entwürfen als Ergebnis einer [Genehmigung](https://support.catenda.com/en/articles/5784717-document-approval) erstellt wird, können Sie auswählen, welcher Status sie standardmäßig hat. Dieser Status kann immer noch vor der Veröffentlichung jedes Dokuments geändert werden.

## 4. **Hochladen-Menü**

So kann das Hochladen-Menü aussehen, wenn der Status-Workflow noch nicht aktiviert ist.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/j19gh65w/04-upload-menu.png)

So kann das Hochladen-Menü aussehen, wenn der Status-Workflow aktiviert wurde.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/j19gh65w/05-upload-menu.png)

### 4.1 **Standardmäßig Entwurf**

Standardmäßig ist das Kontrollkästchen "Als Entwurf hochladen" aktiviert. Dieses Kontrollkästchen kann deaktiviert werden, um stattdessen als veröffentlicht hochzuladen. Standardmäßig ist der Standardstatus für Entwürfe "In Bearbeitung", das erste in der Liste. Ein Status aus der Liste der Entwurfsstatus kann vor dem Hochladen ausgewählt werden.

### 4.2 **Deaktivieren zum Hochladen als veröffentlicht**

Wenn das Kontrollkästchen "Als Entwurf hochladen" deaktiviert ist, werden Informationen als veröffentlicht hochgeladen. Standardmäßig ist der Standardstatus für veröffentlichte Inhalte "Kein Status". Ein Status aus der Liste der veröffentlichten Status kann vor dem Hochladen ausgewählt werden.
