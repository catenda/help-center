# Eigenschaftswert-Bibliothek

Mit der neuen Eigenschaftswert-Bibliothek können Sie Catenda Hub die Werte einer bestimmten Eigenschaft über alle Modelle Ihres Projekts hinweg indexieren. Um beispielsweise eine Liste aller LOD (Level of Detail) oder MMI (Model Maturity Index) mit Links zu allen zugehörigen Objekten anzuzeigen.

Sie können Werte aus Eigenschaften in Eigenschafts- oder Mengensätzen indexieren, und jeder der gefundenen Werte wird mit einem Link zu den zugehörigen Objekten aufgelistet.

Mit dieser Bibliothek können Sie Objekte entweder nach Eigenschaft/Parameter auswählen, isolieren oder abfragen

Sie können die Funktion in Aktion im folgenden Video sehen:

[YouTube-Video](https://www.youtube.com/embed/_PK6jWcZKkQ?rel=0)

Wenn die Eigenschaftsbibliothek erstellt wird, kann die Synchronisierung ihrer Eigenschaften eine Weile dauern. Dies liegt daran, dass alle Eigenschaften aller Objekte aller neuesten Versionen aller Modelle auf diese Eigenschaft überprüft werden müssen.

Wenn später eine Modellversion hinzugefügt wird, wird die Bibliothek erneut synchronisiert. Dieses Mal wird es schneller gehen, da nur die neue Modellversion überprüft werden muss.
