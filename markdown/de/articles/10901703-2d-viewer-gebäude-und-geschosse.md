# 2D-Viewer Gebäude und Geschosse

Informationen darüber, welcher 2D-Schnitt durch Modellobjekte angezeigt wird und welche Zeichnungen unter diesen Schnitten im 2D-Viewer liegen, finden Sie unten rechts im 2D-Viewer. Das Gebäude- und Geschossmenü kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/01-intro.png)

## 1. **Geschoss sperren**

### 1.1 **Gesperrt**

Das aktuelle Geschoss wird immer angezeigt

### 1.2 **Entsperrt**

Das aktuelle Geschoss ist das Geschoss, das der Kamerahöhe am nächsten kommt. Dies ist besonders nützlich im [Gehenmodus](https://support.catenda.com/en/articles/5784718-3d-viewer-settings), wo das Geschoss wechselt, wenn Sie beispielsweise eine Treppe hinaufgehen.

## 2. **Gebäudemenü**

Wenn ein Gebäude im [Geschosskonfigurator](https://support.catenda.com/en/articles/6921756-storey-configurator-page) konfiguriert wurde, können Sie das Gebäudemenü sehen. Das Gebäudemenü kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/02-building-menu.png)

### 2.1 **Geschosskonfigurator-Gebäude**

Zunächst werden alle Gebäude aufgelistet, die im Geschosskonfigurator erstellt wurden. Diese Gebäude können Geschosse enthalten, in denen mehrere 2D-Ansichten von Modellen kombiniert werden und Zeichnungen darunter liegen können.

### 2.2 **Modellgebäude**

Anschließend werden die Gebäude aufgelistet, die in jedem Modell verfügbar sind, für das die 2D-Ansicht aktiviert wurde. Wenn die 2D-Ansicht für ein Modell aktiviert ist, ist die 2D-Schaltfläche aktiv:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/03-model-buildings.png)

Der Name eines Modellgebäudes wird in der IFC-Datei der aktuellen Überarbeitungsversion unter der Entität IfcBuildingStorey konfiguriert. Wenn das Modellgebäude keinen Namen hat, wird es hier als unbenanntes Gebäude angezeigt.

## 3. **Geschossmenü**

Im Geschossmenü sehen Sie die Geschosse des aktuellen Gebäudes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/04-storey-menu.png)

Klicken Sie auf das Menü, um zu sehen, welche Geschosse in Ihrem Gebäude verfügbar sind. Wenn das Gebäude einen Namen hat, wird dieser fett oben in der Liste angezeigt. Dieses Menü ist nicht verfügbar, wenn das aktuelle Gebäude keine Geschosse hat.
