Diese Seite enthält Informationen zu den folgenden Themen: [Planung](#h_595c5ebf4c) - [Aktionen](#h_ef3bbf0441)​ - [Milestones-Liste](#h_5403eb541f)

## 1. Planung

Milestones können auf vielfältige Weise genutzt werden:

- Zum Festlegen eines Fälligkeitsdatums jedes Quartal
- Festlegen eines Fälligkeitsdatums zum Ende des Monats
- Vor Baubeginn

Milestones können als Werkzeug zum Festlegen von mehr als einem Fälligkeitsdatum verwendet werden. Wenn Sie ein Fälligkeitsdatum für ein Thema festlegen, können Sie ein Milestone wählen, zu dem das Thema gehört.

## 2. Aktionen

Oben rechts auf der Seite finden Sie die folgenden Aktionen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5tw3m693/03-actions.png)

### 2.1 Neues Milestone

Klicken Sie auf das grüne + oder auf die Aktion "Neues Milestone" im Aktionsmenü, um ein neues Milestone zu erstellen.

### 2.2 Archivierte Milestones

Klicken Sie auf diese Aktion, um zu sehen, welche Milestones im Projekt archiviert wurden.

## 3. Milestones-Liste

In der Milestones-Liste sehen Sie einen Überblick über alle Milestones, die Teil des Projekts sind. Die Milestones-Liste kann ungefähr so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5tw3m693/04-milestones-list.png)

Klicken Sie auf einem beliebigen Ort auf dem Milestone, um die Seite für dieses Milestone zu öffnen. Für jedes Milestone sehen Sie die folgenden Informationen

### 3.1 Titel

Der Titel des Milestones

### 3.2 Fälligkeitsdatum

Hier sehen Sie eine Flagge und das Fälligkeitsdatum des Milestones. Die Flagge ist rot, wenn das Fälligkeitsdatum in den nächsten zwei Wochen liegt, grau, wenn es mehr als zwei Wochen in der Zukunft liegt, und rosa, wenn das Milestone abgelaufen ist.

### 3.3 Beschreibung

Die Beschreibung des Milestones

### 3.4 Themenstatistik

In der Themenstatistik des Milestones können Sie sehen, wie der Fortschritt dieses Milestones für alle Themenseiten zusammen ist. Weitere themenbereichsspezifische Daten finden Sie auf der Milestone-Seite.

**Prozentsatz** Hier sehen Sie den Prozentsatz der Themen, denen dieses Milestone zugewiesen wurde und die in allen Themenseiten geschlossen sind. Kandidatenthemen werden nicht in diesen Prozentsatz eingerechnet.

**Offen/geschlossen/Kandidat** Hier sehen Sie die Anzahl der Themen mit offenen, geschlossenen oder Kandidaten-Metastatus, denen dieses Milestone zugewiesen wurde. Klicken Sie auf das Wort Offen, Geschlossen oder Kandidat, um die entsprechenden Themen auf der Seite "Alle Themen" anzuzeigen.

**Mitgliederfoto** Hier sehen Sie zuerst den Ersteller des Milestones und das nicht zugewiesene Symbol. Für jedes Profilfoto sehen Sie eine Anzahl von Themen. Für den Milestone-Ersteller und Nicht zugewiesen kann diese Anzahl 0 sein und wird dann grün angezeigt. Andere Benutzer werden nur angezeigt, wenn sie offene Themen haben, denen dieses Milestone zugewiesen wurde, mit einer Anzahl offener Themen, denen sie in rot zugewiesen wurden.

### 3.5 Erstellt von

Hier sehen Sie den Namen des Benutzers, der das Milestone erstellt hat, und das Datum, an dem das Milestone erstellt wurde.
