## 2. **Desktop Connector**

- Verbindet Ihren Desktop mit Catenda
- Planen Sie Downloads aus dem Dokumenten-Repository auf Catenda an einen definierten Ort auf Ihrem PC
- Planen Sie Uploads von einem definierten Ort auf Ihrem PC in das Dokumenten-Repository auf Catenda
- Führen Sie diese geplanten Downloads und Uploads täglich durch

## 3. **Navisworks**

- Zugriff auf alle Ihre Catenda-Projekte
- Austausch von Themen zwischen Catenda und Navisworks
- Lokalisieren Sie Clash-Objekte in Navisworks
- Erstellen Sie BCF-Themen aus Clashes in Navisworks
- Greifen Sie auf die Dokumentenbibliothek auf Catenda zu, um jedes von Navisworks unterstützte Dateiformat zu öffnen
- Zugriff auf alle Modellrevisionen (nicht nur die neueste)
- Speichern Sie Ihre NWD-Datei direkt in Catenda
- Konsolidieren Sie Ansichtspunkte, wenn Sie ein Thema aus einer Gruppe oder mehreren Clashes erstellen (erstellen Sie einen Ansichtspunkt mit allen Clashes)

## 4. **Revit**

- Zugriff auf alle Ihre Catenda-Projekte
- Austausch von Themen zwischen Catenda und Revit
- Exportieren Sie IFC-Modelle in Catenda
- Lokalisieren Sie Clash-Objekte in Revit
- Erstellen Sie BCF-Themen (2D und 3D) in Revit
