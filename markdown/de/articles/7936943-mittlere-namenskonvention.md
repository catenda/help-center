# Mittlere Namenskonvention

Dieser Artikel baut auf dem Artikel [Einfachste Namenskonvention](https://support.catenda.com/en/articles/7845360-simplest-naming-convention) auf, kann aber auch ohne vorherige Lektüre befolgt werden. Es gibt einen Folgeartikel mit dem Namen [Erweiterte Namenskonvention](https://support.catenda.com/en/articles/7936947-advanced-naming-convention).

## 1. A001-Dateiname.erweiterung

Angenommen, Sie haben einen Code für Ihre lokalen Dateien, der aus dem ersten Buchstaben des Projekts und einer Nummer besteht, die wie A001, A002, A003, M001, M002 usw. aussieht. Um Ihren [Dokumentbereich](https://support.catenda.com/en/articles/4670292-documents-page) organisiert zu halten, möchten Sie sicherstellen, dass alle Ihre Dateien diesen Code haben. Es spielt keine Rolle, dass mehrere Dateien den gleichen Code haben, solange sie den Code haben. Dies kann Ihren [Dokumentbereich](https://support.catenda.com/en/articles/4670292-documents-page) klarer und organisierter gestalten, damit Sie sich in der riesigen Menge an Dateien, die wir heutzutage generieren, nicht verlaufen.

### 1.1 **Anfangseinrichtung**

Dies ist der erste Schritt zur Angabe von Einstellungen für die Dateibenennung. Versuchen wir für dieses Beispiel, einen Text-[Block](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) zur Konvention mit einer Länge von 4 hinzuzufügen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/01-initial-setup.png)

Nun [weisen Sie die Konvention](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90) einem Ordner zu und versuchen Sie, eine Datei mit dem Namen text.txt hochzuladen, um zu sehen, was passiert.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/02-initial-setup.png)

Wie Sie sehen können, erhalten wir einen Fehler und können unsere Datei nicht hochladen. Natürlich ist das der Fall, weil ich vergessen habe, dir zu sagen, dass du einen Code zum Dateinamen hinzufügen musst.... Entschuldigung.

### 1.2 **Ändern des Dateinamens, um die Konvention einzuhalten**

Wenn Sie sich jemals fragen, welcher [Block](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) fehlt, können Sie die [Vorschau](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) neben der Namenskonvention in Grau ansehen. Sie haben jetzt zwei Möglichkeiten, den Namen Ihrer Datei zu ändern, damit sie erfolgreich hochgeladen werden kann. Sie können den Dateinamen lokal ändern oder den Namen im Upload-Dialog bearbeiten. Ändern Sie den Namen zu A0001-test.txt und Sie werden sehen, dass OH?!

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/03-changing-the-file-name-to-fit-the-convention.png)

Nochmals, die Datei wurde nicht akzeptiert, Sie wurden aufgefordert, zu viele Nullen zum Code Ihrer Datei hinzuzufügen! Keine Sorge, die Namenskonvention teilt Ihnen mit, welcher [Block](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) ein Problem aufweist und wie lang Ihr Code sein soll. Ändern Sie jetzt den Namen der Datei zu A001-test.txt und Sie werden sehen, dass die Datei akzeptiert wird.

### 1.3 **Trennzeichen**

Achten Sie darauf, einen Bindestrich _( - )_ zwischen den beiden [Blöcken](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) zu verwenden, da dies als [Trennzeichen](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=in%20document%20settings-,Separator,-%3A%20The%20character) gewählt wurde. Sie können Ihre Datei jetzt hochladen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/04-separator.png)

Um mehr über Namenskonventionen zu erfahren, lesen Sie den folgenden Artikel: [Erweiterte Namenskonvention](https://support.catenda.com/en/articles/7936947-advanced-naming-convention)
