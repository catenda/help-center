# Verfolgung von Informationen durch Verlinkung

Es gibt mehrere Möglichkeiten, Teile von Catenda Hub mit anderen Teilen von Catenda Hub zu verlinken. Wenn Sie sich die rechten Informationspanels an verschiedenen Stellen ansehen, können Sie feststellen, welche Informationen mit dem Element verlinkt wurden, das Sie gerade ansehen. Dieser Artikel beschreibt gute Möglichkeiten, um sicherzustellen, dass Ihre Elemente verlinkte Elemente haben. Elemente können manuell verlinkt werden, indem Sie an verschiedenen Stellen auf Links klicken. In diesem Artikel finden Sie auch einige Tipps und Tricks, wie Sie so arbeiten können, dass alles automatisch verlinkt wird, ohne dass Sie jedes Mal auf Links klicken müssen.

## 1. **Verlinkung von Themen**

Sie können im [rechten Panel](https://support.catenda.com/en/articles/8053299-issue-right-panel) eines Themas einsehen, womit ein Thema verlinkt ist

### 1.1 **Verlinkung von Objekten mit Themen**

**Manuell** Klicken Sie [hier](https://support.catenda.com/en/articles/8053299-issue-right-panel#h_758f17abbc), um zu erfahren, wie Sie Themen mit Objekten verlinken

**Automatisch** Wenn Sie 3D-Objekte im 3D-Schnappschuss ausgewählt haben, wenn Sie das Thema einreichen, werden diese Objekte mit dem Thema verlinkt.

### 1.2 **Verlinkung von Dokumenten mit Themen**

**Manuell** Klicken Sie [hier](https://support.catenda.com/en/articles/4670250-linking-a-document-to-an-issue), um zu erfahren, wie Sie Dokumente mit Themen verlinken

### 1.3 **Verlinkung von Themen mit anderen Themen**

**Manuell** Klicken Sie [hier](https://support.catenda.com/en/articles/8053299-issue-right-panel#h_edf2cb07a8), um zu erfahren, wie Sie ein Thema mit einem anderen Thema verlinken

**Automatisch** Wenn Sie # verwenden, um auf ein Thema im Kommentar oder in der Beschreibung eines Themas hinzuweisen, wird dieses Thema mit diesem Thema verlinkt und dieses Thema wird mit diesem Thema verlinkt. Dieser Link kann später bearbeitet werden.

## 2. **Verlinkung von Dokumenten**

### 2.1 **Verlinkung von Themen mit Dokumenten**

**Manuell** Wenn Sie ein Thema von der [Registerkarte Anmerkungen](https://support.catenda.com/en/articles/5001165-annotations-on-documents) im rechten Informationspanel eines Dokuments erstellen und es einreichen, wird das Dokument mit diesem Thema verlinkt.

**Automatisch** Wenn Sie eine [Anmerkung](https://support.catenda.com/en/articles/5001165-annotations-on-documents) erstellen und diese einem Thema hinzufügen, wird das Dokument automatisch mit diesem Thema verlinkt.

### 2.2 **Verlinkung von Objekten mit Dokumenten**

**Manuell** Klicken Sie [hier](https://support.catenda.com/en/articles/4670297-linking-documents-to-objects), um zu erfahren, wie Sie Dokumente mit Objekten verlinken.

## 3. **Verlinkung von Objekten**

### 3.1 **Verlinkung von Themen mit Objekten**

**Manuell** Klicken Sie [hier](https://support.catenda.com/en/articles/4670285-inspect-panel#h_8550da1056), um zu erfahren, wie Sie Objekte mit Themen verlinken

**Automatisch**

1. Laden Sie ein Modell in 3D und wählen Sie ein Objekt.
1. Entweder

Klicken Sie auf die Schaltfläche Plus in der [Themensektion](https://support.catenda.com/en/articles/4670285-inspect-panel#h_8550da1056) des Inspektionsbereichs des Informationspanels.

oder

Erstellen Sie eine neue Themensektion, indem Sie auf der Themaseite des Inhaltsbereichs auf neues Thema klicken.

1. Geben Sie dem Thema einen Titel und reichen Sie es ein
1. Beachten Sie, dass Ihr Thema die ausgewählten Objekte verlinkt hat

### 3.2 **Verlinkung von Dokumenten mit Objekten**

Sie können nur Objekte zu Dokumenten hinzufügen und nicht anders herum, siehe [hier](#h_41401e4836).

## 4. **Verlinkung so viel wie möglich so einfach wie möglich**

Laden Sie ein Modell im 3D-Viewer und wählen Sie ein Objekt. Erstellen Sie eine Auswahl für die Objekte im Auswahlbereich des Informationspanels. Erstellen Sie ein neues Thema Geben Sie dem Thema einen Titel. Verlinken Sie ein Dokument mit dem Thema. Reichen Sie das Thema ein. Wechseln Sie zum Dokument und verlinken Sie die Objekte mit dem Dokument.
