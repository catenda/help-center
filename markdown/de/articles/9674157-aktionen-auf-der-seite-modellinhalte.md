# Aktionen auf der Seite "Modellinhalte"

Je nach Ihrem Zugriff können verschiedene Aktionen für Ihr aktuelles Modell und jede seiner Revisionen auf der Modellübersichtsseite angezeigt werden.

## 1. **Modellaktionen**

Je nach Modellauswahl und je nach Zugriffseinstellungen können verschiedene Aktionsschaltflächen oben rechts auf der [Modellübersichtsseite](https://support.catenda.com/en/articles/4670270-model-overview-page#h_c10dbce6c8) gefunden werden. Alle Aktionsschaltflächen werden in ihren Aktionsmenüs aufgelistet, die etwa so aussehen können:

![mceclip0.png](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/01-model-actions.png)

Das Aktionsmenü auf der Modellübersichtsseite kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/02-model-actions.png)

### 1.1 **Letzte Revision herunterladen**

Sobald Sie eine Revision hochgeladen haben, können Sie sie hier herunterladen

### 1.2 **Neue Revision**

Klicken Sie auf die Aktion "Neue Revision" oder ziehen Sie eine Datei in die Modellinhalteliste, um eine neue Revision hochzuladen. Klicken Sie [hier](#h_118c049d47), um mehr über das Hochladen einer neuen Revision zu erfahren.

### 1.3 **Exporte**

Dies führt Sie zur [Modellexportseite](https://support.catenda.com/en/articles/4670280-model-export)

### 1.4 **Entfernen**

Mit dieser Aktion werden Sie aufgefordert, zu bestätigen, bevor das Modell von der Modellseite entfernt wird.

> **Hinweis:** Wenn Sie das Modell entfernen, wird es nur von der Modellseite entfernt. Das Dokument-Modell bleibt im Bereich "Dokumente" erhalten und muss mit der ausgewählten Dokumentlöschaktion gelöscht werden, wenn Sie es auch löschen möchten. Das Modell kann jederzeit aus demselben Dokument im Bereich "Modelle" neu erstellt werden.

_Erforderlicher Zugriff:_ Erstellen und Löschen von Modellen in den Projekteinstellungen sowie Schreibzugriff auf die Modelle, die Sie entfernen möchten.

## 2. **Modellrevisionsaktionen**

Rechts von jeder Revision können Sie die folgenden Aktionen finden:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/03-model-revision-actions.png)

### 2.1 Herunterladen

Klicken Sie auf die Aktion "Herunterladen", um diese Revision herunterzuladen

### 2.2 Veröffentlichen

Wenn gemeinsame Revisionen im [Statusworkflow-Menü](https://support.catenda.com/en/articles/12495583-status-workflow-document-settings) der Dokumenteinstellungen im Projekt aktiviert sind, beginnt jede neue Revision als gemeinsame Revision, die später veröffentlicht werden kann.

Gemeinsame Revisionen haben eine Nebenversionsnummer. (0.1, 0.2, 1.1 usw.) Die Veröffentlichungsaktion kann für gemeinsame Revisionen im Modell verfügbar sein. Nur gemeinsame Revisionen nach der neuesten veröffentlichten Revision können veröffentlicht werden. Veröffentlichte Revisionen haben eine Nebenversionsnummer. (1.0, 2.0, 3.0 usw.) _Erforderlicher Zugriff:_ Kann im Zugriff auf das Dokument-Modell veröffentlichen

**Veröffentlichung vorheriger Revisionen** Mit der Veröffentlichungsaktion können gemeinsame Revisionen nach der neuesten veröffentlichten Revision im Modell veröffentlicht werden. Auf der Seite "Modellinhalte" können vorherige gemeinsame Revisionen veröffentlicht werden, solange sie nach der neuesten veröffentlichten Revision erstellt wurden. Hier kann nur eine Revision gleichzeitig durch Klicken auf die Schaltfläche veröffentlicht werden, während die neuesten gemeinsamen Revisionen aus mehreren Modellen gleichzeitig veröffentlicht werden können, indem Sie sie in der Modelltabelle auf der Modellseite auswählen und die Veröffentlichungsaktion dort verwenden.

Nach der Veröffentlichung wird eine neue veröffentlichte Revision mit einer Hauptversionsnummer (1.0, 2.0, 3.0 usw.) hinzugefügt. Diese veröffentlichte Revision wird sowohl auf der Registerkarte "Arbeitsbereich" als auch auf der Registerkarte "Veröffentlicht" angezeigt.

### 2.3 2D

Klicken Sie auf die Aktion "2D", um die 2D-Ansicht für diese Revision zu öffnen

### 2.4 3D

Klicken Sie auf die Schaltfläche "3D", um die 2D-Ansicht für diese Revision zu öffnen
