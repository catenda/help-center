# Projektbenachrichtigungsseite

Die Projektbenachrichtigungsseite finden Sie als sechste Seite im linken Navigationsmenü eines Projekts. Diese Seite ist Teil des Inhaltsbereichs.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9hmpesfd/01-intro.png)

## 1. Letzte Benachrichtigungen

Hier werden die neuesten für Sie relevanten Benachrichtigungen angezeigt. Sie können auf die Benachrichtigung klicken und werden zur Unterseite für den Fall weitergeleitet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9hmpesfd/02-latest-notifications.png)

## 2. Filterung und Funktionalität

Sie können mehr darüber erfahren, wie Sie auf dieser Seite filtern können und wann Sie die verschiedenen Benachrichtigungen erhalten, auf [dieser](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages) Seite.
