# Schritt 4 - Modelle

> Navigieren Sie durch verbundene Modelle, in denen Sie Objekte anzeigen und auswählen können

> **Tipp:** Finden Sie [Schritt 3](https://support.catenda.com/en/articles/10576100-step-3-documents) in [Erste Schritte](https://support.catenda.com/en/collections/2657208-getting-started) im Hilfecenter oder im Hilfemenü.

Im Bereich Modelle wird Ihnen eine Liste mit allen Modellen angezeigt, auf die Sie Zugriff haben. Diese können basierend auf Ihren Zugriffsrechten ausgewählt und im 3D-Viewer aktiviert werden, sodass Sie verbundene Modelle intuitiv anzeigen und navigieren können.
