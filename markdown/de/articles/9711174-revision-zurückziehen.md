# Revision zurückziehen

> In diesem Artikel beschreiben wir Ihnen, wie Sie eine Revision zurückziehen.

Revisionen können mit der Aktion "Revision zurückziehen" im Aktionsmenü einer Revision zurückgezogen werden. Wählen Sie ein einzelnes Dokument in der [Dokumenttabelle](https://support.catenda.com/en/articles/8204673-documents-page#h_54e8dfcac2) aus oder öffnen Sie die [Dokumentvorschau](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations) einer Revision, um das Aktionsmenü der Revision im [rechten Menü der Revision](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision-revision-info#h_508f911117) zu finden.

Bei der Datenübertragung passieren manchmal einfache Fehler, z. B. wenn die falsche Datei hochgeladen oder ein vorhandenes Dokument mit der falschen Revision aktualisiert wird. Es gibt eine neue Lösung dafür in Catenda HUB. _Erforderlicher Zugriff:_ Vollständiger Zugriff auf das Dokument

Sie finden die Option im [rechten Menü einer Revision](https://support.catenda.com/en/articles/8302244-right-menu-in-a-document) und sie kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hhtwytcy/01-intro.png)

Mit der Funktion **"Revision zurückziehen"** können Sie:

- Unerwünschte oder fälschlicherweise hochgeladene Revisionen entfernen

- Vermeiden Sie das Herunterladen und Anzeigen von unerwünschten oder fälschlicherweise hochgeladenen Revisionen

- Führen Sie einen sauberen Audit-Trail

> **Hinweis:** **Tipp:** Sind Sie sicher, dass Sie diese Revision zurückziehen möchten? Wenn Sie eine Revision zurückziehen, können Sie sie nicht mehr anzeigen oder herunterladen.

## 1. Darstellung der zurückgezogenen Revision

Die Revision wird nur als zurückgezogen angezeigt. Dies bedeutet nicht, dass sie gelöscht wurde. Sie kann jedoch nicht mehr angezeigt werden. Diese Aktion wird jetzt auch in der Historie angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hhtwytcy/02-withdrawn-revision-appearance.png)

Wenn Sie jetzt auf die zurückgezogene Revision klicken, wird eine Fehlermeldung im Dokumentbetrachter angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/hhtwytcy/03-withdrawn-revision-appearance.png)

> **Hinweis:** **Wichtiger Hinweis:** Wenn eine Revision zurückgezogen wird, können Sie eine zurückgezogene Revision nicht wiederherstellen. Sie muss neu hochgeladen werden.

## 2. Zurückziehen einer Modell-Revision

Um eine Modell-Revision zurückzuziehen, gehen Sie zu dem Dokument, das mit dem Modell verknüpft ist, und ziehen Sie die Revision aus dem Dokument zurück. Nach dem Zurückziehen einer Dokument-Revision, die mit einem Modell verknüpft ist, wird die Modell-Revision ebenfalls zurückgezogen.
