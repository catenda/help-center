# Themen-Seite

Sie finden die Themen-Seite als dritte Seite im linken Navigationsmenü eines Projekts. Diese Seite ist Teil des Inhaltsbereichs. Das Themen-Fenster bietet Ihnen einen schnellen aktualisierten Überblick über den Projektfortschritt in Bezug auf neue/aktualisierte Themen und offene/geschlossene Themen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/01-intro.png)

## 1. **Breadcrumbs - Themen-Board Dropdown**

Wenn Sie oben links auf den Namen des Themen-Boards klicken, wird eine Dropdown-Liste aller Themen-Boards im Projekt angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/02-breadcrumbs-topic-boards-dropdown.png)

### 1.1 **Alle Themen-Boards**

Wenn es mehr als ein Themen-Board im Projekt gibt, wird die Option "Alle Themen-Boards" am Ende der Dropdown-Liste angezeigt. Hier werden die Themen aus allen Boards zusammengefasst. Dies kann hilfreich sein, um ein Thema zu finden, dessen Themen-Board Sie nicht genau kennen.

> **Hinweis 1:** In der "Alle Themen-Boards"-Übersicht ist die Suche nur auf Folgendes möglich: Meine Themen, Meta-Status, Fälligkeit, Aktualisiert, Verantwortlicher, Anforderer, Ersteller, Meilenstein, Benutzerdefinierte Felder, Etiketten, Links. **Hinweis 2:** Ein Austausch von Themen ist nur von einem Themen-Board auf einmal möglich.

## 2. **Neue Element-Aktionen**

Die neuen Element-Aktionen befinden sich im Hamburger-Menü neben der Schaltfläche "+" oben rechts auf der Seite. Weitere Informationen zu den verschiedenen Aktionen finden Sie [hier](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/03-new-item-actions.png)

## 3. **Nicht verknüpfte Felder**

Wenn es nicht verknüpfte Status/Typen in einem Themen-Board gibt, wird eine orange Warnmeldung angezeigt, die besagt, dass es nicht verknüpfte Felder im Themen-Board gibt. _Erforderlicher Zugriff:_ Projektadministrator

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/04-unlinked-fields.png)

Wenn Sie auf den Link klicken, gelangen Sie zum Bereich [nicht verknüpfte Felder](https://support.catenda.com/en/articles/4670277-topic-board-settings#h_3bd7e3e759) der [Themen-Board-Einstellungen](https://support.catenda.com/en/articles/4670277-topic-board-settings), wo Sie alle Felder einer Art auf einmal mit einem vorhandenen Wert verknüpfen können.

## 4. **Suche, Filter und rechtes Menü**

So kann die Such- oder Filterleiste aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/05-search-filter-and-right-menu.png)

Ein Status kann offen, geschlossen oder Kandidat sein, obwohl er anders benannt sein könnte. Standardmäßig werden alle Themen mit einem offenen Meta-Status gefiltert.

### 4.1 **Suche**

Wenn alle offenen, geschlossenen oder Kandidaten-Status angezeigt werden, werden diese in ein einzelnes Filterfeld kombiniert. Klicken Sie auf das Dropdown-Menü neben dem kombinierten Filterfeld, um zu sehen, welche Status kombiniert werden. Drücken Sie das x auf der rechten Seite, um alle Filter zu entfernen. Klicken Sie [hier](https://support.catenda.com/en/articles/8370693-filtering-in-an-issue-board), um mehr über die Suche nach Themen zu erfahren.

### 4.2 **Filtermenü**

Wenn Sie in einem Themen-Board auf die Schaltfläche "Themen-Filter" links neben der Such- oder Filterleiste klicken:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/06-filter-menu.png)

Ein Filtermenü wird auf der linken Seite geöffnet. Hier können Sie angeben, welche Filter Sie verwenden möchten, um Ihre Suche einzugrenzen. Klicken Sie [hier](https://support.catenda.com/en/articles/8370693-filtering-in-an-issue-board), um mehr über das Filtern von Themen zu erfahren.

### 4.3 **Rechtes Menü**

Im [Themen-Board-Menü auf der rechten Seite](https://support.catenda.com/en/articles/6941224-right-panel-in-an-issue-board) können Sie Informationen zu den ausgewählten Themen anzeigen und mehrere Themen gleichzeitig bearbeiten.

## 5. **Themen-Board**

Standardmäßig werden kürzlich aktualisierte, offene Themen angezeigt.

### 5.1 **Ausgewählte Element-Aktionen**

Nach Auswahl eines Themas werden ausgewählte Element-Aktionen am oberen Rand der Tabelle angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/07-selected-item-actions.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board), um zu sehen, wie jede Aktion verwendet werden kann:

### 5.2 **Spalten**

Einige Spalten in der Themen-Tabelle sind standardmäßig aktiviert, während andere ausgeblendet werden können und aktiviert werden müssen. Basierend auf der konfigurierten Spaltenreihenfolge werden die ersten Spalten angezeigt, während die Tabelle möglicherweise horizontal gescrollt werden muss, um andere aktivierte Spalten anzuzeigen. Die standardmäßige Reihenfolge und Sichtbarkeitseinstellung der Spalten auf der Themen-Seite ist wie folgt:

- Kontrollkästchen - Standard
- Index - Standard
- Titel - Standard
- Zugewiesen - Standard
- Status - Standard
- Themen-Board - Standard
- Fälligkeit - Standard
- Angefordert von - Standard
- Etiketten - Standard
- Typ - Standard
- Erstellt von - Standard
- Erstellt - Standard
- Meilenstein - Standard
- Aktualisiert - Standard
- Anzahl der Kommentare
- Anzahl der Dokumente
- Benutzerdefinierte Felder - Standard

Klicken Sie [hier](https://support.catenda.com/en/articles/6941099-columns-on-the-topics-page), um mehr darüber zu erfahren, welche Spalten auf der Themen-Seite verfügbar sind.

### 5.3 **Listenansicht - Standard**

Eine Ansicht, die Themen mit einer Vorschau der Bilder in den Kommentaren anzeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/08-list-view-default.png)

So sieht ein Themen-Board in der Listenansicht aus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/09-list-view-default.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/6941232-list-view-in-an-issue-board), um mehr über die Listenansicht in einem Themen-Board zu erfahren. Klicken Sie [hier](https://support.catenda.com/en/articles/11748020-tables-on-catenda), um allgemeine Informationen über Listen in Catenda zu erhalten.

### 5.4 **Tabellenansicht**

Eine Tabelle von Themen, die nur die notwendigsten Informationen anzeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/10-table-view.png)

So sieht ein Themen-Board in der Tabellenansicht aus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/11-table-view.png)

Hier können Sie viele Themen auf einmal sehen. Durch Klicken auf eine beliebige Information im Themen-Fenster gelangen Sie zu einer Unterseite mit vollständigen Informationen. Klicken Sie [hier](https://support.catenda.com/en/articles/11748020-tables-on-catenda), um allgemeine Informationen über Tabellen in Catenda zu erhalten.
