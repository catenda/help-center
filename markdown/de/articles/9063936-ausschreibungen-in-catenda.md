# Ausschreibungen in Catenda

Die Einrichtung von Ausschreibungen ist ein großer Teil des Bauprozesses. Da die Dokumente bereits auf Catenda Hub verfügbar sind, möchten Benutzer ihr Projekt natürlich für Ausschreibungen einrichten. Im Vergleich zur regulären Nutzung von Catenda mit Zusammenarbeit von Projektmitgliedern stellt dies einige Herausforderungen dar, da die Partei, die die Ausschreibung erstellt, einen fairen Wettbewerb gewährleisten möchte. Dieser Artikel enthält einige

## 1. **Zugangskontrolle**

Auftragnehmer, die an der Ausschreibung teilnehmen, sollten bei den Maßnahmen, die sie in Catenda durchführen können, eingeschränkt sein. Ausschreibungsbenutzer können Zugriff auf nur einen bestimmten Satz von Dokumenten im Projekt erhalten, die sie als Grundlage verwenden können. Sie können Lesezugriff auf alle Orte im Projekt erhalten, während ihnen kein Zugriff auf die Orte gewährt wird, die sie nicht sehen sollten.

## 2. **Anonyme Nutzung von Catenda**

Bei einem Ausschreibungsprozess ist es wichtig, dass die einreichenden Parteien nicht voneinander wissen. In Catenda können alle Benutzer alle anderen Benutzer im Projekt sehen, was in einer Ausschreibungssituation Probleme verursachen kann. Je nachdem, wie Sie ein Konto in Catenda erstellen können, gibt es mehrere Möglichkeiten, dieses Problem zu lösen.

### 2.1 **E-Mail-Aliase**

In Catenda ist jedes Konto mit einer E-Mail-Adresse verbunden. Eine Möglichkeit, um sicherzustellen, dass die für die Ausschreibung verwendeten Konten anonym bleiben, besteht darin, E-Mail-Aliase zu erstellen, die zum Erstellen von Konten verwendet werden. Da Sie die E-Mail-Adresse steuern, mit der das Konto verbunden ist, können Sie sicherstellen, dass sowohl der Benutzername als auch die E-Mail-Adresse anonym bleiben. Sie können dann den Benutzernamen und das Passwort der Konten mit den Parteien teilen, die Zugriff benötigen.

### 2.2 **E-Mail-Konto für jeden Benutzer**

Einige Unternehmen erlauben ihren Mitarbeitern nicht, Aliase für ihre E-Mails zu erstellen. Wenn es nicht wichtig ist, dass Benutzer sich gegenseitig sehen, können Benutzer auf die reguläre Weise eingeladen werden. An allen Orten in Catenda, mit Ausnahme der Seite Mitglieder, gibt es gute Möglichkeiten, um sicherzustellen, dass von einem Mitglied geteilte Informationen nicht von einem anderen gesehen werden.

### 2.3 **Externe Benutzer**

Wenn Sie nicht in der Lage sind, separate Benutzer für jeden Ausschreibungseinreicher zu erstellen, können Sie Ihr Catenda-Projekt auch als Ort nutzen, um Ihre Ausschreibungsinformationen zu teilen, ohne die Einreicher einzuladen. Wie in der [Informationsbasis für Ausschreibungen](#h_9ab97bdd71) beschrieben, können [Dokumentsammlungen](https://support.catenda.com/en/articles/6344318-collections-page) und [3D-Lesezeichen](https://support.catenda.com/en/articles/4670281-bookmarks-page) vorbereitet und mit externen Parteien geteilt werden, um sie als Grundlage für die Einreichung zu nutzen. Auf diese Weise können externe Benutzer auf Dokumente und 3D-Ansichten im Projekt zugreifen, ohne selbst Teil des Projekts zu sein. Da die Benutzer nicht Teil des Projekts sind, muss die Dokumentenlieferung an anderer Stelle eingereicht werden. Die eingereichten Dokumente können vom Bieter nach der Einreichung ins Projekt hochgeladen werden.

## 3. **Informationsbasis für Ausschreibungen**

Projekte enthalten oft bereits viele Informationen über das Gebäude, wenn ein Ausschreibungsprozess beginnt. Es ist daher wichtig, die einreichende Partei zu den richtigen Dokumenten zu führen, nicht nur damit sie nicht versehentlich das falsche Dokument ansieht, sondern auch um sicherzustellen, dass alle Einreicher mit denselben Informationen arbeiten.

### 3.1 **Dokumentenbasis**

Das Erstellen von [Dokumentsammlungen](https://support.catenda.com/en/articles/6344318-collections-page) der Dokumente, die Sie als Grundlage für den Ausschreibungsprozess verwenden möchten, ist eine einfache Möglichkeit, dem Bieter zu zeigen, welche Dokumente angesehen werden sollten. Da Sie [Dokumentsammlungen](https://support.catenda.com/en/articles/6344318-collections-page) auf Revisionen sperren können, können Sie sicherstellen, dass keine Verwirrung über die beabsichtigte Dokumentversion besteht. Wenn die Einreicher nicht Teil des Projekts sind, können Sie Dokumentsammlungen auch extern teilen. Auf diese Weise können Sie große Dateien mit jeder einreichenden Partei teilen und eine Bestätigung sehen, wenn diese auf den an sie gesendeten Download-Link geklickt hat.

### 3.2 **3D-Basis**

Wie bei Dokumenten können Sie [Lesezeichen](https://support.catenda.com/en/articles/4670281-bookmarks-page) verwenden, um eine Basis für die Darstellung von Ausschreibungseinreichern zu erstellen, welche 3D-Modelle zu betrachten sind. Lesezeichen sind eine großartige Möglichkeit, um Bietern einen Ansichtspunkt zu zeigen, welcher Teil des Projekts in 3D in diesem Fall beabsichtigt ist.

**Mit Projekt geteilt** [Lesezeichen](https://support.catenda.com/en/articles/4670281-bookmarks-page) müssen mit dem Projekt geteilt werden, damit andere Projektmitglieder sie sehen können. Mit [Modellen als Dokumente](https://support.catenda.com/en/articles/8064548-models-as-documents) kann der Zugriff so konfiguriert werden, dass Ausschreibungsbenutzer nur die Modelle sehen, auf die sie Zugriff haben.

**Öffentliche Lesezeichen** Öffentliche Lesezeichen sind eine großartige Möglichkeit, 3D-Ansichten im Rahmen einer Ausschreibung mit externen Parteien zu teilen. Mit einem öffentlichen Lesezeichen können Sie einen Link generieren, über den Ausschreibungseinreicher eine vereinfachte Version der Modelle im Lesezeichen anzeigen können, ohne die Objekteigenschaften. Dies dient dazu, sicherzustellen, dass vertrauliche Mengeninformationen, die sich möglicherweise in diesen Objekten befinden, nicht versehentlich.

## 4. **Öffentliches Teilen deaktivieren**

Ausschreibungsprojekte sind oft privat und es ist wichtig, dass keine Informationen mit anderen Parteien geteilt werden. Eine Möglichkeit, um sicherzustellen, dass es keine andere Möglichkeit zum Exportieren als zum Herunterladen gibt, besteht darin, uns zu bitten, die öffentliche Freigabefunktion des Projekts zu deaktivieren. Wenn diese Option deaktiviert ist, ist es nicht mehr möglich, teilbare Links mit Dokumentsammlungen oder Lesezeichen zu erstellen, damit keine vertraulichen Informationen auf andere Weise als durch Herunterladen aus dem Projekt verloren gehen. Diese Option finden Sie [hier](https://support.catenda.com/en/articles/8224886-organization-options#h_1027778040) ausführlicher beschrieben.
