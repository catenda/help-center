# Filterung auf der Genehmigungsseite

Das Filterfenster kann auf der Genehmigungsseite für Projekte geöffnet werden, bei denen gemeinsame Revisionen nach dem 2. Oktober 2025 aktiviert wurden, indem Sie auf die Filterschaltfläche links neben der Suchleiste auf der [Genehmigungsseite](https://support.catenda.com/en/articles/8349340-approvals-page) klicken. Bei Projekten, bei denen gemeinsame Revisionen vor dem 2. Oktober 2025 aktiviert wurden, wird stattdessen das alte Filterfenster der Genehmigungsseite angezeigt.

## 1. **Filter**

Die folgenden Filter sind auf der Genehmigungsseite verfügbar, wenn der neue Validierungs-Workflow aktiviert werden soll.

Klicken Sie auf die Filterschaltfläche oben links, um ein Fenster auf der linken Seite zu öffnen. Wenn ein Filter angewendet wird, ändert sich die im Browser sichtbare URL entsprechend. In diesem Artikel werden Filter wie folgt angezeigt: _Filtername im Menü_ - `Filtername in URL=Filteroption in URL`

**Standardfilter** Der Standardfilter ist anfangs nicht in der URL sichtbar. Wenn die Seite zum ersten Mal aufgerufen wird, wird der folgende Filter angewendet. Offen - `status=open`

### 1.1 **Aktuellen Filter speichern und teilen**

Gehen Sie zur URL einer gefilterten Seite, um diese Seite mit dem angewendeten Filter zu laden. Die angewendeten Filter können oben im Filtermenü gespeichert werden. Klicken Sie [hier](https://support.catenda.com/en/articles/11401493-saving-a-filter-link), um mehr darüber zu erfahren, wie Sie Filter speichern und teilen. Beachten Sie, dass es auf der Genehmigungsseite im Gegensatz zu anderen Filtermenüs nicht möglich ist, persönliche Filter oben im Filtermenü zu speichern.

### 1.2 **Leere Filter ausblenden**

Klicken Sie [hier](https://support.catenda.com/en/articles/8551755-saving-filters), um mehr über die Begrenzung der Filterergebnisse zu erfahren.

### 1.3 **Status**

Offen - Standard - `status=open` Geschlossen - `status=closed` Entwurf - `status=draft`

### 1.4 **Suche**

Textsuche - `search=test`

**Inhalt, der durchsucht werden kann** Standardmäßig wird der Filter "Offen" bei der Verwendung einer Textsuche angewendet, sodass nur offene Genehmigungsanforderungen übereinstimmen. Um nach geschlossenen oder entworfenen Genehmigungsanforderungen zu suchen, filtern Sie zunächst nach dem Status und verwenden Sie dann die Textsuche.

**Großschreibung** Die Textsuche reagiert nicht auf Groß- oder Kleinbuchstaben.

**Zeichenanzahl** Beliebige Anzahl von Zeichen, die die gesuchte Phrase enthalten, wird angepasst.

**Leerzeichen** Leerzeichen am Anfang einer Suchphrase werden für Treffer am Anfang des Inhalts entfernt. Leerzeichen werden für Treffer in der Mitte des Inhalts einbezogen.
