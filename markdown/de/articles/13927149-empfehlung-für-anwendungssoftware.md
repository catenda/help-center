# Empfehlung für Anwendungssoftware

Bitte überprüfen Sie, ob Sie Browser-Erweiterungen oder andere Programme haben, die Ihr Catenda Hub-Erlebnis verlangsamen könnten.

## 1. **Browsereinstellungen**

**Bester Browser nach Speichernutzung unter Windows (März 2026):**

1. Firefox
2. Chrome
3. Microsoft Edge

In diesem Abschnitt werden die folgenden Themen beschrieben:

### 1.1 **Zoomfaktor**

Catenda wird empfohlen mit einem Zoomfaktor von 100% zu verwenden. Catenda funktioniert gut mit Zoomfaktoren zwischen 75% und 150%

**Großer Zoomfaktor** Ein großer Zoomfaktor kann dazu führen, dass einige Menüs so groß werden, dass sie andere erforderliche Menüs überlagern. Während Grafiken, die nach Breite und Höhe definiert sind, mit dem Browser-Zoomfaktor skaliert werden können, können Grafiken, die nach Pixeln definiert sind, beim Erhöhen des Zoomfaktors pixeliger werden. Ein Zoomfaktor von 125% oder sogar 150% wird empfohlen, wenn Sie Bildschirme in Meetings freigeben, da dies es für die Personen, die dem Bildschirm folgen, einfacher machen kann zu verstehen, was getan wird.

**Kleiner Zoomfaktor** Ein kleiner Zoomfaktor kann dazu führen, dass Grafiken so klein werden, dass sie unsichtbar sind. Das präzise Darstellen von verkleinerten Ressourcen kann auf dem Gerät anspruchsvoller sein. Ein Zoomfaktor von 80% oder sogar 75% wird empfohlen, wenn Sie mit dem 3D-Viewer interagieren, falls das Gerät dies bewältigen kann.

### 1.3 **Cookies**

Mit den in Cookies gespeicherten Daten kann Ihr Browser erkennen, ob Sie angemeldet sind, und einige Ihrer Einstellungen in Catenda-Projekten. Einige Einstellungen können sich pro Projekt unterscheiden, während andere für alle Projekte gleich sind. Wenn Sie Ihre Einstellung ändern, z. B. durch Schließen eines Menüs, wird dies über Browser-Fenster und Registerkarten hinweg beibehalten. Wenn Sie beispielsweise das Filtermenü in einer Registerkarte schließen und dann dieselbe Seite in einer anderen Registerkarte aktualisieren, wird das Filtermenü in dieser Registerkarte ebenfalls geschlossen. Auf diese Weise merkt sich der Browser auch, ob Sie angemeldet sind oder nicht. Wenn Sie sich in einer Registerkarte abmelden, um sich bei einem anderen Konto anzumelden, und dann die Seite einer anderen Registerkarte aktualisieren, werden Sie mit dem anderen Konto angemeldet, das möglicherweise keinen Zugriff auf das Projekt hat, in dem Sie sich befunden haben.

**Cookies suchen** In Chrome können Sie Ihre Cookies wie folgt verwalten: Klicken Sie auf Cookies und Websitedaten

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/01-cookies.png)

Klicken Sie auf Websitedaten auf dem Gerät verwalten

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/02-cookies.png)

_Cookies zulassen_ Um Catenda Hub zu verwenden, müssen Sie mindestens die Speicherung von Daten für hub.catenda.com während Ihrer Sitzung zulassen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/03-cookies.png)

Wenn Sie sich dafür entscheiden, Daten beim Schließen aller Fenster zu löschen, werden Ihre Daten jedes Mal zurückgesetzt, wenn Sie Catenda verwenden. Das Löschen Ihrer Daten jedes Mal, wenn alle Fenster geschlossen sind, führt dazu, dass Ihre Einstellungen jedes Mal zurückgesetzt werden, nachdem Sie alle Fenster Ihres Browsers geschlossen haben.

_Cookies löschen_ Cookie-Daten können manuell gelöscht werden, indem Sie auf das Papierkorbsymbol klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/04-cookies.png)

Sie werden dann aufgefordert, die Seite neu zu laden. Nach dem erneuten Laden müssen Sie sich wieder bei Catenda anmelden, da Sie Ihre Anmeldeinformationen gelöscht haben.
