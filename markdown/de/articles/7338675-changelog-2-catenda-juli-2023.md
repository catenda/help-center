## 2. Behobene Probleme

**Catenda Hub**

- [Modelle](https://support.catenda.com/de/articles/4670286-modellseite) mit japanischen Zeichen werden jetzt mit dem korrekten Namen heruntergeladen
- [Mengenermittlung](https://support.catenda.com/de/articles/6673929-mengenermittlung-qto) verfügt nun über abwechselnde schwarz- und weißhinterlegte Spalten für bessere Lesbarkeit
- [Import](https://support.catenda.com/de/articles/4670270-modellinhaltseite#h_04142f81bf) Check-in - Importe mit kleinen Fehlern wie ein Komma hier, eine Klammer dort werden nun akzeptiert, auch wenn die Datei mit einem kleinen Fehler geschrieben oder exportiert wurde.
- Das [Baum-Panel](https://support.catenda.com/de/articles/4670290-modellbaum-panel) zeigt nun immer das richtige Modell eines Objekts an, wenn dieses Objekt ausgewählt ist. Zuvor gab es einige Fälle, in denen sich das Baum-Menü nicht immer zum richtigen Modell aktualisierte
- Es ist nun möglich, eine Auswahl mit dem Auswahlmenü im Inspektbereich zu speichern.

    Eine Auswahl von Objekten kann auch gefärbt werden. Diese Auswahl kann in einem Schnappschuss oder Lesezeichen gespeichert werden.

- Unsere Server können jetzt den [Import](https://support.catenda.com/de/articles/4670270-modellinhaltseite#h_04142f81bf) von Dateien mit großem Geometry-Umfang verarbeiten, die zuvor zu Timeouts geführt hätten.
- Die [3D-Schaltfläche](https://support.catenda.com/de/articles/4670286-modellseite#h_82b7400edc) bleibt jetzt wieder aktiv, wenn mehrere Modelle geladen werden
- Objekte können wieder gelöscht und transparent gemacht werden.
- Benutzer mit Zugriff auf Ordner der obersten Ebene im Bereich "Dokumente" können ihre Ordner jetzt sehen, auch wenn nicht allen Benutzern in den [Dokumenteinstellungen](https://support.catenda.com/de/articles/7831371-seite-dokumenteinstellungen) Zugriff gewährt wird.
