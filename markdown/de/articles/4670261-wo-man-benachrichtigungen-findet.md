# Wo man Benachrichtigungen findet

Sie finden die Schaltfläche Benachrichtigungen im Hauptmenü oder oben rechts auf dem Bildschirm, indem Sie auf Ihr Profilbild klicken.

Die oben rechts in der Ecke des Bildschirms zeigt Ihnen [Benachrichtigungen von allen Projekten, an denen Sie beteiligt sind](https://bimsync.com/notifications). Die in der linken Navigationsleiste

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bwfkbb29/01-intro.png)

zeigt Ihnen Benachrichtigungen des Projekts, in dem Sie sich befinden.

Es ist auch möglich, Projektbenachrichtigungen für jedes Mitglied/Team des Projekts zu finden, indem Sie in Einstellungen -> Mitglieder zu diesem Mitglied/Team gehen.

## 1. Benachrichtigungen verwenden

Das Benachrichtigungssystem ist nützlich, um den Überblick über das zu behalten, was in den Gebäuden und Baustellen geschieht, die Sie überwachen möchten. Es teilt Ihnen mit, wenn es etwas Neues gibt - zum Beispiel, wenn eine neue Version eines Gebäudes hochgeladen wird oder wenn Ihnen jemand ein Problem zugewiesen hat.

**Benachrichtigungseinstellungen:** Einstellungen für Benachrichtigungen sind auf einer Unterseite von Benachrichtigungen zu finden. Hier finden Sie eine Filterliste für die Benachrichtigungen, die Sie erhalten möchten. <a class="intercom-content-link" href="" target="_blank">Siehe hier</a>
