## 1. **Benutzertypen**

Es gibt zwei Arten von Organisationsbenutzern.

### 1.1 **Organisationseigentümer**

Eigentümer sind Personen, die die Organisation verwalten. Die Gruppe der Eigentümer sollte klein gehalten werden, oft nur ein oder zwei Eigentümer, da möglicherweise Kosten für die Anzahl der aktiven Projekte in der Organisation anfallen.

Organisationseigentümer haben Zugriff auf Folgendes:

- Das Organisationsverwaltungstool
- Erstellen von Projekten, solange Ihr Plan dies zulässt.
- Verschieben von Projekten zu anderen Organisationen, die ihnen gehören.
  Dies macht einen Platz frei und ermöglicht das Erstellen neuer Projekte.

> **Hinweis:** Organisationseigentümer werden von Catenda konfiguriert. Wenn Sie einen Organisationseigentümer hinzufügen oder entfernen möchten, wenden Sie sich bitte an Ihren Ansprechpartner, damit dieser unseren Support kontaktiert, und wir helfen Ihnen gerne weiter.

### 1.2 **Organisationsmitglied**

Mitglieder sind Konten von Personen, die Eigentümer häufig in und aus Projekten in dieser Organisation verschieben. Um ein Mitglied hinzuzufügen, verwenden Sie die Schaltfläche „Aus Domäne hinzufügen" oben rechts auf dieser Seite. Organisationseigentümer können mit Organisationsmitgliedern Folgendes tun:

- Ein Organisationsmitglied zu einem Projekt hinzufügen, ohne es per E-Mail einzuladen

## 2. **Schaltflächen oben**

### 2.1 **Aus Domäne hinzufügen**

Wenn Sie Ihre Domäne bei Catenda registriert haben, können Sie diese Schaltfläche sehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/03-add-from-domain.png)

Sie können die Registrierung Ihrer Domäne anfordern, indem Sie den Support über die schwarze Chatschaltfläche neben Ihrem Profilbild oben rechts kontaktieren oder eine E-Mail an [support@catenda.com](mailto:support@catenda.com) senden. Wenn Sie auf diese Schaltfläche klicken, wird das Dialogfeld „Aus Domäne hinzufügen" geöffnet

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/04-add-from-domain.png)

Im obigen Beispiel wurde die Domäne test.com registriert. In der Liste der Benutzer, aus denen Sie wählen können, sehen Sie alle Catenda-Benutzer, die ein Konto bei Catenda unter dem registrierten Domänennamen erstellt haben. Wenn Sie jemanden hinzufügen möchten, der noch kein Catenda-Konto hat, müssen Sie warten, bis er sein Konto erstellt hat, bevor Sie ihn hinzufügen können.

## 3. **Suchen und Filtern**

### 3.1 **Leere Filter ausblenden**

Der Schalter "Leere Filter ausblenden" ist standardmäßig ausgeschaltet, d. h. Sie sehen alle möglichen Filter. Sie können diesen Filterschalter aktivieren, um alle Filter auszublenden, die keine Ergebnisse haben.

### 3.2 **Rolle -** `role=owner,member`

_Eigentümer_ - Der/die Eigentümer der Organisation _Mitglied_ - Organisationsmitglieder

## 4. **Aktionsschaltflächen**

Nachdem Sie einen oder mehrere Benutzer in der Benutzerliste ausgewählt haben, indem Sie auf das Kontrollkästchen klicken, werden die folgenden Aktionsschaltflächen oben in der Projektliste angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/05-action-buttons.png)

### 4.1 **Zu Projekten hinzufügen**

Fügen Sie Ihre ausgewählten Benutzer zu einem oder mehreren Projekten hinzu. Nach dem Klick auf "Zu Projekten hinzufügen" wird das Dialogfeld "Mitglieder zu Projekten hinzufügen oder einladen" geöffnet. Dieses Dialogfeld kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/06-add-to-projects.png)

**Projekte auswählen** Wählen Sie aus, zu welchen Projekten Sie den Benutzer hinzufügen möchten

**Projektrolle auswählen** Wählen Sie die Rolle aus, die sie in diesen Projekten haben werden

**Benutzer auswählen** Fügen Sie Benutzer hinzu oder entfernen Sie sie, bevor Sie sie den ausgewählten Projekten hinzufügen, ohne sie per E-Mail einladen zu müssen. Es können nur Benutzer hinzugefügt werden, die Mitglieder der Organisation sind. Andere Benutzer müssen per E-Mail eingeladen werden.

**Per E-Mail einladen** Laden Sie Benutzer per E-Mail ein, ohne Teil des Projekts sein zu müssen. Diese Benutzer müssen auf den Einladungslink in der E-Mail klicken, die sie erhalten, genauso wie wenn sie über die Projekteinladungsseite von einem Projektadministrator eingeladen würden.

### 4.2 **Mitglied entfernen**

Entfernen Sie die ausgewählten Mitglieder aus der Organisation

## 5. **Benutzerliste**

Hier sehen Sie eine Liste der Benutzer, die Teil Ihrer Organisation sind.

> **Hinweis:** Dies sind nicht alle Benutzer, die Teil von Projekten Ihrer Organisation sind. Benutzer, die Teil von Projekten sind, finden Sie auf der [Projektmitgliedschaftsseite](https://support.catenda.com/en/articles/9003642-members-page-in-organization-tool).

### 5.1 **Kontrollkästchen**

Organisationsbenutzer auswählen

### 5.2 **Mitglied**

Das Profilbild, der Benutzername und die E-Mail des Benutzers. Sie können entweder ein normales Mitglied oder ein Eigentümer sein. Eigentümer haben Zugriff auf das Organisationsverwaltungstool. Sie können Organisationsmitglieder zu Projekten hinzufügen, ohne sie einzuladen.
