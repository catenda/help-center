# Tabellen in Catenda

Auf Seiten, auf denen mehrere Elemente angezeigt werden, werden Informationen häufig in Tabellen dargestellt. Verschiedene Möglichkeiten, mit Tabellen zu arbeiten, die oft ähnlich in verschiedenen Tabellen sind, werden in diesem Artikel beschrieben. In dem Beispiel unten wird die Tabelle auf der Seite Mitglieder als Beispiel für das Aussehen einer Tabelle in Catenda angezeigt:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/01-intro.png)

## 2. Auswahlübersicht

Oben links in einer Tabelle wird ein Kontrollkästchen angezeigt. Rechts neben dem Kontrollkästchen wird eine Übersicht über die aktuelle Anzahl der ausgewählten Zeilen und die Gesamtzahl der Zeilen auf der aktuellen Ebene der Tabelle angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/02-selection-overview.png)

### 2.1 Alle auswählen

In einigen Tabellen können bei vielen Zeilen alle Zeilen gleichzeitig ausgewählt werden. In anderen Tabellen können nur die derzeit geladenen Zeilen ausgewählt werden. Klicken Sie auf das Kontrollkästchen, um alle Zeilen in der Tabelle auszuwählen. Wenn das rechte Menü zuvor geöffnet war, wird es automatisch wieder geöffnet, wenn eine Zeile ausgewählt wird.

### 2.2 Weitere Zeilen durch Scrollen laden

In einigen Tabellen werden nur die derzeit geladenen Zeilen ausgewählt. In der Regel werden jeweils etwa 100 Zeilen geladen. Das Scrollen über 100 Zeilen hinaus führt dazu, dass mehr Zeilen geladen werden und somit mehr Zeilen gleichzeitig ausgewählt werden können.

### 2.3 Aktionen für ausgewählte Elemente

Nach der Auswahl oder dem Öffnen des Inhalts einer Zeile in der Tabelle kann ein Menü für Aktionen bei ausgewählten Elementen in der Auswahlübersicht angezeigt werden. So kann das Menü für Aktionen bei ausgewählten Elementen in der Tabelle "Dokumente" aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/03-selected-item-actions.png)

Das Menü für Aktionen bei ausgewählten Elementen kann je nach Inhalt der Zeile und den Zugriffsmöglichkeiten des Benutzers verschiedene Aktionen enthalten. Die möglichen Aktionen für jede Tabelle finden Sie hier:

- [Aktionen für ausgewählte Elemente im Themenbrett](https://support.catenda.com/en/articles/4670284-topic-board-actions#h_b5c00c149b)
- [Aktionen für ausgewählte Elemente auf der Seite "Modelle"](https://support.catenda.com/en/articles/9431936-models-page-actions#h_9c268c45ed)
- [Aktionen für ausgewählte Elemente auf der Seite "Dokumente"](https://support.catenda.com/en/articles/4670288-document-structure-actions#h_fb4e9ef375)

### 2.4 Alle abwählen

Nach der Auswahl einer Zeile wird das Kontrollkästchen der Auswahlübersicht mit einem Minuszeichen aktiviert. Hier ist ein Beispiel, wie das in der Tabelle "Dokumente" aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/04-deselecting-all.png)

Klicken Sie auf das Minus, um die Auswahl aller ausgewählten Zeilen aufzuheben.

## 3. Tabellensichtbarkeitseinstellungen

Oben rechts in einer Tabelle finden Sie die Tabellensichtbarkeitseinstellungen. So können die Tabellensichtbarkeitseinstellungen aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/05-table-visibility-settings.png)

### 3.1 Exportieren

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/06-export.png)

Tabellen können durch Klicken auf die Exportschaltfläche exportiert werden.

### 3.2 Anzeigen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/07-view.png)

_Listenansicht -_ Standard

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/08-view.png)

In der Listenansicht werden Informationen über Elemente oben/unten/links/rechts in einem größeren Feld angeordnet.

**Tabellenansicht**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/09-view.png)

In der Tabellenansicht werden Informationen über Elemente in Zeilen und Spalten angeordnet.

### 3.3 Zeilenhöhe

Mit den Zeilenhöhenschaltflächen wird die Höhe jeder Zeile in der Tabelle geändert.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/10-row-height.png)

**Standardansicht** Eine Zeilenhöhe, die auf den meisten Bildschirmen gut funktioniert, wird angezeigt.

**Kompakte Ansicht** Der Leerraum über und unter Elementen in einer Zeile wird entfernt, wodurch die Zeilenhöhe reduziert wird.

Bei kleinen Bildschirmen oder Bildschirmen mit niedriger Auflösung können mit der Standardzeilenhöhe nur wenige Zeilen angezeigt werden. In dieser Situation ist die kompakte Ansicht die beste Wahl.

### 3.4 Spaltendropdown

Oben rechts in einer Tabelle können Sie das Spaltendropdown sehen. So kann die Spaltendropdown-Schaltfläche aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/11-column-dropdown.png)

Mit dem Spaltendropdown können die Spalten in einer Tabelle neu angeordnet, aktiviert und deaktiviert werden. So kann das Spaltendropdown aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/12-column-dropdown.png)

Oben im Spaltendropdown können Optionen angezeigt werden, die sich auf alle Spalten auswirken. Hier ist ein Beispiel dafür, wie der gesamte Spaltendropdown oben aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/13-column-dropdown.png)

**Umschalter-Erscheinungsbild** Wenn der Umschalter aktiviert ist, werden alle Spalten angezeigt. Wenn sich der Umschalter in der Mitte befindet, werden einige Spalten angezeigt. Wenn der Umschalter deaktiviert ist, werden keine Spalten angezeigt. Wenn ein Umschalter einen helleren Farbton hat, kann er nur aktiviert oder deaktiviert werden, wenn alles oder nichts aktiviert oder deaktiviert ist.

**Filter** Geben Sie in der Filterleiste Text ein, um nach einer bestimmten Spalte zu filtern.

**Einstellungen zurücksetzen** Klicken Sie auf die Schaltfläche "Einstellungen zurücksetzen", um die Spalten auf ihre Standardkonfiguration zurückzusetzen.

**Spaltentyp erweitern/minimieren** Erweitern oder minimieren Sie einen Spaltentyp mit der Pfeiltaste links, um alle Spalten dieses Typs anzuzeigen oder auszublenden.

**Ziehpunkt** Spalten, die neu angeordnet werden können, können ein Gittersymbol rechts neben dem Spaltennamen anzeigen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/14-column-dropdown.png)

Der Cursor kann sich in eine Hand verwandeln, wenn der Ziehpunkt darüber bewegt wird. Nach dem Greifen des Gitters wird ein Ziehpunkt unter dem Cursor angezeigt und die gehaltene Spalte kann in einem helleren Farbton angezeigt werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/15-column-dropdown.png)

Wenn der Ziehpunkt zu einer anderen Spalte gezogen wird, wird die gehaltene Spalte nach der Spalte angezeigt, zu der sie gezogen wird. Lassen Sie den Ziehpunkt los oder klicken Sie darauf, um die gehaltene Spalte an Ort und Stelle zu verriegeln und die Spaltenliste neu anzuordnen.

### 3.5 Tabelleneinstellungen

Klicken Sie auf die Schaltfläche "Tabelleneinstellungen", um die Tabelleneinstellungen zu aktivieren oder zu deaktivieren

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/16-table-settings.png)

## 4. Zeilen

In einer Tabelle werden Elemente in Zeilen angezeigt, die sich unterschiedlich verhalten können.

## 5. Zeilen - Kopfzeile

Die Kopfzeile ist die erste Zeile in der Tabelle.

### 5.1 Kopfzeileninteraktion

Das Bewegen der Maus über verschiedene Teile der Kopfzeile kann anzeigen, wie damit interagiert werden kann.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/17-header-row-interaction.png)

### 5.2 Sortierung

Wenn eine Spalte sortiert werden kann, wird ein Pfeil nach oben/unten rechts neben dem Spaltennamen angezeigt.

**Mauszeiger-Änderung** Der Mauszeiger wird zu einem Zeiger.

**Sortierungspfeile** Sortierungspfeile können anzeigen, welche Spalte aktuell sortiert ist. Sortierungspfeile können anzeigen, in welche Richtung die Zeilen sortiert sind.

**Zum Sortieren klicken** Klicken Sie auf die Kopfzelle einer sortierbaren Spalte, um die Tabellenzeilen nach der Spalte zu sortieren, in der sich diese Kopfzelle befindet. Nach dem Sortieren nach einer Spalte werden die Zeilen in der Tabelle nach den [typischen Sortierungsregeln in Catenda](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists) neu angeordnet. Klicken Sie erneut auf die Kopfzelle der sortierten Spalte, um sie in die entgegengesetzte Richtung zu sortieren. Das Sortieren einer Spalte aktualisiert die Sortierungseinstellungen für die Tabelle.

> **Hinweis:** Tabellen können immer nur nach einer Spalte sortiert werden

### 5.3 Breiteneinstellung

Breiteneinstellungsanker sehen wie eine dicke Linie aus, die etwa die Hälfte der Höhe der Kopfzeile beträgt.

**Mauszeiger-Änderung** Das Bewegen der Maus über den Einstellungsanker ändert den Mauszeiger in einen Pfeil nach links-rechts, der als Größenänderungszeiger bekannt ist.

**Ziehen zum Anpassen** Ziehen Sie auf dem Breiteneinstellungsanker in der Kopfzeile, um die Breite der Spalte zu ändern.

**Doppelklick zum automatischen Anpassen** Doppelklicken Sie auf den Einstellungsanker, um die Spalte links des Ankers automatisch basierend auf dem Inhalt dieser Spalte anzupassen. Wenn der Spalteninhalt so lang ist, dass er abgeschnitten wird, aber die benötigte Information am Ende des Inhalts steht, kann das Ändern der Spaltengröße hilfreich sein.

### 5.4 Spaltenreihenfolgenanpassung

Ziehen Sie auf der Kopfzelle einer Spalte, um die Spaltenreihenfolge zu reorganisieren. Ziehen Sie die Kopfzelle einer Spalte außerhalb der Tabelle, um diese Spalte auszublenden. Um die Spalte wiederherzustellen, müssen Sie sie im Spalten-Dropdown erneut aktivieren.

## 6. Zeilen - Aktualisierte Zeileninformationen

Wenn die Informationen in einer Zeile außerhalb der aktuellen Browserregisterkarte aktualisiert werden, wird eine Informationsleiste am unteren Rand der Tabelle angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/18-rows-updated-row-information.png)

Klicken Sie auf "Aktualisierungen abrufen", um die Zeilen in Ihrer Tabelle mit den neuen Informationen zu aktualisieren. Wenn "Aktualisierungen abrufen" angeklickt wird, werden neue Zeilen eingefügt und gelöschte Zeilen entfernt. Zellen mit vorhandenen Informationen, die sich ändern, blinken kurz mit grünem Hintergrund.

## 7. Zeilen - Unterste Zeile

Spalten mit numerischen Werten können in der untersten Zeile der Tabelle summiert werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/19-rows-bottom-row.png)

Beispiele für Spalten, die summiert werden können, sind benutzerdefinierte Feldspalten und Objekteigenschaftsspalten.

## 8. Verschieben durch Ziehen

Um den Speicherort einer Spalte oder einer Zeile zu ändern, geben Sie den Ziehpunkt am neuen Speicherort frei.

### 8.1 Spaltenkonfiguration durch Ziehen ändern

Klicken und ziehen Sie auf der Kopfzelle einer Spalte, um mit der Änderung der Spaltenkonfiguration zu beginnen. Nach dem Greifen der Spalte wird ein Ziehpunkt unter dem Mauszeiger angezeigt. Der Ziehpunkt kann den Namen der Spalte und ein Augensymbol enthalten, das anzeigt, ob die Spalte aktiviert oder deaktiviert wird, wenn der Anker freigegeben wird.

**Ziehpunkt zum Neuanordnen einer Spalte** Wenn der Ziehpunkt über eine Spaltenbegrenzung oder außerhalb der Tabelle gezogen wird, wird die gezogene Spalte aus ihrer aktuellen Position entfernt. Wenn der Ziehpunkt über einen anderen Speicherort in der Tabelle bewegt wird, wird die Spalte dort in der Vorschau angezeigt. Geben Sie den Ziehpunkt am gewünschten Speicherort frei, um die gehaltene Spalte an diesem Speicherort einzufügen.

**Ziehpunkt zum Entfernen einer Spalte** Wenn der Ziehpunkt außerhalb der Tabelle gezogen wird, wird das Sichtbarkeitssymbol zu einem durchgestrichenen Auge und die Spalte wird in der Tabelle deaktiviert. Geben Sie den Ziehpunkt frei oder klicken Sie, um die gehaltene Spalte zu deaktivieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/20-change-column-configuration-by-dragging.png)

### 8.2 Zeilen durch Ziehen verschieben

Wenn die Zelle in der Titelspalte (oft als Name bezeichnet) überfahren wird, kann rechts des Titels ein Gitternetz aus Punkten angezeigt werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/21-move-rows-by-dragging.png)

Bewegen Sie die Maus über das Gitter und sehen Sie, dass sich der Mauszeiger in eine Hand ändert, was anzeigt, dass die Zeile gegriffen werden kann. Nach dem Greifen des Gitters wird ein Ziehpunkt unter dem Mauszeiger angezeigt. Der Ziehpunkt kann die Titel der Zeile(n) enthalten, die ausgewählt wurden, als die Zeile gegriffen wurde.

**Ziehpunkt zum Verschieben einer Zeile** Während die Zeile(n) innerhalb der Tabelle gezogen wird/werden, werden sie hervorgehoben und erhalten einen helleren Farbton, der anzeigt, dass in der Tabelle etwas passieren kann.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/22-move-rows-by-dragging.png)

Interaktive Zeilen werden mit einem anderen Hintergrund hervorgehoben, wenn der Ziehpunkt über die interaktive Zeile gezogen wird.

### 8.3 Ziehpunkt freigeben

Wenn der Ziehpunkt über einer interaktiven Zeile freigegeben wird, kann sich das Verschiebungsdialogfeld öffnen. Obwohl das Gittersymbol einer Zeile gezogen wurde, wird die Verschiebungsaktion auf die in der Tabelle ausgewählten Zeilen angewendet. Wenn der Ziehpunkt über eine nicht-interaktive Zeile oder außerhalb der Tabelle gezogen und freigegeben wird, findet in der Tabelle keine Änderung statt.

Es ist möglich, Spalten in den folgenden Tabellen zu verschieben:

  - [Projektseite](https://support.catenda.com/en/articles/8505058-projects-page-organization-tool)

## 9. Mit Zeilen durch Bewegen der Maus interagieren

Das Bewegen der Maus über verschiedene Teile der Tabelle kann anzeigen, wie damit interagiert werden kann. Zeilen, die nicht überfahren werden, können einen weißen Hintergrund haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/23-interacting-with-rows-by-hovering.png)

### 9.1 Zeilenbewegung

Das Bewegen der Maus über einer Zeile kann diese Zeile mit einem anderen Hintergrund hervorheben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/24-row-hover.png)

### 9.2 Box-Bewegung

Wenn die Maus über eine anklickbare Box in einer Zeile bewegt wird, kann sich der Mauszeiger in einen Zeiger ändern und die Box kann eine dunklere Kontur und einen Schatten um sich herum erhalten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/25-box-hover.png)

### 9.3 Text-Bewegung

Wenn die Maus über anklickbaren Text in einer Zeile bewegt wird, kann sich der Mauszeiger in einen Zeiger ändern. Der Text kann beim Überfahren unterstrichen werden und einige Browser können die URL der Seite anzeigen, die sich unten links öffnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/26-text-hover.png)

## 10. Mit Zeilen durch Klicken interagieren

Verschiedene Verhalten können auftreten, wenn auf den Inhalt einer Zeile geklickt wird.

### 10.1 Zeile auswählen

Wenn das rechte Menü zuvor geöffnet wurde, wird es erneut geöffnet, wenn eine Zeile ausgewählt wird.

**Leerraum** Klicken Sie einmal auf einen beliebigen Leerraum in der Zeile, um ihn auszuwählen. Wenn das rechte Menü zuvor geöffnet wurde, wird es erneut geöffnet, wenn eine Zeile ausgewählt wird. Klicken Sie schnell zweimal, um den Inhalt der Zeile zu öffnen. Klicken Sie nach einiger Zeit erneut auf die Zeile, um sie abzuwählen.

**Kontrollkästchen** Aktivieren Sie das Kontrollkästchen in der Kontrollkästchenspalte, um die Zeile auszuwählen. Mit dem Kontrollkästchen kann die Zeile ausgewählt werden, ohne sich Sorgen machen zu müssen, versehentlich den Inhalt dieser Zeile zu öffnen.

**Zeilenbereichsauswahl** Halten Sie `Umschalt` und klicken Sie, um alle Zeilen zwischen der aktuellen Zeile und der nächstgelegenen ausgewählten Zeile auszuwählen.

**Zeilenauswahlbearbeitung** Halten Sie `Strg` und klicken Sie, um einzelne Elemente in der Auswahl zu bearbeiten

### 10.2 Zeileninhalt öffnen

Text in Zeilen mit Inhalt, der in der Vorschau angezeigt werden kann, kann angeklickt werden, um die Vorschau des Inhalts der Zeile auf einer neuen Seite zu öffnen.

**Zeilensymbole öffnen** Symbole in Zeilen mit Inhalt, der in der Vorschau angezeigt werden kann, können angeklickt werden, um entweder die Vorschau des Inhalts der Zeile auf einer neuen Seite oder in einem Popupdialogfeld zu öffnen. Wenn Sie auf Symbole in Zeilen klicken, deren Inhalt nicht in der Vorschau angezeigt werden kann, wird stattdessen die Zeile ausgewählt.

### 10.3 Boxen in Zeilen

Es können verschiedene Arten von Boxen in einer Zeile vorhanden sein. Jede Box kann ihr eigenes Symbol oder ihre eigene Farbe haben.

**Etikettenbox** Etikettenboxen haben ein Etikettensymbol in der Farbe dieses Etiketts. Wenn auf eine Etikettenbox geklickt wird, kann sie zum aktuellen Filter hinzugefügt werden. Dies ist ein Beispiel für eine Etikettenbox:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/27-boxes-in-rows.png)

**Status- oder Typbox** Status- und Typboxen haben einen Kreis mit der Farbe des Status oder des Typs. Wenn auf eine Statusbox geklickt wird, kann sie zum aktuellen Filter hinzugefügt werden. Dies ist ein Beispiel für eine Status- oder Typbox:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/28-boxes-in-rows.png)

**Team-Box** Team-Boxen sind grün für Mitglied-Teams und orange für Administrator-Teams. Dies ist ein Beispiel für eine Team-Box:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/29-boxes-in-rows.png)

**Weitere Box anzeigen** Wenn mehr Boxen vorhanden sind, als in die Spaltenbreite einer Zellzeile passen, wird eine Box mit drei Punkten angezeigt:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/30-boxes-in-rows.png)

Klicken Sie auf diese Box, um die verbleibenden Boxen in der Zellzeile für diese Spalte zu sehen.

**Viewer-Box** Die 2D-, 3D- und Zoom-auf-Ausdehnung-Boxen können angezeigt werden. Klicken Sie auf die 2D-Box, um den Inhalt der Zeile im 2D-Viewer zu laden. Klicken Sie auf die 3D-Box, um den Inhalt der Zeile im 3D-Viewer zu laden. Nach dem Laden des Inhalts der Zeile im 3D-Viewer wird die Schaltfläche "Zoom auf Ausdehnung" verfügbar und kann angeklickt werden, um die Kamera im 3D-Viewer so zu positionieren, dass der gesamte Inhalt der Zeile sichtbar ist. Dies ist ein Beispiel, wie Viewer-Boxen aussehen können:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/31-boxes-in-rows.png)

**Objektbox** Die Anzahl der Objekte, die mit der Zeile verknüpft sind, wird angezeigt. Dies ist ein Beispiel, wie eine Objektbox aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/32-boxes-in-rows.png)

Wenn auf eine Objektbox geklickt wird, kann das folgende Kontextmenü geöffnet werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/33-boxes-in-rows.png)

Objekte auswählen Das 3D-Panel wird geöffnet und das/die Modell(e), zu dem/denen die Objekte gehören, wird/werden im 3D-Viewer zusätzlich zu allen zuvor geöffneten Modellen geladen. Nachdem die Modelle geladen wurden, wird die aktuelle Auswahl gelöscht. Die Objekte, die mit der Zeile verknüpft sind, werden dann ausgewählt.

Objekte isolieren Das 3D-Panel wird geöffnet und das/die Modell(e), zu dem/denen die Objekte gehören, wird/werden im 3D-Viewer zusätzlich zu allen zuvor geöffneten Modellen geladen. Nachdem die Modelle geladen wurden, wird die aktuelle Auswahl gelöscht. Die Objekte, die mit der Zeile verknüpft sind, werden dann isoliert.

Als Abfrage laden Das 3D-Panel wird geöffnet. Alle zuvor im 3D-Viewer geladenen Modelle werden vollständig gelöscht (nicht ausgeblendet). Nur die Objekte, die mit der Zeile verknüpft sind (diese können mehreren Modellen angehören), werden dann im 3D-Viewer geladen.
