# Verwenden von Themen-Vorlagen beim Speichern von Markup-Themen

> Wenden Sie eine Dokumentthemen-Vorlage an, wenn Sie ein Markup aus einem Dokument erstellen

Dokumentthemen-Vorlagen können auf der [Seite mit den Einstellungen für Themen-Vorlagen](https://support.catenda.com/en/articles/14076010-topic-template-settings-page) konfiguriert werden. _Erforderlicher Zugriff:_ Projektadministrator

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qwdn8hpc/01-intro.png)

1. Erstellen Sie zunächst eine Anmerkung zu einem Dokument im Dokumentviewer.
1. Speichern Sie Ihr Markup als Thema.
   _Erforderlicher Zugriff:_ Schreibzugriff auf ein Themen-Board.
1. Ein Popup-Fenster wird angezeigt, um ein Thema aus Ihrem Markup zu erstellen.

    <div class="intercom-container intercom-align-center"><img height="541" src="https://raw.githubusercontent.com/catenda/help-center/main/images/qwdn8hpc/inline-9980053aae3a.png" style="height: auto;" width="500"/></div>

1. Wählen Sie dann das richtige Themen-Board aus, in dem Sie Ihr Thema erstellen möchten.
   _Erforderlicher Zugriff:_ Schreibzugriff auf das Themen-Board.
1. Abhängig vom ausgewählten Themen-Board können Dokumentthemen-Vorlagen, wenn sie von einem Administrator konfiguriert wurden, im Dropdown-Menü "Vorlage" verfügbar sein und vorgeschlagen werden.

    <div class="intercom-container intercom-align-center"><img height="540" src="https://raw.githubusercontent.com/catenda/help-center/main/images/qwdn8hpc/inline-b8fd0218f860.png" style="height: auto;" width="500"/></div>

1. Wählen Sie die richtige Vorlage aus, die Sie verwenden möchten.
   Sobald Sie die richtige Vorlage auswählen, werden alle Felder in dem neuen Thema automatisch mit den Einstellungen aus der zugehörigen Themen-Vorlage ausgefüllt, auf die über die [Seite mit den Einstellungen für Themen-Vorlagen](https://support.catenda.com/en/articles/14076010-topic-template-settings-page) zugegriffen werden kann.

    <div class="intercom-container intercom-align-center"><img height="814" src="https://raw.githubusercontent.com/catenda/help-center/main/images/qwdn8hpc/inline-50d2237a44b3.png" style="height: auto;" width="500"/></div>

1. Sie können Ihr Thema abschließend speichern, indem Sie auf die Schaltfläche "Als Themen speichern" klicken.
