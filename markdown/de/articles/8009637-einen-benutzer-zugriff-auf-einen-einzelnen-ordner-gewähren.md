# Einen Benutzer Zugriff auf einen einzelnen Ordner gewähren

Die beste Möglichkeit, einem Benutzer Zugriff auf einen einzelnen Ordner zu gewähren, besteht darin, allen Benutzern in den Dokumenteinstellungen "Kein Zugriff" zu geben.

> **Hinweis:** Denken Sie daran, die Option "Ordner und alle Unterordner und Dateien" zu verwenden, damit Sie den Zugriff auf alle Unterordner ebenfalls überschreiben.

Sie können den Benutzer dann zu einem Team hinzufügen und dem Team (oder dem Benutzer, aber Teams sind einfacher zu verwalten) den Zugriff geben, den Sie ihnen auf den Ordner gewähren möchten.

> **Hinweis:** Der Benutzer benötigt auch Zugriff auf alle übergeordneten Ordner, um zu seinem Ordner navigieren zu können.
