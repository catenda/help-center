## 1. **In kleinere Dateien aufteilen**

Große .ifc- und .ifczip-Dateien sollten in kleinere Dateien unterteilt werden. Das Aufteilen kann dabei helfen, die 750-MB-Uploadbegrenzung einzuhalten, und ermöglicht eine besser verwaltbare Dateibehandlung innerhalb von Projekten.

Durch das Hochladen mehrerer kleinerer Dateien wird es für Projektmitglieder einfacher, verschiedene Teile ein- und auszuschalten und separate Teile der Datei einzeln herunterzuladen.

## 2. **Nach IfcZip exportieren**

Einige Authoring-Tools unterstützen IfcZIP als Option beim Exportieren von IFC-Dateien.

> **Hinweis:** **Beispiel:** `3D-model.ifczip`

## 3. **IfcZip erstellen**

Wenn die Größe einer `.ifc`-Datei das obere Limit überschreitet, kann eine `.ifczip`-Datei erstellt werden, um zum Hochladen berechtigt zu bleiben. Befolgen Sie diese Schritte, um eine `.ifc`-Datei in eine `.ifczip`-Datei umzuwandeln:

- Komprimieren Sie die `.ifc`-Datei zu einer `.zip`-Datei.
- Ändern Sie die Dateierweiterung von `.zip` zu `.ifczip`

> **Hinweis:** **Beispiel:** `3D-model.ifc` vs. `3D-model.zip` vs. `3D-model.ifczip ​`

## 4. **Support kontaktieren**

Wenn das Ändern der Datei keine Option ist und die Datei größer ist als das, was hochgeladen werden kann, teilen Sie uns dies unter [support@catenda.com](mailto:support@catenda.com) mit. Dateien werden von Fall zu Fall bearbeitet. Bevor Sie sich an uns wenden, sollten Sie alternative Methoden wie das Erstellen einer `.ifczip`-Datei, die Verwendung des Desktop Connectors oder das Aufteilen der Datei in kleinere Teile in Betracht ziehen.
