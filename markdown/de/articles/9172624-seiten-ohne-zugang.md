# Seiten ohne Zugang

Es gibt mehrere Möglichkeiten, den Zugang zu Orten auf Catenda Hub zu verweigern. Benutzer, die es gewohnt sind, nur Seiten zu sehen, auf die sie Zugriff haben, könnten überrascht oder verwirrt sein, wenn sie versuchen, einem Link zu folgen, von dem sie erwarten, dass er Inhalte enthält. In diesem Support-Artikel finden Sie Screenshots, die zeigen, wie eine Seite aussehen kann, wenn Sie keinen Zugriff auf den Inhalt der Seite haben, auf die Sie zugreifen möchten. Wenn Sie versuchen, einem Link zu einem Ort auf Catenda Hub zu folgen, auf den Sie keinen Zugriff haben, wird die Seite geladen, aber Sie können deren Inhalte nicht sehen.

## 3. **Zugang zum Themen-Board**

### 3.1 **Kein Zugang zu Themen-Boards auf der Boards-Seite**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues/boards](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues/boards) Dies ist, wie die Boards-Seite aussehen kann, wenn Sie keinen Zugriff auf Themen-Boards haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/04-no-access-to-topic-boards-on-the-boards-page.png)

**Klicken Sie hier, um ein Themen-Board zu erstellen** Klicken Sie auf die Nachricht, um ein Themen-Board im Projekt zu erstellen. Diese Nachricht wird immer angezeigt, aber ohne Zugriff auf die Erstellung von Themen-Boards wird beim Versuch, das Board zu erstellen, ein Fehler angezeigt. _Erforderlicher Zugang:_ Zugriff auf die Erstellung neuer Themen-Boards auf der Projekteinstellungsseite.

### 3.2 **Kein Zugang zu Themen-Boards auf der Themenseite**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues?board=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues?board=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) Dies ist, wie die Themenseite aussehen kann, wenn Sie keinen Zugriff auf Themen-Boards haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/05-no-access-to-topic-boards-on-the-topics-page.png)

**Neues Themen-Board** Klicken Sie auf die Schaltfläche für neues Themen-Board, um ein neues Themen-Board zu erstellen. _Erforderlicher Zugang:_ Zugriff auf die Erstellung neuer Themen-Boards auf der Projekteinstellungsseite.

### 3.3 **Nicht vorhandenes Themen-Board**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues?board=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues?board=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) Dies ist, wie die Themenseite aussehen kann, wenn der Benutzer versucht hat, auf ein Themen-Board zuzugreifen, das nicht vorhanden ist oder nicht mehr vorhanden ist.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/06-non-existant-topic-board.png)

Wenn die Themenseite geöffnet wird, wird das letzte besuchte Board geladen. Wenn das letzte besuchte Board nicht mehr vorhanden ist, wird diese Seite angezeigt.

**Laden Sie das Standard-Themen-Board** Klicken Sie auf die Schaltfläche zum Laden des Standard-Themen-Boards, um das erste Themen-Board zu laden, auf das Sie in einem Projekt Zugriff haben.

_Kein Zugang zum Standard-Themen-Board_ Ohne Zugriff auf das erste Themen-Board in der Liste der aktiven Themen-Boards im Projekt wird die Schaltfläche zum Laden des Standard-Themen-Boards nicht angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/07-non-existant-topic-board.png)

Um in diesem Fall zu einem anderen Themen-Board zu gelangen, gehen Sie zur Boards-Seite und wählen Sie ein Themen-Board aus.

### 3.4 **Kein Zugang zum Themen-Board**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues?board=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues?board=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) Dies ist, wie die Themenseite aussehen kann, wenn ein Benutzer versucht hat, auf ein Themen-Board zuzugreifen, auf das ihm kein Zugriff gewährt wurde.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/08-no-access-to-topic-board.png)

Um Zugriff auf dieses Themen-Board zu erhalten, wenden Sie sich bitte an einen Projektadministrator.

### 3.5 **Kein Zugang in einem Thema**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues/xxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/issues/xxxx) Dies ist, wie ein Thema aussehen kann, wenn der Zugriff an einigen Stellen entfernt wurde.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/09-no-access-in-a-topic.png)

**Zugewiesen und angefordert von** Wenn der Empfänger oder der Anforderer keinen Zugriff auf das Themen-Board hat, sehen Sie (kein Zugang) in Klammern hinter seinem Benutzernamen. Wenn der Benutzer nicht im Projekt vorhanden ist, sehen Sie stattdessen seine E-Mail-Adresse in Klammern

**Themen mit # verknüpfen** Wenn ein Thema von einem Board, auf das Sie keinen Zugriff haben, mit # in der Beschreibung oder einem Kommentar verknüpft ist, sehen Sie # mit der Themennummer, aber nicht den Titel des Themas. Das Thema wird dann für Sie in den verknüpften Themen im rechten Informationsmenü nicht angezeigt.

**Kein Zugang zu verknüpften Dokumenten** Wenn Sie keinen Zugriff auf ein verknüpftes Dokument haben, sehen Sie ein Fragezeichen im Dokumentteil des rechten Informationsmenüs.

**Kein Zugang zu Objekten** Wenn Sie keinen Zugriff auf die mit dem Thema verknüpften Objekte haben, sehen Sie, dass einige Objekte verknüpft sind, aber sie werden als _Unbekannt_ angezeigt

_Schnappschuss - Kein Modellzugang_ Der Schnappschuss enthält ein Bild von dem Zeitpunkt, an dem er hinzugefügt wurde. Dieses Bild wird nicht aktualisiert, daher kann es veraltet sein.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/10-no-access-in-a-topic.png)

Wenn Sie keinen Zugriff auf Modelle im Schnappschuss haben, können Sie ihn nicht wiedergeben, da die Wiedergabeschaltfläche deaktiviert wurde. Wenn Sie keinen Zugriff auf ein Modell haben, sehen Sie es nicht in der Modellauswahl aufgelistet, wie im Screenshot des Schnappschusses.

### 4.3 **Keine Dokumentrevisionen**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/libraries/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/items/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/libraries/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/items/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) Dies ist, wie die Seite aussehen kann, wenn der Benutzer Zugriff auf das Dokument hat, aber keine Revisionen sieht. Ein Grund für diese Seite könnte sein, dass es keine Revisionen gibt. Dies kann passieren, wenn ein Modell auf der Modellseite erstellt wird. Ein Dokument mit dem gleichen Namen wie das Modell und ohne Revisionen wird dann erstellt und mit dem Modell verknüpft. In der Dokumentstruktur ist die Spalte "Revision" leer und Sie sehen "keine Revisionen" in der Spalte "Revisionsname".

Ein weiterer Grund dafür kann sein, dass es keine öffentlichen Revisionen im Dokument gibt, aber es Revisionsversionen gibt. Wenn der Benutzer Lesezugriff auf das Dokument hat und der Zugriff auf das Lesen von Entwurfsdokumenten in den Projekteinstellungen verweigert wurde. In der Dokumentstruktur ist die Spalte "Revision" leer und Sie sehen "x neue Entwürfe" in der Spalte "Revisionsname".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/13-no-document-revisions.png)

### 4.4 **Zurückgezogene Dokumentrevision**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/libraries/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/items/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/libraries/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/items/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) Eine Dokumentrevision kann [zurückgezogen](https://support.catenda.com/en/articles/9711174-withdraw-revision) werden mit der [Aktion "Revision zurückziehen"](https://support.catenda.com/en/articles/8302244-right-menu-in-a-document). Sie werden feststellen, dass der Name der zurückgezogenen Revision durchgestrichen ist.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/14-withdrawn-document-revision.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/15-withdrawn-document-revision.png)

### 4.5 **Kein Zugang zu einem Dokument in einer Genehmigung**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/libraries/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/approvals/xx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/libraries/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/approvals/xx) Dies ist, wie kein Zugang in einer Genehmigung aussehen kann

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/16-br-br-no-access-to-a-document-in-an-approval.png)

**Kein Zugang für Prüfer** Wenn ein Prüfer keinen Zugriff auf eine Genehmigung hat, sehen Sie (Kein Zugang) hinter dem Benutzer. Dies kann passieren, wenn der Benutzer nicht mehr Teil des Projekts ist.

**Kein Zugang zu Dokumenten in einer Genehmigung** Wenn Sie ein Dokument nicht anzeigen können, entweder weil Sie keinen Zugriff haben oder weil das Dokument gelöscht ist, sehen Sie in einer Genehmigung eine Nachricht:

**Es gibt eine Datei in der Genehmigung, die Sie nicht sehen können.** Wenn Sie die Genehmigung veröffentlichen können, sehen Sie auch eine Schaltfläche, um die Datei aus der Anfrage zu entfernen, da Sie Dateien, auf die Sie keinen Zugriff haben, nicht veröffentlichen können.

## 5. **Modellzugang**

### 5.1 **Zugang zur Modellseite**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/models](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/models) Dies ist, wie die Seite aussehen kann, wenn es entweder keine Modelle gibt oder der Benutzer keinen Zugriff auf Modell-Dokumente im Projekt hat. ### 5.2 **Zugang zur Modellseite**

[https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/models/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx](https://hub.catenda.com/project/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/models/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx) Dies ist, wie die Seite aussehen kann, wenn der Benutzer versucht hat, einem Link zu einer Modellseite zu folgen, ohne Zugriff auf das mit dem Modell verbundene Dokument-Modell zu haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/19-model-page-access.png)

### 5.3 **Modellrevision zurückgezogen**

Wenn eine Modellrevision [zurückgezogen](https://support.catenda.com/en/articles/9711174-withdraw-revision) wurde, sehen Sie ihren Namen durchgestrichen. Wenn die neueste Revision zurückgezogen wurde, sehen Sie eine Warnung auf der Modellseite.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/20-model-revision-withdrawn.png)

Der Titel einer zurückgezogenen Revision wird durchgestrichen und Sie können sie nicht herunterladen oder in 2D/3D öffnen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qewb0f5x/21-model-revision-withdrawn.png)
