# 3D-Viewer - Catenda Site

Öffnen Sie die [2D/3D-Seite](https://support.catenda.com/en/articles/7734138-2d-3d-catenda-site), um den 3D-Viewer oben auf dem Bildschirm von Catenda Site zu sehen. So kann der 3D-Viewer auf Catenda Site aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/01-intro.png)

3D-Modelle aus dem Modellebereich in einem Catenda-Projekt können im 3D-Viewer auf Catenda Site aktiviert und deaktiviert werden.

## 1. **Modellwähler**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/02-model-selector.png)

Tippen Sie auf die Schaltfläche "Modellauswahl", um das Menü "Modellauswahl" zu öffnen. Aktivieren Sie die Kontrollkästchen neben jedem Modell, um dieses Modell im 3D-Viewer zu aktivieren. Tippen Sie nach dem Aktivieren/Deaktivieren von Modellen auf "**Fertig**".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/03-model-selector.png)

## 2. **Symbolleiste**

Die Symbolleiste finden Sie oben rechts im 3D-Viewer.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/04-toolbar.png)

### 2.1 **Zoom Grenze**

Positionieren Sie die Kamera des 3D-Viewers so, dass alle Objekte sichtbar sind.

### 2.2 Optionen zurücksetzen

So kann das Menü „Optionen zurücksetzen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/05-reset-options.png)

Im Menü „Optionen zurücksetzen

- _Alle Objekte anzeigen_ - Offenbaren Sie alle Objekte, die Sie ausgeblendet hatten
- _Messungen löschen_ - Entfernen Sie alle Messungen
- _Schnittebenen entfernen_ - Entfernen Sie alle Schnittebenen

Tippen Sie auf "**Fertig**", wenn Sie die Konfiguration der 3D-Zurücksetzen-Optionen abgeschlossen haben

## 3. **3D-Viewer-Einstellungen**

So kann das Menü „3D-Viewer-Einstellungen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/06-3d-viewer-settings.png)

### 3.1 **Navigationsmodus**

**Pinch** Ziehen Sie zwei Finger näher zueinander oder voneinander weg, um zu pinchen. Wenn Sie den 3D-Viewer pinchen, bewegt sich die Kamera vorwärts/rückwärts.

**Schwenken** Ziehen Sie mit einem Finger auf dem 3D-Viewer, um zu schwenken. Der Navigationsmodus beeinflusst, was geschieht, wenn der 3D-Viewer geschwenkt wird.

_Mobil_ - Standard Kamerawinkel anpassen

**Tablet** Wenn Sie einen Finger auf dem 3D-Viewer halten, wird ein Zugpunkt unter der gehaltenen Position angezeigt. Wenn Sie ein Objekt halten, wird der Zugpunkt auf diesem Objekt angezeigt. Wenn Sie Leerraum halten, wird der Zugpunkt in einem festen Abstand in der Richtung von der Kamera zur Zugposition angezeigt. Nach dem Ziehen des 3D-Viewers zeigt der Zugpunkt die Zugrichtung an und Kamerawinkel und -position beginnen sich um den Zugpunkt zu drehen. Lassen Sie den Bildschirm los, um die Kamera in ihrer neuen Position und ihrem neuen Winkel zu sperren.

### 3.2 **Joystick-Sichtbarkeit**

Aktivieren oder deaktivieren Sie den Joystick. Der Joystick kann gezogen werden, um die Kamera nach oben/unten/links/rechts zu bewegen

## 4. **3D-Viewer-Interaktion**

Wenn auf ein Objekt getippt wird, wird es ausgewählt und ein Kontextmenü wird geöffnet. Das Kontextmenü kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/07-3d-viewer-interaction.png)

### 4.1 **Titel**

Der Titel des Kontextmenüs besteht aus dem Namen des ausgewählten Objekts.

### 4.2 **Ausblenden**

Tippen Sie auf die Schaltfläche "Ausblenden", um das Objekt auszublenden. Objekte können mit der Reset-Schaltfläche in der Symbolleiste oben rechts erneut angezeigt werden.

### 4.3 **Lasermaß**

Tippen Sie auf das Lasermaß, um die Abstände zu den nächsten Oberflächenkanten oder sich schneidenden Objekten in den X-, Y- und Z-Richtungen zu messen. Messungen können mit der Schaltfläche „Zurücksetzen

### 4.4 **Punktmessung**

Tippen Sie auf die Schaltfläche "Punktmessung", um die X-, Y- und Z-Koordinaten der angetippten Position auf dem Objekt anzuzeigen. Messungen können mit der Reset-Schaltfläche in der Symbolleiste oben rechts gelöscht werden.

### 4.5 **Schnittebene**

Tippen Sie auf die Schaltfläche "Schnittebene", um eine Schnittebene entlang der angetippten Oberfläche zu erstellen. So kann der 3D-Viewer nach dem Erstellen einer Schnittebene aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/08-clipping-plane.png)

Nach dem Erstellen einer Schnittebene wird ein Schieberegler unten auf dem Bildschirm angezeigt. Passen Sie diesen Schieberegler an, um die Schnittebene in ihrer Normalrichtung zu verschieben und Feineinstellungen vorzunehmen. Schnittebenen können mit der Schaltfläche „Zurücksetzen

### 4.6 **Informationen**

Tippen Sie auf die Schaltfläche "Informationen", um die Informationsseite für das angetippte Objekt zu öffnen.

**Objektinformationen** In den Objektinformationen können Sie Folgendes finden:

- Name
- Entität
- Guid
- Etikett
- Typ
- Vordefinierter Typ

**Eigenschaften** Standardmäßige IFC-Eigenschaften sowie verschiedene Eigenschaftssätze für das Objekt werden hier angezeigt. Hier finden Sie typischerweise Informationen wie Messungen, Mengen, Material usw.

**Dokumente** Der Titel und das Erstellungsdatum von Dokumenten, die mit dem ausgewählten Objekt verknüpft wurden, werden angezeigt. Tippen Sie auf das Dokument, um es auf der Seite Dokumente zu öffnen.

**Themen** Der Titel und die Themennummer von Themen, die mit dem ausgewählten Objekt verknüpft wurden, werden angezeigt. Tippen Sie auf das Thema, um es auf der Seite Themen zu öffnen.
