# CatendaSP-App hinzufügen und entfernen

> **Hinweis:** Die Installationsdatei für das Plugin finden Sie in [diesem Artikel](https://intercom.help/bimsync-arena/en/articles/8396532-catenda-plugins-and-integrations).

Die Catenda SharePoint-Anwendung kann von einem Website-Besitzer zu einer SharePoint-Umgebung hinzugefügt werden, wenn die App vom SharePoint-Administrator für den Mandanten aktiviert wurde. Mit dieser App können SharePoint-Benutzer Dokumente in Catenda zusammen mit anderen Mitgliedern des Bauprojekts anzeigen, verwalten und gemeinsam bearbeiten.

## 1. **App hinzufügen**

### 1.1 **Neue Benutzeroberfläche**

Um die App zu Ihrer Website hinzuzufügen, finden Sie die neue App-Aktion im Abschnitt "Inhalte der Website" oder gehen Sie zu Ihrer Website und klicken Sie auf Ihr Profilbild, um die Option "App hinzufügen" im Zahnradmenü zu finden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/01-new-experience.png)

Dies öffnet den Bereich "Meine Apps" Ihres SharePoint App Store, in dem Sie auf "Hinzufügen" klicken können. Es könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/02-new-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/appStore.aspx/myApps?entry=SettingAddAnApp&sorting=1**

Sie können auch auf den App-Namen klicken, um weitere Informationen zur App zu erhalten und die App von ihrer Store-Eintrag-Seite hinzuzufügen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/03-new-experience.png)

https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/appStore.aspx/appDetail/WA200005981

### 1.2 **Klassische Benutzeroberfläche**

Wenn Sie mit der klassischen SharePoint-Benutzeroberfläche vertraut sind, können Sie die App zu Ihrer Website hinzufügen, indem Sie zu Abschnitt "Inhalte der Website" Ihrer Website gehen und auf "App hinzufügen" klicken, oder indem Sie auf Ihr Profilbild klicken, um die Option "App hinzufügen" im Zahnradmenü zu finden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/04-classic-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/viewlsts.aspx**

Dies öffnet den Bereich "Ihre Apps" des Inhalts Ihrer Website. Es könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/05-classic-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/addanapp.aspx?Source=https%3A%2F%2F\<Tenant>%2Esharepoint%2Ecom%2Fsites%2F\<Sitename>%2F%5Flayouts%2F15%2Fviewlsts.aspx**

Wenn Sie auf die App auf dieser Seite klicken, wird sie zu Ihrer Website hinzugefügt. Wenn Sie auf "App-Details" klicken, werden Sie zum klassischen SharePoint Store-Eintrag weitergeleitet. Es könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/06-classic-experience.png)

_https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/storefront.aspx?source=https%3A%2F%2F\<Tenant>%2Esharepoint%2Ecom%2Fsites%2FSharepointTest2%2F%5Flayouts%2F15%2Fviewlsts%2Easpx&sname=Sharepoint%20Test%202#vw=AppDetailsView,app=e39e0641%2D5c83%2D4639%2Dad87%2Dbe9ccf43ab75,clg=1,bm=,cm=_

Wenn Sie auf dieser Seite auf "Anfordern" klicken, wird die App zu Ihrer Website hinzugefügt.

## 2. **App installieren**

Unmittelbar nach dem Hinzufügen der Catenda SharePoint-App wird sie als ausgegrautes Element in den Website-Inhalten angezeigt. Es kann einige Zeit dauern, bis die Installation abgeschlossen ist und die App verfügbar wird. So könnte es aussehen, wenn die App installiert wird:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/07-installing-the-app.png)

https://_\<Tenant>_.sharepoint.com/sites/\<_Sitename_>/\_layouts/15/viewlsts.aspx?view=14

## 3. **App entfernen**

### 3.1 **Neue Benutzeroberfläche**

In Zukunft wird es möglich sein, die App von einer Website aus über das Hamburger-Menü im Abschnitt "Inhalte der Website" zu entfernen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/08-new-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/viewlsts.aspx?view=14**

Derzeit ist es nur möglich, die App in der alten Benutzeroberfläche zu entfernen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/09-new-experience.png)

Klicken Sie auf "Zur klassischen SharePoint-Version zurückkehren" oder suchen Sie die ältere Benutzeroberfläche unten links auf der Seite mit den Website-Inhalten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/10-new-experience.png)

### 3.2 **Alte Benutzeroberfläche**

Um die Catenda-App zu entfernen, zeigen Sie auf das App-Element auf der Seite "Inhalte der Website". Klicken Sie auf die drei Punkte, die oben rechts in der App angezeigt werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/11-old-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/viewlsts.aspx**

Klicken Sie im angezeigten Menü auf "Entfernen" und die App wird von der Website entfernt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/12-old-experience.png)

Beachten Sie, dass die App nicht für den gesamten Mandanten entfernt wird und Website-Besitzer die App weiterhin auf ihren Websites hinzufügen können.
