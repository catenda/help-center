# Neue Version der Mobile App

[Es gibt eine neue Version der mobilen App (1.5.0), die jetzt in beiden Stores verfügbar ist!](https://catenda.com/products/bimsync-mobile-app/) 🎉🎉

Hier ist, was es in dieser Version Neues gibt:

- Brandneues interaktives Dashboard mit mehr Statistiken und direkter Navigation zu Ihren Problemlisten mit vordefinierten Filtern

- Unterstützung für das Hinzufügen mehrerer Bilder und Viewpoints beim Erstellen eines neuen Problems

- Problemberichte durch Wischgeste löschen

- Verbesserter Einstellungsbildschirm. Jetzt können Sie Ihren bevorzugten Startbildschirm wählen

- Neues In-App-Benachrichtigungssystem, um Ihnen nützlichere Informationen zu bieten

- Leistungssteigerung für alle Android-Geräte
