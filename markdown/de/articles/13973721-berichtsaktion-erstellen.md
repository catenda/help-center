# Berichtsaktion erstellen

Die Aktion "Bericht erstellen" ist für Projekte verfügbar, in denen die Opt-in-Berichtsfunktion aktiviert werden soll. Wenn die Berichtsfunktion in einem Projekt aktiviert ist, wird die Aktion "Bericht erstellen" in den Aktionsmenüs der Dokumente und Themen-Tabelle verfügbar. Wählen Sie ein oder mehrere Elemente in der Dokumenttabelle aus und öffnen Sie das [Dokumenttabellen-Aktionsmenü](https://support.catenda.com/en/articles/4670288-documents-table-actions). Wählen Sie ein oder mehrere Elemente in der Thematabelle aus und öffnen Sie das [Thematabellen-Aktionsmenü](https://support.catenda.com/en/articles/4670284-topics-table-actions). So könnte die Aktion "Bericht erstellen" aussehen:

<img alt="" src="https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/inline-ef841bc1c2c3.png" width="290"/>   \<->   <img alt="" src="https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/inline-0c1ebf646ff6.png" width="290"/>

## 1. Exportoptionen wählen

Wenn die Aktion "Bericht erstellen" angeklickt wird, wird das Dialogfeld "Bericht generieren" geöffnet:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/01-choose-export-options.png)

> **Hinweis:** Beachten Sie bei Berichten, die auf ausgewählten Elementen in der Dokumenttabelle erstellt wurden, dass nur Dokumentelemente in den Bericht aufgenommen werden und nicht Ordnerelemente.

### 1.1 **Ausgewählt**

Zeigt die Anzahl der ausgewählten Elemente an (Ordner in Dokumentberichten ausgeschlossen)

### 1.2 **Aktueller Filter**

Zeigt die Anzahl der Elemente an, die dem aktuellen Filter entsprechen. Die Anzahl umfasst Ordnerelemente in Dokumentberichten, obwohl diese nicht in den Bericht aufgenommen werden

### 1.3 **Weiter**

Klicken Sie auf "Weiter", um den Bericht auf der Berichtsseite zu öffnen.

## 2. Neue Berichtsseite

So könnte die neue Berichtsseite aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/02-new-report-page.png)

### 2.1 **Berichtsvorlage wählen**

Wählen Sie einen vordefinierten Bericht aus der Liste der Berichtsvorlagen aus, die der Projektadministrator im Projekt verfügbar gemacht hat. Wählen Sie für Berichte aus der Dokumenttabelle aus einer Liste der verfügbaren Dokumentvorlagen aus. Wählen Sie für Berichte aus der Thematabelle aus einer Liste der verfügbaren Themenvorlagen aus.

### 2.2 **Neue Berichts-Symbolleiste**

**Speichern** So könnte das Speichermenü aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/03-new-report-toolbar.png)

> **Hinweis:** Stellen Sie sicher, dass der Browserzoom auf die richtige Skalierung eingestellt ist, um das gesamte Menü zu sehen.

Eine Vorschau des Berichts wird nach der Standardvorlage erstellt.

**Themenbericht** So könnte ein Themenbericht aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/06-report-preview.png)

**Dokumentenbericht** So könnte ein Dokumentenbericht aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/07-report-preview.png)

Berichtsvorlagen werden auf der Seite "Berichtsvorlagen" konfiguriert. _Erforderlicher Zugriff zum Speichern von Berichten:_ Lesezugriff überall im Dokumentbereich. _Erforderlicher Zugriff für die Vorlagenkonfiguration:_ Administrator
