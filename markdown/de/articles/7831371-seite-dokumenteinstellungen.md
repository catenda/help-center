# Seite "Dokumenteinstellungen"

Die Einstellungen für die Dokumentenbibliothek finden Sie als Unterseite auf der [Seite "Dokumente"](https://support.catenda.com/en/articles/8204673-documents-page). Auf dieser Seite kann der Zugriff auf die oberste Ebene der Dokumentenseite konfiguriert werden und es kann eine Zugriffsübersicht generiert werden. Der Status-Workflow kann aktiviert werden, damit Projektmitglieder verfolgen können, wie weit eine Revision in einem Workflow vorangeschritten ist. Workflows zur Genehmigung einer Revision für die nächste Phase können konfiguriert werden. Standardmetadaten, Namenskonventionen oder QR-Code-Stempelung können für Ordner und Dokumente konfiguriert werden. _Erforderlicher Zugriff:_ Administrator oder Zugriff auf [Dokumentstatus-Konfiguration](#h_e6f3ffdbff) in [Projekteinstellungen](https://support.catenda.com/en/articles/4670273-project-settings-page).

## 1. **Zugriffskontrolle**

### 1.1 **Zugriffsübersicht**

Diese Schaltfläche führt Sie zur [Zugriffsübersicht](https://support.catenda.com/en/articles/6660820-document-access-overview-acl-dashboard) des Dokumentenbereichs. Hier können Sie eine Übersicht generieren, welches Team oder welche Mitglieder Zugriff auf welche Ordner im Dokumentenbereich haben.

### 1.2 **Zugriff bearbeiten**

Im Menü "Zugriffskontrolle" können Sie den Zugriff auf den Stammordner des Dokumentenbereichs festlegen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/03-edit-access.png)

Auf der Dokumentenseite kann der Zugriff für Ordner und Dokumente konfiguriert werden. Allerdings gibt es nichts auszuwählen, um den Zugriff auf die oberste Ebene der Dokumentenseite zu konfigurieren. Wer kann auf der obersten Ebene der Dokumententabelle Aktionen durchführen? Dafür ist das Menü "Zugriffskontrolle" auf der Seite "Dokumenteinstellungen" da. Stellen Sie sich die gesamte Dokumententabelle als einen großen Ordner vor, der alle Ordner und Dokumente im Projekt enthält. Das Menü "Zugriffskontrolle" auf der Seite "Dokumenteinstellungen" ist das Menü "Zugriffskontrolle" für diesen Ordner. Klicken Sie [hier](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl), um mehr über die Zugriffskontrolle für Dokumente zu erfahren

## 2. **Status-Workflow**

Wenn Sie den Status-Workflow aktivieren, können Sie Informationen Status zuordnen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/04-status-workflow.png)

Der Status-Workflow folgt den ISO-19650-Standards, die beschreiben, wie weit Informationen in einem Prozess vorangeschritten sind. Vor der Aktivierung des Status-Workflows werden alle an Catenda übermittelten Informationen als veröffentlichte Phase angesehen, was typischerweise bedeutet, dass die hochgeladenen Informationen die endgültige Version dieser Informationen sind. In der Phase vor der Veröffentlichungsphase können Dokumente zusammengearbeitet werden, bevor sie abgeschlossen und in die Veröffentlichungsphase verschoben werden. Die Phase nach der Veröffentlichung ist die Archivierungsphase, wenn das Projekt entweder auf Catenda archiviert wird oder Informationen exportiert werden, um außerhalb von Catenda gespeichert zu werden. Klicken Sie [hier](https://support.catenda.com/en/articles/12310173-status-workflow-document-settings), um mehr über das Status-Workflow-Menü zu erfahren.

## 3. **Freigaben**

So kann das Menü "Freigaben" aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/05-approvals.png)

Das Menü "Freigaben" ist nur in Projekten verfügbar, in denen der neue Validierungs-Workflow aktiviert werden soll. Der neue Validierungs-Workflow ist eine bedarfsorientierte Funktion, die für neue Projekte aktiviert werden kann. Neue Projekte, die auf einem Vorlagenprojekt basieren, in dem diese Funktion aktiviert ist, haben diese Funktion nicht aktiviert.

### 3.1 **Workflows konfigurieren**

Wenn Sie auf die Schaltfläche "Workflows konfigurieren" klicken, wird die Seite "Workflows" geöffnet. Auf der Seite "Workflows" können Workflows konfiguriert werden, aus denen Mitglieder bei der Erstellung einer Freigabe auf der [Seite "Freigaben"](https://support.catenda.com/en/articles/8349340-approvals-page) wählen können. Klicken Sie [hier](https://support.catenda.com/en/articles/12309903-workflows-page-document-settings), um mehr über die Seite "Workflows" zu erfahren.

## 4. **Ordnerkonfiguration**

So kann das Menü "Ordnerkonfiguration" aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/06-folder-configuration.png)

In der Tabelle "Ordnerkonfiguration" können folgende Einstellungen für Ordner konfiguriert werden:

- Namenskonventionen
- Benutzerdefinierte Felder in Dokumenten
- Benutzerdefinierte Felder in Dokumentrevisionen
- QR-Code-Stempelung

Klicken Sie [hier](https://support.catenda.com/en/articles/12302595-folder-configuration-menu), um mehr über das Menü "Ordnerkonfiguration" zu erfahren.
