# Dokumentvorschau-Tools

Wenn die [Vorschauseite](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations) eines [Dateityps, der in der Vorschau angezeigt werden kann](https://support.catenda.com/en/articles/4670320-previewing-file-types-on-catenda-hub) zum ersten Mal geöffnet wird, wird die folgende Symbolleiste oben angezeigt.

![Ansicht Kommentieren Formen Einfügen Messen](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/01-intro.png)

Wenn die Browserskalierung auf eine mittlere Größe eingestellt ist oder eine mittlere Bildschirmgröße verwendet wird, können die Menüs in ein Aktionsmenü überlaufen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/02-intro.png)

Wenn die Browserskalierung auf eine große Größe eingestellt ist oder eine kleine Bildschirmgröße verwendet wird, können alle Menüs wie folgt in einem Dropdown-Menü angezeigt werden:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/03-intro.png)
Formen, Text und Beschriftungen können hinzugefügt werden, Text kann hervorgehoben werden, Messungen können durchgeführt werden und Sie können freihand zeichnen.
All dies kann später in Themen gespeichert werden.
Klicken Sie [hier](https://support.catenda.com/en/articles/10209740-saving-a-markup), um mehr über das Speichern von Anmerkungen zu erfahren.

## 1. **Menü**

So kann das Symbolleistenmenü aussehen:

![Herunterladen Vollbildmodus Speichern unter Drucken Einstellungen](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/04-menu.png)

### 1.1 **Herunterladen**

Klicken Sie auf Herunterladen, um das Dokument mit allen aktiven Anmerkungen in der Dokumentenvorschau herunterzuladen.

### 1.2 **Vollbildmodus aktivieren**

Klicken Sie auf Vollbildmodus aktivieren, um nur die Dokumentenvorschau und die Symbolleiste im Vollbildmodus zu öffnen. Drücken Sie Escape oder öffnen Sie dasselbe Menü erneut, um die Schaltfläche Vollbildmodus beenden zu finden.

### 1.3 **Speichern unter**

Mit dem Menü Speichern unter kann jeder vorschaubare 2D-Dateityp als rekonstruierte Datei gespeichert werden. Das Dialogfeld Speichern unter kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/05-save-as.png)

**Dateiname** Geben Sie den Namen ein, den die gespeicherte Datei erhalten soll.

**Dateityp** Speichern Sie jeden vorschaubaren 2D-Dateityp als PDF (\*.pdf) oder PNG (\*.png)

**Seitenbereich** Wählen Sie, welche Seiten einzubeziehen sind. Die Optionen sind:

Alle - Standard Speichern Sie alle Seiten

Seiten angeben Speichern Sie bestimmte Seiten nach Seitennummer, getrennt durch Komma oder mit einem Bindestrich, um einen Seitenbereich wie beispielsweise (1, 3, 5-10) zu speichern.

Aktuelle Seite Speichern Sie nur die aktuelle Seite

**Eigenschaften** Anmerkungen einbeziehen - Standard Fügen Sie dem heruntergeladenen Dokument eine separate Seite mit einem Überblick über die Anmerkungen im Dokument und deren Inhalte ein.

Kommentare einbeziehen Fügen Sie dem heruntergeladenen Dokument eine separate Seite mit einem Überblick über die Kommentare im Dokument und deren Inhalte ein.

## 3. **Marquee-Zoom**

So kann das Dokumentenzoom-Symbol aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/11-marquee-zoom.png)

Wenn der Dokumentenzoom ausgewählt ist, klicken Sie überall im Dokument an, um in diese Richtung zu zoomen. Sie können auch klicken und ziehen, um einen Teil des Dokuments zu markieren, zu dem Sie zoomen möchten. Halten Sie Strg oder Befehl gedrückt, um stattdessen herauszuzoomen. Sie sehen, dass sich Ihr Cursor in ein Lupe mit einem + oder - ändert, das Ihre Zoomrichtung angibt.

## 4. **Zoompercentage**

Klicken Sie auf den Zoomprozentsatz, um das Menü Zoompercentage zu öffnen. Das Menü Zoompercentage kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/12-zoom-percentage.png)

### 4.1 **Breite anpassen**

Passen Sie das Dokument so an, dass es die gesamte Breite der Dokumentenvorschau abdeckt

### 4.2 **An Seite anpassen**

Passen Sie das Dokument so an, dass die ganze aktuelle Seite, auf der Sie sich in der Dokumentenvorschau befinden, angezeigt wird.

### 4.3 **Zoom vergrößern und verkleinern**

Klicken Sie auf die Plus- und Minusschaltflächen neben dem Zoomprozentsatz, um eine Stufe nach oben/unten zu gehen.

## 5. **Verschieben**

So kann die Schaltfläche Verschieben aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/13-pan.png)

Wenn Sie die Leertaste loslassen, wird Ihr vorheriges Tool erneut ausgewählt.

So können die Einfügungsmenü-Tools aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/20-insert-menu.png)

_Bild - Tastaturkürzel:_ (I) Wählen Sie das Bildwerkzeug aus und klicken Sie überall im Dokument an, um an dieser Stelle ein Bild hinzuzufügen.

Beispiele für eingefügte Bilder sind:

- Generierte Informationen mit Metadaten.
  In einigen Arbeitsabläufen werden Bilder mit Informationen über den Benutzer generiert, der das Dokument angesehen hat, zusammen mit einigen Informationen wie Datum und Fachbereich.
- Ein persönliches oder Unternehmenslogo.
  In einigen Fällen wird das Logo eines Unternehmens als Bild eingefügt, um anzuzeigen, dass dieses Unternehmen das Dokument überprüft hat.
- Eine persönliche Unterschrift
  Sometimes Manchmal ist es ein Scan einer handschriftlichen Unterschrift, manchmal kann es auch eine digital generierte Unterschrift sein.
- Ein persönlicher Stempel.
  In einigen Kulturen werden Stempel der Unterschrift vorgezogen

Nach dem Klicken auf den Einfügungsort wird der System-Dateibrowser geöffnet. Navigieren Sie zu dem einzufügenden Bild und wählen Sie es aus. Nach der Auswahl des Bildes wird es an der angegebenen Stelle platziert.

Obwohl das Bild eine Unterschrift enthalten kann, die sogar digital generiert sein könnte, wird das ausgewählte Bild als Bitmap-Bild eingefügt, das nicht kryptografisch durch einen privaten Schlüssel zur Bildung einer elektronischen Signatur geschützt ist. Klicken Sie [hier](https://en.wikipedia.org/wiki/Electronic_signature), um mehr über elektronische Signaturen zu erfahren.

Wählen Sie das platzierte Bild aus: Verschieben - Ziehen Sie das Bild Skalieren - Ziehen Sie die Ecke des Bildes Drehen - Ziehen Sie die Rotationsgriff Duplizieren - Halten Sie Alt gedrückt und ziehen Sie das Bild, um es zu duplizieren Löschen - Klicken Sie auf den Papierkorb oder drücken Sie Löschen, um das Bild zu löschen
