# PDF-Vergleich

Wenn Sie ein PDF mit mehr als einer revision im Abschnitt Dokumente öffnen, wird die Schaltfläche "Vergleichen" oben rechts des Dokuments neben dem Dropdown-Menü "revision" angezeigt.

## 1. **Schaltfläche "Vergleichen"**

Wenn Sie auf die Schaltfläche "Vergleichen" klicken, wird die aktuelle revision mit der vorherigen revision verglichen. Wenn Sie die Schaltfläche "Vergleichen" erneut klicken, wird der Vergleich abgebrochen.

### 1.1 **Dropdown-Menü "Vergleichen"**

Wenn Sie auf das Dropdown-Menü "Vergleichen" klicken, haben Sie die Möglichkeit, die Farbe der aktuellen revision und die Farbe der revision, die Sie vergleichen, auszuwählen. Mit dem Schieberegler können Sie die Deckkraft anpassen, um zu steuern, welche revision deutlicher angezeigt werden soll.

## 2. **Anmerkungen mit verglichenen Dokumenten**

Es ist möglich, Anmerkungen von zwei verglichenen PDF-Revisionen zu erstellen. Diese Anmerkung kann wie eine reguläre Anmerkung im Kommentarbereich eines Problems gespeichert werden.
