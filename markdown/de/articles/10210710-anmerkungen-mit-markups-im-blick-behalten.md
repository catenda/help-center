# Anmerkungen mit Markups im Blick behalten

Die neue Markup-Funktion ermöglicht es, Anmerkungen zu gruppieren, die sich möglicherweise auf verschiedenen Seiten eines Dokuments und über mehrere Versionen hinweg befinden. Anmerkungssätze finden Sie als [Kommentare zu Topics](https://support.catenda.com/de/articles/8053352-themen-text-der-inhalt-eines-themas#h_f76b44d3ca). In der [Markups-Registerkarte](https://support.catenda.com/de/articles/10205725-rechtes-menu-einer-revision-markups) des rechten Informationsmenüs eines Dokuments finden Sie die Anmerkungssätze, die in einem Markup zusammengefasst sind. Wenn aktiviert, können die Anmerkungen in einem Markup [in einer Dokumentvorschau angezeigt werden](https://support.catenda.com/de/articles/5001165-dokumentvorschau-und-anmerkungen).

Das folgende Diagramm zeigt, wie Anmerkungen unter verschiedenen Markups gruppiert sind, die dann [als Kommentar gespeichert](https://support.catenda.com/de/articles/10209740-ein-markup-speichern) werden können unter neuen oder vorhandenen Topics.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/01-intro.png)

Beachten Sie bitte Folgendes:

1. Ein **Markup** kann **einen oder mehrere Anmerkungssätze enthalten.**
1. Ein **Themen** kann **einen oder mehrere Markups** als **Kommentare** enthalten
1. In einem **Topic** ist ein **Markup** ein **Satz von Anmerkungen**, der immer **derselben Version angehört.**
1. **Mehrere Markups** in einem Dokument können als **mehrere Themen** ODER unter einem **einzelnen vorhandenen Themen** gespeichert werden
1. Wenn ein **Markup** **mehrere Anmerkungssätze auf mehreren Seiten** enthält, gibt es **einen Kommentar pro Anmerkungssatz auf jeder Seite**.

## 1. **Zwei Workflows**

Wenn Sie etwas in einem Dokument hervorheben möchten, gibt es verschiedene Möglichkeiten, dies mit Ihren Kollegen zu kommunizieren.

### 1.1 **Ein Topic pro Markup**

Jedes Markup mit Anmerkungen wird separat kommuniziert.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/02-one-topic-per-markup.png)

Dies kann gut für Markups sein, die jeweils an eine oder mehrere Personen gerichtet sind. Ein Topic kann aus jedem Markup erstellt werden. Jedes Topic kann dann weiterverfolgt werden.

### 1.2 **Alle Markups in einem Topic**

Halten Sie die gesamte Kommunikation über die von Ihnen erstellten Anmerkungen an einem Ort.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/03-all-markups-in-one-topic.png)

Dies kann gut für Markups mit allgemeinen Anmerkungen sein, die von einer oder mehreren Personen weiterverfolgt werden. Ein Topic sollte dann vorbereitet werden, in dem Sie alle Ihre Markups kombinieren.

## 2. **Anmerkungen erstellen**

Wie zuvor können Sie Anmerkungen erstellen, indem Sie das Dokument in der [Dokumententabelle](https://support.catenda.com/de/articles/8204673-dokumentenseite#h_54e8dfcac2) aufsuchen und auf seinen Namen klicken, um die [Dokumentvorschau](https://support.catenda.com/de/articles/5001165-dokumentvorschau-und-anmerkungen) anzuzeigen. Hier können Sie ein Anmerkungswerkzeug aus der Symbolleiste auswählen. Klicken Sie auf eine beliebige Stelle im Dokument, um die erste Anmerkung zu erstellen und Ihr Markup zu starten:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/04-creating-annotations.png)

## 3. **Markups-Registerkarte**

Nach dem Erstellen einiger Anmerkungen sehen Sie, dass Sie [ungespeicherte Markups](https://support.catenda.com/de/articles/10209740-ein-markup-speichern) in der [Markups-Registerkarte des rechten Informationsfensters](https://support.catenda.com/de/articles/10205725-rechtes-menu-einer-revision-markups) haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/05-markups-tab.png)

> **Hinweis:** Wenn Sie ein Dokument zum ersten Mal öffnen, ist das rechte Menü möglicherweise geschlossen. Sie können auf die Informationsschaltfläche in der unteren rechten Ecke des [Dokumentbannners](https://support.catenda.com/de/articles/8461918-dokumentbanner-navigation) klicken, um dieses Menü zu erweitern. <div> <img alt="" src="https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/06-document-banner-information-button.png" width="400" > </div>

### 3.1 **Mehrere Markups gleichzeitig**

Nehmen wir an, dieses Markup war an den Architekten gerichtet, aber Sie möchten auch einige Änderungen für den Statiker senden. Sie können dann auf die Schaltfläche "Neues Markup" klicken, um ein weiteres Markup vorzubereiten. An dieser Stelle können Sie immer noch zu Ihrem vorherigen Markup zurückkehren und es bearbeiten

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/07-multiple-markups-at-once.png)

## 4. **Markups speichern**

Nachdem Sie die Bearbeitung Ihrer Markups abgeschlossen haben, können Sie [diese speichern](https://support.catenda.com/de/articles/10209740-ein-markup-speichern#h_8542b82cf8). Beim Speichern wird für jeden Anmerkungssatz auf der Seite einer Revision ein Kommentar erstellt

### 4.1 **Jeden Markup in sein eigenes Topic speichern**

Wenn Sie auf [Markups speichern](https://support.catenda.com/de/articles/10209740-ein-markup-speichern#h_8542b82cf8) klicken, erstellen Sie ein Topic für jeden Markup.

Diese Topics können etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/08-save-each-markup-to-its-own-topic.png)

Wenn sich Anmerkungen auf mehreren Seiten in den Dokumenten befinden, gibt es einen [Kommentar](https://support.catenda.com/de/articles/8053352-themen-text-der-inhalt-eines-themas#h_e98c0964d4) mit einem Screenshot der Anmerkung für jede Seite, die Anmerkungen enthält.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/09-save-each-markup-to-its-own-topic.png)

Sie können nun jedem Topic die richtige Person zuweisen, damit diese mit den Änderungen beginnen kann.

### 4.2 **Alle Markups in einem Topic speichern**

Wenn Sie es vorziehen, alle Markups in einem Topic zu haben, können Sie ein Topic vorbereiten und auf die Dropdown-Liste "Topic auswählen" klicken und ein vorhandenes Topic auswählen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/10-br-save-all-markups-to-one-topic.png)

Hier sehen Sie Topics, bei denen das Dokument [verlinkt wurde](https://support.catenda.com/de/articles/8053299-rechtes-menu-in-einem-thema#h_b00b9c5150) und falls es [Kommentare](https://support.catenda.com/de/articles/8053352-themen-text-der-inhalt-eines-themas#h_e98c0964d4) zu dieser Version gibt. Wenn sich Anmerkungen auf mehreren Seiten in den Dokumenten befinden, gibt es einen [Kommentar](https://support.catenda.com/de/articles/8053352-themen-text-der-inhalt-eines-themas#h_e98c0964d4) mit einem Screenshot der Anmerkung für jede Seite mit Anmerkungen in jedem Markup.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/11-br-save-all-markups-to-one-topic.png)

So kann das Topic aussehen, wenn Sie mehrere Markups in demselben Topic speichern:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6jfe897w/12-br-save-all-markups-to-one-topic.png)
