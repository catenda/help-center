# Zugriff mit begrenztem Bildschirmplatz

Bei begrenzter Bildschirmgröße können einige Funktionen auf benutzerfreundliche Weise auf Catenda Site aufgerufen werden. Wenn der Zugriff auf die gesamte Funktionalität für Sie wichtiger ist als die Barrierefreiheit, ist dies immer über den Browser verfügbar. Browserseiten können zum Startbildschirm/Dashboard/Dock hinzugefügt werden, um die Erfahrung beim Zugriff auf Catenda mit begrenztem Bildschirmplatz zu verbessern.

## 1. **Catenda Site -** Barrierefreundlich und offline

Auf Geräten mit begrenzter Bildschirmgröße müssen Schaltflächen größer sein, damit Sie sehen, worauf Sie mit Ihrem Finger tippen. In dieser Situation ist unsere mobile App [Catenda Site](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site) das beste Tool für Sie.

- Die Funktionalität ist begrenzt und einfach gehalten, damit Sie die benötigten Schaltflächen leicht antippen können.
- Inhalte können ohne Internetverbindung heruntergeladen und übermittelt werden

## 2. **Startbildschirm / Dashboard / Dock -** Vollständige Funktionalität

Die vollständige Funktionalität von Catenda Hub ist immer über den Browser verfügbar. Catenda unterstützt das [Hinzufügen zum Startbildschirm](https://support.catenda.com/en/articles/10741601-add-to-home-screen), Dashboard oder Dock durch Installation über einen Browser. Die Installation von Catenda über einen Browser statt das Erstellen einer Verknüpfung bietet folgende Vorteile:

- Catenda ist leichter erreichbar, da dies oft die Kernmethode für den Zugriff auf Inhalte auf mobilen Geräten ist.
- Bildschirmplatz wird gespart, da die Browserleiste oben ausgeblendet wird.
- Besonders auf Tablets möchten Sie die gesamte Funktionalität von Catenda nutzen und dabei den verfügbaren Bildschirmplatz optimal nutzen.
