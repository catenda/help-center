# Zugriff mit begrenztem Bildschirmplatz

Bei begrenzter Bildschirmgröße können einige Funktionen in benutzerfreundlicher Weise in unseren mobilen Apps aufgerufen werden. Wenn der Zugriff auf die gesamte Funktionalität für Sie wichtiger ist als die Benutzerfreundlichkeit, ist dies immer über den Browser verfügbar. Browserseiten können zum Startbildschirm/Dashboard/Dock hinzugefügt werden, um die Erfahrung beim Zugriff auf Catenda mit begrenztem Bildschirmplatz zu verbessern.

## 1. **Mobile Apps -** Auf der Website zugänglich

Auf Geräten mit begrenzter Bildschirmgröße müssen Schaltflächen größer sein, damit Sie sehen, worauf Sie mit Ihrem Finger tippen. In dieser Situation sind unsere mobilen Apps Catenda Site und Catenda Mobile die besten Tools für Sie.

### 1.1 **Catenda Site**

[Catenda Site](https://support.catenda.com/de/articles/6530821-laden-sie-ihre-mobile-app-catenda-site-herunter) ist unsere offizielle mobile App, verfügbar für iPhone und iPad sowie für Android.

- Die Funktionalität ist begrenzt und einfach gehalten, damit Sie die benötigten Schaltflächen leicht antippen können.
- Inhalte können heruntergeladen und übermittelt werden, [ohne dass eine Internetverbindung erforderlich ist](https://support.catenda.com/de/articles/7325268-offline-modus-in-catenda-site).

### 1.2 **Catenda Mobile**

[Catenda Mobile](https://support.catenda.com/de/articles/17601630-deine-mobile-catenda-app-herunterladen) ist unsere mobile App im Early-Access, erhältlich für iPhone und iPad über [TestFlight](https://testflight.apple.com/join/xj6WppjQ) und für Android im [Google Play Store](https://play.google.com/store/apps/details?id=com.catenda.apex). Sie behandelt Themen, Standorte, Formulare und Dokumente und wird im Laufe der Zeit alle Funktionen von Catenda Site erhalten. Die App wird zusammen mit den Kunden im Co-Creation-Programm entwickelt und ist noch nicht final, daher kann sie sich noch erheblich ändern.

## 2. **Startbildschirm / Dashboard / Dock -** Vollständige Funktionalität

Die vollständige Funktionalität von Catenda Hub ist immer über den Browser verfügbar. Catenda unterstützt das [Hinzufügen zum Startbildschirm](https://support.catenda.com/de/articles/10741601-zum-startbildschirm-hinzufugen), Dashboard oder Dock durch Installation über einen Browser. Die Installation von Catenda über einen Browser statt das Erstellen einer Verknüpfung bietet folgende Vorteile:

- Catenda ist leichter erreichbar, da dies oft die Kernmethode für den Zugriff auf Inhalte auf mobilen Geräten ist.
- Bildschirmplatz wird gespart, da die Browserleiste oben ausgeblendet wird.
- Besonders auf Tablets möchten Sie die gesamte Funktionalität von Catenda nutzen und dabei den verfügbaren Bildschirmplatz optimal nutzen.
