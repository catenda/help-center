# Catenda Revit Plugin-Änderungsprotokoll - 1.0.15

Neue Funktionen in 1.0.15

- Dieses Plugin verfügt jetzt über ein eigenes .MSI-Installationsprogramm, das vom Autodesk-Plugins-Portal getrennt ist.
- Wenn Sie @ in einem Kommentar oder einer Beschreibung eingeben, erhalten Sie eine Liste mit Mitgliedern, aus der Sie auswählen können, welche Sie erwähnen möchten.
- Bilder für 3D-Schnappschüsse und andere Bilder in Themenkommentaren werden jetzt viel schneller geladen.
- Unterstützung für Revit 2026

> **Hinweis:** Das Deinstallieren der vorherigen Version und das Installieren der neuen Version ist erforderlich, um dieses Plugin zu verwenden.
