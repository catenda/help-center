# Zum Startbildschirm hinzufügen

Die vollständige Funktionalität von Catenda Hub ist immer über den Browser verfügbar. Catenda unterstützt das Hinzufügen zum Startbildschirm, Dashboard oder Dock durch Installation über einen Browser. Dies wird auch als Progressive Web App (PWA) bezeichnet. Klicken Sie [hier](https://support.catenda.com/en/articles/10774300-home-screen-system-browser-support), um zu sehen, welche Browser PWA auf Ihrem System unterstützen.

## 1. **Vorteile**

Die Installation von Catenda über einen Browser anstelle der Erstellung einer Verknüpfung bietet folgende Vorteile:

### 1.1 **Systeme, die von mehreren Personen verwendet werden**

Durch die Installation von Catenda Hub auf Ihrem Startbildschirm können Sie auf Catenda auf die Art zugreifen, auf die auf Ihrem System auf Anwendungen zugegriffen wird. Wenn es Teil einer Liste verfügbarer Anwendungen ist, können Benutzer leichter erkennen, welche Apps auf diesem System verfügbar sind.

### 1.2 **Systeme mit begrenztem Bildschirmplatz**

Die Installation von Catenda Hub als App auf dem Startbildschirm spart Bildschirmplatz, da die Browserleiste oben nicht angezeigt wird. Besonders auf Tablets ist es angenehm, die vollständige Funktionalität von Catenda zur Verfügung zu haben und dabei den Bildschirmplatz optimal zu nutzen.

## 2. **iPhone & iPad - Empfohlener Browser**

Auf Apple-Geräten ist es oft nur über Safari möglich, eine Seite zum Startbildschirm hinzuzufügen. Navigieren Sie zu der Seite, die geöffnet werden soll, wenn Sie die Anwendung öffnen, die zum Startbildschirm Ihres Geräts hinzugefügt wird.

### 2.1 **Schaltfläche "Teilen"**

Tippen Sie auf die Schaltfläche "Teilen", die etwa so aussehen kann.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/01-share-button.png)

Die Schaltfläche "Teilen" kann rechts neben der Adressleiste oder am unteren Rand der Seite angezeigt werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/02-share-button.png)

### 2.2 **Zum Startbildschirm hinzufügen**

Scrollen Sie in der angezeigten Optionsliste nach unten, bis Sie die Aktion "Zum Startbildschirm hinzufügen" sehen, und wählen Sie diese aus. Das Dialogfeld "Zum Startbildschirm hinzufügen" wird jetzt angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/03-add-to-home-screen.png)

Geben Sie der Verknüpfung, die auf Ihrem Startbildschirm angezeigt wird, einen Namen. Der Link, der geöffnet wird, wird angezeigt, damit Sie ihn bestätigen können. Sie sehen auch das Symbol, das die Startbildschirm-Verknüpfung haben wird.

### 2.3 **Hinzufügen**

Klicken Sie auf "Hinzufügen", wenn Sie fertig sind.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/04-add.png)

Safari wird geschlossen und Sie werden zu dem Ort weitergeleitet, an dem die Verknüpfung auf dem Startbildschirm Ihres iPhone oder iPad installiert ist. Die Catenda-Verknüpfung kann auf Ihrem Startbildschirm etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/05-add.png)

> **Hinweis:** Um die Website-Verknüpfung zu entfernen, löschen Sie sie wie jede andere App auf Ihrem Telefon.

## 3. **Android - Empfohlener Browser**

Durch die Installation von Catenda als App auf Ihrem Gerät können Sie es mit dem Chrome-Browser zu Ihrem Startbildschirm hinzufügen. Navigieren Sie im Chrome-Browser zu der Seite, die geöffnet werden soll, wenn Sie auf die Seite tippen, die zum Startbildschirm Ihres Geräts hinzugefügt wird.

### 3.1 **Aktionsmenü**

Tippen Sie auf das Hamburger-Menü (Aktionsmenü mit 3 Punkten oben rechts)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/06-action-menu.png)

### 3.2 **Zum Startbildschirm hinzufügen**

Tippen Sie im Aktionsmenü auf "Zum Startbildschirm hinzufügen".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/07-add-to-home-screen.png)

### 3.3 **Verknüpfung installieren oder erstellen**

Wählen Sie "Installieren" oder "Verknüpfung erstellen"

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/08-install-or-create-shortcut.png)

**Verknüpfung erstellen** Erstellen Sie eine einfache Verknüpfung, die die Seite öffnet, zu der Sie in der Chrome-App navigiert haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/09-install-or-create-shortcut.png)

_Installieren_ (empfohlen) Installiert die Seite auf Ihrem Startbildschirm. Die Installation von Catenda bietet Ihnen die beste Erfahrung, da die Chrome-Leiste oben nicht vorhanden ist. Dies ermöglicht es Ihnen, den gesamten Bildschirm Ihres Geräts zum Durchsuchen von Catenda zu verwenden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/10-install-or-create-shortcut.png)

So kann die Browser-Verknüpfung und die installierte Seite auf Ihrem Startbildschirm aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/11-install-or-create-shortcut.png)

### 3.4 **Deinstallation**

Um die installierte Website oder Website-Verknüpfung zu entfernen, löschen Sie sie wie jede andere App auf Ihrem Telefon.

## 4. **Computer - Empfohlener Browser**

Je nach Ihren Anforderungen funktionieren Chrome, Microsoft Edge oder Safari am besten.

> **Hinweis:** Sie benötigen die erforderlichen Berechtigungen, um eine Anwendung auf Ihrem Computer installieren zu können.

### 4.1 **Chrome:**

Chrome kann verwendet werden, da es auf vielen Betriebssystemen wie Windows, macOS und Linux funktioniert

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/12-chrome.png)

### 4.2 **Microsoft Edge:**

Microsoft Edge kann verwendet werden, da viele Arbeitgeber verlangen, dass Sie Microsoft Edge verwenden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/13-microsoft-edge.png)

### 4.3 **Safari:**

Safari ist der empfohlene Browser auf dem Mac-Betriebssystem.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/14-safari.png)

Geben Sie Ihrer Anwendung einen Namen und klicken Sie auf "Hinzufügen" im angezeigten Menü.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/15-safari.png)

### 4.4 **Deinstallation**

Um die installierte Website oder Website-Verknüpfung zu entfernen, löschen Sie sie wie jede andere App auf Ihrem Computer.
