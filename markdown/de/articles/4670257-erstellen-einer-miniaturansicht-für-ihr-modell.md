# Erstellen einer Miniaturansicht für Ihr Modell

1\. Wählen Sie das gewünschte Modell aus der Modellübersicht aus.

2\. Öffnen Sie das Modell in 3D.

3\. Drücken Sie "Bild hinzufügen"

4\. Wählen Sie den Umfang des Bildes

5\. Drücken Sie Speichern.

![Snag_665ab2.png](https://raw.githubusercontent.com/catenda/help-center/main/images/ez137xtp/01-intro.png)

Sie haben nun eine Miniaturansicht des Modells in der Modellübersicht. Sie können auch jedes beliebige Bild hochladen, das Sie als Modellminiaturansicht verwenden möchten.
