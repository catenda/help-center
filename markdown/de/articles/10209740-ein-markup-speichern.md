# Ein Markup speichern

Wählen Sie ein [Annotationswerkzeug](https://support.catenda.com/en/articles/11384618-document-preview-tools) aus der Symbolleiste über der [Dokumentvorschau](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations). Platzieren Sie die Anmerkung, um das Menü der nicht gespeicherten Markups in der [Registerkarte Markups](https://support.catenda.com/en/articles/10205725-right-menu-of-a-revision-markups) des rechten Menüs einer Revision anzuzeigen.

Wenn ein Dokument zum ersten Mal geöffnet wird, ist das rechte Menü der Revision möglicherweise geschlossen. Klicken Sie auf die Informationsschaltfläche auf der rechten Seite des [Dokumentbanners](https://support.catenda.com/en/articles/8461918-document-banner-actions-navigation), um dieses Menü zu erweitern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/01-intro.png)

## 1. **Themennavigation für Markups**

Das Menü der nicht gespeicherten Markups kann je nachdem, ob in der Themennavigations-Dropdown-Liste oben in der Registerkarte Markups zu einem Thema navigiert wurde oder nicht, an verschiedenen Stellen angezeigt werden.

### 1.1 **Neue Themen**

Wenn in der Markups-Navigation oben in der Registerkarte kein Thema ausgewählt wurde, wird in der Dropdown-Liste "neue Themen" angezeigt. In diesem Fall sind nicht gespeicherte Markups immer oben in der Registerkarte Markups sichtbar.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/02-new-topics.png)

### 1.2 **Ausgewählte Themen**

Klicken Sie auf die Themennavigations-Dropdown-Liste oben in der Registerkarte Markups, um ein Thema auszuwählen.

**Neueste Kommentare zuerst** Themenkommentare, die nach dem neuesten zuerst sortiert sind, zeigen das Menü der neuen Markups oben im Kommentarbereich an.

**Älteste Kommentare zuerst** Themenkommentare, die nach dem ältesten zuerst sortiert sind, zeigen das Menü der neuen Markups unten im Kommentarbereich an. In diesem Fall müssen Sie möglicherweise zum unteren Ende des Kommentarbereichs scrollen, um das Menü der neuen Markups anzuzeigen.

## 2. **Menü der nicht gespeicherten Markups**

So kann das Menü der nicht gespeicherten Markups aussehen, nachdem Anmerkungen zu einem Dokument hinzugefügt wurden:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/03-unsaved-markups-menu.png)

## 3. **Neues Markup**

Klicken Sie auf die neue Markup-Schaltfläche, um an einem neuen Markup zu arbeiten. Dies ist, wie das Menü der nicht gespeicherten Markups aussehen kann, wenn mehrere Markups erstellt wurden:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/04-new-markup.png)

Klicken Sie auf ein Markup, um es vor dem Speichern zu erweitern und zu bearbeiten.

## 4. **Markups speichern**

Markups werden als Kommentare in Themen gespeichert. Wenn ein Markup mehrere Sätze von Anmerkungen enthält, die über mehrere Seiten verteilt sind, gibt es einen Kommentar pro Satz von Anmerkungen auf jeder Seite.

### 4.1 **Ausgewähltes Thema**

Navigieren Sie zu einem Thema mithilfe der Themennavigations-Dropdown-Liste oben in der Registerkarte Markups und wählen Sie ein Thema aus. Klicken Sie auf Markups speichern, um alle Markups im ausgewählten Thema zu speichern..

> **Hinweis:** Jeder Annotationssatz wird in demselben Thema gespeichert und dadurch in ein großes Markup kombiniert. Auf diese Weise kann für jeden in dem Thema erstellten Kommentar ein separater Markup-Name hinzugefügt werden.

### 4.2 **Neue Themen**

Wenn in der Themennavigations-Dropdown-Liste oben in der Registerkarte Markups keine Themen ausgewählt sind, wird „neue Themen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/05-new-topics.png)

Klicken Sie auf Als Themen speichern, um für jedes erstellte Markup ein Thema zu erstellen.

**Titel** Im Titel wird `{documentName} - {markupName}` standardmäßig vorgeschlagen. Damit werden Themen nach dem Namen des Markups und des Dokuments benannt, auf dem es erstellt wird.

**Thema-Header** Die Felder, die im Thema-Header ausgefüllt sind, werden auf jedes erstellte Markup-Thema angewendet.

**Beschreibung** Geben Sie eine Beschreibung ein, die jedem erstellten Markup-Thema hinzugefügt wird.

**Kommentare** Ein Kommentar für jeden Satz von Anmerkungen, die zum Markup gehören, wird zu jedem erstellten Markup-Thema hinzugefügt.

## 5. **Markup-Name**

Generieren Sie einen Kommentar für jeden Satz von Anmerkungen, wenn ein Markup gespeichert wird. Der Text, der in das Feld Markup-Name geschrieben wird, wird als Text zu jedem generierten Kommentar hinzugefügt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/06-markup-name.png)

### 5.1 **Markup verwerfen**

Klicken Sie auf das Papierkorbsymbol rechts neben dem Markup-Namen, um es zu löschen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/07-discard-markup.png)

## 6. **Annotationssätze**

Jede Seite in einem Dokument, auf dem Anmerkungen gemacht werden, hat ihren eigenen Satz von Anmerkungen. So kann es aussehen, wenn Anmerkungen auf mehreren Seiten in einem Dokument gemacht werden:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/08-annotation-sets.png)

### 6.1 **Markup-Seite**

Die Seitennummer zeigt an, auf welcher Seite das Markup erstellt wurde.

### 6.2 **Menü Anmerkungen**

Sehen Sie sich die Anzahl der Anmerkungen an, die für jede Seite erstellt werden. Klicken Sie auf "Anmerkungen", um das Menü Anmerkungen zu erweitern und die Seitenanmerkungen in einer Liste anzuzeigen. Bearbeiten oder löschen Sie die Anmerkung, indem Sie auf die drei Punkte rechts neben der Anmerkung klicken. Bearbeiten Sie die Anmerkungen, um neben dieser Anmerkung einen kurzen Text hinzuzufügen. Dieser Text kann später durch Hovern über der Anmerkung gefunden werden.

### 6.3 **Einen Satz von Anmerkungen verwerfen**

Klicken Sie auf Verwerfen, um alle auf dieser Seite erstellten Anmerkungen zu verwerfen.

### 6.4 **Schnappschuss**

Für jeden Satz von Anmerkungen wird ein Bild des Bereichs auf der Seite der Revision erstellt, auf dem die Anmerkungen gemacht werden. Das Bild wird aktualisiert, wenn sich die Anmerkungen auf der Seite ändern. Wenn neue Anmerkungen erstellt werden, wird ein größeres Bild erstellt, um alle Anmerkungen einzubeziehen, während das Bild möglicherweise verkleinert wird, wenn eine Anmerkung entfernt wird. Um einen Teil einer Seite hervorzuheben, wird empfohlen, eine Rechteckanmerkung mit einer Deckkraft von 0 zu verwenden, um sicherzustellen, dass das Bild den gesamten Bereich im Rechteck erfasst.
