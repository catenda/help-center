# BCF-Workflow mit Naviate für Revit

**BCF von Revit mit Naviate zu Bimsync.**

Erstellen Sie ein Problem in Revit mit dem Naviate BCF-Manager.

Wählen Sie die Elemente aus, zu denen Sie ein Problem erstellen möchten, und gehen Sie zum Naviate BCF-Manager. Stellen Sie sicher, dass Sie entweder Version 1.0 oder 2.0 auswählen. Klicken Sie auf OK.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/01-intro.png)

Klicken Sie auf BCF-Datei speichern und speichern Sie sie als bcfzip-Datei.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/02-intro.png)

Gehen Sie zu Probleme in Bimsync und importieren Sie die BCF, die Sie in Revit erstellt haben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/03-intro.png)

Die ausgewählte BCF.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/04-intro.png)

Die BCF wird jetzt unter Probleme in Bimsync geladen.

Sie können dann die verschiedenen Einstellungen im Problem ändern, indem Sie darauf klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/05-intro.png)

**BCF von Bimsync zu Revit mit Naviate.**

Filtern Sie das Problem heraus, das Sie erhalten möchten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/06-intro.png)

Exportieren Sie die gefilterten Probleme.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/07-intro.png)

Sie erhalten eine Benachrichtigung, wenn die BCF exportiert wird. Laden Sie die BCF herunter.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/08-intro.png)

Gehen Sie zurück zu Revit, um die heruntergeladene BCF zu erhalten.

Öffnen Sie es im BCF-Manager.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/09-intro.png)

Die BCF wird in Revit mit den zugehörigen Komponenten geladen. Revit erstellt eine individuelle Ansicht für die BCF.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/10-intro.png)

Sie können die zugehörigen Komponenten auch schneiden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/11-intro.png)
