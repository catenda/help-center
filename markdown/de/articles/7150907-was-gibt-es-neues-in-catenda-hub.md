# Was gibt es Neues in Catenda Hub?

> Entdecken Sie das neue Aussehen und Verhalten Ihrer Liebplattform

Wie Sie sehen, haben wir ein neues Produkt :) Neben dem Aussehen und Verhalten sowie dem Namen finden Sie hier die Highlights und Upgrades, die Sie in Catenda Hub finden werden.

## 1. **Linkes Navigationsmenü**

Wir haben das Layout der Funktionen geändert, um den Zugriff auf Ihr Tool zu vereinfachen. Die Abschnitte von Catenda Hub sind gut definiert und leichter zu verstehen.

![Catenda Hub](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/01-left-navigation-menu.png)

Jeder Abschnitt verfügt über einen ausklappbaren Unterabschnitt, der Benutzern Zugriff auf sekundäre Funktionen bietet.

## 2. **Unterstützung für IFC 4.3**

Catenda Hub kann nun IFC 4.3-Dateien importieren und anzeigen, und Benutzer können bereits von neuen Funktionen im Zusammenhang mit diesem Format profitieren. Weitere Informationen finden Sie in unserem Artikel: [LINK](https://intercom.help/bimsync-arena/en/articles/4670320-previewing-file-types-on-catenda-hub#h_2edd1d4e9c)

## 3. **Organisationen: Benutzer- und Projektmanagement - Portfolio-Toolset**

Im Abschnitt [Organisationen](http://bimsync.com/orgs) von Catenda Hub finden Sie einen neuen Satz von Tools zur Organisation von Projektmitgliedern, Rollen und Projektmitgliedschaften. Benutzer können aus Projekten hinzugefügt oder entfernt werden, Projekte können zwischen Organisationen verschoben werden usw...

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/02-organizations-users-and-projects-management-portfolio-toolset.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/03-organizations-users-and-projects-management-portfolio-toolset.png)

## 4. **Neue Themen-Tabellenansicht**

Wir haben die [Tabellenansicht](https://support.catenda.com/en/articles/6941099-table-view-in-an-issue-board) für Probleme aktualisiert. Benutzer können mehr Komponenten nach ihren Anforderungen anpassen und auch von einer Problemvorschau beim Auswählen in der Liste profitieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/04-new-topics-table-view.png)

## 5. **Teilweise Namensübereinstimmung in Dokumenten**

Wenn Sie ein neues Dokument in Catenda Hub hochladen, schlägt unser System automatisch ähnliche Dokumente vor und zeigt den Vorschlag im Popup-Fenster an.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/05-partial-name-matching-in-documents.png)

Die Matching-Engine vergibt eine Bewertung für die Zuordnung und schlägt das höchste Ergebnis vor.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jah4q53q/06-partial-name-matching-in-documents.png)

## 6. **Namenskonvention**

Sie werden eine neue Funktion entdecken, die im Abschnitt Dokumente sichtbar ist und [Namenskonvention](https://support.catenda.com/en/articles/7832559-naming-convention) genannt wird. Dies ist ein Work In Progress und wird als neue Funktion im Q4 2023 bereitgestellt. Bitte kontaktieren Sie uns, um eine Demo und eventuell eine Testversion zu erhalten. Verwenden Sie dazu die Chat-Schaltfläche in Catenda Hub.
