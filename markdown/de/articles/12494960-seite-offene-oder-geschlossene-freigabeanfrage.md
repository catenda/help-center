# Seite „Offene oder geschlossene Freigabeanfrage

Wenn Shared Revisions in einem Projekt aktiviert sind, wird die [Seite „Freigaben

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/01-intro.png)

_Erforderliche Zugriffsberechtigung:_ Einer der folgenden, unabhängig vom Administratorstatus:

- Mitglied des Absendeteams, das aus der Liste der möglichen Absendeteams für den ausgewählten Workflow ausgewählt wurde, im Namen des Mitglieds, das die Freigabeanfrage eingereicht hat.
- Mitglied eines Reviewer-Teams, das zum Überprüfen eines der Schritte für den ausgewählten Workflow in der Freigabeanfrage konfiguriert ist.
- Mitglied des Publisher-Teams, das zum Einreichen der endgültigen Freigabe für den ausgewählten Workflow in der Freigabeanfrage konfiguriert ist.

Freigabeanfragen können auf der Seite „Freigaben

## 1. **Neue Elementaktionen**

So können die Aktionen auf der Genehmigungsseite aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/02-new-item-actions.png)

Verwenden Sie die Aktion für neue Genehmigungsanfrage, um eine neue Genehmigungsanfrage zu erstellen. Klicken Sie [hier](https://support.catenda.com/en/articles/12495005-creating-a-new-approval-request), um mehr über die Erstellung einer neuen Genehmigungsanfrage zu erfahren.

## 2. **Genehmigungskopfzeile**

So kann die Genehmigungskopfzeile in einer offenen Genehmigung aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/03-approval-header.png)

Nachdem der Genehmigungsersteller die Genehmigung im Dialogfeld "Genehmigungsanfrage erstellen" eingereicht hat oder nachdem eine Entwurfsgenehmigungsanfrage eingereicht wurde, ist es nicht mehr möglich, die Genehmigungskopfzeile zu bearbeiten.

### 2.1 **Titel**

Der Titel der offenen oder geschlossenen Genehmigungsanfrage.

### 2.2 Workflow

Der Workflow, der bei der Erstellung dieser Genehmigung ausgewählt wird _Erforderlicher Zugriff:_ Genehmigungsübermittler

### 2.3 **Beschreibung**

Die Beschreibung der Genehmigung.

## 3. **Schrittband**

Im Schrittband wird eine Vorschau aller Schritte in einer Genehmigung angezeigt. So kann das Schrittband in einer offenen Genehmigungsanfrage aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/04-step-ribbon.png)

So kann das Schrittband in einer geschlossenen Genehmigungsanfrage aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/05-step-ribbon.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/12495212-step-ribbon-in-an-approval-request), um mehr über das Schrittband zu erfahren.

## 4. **Registerkarte "Überblick"**

Auf der Registerkarte "Überblick" finden Sie eine Schrittvorschau für jeden Schritt im Schrittband der Genehmigungsanfrage oben. So kann die Registerkarte "Überblick" aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/06-overview-tab.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/12495126-overview-tab-in-an-approval-request), um mehr über die Registerkarte "Überblick" in einer Genehmigung zu erfahren.

## 5. **Registerkarte "Dokumente"**

Auf der Registerkarte "Dokumente" einer Genehmigung wird eine Übersicht aller Dokumente angezeigt, die Teil der Genehmigung sind. So kann die Registerkarte "Dokumente" im Genehmigungsinhalt aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/07-documents-tab.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/12495130-documents-tab-in-an-approval-request), um mehr über die Registerkarte "Dokumente" in einer Genehmigung zu erfahren
