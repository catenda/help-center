# Ein neues Lesezeichen erstellen

Neue Lesezeichen können erstellt werden, indem Sie auf Neues Lesezeichen in den [oberen Schaltflächen](https://support.catenda.com/en/articles/4670281-bookmarks-page#h_e85b08bb62) auf der [Seite Lesezeichen](https://support.catenda.com/en/articles/4670281-bookmarks-page) oder auf der Seite eines bestimmten Lesezeichens klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/01-intro.png)

## 1. Neues Lesezeichen

Öffnen Sie den 3D-Viewer aus dem Navigationsmenü. Drücken Sie die Schaltfläche [neues Lesezeichen](https://support.catenda.com/en/articles/4670281-bookmarks-page#h_e85b08bb62) oben rechts auf der [Seite Lesezeichen](https://support.catenda.com/en/articles/4670281-bookmarks-page). Bewegen Sie sich im Modell umher, bis Sie die Bildschirmansicht haben, von der Sie ein Lesezeichen erstellen möchten, und klicken Sie auf "Schnappschuss erstellen", wenn Sie bereit sind.

> **Hinweis:** Es ist zwar nicht möglich, ein Lesezeichen mit einer Abfrage zu erstellen, aber es ist möglich, einen Schnappschuss in einem Thema mit einer Abfrage zu erstellen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/02-new-bookmark.png)

## 2. Eine Beschreibung hinzufügen (optional)

Wenn Sie möchten, können Sie eine Beschreibung des Lesezeichens hinzufügen, die optional ist. Dann wählen Sie, ob das Lesezeichen privat sein soll oder für alle Mitglieder des Projekts sichtbar sein soll. Klicken Sie dann auf die Schaltfläche "Erstellen", und das Lesezeichen wird erstellt.

## 3. Teilen

Sie können wählen, ob Sie Ihr "**privates Lesezeichen / mit dem Projekt teilen**" teilen möchten oder nicht

## 4. Modelle und Revisionen

Sie haben zwei Optionen: Entweder "**immer der neuesten Revision**" Ihrer ausgewählten Modelle folgen oder das Lesezeichen dauerhaft auf diese aktuellen Revisionen "**An ursprüngliche Revisionen sperren**" festlegen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/03-models-and-revisions.png)

> **Hinweis:** Um zu finalisieren, denken Sie daran, auf die Schaltfläche "Erstellen" zu klicken.
