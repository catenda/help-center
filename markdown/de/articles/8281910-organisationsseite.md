# Organisationsseite

Die Organisationsseite finden Sie als letzte Seite im linken Navigationsmenü auf der Hauptseite oder unter [https://hub.catenda.com/orgs](https://hub.catenda.com/orgs)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/v5hzcvsx/01-intro.png)

Bei Test- oder Testprojekten können einige Catenda-Projekte von einem einzelnen Mitglied besessen werden, aber oft werden Projekte von einer Organisation besessen. Sehen Sie, welche Organisation Ihr Projekt besitzt, indem Sie die [Eigentümer-Dropdown](https://support.catenda.com/en/articles/8400797-projects-page#h_5e76dedd21) auf der [Projektseite](https://support.catenda.com/en/articles/8400797-projects-page) für verschiedene Organisationen filtern. Ein Catenda-Kunde kann eine oder mehrere Organisationen haben, in denen seine Projekte organisiert sind.

## 1. **Organisationsliste**

In der Organisationsliste können Organisationsbesitzer die verschiedenen ihnen zur Verfügung stehenden Organisationen sehen. So könnte die Organisationsliste aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/v5hzcvsx/02-organizations-list.png)

Die Organisationsliste ist standardmäßig in absteigender Reihenfolge sortiert, kann aber durch Klicken auf Name oben in der Liste in aufsteigender Reihenfolge sortiert werden. Während Organisationen neben Eigentümern auch Mitglieder haben können, sehen nur die Eigentümer die Organisation in dieser Liste. Wenn die Organisation ihre Grenze nicht erreicht hat, können Organisationseigentümer Projekte in der Organisation auf der neuen Projektseite erstellen.

Die folgenden Seiten werden nach dem Klicken auf eine Organisation verfügbar:

### 1.1 **Profilseite**

Klicken Sie auf eine beliebige Organisation in der Liste, um zur Profilseite der Organisation zu gelangen. Auf der Profilseite können Sie ein Profilbild für die Organisation hochladen. Klicken Sie [hier](https://support.catenda.com/en/articles/8497478-organization-profile-page), um mehr über die Profilseite einer Organisation zu erfahren

### 1.2 **Benutzerseite**

Auf der Benutzerseite haben Organisationsbesitzer einen Überblick darüber, wer Besitzer einer Organisation ist. Sie können auch die Verwaltung von Organisationsmitgliedern mit einer registrierten E-Mail-Domain in und aus Projekten verwalten, ohne sie einladen zu müssen. Klicken Sie [hier](https://support.catenda.com/en/articles/8508311-users-page-organization-tool), um mehr über die Benutzerseite einer Organisation zu erfahren

### 1.3 **Projektseite**

Auf der Projektseite können Organisationseigentümer die verschiedenen Projekte sehen, die Teil dieser Organisation sind. Jede Organisation kann eine begrenzte Anzahl von Projekten haben. Sehen Sie die aktuelle Menge und die Grenze auf der neuen Projektseite. Organisationseigentümer, die Teil mehrerer Organisationen sind, können Projekte auf dieser Seite von einer Organisation zu einer anderen verschieben. Dies wird häufig durchgeführt, um einen Platz für die Erstellung eines neuen Projekts freizugeben. Projekte können auch gelöscht werden, um einen Platz freizugeben. Klicken Sie [hier](https://support.catenda.com/en/articles/8505058-projects-page-organization-tool), um mehr über die Projektseite einer Organisation zu erfahren

### 1.4 **Seite "Projektmitgliedschaften"**

Auf der Projektmitgliedschaftsseite haben Organisationseigentümer einen Überblick über jeden Catenda-Kontoeintrag in jedem Projekt, das Teil der Organisation ist. Suchen Sie nach Mitgliedschaften per E-Mail, um beispielsweise alle Kontoeinträge von "contractor.com" auszuwählen und Mitglieder mit dieser E-Mail-Domäne aus allen Projekten der Organisation zu entfernen. Klicken Sie [hier](https://support.catenda.com/en/articles/9003642-project-memberships-organization-tool), um mehr über die Projektmitgliedschaftsseite einer Organisation zu erfahren
