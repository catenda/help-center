# Über Catenda Data Export

> Catenda Data Export kopiert die Daten von Catenda Hub-Projekten automatisch in den Cloud-Speicher einer Organisation.

Catenda Hub bietet mehrere Möglichkeiten zum Herunterladen von Projektdaten, die in [Alle Projektdaten exportieren](https://support.catenda.com/de/articles/7946690-exportieren-aller-projektdaten) beschrieben sind. Catenda Data Export ist die automatisierte Lösung: Sie kopiert Projektdaten direkt in den Cloud-Speicher einer Organisation in Amazon S3 oder Azure Blob Storage. Sie wird separat von Catenda Hub verkauft.

## 1. **Was es ist**

Catenda Data Export bewahrt eine Kopie der Dokumente, Modelle und Themen eines Projekts in dem Speicher auf, den die Organisation kontrolliert. Es wird nach einem Zeitplan oder einmalig ausgeführt, ohne dass jemand Dateien manuell herunterlädt.

## 2. **Projektbesitzer und Teilnehmer**

Catenda Data Export ist nicht nur für Organisationen gedacht, die Projekte in Catenda Hub besitzen. Was exportiert wird, hängt von der Rolle der Organisation in jedem Projekt ab.

### 2.1 **Projektbesitzer**

Eine Organisation, die ein Projekt besitzt, kann ein vollständiges Backup aller Daten dieses Projekts exportieren.

### 2.2 **Projektbeteiligte**

Eine Organisation, die an Projekten anderer Organisationen beteiligt ist, kann Catenda Data Export ebenfalls nutzen, ohne ein Projekt selbst zu besitzen. In diesen Projekten exportiert sie nur, worauf der Teilnehmer Zugriff hat, was ein begrenzter Teil des Projekts sein kann. So behält der Teilnehmer eine eigene Kopie seiner Arbeit, auch wenn sein Zugriff auf ein Projekt endet.
