# 3D-Messaktualisierung!

> Verbesserungen der Messwerkzeuge in Catenda Hub

Es wurden mehrere Verbesserungen an den Messwerkzeugen in Catenda Hub vorgenommen.

## 1. **Messwerte**

Wir haben kürzlich Unterstützung für imperiale Messungen zusätzlich zu den vorhandenen metrischen Einheiten hinzugefügt. Der Standard kann in den Projekteinstellungen definiert werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8kcjrrhv/01-measurement-units.png)

## 2. **An Objekte andocken**

Mit dem Messbandwerkzeug und dem Laser-Messwerkzeug können Sie jetzt an Objekte andocken.

- Kurven und Linien, die durch eine Schnittebene erstellt wurden, können angedockt werden.
- Mittelpunkte von kreisförmigen Objekten wie Rohren können ebenfalls angedockt werden.
- Punkte in Punktwolken können angedockt werden.

Beachten Sie das "Fadenkreuz" im Messzeiger.

- Ein rotes Fadenkreuz zeigt das Andocken an einer Linie oder Kurve an.
- Ein grünes Fadenkreuz zeigt das Andocken an einer Ecke an.
- Ein blaues Fadenkreuz zeigt an, dass es noch auf das Andocken an etwas wartet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8kcjrrhv/02-snap-to-objects.png)

## 3. **Punktmessung**

Ein neues Werkzeug in der Messwerkzeugkasten ist die Punktmessung. Mit diesem Werkzeug können Sie die x-, y- und z-Position des Teils, auf das Sie in 3D zeigen, abrufen. Es wird sowohl für IFC als auch für Punktwolken unterstützt. Dieses Werkzeug unterstützt auch das Andocken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8kcjrrhv/03-point-measure.png)

## 4. **Messwerkzeugkasten**

Auf alle diese Werkzeuge können Sie zugreifen, indem Sie auf das Pfeilsymbol in der oberen rechten Ecke des Viewers klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8kcjrrhv/04-measurement-toolbox.png)
