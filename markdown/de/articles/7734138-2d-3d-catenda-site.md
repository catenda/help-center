# 2D / 3D - Catenda Site

Die Seite 2D / 3D finden Sie im [Menü](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site) oder durch Tippen auf die Schaltfläche "Probleme" in der unteren Navigationsleiste.

![2D / 3D](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/01-intro.png)

So kann die Seite 2D / 3D aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/02-intro.png)

Oben auf der Seite 2D / 3D sehen Sie den issue board Selector.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/03-intro.png)

Die Probleme, die sich aus dem Filter auf der gewählten issue board ergeben, sind die Probleme, deren Marker in der 2D-Ansicht angezeigt werden.

### Obere Hälfte

In der oberen Hälfte der Seite 2D / 3D sehen Sie den [3D-Viewer](https://support.catenda.com/en/articles/7744403-3d-viewer-catenda-site).

### Untere Hälfte

In der unteren Hälfte der Seite 2D / 3D sehen Sie den [2D-Viewer](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site).

### Trennleiste

Zwischen den beiden Viewern sehen Sie einen Schieberegler zum Trennen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/04-dividing-bar.png)

Ziehen Sie an diesem Schieberegler, um zu konfigurieren, wie groß ein Teil des Bildschirms sein soll, den jeder der Viewer einnehmen soll
