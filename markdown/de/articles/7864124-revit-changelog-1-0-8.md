# Revit Changelog - 1.0.8

Neue Funktionen in 1.0.8

- Revit 2024 Verfügbarkeit
- Teams-Filter
- Benutzerdefinierte Exporteinstellungen sind erneut im Plugin verfügbar
- Seitenpanel für Probleme
  - Innerhalb eines Problems ist es jetzt möglich, das Seitenpanel durch Klicken auf verwandte Elemente zu öffnen.
  - Dokumente anzeigen, die mit dem Problem verknüpft sind
  - Objekte auswählen, die mit dem Problem verknüpft sind
  - Anzeigen, welche Probleme mit diesem Problem verknüpft sind
