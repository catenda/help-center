# Aktionen des Geschosskonfi gurators

Die Aktion zum Erstellen eines neuen Gebäudes befindet sich oben rechts auf der [Geschosskonfiguratorseite](https://support.catenda.com/en/articles/6921756-storey-configurator-page). Dies ist der Ort, an dem sich die Aktionen auf der Geschosskonfiguratorseite befinden:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/01-intro.png)

## 1. **Neue Elementaktionen**

Wenn noch keine Gebäude konfiguriert wurden, kann die Schaltfläche "Neues Element hinzufügen" in der Mitte der Seite angeklickt werden. Klicken Sie auf die grüne Plus-Schaltfläche oben rechts oder öffnen Sie das Aktionsmenü, um die Aktion "Neues Gebäude hinzufügen" zu verwenden. Um ein Gebäude hinzuzufügen, können Sie jederzeit auf die grüne Plus-Schaltfläche klicken oder auf die Aktion im Aktionsmenü klicken.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/02-new-item-actions.png)

## 2. **Neues Gebäude hinzufügen**

Nach Verwendung der Aktion "Neues Gebäude hinzufügen" wird das Dialogfeld "Neues Gebäude erstellen" geöffnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/03-add-new-building.png)

Im Dialogfeld "Neues Gebäude erstellen" wird ein Initialmodell ausgewählt.

> **Hinweis:** Um ein Modell auswählen zu können, muss mindestens ein Modell im Projekt konfiguriert sein.

Klicken Sie [hier](https://support.catenda.com/en/articles/9431936-models-page-actions#h_4100594482), um mehr über die Erstellung von Modellen zu erfahren. Wenn ein Modell importiert wird, wird eine 2D-Ansicht erzeugt, indem die Objekte des Modells 1,4 Meter über der Höhe jedes Geschosses durchschnitten werden.

### 2.1 **Modelle ohne 2D-Geometrie**

Wenn keine Objekte durchschnitten wurden, ist es nicht möglich, das Modell auszuwählen. Sie können erkennen, dass dies der Fall ist, wenn die [2D-Schaltfläche](https://support.catenda.com/en/articles/4670279-revision-selector#h_180a64490d) beim Öffnen der 2D-Ansicht des Modells nicht aktiviert wird.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/04-models-with-no-2d-geometry.png)

### 2.2 **Beispieldatei**

Klicken Sie [hier](https://hub.catenda.com/share/collections/zBkFZ5yzhIUvw5a028kNt8A8oZNXVQhdtV9QhO8FuFuS), um ein Beispielmodell mit einem Geschoss und einem einzelnen Objekt herunterzuladen, das als Beispiel verwendet werden kann.

## 3. **Gebäudeerstellung**

Wenn ein Modell mit 2D-Geometrie ausgewählt wird, wird ein Entwurf einer Gebäudekonfiguration erstellt. In dieser Phase sind die an der Geschosskonfiguration vorgenommenen Änderungen noch nicht für Projektmitglieder verfügbar. Dies ist das Aussehen der Geschosskonfiguratorseite nach Auswahl eines Modells.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/05-building-creation.png)

Im erstellten Gebäude wird für jedes IfcStorey im Modell ein Geschoss mit seiner jeweiligen Höhe erstellt. Mit dieser Grundlage können weitere 2D-Ansichten hinzugefügt, eine PDF-Zeichnung unterlegt und die Höhe für jedes Geschoss geändert werden.

### 3.1 **Geschossvorschau**

Das aktuelle Geschoss wird grün hervorgehoben. Die Konfiguration des Geschosses wird auf der rechten Seite angezeigt. Wenn mehrere Fenster und das Inhaltsfeld mit der Geschosskonfiguratorseite weniger Platz haben, wird möglicherweise die rechte Geschossvorschau auf der rechten Seite nicht angezeigt. Klicken Sie auf ein anderes Geschoss, um die Konfiguration für dieses Geschoss in der Vorschau anzuzeigen.

### 3.2 **Konfiguration speichern**

Um das Gebäude zu speichern, klicken Sie am unteren Rand der Seite auf "Konfiguration speichern".
