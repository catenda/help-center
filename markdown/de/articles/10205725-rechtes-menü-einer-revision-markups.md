# Rechtes Menü einer Revision - Markups

Wenn Sie ein Dokument auf der [Dokumentseite](https://support.catenda.com/en/articles/8204673-documents-page) oder in einer Bibliothek auswählen, wird ein neues Fenster für dieses Dokument angezeigt. Beim Öffnen eines Dokuments sehen Sie immer die neueste Revision. Die Dokumentseite kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/01-intro.png)

1. Das [Dokumentbanner](https://support.catenda.com/en/articles/8461918-document-banner-actions-navigation) erstreckt sich über den oberen Bereich der Dokumentseite
1. Sie finden die Dokumentkopfzeile unterhalb des Dokumentbanners und oberhalb der Dokumentvorschau.
1. Unterhalb der Dokumentkopfzeile finden Sie die [Dokumentvorschau](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations).
1. Links neben der Dokumentkopfzeile und der Vorschau finden Sie die Dokumentenliste
1. _Dieser Artikel:_ Rechts neben der Dokumentkopfzeile und der Vorschau finden Sie das rechte Informationsmenü.

Wenn Sie ein Dokument erstmals öffnen, ist sein rechtes Menü möglicherweise geschlossen. Sie können auf die Informationsschaltfläche unten rechts im [Dokumentbanner](https://support.catenda.com/en/articles/8461918-document-banner-actions-navigation) klicken, um dieses Menü zu erweitern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/02-intro.png)

## 1. **Registerkarten "Dateiinfo" und "Markups"**

Oben im Menü sehen Sie die Registerkarten "Dateiinfo" und "Markups". Standardmäßig ist die Registerkarte "Dateiinfo" aktiv, wenn Sie das rechte Menü öffnen. Wenn Sie eine Anmerkung in der Dokumentvorschau erstellen, wechselt dieses Menü automatisch zur Markup-Registerkarte. Dieser Artikel beschreibt die Markup-Registerkarte. Wenn Sie Informationen zur Registerkarte "Dateiinfo" suchen, klicken Sie [hier](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision).

## 2. **Was ist ein Markup**

Ein Markup ist ein Satz von Anmerkungen, die in einer Revision erstellt wurden. Markups können als Kommentare in einem Thema gespeichert werden.

**Ein Satz von Anmerkungen pro Seite** Anmerkungen in Markups können über mehrere Seiten verteilt sein. Für jede Seite werden die Anmerkungen zusammengefasst und können als Kommentar in einem Thema gespeichert werden. Themen können Kommentare mit Anmerkungssätzen aus allen Arten von Revisionen enthalten. Alle Kommentare für die gleiche Revision im Thema bilden das Markup.

**Ein Schnappschuss-Satz von Anmerkungen** Jeder Satz von Anmerkungen hat einen damit verbundenen Schnappschuss. Dieser Schnappschuss enthält ein Bild des Teils der Seite, auf dem sich Anmerkungen befinden.

**Ein Textkommentar pro Anmerkungssatz** Wie bei normalen Kommentaren in Themen kann ein Markup einen Textkommentar haben.

> **Hinweis:** Mehrere Anmerkungen wie die Text- und die Notizanmerkung, die Informationen enthalten können, können Teil des Markups sein. Es kann nur einen Themenkommentar geben, der mit dem Markup verbunden ist.

### 2.1 **Markup-Registerkarte**

Wenn Markups in Ihrer aktuellen Revision zu Themen hinzugefügt wurden, wird eine Reihe von Themen mit Markups in dieser Revision auf der Markup-Registerkarte angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/03-markup-tab.png)

Um ein Markup hinzuzufügen, wählen Sie ein Werkzeug aus der [Symbolleiste](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations#h_6e3ac983b6) über der Dokumentvorschau aus und erstellen Sie eine Anmerkung.

### 2.2 **Themenselektor-Dropdown**

Oben auf der Markup-Registerkarte sehen Sie das Themen-Dropdown. Das Themen-Dropdown kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/04-topic-selection-dropdown.png)

Standardmäßig wird [Neue Themen](#h_e79077cdfd) ausgewählt.

_Ein Thema auswählen_ Darunter sehen Sie alle offenen oder geschlossenen Themen, die mit Ihrem aktuellen Dokument verknüpft sind. In diesen Themen finden Sie das Dokument in den zugehörigen Dokumenten im rechten Menü des Themas. Wenn Markups, die in der aktuellen Revision erstellt wurden, zu einem Thema hinzugefügt wurden, sehen Sie ein Symbol mit der Nummer rechts neben dem Thementitel. Diese Nummer zeigt die Anzahl der Anmerkungen an, die Teil von Markups sind, die in der aktuellen Revision erstellt wurden. Klicken Sie auf eines der Themen, um [das Thema auszuwählen](#h_233bbefe34).

**Ein anderes Thema auswählen** Wenn Sie ein Thema auswählen möchten, in dem das aktuelle Dokument noch nicht verknüpft wurde, können Sie dies tun, indem Sie auf "Ein anderes Thema auswählen" klicken, das sich am Ende der Liste befindet. Nach dem Klicken auf "Ein anderes Thema auswählen" im Themenselektor-Dropdown können Sie zu Ihrem gewünschten Thema navigieren, indem Sie das Themen-Board oben links auswählen und die Filter oben rechts verwenden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/05-topic-selection-dropdown.png)

Wenn Sie das Thema gefunden haben, zu dem Sie Markups hinzufügen möchten, können Sie auf "Auswählen und verknüpfen" klicken. Dies macht dieses Thema zu Ihrem [derzeit ausgewählten Thema](#h_233bbefe34). Dies verknüpft auch Ihr aktuelles Dokument mit dem Thema. Der Link kann später im rechten Informationsmenü des Themas auf der Themenseite entfernt werden.

> **Hinweis:** Wenn Sie ein Markup zu einem neuen Thema hinzufügen möchten, können Sie dies tun, indem Sie eine Anmerkung in der Dokumentvorschau hinzufügen und auf "Markup speichern" klicken.

## 3. **Neue Themen**

Wenn Markups in Ihrer aktuellen Revision zu einem Thema hinzugefügt wurden, werden sie in der Reihenfolge ihrer Erstellung unter Themen mit Markups angezeigt. Dies kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/06-new-topics.png)

### 3.1 **Nicht gespeicherte Markups**

Weitere Informationen zum Speichern neuer Markups ohne Auswahl eines Themas finden Sie [hier](https://support.catenda.com/en/articles/10209740-saving-a-markup#h_8542b82cf8).

### 3.2 **Themendarstellungsoptionen**

Oben haben Sie zwei Optionen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/07-topic-display-options.png)

### 3.3 **Alle anzeigen**

Aktivieren Sie das Kontrollkästchen "Alle anzeigen", um alle Markups aller Themen anzuzeigen, die in dieser Revision erstellt wurden.

### 3.4 **Anmerkungen aus anderen Revisionen einbeziehen**

Aktivieren Sie das Kontrollkästchen "Anmerkungen aus anderen Revisionen einbeziehen", um Anmerkungen aus allen Revisionen anzuzeigen.

> **Hinweis:** Wenn Sie ein Markup aus einer anderen Revision anzeigen, stimmen die Anmerkungen möglicherweise nicht mit Ihrer aktuellen Revision überein, da das Markup in einer anderen Revision erstellt wurde

**Markups aus anderen Revisionen im gleichen Thema** Wenn es Markups aus mehreren Revisionen im gleichen Thema gibt, sehen Sie einen Eintrag für jede Revision. Die aktuelle Revision wird oben angezeigt, mit den Markups jeder Revision darunter, nach rechts eingerückt. Dies kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/08-include-annotations-from-other-revisions.png)

### 3.5 **Thema mit Markup**

Unter den Kontrollkästchen sehen Sie einen Eintrag für jedes Thema mit Markups, die mit dieser Revision (oder diesem Dokument, falls einbezogen) verbunden sind. Dies ist, wie ein Thema mit Markups aussehen kann, wenn "Neue Themen" ausgewählt ist.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/09-topic-with-markup.png)

_Themen-Header_ Oben sehen Sie den Titel und die Nummer des Themas. Klicken Sie auf den Titel des Themas, um dieses Thema auf der Themenseite zu öffnen. Wenn Sie nicht gespeicherte Markups haben, werden Sie aufgefordert, diese zuerst zu speichern oder zu verwerfen, da Sie den Dokumentbereich verlassen werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/10-topic-with-markup.png)

Unterhalb des Thementitels sehen Sie den Status und den Typ des Themas. Sie können den Status dieses Themas in dieser Ansicht ändern, indem Sie darauf klicken und einen anderen Status auswählen. Dies kann nützlich sein, wenn alle Markups im Thema bearbeitet wurden und das Thema geschlossen werden kann. _Erforderlicher Zugriff:_ Schreibzugriff auf das Themen-Board, in dem sich das Thema befindet.

**Markups der Dokumentrevision in Themenkommentaren** Jedes Markup hat einen damit verbundenen Schnappschuss. Dieser Schnappschuss ist ein Bild aller Anmerkungen, die sich im aktuellen Markup befinden. Sie können auf den Schnappschuss klicken, um den Schnappschuss-Dialog zu öffnen, genau wie [in einem Thema](https://support.catenda.com/en/articles/8053352-topic-body-the-content-of-a-topic#h_1ba7f8873f). Dort können Sie das Bild vergrößert auf dem Bildschirm anzeigen und herunterladen.

Wenn es Markups gibt, der Revision des unten angegebenen Dokuments, in mehreren Kommentaren des Themas sehen Sie Pfeile auf der linken und rechten Seite des Bildes. Diese Pfeile können verwendet werden, um die verschiedenen Markups des Themas durchzublättern.

> **Hinweis:** Es werden nur Markups in Kommentaren zur angegebenen Revision angezeigt. Es können Markups in anderen Revisionen/Dokumenten im Thema vorhanden sein.

## 4. **Ausgewähltes Thema**

Nach Auswahl eines der Themen sehen Sie eine vereinfachte Version des Themas auf der Markup-Registerkarte. Im Themen-Dropdown sehen Sie den Titel und die Nummer des derzeit ausgewählten Themas.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/11-selected-topic.png)

Klicken Sie auf die Schaltfläche "Zurück" links neben dem Dropdown, um zur Themenübersicht zurückzukehren. Klicken Sie auf die Schaltfläche "Link öffnen" rechts neben dem Dropdown, um das Thema auf der Themenseite zu öffnen. Das Thema kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/q23002me/12-selected-topic.png)

### 4.1 **Speichern neuer Markups in ausgewählten Themen**

Weitere Informationen zum Speichern neuer Markups in einem ausgewählten Thema finden Sie [hier](https://support.catenda.com/en/articles/10209740-saving-a-markup#h_17e389a6b7).
