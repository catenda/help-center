# Organisationsprofilseite

Sie finden die Organisationsprofilseite, indem Sie auf den Namen der Organisation auf der [Organisationsseite](https://support.catenda.com/en/articles/8281910-organizations-page) klicken. Die Organisationsprofilseite ist die Hauptseite im Organisationstool.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/erq1xqqf/01-intro.png)

So kann ein Organisationsprofil aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/erq1xqqf/02-intro.png)

Informationen zur Organisation

Profilbild der Organisation

## 3. **Unterseiten**

_Benutzer_ - Hier finden Sie Eigentümer und reguläre Benutzer auf der [Benutzerseite der Organisation](https://support.catenda.com/en/articles/8508311-users-page-in-organization-tool).

**Projekte** Zeigt alle Projekte an, die Teil dieser Organisation sind, auf der [Projektseite der Organisation](https://support.catenda.com/en/articles/8505058-projects-page-in-organization-tool).

_Projektmitgliedschaften_ - [Mitglieder, die Teil der Projekte sind](https://support.catenda.com/en/articles/9003642-members-page-in-organization-tool) in dieser Organisation
