# Seite Projekteinstellungen

Sie finden die Seite Projekteinstellungen als letzte Seite im linken Navigationsmenü eines Projekts. Diese Seite ist Teil des Inhaltsfensters. Hier finden Sie Einstellungen, die sich auf mehr als einen Projektbereich beziehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/01-intro.png)

## 1. **Projekteigentümer**

So kann das Menü Projekteigentümer aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/02-project-owner.png)

Es kann nur einen Projekteigentümer geben. Bei den meisten Projekten ist der Eigentümer des Projekts die Organisation des Kunden, dem das Projekt gehört. Organisationen werden häufig nach dem Namen des Kunden benannt, gefolgt von der Art der Organisation. Wie die Organisation genannt wird, liegt bei jedem Organisationseigentümer, aber sie werden oft so genannt wie "Unternehmen A - Laufende Projekte", "Unternehmen B - Archiv" oder "Unternehmen C - Verwaltung und Vorlagen". Organisationen können mehreren Personen gehören, die dann einen Überblick über alle Projekte in dieser Organisation haben. Organisationseigentümer können Projekte auch von der [Projektseite im Organisationstool](https://support.catenda.com/en/articles/8505058-projects-page-organization-tool) verschieben, ohne Teil des Projekts sein zu müssen.

### 1.1 **Besitzer ändern**

Wenn Sie der Eigentümer dieser Organisation und auch anderer Organisationen sind, sehen Sie den Text "Besitzer ändern" auf der rechten Seite dieses Menüs. Hier können Sie ändern, welche Organisation dieses Projekt besitzt. Sie könnten z. B. ein Projekt von einer Organisation mit laufenden Projekten in eine Archivorganisation verschieben. Klicken Sie auf "Besitzer ändern", wählen Sie die neue Organisation aus, klicken Sie auf "Zum Besitzer machen" und bestätigen Sie.

## 2. **Projektdetails**

So kann das neue Projektmenü aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/03-project-details.png)

### 2.1 **Projektdetails**

Hier können Sie ein Foto des Gebäudes oder ein beliebiges Bild hinzufügen. Dieses Bild wird in den Projektdetails und auf der [Projektseite](https://support.catenda.com/en/articles/8400797-projects-page#h_1285a6d343) angezeigt, wenn Sie das Projekt als Favorit markieren. _Erforderlicher Zugriff:_ Projektadministrator

### 2.2 **Projektname**

Klicken Sie auf den Stift neben dem Projektnamen, um das Projekt umzubenennen. _Erforderlicher Zugriff:_ Projektadministrator

### 2.3 **Beschreibung**

Hier können Sie eine Beschreibung des Projekts eingeben _Erforderlicher Zugriff:_ Projektadministrator

## 3. **Maßeinheiten**

Das Menü "Maßeinheiten" kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/04-measurement-units.png)

Konfigurieren Sie, welche Einheiten Sie in Ihrem Projekt verwenden möchten

- Meter (m)
- Zentimeter (cm)
- Millimeter (mm)
- Füße (')
- Zoll ('')
- Zoll als Bruch

Die ausgewählte Maßeinheit wird standardmäßig von Projektmitgliedern beim Messen im 3D-Viewer in diesem Projekt verwendet. Ändern Sie die Maßeinheit und klicken Sie auf Speichern. _Erforderlicher Zugriff:_ Projektadministrator

## 4. **Ordner Standardmodelle**

Das Menü "Ordner Standardmodelle" kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/05-default-models-folder.png)

Bei [Modellen als Dokumente](https://support.catenda.com/en/articles/8064548-models-as-documents) ist jedes Modell mit einem Dokument im Dokumentbereich verknüpft. Wenn Sie ein Modell erstellen, werden Sie daher gefragt, wo in der Dokumentstruktur das Dokument enden soll. Wenn Sie Modelle über die API erstellen, benötigen die Dokumente, die für jedes Modell verknüpft werden, einen Platz im Dokumentbereich. Wenn kein Standardordner angegeben ist, wird ein Ordner namens Modelle angezeigt, wenn ein Modell über die API erstellt wird. Standardmäßig haben alle Benutzer Schreibzugriff auf den automatisch generierten Ordner.

## 5. **Projekt löschen**

Das Menü "Projekt löschen" kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/06-delete-project.png)

Klicken Sie auf die Schaltfläche "Projekt löschen" und geben Sie den genauen Namen des Projekts ein, um zu bestätigen, dass Sie es löschen möchten. Organisationseigentümer können das Projekt auch von der [Projektseite im Organisationstool](https://support.catenda.com/en/articles/8505058-projects-page-organization-tool) löschen, ohne Teil des Projekts sein zu müssen. Wenn Sie diese Option nicht sehen und Ihr Projekt löschen möchten, wenden Sie sich bitte an den Support. _Erforderlicher Zugriff:_ Organisation oder Projekteigentümer

> **Warnung:** **Warnung!** Ein gelöschtes Projekt kann nicht wiederhergestellt werden

## 6. **Zugangskontrolle**

Das Menü "Zugangskontrolle" kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/07-access-control.png)

Hier können Sie Aktionen steuern, die projektübergreifend sind. Klicken Sie auf jedes Menü, um es zu öffnen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/08-access-control.png)

Klicken Sie auf "Zugriff bearbeiten", um den Zugriff auf jede Einstellung zu ändern. _Erforderlicher Zugriff:_ Administrator

_Standardzugriff:_ Alle Benutzer - Kein Zugriff [Neue Mitglieder einladen](https://support.catenda.com/en/articles/4670263-invite-members-page)

### 6.3 **Konfiguration des Dokumentstatus**

_Standardzugriff:_ Alle Benutzer - Schreiben [Konfiguration des Dokumentstatus](https://support.catenda.com/en/articles/9874698-revision-publishing-iso-19650)

### 6.4 **Modelle erstellen und löschen**

_Standardzugriff:_ Alle Benutzer - Schreiben [Modelle erstellen und löschen](https://support.catenda.com/en/articles/8300623-model-configuration)

## 7. **Geolokalisierung**

Das Menü "Geolokalisierung" kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/09-geolocation.png)

Hier können Sie eine visuelle Darstellung konfigurieren, wo sich das Projekt auf der Welt befindet.

### 7.1 **Geolokalisierung von 3D-Modellen**

Das Konfigurieren dieser Einstellung hat keine Auswirkungen auf die 3D-Modelle im Projekt, da ihre Koordinaten in jeder IFC-Datei und/oder Modelltransformationseinstellung angegeben sind.

### 7.2 **Geolokalisierung von 2D-Modellen**

Das Konfigurieren dieser Einstellung platziert die 2D-Ansichten von Modellen, die durch Schneiden durch Objekte in einer Höhe generiert werden, an einer Stelle in der Welt. Nach der Konfiguration wird eine Karte im 2D-Viewer angezeigt. Das Konfigurieren dieser Einstellung ermöglicht es Ihnen auch, Ihre anfängliche 2D-Viewer-Rotation anzugeben.

> **Hinweis:** Wenn Ihr Standort vor dem 24. März 2025 festgelegt wurde, müssen Sie Ihren Standort bearbeiten und speichern oder neu konfigurieren, um die Karte zu sehen.

### 7.3 **Projektseiten-Karte**

Wenn ein Standort festgelegt wurde, sehen die Mitglieder einen Pin für dieses Projekt auf ihrer [Karte auf der Projektseite](https://support.catenda.com/en/articles/8400797-projects-page#h_5cf5358c76).
