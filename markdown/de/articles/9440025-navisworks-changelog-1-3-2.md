# Navisworks Changelog - 1.3.2

## 1. **Neue Funktionen**

Greifen Sie auf die Dokumentbibliothek auf Catenda zu, um Dateien in jedem von Navisworks unterstützten Format zu öffnen. Greifen Sie auf alle model revisions zu (nicht nur die neueste). Speichern Sie Ihre NWD-Datei direkt in Catenda. Konsolidieren Sie viewpoints, wenn Sie ein topic aus einer Gruppe oder mehreren clashes erstellen (erstellen Sie einen viewpoint mit allen clashes)
