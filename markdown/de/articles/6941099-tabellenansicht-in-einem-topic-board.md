# Tabellenansicht in einem topic board

Klicken Sie auf Tabellenansicht (**4**) oben rechts in der Topics-Tabelle auf der [topics page](https://support.catenda.com/en/articles/4670271-topics-page). Standardmäßig wird die Listenansicht in der Tabelle angezeigt. Die Einstellung für die Tabellenansicht ist eine globale Einstellung. Sobald die bevorzugte Ansicht ausgewählt ist, werden topic-Tabellen in jedem topic board jedes Projekts für den Benutzer in dieser Ansicht angezeigt.

Die folgenden Topics werden in diesem Artikel beschrieben:

## 1. **Topics-Tabelle**

Die Topics-Tabelle kann ungefähr so aussehen, wenn die Tabellenansicht konfiguriert ist.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/01-topics-table.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/11748020-tables-on-catenda), um mehr über die Arbeit mit Tabellen in Catenda zu erfahren. Sobald ein topic erstellt ist und die Tabelle geladen ist, wird das topic als Zeile in der Topics-Tabelle für den Benutzer angezeigt. Beachten Sie, dass der offene Filter standardmäßig aktiviert ist und geschlossene topics möglicherweise bis zur Filterung ausgeblendet werden.

Die folgenden Topics werden in diesem Abschnitt beschrieben:

### 1.1 **Während der Anzeige vorgenommene Änderungen**

Wenn Änderungen an einem der angezeigten topics vorgenommen werden, kann eine Benachrichtigung, dass Änderungen vorgenommen wurden, am unteren Ende der Tabelle angezeigt werden. Klicken Sie auf diese Benachrichtigung, um die während der Anzeige von topics vorgenommenen Änderungen zu laden. Beim Abrufen von Änderungen wird eine Animation wiedergegeben, bei der Zeilen für neue topics in die Tabelle rutschen und Zeilen für gelöschte topics aus der Tabelle herausrutschen.

### 1.2 **Ausgewählte Elementaktionen**

Nach der Auswahl einer topic-Zeile wird das Menü der ausgewählten Elementaktionen oben in der Topics-Tabelle angezeigt. So kann das Menü der ausgewählten Elementaktionen aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/02-selected-item-actions.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board), um mehr über das Menü der ausgewählten Elementaktionen zu erfahren.

### 1.3 **Zeileninhalt**

Wenn die Tabelle erstmals geladen wird, werden bis zu 100 Zeilen angezeigt. Wenn mehr als 100 Zeilen in der Tabelle vorhanden sind, scrollen Sie nach unten, um die nächsten 100 Zeilen zu laden.

**Topic-Zeile** Das Öffnen des Inhalts einer topic-Zeile führt dazu, dass die Tabelle den Inhalt dieses topics auf der topics page anzeigt.

### 1.4 **Spalten**

Einige Spalten in der Topics-Tabelle sind standardmäßig aktiviert, während andere ausgeblendet werden können und aktiviert werden müssen. Basierend auf der konfigurierten Spaltenreihenfolge werden die ersten Spalten angezeigt, während die Tabelle möglicherweise horizontal verschoben werden muss, um andere aktivierte Spalten anzuzeigen. ## 2. **Topic-Auswahl**

### 2.1 **1. Auswahl von topics mit einem Auswahlkästchen**

Wählen Sie ein Kontrollkästchen aus, um ein topic aus der Liste auszuwählen. Sie können auch an einer beliebigen Stelle in der Zeile des topics klicken, wo sich kein Link befindet, um es auszuwählen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/03-1-selecting-topics-with-selection-box.png)

**Zeilenauswahl** Nachdem Sie ein topic ausgewählt haben, können Sie `Umschalt + Klick` ausführen, um alle dazwischen liegenden topics auszuwählen.

**Auswahl bearbeiten** Sie können auch `Strg + Klick` ausführen, um ein topic zur Auswahl hinzuzufügen oder daraus zu entfernen

### 2.2 **2. Alle auswählen**

Wählen Sie alle topics im topic board(s) aus. Wenn Sie ein topic board öffnen, werden 100 topics geladen. Wenn Sie nach unten über 100 topics hinaus scrollen, werden mehr topics geladen. Beim ersten Mal, wenn Sie dieses Kästchen aktivieren, werden alle topics ausgewählt, die Sie geladen haben. Wenn Sie viele topics in Ihrem board haben und sie nicht alle laden möchten, indem Sie scrollen, können Sie im Filter auf "Alle auswählen" klicken, das erscheint, nachdem Sie "topics ausgewählt" sehen, wenn Sie das Auswahlkästchen aktivieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/04-2-select-all.png)

## 3. **6. Spalten-Dropdown**

Oben rechts in der Topics-Tabelle finden Sie das Dropdown "Spalten".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/05-6-columns-dropdown.png)

Mit diesem Dropdown können Sie die Spalten der Tabelle neu anordnen und umschalten. Ihre Einstellung für die Neuordnung und Umschaltung von Spalten wird über topic boards und Projekte hinweg gespeichert und in Ihrem Konto gespeichert. Das heißt, es behält diese Reihenfolge, wenn Sie den Browser schließen und neu ordnen. Wenn Sie versehentlich eine Spalte ausgeblendet haben, indem Sie sie aus der Tabelle gezogen haben, können Sie sie hier erneut aktivieren. ## 4. **3. Header-Zeile**

Die folgenden Topics werden in diesem Abschnitt beschrieben:

### 4.1 **Sortierung**

Wenn Sie auf die Kopfzeile einer Spalte klicken, ist es möglich, nach dieser Spalte zu sortieren. Wenn Sie erneut darauf klicken, wird die Sortierung umgekehrt. Standardmäßig wird die Spalte "Erstellt" sortiert. Wenn Sie Ihre Sortierungseinstellung ändern, wird sie gespeichert, bis Sie das topic board das nächste Mal öffnen.

### 4.2 **Ziehen von Spaltenüberschriften**

Spaltenüberschriften können nach links und rechts gezogen werden, um neu angeordnet zu werden. Sie können die Spaltenüberschrift aus der Tabelle ziehen, um die Spalte zu deaktivieren. Sie können die Spalte erneut im [Spalten-Dropdown](#h_9e88dec7ef) oben rechts aktivieren.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/06-dragging-column-headers.png)

### 4.3 **Spaltenbreite**

Wenn Sie die Maus über die Linie zwischen zwei Spalten bewegen, können Sie ziehen, um die Breite einer Spalte zu ändern. Ihre Einstellung für die Spaltenbreite wird über topic boards und Projekte hinweg gespeichert und in Ihrem Konto gespeichert. Es ist möglich, auf den Bereich zwischen zwei Spalten doppelzuklicken, um den Text in der Spalte automatisch anzupassen.

_Cursor-Änderung_ Sie werden wissen, dass Sie über der richtigen Stelle schweben, wenn sich der Cursor zu einem Größenänderungszeiger ändert

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/07-column-width.png)
