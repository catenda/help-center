# Einladung zum Beitreten zu einem Projekt annehmen

Die häufigste Möglichkeit, mit Catenda Hub zu beginnen, ist eine Einladung zu einem Projekt.

## 1. Einladung erhalten

Um eine Projekteinladung zu erhalten, muss ein Benutzer im Projekt Sie mit Ihrer E-Mail-Adresse einladen. Wenn Sie wissen, zu welchem Projekt Sie eingeladen werden möchten, aber nicht wissen, wer dazu berechtigt ist, wenden Sie sich bitte an [support@catenda.com](mailto:support@catenda.com). Wir teilen Ihnen mit, wer Sie einladen kann.

_Erforderlicher Zugriff:_ Administrator oder Zugriff zum Einladen von Mitglieder auf der Projekteinstellungsseite.

### 1.1 Einladungsbenachrichtigung

Wenn Sie bereits ein Konto bei Catenda haben, erhalten Sie die folgende Benachrichtigung.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/01-invite-notification.png)

### 1.2 Einladungs-E-Mail

Wenn Sie noch kein Konto haben oder selbst wenn Sie Ihre E-Mail-Benachrichtigungen vollständig ausgeschaltet haben, erhalten Sie eine E-Mail mit dem folgenden Betreff:

> **Tipp:** "(Name des einladenden Benutzers) hat Sie zu (Catenda-Projekt, zu dem Sie eingeladen werden) eingeladen."

[Hier](https://support.catenda.com/en/articles/8417802-why-am-i-not-receiving-emails) finden Sie Informationen zur Behebung von E-Mail-Problemen. Sie können die Einladung annehmen, indem Sie auf die Benachrichtigung klicken, wenn Sie ein Konto unter [https://hub.catenda.com/signup](https://hub.catenda.com/signup) erstellen und erneut eingeladen werden. Es kann jedoch hilfreich sein zu überprüfen, warum Sie möglicherweise keine E-Mails erhalten, damit Sie E-Mail-Benachrichtigungen erhalten können.

Der Name des einladenden Benutzers und die E-Mail-Adresse des Benutzers werden in der Einladungs-E-Mail angezeigt, die wie folgt aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/02-invite-email.png)

Die E-Mail wird von [noreply@catenda.com](mailto:noreply@catenda.com) gesendet

> **Hinweis 1:** Eine Projekteinladung kann mehrmals gesendet werden. Alle E-Mails enthalten denselben Link, sodass sie alle funktionieren, es sei denn, die Einladung wurde widerrufen. **Hinweis 2:** Sie können nicht auf die E-Mail [noreply@catenda.com](mailto:noreply@catenda.com) antworten. Wenn Sie Fragen zur Einladung haben, müssen Sie an die E-Mail-Adresse der einladenden Person antworten oder [support@catenda.com](mailto:support@catenda.com) kontaktieren

## 2. Einladung annehmen

Um die Einladung anzunehmen, klicken Sie entweder auf die Einladungsbenachrichtigung oder klicken Sie auf den Link "Hier klicken, um die Einladung anzunehmen" in der Einladungs-E-Mail.

Wenn Sie auf die Einladung klicken, werden Sie zu Catenda Hub weitergeleitet, wo Sie aufgefordert werden, sich anzumelden und die Einladung anzunehmen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/03-accepting-the-invitation.png)

### 2.1 Konto erstellen

Wenn Sie noch kein Konto haben, werden Sie aufgefordert, ein Konto bei Catenda Hub zu erstellen. Befolgen Sie die [Registrierungsprozedur](https://intercom.help/bimsync-arena/en/articles/8412895-creating-an-account).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/04-creating-an-account.png)

Klicken Sie dann auf "Einladung annehmen"

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/05-creating-an-account.png)

> **Hinweis:** Wenn Sie feststellen, dass Sie mit einem anderen Konto angemeldet sind als dem, das Sie für dieses Projekt verwenden möchten, erhalten Sie vor dem Annehmen der Einladung die Möglichkeit, den Benutzer zu wechseln.
