# Menü für Genehmigungsanfrage-Dokumente auf der rechten Seite

Dieser Artikel enthält Informationen zu den folgenden Themen: _[Wird überprüft](#h_b398f04f49) - [Schrittsübersicht](#h_be2d5b96e1)_ Das rechte Menü kann durch Auswahl von Dokumenten in der [Registerkarte Dokumente](https://support.catenda.com/en/articles/12495130-documents-tab-in-an-approval-request) auf einer Genehmigungsanfrage-Seite geöffnet werden. Je nachdem, ob Sie ein Dokument oder mehrere Dokumente auswählen, sieht das Menü unterschiedlich aus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/01-intro.png)

### Mehrfachauswahl:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/02-multiple-selection.png)

Wenn Sie mehrere Dokumente auswählen, können Sie Ihre Auswahl direkt überprüfen, indem Sie auf die Schaltfläche "Dokumente überprüfen" klicken.

### Einzelauswahl:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/03-single-selection-br.png)

Die Einzelauswahl öffnet eine Übersicht im rechten Menü. Es ist dasselbe Menü, das sich in der Dokumentenüberprüfung im 2D-Viewer öffnet, zeigt aber die Dokumentvisualisierung nicht an. Es ermöglicht Prüfern, das Dokument genehmigen/ablehnen oder einreichen zu können, ohne es zu öffnen.

### Schrittsübersicht

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dmdyh23e/04-steps-overview.png)

Dies ist ein Beispiel für die Schrittsübersicht, bei der ein Mitglied eines Prüferteams eine Angabe eingereicht hat, dass das Dokument im Namen eines Prüferteams genehmigt werden sollte. Sie zeigt den Schrittstatus sowie das Team und das Mitglied, das die Überprüfung und Einreichung durchgeführt hat.
