# Zusammengeführte Datei in Navisworks

## 1. Erstellen einer zusammengeführten Datei in Navisworks

Sie können die IFC-Modelle aus Ihrem Catenda-Projekt ganz einfach mit diesem Plugin und den Aktionen auf der Registerkarte "Modelle" herunterladen.

So laden Sie auf Ihr lokales Gerät herunter:

- Klicken Sie auf die Download-Schaltfläche für jedes Modell, das Sie herunterladen möchten.
- Die Modelle werden in einem neuen Ordner mit dem Projektnamen unter dem in der Registerkarte "Einstellungen" angegebenen Download-Pfad gespeichert.
  - Beispiel: C:\\...\\Dokumente\\Catenda-Projektname

## 2. Erstellen einer zusammengeführten .nwf-Datei mit IFCs aus Catenda

Um die BCF-Ansichtspunkte aus Ihrem Catenda-Projekt im Catenda-Plugin verwenden zu können, benötigen Sie eine zusammengeführte NavisWorks-Datei mit den IFCs aus Catenda.

- Laden Sie die IFC-Modelle herunter, die Sie zusammenführen möchten, indem Sie die obigen Schritte befolgen.
- Öffnen Sie eine der heruntergeladenen Dateien in NavisWorks.
- Führen Sie weitere Modelle aus dem gleichen Projekt mit "Anhängen" in das NavisWorks-Modell ein.
- Nachdem Sie alle Dateien, die Sie zusammenführen möchten, angehängt haben, speichern Sie die Datei als .nwf-Datei.
- Speichern Sie die Datei im gleichen Ordner wie Ihre heruntergeladenen IFC-Dateien.
- Verwenden Sie diese zusammengeführte Datei, wenn Sie BCF-Ansichtspunkte in Navisworks anzeigen.
- Sie können diese zusammengeführte Datei auch für die Durchführung von Kollisionsprüfungen in NavisWorks verwenden.
