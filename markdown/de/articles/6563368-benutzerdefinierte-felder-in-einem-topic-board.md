# Benutzerdefinierte Felder in einem topic board

Nach der Konfiguration der Einstellungen Ihrer benutzerdefinierten Felder können Sie diese Felder nun zu Ihrem topic board hinzufügen

Sie befinden sich im Bereich "**topics"**

1. Wählen Sie die Einstellungen Ihres topic board

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/01-intro.png)

2. Klicken Sie auf **benutzerdefiniertes Feld hinzufügen**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/02-intro.png)

**3**. Wählen Sie das hinzuzufügende Feld

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/03-intro.png)

4. Sie können dieses Feld als erforderlich kennzeichnen (Ja/Nein)

5. Legen Sie einen Standardwert fest.

6. Validieren Sie zum Speichern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/04-intro.png)

Nach Abschluss können Sie eine Vorschau Ihrer benutzerdefinierten Felder anzeigen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/05-intro.png)

Sie können die Felder jetzt bei Ihren nächsten topics eingeben!

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/06-intro.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tv2vef51/07-intro.gif)
