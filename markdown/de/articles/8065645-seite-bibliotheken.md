# Seite Bibliotheken

Die Seite Bibliotheken finden Sie als fünfte Seite im linken Navigationsmenü eines Projekts. Diese Seite ist Teil des Inhaltsbereichs. Hier finden Sie Bibliotheken, die Sätze von Elementen enthalten.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/01-intro.png)

## 1. **Neue Elementaktionen**

Durch Klicken auf die Schaltfläche "Neues Element" können Sie eine neue Bibliothek hinzufügen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/02-new-item-actions.png)

### 1.1 **Dokument-Bibliotheken**

[Dokumente](https://support.catenda.com/en/articles/8204673-documents-page) - Die Dokumentbibliothek im Dokumentbereich [Links-Bibliothek](https://support.catenda.com/en/articles/4670254-links-library) - Verbinden Sie Links mit Objekten und Problemen _Dropbox_ - Verlinken Sie Dateien von Dropbox zu Objekten im BIM

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/03-document-libraries.png)

Nachdem Sie Ihrer Bibliothek einen Namen gegeben haben, leitet Catenda Sie an Dropbox weiter, um die Berechtigung für den Zugriff auf Ihr Dropbox-Konto zu erhalten. Sie können dann Ihr Dropbox durchsuchen und auswählen, welcher Ordner für das Projekt freigegeben werden soll. Wenn Sie möchten, können Sie mehrere Dropbox-Bibliotheken erstellen, auch mit demselben Dropbox-Konto.

> **Hinweis:** Catenda erhält niemals Zugriff auf Ihr Dropbox-Passwort, da OAuth 2.0 zur Authentifizierung verwendet wird.

_[Sharepoint](https://support.catenda.com/en/articles/5744548-sharepoint-library)_ - Fügen Sie eine Sharepoint-Bibliothek zum Projekt hinzu. Dies ermöglicht Mitgliedern, die Dateien anzuzeigen und sie mit anderen zu verbinden.

> **Hinweis:** Dies unterscheidet sich von unserer [SharePoint-Anwendung](https://support.catenda.com/en/articles/8396496-catenda-sharepoint-application), die es Mitgliedern ermöglicht, Dokumente von SharePoint an Catenda zu posten

_coBuilder Pro_ - Dokumente - Objekte mit Dokumenten aus coBuilder Pro markieren Diese Bibliothek ist nur in Legacy-Projekten verfügbar.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/7wg8652x/04-document-libraries.png)

Geben Sie Ihren coBuilderPRO-Benutzernamen und Ihr Passwort ein, um eine Verbindung herzustellen.

### 1.2 **Generische Bibliotheken**

_[Klassifikation](https://support.catenda.com/en/articles/4670255-classification-library)_ - Markieren Sie Objekte mit benutzerdefinierten Klassifikationen aus einer CSV-Datei _coBuilder Pro_ - Markieren Sie Objekte mit Produktinformationen aus coBuilder Pro _Lookup_ - Fügen Sie eine externe Website als Bibliothek hinzu _[Eigenschaftswerte](https://support.catenda.com/en/articles/4670252-property-value-library)_ - Erstellen Sie Einträge basierend auf Eigenschaftswerten

### 1.3 **Vorgeschlagene Bibliotheken**

Wenn eines der Modelle in Ihrem Projekt eine Klassifikation enthält, wird eine eingebettete Bibliothek für diese Klassifikation hier vorgeschlagen. Klicken Sie auf die vorgeschlagene Bibliothek, um sie zu aktivieren. Eine vorgeschlagene Bibliothek sucht die Codes für diese Klassifikation online und versucht, sie mit den in Ihrer Datei angegebenen Codes abzugleichen. Diese öffentlichen Klassifikationsbibliotheken können nicht bearbeitet werden und finden Objekte mit einem Klassifikationscode nur, wenn dieser Code gemäß der Klassifikation korrekt ist.

## 2. **Bibliotheksliste**

Hier sehen Sie eine Liste aller konfigurierten Bibliotheken. Bibliotheken werden entweder als Dokumentbibliothek oder als generische Bibliothek angezeigt

### 2.1 **Mit Stern versehen**

Fügen Sie einen Stern zu einer Ihrer Bibliotheken hinzu, um sie als Unterkategorie zur Seite Bibliotheken im rechten Informationsmenü anzuzeigen.

### 2.2 **Dokument-Bibliotheken**

Sie sehen immer die Dokumente und die Links-Bibliothek oben. Die Dokumentbibliothek führt Sie zur Dokumentseite. Die Links-Bibliothek führt Sie zur Links-Bibliothek. Alle konfigurierten Dropbox- und Sharepoint-Bibliotheken werden hier auch angezeigt.

### 2.3 **Generische Bibliotheken**

Hier können Sie die buildingSMART Data Dictionary-Bibliothek oben sehen. Darunter werden alle Klassifikations-, eingebettete Klassifikations-, coBuilder Pro-, Lookup- und Eigenschaftswert-Bibliotheken in der Reihenfolge angezeigt, in der sie hinzugefügt wurden.
