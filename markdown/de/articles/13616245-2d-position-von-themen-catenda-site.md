# 2D-Position von Themen - Catenda Site

Die Position kann auf Themen angewendet werden, indem ein Marker bei einer x-, y-, z-Koordinate im [2D-Viewer](https://support.catenda.com/en/articles/4854537-2d-viewer) platziert wird. Farbige Punkte markieren die Position von Themen im 2D-Viewer und geben ein unmittelbares visuelles Verständnis dafür, wo sich die Themen befinden, sowie deren Status und Typ. Mit Themenpositionen kann Ihr Projekt die Platzierung von Themen massiv besser kontrollieren. Diese Funktion ergänzt die Funktionalität unserer Browseranwendung [Catenda Hub](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site). Mit Markern werden Projekte mit nahtloser Erstellung, Überwachung und Verwaltung von vor Ort erstellten Themen ausgestattet.

Dies ist ein Beispiel dafür, wie Marker im 2D-Viewer in Catenda Site aussehen können:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/01-intro.png)

## 1. **Themen mit bestehenden Markern**

### 1.1 **Interaktion mit Markern**

Tippen Sie auf einen Marker in Catenda Site, um die Themennummer und den Titel des Themas anzuzeigen, zu dem dieser Marker gehört. Dies ist ein Beispiel dafür, wie ein angetippter Marker in Catenda Site aussehen kann.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/02-interacting-with-markers.png)

### 1.2 **Anzeige von Markern**

Um mit Themen und Positionen zu arbeiten, öffnen Sie das 2D/3D-Viewer-Menü.

**Wählen Sie ein Themen-Board** Wählen Sie ein Themen-Board aus, um die Marker auf dem Geschoss aus diesem Themen-Board anzuzeigen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/03-displaying-markers.png)

Wenn ein Geschoss im Geschoss-Konfigurator konfiguriert worden ist, wird das erste Geschoss des ersten Gebäudes standardmäßig geöffnet, sobald das 2D/3D-Viewer-Menü geöffnet wurde.

**Filtern Sie das Themen-Board** Reduzieren Sie die Anzahl der Marker auf dem Bildschirm, indem Sie das Themen-Board filtern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/04-displaying-markers.png)

> **Warnung 1:** Wenn das Themen-Menü geöffnet wird, werden Marker aus den ersten 250 Themen des Ergebnisses aktualisiert und gespeichert. Wenn der 2D-Viewer geöffnet wird, werden Marker aus zuvor aktualisierten Themen angezeigt, die dem Ergebnis im Themen-Menü entsprechen. Beachten Sie, dass Marker aus Themen über mehrere Geschosse verteilt sein können, nicht nur das aktive Geschoss. **Warnung 2:** Wenn sich 250+ Themen im Themen-Menü-Ergebnis befinden, wurden Marker möglicherweise nicht geladen oder sind veraltet. Scrollen Sie in der Liste nach unten, um deren Marker ebenfalls anzuzeigen/zu aktualisieren. Das Filtern des Boards, sodass weniger Themen im Ergebnis vorhanden sind, kann auch dazu beitragen, dass Marker, die zu Themen im gefilterten Ergebnis gehören, zusätzlich aktualisiert und angezeigt werden. **Warnung 3:** Wenn Sie sich von der Anwendung abmelden und sich wieder anmelden, geht der Verlauf der geladenen Themen verloren und Themen, die zuvor geladen waren, müssen möglicherweise erneut geladen werden.

**Erweitern Sie die 2D-Ansicht** Ziehen Sie auf dem Teiler zwischen dem 2D- und 3D-Viewer, um diese zu erweitern.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/05-displaying-markers.png)

Wählen Sie ein Geschoss aus einem IFC-Modell oder aus einem konfigurierten Gebäude, indem Sie auf das Geschoss-Menü oben links tippen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/06-displaying-markers.png)

### 1.3 **Suche nach Themen aus Markern**

**Suche nach einem Thema aus einem Marker auf einem Geschoss in der 2D-Ansicht** Tippen Sie auf einen Marker in der 2D-Ansicht, um die Themennummer und den Titel des Themas anzuzeigen, zu dem er gehört. Tippen Sie auf den Pfeil des ausgewählten Markers, um das ausgewählte Thema in seinem Themen-Board auf der Seite "Themen" anzuzeigen.

**Suche nach einem Marker im 2D-Viewer aus einem Thema** Suchen Sie ein Thema, das "Hat Position" im Feld "Position" anzeigt, und tippen Sie darauf.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/07-finding-topics-from-markers.png)

Tippen Sie im sich öffnenden Menü auf "Position auf 2D anzeigen":

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/08-finding-topics-from-markers.png)

Wenn ein Thema in einem Themen-Board geöffnet wird, wird die Farbe dieses Markers grün mit einem Häkchen im 2D/3D-Menü hervorgehoben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/09-finding-topics-from-markers.png)

### 1.4 **Bearbeitung von Markern**

**Verschieben von Markern** Tippen Sie auf das Positionsfeld in einem Thema und tippen Sie im sich öffnenden Menü auf "Position ersetzen". Ziehen Sie den Marker mit der Ankerpunkt an die neue Position und bestätigen Sie.

**Entfernen von Markern** Tippen Sie auf das Positionsfeld in einem Thema und tippen Sie im sich öffnenden Menü auf "Position ersetzen". Tippen Sie auf "Position entfernen".

### 1.5 **Marker-Konfiguration**

Tippen Sie auf das Zahnrad-Symbol im 2D-Viewer, um die Catenda Site 2D-Viewer-[Einstellungen](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site#h_63e1728758) zu öffnen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/10-marker-configuration.png)

Hier können verschiedene 2D-Viewer-Optionen konfiguriert werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/11-marker-configuration.png)

**Marker-Sichtbarkeit** Schalten Sie Marker ein oder aus

**Marker-Färbungsmodus** Ändern Sie die Art der Farbe, die die Marker haben sollen

**Raumnamensformat** Räume können im IFC-Format kurze oder lange Namen haben

## 2. **Themen mit neuen Markern**

### 2.1 **Neues Thema mit Marker erstellen**

Die grüne Plus-Schaltfläche in einem Themen-Board ist nicht die einzige Möglichkeit, ein Thema zu erstellen. Tippen Sie an eine beliebige Stelle im 2D-Viewer, um dort ein Thema zu erstellen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/12-create-a-new-topic-with-a-marker.png)

Das auf diese Weise erstellte Thema wird automatisch den Marker an dieser Position angewendet haben.

### 2.2 **Marker aus Thema hinzufügen**

Erstellen Sie ein neues Thema oder öffnen Sie ein Thema ohne Marker und tippen Sie auf "Position".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/13-add-marker-from-topic.png)

Das 2D/3D-Menü wird jetzt geöffnet und ein neuer Marker mit einem Ankerpunkt wird grün angezeigt:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/14-add-marker-from-topic.png)

Zoomen Sie im 2D-Viewer mit zwei Fingern heran und verschieben Sie den Marker an die richtige Position. Klicken Sie dann auf das Häkchen, um ihn an der Position zu fixieren.
