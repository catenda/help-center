# Feature-Status Q2 2026

Um Benachrichtigungen zu vermeiden und einen reibungslosen Start zu gewährleisten, können neue Verhaltensweisen oder Änderungen an bestehenden Verhaltensweisen schrittweise und ohne Ankündigung eingeführt werden. Benutzer, die Änderungen im Verhalten eines häufig genutzten Seitenbereichs bemerken, oder die sich fragen, was neu ist, können diese Artikel für Aktualisierungen über aktuelle Verhaltensänderungen für alle Benutzer konsultieren.

## 1. **Neue Funktionen**

Jeder Benutzer nutzt die Plattform unterschiedlich. Selbst wenn eine neue Funktion veröffentlicht oder Änderungen an einer Funktion vorgenommen werden, kann es sein, dass Benutzer diesen Teil der Funktion nicht nutzen. Für diejenigen, die neugierig sind, was "dieser neue Button" oder "diese neue Seite" auf der Plattform ist, enthält dieser Artikel eine Einführung in das, worum es bei der Änderung geht. Für diese Funktionen ist oft nur grundlegendes oder leicht veraltetes Supportmaterial verfügbar, da dieses während des Prozesses aktualisiert wird. Zusammen mit der Unterstützung von Benutzern wird der Support-Artikel oft aktualisiert und falls Fragen, die gestellt wurden, schnell in einem Artikel erklärt werden können, wird dies in der nächsten Woche verfügbar sein.

## 2. **Aktualisierte Funktionen**

### 2.1 **Objektname im Baum-Panel**

Bis jetzt wurden Namen für die verschachtelten Ebenen angezeigt, aber für das Objekt auf der niedrigsten Ebene wurde ein automatisch generierter Name wie folgt angezeigt:

```
WallStandardCase1.0WallStandardCase1.1WallStandardCase1.2
```

Das Standardverhalten hat sich jetzt geändert, um stattdessen den Wert im Namen des Objekts anzuzeigen, der im Inspektor-Panel zu sehen ist, wie folgt:

```
Basic Wall:Exterior - Insul Panel on Mtl. Stud:140707Basic Wall:Exterior - Insul Panel on Mtl. Stud:140832Basic Wall:Exterior - Insul Panel on Mtl. Stud:140972 
```

Eine neue Model-Revision muss hochgeladen werden, um den Unterschied zu sehen.

Das vorherige Verhalten mit dem automatisch generierten Namen, das nützlich sein kann, wurde beibehalten, indem man auf das Zahnradsymbol oben rechts in jedem Model-Baum-Menü klickt.

## 3. **On-Demand-Funktionen aktivieren**

Jede On-Demand-Funktion ist produktionsreif und einsatzbereit für echte Projektnutzung. Obwohl diese Funktionen getestet wurden und wie erwartet funktionieren, kann es unterschiedliche Grade geben, wie viele Projekte mit diesen Funktionen begonnen haben, daher könnten unbekannte Grenzfälle gefunden werden. Während Änderungen auftreten können, während wir daran arbeiten, diese Funktionen für alle Benutzer verfügbar zu machen, werden Daten, die in diesen Funktionen eingereicht werden, nicht gelöscht.

### 3.1 **On-Demand-Funktionen zur Aktivierung anfragen**

Einige Funktionen können von der Kontaktperson für Ihre Catenda-Lizenz für bestehende Projekte aktiviert werden, während andere mit einer Einstellung im Projekt aktiviert werden können. Wenn eine On-Demand-Funktion aktiviert werden soll, wird ein Treffen mit einem Support-Vertreter vereinbart, um den aktuellen Status der Funktion zu besprechen. Wenn ein Projekt, in dem die On-Demand-Funktion getestet werden kann, nicht bereits verfügbar ist, kann ein Dummy-Projekt für eine begrenzte Zeit erstellt werden, in dem die On-Demand-Funktion getestet werden kann, um zu prüfen, ob die Funktion einsatzbereit ist.

### 3.2 **Report-Editor**

Erstellen Sie Report-Vorlagen für Themen und Dokumente, damit Projektmitglieder Themen oder Dokumente aus der Tabelle auswählen und die Report-Aktion verwenden können, um einen Report zu erstellen. Die Reports-Seite ist eine On-Demand-Funktion, die für laufende Projekte aktiviert werden kann. Neue Projekte, die auf einem Template-Projekt erstellt werden, in dem diese Funktion aktiviert ist, haben diese Funktion nicht aktiviert. Separate Vorlagen können für Themen und Dokumente erstellt werden. Wenn eine Vorlage in einem Projekt verfügbar ist, kann die Report-Aktion mit ausgewählten Themen und Dokumenten verwendet werden, um einen Report basierend auf der ausgewählten Vorlage zu erstellen. Catenda bietet Unterstützung zur Anzeige verschiedener Werte auf der Seite an. Wenn Sie einen benutzerdefinierten Report möchten, der auf Ihr Unternehmen zugeschnitten ist, können wir Sie mit einem Berater in Kontakt bringen, der Ihnen dabei helfen kann.
