# Wer kann Mitglieder einladen

1. Wechseln Sie zu den Einstellungen im linken Hauptmenü.
2. Unter der Zugriffskontrolle auf dieser Seite haben Sie "Neues Mitglied einladen". <br>Klicken Sie darauf.
3. Eine Liste der Personen, die Zugriff erstellen und bearbeiten können, wird angezeigt. <br>Klicken Sie auf die Schaltfläche "Zugriff bearbeiten".
4. Definieren Sie den Zugriff für Mitglied(er) oder Team(s).
5. Unter den Mitgliedern oder Teams, die Sie ausgewählt haben, wird angezeigt.<br>Unter "Zugriff" wählen Sie zwischen "Kann einladen" und "Nicht zulässig".
6. Drücken Sie die Schaltfläche "Speichern".
