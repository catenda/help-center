# Neue Mitglieder zum Projekt einladen

[YouTube-Video](https://www.youtube.com/embed/yd6R0FUEj-4?rel=0)

Wenn Sie ein Administrator in einem Projekt sind, können Sie neue Mitglieder hinzufügen. Als Mitglied eines Projekts können Sie standardmäßig keine neuen Mitglieder hinzufügen, aber ein Administrator kann Ihnen Zugriff zum Einladen von Mitgliedern gewähren.

Ein neues Mitglied kann hinzugefügt werden, indem Sie zu folgendem gehen:

"Mitglieder" (linkes Menü)

1. Mitglied einladen
1. Geben Sie deren E-Mail-Adresse(n) ein
1. Wählen Sie deren Rolle im Projekt und welches Team (optional)
1. +Hinzufügen
1. Optionale Nachricht=>Einladung(en) senden
