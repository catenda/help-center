# Dateitypen auf Catenda Site in der Vorschau anzeigen

Dokumente auf Catenda Site können durch Antippen eines Dokuments im [Dokumentenmenü](https://support.catenda.com/en/articles/7774637-documents-menu-catenda-site) gefunden werden.

## 1. Schaltflächen oben rechts

Oben im Dokument finden Sie die folgenden Optionen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/01-top-right-buttons.png)

### 1.1 Hamburger-Menü

Wenn Sie auf das Hamburger-Menü oben rechts im Dokument klicken, öffnet sich ein Menü am unteren Rand des Bildschirms.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/02-1-hamburger-menu.png)

**Öffnen**

Tippen Sie auf die Option Öffnen, um Ihr Dokument mit einer anderen Anwendung auf Ihrem Gerät zu öffnen.

Diese Option kann verwendet werden, um Ihr Dokument in einer Anwendung mit Dokumentvorschau-Funktionen zu öffnen. Sie könnten beispielsweise ein Bild in einer Bildbearbeitungs-App oder ein PDF in einer App öffnen, in der Sie Kommentare hinzufügen können.

**Teilen**

Tippen Sie auf die Option Teilen, um Ihr Dokument mit einer anderen Anwendung auf Ihrem Gerät zu teilen.

Diese Option kann verwendet werden, um Ihr Dokument als Anlage in Kommunikationstypen wie E-Mail oder Nachrichten zu teilen, die Anlagen haben können.

Tippen Sie überall außerhalb des Hamburger-Menüs oder ziehen Sie das Menü nach unten, um es zu schließen.

### 1.2 Suche

Wenn durchsuchbarer Text in einem Dokument vorhanden ist, kann die Suchoption verwendet werden, um Phrasen in diesem Text zu finden. Wenn Sie auf die Schaltfläche Suchen tippen, wird eine Suchleiste angezeigt und Sie können die gesuchte Phrase eingeben.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/03-2-search.png)

Drücken Sie das x, um Ihre Suche zu löschen.

**Trefferfinder**

Nachdem Sie eine Phrase eingegeben haben, können Sie auf die Schaltfläche Treffer tippen, um eine Übersicht aller Stellen im Dokument zu sehen, an denen Ihre Phrase gefunden wurde.

**Hamburger-Menü in der Suchleiste**

Durch Tippen auf das Hamburger-Menü können Sie wählen, ob Großbuchstaben mit der Option "Groß-/Kleinschreibung beachten" berücksichtigt werden sollen und ob Ihre Phrase gefunden werden soll, wenn sie ein ganzes Wort statt nur ein Teil eines Wortes ist.

### 1.3 Seiten

Mit der Schaltfläche Seiten erhalten Sie einen Überblick über die Seiten in Ihrem Dokument.

Tippen Sie auf eine der Seiten, um diese zu öffnen.

### 1.4 Anzeigeeinstellungen

Durch Tippen auf die Schaltfläche Anzeigeeinstellungen wird das Dialogfeld Anzeigeeinstellungen geöffnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/04-4-viewing-settings.png)

Hier können Sie entscheiden, wie Ihr Anzeigemodus sein soll:

_Einzelne Seite_ - Standard

Hier sehen Sie jeweils eine Seite.

**Doppelseite**

Hier sehen Sie zwei Seiten nebeneinander.

**Lesemodus**

Hier sehen Sie eine vereinfachte Version des Dokuments mit leicht lesbaren, fetten Überschriften und entfernten Rändern.

Deckelmodus

Dies ist dasselbe wie die Doppelseite, aber der erste Bildschirm zeigt nur den Umschlag.

Dieser Modus kann schön sein, wenn Sie das vertikale Scrollen deaktivieren.

**Vertikales Scrollen**

Standardmäßig ist das vertikale Scrollen aktiviert, kann aber deaktiviert werden, wenn Sie stattdessen horizontal scrollen möchten.

**Im Uhrzeigersinn drehen**

Drehen Sie Ihr Dokument um 90 Grad im Uhrzeigersinn.

Jede Seite wird einzeln gedreht und die Scrollrichtung bleibt erhalten.

## 3. Offene Dateiformate

Bei Catenda arbeiten wir gerne mit offenen Standards, damit jeder zusammenarbeiten kann, unabhängig von der Software, die er besitzt.

_Typischerweise kann jeder an ihrer Entwicklung teilnehmen, da sie von Natur aus offen sind ([Wikipedia](https://en.wikipedia.org/wiki/Open_standard#:~:text=Typically%2C%20anybody%20can%20participate%20in%20their%20development%20due%20to%20their%20inherently%20open%20nature.))_

Das bedeutet, dass nicht nur eine Organisation kontrolliert, was entwickelt wird.

### 4.1 IFC-Versionen

Abhängig vom Status der IFC-Version unterstützen wir die Version auf unterschiedliche Weise:

_Offiziell, Veraltet_ - Vollständige Unterstützung. Alle offiziellen und veralteten IFC-Versionen werden unterstützt.

_Zurückgezogen_ - Teilweise Unterstützung. Modelle werden nach der letzten offiziellen Version verarbeitet.

_In Entwicklung_ - Keine Unterstützung. Diese können sich vor der Veröffentlichung noch ändern.

Sie finden offizielle IFC-Versionen [hier](https://technical.buildingsmart.org/standards/ifc/ifc-schema-specifications/)

Offizielle BuildingSMART-Beispiel-IFC-Dateien finden Sie [hier](https://github.com/buildingSMART/Sample-Test-Files)

Punkte in Punktwolken können entweder mit Farbe oder Intensität angezeigt werden.

## 6. Proprietäre Dateiformate

Es gibt viele Dateiformatstandards, die von Organisationen entwickelt wurden und von vielen verwendet werden.

Es ist wichtig für uns, dass es einfach ist, Catenda zu verwenden. Daher tun wir unser Bestes, um so viele der häufigsten verwendeten Dateitypen wie möglich zu unterstützen.
