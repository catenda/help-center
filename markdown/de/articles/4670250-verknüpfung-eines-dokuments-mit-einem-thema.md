# Verknüpfung eines Dokuments mit einem Thema

Es gibt zwei Möglichkeiten, um ein Dokument zu einem Thema hinzuzufügen.

1\. Fügen Sie ein vorhandenes Dokument aus einer Bibliothek in Catenda Hub hinzu (Dokumente, Sharepoint oder Links)

![18D20364-879B-4E62-A4C1-0B70C56731F1.GIF](https://raw.githubusercontent.com/catenda/help-center/main/images/8gk0dtb1/01-intro.gif)

2\. Laden Sie ein neues Dokument aus dem Datei-Explorer von Ihrem Computer hoch

![71E8048C-9DFD-4DCC-A482-62DC812E7D11.GIF](https://raw.githubusercontent.com/catenda/help-center/main/images/8gk0dtb1/02-intro.gif)
