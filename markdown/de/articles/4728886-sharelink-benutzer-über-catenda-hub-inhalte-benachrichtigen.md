# ShareLink – Benutzer über Catenda Hub-Inhalte benachrichtigen

> Benutzer manuell benachrichtigen, wenn nötig und wichtig.

Suchen Sie die ShareLink-Schaltfläche in der [oben rechts auf der Seite](https://support.catenda.com/en/articles/4670260-landing-page#h_7e60f1b700) neben Ihrem Profilbild.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/01-intro.png)

Wenn Sie sich auf der Hauptseite befinden, bevor Sie ein Projekt öffnen, wird die ShareLink-Schaltfläche ausgegraut. Es ist nur möglich, Seiten innerhalb eines Projekts freizugeben.

## 1. **Benutzer benachrichtigen**

Möchten Sie ein Projektmitglied über ein Dokument, einige Themen oder andere Inhalte in Catenda Hub benachrichtigen, ohne Catenda Hub zu verlassen? Oder haben Benutzer möglicherweise ihre Catenda Hub-Benachrichtigungen deaktiviert? Diese Funktion löst diese Probleme.

ShareLink sendet eine E-Mail von Catenda Hub an die von Ihnen ausgewählten Projektmitglieder mit einem Link zu dem Inhalt, den Sie freigeben möchten.

> **Hinweis:** Benutzer erhalten immer eine Benachrichtigung über einen Link, der auf diese Weise mit ihnen geteilt wird. Auch wenn sie ihre Benachrichtigungen deaktiviert haben.

### 1.1 **So verwenden Sie ShareLink:**

1. Wählen Sie zunächst bis zu 100 Inhaltselemente aus, die Sie freigeben möchten.

Beispielsweise einige Dokumente oder Themen.

Ein ShareLink-Empfänger sieht dann nur diese Elemente. Wenn die Seite mit einem ShareLink-Empfänger geteilt wird, sieht er die ganze Seite, einschließlich Filter, basierend auf seinem Zugriff im Projekt.

1. Klicken Sie auf die ShareLink-Schaltfläche.
   ​

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/02-to-use-sharelink.png)

## 2. **ShareLink-Fenster**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/03-sharelink-window-br.png)

### 2.1 **Empfänger**

Wählen Sie die Projektmitglieder aus, denen Sie die Nachricht senden möchten. Sie können Teams auswählen, indem Sie @ eingeben. Sie können auch einfach eine Nachricht an alle Benutzer im Projekt auf diese Weise senden.

> **Hinweis:** Wenn Sie von außerhalb des Empfängerfelds klicken und ziehen, können Sie alle Empfänger auswählen. Dies ist sehr nützlich, wenn Sie die E-Mails aller Benutzer im Projekt kopieren möchten. Das Empfängerfeld kann kopiert und in das Empfängerfeld An: einer beliebigen E-Mail-Anwendung eingefügt werden.

### 2.2 **Thema**

Ändern Sie den Titel der Nachricht dem Grund für die Freigabe des Inhalts entsprechend

### 2.3 **Nachricht**

Schreiben Sie Ihre eigene Nachricht in den Nachrichtentext.

### 2.4 **Freigegebener Inhalt**

Die URL, die Sie senden werden, ist hier verfügbar zur Überprüfung.

### 2.5 **Bildschirmfoto**

Wenn Sie sicherstellen möchten, dass der Benutzer weiß, was er beim Klicken auf den Link erwartet, können Sie einen Screenshot des Links, den Sie freigeben, hinzufügen. In diesem Fall wird das folgende Bild an die ShareLink-E-Mail-Benachrichtigung angehängt:

![Screenshot des geteilten Inhalts](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/04-screenshot.png)

## 3. **Die Nachricht senden**

Die Nachricht wird von [noreply@catenda.com](mailto:noreply@catenda.com) an die in Schritt 1 ausgewählten Empfänger gesendet. Sie erhalten eine Kopie an Ihre eigene E-Mail.

Die E-Mail-Nachricht kann so aussehen, wenn Sie einen Screenshot hinzugefügt haben:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/05-send-the-message.png)

## 4. **Zugriff auf den Inhalt**

1. Klicken Sie auf diesen Link und Catenda Hub öffnet eine Seite mit den freigegebenen Elementen.

oder

1. Kopieren Sie diese URL in Ihren Browser.

Wenn dem Link gefolgt wird, werden nur die ausgewählten Elemente angezeigt:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/06-accessing-the-content.png)

Ausgewählte Elemente funktionieren sowohl für Themen als auch für Dokumente.
