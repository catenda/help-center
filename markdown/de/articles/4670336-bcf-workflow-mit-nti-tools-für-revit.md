# BCF-Workflow mit NTI Tools für Revit

**BCF von Revit mit NTI Tools zu Bimsync.**

Gehen Sie zur NTItools-Symbolleiste und öffnen Sie die BCF-Zusammenarbeit. Hier können Sie sich mit dem Bimsync-Server in Ihrem Projekt synchronisieren, indem Sie auf "Öffnen" klicken, dann das Bimsync issue board öffnen und sich bei Ihrem Bimsync-Konto anmelden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/01-intro.png)

Dort können Sie alle Ihre Probleme sehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/02-intro.png)

Issue hinzufügen und die zugehörigen Informationen ausfüllen. Wenn Sie die zugehörigen Elemente vor diesem Schritt ausgewählt haben, werden sie automatisch in die Issue aufgenommen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/03-intro.png)

Klicken Sie auf "Kommentar hinzufügen". Wenn Sie keine Elemente ausgewählt haben, die mit der Issue verbunden sind, klicken Sie auf "Auswählen" und wählen Sie die zugehörigen Elemente aus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/04-intro.png)

Jetzt wurde eine Issue zur Liste hinzugefügt. Sie können die zugehörigen Elemente sehen und klicken auf "Synchronisieren", um die neu erstellte Issue zu Bimsync zu übertragen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/05-intro.png)

Die in Revit erstellte BCF wurde zu Bimsync hinzugefügt. Dieser Workflow funktioniert in beide Richtungen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/06-intro.png)
