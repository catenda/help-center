# Offline-Modus in Catenda Site

Egal ob Baustelle, Eisenbahntunnel oder tiefes Untergeschoss einer Parkgarage – es besteht eine gute Chance, dass Sie keine Internetverbindung haben. Während dieser Unterbrechung kann Catenda Site weiterhin zur Zusammenarbeit auf tragbaren Geräten genutzt werden. Dieser Artikel beschreibt die verschiedenen Wege, wie Catenda Site ohne Netzwerkzugriff zur Zusammenarbeit verwendet werden kann.

Dieser Artikel enthält Informationen zu den folgenden Themen:

## 1. **Themen-Menü im Offline-Modus**

Ohne Netzwerkverbindung ist das Themen-Menü weiterhin verfügbar.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/01-topics-menu-in-offline-mode.png)

> **Hinweis:** Ohne Netzwerkverbindung **werden Änderungen nicht automatisch übermittelt.** Nach der Wiederverbindung mit dem Netz können Änderungen von Ihrer Postausgang aus dem Projekt übermittelt werden.

### 1.1 **Themen-Boards im Offline-Modus**

Hier sehen Sie, wie ein Themen-Board ohne Netzwerkverbindung aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/02-topic-boards-in-offline-mode.png)

Themen, die zuvor geladen wurden, erscheinen als normale Themen.

### 1.2 **Offline-Symbol**

Themen, die ohne Netzwerkverbindung erstellt werden, haben ein Offline-Symbol.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/03-offline-icon.png)

Solange ein Thema ein Offline-Symbol hat, wird es nicht mit dem Projekt synchronisiert.

### 1.3 **Zuvor geladene Themen**

Themen, die zuvor geladen wurden, können ohne Netzwerkverbindung geöffnet werden. Nachdem Sie ein Thema geöffnet haben, wissen Sie, dass Sie sich ein zuvor geladenes Thema im Offline-Modus ansehen, wenn Sie das gelbe Feld "Offline" rechts neben dem Thementitel sehen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/04-previously-loaded-topics.png)

> **Hinweis:** Vorhandene Informationen in Themen, die geladen wurden, als Sie die Verbindung zum Netz verloren haben, können nicht bearbeitet werden.

**Kommentare zu zuvor geladenen Themen:** Zuvor geladene Themen können ohne Netzwerkverbindung kommentiert werden. Bilder von Kamera/Fotos können zum Kommentar hinzugefügt werden. _Erforderlicher Zugriff:_ Vollständiger Zugriff auf das Gerät

Kommentare, die vom angemeldeten Benutzer erstellt wurden, können ohne Netzwerkverbindung bearbeitet und gelöscht werden.

### 1.4 **Neue Themen**

Ohne Netzwerkverbindung ist es weiterhin möglich, ein neues Thema zu erstellen. Nach der Erstellung wird ein Thema noch nicht mit dem Projekt synchronisiert. Wenn Sie ein Thema öffnen, das noch nicht mit dem Projekt synchronisiert wurde, sehen Sie ein Cloud-Symbol links neben dem Thementitel.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/05-new-topics.png)

Wenn die Netzwerkverbindung wiederhergestellt ist, werden diese Themen nicht automatisch mit dem Projekt synchronisiert. Neue Informationen und Änderungen, die im Offline-Modus vorgenommen wurden, können im Postausgang übermittelt werden, wenn die Netzwerkverbindung wiederhergestellt ist.

Die folgenden Informationen können zu einem neuen Thema hinzugefügt werden, das ohne Netzwerkverbindung erstellt wird:

- Ein Titel kann hinzugefügt werden
- Ein Themen-Board kann für das Thema ausgewählt werden
- Status/Typ kann geändert werden
- Ein Meilenstein kann hinzugefügt werden
- Etiketten können hinzugefügt werden
- Eine Beschreibung kann geschrieben werden
- Kommentare können hinzugefügt werden.
  - Bilder von Kamera/Fotos können zu Kommentaren hinzugefügt werden.

    _Erforderlicher Zugriff:_ Vollständiger Zugriff auf das Gerät

- Wenn Modelle vor dem Verlust der Netzwerkverbindung geladen wurden, kann einem Thema eine Position hinzugefügt werden, indem Sie einen Marker in der 2D-Ansicht dieser Modelle platzieren.

**Bearbeiten und Absenden neuer Themen**

- Sie wissen, dass Sie sich ein neues Offline-Thema ansehen, wenn Sie oben im Thema einen grauen Balken sehen.
- Es ist möglich, Themen im Offline-Modus zu bearbeiten, die noch nicht über den [Postausgang](#h_ff2a47f221) übermittelt wurden

### 1.5 **Postausgang**

Wenn neue Informationen und Änderungen in einem Themen-Board im Offline-Modus vorgenommen wurden, wird oben rechts des Themen-Boards ein Postausgang-Symbol angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/06-outbox.png)

Tippen Sie auf das Symbol, um den Postausgang zu öffnen. Nach Wiedererlangung des Netzwerkzugriffs können neue Informationen und Änderungen in diesem Menü zum Projekt übermittelt werden.

**Lokale Entwürfe:** Die Themen in dieser Liste können als lokale Entwürfe bis zur Übermittlung angesehen werden. Wenn neue Themen erstellt oder vorhandene Themen ohne Netzwerkverbindung kommentiert wurden, landen sie in dieser Liste.

**Postausgang übermitteln:** Alle neuen Informationen und Änderungen, die ohne Netzwerkverbindung vorgenommen werden, bleiben auf dem Gerät, bis der Postausgang übermittelt wird. Wenn die Netzwerkverbindung wiederhergestellt ist, kann der Postausgang übermittelt werden. Neue Informationen und Änderungen, die vorgenommen wurden, während keine Verbindung zum Netz bestand, werden dann mit dem Projekt synchronisiert und sind für alle Projektmitglieder sichtbar.

## 2. **Modelle im Offline-Modus**

Wenn die Netzwerkverbindung unterbrochen wird, ist es möglich, Modelle weiterhin zu verwenden, die zuvor auf das Gerät geladen wurden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/07-models-in-offline-mode.png)

### 2.1 **Zuvor geladene Modelle**

In der 2D-Ansicht von Modellen, die geladen wurden, bevor die Netzwerkverbindung unterbrochen wurde, können Themen mit 2D-Ansichtsposition ohne Netzwerkverbindung erstellt werden. Zuvor geladene Modelle können ohne Funktionsverlust ein- und ausgeschaltet werden.

## 3. **Dokumente im Offline-Modus**

Wenn die Netzwerkverbindung unterbrochen wird, können Dokumente weiterhin verwendet werden.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b8ttbe3j/08-documents-in-offline-mode.png)

### 3.1 **Zuvor geladene Dokumente**

Dokumente im Ordner oder in der Sammlung, die geöffnet wurde, als die Verbindung unterbrochen wurde, können weiterhin angezeigt werden. Solange dieser Ordner oder diese Sammlung offen bleiben, können die Dokumente im Ordner weiterhin angezeigt werden, während andere Teile der Anwendung verwendet werden. Der Zugriff auf die Dokumente im Ordner ist nur verfügbar, während Sie sich im Ordner oder in der Sammlung befinden. Wenn Sie zu einem anderen Ordner oder einer anderen Sammlung navigieren, werden die Dokumente entladen. Dokumente, die sich nicht im selben Ordner befinden, können in einer Sammlung zusammengefasst werden. Auf diese Weise können alle Dokumente geladen werden, bevor Sie den Zugriff auf das Netzwerk für die Offline-Nutzung verlieren.
