# Fehlerbehebung bei der Genehmigungsdateiüberprüfung

## 1. **Eingezogenes Dokument**

Dokumentversionen, die Teil von Genehmigungsanfragen sind, können im Dokumentbereich eingezogen werden. So sieht es aus, wenn die Seite für eine Dokumentversion geladen wird, die nach dem Hinzufügen zu einer Genehmigungsanfrage eingezogen wird.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/pew9gsvy/01-withdrawn-document.png)

Dokumentversionen, die der Genehmigung hinzugefügt und später eingezogen wurden, können aus der Genehmigungsanfrage verworfen werden.

## 2. **Gelöschtes Dokument**

Dokumente, die Teil von Genehmigungsanfragen sind, können im Dokumentbereich gelöscht werden. So sieht es aus, wenn die Seite für ein Dokument geladen wird, das nach dem Hinzufügen zu einer Genehmigungsanfrage gelöscht wird.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/pew9gsvy/02-deleted-document.png)

Nach einigen Sekunden wird eine Fehlermeldung angezeigt, die wie folgt aussehen kann:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/pew9gsvy/03-deleted-document.png)

Dokumente, die einer Genehmigung hinzugefügt und später gelöscht wurden, können entweder von einem Administrator wiederhergestellt oder aus der Genehmigungsanfrage verworfen werden.
