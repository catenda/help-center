# Projektpanels

Auf Projektebene werden die Hauptpanelschaltflächen immer oben rechts angezeigt, unabhängig von der Projektseite.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/01-intro.png)

So können die Panelsymbole oben rechts aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/02-intro.png)

Auf Geräten mit begrenztem Bildschirmplatz wird stattdessen eine Schaltfläche namens Ansicht angezeigt. Klicken Sie auf Ansicht, um zwischen den verschiedenen Panels zu wechseln.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/03-intro.png)

## 1. **Panels öffnen**

Panels können auf verschiedene Arten geöffnet werden.

### 1.1 **Automatisch geöffnet**

Standardmäßig wird beim Öffnen eines Projekts von der Projektseite die Inhaltsseite geöffnet und die Dashboard-Seite angezeigt. Es gibt mehrere Situationen, in denen das Modell-Viewer-/3D-Panel automatisch geöffnet wird.

### 1.2 **Manuelles Öffnen und Schließen von Panels**

**Geräte mit größeren Bildschirmen** Wenn ein Panel geöffnet ist, wird es grün hervorgehoben. Wählen Sie ein Panel aus, das noch nicht aktiv ist, um es nebeneinander mit den anderen aktiven Panels zu öffnen. Wählen Sie ein aktives Panel aus, um es zu deaktivieren. Es muss mindestens ein Panel gleichzeitig aktiv sein. Um beispielsweise vom Inhaltsbereich zum 3D-Panel zu wechseln, aktivieren Sie zunächst das 3D-Panel zusammen mit dem Inhaltsbereich und deaktivieren Sie dann den Inhaltsbereich, um nur das 3D-Panel aktiv zu haben.

Um leicht zwischen den verschiedenen Panels zu wechseln, können Tastenkombinationen verwendet werden. Umschalt+1 für den Hauptinhaltsbereich Umschalt+2 für das Modell-Viewer-Panel Umschalt+3 für das Modellbaum-Panel Umschalt+4 für das Modell-Infos-Panel

**Geräte mit begrenztem Bildschirmplatz** Das offene Panel hat einen grauen Hintergrund. Wählen Sie ein anderes Panel aus, um zu diesem Panel zu wechseln. Bei begrenztem Bildschirmplatz kann nur ein Panel gleichzeitig geöffnet sein.

## 2. **Hauptinhaltsbereich**

Das Hauptinhalts-Panel ist das erste Panel und enthält die meisten Informationen. Einige Benutzer arbeiten ausschließlich im Inhaltsbereich. Dieses Panel wird auch als Inhaltsbereich bezeichnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/04-main-content-panel.png)

Das Inhalts-Panel kann die folgenden Hauptseiten enthalten:

Dashboard Modelle Themen Dokumente Bibliotheken Berichte Benachrichtigungen Einstellungen

Klicken Sie [hier](https://support.catenda.com/en/articles/8212646-dashboard-page), um mehr über das Inhalts-Panel zu erfahren.

## 3. **Modell-Viewer-Panel**

Das Modell-Viewer-Panel ist das zweite Panel. Dieses Panel wird auch als 3D-Viewer-Panel bezeichnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/05-model-viewer-panel.png)

Das Modell-Viewer-Panel kann die folgenden Hauptseiten enthalten:

3D-Viewer-Tools 2D-Viewer

Klicken Sie [hier](https://support.catenda.com/en/articles/8227211-3d-viewer), um mehr über das 3D-Panel zu erfahren.

## 4. **Modellbaum-Panel**

Das Modellbaum-Panel ist das dritte Panel. Dieses Panel wird auch als Baum-Panel bezeichnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/06-model-tree-panel.png)

Das Baum-Panel kann die folgenden Hauptseiten enthalten:

Containment-Baum Komponenten-Baum Typ-Baum Ebenen-Baum System-Baum

Klicken Sie [hier](https://support.catenda.com/en/articles/4670290-trees-panel), um mehr über das Baum-Panel zu erfahren.

## 5. **Modell-Infos-Panel**

Das Modell-Infos-Panel ist das vierte und letzte Panel. Dieses Panel wird auch als Inspect-Panel bezeichnet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/07-model-info-panel.png)

Das Inspect-Panel kann die folgenden Hauptseiten enthalten:

Inspect QTO (Quantity Take-Off) 4D-Auswahl Messen

Klicken Sie [hier](https://support.catenda.com/en/articles/4670285-inspect-menu), um mehr über das Inhalts-Panel zu erfahren.
