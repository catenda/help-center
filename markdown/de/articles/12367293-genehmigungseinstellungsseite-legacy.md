# Genehmigungseinstellungsseite - Legacy

Die Genehmigungseinstellungsseite kann durch Klicken auf die Genehmigungseinstellungsaktion im Aktionsmenü rechts neben der grünen Schaltfläche Plus auf der [Genehmigungsseite](https://support.catenda.com/en/articles/8349340-approvals-page) aufgerufen werden. _Erforderlicher Zugriff_: Administrator

Das Banner auf der Genehmigungseinstellungsseite könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/01-intro.png)

## 1. **Aktionen auf der Genehmigungseinstellungsseite**

Die Aktionen der Genehmigungseinstellungsseite können durch Klicken auf das Aktionsmenü oben rechts auf der Genehmigungseinstellungsseite aufgerufen werden. Die Aktionen der Genehmigungseinstellungsseite könnten etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/02-actions-on-the-approvals-settings-page.png)

Klicken Sie [hier](https://support.catenda.com/en/articles/12367730-topic-templates-page), um mehr über die Themenvorlagenseite zu erfahren.

## 2. **Veröffentlichungsoptionen**

Wählen Sie das Standardverhalten aus, das auftritt, wenn eine veröffentlichte Überarbeitung in einem Dokument als Ergebnis einer endgültigen Validierung in einer Genehmigung erstellt wird. Die Genehmigungseinstellungsseite könnte etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/03-publish-options.png)

Das ist, wie die Genehmigungseinstellungsseite aussehen kann, nachdem veröffentlichte Status für jedes Ergebnis erstellt und konfiguriert wurden sowie Themenvorlagen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/04-publish-options.png)

### 2.1 **Dateiprüfstatus**

Die folgenden Genehmigungsvalidierungsergebnisse können bei endgültiger Validierung unterschiedliches Themenersteilungsverhalten verursachen:

- Genehmigt
- Genehmigt mit Kommentar
- Genehmigung ausstehend
- Abgelehnt

### 2.2 **Dokumentstatus**

Klicken Sie auf das Dropdown-Menü Dokumentstatus, um einen Status aus der Liste der veröffentlichten Status im Projekt auszuwählen oder keinen Status festzulegen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/05-document-status.png)

Um die Status im Projekt zu bearbeiten, gehen Sie zum Status-Workflow-Menü der [Dokumenteinstellungsseite](https://support.catenda.com/en/articles/7831371-document-settings-page).

### 2.3 **Themenvorlage**

Wenn eine Themenvorlage konfiguriert ist, kann ein Thema für jede veröffentlichte Überarbeitung erstellt werden, die als Ergebnis einer endgültigen Validierung in einer Genehmigungsanfrage erstellt wird. Wenn eine Markierung auf einer Entwurfsüberarbeitung während des Genehmigungsprozesses erstellt wird, wird für jeden Satz von Anmerkungen in der Markierung ein Kommentar im erstellten Thema hinzugefügt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/06-topic-template.png)

**Themen nicht erstellen / Markierungen nicht speichern** Standardmäßig ist die Einstellung auf Themen nicht erstellen gesetzt, die durch Auswahl von Markierungen nicht speichern in der Dropdown-Liste zurückgesetzt werden kann.

**Neue Themenvorlage erstellen** Klicken Sie [hier](https://support.catenda.com/en/articles/12372007-creating-a-new-topic-template), um mehr über das Erstellen einer Themenvorlage zu erfahren.

**Themenvorschau** Wenn eine Themenvorlage ausgewählt ist, klicken Sie auf das Auge neben der Vorlage, um den Inhalt dieser Themenvorlage anzuzeigen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/07-topic-template.png)

### 2.4 **Speichern**

Klicken Sie auf Speichern, um die Änderungen zu speichern

## 3. **Neuer Validierungsworkflow**
