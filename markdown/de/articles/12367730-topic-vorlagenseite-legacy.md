# Topic-Vorlagenseite - Legacy

Die Topic-Vorlagenseite kann durch Klicken auf die Topic-Vorlagenaction im Actionmenü oben rechts auf der [Topic-Einstellungsseite](https://support.catenda.com/en/articles/12367293-approval-settings-page#h_320e990d50) aufgerufen werden. _Erforderlicher Zugriff_: Administrator

So kann die Topic-Vorlagenseite aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/01-intro.png)

## 1. **Actions auf der Topic-Vorlagenseite**

Die Actions der Topic-Vorlagenseite können durch Klicken auf das Actionmenü rechts der grünen Plus-Schaltfläche oben rechts auf der Topic-Vorlagenseite aufgerufen werden. So können die Actions der Topic-Vorlagenseite aussehen, wenn Sie Topic-Vorlagen anzeigen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/02-actions-on-the-topics-templates-page.png)

So können die Actions der Topic-Vorlagenseite aussehen, wenn Sie archivierte Topic-Vorlagen anzeigen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/03-actions-on-the-topics-templates-page.png)

### 1.1 **Neue Topic-Vorlage**

Klicken Sie auf die Action "Neue Topic-Vorlage", um eine neue Topic-Vorlage zu erstellen. Klicken Sie [hier](https://support.catenda.com/en/articles/12372007-creating-a-new-topic-template), um mehr über das Erstellen neuer Topic-Vorlagen zu erfahren.

### 1.2 **Topic-Vorlagen / Archivierte Topic-Vorlagen**

Klicken Sie auf die Actions "Topic-Vorlagen" und "Archivierte Topic-Vorlagen", um zwischen der Anzeige von Topic-Vorlagen und archivierten Topic-Vorlagen zu wechseln.

## 2. **Topic-Vorlagenkarte**

Nach dem Erstellen einer Topic-Vorlage wird eine Karte für die Topic-Vorlage auf dieser Seite angezeigt. Klicken Sie auf eine Topic-Vorlagenkarte, um die [Topic-Vorlagenseite](https://support.catenda.com/en/articles/12371549-topic-template-page) dieser Topic-Vorlage zu öffnen. So kann eine Topic-Vorlagenkarte aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/04-topic-template-card.png)

### 2.1 **Topic-Vorlagentitel**

Der Titel der Topic-Vorlage

### 2.2 **Topic-Vorlage erstellt von**

Der Ersteller der Topic-Vorlage

### 2.3 **Titel**

Der Titel, den das Topic haben wird. Standardmäßig ist es so eingestellt, dass es den Namen der Genehmigungsanfrage und den Namen des Dokuments erhält, dessen Validierungsergebnis zur Erstellung dieses Topics führte.

### 2.4 **Topic-Board**

**Board** Das Topic-Board, in dem das Topic erstellt wird.

**Status** Der Status, den das Topic haben wird

**Typ** Der Typ, den das Topic haben wird

### 2.5 **Fälligkeit**

Das Fälligkeitsdatum, das auf das Topic angewendet wird.

### 2.6 **Milestone**

Der Milestone, der auf das Topic angewendet wird.

### 2.7 **Zugewiesen**

Das Mitglied, dem das Topic zugewiesen ist. Standardmäßig ist dies der Herausgeber der Genehmigung.

### 2.8 **Angefordert von**

Das Mitglied, das das Topic anfordert. Standardmäßig ist dies der Uploader der Revision, deren Validierungsergebnis zur Erstellung dieses Topics führte.

### 2.9 **Etiketten**

Die Etiketten, die beim Erstellen auf das Topic angewendet werden.

### 2.10 **Beschreibung**

Die Beschreibung, die das generierte Topic haben wird. Standardmäßig enthält das generierte Topic einen Link zur Genehmigungsanfrage sowie einen Link zur Dokumentversion in der Genehmigungsanfrage.

## 3. **Neuer Validierungs-Workflow**

Die Topic-Vorlagenseite ist nicht für Projekte verfügbar, die mit dem neuen Validierungs-Workflow beginnen.
