# Modellkonfiguration

Modelle können als Container für IFC-Datei-Revisionen betrachtet werden, ähnlich wie Dokumente Container für Dateien sind. Der Unterschied zwischen einem Modell und einem Dokument besteht darin, dass der Inhalt einer IFC-Datei in einem Modell vollständig verarbeitet wird, mit allen IDs und Daten, die mit Objekten verbunden sind, und einen generierten 2D-Plan pro Geschoss hat. Benutzer haben oft ein oder mehrere Modelle pro Fachgebiet. Modelle können auf der [Modellseite](https://support.catenda.com/en/articles/4670270-model-overview-page) im Inhaltspanel aufgerufen und konfiguriert werden. Sie können auch im Revision-Selector im 3D-Viewer-Panel gesehen werden, um sie schnell ein- und auszuschalten, ohne das Inhaltspanel zu öffnen.

## 1. Benutzern erlauben, Modelle zu erstellen

Administratoren können Modelle erstellen, aber manchmal möchten Sie es dem Modellierer selbst ermöglichen, neue Modelle zu erstellen, ohne dass dieser unbedingt alle Dokumente sehen muss. In diesem Fall können Sie jemandem in den [Projekteinstellungen](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3) erlauben, Modelle zu erstellen. Wenn Sie Zugriff zum Erstellen von Modellen in den Projekteinstellungen erhalten haben, können Sie diese erstellen und löschen, indem Sie auf die [neue Modell-Schaltfläche](https://support.catenda.com/en/articles/4670270-model-overview-page#h_0c6f0e7347) oben rechts klicken und dann auf die drei Punkte neben Export und anschließend auf [Modell löschen](https://support.catenda.com/en/articles/4670270-model-overview-page#h_0c6f0e7347).
