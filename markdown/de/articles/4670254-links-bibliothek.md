# Links-Bibliothek

Sie finden die Links-Bibliothek als zweite Bibliothek auf der [Bibliotheken-Seite](https://support.catenda.com/en/articles/8065645-libraries-page). Dort können Sie auf den Stern auf der linken Seite klicken, um die Links-Bibliothek immer in Ihrem linken Navigationsmenü im Projekt anzuzeigen.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/01-intro.png)

## 1. **Obere Schaltflächen**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/02-top-buttons.png)

### 1.1 **Neuer Link**

Klicken Sie auf die grüne Schaltfläche "Neuer Link", um einen neuen Link zu erstellen

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/03-new-link.png)

_URL_ - Fügen Sie die URL ein, die Sie als Link in der Link-Bibliothek haben möchten. _Name_ - Wählen Sie einen Namen für den Link

Denken Sie daran, auf "Absenden" zu klicken

### 1.2 **Hamburger-Menü**

Neue Bibliothek - Führt Sie zur Seite zur Erstellung einer Bibliothek

## 2. **Filterung in der Links-Bibliothek**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/04-filtering-in-the-links-library.png)

Klicken Sie auf die Filterschaltfläche, um die verschiedenen möglichen Filter anzuzeigen. In der Links-Bibliothek können Sie nach folgendem filtern: _Verknüpft_ - `link=linked` _Nicht verknüpft_ - `link=unlinked` _Mit ausgewählten Objekten verknüpft_ - `link=backlink`

## 3. **Spalten**

_Kontrollkästchen_ - Ermöglicht es Ihnen, den Link auszuwählen, was dazu führt, dass das rechte Informationsfeld angezeigt wird. _Name_ - Der Name des Links _URL_ - Bietet Ihnen eine Schaltfläche zum Anklicken, um zur URL des Links zu gelangen

**Links** Wenn Objekte mit diesem Link verknüpft wurden, sehen Sie hier die Anzahl der Objekte, die mit diesem Link verknüpft sind. Wenn Sie auf diese Anzahl klicken, können Sie: Die verknüpften Objekte im [3D-Viewer](https://support.catenda.com/en/articles/8227211-3d-viewer) auswählen Die verknüpften Objekte im [3D-Viewer](https://support.catenda.com/en/articles/8227211-3d-viewer) isolieren Die verknüpften Objekte als [Abfrage](https://support.catenda.com/en/articles/4854514-queries) im [3D-Viewer](https://support.catenda.com/en/articles/8227211-3d-viewer) laden
