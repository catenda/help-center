# Projektmitgliedschaften - Organisationswerkzeug

Sie können die Projektseite als Unterseite auf Ihrer [Organisationsprofilseite](https://support.catenda.com/en/articles/8497478-organization-profile-page) finden. Hier sehen Sie einen Überblick über alle Mitglieder, die Teil von Projekten sind, die zu dieser Organisation gehören.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/01-intro.png)

## 1. **Suchen und filtern**

Auf der Seite "Mitglieder" können Sie nach Folgendem filtern:

### 1.1 **Leere Filter ausblenden**

Der Schalter "Leere Filter ausblenden" ist standardmäßig deaktiviert, d. h. Sie sehen alle möglichen Filter. Sie können diese Filterschaltfläche aktivieren, um Filter auszublenden, die keine Ergebnisse haben.

### 1.2 **Projekt -** `project=<Project GUID>`

Mit diesem Filter können Sie alle Einträge eines Projekts filtern

### 1.3 **Rolle -** `role=administrator,member`

Mit diesem Filter können Sie filtern, ob ein Benutzer ein Administrator oder ein Mitglied eines Projekts ist

### 1.4 **Benutzer -** `user=<User GUID>`

Mit diesem Filter können Sie alle Einträge filtern, die zu einem Benutzer gehören

## 2. **Aktionsschaltflächen**

Nachdem Sie ein oder mehrere Mitglied(er) in der Projektmitgliederliste ausgewählt haben, indem Sie auf das Kontrollkästchen klicken, werden die folgenden Aktionsschaltflächen oben in der Projektliste angezeigt.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/02-action-buttons.png)

### 2.1 **Zu Projekten hinzufügen**

Fügen Sie einen oder mehrere Benutzer zu Organisationsprojekten hinzu, ohne Teil des Projekts sein zu müssen

### 2.2 **Projektrolle(n) ändern**

Ändern Sie die Projektrolle von einem oder mehreren Benutzern, ohne Teil des Projekts sein zu müssen

### 2.3 **Aus Projekt(en) entfernen**

Entfernen Sie einen oder mehrere Benutzer, ohne Teil des Projekts sein zu müssen

## 3. **Projektmitgliederliste**

In der Projektmitgliederliste sehen Sie einen Eintrag pro Mitglied pro Projekt. Wenn ein Mitglied Teil vieler Projekte ist, werden möglicherweise viele Einträge für alle Projekte angezeigt. Um dieses Mitglied in einem bestimmten Projekt zu finden, können Sie den Projektfilter verwenden, um Ihre Suche einzugrenzen. Die Mitgliederliste kann etwa so aussehen:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/03-project-membership-list.png)

### 3.1 **Kontrollkästchen**

Mit dem Kontrollkästchen oben können Sie alle Mitglieder auswählen, die Teil von Projekten sind, die Ihre Organisation besitzt. Klicken Sie erneut, um die Auswahl aller aufzuheben. Mit dem Kontrollkästchen neben einem Mitglied können Sie ein Mitglied hinzufügen oder aus Ihrer Auswahl entfernen

### 3.2 **Benutzer**

Das Profilbild, der Benutzername und die E-Mail-Adresse jedes Mitglieds. Mitglieder werden einmal für jedes Projekt angezeigt, an dem sie beteiligt sind.

### 3.3 **Rolle**

Ob das Mitglied ein reguläres Mitglied oder ein Administrator ist

### 3.4 **Projekt**

Das Projekt, an dem dieses Mitglied beteiligt ist

### 3.5 **Organisation**

Ob das Mitglied ein Benutzer in der Organisation ist oder nicht
