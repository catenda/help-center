# Wie kann ich eine mit einer Etikett verbundene Gruppe entfernen?

Sie können eine Gruppe aus einer Etikett entfernen, indem Sie: 1\. Die Etikett mithilfe des Kontrollkästchens links neben der Etikett auswählen. 2\. Dann "Gruppe festlegen" drücken 3\. "Gruppe entfernen" auswählen 4\. Aktualisieren
