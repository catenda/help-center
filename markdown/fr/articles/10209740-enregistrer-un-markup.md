# Enregistrer un markup

Sélectionnez un [outil d'annotation](https://support.catenda.com/en/articles/11384618-document-preview-tools) dans la barre d'outils au-dessus de l'[aperçu du document](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations). Placez l'annotation pour voir le menu des markups non sauvegardés dans l'[onglet markups](https://support.catenda.com/en/articles/10205725-right-menu-of-a-revision-markups) du menu droit d'une revision.

Lorsqu'un document est ouvert pour la première fois, le menu droit de la revision peut être fermé. Cliquez sur le bouton d'information sur le côté droit de la [bannière du document](https://support.catenda.com/en/articles/8461918-document-banner-actions-navigation) pour développer ce menu.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/01-intro.png)

## 1. **Navigation des sujets pour les markups**

Le menu des markups non sauvegardés se trouve à différents endroits selon qu'un sujet a été navigué ou non dans le menu déroulant de navigation des sujets en haut de l'onglet markups.

### 1.1 **Nouveaux sujets**

Si aucun sujet n'a été navigué dans la navigation des markups en haut de l'onglet, il dira "nouveaux sujets" dans le menu déroulant. Dans ce cas, les markups non sauvegardés sont toujours visibles en haut de l'onglet markups.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/02-new-topics.png)

### 1.2 **Sujets sélectionnés**

Cliquez sur le menu déroulant de navigation des sujets en haut de l'onglet markups pour sélectionner un sujet.

**Commentaires les plus récents en premier** Les commentaires des sujets triés par ordre de récence affichent le menu des nouveaux markups en haut de la section des commentaires.

**Commentaires les plus anciens en premier** Les commentaires des sujets triés par ordre d'ancienneté affichent le menu des nouveaux markups en bas de la section des commentaires. Dans ce cas, vous devrez peut-être faire défiler jusqu'au bas de la section des commentaires pour voir le menu des nouveaux markups.

Cliquez sur un markup pour l'agrandir et le modifier avant de l'enregistrer.

## 4. **Enregistrer les markups**

Les markups sont enregistrés comme des commentaires dans les sujets. Si un markup contient plusieurs ensembles d'annotations répartis sur plusieurs pages, il y aura un commentaire par ensemble d'annotations sur chaque page.

### 4.1 **Sujet sélectionné**

Accédez à un sujet avec le menu déroulant de navigation des sujets en haut de l'onglet markups et sélectionnez un sujet. Cliquez sur enregistrer les markups pour enregistrer tous les markups dans le sujet sélectionné...

> **Remarque:** Chaque ensemble d'annotations sera enregistré dans le même sujet et combiné en un seul grand markup. De cette façon, un nom de markup séparé peut être ajouté pour chaque commentaire créé dans le sujet.

### 4.2 **Nouveaux sujets**

Lorsqu'aucun sujet n'est sélectionné dans le menu déroulant de navigation des sujets en haut de l'onglet markups, il dira nouveaux sujets. Cliquez sur le bouton enregistrer les markups pour ouvrir le dialogue enregistrer les markups qui peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/05-new-topics.png)

Cliquez sur Enregistrer en tant que sujets pour créer un sujet pour chaque markup qui a été créé.

**Titre** Le titre `{documentName} - {markupName}` est suggéré par défaut. Avec ceci, les sujets sont nommés d'après le nom du markup et du document sur lequel il est créé.

**En-tête du sujet** Les champs remplis dans l'en-tête du sujet seront appliqués à chaque sujet de markup créé.

**Description** Remplissez une description qui est ajoutée à chaque sujet de markup créé.

**Commentaires** Un commentaire pour chaque ensemble d'annotations appartenant au markup est ajouté à chaque sujet de markup créé.

## 5. **Nom du markup**

Générez un commentaire pour chaque ensemble d'annotations lorsqu'un markup est enregistré. Le texte écrit dans le champ du nom du markup est ajouté comme texte à chaque commentaire généré.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/06-markup-name.png)

### 5.1 **Rejeter le markup**

Cliquez sur l'icône de la corbeille à droite du nom du markup pour la supprimer.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/07-discard-markup.png)

## 6. **Ensembles d'annotations**

Chaque page d'un document où des annotations sont faites aura son propre ensemble d'annotations. Voici à quoi cela peut ressembler lorsque des annotations sont faites sur plusieurs pages d'un document:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g0sj62y4/08-annotation-sets.png)

### 6.1 **Page du markup**

Le numéro de page indique sur quelle page le markup a été créé.

### 6.2 **Menu des annotations**

Consultez le nombre d'annotations créées pour chaque page. Cliquez sur "annotations" pour développer le menu des annotations et voir les annotations de la page dans une liste. Modifiez ou supprimez l'annotation en cliquant sur les trois points à droite de l'annotation. Modifiez les annotations pour ajouter du texte à côté de cette annotation. Ce texte peut ensuite être trouvé en survolant l'annotation.

### 6.3 **Rejeter un ensemble d'annotations**

Cliquez sur rejeter pour rejeter toutes les annotations créées sur cette page.

### 6.4 **Capture**

Pour chaque ensemble d'annotations, une image de la zone sur la page de la revision où les annotations sont faites est créée. L'image est actualisée chaque fois qu'il y a une modification dans les annotations sur la page. Lorsque de nouvelles annotations sont créées, une image plus grande est créée pour inclure toutes les annotations tandis que l'image peut être ajustée plus petite si une annotation est supprimée. Pour mettre en évidence une partie d'une page, il est recommandé d'utiliser une annotation de rectangle avec une opacité de 0 pour assurer que l'image capture toute la zone dans le rectangle.
