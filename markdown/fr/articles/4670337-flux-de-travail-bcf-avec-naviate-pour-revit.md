# Flux de travail BCF avec Naviate pour Revit

**BCF de Revit avec Naviate vers Bimsync.**

Créer un problème dans Revit avec le gestionnaire BCF de Naviate.

Sélectionnez les éléments pour lesquels vous souhaitez créer un problème et allez au gestionnaire BCF de Naviate. Assurez-vous de sélectionner la version 1.0 ou 2.0. Cliquez sur OK.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/01-intro.png)

Cliquez sur Enregistrer le fichier BCF et enregistrez-le en tant que fichier bcfzip.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/02-intro.png)

Accédez aux problèmes dans bimsync et importez le BCF que vous avez créé dans Revit.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/03-intro.png)

Le BCF sélectionné.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/04-intro.png)

Le BCF est maintenant chargé sous les problèmes dans Bimsync.

Vous pouvez alors modifier les différents paramètres du problème en cliquant dessus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/05-intro.png)

**BCF de Bimsync vers Revit avec Naviate.**

Filtrez le problème que vous souhaitez obtenir.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/06-intro.png)

Exportez les problèmes filtrés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/07-intro.png)

Vous recevrez une notification lorsque le BCF sera exporté. Téléchargez le BCF.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/08-intro.png)

Retournez à Revit pour obtenir le BCF téléchargé.

Ouvrez-le dans le gestionnaire BCF.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/09-intro.png)

Le BCF est chargé dans Revit avec les composants associés. Revit crée une vue individuelle pour le BCF.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/10-intro.png)

Vous pouvez également découper les composants associés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a8twaqnf/11-intro.png)
