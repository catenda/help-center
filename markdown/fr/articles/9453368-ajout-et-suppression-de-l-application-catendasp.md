# Ajout et suppression de l'application CatendaSP

> **Remarque :** Le fichier d'installation du plugin se trouve dans [cet article](https://intercom.help/bimsync-arena/en/articles/8396532-catenda-plugins-and-integrations).

L'application Catenda SharePoint peut être ajoutée à un environnement SharePoint par un propriétaire de site si l'application a été activée pour le client par l'administrateur SharePoint. Avec cette application, les utilisateurs SharePoint pourront afficher, gérer et collaborer sur les Documents dans Catenda avec d'autres Membres du projet de construction.

## 1. **Ajout de l'application**

### 1.1 **Nouvelle expérience**

Pour ajouter l'application à votre site, vous pouvez trouver la nouvelle action d'application dans la section Contenu du site de votre site ou en accédant à votre site et en cliquant sur votre photo de profil pour trouver l'option « Ajouter une application » dans le menu des paramètres.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/01-new-experience.png)

Cela vous amènera à la zone de mes applications de votre boutique d'applications SharePoint où vous pouvez cliquer sur ajouter et cela peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/02-new-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/appStore.aspx/myApps?entry=SettingAddAnApp&sorting=1**

Vous pouvez également cliquer sur le nom de l'application pour obtenir plus d'informations sur l'application et ajouter l'application à partir de sa page d'entrée de magasin :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/03-new-experience.png)

https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/appStore.aspx/appDetail/WA200005981

### 1.2 **Expérience classique**

Pour ceux plus familiers avec l'expérience SharePoint classique, vous pourrez ajouter l'application à votre site en accédant à la section Contenu du site de votre site et en cliquant sur ajouter une application ou en cliquant sur votre photo de profil pour trouver l'option « Ajouter une application » dans le menu des paramètres.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/04-classic-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/viewlsts.aspx**

Cela vous amènera à la zone Vos applications de votre Contenu du site qui peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/05-classic-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/addanapp.aspx?Source=https%3A%2F%2F\<Tenant>%2Esharepoint%2Ecom%2Fsites%2F\<Sitename>%2F%5Flayouts%2F15%2Fviewlsts.aspx**

Si vous cliquez sur l'application sur cette page, elle sera ajoutée à votre site. Si vous cliquez sur Détails de l'application, vous serez dirigé vers l'entrée du magasin SharePoint classique qui peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/06-classic-experience.png)

_https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/storefront.aspx?source=https%3A%2F%2F\<Tenant>%2Esharepoint%2Ecom%2Fsites%2FSharepointTest2%2F%5Flayouts%2F15%2Fviewlsts%2Easpx&sname=Sharepoint%20Test%202#vw=AppDetailsView,app=e39e0641%2D5c83%2D4639%2Dad87%2Dbe9ccf43ab75,clg=1,bm=,cm=_

Cliquer sur « Demander » sur cette page ajoutera l'application à votre site.

## 2. **Installation de l'application**

Immédiatement après l'ajout de l'application Catenda Sharepoint, elle apparaîtra comme un élément grisé dans le contenu du site. Cela peut prendre un certain temps pour s'installer avant de devenir disponible. Voici à quoi cela peut ressembler lors de l'installation de l'application :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/07-installing-the-app.png)

https://_\<Tenant>_.sharepoint.com/sites/\<_Sitename_>/\_layouts/15/viewlsts.aspx?view=14

## 3. **Suppression de l'application**

### 3.1 **Nouvelle expérience**

À l'avenir, il sera possible de supprimer l'application d'un site à partir de son menu hamburger dans la section de contenu du site de votre page.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/08-new-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/viewlsts.aspx?view=14**

Actuellement, il n'est possible de supprimer l'application que dans l'ancienne expérience.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/09-new-experience.png)

Cliquez sur « Retour à SharePoint classique » ou trouvez l'ancienne expérience vers le bas à gauche de la page de contenu du site.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/10-new-experience.png)

### 3.2 **Ancienne expérience**

Pour supprimer l'application Catenda, survolez l'élément d'application sur la page Contenu du site. Cliquez sur les trois points qui apparaissent vers le haut à droite de l'application.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/11-old-experience.png)

**https://\<Tenant>.sharepoint.com/sites/\<Sitename>/\_layouts/15/viewlsts.aspx**

Dans le menu qui s'affiche, cliquez sur supprimer et l'application sera supprimée du site.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vw41y5jc/12-old-experience.png)

Notez que l'application ne sera pas supprimée pour l'ensemble du client et que les propriétaires de sites pourront toujours ajouter l'application à leurs sites.
