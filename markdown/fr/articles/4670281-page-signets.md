# Page Signets

Vous pourrez trouver les signets comme sous-menu de la [page des modèles](https://support.catenda.com/en/articles/4670286-models-page). Cette page fait partie du panneau de contenu. La lecture d'un signet recréera la situation qui était dans la Visionneuse 3D lorsque le signet a été créé.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0ve72xx4/01-intro.png)

S'il y a un ensemble spécifique de modèles que vous ouvrez et avec lesquels vous travaillez, cela peut souvent prendre du temps de cliquer sur le bouton 3D de chaque modèle. Même la sélection des bons modèles sur la [page des modèles](https://support.catenda.com/en/articles/4670286-models-page) et ensuite [l'ouverture de tous en 3D](https://support.catenda.com/en/articles/4670286-models-page#h_9447efb869) peut être long car les modèles doivent souvent être trouvés dans une longue liste de modèles.

## 1. **Boutons supérieurs**

Cliquez sur ce bouton pour créer un [nouveau signet](https://support.catenda.com/en/articles/4670269-creating-a-new-bookmark)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0ve72xx4/02-top-buttons.png)

## 2. **Recherche et filtrage**

Par défaut, le filtre "Mes signets" sera actif. Ici, vous verrez tous les signets que vous avez créés. Si vous appuyez sur le x à droite de la barre de recherche et supprimez tous les filtres, ce filtre s'activera et tous les autres filtres seront supprimés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0ve72xx4/03-search-and-filter.png)

Si les personnes ont choisi de partager leurs signets avec le projet, vous pourrez les trouver en les filtrant.

Pour voir les filtres disponibles, cliquez sur le bouton de filtre à gauche de la barre de recherche. Ici, vous pourrez trouver les filtres suivants :

_Tous_ - `type=all` Tous les signets auxquels vous avez accès

Mes signets - `type=my` - Par défaut Vos signets privés

_Signets en vedette_ - `type=starred` Si vous avez des signets en vedette, vous pourrez voir tous les signets que vous avez [mis en vedette](#h_a2d5caf18c) avec ce filtre.

_Signets partagés_ - `type=shared` Tous les signets que vous avez partagés avec les projets

_URL partagée_ - `type=shared-url` Tous les signets du projet qui ont été partagés en externe

## 3. **Album de signets**

Dans l'album de signets, vous pourrez voir tous les signets qui correspondent aux filtres de la barre de recherche. L'album de signets peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0ve72xx4/04-bookmark-album.png)

Ici, tous les signets seront listés dans l'ordre chronologique. Un signet unique peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/0ve72xx4/05-bookmark-album.png)

Lorsque vous survolez l'image, vous verrez apparaître un bouton de lecture. Si vous cliquez n'importe où sur l'image, le panneau 3D s'ouvrira et le signet sera chargé. Si vous cliquez n'importe où sur la description, vous ouvrirez le signet où vous pouvez modifier ses paramètres. Si le signet a été partagé avec le projet par quelqu'un d'autre, vous verrez une icône "partagé avec le projet". Si le signet a été partagé en externe, vous verrez une icône d'ouverture dans un nouvel onglet.

### 3.1 **Icône en haut à gauche**

**Copier vers mes signets** Si le signet a été partagé avec le projet par quelqu'un d'autre, vous verrez un plus en haut à gauche. Cliquez sur ce bouton pour faire une copie privée de ce signet. Vous saurez si vous avez réussi à en faire une copie lorsque l'icône se transforme en coche et que vous voyez un message en bas de la page où vous pouvez ouvrir votre copie. Vous pourrez également rechercher votre copie après actualisation de la page.

**Signets en vedette** Si vous possédez le signet, vous verrez que l'icône en haut à gauche est devenue une étoile. En cliquant sur cette étoile, vous ajouterez une étoile jaune pour ce signet. Les signets en vedette apparaîtront sur votre [tableau de bord](https://support.catenda.com/en/articles/8212646-dashboard-page#h_6785d4f10c).
