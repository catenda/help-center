# Créer une nouvelle demande d'approbation - Hérité

La nouvelle action de demande d'approbation se trouve en cliquant sur le menu d'action à droite du bouton plus vert sur la [page des approbations](https://support.catenda.com/en/articles/8349340-approvals-page).

## 1. **En-tête d'approbation - Le sujet d'une approbation**

ou en cliquant sur l'action dans l'action de création d'une nouvelle approbation dans le menu des approbations du menu droit d'une révision de brouillon. Il n'est possible de créer de nouveaux flux de travail que dans les projets où tous les statuts de brouillon n'ont pas été archivés ou où les révisions de brouillon ont été téléchargées avant l'archivage de tous les statuts de brouillon.

Voici à quoi peut ressembler l'en-tête d'une nouvelle approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a5gqwxkx/01-approval-header-the-subject-of-an-approval.png)

### 1.1 **Titre**

Le titre de la demande d'approbation. Une approbation doit avoir au minimum un titre pour être soumise.

### 1.2 **Éditeur**

Le Membre éditeur a le dernier mot dans le résultat de la validation des brouillons dans l'approbation en fonction des examens soumis par les relecteurs. Par défaut, l'éditeur est défini sur n'importe qui avec accès, ce qui signifie que n'importe qui peut publier l'approbation après sa création. Cliquez sur la liste déroulante de l'éditeur pour configurer un Membre en tant qu'éditeur.

### 1.3 **Créé par**

Le créateur de l'approbation.

### 1.4 **Échéance / Jalon**

L'échéance et/ou le jalon de l'approbation.

### 1.5 **Relecteurs (optionnel)**

Les relecteurs qui peuvent faire des commentaires, approuver ou refuser les brouillons dans l'approbation peuvent être assignés. _Nombre maximum de relecteurs :_ 20

### 1.6 **Nombre minimum de relecteurs**

Par défaut, le nombre minimum de relecteurs est le nombre de relecteurs qui ont été sélectionnés. Au moins un Membre doit être sélectionné comme relecteur pour soumettre une approbation. Lorsqu'ils travaillent seuls, les créateurs d'approbation peuvent se fixer comme relecteur s'ils seront ceux qui examinent l'approbation qu'ils créent.

Le nombre minimum de relecteurs est le nombre de relecteurs requis pour soumettre un examen afin de publier l'approbation. Le nombre minimum de relecteurs doit être inférieur ou égal au nombre de relecteurs sélectionnés, car il ne peut pas y avoir plus de relecteurs requis que le nombre total de relecteurs. _Nombre minimum de relecteurs : 1_

Si le nombre de relecteurs n'est pas suffisant pour soumettre leur examen, le Membre défini comme éditeur peut forcer la validation finale de l'approbation.

### 1.7 **Corps d'approbation - Le contenu d'une approbation**

Voici à quoi peut ressembler le corps d'une nouvelle approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a5gqwxkx/02-approval-body-the-content-of-an-approval.png)

### 1.8 **Description**

La description de l'approbation suit les [règles générales de formatage des messages](https://support.catenda.com/en/articles/8430847-formatting-of-posts).

### 1.9 **Brouillons**

Les révisions de brouillon dans chaque Document qui doit être validé.

### 1.10 **Ajouter un brouillon**

Cliquez ici pour en savoir plus sur l'ajout de brouillons. N'importe quel nombre de révisions de brouillon dans les Documents peut être ajouté à une demande d'approbation, ce qui aboutit à n'importe quel nombre de sujets créés suite à la publication de la demande d'approbation.

### 1.11 **Soumettre**

Cliquez sur Soumettre pour soumettre l'approbation. Les éléments suivants sont requis pour soumettre la demande d'approbation :

- Minimum 1 révision de brouillon d'un Document
- Un titre.

Après avoir soumis une demande d'approbation, il sera toujours possible d'apporter des modifications à la demande d'approbation.

- D'autres Documents avec des révisions de brouillon peuvent être ajoutés.
- Le titre peut être changé.
- La description peut être changée.
- Les révisions de brouillon peuvent être supprimées de la demande d'approbation.

N'importe quel nombre de révisions de brouillon dans les Documents peut être ajouté à une demande d'approbation.

Dans les nouveaux projets qui sont créés, le nouveau flux de travail de Statut est activé par défaut. Avec le flux de travail de Statut activé, les nouvelles révisions sont téléchargées en tant que révisions partagées au lieu de pouvoir choisir si elles doivent être des brouillons ou publiées lors du téléchargement.

## 2. **Nouvelle demande d'approbation de brouillon**

Dans les projets où des révisions de brouillon ont été soumises avant que le nouveau flux de travail de Statut soit demandé à être activé, les brouillons peuvent continuer à être ajoutés aux approbations avec la nouvelle action de demande d'approbation de brouillon. L'en-tête et le corps fonctionneront tous les deux de la même manière qu'avant avec la demande d'approbation régulière avant que le nouveau flux de travail de Statut ne soit activé.
