# Flux de travail BCF utilisant NTI Tools pour Revit

**BCF de Revit avec NTITools vers Bimsync.**

Accédez à la barre d'outils NTItools et ouvrez la collaboration BCF. Ici, vous pouvez vous synchroniser avec le serveur Bimsync de votre projet en cliquant sur ouvrir, puis en ouvrant le tableau des problèmes Bimsync et en vous connectant à votre compte Bimsync.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/01-intro.png)

Vous pouvez voir tous vos problèmes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/02-intro.png)

Ajouter un problème et remplir les informations connexes. Si vous avez sélectionné les éléments connexes avant cette étape, ils sont automatiquement inclus dans le problème

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/03-intro.png)

Cliquez sur ajouter un commentaire. Si vous n'avez pas sélectionné les éléments liés au problème, cliquez sur sélectionner et choisissez les éléments connexes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/04-intro.png)

Maintenant, un problème a été ajouté à la liste. Vous pouvez voir les éléments connexes et vous cliquez sur synchroniser pour obtenir le problème nouvellement créé sur Bimsync.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/05-intro.png)

Le BCF créé dans Revit est ajouté à Bimsync. Ce flux de travail fonctionne dans les deux sens.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2bk19fa9/06-intro.png)
