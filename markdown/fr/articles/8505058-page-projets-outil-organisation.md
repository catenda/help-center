# Page Projets - Outil Organisation

Vous pourrez trouver la page des projets comme sous-page de votre [page de profil d'organisation](https://support.catenda.com/en/articles/8497478-organization-profile-page).

Ici, vous verrez un aperçu de tous les projets qui font partie de cette organisation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9sr2253p/01-intro.png)

## 1. Rechercher et filtrer

Sur la page des projets, vous pourrez filtrer selon les éléments suivants :

### 1.1 Masquer les filtres vides

Le bouton bascule « Masquer les filtres vides » est désactivé par défaut, ce qui signifie que vous voyez tous les Filtres possibles.

Vous pouvez activer ce bouton de Filtre pour masquer tous les Filtres qui n'ont pas de résultats.

### 1.2 Créé - createdAtFrom=\<UTC timestamp>&createdAtTo=\<UTC timestamp>

Projets qui ont été créés entre deux dates que vous choisissez

### 1.3 Expiré - expiration=expired

Projets qui ont dépassé leur date d'expiration.

### 1.4 Non expiré - expiration=not-expired

Projets qui ne sont pas expirés.

## 2. Boutons d'action

Après avoir sélectionné un ou plusieurs projet(s) dans la liste des projets en cliquant sur leur case à cocher, vous verrez les boutons d'action suivants apparaître vers le haut de la liste des projets.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9sr2253p/02-action-buttons.png)

### 2.1 Ajouter de nouveaux Membres

Si l'utilisateur que vous souhaitez ajouter est un Membre de votre organisation, vous pourrez ajouter le Membre à un projet sans invitation par courrier électronique.

Consultez un aperçu des Membres de votre organisation sur la page utilisateur de l'outil d'organisation.

Dans le menu « Ajouter de nouveaux Membres », vous pouvez également inviter des utilisateurs externes par adresse e-mail sans faire partie du projet.

Si vous souhaitez ajouter un Membre de l'organisation à plusieurs projets, vous pouvez également le faire en sélectionnant l'utilisateur sur la page des utilisateurs et en cliquant sur l'action ajouter aux projets dans le menu d'action de cette page.

### 2.2 Déplacer

Déplacer les projets sélectionnés vers une autre organisation

### 2.3 Rejoindre

Devenir membre des projets sélectionnés

### 2.4 Quitter

Quitter les projets sélectionnés

### 2.5 Supprimer

Supprimer les projets sélectionnés

## 3. Liste des projets

Dans la liste des projets, vous pourrez trouver les colonnes suivantes que vous pouvez trier en ordre croissant et décroissant.

L'ordre de tri de la liste des projets suit l'[ordre de tri des listes](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists) autour de Catenda.

Cliquez sur la case à cocher en haut à gauche de la liste pour sélectionner tous les projets.

### 3.1 Case à cocher

Cochez la case à cocher d'un projet pour le sélectionner.

Après avoir sélectionné un projet, vous verrez le menu d'action apparaître vers le haut de la liste.

Il n'est pas possible de sélectionner les projets qui ont expiré.

### 3.2 Nom

Le nom du projet

Si le projet n'a pas expiré, vous verrez une icône de lien pour ouvrir dans un nouvel onglet à côté du nom.

**Membre**

Sous le nom, vous verrez combien d'utilisateurs sont Membres de ce projet et si vous êtes un Membre de ce projet ou non.

### 3.3 Dernière mise à jour

L'heure et la date de la dernière mise à jour du projet

### 3.4 Créé le

L'heure et la date de création du projet

### 3.5 Expire

L'heure et la date d'expiration du projet.

Si c'est rouge, cela signifie que le projet a expiré.
