# Convention de nommage intermédiaire

Cet article s'appuie sur l'article [convention de nommage la plus simple](https://support.catenda.com/en/articles/7845360-simplest-naming-convention) mais peut être suivi sans l'avoir lu. Il existe un article de suivi intitulé [Convention de nommage avancée](https://support.catenda.com/en/articles/7936947-advanced-naming-convention).

## 1. A001-Nomdefichier.extension

Supposons que vous ayez un code pour vos fichiers locaux qui comporte la première lettre du projet et un numéro qui ressemble à A001, A002, A003, M001, M002, etc. Pour garder votre [section Documents](https://support.catenda.com/en/articles/4670292-documents-page) organisée, vous voulez vous assurer que tous vos fichiers ont ce code. Peu importe que plusieurs fichiers aient le même code, du moment qu'ils l'ont. Cela peut rendre votre [section Documents](https://support.catenda.com/en/articles/4670292-documents-page) plus claire et organisée afin que vous ne vous perdiez pas dans les énormes quantités de fichiers que nous générons de nos jours.

### 1.1 **Configuration initiale**

Ceci est la première étape pour spécifier les préférences de nommage des fichiers. Pour cet exemple, essayons donc d'ajouter un [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) de texte à la convention avec une longueur de 4.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/01-initial-setup.png)

Maintenant, [assignons la convention](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90) à un dossier et essayons de télécharger un fichier nommé text.txt pour voir ce qui se passe.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/02-initial-setup.png)

Comme vous pouvez le voir, nous obtenons une erreur et ne pouvons pas télécharger notre fichier. Bien sûr, c'est parce que j'ai oublié de vous dire d'ajouter un code au nom du fichier.... Désolé.

### 1.2 **Modification du nom de fichier pour respecter la convention**

Si vous vous demandez quel [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) manque, vous pouvez consulter l'[aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) à côté de la convention de nommage en gris. Vous avez maintenant deux façons de modifier le nom de votre fichier pour qu'il puisse être téléchargé avec succès. Vous pouvez soit modifier le nom de votre fichier localement, soit modifier le nom dans la boîte de dialogue de téléchargement. Modifiez le nom en A0001-test.txt et vous verrez OH?!

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/03-changing-the-file-name-to-fit-the-convention.png)

Une fois de plus, le fichier n'a pas été accepté, vous avez été invité à ajouter un zéro de trop au code de votre fichier ! Ne vous inquiétez pas, la convention de nommage vous indiquera quel [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) pose problème et quelle longueur votre code est censé avoir. Maintenant, modifiez le nom du fichier en A001-test.txt et vous verrez que le fichier sera accepté.

### 1.3 **Séparateur**

Assurez-vous d'utiliser un tiret _( - )_ entre les deux [blocs](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) car c'est ce qui a été choisi comme [séparateur](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=in%20document%20settings-,Separator,-%3A%20The%20character). Vous pouvez maintenant télécharger votre fichier.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/getb0xqv/04-separator.png)

Pour en savoir plus sur les conventions de nommage, consultez l'article suivant : [Convention de nommage avancée](https://support.catenda.com/en/articles/7936947-advanced-naming-convention)
