# Nouvelle version de Catenda Site

Nous venons de publier une mise à jour de notre application sur l'App Store et Google Play. Ces nouvelles fonctionnalités sont désormais disponibles :

- Support de l'orientation paysage pour les tablettes.
- Option de plein écran intégrée pour le 2D et le 3D.
- Navigation améliorée dans l'application.
- Amélioration importante des performances.
- Langues néerlandaise et portugaise ajoutées.
