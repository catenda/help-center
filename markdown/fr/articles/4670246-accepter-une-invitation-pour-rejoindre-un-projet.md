# Accepter une invitation pour rejoindre un projet

Le moyen le plus courant de commencer à utiliser Catenda Hub est de recevoir une invitation à un projet.

## 1. Recevoir une invitation

Pour recevoir une invitation à un projet, un utilisateur du projet devra vous inviter avec votre adresse e-mail. Si vous savez quel projet vous souhaitez rejoindre, mais que vous ne savez pas qui a la permission de le faire, veuillez contacter [support@catenda.com](mailto:support@catenda.com) nous vous ferons savoir qui est en mesure de vous inviter.

_Accès requis :_ Administrateur ou accès à l'invitation de Membres sur la page des paramètres du projet.

### 1.1 Notification d'invitation

Si vous avez déjà un compte chez Catenda, vous recevrez la notification suivante.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/01-invite-notification.png)

### 1.2 E-mail d'invitation

Si vous n'avez pas encore de compte, ou même si vos Notifications par e-mail sont complètement désactivées, vous recevrez un e-mail avec l'objet suivant :

> **Conseil :** "(Nom de l'utilisateur qui invite) vous a invité à (Projet Catenda auquel vous êtes invité)."

Voir [ici](https://support.catenda.com/en/articles/8417802-why-am-i-not-receiving-emails) pour le dépannage des e-mails. Vous pouvez accepter l'invitation en cliquant sur la Notification si vous créez un compte sur [https://hub.catenda.com/signup](https://hub.catenda.com/signup) et que vous êtes invité à nouveau, mais il peut être utile d'investiguer pourquoi vous ne recevez pas d'e-mails afin que vous puissiez commencer à recevoir les Notifications par e-mail.

Le nom de l'utilisateur qui invite et l'adresse e-mail de l'utilisateur seront visibles dans l'e-mail d'invitation qui peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/02-invite-email.png)

L'e-mail sera envoyé depuis [noreply@catenda.com](mailto:noreply@catenda.com)

> **Remarque 1 :** Une invitation à un projet peut être envoyée plusieurs fois. Tous les e-mails auront le même Lien, ils fonctionneront tous à moins que l'invitation n'ait été révoquée. **Remarque 2 :** Vous ne pouvez pas répondre à l'e-mail [noreply@catenda.com](mailto:noreply@catenda.com). Si vous avez des questions concernant l'invitation, vous devrez répondre à l'adresse e-mail de la personne qui vous invite ou contacter [support@catenda.com](mailto:support@catenda.com)

## 2. Accepter l'invitation

Pour accepter l'invitation, cliquez soit sur la Notification d'invitation, soit sur le Lien "Cliquez ici pour accepter l'invitation" dans l'e-mail d'invitation.

Lorsque vous cliquez sur l'invitation, vous êtes redirigé vers Catenda Hub où il vous est demandé de vous connecter et d'accepter l'invitation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/03-accepting-the-invitation.png)

### 2.1 Créer un compte

Si vous n'avez pas encore de compte, il vous sera demandé de créer un compte sur Catenda Hub. Suivez la [procédure d'inscription](https://intercom.help/bimsync-arena/en/articles/8412895-creating-an-account).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/04-creating-an-account.png)

Ensuite, cliquez sur "accepter l'invitation"

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qn9t3aze/05-creating-an-account.png)

> **Remarque :** Si vous remarquez que vous êtes connecté avec un compte différent de celui que vous avez l'intention d'utiliser dans ce projet, vous aurez la possibilité de changer d'utilisateur avant d'accepter l'invitation.
