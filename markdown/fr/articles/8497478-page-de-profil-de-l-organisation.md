# Page de profil de l'organisation

Vous pouvez accéder à la page de profil de l'organisation en cliquant sur le nom de l'organisation sur la [page organisation](https://support.catenda.com/en/articles/8281910-organizations-page). La page de profil de l'organisation est la page principale de l'outil organisation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/erq1xqqf/01-intro.png)

Voici à quoi peut ressembler un profil d'organisation :
