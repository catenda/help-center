# Page de profil de l'organisation

Vous pouvez accéder à la page de profil de l'organisation en cliquant sur le nom de l'organisation sur la [page organisation](https://support.catenda.com/fr/articles/8281910-page-organisations). La page de profil de l'organisation est la page principale de l'outil organisation.
