# Comment puis-je lier un document à un objet dans Catenda Hub ?

1. Ouvrez la visionneuse 3D et sélectionnez un (ou plusieurs) objet(s) en cliquant dessus avec le bouton gauche (ctrl+clic gauche permet de sélectionner plusieurs objets).
2. Cliquez sur le menu Documents dans la barre de menu principal à gauche
3. Sélectionnez un (ou plusieurs) document(s) en cliquant sur les cases à cocher à gauche de chacun d'eux
4. Cliquez sur le bouton « Liens » qui apparaît à droite de la vue Documents.
