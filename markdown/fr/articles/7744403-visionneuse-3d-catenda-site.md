# Visionneuse 3D - Catenda Site

Ouvrez la [page 2D/3D](https://support.catenda.com/en/articles/7734138-2d-3d-catenda-site) pour voir la visionneuse 3D vers le haut de l'écran sur Catenda Site. Voici à quoi peut ressembler la visionneuse 3D sur Catenda Site :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/01-intro.png)

Les modèles 3D de la section modèles d'un projet Catenda peuvent être activés et désactivés dans la visionneuse 3D sur Catenda Site.

## 1. **Sélecteur de modèle**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/02-model-selector.png)

Appuyez sur le bouton du sélecteur de modèle pour ouvrir le menu du sélecteur de modèle. Cochez les cases à côté de chaque modèle pour activer ce modèle dans la visionneuse 3D. Après avoir activé/désactivé les modèles, appuyez sur "**Terminé**".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/03-model-selector.png)

## 2. **Barre d'outils**

La barre d'outils se trouve vers le coin supérieur droit de la visionneuse 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/04-toolbar.png)

### 2.1 **Zoom sur les extents**

Positionnez la caméra de la visionneuse 3D pour que tous les objets soient visibles.

### 2.2 Options de réinitialisation

Voici à quoi peut ressembler le menu des options de réinitialisation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/05-reset-options.png)

Dans le menu des options de réinitialisation, vous pouvez choisir de :

- _Afficher tous les objets_ - Afficher tout objet que vous aviez masqué
- _Effacer les mesures_ - Supprimer toutes les mesures
- _Supprimer les plans de coupe_ - Supprimer tous les plans de coupe

Appuyez sur "**Terminé**" lorsque vous avez terminé la configuration des options de réinitialisation 3D

## 3. **Paramètres de la visionneuse 3D**

Voici à quoi peut ressembler le menu des paramètres de la visionneuse 3D :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/06-3d-viewer-settings.png)

### 3.1 **Mode de navigation**

**Pincer** Faites glisser deux doigts l'un vers l'autre ou loin l'un de l'autre pour pincer. Le pincement de la visionneuse 3D déplace la caméra vers l'avant/l'arrière.

**Panoramique** Faites glisser sur la visionneuse 3D avec un seul doigt pour faire un panoramique. Le mode de navigation affecte ce qui se passe lorsque la visionneuse 3D est panoramiquée.

_Mobile_ - Par défaut Ajuster l'angle de la caméra

**Tablette** Lorsque vous maintenez un doigt sur la visionneuse 3D, une ancre de glissement apparaît sous l'emplacement maintenu. Lorsque vous maintenez un objet, l'ancre de glissement apparaît sur cet objet. Lorsque vous maintenez un espace blanc, l'ancre de glissement apparaît à une distance fixe dans la direction de la caméra à l'emplacement de glissement. Après que la visionneuse 3D soit glissée, l'ancre de glissement affiche la direction du glissement et l'angle de la caméra et la position commenceront à tourner autour de l'ancre de glissement. Relâchez l'écran pour verrouiller la caméra dans sa nouvelle position et son nouvel angle.

### 3.2 **Visibilité du joystick**

Activez ou désactivez le joystick. Le joystick peut être glissé pour déplacer la caméra vers le haut/bas/gauche/droite

## 4. **Interaction avec la visionneuse 3D**

Lorsqu'un objet est appuyé, il est sélectionné et un menu contextuel s'ouvre. Le menu contextuel peut ressembler à quelque chose comme ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/07-3d-viewer-interaction.png)

### 4.1 **Titre**

Le titre du menu contextuel consiste en le nom de l'objet sélectionné.

### 4.2 **Masquer**

Appuyez sur le bouton masquer pour masquer l'objet. Les objets peuvent être révélés à nouveau avec le bouton de réinitialisation dans la boîte à outils vers le coin supérieur droit.

### 4.3 **Mesure laser**

Appuyez sur la mesure laser pour mesurer les distances aux bords de surface les plus proches ou aux objets qui se croisent dans les directions X, Y et Z. Les mesures peuvent être effacées avec le bouton de réinitialisation dans la boîte à outils vers le coin supérieur droit.

### 4.4 **Coordonnées**

Appuyez sur le bouton de mesure de point pour voir les coordonnées X, Y et Z de l'emplacement appuyé sur l'objet. Les mesures peuvent être effacées avec le bouton de réinitialisation dans la boîte à outils vers le coin supérieur droit.

### 4.5 **Plan de coupe**

Appuyez sur le bouton du plan de coupe pour créer un plan de coupe le long de la surface appuyée. Voici à quoi peut ressembler la visionneuse 3D après la création d'un plan de coupe :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/d7q47dvw/08-clipping-plane.png)

Après la création d'un plan de coupe, un curseur apparaîtra vers le bas de l'écran. Ajustez ce curseur pour faire défiler le plan de coupe selon sa direction normale pour un ajustement fin. Les plans de coupe peuvent être effacés avec le bouton de réinitialisation dans la boîte à outils vers le coin supérieur droit.

### 4.6 **Informations**

Appuyez sur le bouton d'information pour ouvrir la page d'information de l'objet appuyé.

**Informations sur l'objet** Dans les informations sur l'objet, vous pouvez trouver les éléments suivants :

- Nom
- Entité
- GUID
- Étiquette
- Type
- Type prédéfini

**Propriétés** Les propriétés IFC par défaut ainsi que les différents ensembles de propriétés pour l'objet sont affichés ici. Vous trouverez généralement ici des informations comme les mesures, les quantités, les matériaux, etc.

**Documents** Le titre et la date de création des documents qui ont été liés à l'objet sélectionné sont affichés. Appuyez sur le document pour ouvrir le document sur la page des documents.

**Sujets** Le titre et le numéro du sujet des sujets qui ont été liés à l'objet sélectionné sont affichés. Appuyez sur le sujet pour ouvrir le sujet sur la page des sujets.
