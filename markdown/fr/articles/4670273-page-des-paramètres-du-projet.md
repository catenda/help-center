# Page des paramètres du projet

Vous trouverez la page des paramètres du projet comme dernière page du menu de navigation de gauche dans un projet. Cette page fait partie du panneau de contenu. Ici, vous pourrez trouver des paramètres qui concernent plus d'une zone de projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/01-intro.png)

## 1. **Propriétaire du projet**

Voici à quoi le menu propriétaire du projet peut ressembler:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/02-project-owner.png)

Il ne peut y avoir qu'un seul propriétaire de projet. Pour la plupart des projets, le propriétaire du projet est l'organisation du client auquel le projet appartient. Les organisations sont souvent nommées par le nom du client suivi du type d'organisation. Le nom donné à l'organisation dépend de chaque propriétaire d'organisation, mais ils seront souvent appelés quelque chose comme "Business A - Projets en cours", "Business B - Archive" ou "Business C - Admin et modèles". Les organisations peuvent être possédées par plusieurs personnes qui ont alors une vue d'ensemble de tous les projets de cette organisation. Les propriétaires d'organisation peuvent également déplacer des projets à partir de la [page des projets dans l'outil d'organisation](https://support.catenda.com/en/articles/8505058-projects-page-organization-tool) sans avoir à faire partie du projet.

### 1.1 **Changer le propriétaire**

Si vous êtes propriétaire de cette organisation ainsi que d'autres organisations, vous verrez le texte de changement de propriétaire à droite de ce menu. Ici, vous pourrez modifier l'organisation qui possède ce projet. Par exemple, vous pouvez déplacer un projet d'une organisation avec des projets en cours vers une organisation d'archive de cette manière. Cliquez sur changer le propriétaire, sélectionnez la nouvelle organisation, cliquez sur faire propriétaire et confirmez.

## 2. **Détails du projet**

Voici à quoi le nouveau menu projet peut ressembler:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/03-project-details.png)

### 2.1 **Détails du projet**

Ici, vous pouvez ajouter une photo du bâtiment ou toute autre photo que vous souhaitez. Cette photo sera affichée dans les détails du projet et sur la [page du projet](https://support.catenda.com/en/articles/8400797-projects-page#h_1285a6d343) si vous marquez le projet comme favori. _Accès requis:_ Administrateur du projet

### 2.2 **Nom du projet**

Cliquez sur le crayon à côté du nom du projet pour renommer le projet. _Accès requis:_ Administrateur du projet

### 2.3 **Description**

Ici, vous pouvez entrer une description du projet _Accès requis:_ Administrateur du projet

## 3. **Unités de mesure**

Le menu des unités de mesure peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/04-measurement-units.png)

Configurez les unités que vous souhaitez utiliser dans votre projet

- Mètres (m)
- Centimètres (cm)
- Millimètres (mm)
- Pieds (')
- Pouces ('')
- Pouces fractionnés

L'unité de mesure sélectionnée sera utilisée par défaut pour les membres du projet lors de la mesure dans la visionneuse 3D de ce projet. Modifiez l'unité de mesure et cliquez sur enregistrer. _Accès requis:_ Administrateur du projet

## 4. **Dossier des modèles par défaut**

Le menu du dossier des modèles par défaut peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/05-default-models-folder.png)

Avec [modèles en tant que documents](https://support.catenda.com/en/articles/8064548-models-as-documents), chaque modèle est lié à un document dans la section des documents. Lorsque vous créez un modèle, on vous demande où, dans la structure des documents, vous souhaitez que le document se termine. Si vous créez des modèles via l'API, les documents qui seront liés pour chaque modèle auront besoin d'une place dans la section des documents. Si aucun dossier par défaut n'est spécifié, un dossier appelé modèles apparaîtra si un modèle est créé via l'API. Par défaut, tous les utilisateurs auront un accès en écriture au dossier généré automatiquement.

## 5. **Supprimer le projet**

Le menu de suppression de projets peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/06-delete-project.png)

Cliquez sur le bouton de suppression de projet et écrivez le nom exact du projet pour confirmer que vous souhaitez le supprimer. Les propriétaires d'organisation peuvent également supprimer le projet à partir de la [page des projets dans l'outil d'organisation](https://support.catenda.com/en/articles/8505058-projects-page-organization-tool) sans avoir à faire partie du projet. Si vous ne voyez pas cette option et souhaitez supprimer votre projet, veuillez contacter le support. _Accès requis:_ Propriétaire de l'organisation ou du projet

> **Avertissement:** **Avertissement!** Un projet supprimé ne peut pas être restauré

## 6. **Contrôle d'accès**

Le menu de contrôle d'accès peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/07-access-control.png)

Ici, vous pourrez contrôler les actions qui sont à l'échelle du projet. Cliquez sur chacun des menus pour les ouvrir.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/08-access-control.png)

Cliquez sur modifier l'accès pour modifier l'accès de chaque paramètre. _Accès requis:_ Administrateur

Après avoir ouvert le menu, les membres du projet pourront voir qui a accès à chaque action.

### 6.1 **Créer une nouvelle liste de sujets**

_Accès par défaut:_ Tous les utilisateurs - Écriture [Créer une nouvelle liste de sujets](https://support.catenda.com/en/articles/4670299-issue-board-creation-acl)

### 6.2 **Inviter de nouveaux membres**

_Accès par défaut:_ Tous les utilisateurs - Aucun accès [Inviter de nouveaux membres](https://support.catenda.com/en/articles/4670263-invite-members-page)

### 6.3 **Configuration des statuts des documents**

_Accès par défaut:_ Tous les utilisateurs - Écriture [Configuration des statuts des documents](https://support.catenda.com/en/articles/9874698-revision-publishing-iso-19650)

### 6.4 **Créer et supprimer des modèles**

_Accès par défaut:_ Tous les utilisateurs - Écriture [Créer et supprimer des modèles](https://support.catenda.com/en/articles/8300623-model-configuration)

## 7. **Géolocalisation**

Le menu de géolocalisation peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hamkb6q/09-geolocation.png)

Ici, vous pouvez configurer une représentation visuelle de l'endroit où le projet existe dans le monde.

### 7.1 **Géolocalisation des modèles 3D**

La configuration de ce paramètre n'affecte pas les modèles 3D du projet car leurs coordonnées sont spécifiées dans chaque fichier IFC et/ou paramètre de transformation de modèle.

### 7.2 **Géolocalisation des modèles 2D**

La configuration de ce paramètre place les vues 2D des modèles qui sont générées en coupant les objets à une hauteur à un emplacement dans le monde. Après avoir configuré cela, une carte s'affichera dans la visionneuse 2D. La configuration de ce paramètre vous permettra également de spécifier la rotation initiale de votre visionneuse 2D.

> **Remarque:** Si votre emplacement a été défini avant le 24 mars 2025, vous devrez éditer et enregistrer ou reconfigurer votre emplacement pour voir la carte.

### 7.3 **Carte de la page des projets**

Si un emplacement a été défini, les membres verront une épingle pour ce projet sur leur [carte sur la page des projets](https://support.catenda.com/en/articles/8400797-projects-page#h_5cf5358c76).
