# Visionneuse 2D bâtiments et étages

Les informations sur l'affichage des coupes 2D à travers les objets du modèle et les dessins qui sont superposés à ces coupes dans la Visionneuse 2D se trouvent vers le bas à droite de la Visionneuse 2D. Le menu bâtiment et étage peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/01-intro.png)

## 1. **Verrouillage d'étage**

### 1.1 **Verrouillé**

L'étage actuel sera toujours visible

### 1.2 **Déverrouillé**

L'étage actuel sera l'étage le plus proche en hauteur de celle de la caméra. Ceci est particulièrement utile en [mode marche](https://support.catenda.com/en/articles/5784718-3d-viewer-settings) où l'étage changera vers l'étage suivant si vous montez les escaliers par exemple.

## 2. **Menu bâtiment**

Si un bâtiment a été configuré dans le [configurateur d'étage](https://support.catenda.com/en/articles/6921756-storey-configurator-page), vous pourrez voir le menu bâtiment. Le menu bâtiment peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/02-building-menu.png)

### 2.1 **Bâtiments du configurateur d'étage**

Premièrement, tous les bâtiments qui sont créés dans le configurateur d'étage seront listés. Ces bâtiments peuvent contenir des étages où plusieurs vues 2D de modèles sont combinées et des dessins peuvent être superposés.

### 2.2 **Bâtiments du modèle**

Ensuite, les bâtiments qui sont disponibles dans chaque modèle pour lequel la vue 2D a été activée seront listés. Lorsque la vue 2D pour un modèle est activée, son bouton 2D sera actif :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/03-model-buildings.png)

Le nom d'un bâtiment de modèle est configuré dans le fichier ifc de la révision actuelle sous l'entité IfcBuildingStorey. Si le bâtiment du modèle n'a pas de nom, vous le verrez ici en tant que bâtiment sans nom.

## 3. **Menu étage**

Dans le menu étage, vous verrez les étages du bâtiment actuel.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw6p1nhs/04-storey-menu.png)

Cliquez sur le menu pour voir quels étages sont disponibles dans votre bâtiment. Si le bâtiment a un nom, vous le verrez en gras vers le haut de la liste. Ce menu ne sera pas disponible si le bâtiment actuel n'a pas d'étages.
