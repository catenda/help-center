# Page de notifications de projet

Vous pourrez trouver la page de notifications de projet comme sixième page du menu de navigation de gauche d'un projet. Cette page fait partie du panneau de contenu.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9hmpesfd/01-intro.png)

## 1. Dernières notifications

Les dernières notifications pertinentes pour vous apparaîtront ici. Vous pouvez cliquer sur la notification et être dirigé vers la sous-page pour le dossier.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/9hmpesfd/02-latest-notifications.png)

## 2. Filtrage et fonctionnalités

Vous pouvez en savoir plus sur la façon dont vous pouvez filtrer sur cette page et sur le moment où vous recevez les différentes notifications sur [cette](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages) page.
