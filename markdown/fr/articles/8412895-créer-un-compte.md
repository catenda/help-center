# Créer un compte

Lorsque vous accédez à [hub.catenda.com/signup](http://hub.catenda.com/signup), cette page s'affiche :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/thng6w36/01-intro.png)

Si vous créez un compte, vous ne serez pas automatiquement membre d'un projet. Pour rejoindre le projet de quelqu'un d'autre, vous devrez accepter un [lien d'invitation](https://support.catenda.com/en/articles/4670246-accepting-an-invitation-to-join-a-project). Si vous avez suivi un lien d'invitation et qu'on vous a demandé de créer un compte, ce nouveau compte aura automatiquement accepté l'invitation.

## 1. **Étape 1 sur 4 - Créer un compte gratuit**

Ici, vous pouvez entrer votre adresse e-mail et votre mot de passe pour créer un compte gratuit. Une fois connecté avec succès, vous serez redirigé vers la [page des projets](https://support.catenda.com/en/articles/4670260-projects-page).

### 1.1 **Compte existant**

Si vous avez déjà un compte, vous pouvez cliquer [ici](https://hub.catenda.com/signin) pour vous connecter.

## 2. **Étape 2 sur 4 - Vérifier votre e-mail**

La [page de vérification des e-mails](https://hub.catenda.com/signup/verify-email) peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/thng6w36/02-step-2-of-4-verify-your-email.png)

Après avoir enregistré votre adresse e-mail auprès de nous, nous tenterons de vous envoyer un e-mail pour vérifier que votre adresse e-mail existe et peut recevoir des e-mails de notre part. Sans vérifier votre adresse e-mail, vous ne recevrez de nous que des e-mails contenant des liens publics, tels que les invitations de projet et les collections ou signets partagés publiquement. Veuillez vérifier votre adresse e-mail pour recevoir toute autre notification. Si vous ne recevez pas l'e-mail de vérification, veuillez consulter [cet](https://support.catenda.com/en/articles/8417802-why-am-i-not-receiving-emails) article pour connaître les raisons possibles pour lesquelles l'e-mail de vérification n'arrive pas et comment les résoudre.

### 2.1 **Lien de vérification**

Voici à quoi peut ressembler l'e-mail que vous recevez de notre part :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/thng6w36/03-br-verification-link.png)

Veuillez cliquer sur le lien de vérification de l'e-mail ou coller le lien dans votre navigateur. Vous ne devrez le faire qu'une seule fois par inscription.

Si un compte avec cette adresse e-mail existe déjà dans notre système, vous serez redirigé vers la [page de connexion](https://hub.catenda.com/signin).

## 3. **Étape 3 sur 4 - S'inscrire**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/thng6w36/04-step-3-of-4-sign-up.png)

### 3.1 **Prénom et nom**

Veuillez remplir les champs prénom et nom. Votre nom d'utilisateur sera votre prénom et votre nom séparés par un espace. Vous pourrez modifier votre nom d'utilisateur ultérieurement dans les [préférences du compte](https://support.catenda.com/en/articles/6880968-account-page).

### 3.2 **Mot de passe et confirmation du mot de passe**

Champs Mot de passe et Confirmer le mot de passe. Vous pourrez modifier votre mot de passe ultérieurement dans les [paramètres d'authentification](https://support.catenda.com/en/articles/6880968-account-page). Cliquez [ici](https://support.catenda.com/en/articles/10798891-sign-in-and-passwords) pour dépanner les problèmes de mot de passe.

### 3.3 **Conditions de service**

Veuillez cocher la case devant « J'accepte les [Conditions de service](https://catenda.com/user-terms-of-service?_gl=1*1qc6ibh*_gcl_au*MTgxMzU2ODI3LjE2OTU3MDgyOTk.). » Ceci est requis pour continuer

### 3.4 **Infolettre**

Si vous souhaitez recevoir des infolettres de notre part, vous pouvez vous y abonner en cliquant sur la case à cocher devant « S'abonner à notre infolettre » Cette case n'est pas requise pour continuer Cliquez sur « Continuer » pour accéder à l'étape 4

## 4. **Étape 4 sur 4 - Questionnaire**

La page du questionnaire peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/thng6w36/05-step-4-of-4-questionnaire.png)

Vous serez invité à indiquer comment vous allez utiliser Catenda Hub. La liste déroulante propose trois options :

- Construction / Infrastructure
- Développement web / application mobile
- Éducation

Remplissez le titre qui vous décrit le mieux dans la liste déroulante qui s'affiche ensuite.

**Construction / Infrastructure** Si vous avez choisi Construction / Infrastructure, veuillez préciser le secteur/domaine d'activité dans lequel vous travaillez principalement, la taille de votre entreprise, votre nom et votre numéro de téléphone.

**Développement web / application mobile** Si vous avez choisi Développement web / application mobile, veuillez préciser les secteurs d'activité visés par votre logiciel, la taille de votre entreprise, votre nom et votre numéro de téléphone

**Éducation** Si vous avez choisi Éducation, veuillez préciser le type d'établissement que vous fréquentez. Ensuite, indiquez le nom de l'établissement.

Après avoir rempli le questionnaire, vous verrez que le bouton Continuer est mis en surbrillance avec un remplissage vert.

> **Remarque :** Les options du questionnaire n'ont aucun effet sur votre expérience Catenda.

Cliquez sur le bouton « Continuer » pour être redirigé vers la [page des projets](https://support.catenda.com/en/articles/8400797-projects-page).
