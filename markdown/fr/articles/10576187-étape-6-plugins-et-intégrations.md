## 2. **Bureau Connecteur**

- Connecte votre bureau à Catenda
- Planifiez les téléchargements à partir du référentiel de documents sur Catenda vers une destination définie sur votre PC
- Planifiez les téléchargements à partir d'une destination définie sur votre PC vers le référentiel de documents sur Catenda
- Exécutez ces téléchargements et téléchargements planifiés sur une base quotidienne

## 3. **Navisworks**

- Accès à tous vos projets Catenda
- Échanger les sujets entre Catenda et Navisworks
- Localisez les objets clash dans Navisworks
- Créer des sujets BCF à partir des clashes dans Navisworks
- Accédez à la bibliothèque de documents sur Catenda pour ouvrir n'importe quel format de fichier pris en charge par Navisworks
- Accédez à toutes les révisions de modèles (pas seulement la dernière)
- Enregistrez votre fichier NWD directement sur Catenda
- Consolider les points de vue lorsque vous créez un sujet à partir d'un groupe ou de plusieurs clashes (créer un point de vue avec tous les clashes)

## 4. **Revit**

- Accès à tous vos projets Catenda
- Échanger les sujets entre Catenda et Revit
- Exporter les modèles IFC vers Catenda
- Localisez les objets clash dans Revit
- Créer des sujets BCF (2D et 3D) dans Revit
