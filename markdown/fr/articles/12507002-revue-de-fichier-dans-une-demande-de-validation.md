# Revue de fichier dans une demande de validation

La revue de fichier pour une demande de validation peut être ouverte en cliquant sur revue ou affichage sur la page de demande de validation. Voici ce que la page de revue d'un fichier dans une demande de validation peut ressembler pour les projets qui ont activé les révisions partagées après le 2 octobre 2025 :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zr7fa0bv/01-intro.png)

Les projets pour lesquels les révisions partagées ont été activées avant le 2 octobre 2025 verront plutôt la page de revue de fichier héritée.

## 1. Ouverture de la page de revue de fichier

### 1.1 Tous les documents

Cliquez sur le bouton revue pour une équipe sur l'onglet aperçu d'une page de validation pour ouvrir la revue de fichier pour tous les documents dans une validation au nom de cette équipe.

### 1.2 Documents sélectionnés

Cliquez sur le bouton revue dans le menu de droite de l'onglet documents d'une page de validation après avoir sélectionné certains documents dans l'onglet documents pour ouvrir la revue de fichier pour les documents sélectionnés au nom de cette équipe.

### 1.3 Affichage uniquement

Cliquez sur le bouton affichage dans le menu de droite de l'onglet documents d'une validation après avoir sélectionné certains documents dans l'onglet documents pour afficher la revue de fichier pour les documents sélectionnés.

## 2. Fils d'ariane

### 2.1 Documents

Cliquez sur documents pour aller à la page documents

### 2.2 Validations

Cliquez sur Validations pour aller à la page validations

### 2.3 Numéro et titre de la validation

Le numéro et le titre de la validation Cliquez sur le nom de la demande de validation pour aller à la page de demande de validation de la demande de validation dont cette révision fait partie.

## 3. Navigation de la revue de fichier

### 3.1 Bouton Retour

Retournez à la page de demande de validation dont les fichiers en revue font partie.

### 3.2 Barre de progression

Affiche les révisions vers lesquelles il est possible de naviguer

> **Remarque :** Il est uniquement possible de naviguer vers autant de révisions que celles qui ont été sélectionnées sur la page de demande de validation. Cliquer sur revue sur l'onglet aperçu de la demande de validation vous permettra de naviguer vers toutes les révisions tandis que la sélection de documents dans l'onglet documents de la demande de validation et le clic sur revue dans le menu de droite ne vous permettront de naviguer que vers les documents sélectionnés.

Ce nombre total n'est donc pas toujours indicatif du nombre total de fichiers à revue dans la demande de validation.

_Boutons précédent et suivant_ - Allez à la révision précédente ou suivante dans la revue de demande de validation.

## 4. Menu de droite

Le menu de droite peut être ouvert en cliquant sur l'icône d'information vers la droite de la page de revue de demande de validation. L'icône Infos peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zr7fa0bv/02-right-menu.png)

Cliquez ici pour en savoir plus sur le menu de droite sur la page de revue de demande de validation.

## 5. Plein écran

Le bouton plein écran de revue se trouve vers le haut à droite de la page de revue de demande de validation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zr7fa0bv/03-fullscreen.png)

## 6. Aperçu du document

Lors de la revue de la revue de fichier au nom d'une équipe, tous les [outils d'annotation de document](https://support.catenda.com/en/articles/11384618-document-preview-tools) seront disponibles. L'aperçu du document sur la page de revue de demande de validation fonctionne de la même manière que l'[aperçu du document](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations) lors de l'ouverture d'un document à partir du tableau des documents.

### 6.1 Lecture seule

Lors de la consultation de la revue de fichier en mode lecture seule, seul l'[outil d'affichage](https://support.catenda.com/en/articles/11384618-document-preview-tools#h_27c7badabb) sera disponible dans la barre d'outils de l'aperçu du document.
