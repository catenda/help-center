# Actions du configurateur d'étages

L'action de création d'un nouveau bâtiment se trouve vers le haut à droite de la [page du configurateur d'étages](https://support.catenda.com/en/articles/6921756-storey-configurator-page). Voici où se trouvent les actions de la page du configurateur d'étages :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/01-intro.png)

## 1. **Actions sur les nouveaux éléments**

Si aucun bâtiment n'a été configuré, le bouton d'ajout au milieu de la page peut être cliqué. Cliquez sur le bouton plus vert en haut à droite ou ouvrez le menu des actions pour utiliser l'action Ajouter un nouveau bâtiment. Pour ajouter un bâtiment, il est toujours possible de cliquer sur le bouton plus vert ou de cliquer sur l'action dans le menu des actions.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/02-new-item-actions.png)

## 2. **Ajouter un nouveau bâtiment**

Après avoir utilisé l'action d'ajout d'un nouveau bâtiment, la boîte de dialogue Créer un nouveau bâtiment s'ouvrira.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/03-add-new-building.png)

Dans la boîte de dialogue Créer un nouveau bâtiment, un modèle initial est sélectionné.

> **Remarque :** Pour pouvoir sélectionner un modèle, au moins un modèle doit être configuré dans le projet.

Cliquez [ici](https://support.catenda.com/en/articles/9431936-models-page-actions#h_4100594482) pour en savoir plus sur la création de modèles. Lorsqu'un modèle est importé, une vue 2D est générée en effectuant une coupe à travers les objets du modèle à 1,4 mètre au-dessus de la hauteur de chaque étage.

### 2.1 **Modèles sans géométrie 2D**

Si aucun objet n'a été découpé, il ne sera pas possible de sélectionner le modèle. Vous pouvez le vérifier en consultant le [bouton 2D](https://support.catenda.com/en/articles/4670279-revision-selector#h_180a64490d) qui ne s'active pas à l'ouverture de la vue 2D du modèle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/04-models-with-no-2d-geometry.png)

### 2.2 **Fichier d'exemple**

Cliquez [ici](https://hub.catenda.com/share/collections/zBkFZ5yzhIUvw5a028kNt8A8oZNXVQhdtV9QhO8FuFuS) pour télécharger un modèle d'exemple avec un étage et un seul objet pouvant servir d'exemple.

## 3. **Création de bâtiment**

Si un modèle avec une géométrie 2D est sélectionné, un brouillon de configuration de bâtiment est créé. À ce stade, les modifications apportées à la configuration de l'étage ne sont pas encore disponibles pour les Membres du projet. Voici à quoi peut ressembler la page du configurateur d'étages après la sélection d'un modèle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/43a5z00a/05-building-creation.png)

Dans le bâtiment créé, un étage est créé pour chaque IfcStorey du modèle avec son élévation respective. À partir de là, d'autres vues 2D peuvent être ajoutées, un plan PDF peut être superposé et l'élévation peut être modifiée pour chaque étage.

### 3.1 **Aperçu de l'étage**

L'étage actuel est mis en évidence en vert. La configuration de l'étage s'affiche sur le côté droit. Si plusieurs panneaux et le panneau de contenu avec la page du configurateur d'étages ont moins d'espace, vous pourriez ne pas voir l'aperçu de l'étage droit à droite. Cliquez sur un étage différent pour prévisualiser la configuration de cet étage.

### 3.2 **Enregistrer la configuration**

Pour enregistrer le bâtiment, cliquez sur Enregistrer la configuration vers le bas de la page.
