# Menu de droite sur la page Documents

Après avoir sélectionné un ou plusieurs Document(s), l'icône d'information apparaîtra à droite de la barre de recherche sur la page Documents. En cliquant sur cette icône, un menu d'information s'ouvrira contenant des informations sur le ou les dossier(s) et/ou Document(s) que vous avez sélectionnés ou le dossier que vous avez ouvert. L'icône Info peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/01-intro.png)

Ce panneau développé peut avoir un aspect différent selon ce que vous avez sélectionné [_Un dossier_ ](#h_cad792004b) _- [Un Document](#h_2fac53531d) - [Plusieurs dossier(s) et/ou Document(s)](#h_58d67056f7)_

## 1. Un dossier

Voici à quoi peut ressembler le menu de droite quand un dossier est sélectionné.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/02-one-folder.png)

### 1.1 **Informations sur le dossier**

Si le dossier est vide, l'icône sera ombrée en blanc. En bas à droite de l'icône du dossier, vous verrez le nombre de Documents dans ce dossier. À droite de l'icône, vous pouvez voir le nom du dossier. Vous pouvez modifier le nom du dossier en cliquant sur l'icône de crayon.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/03-folder-information.png)

_Accès requis :_ accès en écriture au dossier.

### 1.2 **Contrôle d'accès**

Pour plus d'informations sur le contrôle d'accès dans la section Documents, lisez [ici](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl).

### 1.3 **Collections**

Si votre Document fait partie de [Collections](https://support.catenda.com/en/articles/6344318-collections-page), ils seront listés ici.

## 2. **Un Document**

Voici à quoi peut ressembler le menu de droite quand un Document est sélectionné :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/04-one-document.png)

Lorsque vous avez un Document sélectionné, les informations concernant la dernière révision publique de ce Document sont affichées. Consultez [ici](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision) pour voir quelles informations sont disponibles.

## 3. **Plusieurs dossier(s) et/ou Document(s)**

Voici à quoi peut ressembler le menu de droite quand plusieurs dossiers et/ou Document(s) sont sélectionnés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/05-multiple-folder-s-and-or-document-s.png)

Si plusieurs Documents ou dossiers sont sélectionnés, les informations sur le Document changeront

![](https://raw.githubusercontent.com/catenda/help-center/main/images/55dfymdy/06-multiple-folder-s-and-or-document-s.png)

Si vous cliquez sur la croix rouge, vous pouvez supprimer ce dossier ou Document de votre sélection.

### 3.1 **Mise à jour des Documents sélectionnés**

Avec ce menu, vous pouvez modifier les valeurs de plusieurs dossier(s) et/ou Document(s) à la fois.

### 3.2 **Contrôle d'accès**

Avec ce menu, vous pouvez modifier l'accès de plusieurs dossier(s) et/ou Document(s) à la fois. Pour plus d'informations sur le contrôle d'accès dans la section Documents, lisez [ici](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl).

### 3.3 **Collections**

Si votre ou vos dossier(s) et/ou Document(s) font partie de [Collections](https://support.catenda.com/en/articles/6344318-collections-page), ils seront listés ici.

### 3.4 **Objets liés**

Avec ce menu, vous pouvez Lier/Delier des objets vers/depuis plusieurs dossier(s) et/ou Document(s) à la fois.
