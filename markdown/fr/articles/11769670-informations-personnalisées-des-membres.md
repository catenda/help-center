# Informations personnalisées des membres

## 1. **Enregistrer plus de données de membres**

Si vous souhaitez enregistrer plus de données de membres que celles fournies sur la page des membres, il est recommandé de créer une liste de sujets avec [des champs personnalisés](https://support.catenda.com/en/articles/8445588-custom-field-page) pour les différentes colonnes souhaitées, puis de créer un sujet par utilisateur. Voici à quoi peut ressembler une telle liste de sujets :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/s4p1rv5j/01-saving-more-member-data.png)

D'autres flux de travail observés consistent à mettre votre numéro de téléphone dans votre nom d'utilisateur. De cette façon, votre numéro de téléphone sera toujours présent dans les sujets que vous envoyez à des tiers.

## 2. **Exporter les données de membres**

Pour le moment, la seule façon d'exporter les données de membres est de les copier et les coller ailleurs.

### 2.1 **Obtenir tous les e-mails des membres**

Il existe une astuce pratique que vous pouvez utiliser pour copier facilement toutes les adresses e-mail des utilisateurs. Pour ce faire, suivez les étapes suivantes : 1\. Cliquez sur le bouton [lien de partage](https://support.catenda.com/en/articles/4728886-sharelink-notify-people-about-catenda-hub-content) en haut à droite à côté de votre photo de profil. 2\. Cliquez dans la zone des destinataires et sélectionnez « Tous les utilisateurs » (ou tout utilisateur ou équipe dont vous souhaitez copier les e-mails des utilisateurs)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/s4p1rv5j/02-get-all-members-emails.png)

3\. Faites glisser du bas de la zone des destinataires vers le haut de la zone des destinataires. (Vous devrez peut-être d'abord faire défiler vers le bas)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/s4p1rv5j/03-get-all-members-emails.png)

Vous pouvez maintenant copier les adresses e-mail que vous avez sélectionnées en cliquant avec le bouton droit -> copier ou avec ctrl+c.

> **Remarque :** Parfois, la sélection de texte peut disparaître si vous relâchez la souris. Dans ce cas, vous pouvez maintenir le bouton de la souris enfoncé pour la sélection et utiliser ctrl+c tout en maintenant le bouton de la souris enfoncé pour la sélection afin de copier le texte.

Vous pourrez coller ces e-mails dans une zone de destinataire e-mail et ajouter tous les utilisateurs comme destinataires à un e-mail.
