# Nouvelle version de l'application mobile

[Il y a une nouvelle version de l'application mobile (1.5.0) disponible sur les deux stores !](https://catenda.com/products/bimsync-mobile-app/) 🎉🎉

Voici les nouveautés de cette version :

- Tout nouveau tableau de bord interactif offrant plus de statistiques et une navigation directe vers vos listes de problèmes en utilisant des filtres prédéfinis

- Support pour ajouter plusieurs images et viewpoints lors de la création d'un nouveau problème

- Supprimer les commentaires de problème à l'aide du geste de balayage

- Écran de paramètres amélioré. Vous pouvez maintenant choisir votre écran d'accueil préféré

- Nouveau système de notifications in-app pour vous fournir des informations plus utiles

- Amélioration des performances pour tous les appareils Android
