# Page des notifications de compte

Vous pourrez trouver la page des Notifications comme deuxième page dans le menu de navigation de gauche dans Catenda Hub. Sur la page [Notifications](https://bimsync.com/notifications) vous trouverez toutes les Notifications qui vous ont été envoyées depuis tous vos projets.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/rwdesfej/01-intro.png)

Sur la gauche de la page des Notifications vous verrez vos dernières Notifications et sur la droite vous pourrez filtrer ces Notifications.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/rwdesfej/02-intro.png)

## 1. **Filtrage et fonctionnalité**

Cliquez [ici](https://support.catenda.com/en/articles/8304417-filtering-and-functionality-on-notifications-pages) pour en savoir plus sur comment filtrer les différents problèmes et dans quels cas vous recevez chaque type de notification.

## 2. **Notifications par email**

Si vous avez activé les Notifications par email, ces Notifications vous seront également envoyées soit dans un email de synthèse, soit comme un email distinct par notification. Cela peut être configuré dans les [paramètres de Notifications par email](https://support.catenda.com/en/articles/8272435-notification-settings#h_75e5db8657). Si vous ne recevez pas d'emails, veuillez consulter [cet](https://support.catenda.com/en/articles/8417802-why-am-i-not-receiving-emails) article.

## 3. **Paramètres des Notifications**

Vous pourrez trouver les [paramètres des Notifications](https://support.catenda.com/en/articles/8272435-notification-settings) comme sous-page de la page des Notifications.
