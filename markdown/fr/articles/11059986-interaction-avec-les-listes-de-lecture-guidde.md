Les thèmes suivants sont décrits dans cet article :

## 1. **Instructions étape par étape**

Trouvez une procédure étape par étape pour chaque vidéo de la liste de lecture en sélectionnant la vidéo et en faisant défiler vers le bas 👇

## 2. **Exporter le guide en tant que document**

Les vidéos de la liste de lecture sont souvent mises à jour avec les modifications de la plateforme. Les informations les plus récentes seront donc toujours dans la liste de lecture. Si vous souhaitez obtenir le guide étape par étape d'une vidéo sous forme de document, veuillez nous faire savoir quel guide vous souhaitez obtenir sous forme de document à [support@catenda.com](mailto:support@catenda.com) où nous serons heureux de vous aider. Les exportations de Documents des guides peuvent être demandées dans les formats suivants :

- MP4
- Gif
- Document PDF
- Slides PDF
- PPTX

## 3. Partager le guide

Après avoir ouvert la liste de lecture, vous pourrez trouver le bouton de partage en haut à droite. Voici à quoi peut ressembler votre menu de partage de liste de lecture :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wm2jp1mz/01-sharing-the-guide.png)

Remarquez que votre URL change lorsque vous cliquez sur les différentes vidéos. Lorsque vous partagez avec le bouton de partage, vous partagerez un Lien vers votre vidéo actuelle dans le contexte de la liste de lecture.
