# Créer de nouvelles étiquettes

Les étiquettes sont utiles dans de nombreux domaines de Catenda HUB. Elles peuvent être utilisées pour les documents et les tâches. Les étiquettes assignées vous aident à mieux organiser et filtrer vos tâches et documents.

Dans l'article suivant, vous trouverez des instructions sur la création de nouvelles étiquettes, la création de groupes d'étiquettes et l'importation d'un groupe d'étiquettes à partir d'une feuille de calcul Excel.

## 1. Créer une nouvelle étiquette

Pour cela, cliquez sur Étiquettes dans la zone Paramètres. Vous avez maintenant la possibilité de créer une nouvelle étiquette

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/01-create-new-label.png)

Une fenêtre d'affichage s'ouvre dans laquelle vous pouvez attribuer un nom à l'étiquette, attribuer une couleur à l'étiquette ou attribuer un groupe à l'étiquette.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/02-create-new-label.png)

## 2. Créer un groupe d'étiquettes

C'est une bonne idée de regrouper / organiser les étiquettes en groupes.

Si vous souhaitez regrouper différentes étiquettes, veuillez procéder comme suit. Pour cela, cliquez sur "Nouveau groupe" dans la zone "Groupes"

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/03-create-label-group.png)

Entrez également un nom ici. Le groupe est créé.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/04-create-label-group.png)

## 3. Importer depuis Excel

Si vous souhaitez créer plusieurs étiquettes à la fois à partir d'un fichier Excel, procédez comme suit. Nous sommes dans la zone des étiquettes et créons une nouvelle étiquette :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/05-import-from-excel.png)

La fenêtre suivante s'ouvre :

Vous n'avez maintenant pas besoin de sélectionner une couleur ou un groupe, mais pouvez insérer ce fichier directement à partir d'un tableau Excel en utilisant "Copier" et "Coller".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/06-import-from-excel.png)

Voici un exemple de tableau. Les codes de couleur se trouvent sur les sites Web pertinents. Entrez simplement "code de couleur" dans Google.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/07-import-from-excel.png)

Maintenant, nous pouvons insérer ce tableau dans la colonne Nom. Pour ce faire, sélectionnez, copiez et collez simplement tout de Label1 au dernier code de couleur.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/08-import-from-excel.png)

Insérez maintenant simplement les cellules sélectionnées dans la zone de nom. Les noms, groupes et couleurs sont attribués automatiquement. Assurez-vous d'utiliser l'orthographe correcte et un code de couleur complet. Utilisez "Soumettre" pour créer les nouvelles étiquettes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/09-import-from-excel.png)

Votre affichage devrait maintenant ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y6vse6fp/10-import-from-excel.png)

Vous avez créé vos étiquettes avec succès.
