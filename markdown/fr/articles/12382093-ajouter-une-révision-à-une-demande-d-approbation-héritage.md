# Ajouter une révision à une demande d'approbation - Héritage

Les révisions de brouillon peuvent être ajoutées à une demande d'approbation en cliquant sur le bouton ajouter un brouillon dans la [dialogue créer une demande d'approbation](https://support.catenda.com/en/articles/12360159-creating-a-new-approval-request) et en cliquant sur le bouton ajouter un brouillon dans le [corps d'une approbation](https://support.catenda.com/en/articles/8349418-approval-page#h_218ac89189) sur la page d'une approbation existante. Voici à quoi peut ressembler la dialogue ajouter un brouillon à la demande d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bzenvg2j/01-intro.png)

## 1. **Rechercher ou filtrer**

Voici à quoi peut ressembler le menu de recherche ou de filtrage dans la dialogue ajouter un brouillon à la demande d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bzenvg2j/02-search-or-filter.png)

Par défaut, le filtre « Téléchargé par moi » est appliqué. De cette façon, toutes les révisions de brouillon téléchargées par le membre créant la révision sont affichées

### 1.1 **Liens**

**Lié** Les brouillons du dossier actuel qui sont liés aux objets actuellement sélectionnés dans la visionneuse 3D Le nombre derrière le filtre affiche le nombre de documents liés dans le dossier actuel

**Non lié** Les brouillons du dossier actuel qui ne sont pas liés à des objets 3D. Le nombre derrière le filtre affiche le nombre de documents non liés

### 1.2 **Filtres de date**

**Publié** Bien que le filtre de date soit visible dans le menu de recherche, il n'est pas activé et ne peut pas être utilisé.

### 1.3 **Groupe d'étiquettes**

**Nom d'étiquette** Recherchez des brouillons selon les étiquettes appliquées au document auquel les révisions de brouillon sont téléchargées.

### 1.4 **Téléchargé par**

**Téléchargé par moi** Brouillons téléchargés par le membre soumettant la demande d'approbation.

### 1.5 **Recherche textuelle**

**Rechercher dans le titre du document :** Recherchez les documents qui contiennent des révisions de brouillon.

**Rechercher dans le nom de fichier :** Recherchez des révisions de brouillon spécifiques.

## 2. **Ajouter une liste de révisions**

Dans la dialogue ajouter un brouillon à la demande d'approbation, une liste plate de toutes les révisions de brouillon téléchargées dans la section des documents s'affiche.

Chaque révision de brouillon affiche :

- Une icône
- Le chemin d'accès du dossier depuis le dossier racine avec le nom du document à la fin
- Le nom de la révision
- Le créateur de la révision
- L'étiquette sur le document dont fait partie le brouillon

## 3. **Ajouter**

Cliquez sur ajouter pour ajouter le brouillon à l'approbation Lorsqu'un brouillon est ajouté à l'approbation, il affichera « ajouté » à la place. Un seul brouillon par document peut être ajouté à une demande d'approbation. Si une révision de brouillon différente du même document est déjà ajoutée à la demande d'approbation, le bouton ajouter sera grisé. Il est possible d'ajouter n'importe quel nombre de brouillons à une demande d'approbation et de la soumettre. Pour les brouillons, cela nécessite un clic par brouillon, ce qui peut représenter beaucoup de clics. Une façon plus rapide est de télécharger 100 révisions de brouillon avec le téléchargement de fichier unique et de les ajouter tous à une demande d'approbation à la fois avec le nouveau bouton d'approbation qui apparaît vers le bas de la liste après le téléchargement de tous les fichiers. Une fois que la demande d'approbation est soumise, il sera toujours possible d'ajouter d'autres révisions de brouillon.

### 3.1 **Limitations**

Après avoir cliqué sur ajouter, les demandes seront envoyées du système à Catenda pour ajouter les documents à la demande d'approbation. Selon la charge du système, certaines demandes peuvent ne pas arriver. En particulier, lors de l'ajout de nombreux documents à la fois, plusieurs tentatives peuvent être nécessaires pour ajouter toutes les révisions de document à la demande d'approbation. Après l'envoi de la demande d'approbation, il sera toujours possible de modifier la liste des documents dans la demande d'approbation.
