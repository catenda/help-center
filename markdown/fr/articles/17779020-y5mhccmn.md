# À propos de Catenda Data Export

> Catenda Data Export copie les données des projets Catenda Hub vers le stockage cloud propre d'une organisation, automatiquement.

Catenda Hub propose plusieurs moyens de télécharger les données de projet, décrits dans [Exporter toutes les données de projet](https://support.catenda.com/fr/articles/7946690-exporter-toutes-les-donnees-du-projet). Catenda Data Export est la solution automatisée : elle copie les données de projet directement vers le stockage cloud propre à une organisation, dans Amazon S3 ou Azure Blob Storage. Elle est vendue séparément de Catenda Hub.

## 1. **Ce qu'il est**

Catenda Data Export conserve une copie des documents, modèles et sujets d'un projet dans le stockage contrôlé par l'organisation. Il s'exécute selon un calendrier ou une seule fois, sans que personne ne télécharge manuellement des fichiers.

## 2. **Propriétaires et participants de projets**

Catenda Data Export n'est pas seulement destiné aux organisations qui possèdent des projets dans Catenda Hub. Ce qu'il exporte dépend du rôle de l'organisation dans chaque projet.

### 2.1 **Propriétaires de projets**

Une organisation qui possède un projet peut exporter une sauvegarde complète de toutes les données de ce projet.

### 2.2 **Participants au projet**

Une organisation qui participe à des projets possédés par d'autres peut également obtenir Catenda Data Export, sans posséder elle-même un projet. Dans ces projets, il exporte uniquement ce à quoi le participant a accès, ce qui peut être une partie limitée du projet. De cette façon, le participant conserve sa propre copie de son travail, même si son accès au projet prend fin.
