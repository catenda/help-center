# Intégration des Topics Solibri

> **Important :** **Solibri version 9.13 :** **Important :** Le plugin BCF Connector est depuis la version 9.13 un onglet séparé appelé BCF Live connector dans Solibri. Une grande partie des mêmes informations s'applique toujours dans cet onglet. **Solibri version 9.9 :** Depuis la mise à jour 9.9 de Solibri, il est maintenant possible de synchroniser vos topics avec Catenda.

Ce document explique comment configurer le connecteur BCF avec votre projet Catenda. Cela permet aux topics d'être communiqués entre les deux applications de manière transparente, en évitant les étapes manuelles d'export et d'import BCF.

1\) Achetez et téléchargez Solibri Model Checker depuis le Solibri Solution Center. Si vous disposez déjà de l'outil, n'oubliez pas de le mettre à niveau.

2\) Vous pouvez obtenir/mettre à niveau le BCF Connector depuis le Solibri Solution Center - [https://solution.Solibri.com/application/#!ProductsView](https://solution.solibri.com/application/#!ProductsView)

Allez à Solibri Extensions et sélectionnez le connecteur BCF

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/01-intro.png)

> **Remarque :** Pour activer le BCF Connector, votre administrateur Solibri doit l'activer dans l'écran de gestion des utilisateurs du Solibri Solution Center.

3\) Ouvrez SMC et allez à l'écran des paramètres. De là, sélectionnez le connecteur BCF

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/02-intro.png)

4\) Ajouter un serveur

1. Commencez par appuyer sur le bouton Ajouter un serveur et vous serez envoyé à la deuxième page.
2. À cette étape, vous pouvez choisir le serveur auquel vous souhaitez vous connecter, en l'occurrence Catenda.
3. Ici, vous pouvez coller l'URL de votre projet Catenda. L'image suivante explique où trouver cette URL.
4. Cliquez sur OK pour terminer la connexion.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/03-intro.png)

6\) Sur la page des topics de votre projet Catenda, vous pouvez trouver l'URL de votre projet. Elle se trouve dans les topics d'échange.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/04-intro.png)

7\) Allez ensuite à l'écran des communications dans Solibri et sélectionnez les présentations. De là, vous pouvez créer une nouvelle présentation. Faites un clic droit sur le menu contextuel pour pouvoir synchroniser avec Catenda.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/05-intro.png)

8\) À partir de là, vous pouvez également créer une nouvelle présentation et importer de Catenda vers Solibri.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qv33595h/06-intro.png)

Pour optimiser votre flux de travail avec le serveur BCF [Voir ici](https://support.bimsync.com/hc/en-us/articles/360011987619)
