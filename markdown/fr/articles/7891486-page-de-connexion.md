# Page de connexion

Lorsque vous accédez à [hub.catenda.com/signin](http://hub.catenda.com/signin), cette page s'affiche :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/z7whdt00/01-intro.png)

## 1. **Adresse e-mail**

Entrez une adresse e-mail associée à un compte existant. Si un compte n'existe pas encore pour cette adresse e-mail, inscrivez-vous plutôt pour créer un nouveau compte. Cliquez [ici](https://hub.catenda.com/signup) pour créer un nouveau compte.

### 1.1 **Comptes d'authentification unique**

Les entreprises qui possèdent des projets Catenda peuvent configurer l'authentification unique (SSO) pour les utilisateurs Catenda de leur organisation. L'authentification unique (SSO) peut être configurée de deux façons :

- Liste blanche - Utilisateurs spécifiques d'un domaine
- Liste noire - Tous les utilisateurs d'un domaine à l'exception de ceux figurant sur une liste spécifiée

Si l'adresse e-mail saisie est reconnue comme compte activé pour l'authentification unique, le champ de mot de passe disparaît et le message suivant s'affiche : Ce compte utilise l'authentification unique. Cliquez sur Continuer pour vous connecter.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/z7whdt00/02-single-sign-on-accounts.png)

En cliquant sur Continuer, vous serez redirigé vers la page de connexion de l'organisation. Les utilisateurs de l'authentification unique n'ont pas d'exigence d'authentification multifacteur pour les projets de leur organisation où l'authentification multifacteur est obligatoire.

> **Remarque :** Le support de Catenda peut vous aider si vous n'êtes pas redirigé comme prévu, mais les questions concernant la page de connexion de l'organisation doivent être posées au département informatique de cette organisation.

Si une mauvaise adresse e-mail a été saisie, modifiez simplement l'adresse et le champ de mot de passe devient disponible à nouveau.

## 2. **Mot de passe**

Entrez ici le mot de passe correspondant au compte enregistré sous l'adresse e-mail fournie. Cliquez [ici](https://support.catenda.com/en/articles/10798891-sign-in-and-passwords) pour obtenir de l'aide sur les mots de passe.

## 3. **Se connecter**

Cliquez sur Se connecter pour vérifier les identifiants saisis. Une fois le processus de vérification terminé avec succès, les utilisateurs sont redirigés vers la [page des projets](https://support.catenda.com/en/articles/4670260-projects-page).

## 4. **Authentification multifacteur**

Si un code d'authentification multifacteur a été configuré pour un compte, les utilisateurs sont d'abord invités à saisir le code d'authentification multifacteur de l'application d'authentification sur l'appareil sur lequel ils ont enregistré le code auprès de leur compte. En cas de problème avec le code ou si l'appareil sur lequel se trouvait le code a disparu, veuillez demander au propriétaire du projet qui est le contact principal avec Catenda (généralement un administrateur du projet) de demander la réinitialisation du code d'authentification de votre compte via la bulle d'assistance sur cette page, sur Catenda ou à l'adresse [support@catenda.com](mailto:support@catenda.com)

## 5. **J'ai oublié mon mot de passe**

Entrez votre adresse e-mail [ici](https://hub.catenda.com/forgot-password) pour réinitialiser votre mot de passe. Si vous ne recevez pas d'e-mail dans les 2 minutes, veuillez contacter le support via la bulle d'assistance sur cette page, sur Catenda ou à [support@catenda.com](mailto:support@catenda.com)

## 6. **Inviter de nouveaux utilisateurs**

En cliquant sur [S'inscrire](https://hub.catenda.com/signup) en haut de la page de connexion, les utilisateurs peuvent créer un compte gratuit même sans être invités à un projet. Après avoir terminé les étapes d'enregistrement du compte, ces utilisateurs trouveront leur compte vide et sans projets.

**Accepter une invitation et créer un nouveau compte** Les nouveaux utilisateurs qui n'ont pas encore de compte peuvent être invités à un projet Catenda par courrier électronique par un administrateur de projet ou par le propriétaire d'une organisation. Lorsqu'un utilisateur qui n'a pas encore de compte reçoit un e-mail d'invitation et clique sur le lien, la page d'enregistrement du compte s'ouvre et il lui est demandé de suivre les étapes d'enregistrement du compte. Une fois les étapes terminées, l'invitation au projet peut être acceptée si elle est toujours valide et l'utilisateur peut automatiquement devenir membre du projet.

**Accepter une invitation avec un compte existant** Les utilisateurs qui ont précédemment créé un compte et qui cliquent sur le lien d'invitation par courrier électronique sans s'être encore connectés sont invités à se connecter avec leurs identifiants avant de se voir demander s'ils souhaitent accepter l'invitation au projet.

Si le compte a été créé avant l'envoi de l'invitation, les utilisateurs peuvent en outre se connecter avec leurs identifiants enregistrés et cliquer sur la notification d'invitation au projet pour accepter l'invitation et devenir membre d'un projet.

**Ajouter de nouveaux utilisateurs au projet sans invitation** Les utilisateurs appartenant à une organisation qui possède des projets Catenda peuvent constater que leur compte a été ajouté à l'un des projets de l'organisation par le propriétaire de l'organisation.
