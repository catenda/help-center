# Champs personnalisés sur les documents

Dans cet article, nous expliquons comment appliquer des champs définis par l'utilisateur aux Documents. Les champs personnalisés sont déjà utilisés dans la convention de nommage et les Sujets.

Il s'agit de métadonnées qui nous aident à travailler de manière plus structurée sur la plateforme. Les projets travaillent souvent avec une clé de plan, la convention de nommage. Cela fournit déjà une structure prédéfinie selon laquelle les Documents ou les modèles (fichiers) sont organisés. Si nous voulons également Lier des métadonnées supplémentaires aux fichiers, cela peut être fait via les Étiquettes ou les champs définis par l'utilisateur, par exemple. > **Remarque :** **Exemple :** Les champs définis par l'utilisateur peuvent être utilisés pour ajouter des commentaires aux Documents. **Remarque :** En utilisant la valeur par défaut, les Documents sont automatiquement fournis avec une valeur prédéfinie correspondante dès qu'ils sont téléchargés vers le dossier correspondant. L'Historique du Document suit également chaque processus individuel ici.

Pour appliquer les champs définis par l'utilisateur aux Documents, procédez comme suit :

1. Créez le champ défini par l'utilisateur souhaité
1. Assignez le champ défini par l'utilisateur créé à un ou plusieurs dossiers

    <div class="intercom-container"><img src="https://raw.githubusercontent.com/catenda/help-center/main/images/grv9pef1/inline-ba695fa6aebd.png" width="496"/></div>

1. Définissez si le champ défini par l'utilisateur doit être assigné à un Document (à travers les révisions) ou à chaque révision individuelle

    <div class="intercom-container"><img src="https://raw.githubusercontent.com/catenda/help-center/main/images/grv9pef1/inline-20eab3b097ce.png" width="500"/></div>

1. Définissez les valeurs par défaut, si souhaité

    <div class="intercom-container"><img src="https://raw.githubusercontent.com/catenda/help-center/main/images/grv9pef1/inline-7241dd9f32dd.png" width="500"/></div>

1. Dans la zone du Document, vous pouvez maintenant reconnaître le champ défini par l'utilisateur assigné sur le Document sous les dossiers dans les informations du Document.

    <div class="intercom-container"><img src="https://raw.githubusercontent.com/catenda/help-center/main/images/grv9pef1/inline-f4243a01e272.png" width="500"/></div>

> **Remarque :** Les champs personnalisés sont également disponibles dans la zone de filtrage ou la barre de recherche.
