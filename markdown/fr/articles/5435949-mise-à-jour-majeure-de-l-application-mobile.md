# Mise à jour majeure de l'application mobile

Nous sommes ravis de publier une mise à jour majeure de l'application mobile Bimsync. Cette fois, nous avons vraiment amélioré la navigation de la Visionneuse en utilisant la vue 2D pour naviguer rapidement exactement où vous voulez être en 3D. Nous avons également ajouté :

- Création de problème améliorée - Capturez d'abord, puis ajoutez des informations et attribuez.
- Mesure laser en 3D.
- Intégré de nombreux nouveaux outils d'édition d'images.
- Ajout de paramètres de performance pour gérer la visualisation du model sur les appareils plus anciens.

## 1. **Navigation 2D/3D**

La fonction de navigation en écran partagé vous permet de déplacer votre emplacement en 3D en utilisant le curseur dans l'aperçu 2D. Vous pouvez ajuster les deux vues à la volée.

Voici comment configurer la vue 2D/3D : 1\. Chargez les models que vous voulez voir dans les vues 2D et 3D. 2\. Cliquez sur le bouton 2D/3D. L'écran se divise en vues 2D et 3D. Vous pouvez déplacer le fractionnement pour augmenter la taille d'une vue selon votre focus. Sur les tablettes en mode paysage, les vues s'affichent côte à côte.

<div class="intercom-container"><a href="https://cloud.headwayapp.co/changelogs_images/images/big/000/071/807-f02572267c31d3134d0c1974f12f2408b09b193a.png" target="_blank"><img alt="Choose 2D_3D.png" src="https://raw.githubusercontent.com/catenda/help-center/main/images/xxhcm1ew/inline-60ce4a5eda79.png"/></a></div>

3\. Utilisez le curseur pour naviguer dans la vue 2D vers la position 3D que vous souhaitez :

<div class="intercom-container"><a href="https://cloud.headwayapp.co/changelogs_images/images/big/000/071/810-e1a99207f18a9868ffaf36107a6791c0217e0e5d.png" target="_blank"><img alt="2D-3d split screen 1.png" src="https://raw.githubusercontent.com/catenda/help-center/main/images/xxhcm1ew/inline-69534a7a9da4.png"/></a></div>

4\. Ouvrez les outils 2D ou 3D pour manipuler le contenu dans chaque vue.

<div class="intercom-container"><a href="https://cloud.headwayapp.co/changelogs_images/images/big/000/071/811-7b8c171290e26c00e00898a4970f006f113507f9.png" target="_blank"><img alt="2D_3D split screen2.png" src="https://raw.githubusercontent.com/catenda/help-center/main/images/xxhcm1ew/inline-12f652337e81.png"/></a></div>

6\. Alignez la vue 3D sur l'étage dans la vue 2D en utilisant ce bouton de synchronisation. Vous êtes maintenant positionné au niveau indiqué dans la vue 2D. En utilisant le curseur en 2D, vous pouvez vous déplacer autour de l'étage et arriver rapidement à votre emplacement souhaité en 3D.

<div class="intercom-container"><a href="https://cloud.headwayapp.co/changelogs_images/images/big/000/071/812-25426b567a0ccf8920a688506ae7033730618a0d.png" target="_blank"><img alt="2D_3D split screen3.png" src="https://raw.githubusercontent.com/catenda/help-center/main/images/xxhcm1ew/inline-0be9894fc47a.png"/></a></div>

À tout moment, vous pouvez revenir à la vue 2D ou 3D complète en choisissant les boutons 2D ou 3D dans la barre d'outils en bas de l'écran.

## 2. **Pièces jointes de problème**

Capturez d'abord, puis documentez. Choisissez de prendre une photo, d'ajouter une image de la galerie de votre appareil ou un point de vue 3D en utilisant cette barre d'actions :

<div class="intercom-container"><a href="https://cloud.headwayapp.co/changelogs_images/images/big/000/071/820-e5736deaf0776090ea038cb5c5ab58c6e1d3ea79.png" target="_blank"><img alt="New issue action bar.png" src="https://raw.githubusercontent.com/catenda/help-center/main/images/xxhcm1ew/inline-b6643c1866d7.png"/></a></div>

Ajoutez simplement un titre et vous pouvez enregistrer le problème, puis remplissez les informations restantes et assignez ultérieurement.
