# Aperçu 3D des documents

> Prévisualisez votre modèle directement dans la section Documents de Bimsync.

Lorsque vous téléchargez un fichier IFC ou un [nuage de points](https://support.catenda.com/en/articles/5606625-point-clouds-in-catenda-hub) dans la section Documents, un aperçu est généré qui vous permet de voir le modèle 3D dans la [section Documents](https://support.catenda.com/en/articles/8204673-documents-page). Cet aperçu est généré rapidement car seules les formes des objets sont traitées sans aucune donnée qui leur est associée. S'il y a un problème avec vos données, vous pourrez donc voir l'aperçu même s'il y a une erreur avec les propriétés de vos objets. Parce que les objets n'ont pas d'ID, vous ne pourrez pas les lier aux problèmes et aux Documents. Si vous cliquez sur les révisions, vous pourrez également charger cet aperçu dans la [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer). Les GUID, les propriétés et les matériaux ne seront donc pas visibles dans la section d'inspection. Il ne sera également pas possible d'utiliser les Bibliothèques avec ces aperçus.

Si vous souhaitez voir les données associées à vos objets, veuillez créer un modèle dans la section des modèles. Lorsque vous téléchargez un fichier IFC dans un modèle de la section des modèles, le traitement est complet, ce qui prend légèrement plus de temps.
