# Recevoir les notifications qui vous conviennent

Recevoir des notifications concernant les actions dans Catenda Hub est important pour pouvoir suivre les activités des projets dont vous faites partie. Les notifications se trouvent à plusieurs endroits dans Catenda Hub.

## 1. **Notifications de compte**

Toutes les notifications de tous les projets sont visibles sur la [page des notifications de compte](https://support.catenda.com/fr/articles/7439223-page-des-notifications-de-compte). Ici, vous pourrez [filtrer toutes les notifications](https://support.catenda.com/fr/articles/8304417-filtrage-sur-la-page-des-notifications) que vous avez reçues.

### 1.1 **Page de notifications de compte**

Sur la [page des notifications de compte](https://support.catenda.com/fr/articles/7439223-page-des-notifications-de-compte), vous verrez toutes les notifications que vous avez reçues de tous vos projets.

### 1.2 **Page des paramètres de notification de compte**

Vous pouvez configurer les notifications que vous souhaitez recevoir pour tous vos projets ensemble sur la [page des paramètres de notification de compte](https://support.catenda.com/fr/articles/8272435-parametres-de-notification-de-compte).

## 2. **Notifications de projet**

Au sein d'un projet, il y a plusieurs endroits où vous pouvez voir les notifications.

### 2.1 **Tableau de bord**

Ici, vous voyez les [5 notifications les plus récentes](https://support.catenda.com/fr/articles/8212646-page-tableau-de-bord#h_77effb806b) qui ont été générées par les utilisateurs du projet

### 2.2 **Page des notifications de projet**

Ici, vous voyez toutes les [notifications générées par les utilisateurs](https://support.catenda.com/fr/articles/4670295-page-de-notifications-de-projet) du projet. Sur cette page, vous pourrez [filtrer toutes les notifications](https://support.catenda.com/fr/articles/8304417-filtrage-sur-la-page-des-notifications) qui ont été générées par les utilisateurs du projet.

### 2.3 **Paramètres de notification spécifiques au projet**

Ici, vous pouvez [configurer les notifications](https://support.catenda.com/fr/articles/4670262-parametres-de-notifications-specifiques-au-projet) que vous souhaitez recevoir pour le projet dans lequel vous êtes. Ce paramètre remplacera le paramètre de notification de compte.

### 2.4 **Paramètres - Membres - Membre**

Si vous accédez à la page d'un membre, vous verrez les [sujets générés par cet utilisateur](https://support.catenda.com/fr/articles/8228836-page-des-membres#h_6b76063480) dans le projet.

### 2.5 **Paramètres - Membres - Équipe**

Si vous accédez à une page d'équipe sur la page des membres, vous verrez les [sujets concernant cette équipe](https://support.catenda.com/fr/articles/7891755-page-d-equipe#h_f91b3824f4) dans le projet.
