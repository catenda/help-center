# Où trouver les notifications

Vous trouverez le bouton Notifications dans le menu principal ou en haut à droite de l'écran en cliquant sur votre photo de profil.

Celui en haut à droite de l'écran vous affiche [les notifications de tous les projets dont vous faites partie](https://bimsync.com/notifications). Celui dans le menu de navigation de gauche

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bwfkbb29/01-intro.png)

vous affiche les notifications du projet dans lequel vous êtes.

Il est également possible de trouver les notifications de projet pour chaque membre/équipe du projet en accédant à ce membre/équipe dans Paramètres -> Membres.

## 1. Comment utiliser les notifications

Le système de notifications est utile pour suivre ce qui se passe dans les bâtiments et les sites que vous souhaitez suivre. Il vous indique s'il y a quelque chose de nouveau - par exemple, si une nouvelle révision d'un bâtiment est téléchargée ou si quelqu'un vous a assigné un problème.

**Paramètres de notification :** Les paramètres de notifications peuvent être trouvés comme une sous-page des Notifications. Vous y trouverez une liste de filtres pour les notifications que vous souhaitez recevoir. <a class="intercom-content-link" href="" target="_blank">Voir ici</a>
