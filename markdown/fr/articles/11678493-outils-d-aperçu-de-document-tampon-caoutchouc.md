# Outils d'aperçu de document - Tampon caoutchouc

L'outil de tampon caoutchouc se trouve dans le [menu insérer](https://support.catenda.com/en/articles/11384618-document-preview-tools#h_34b84f09b9) de la barre d'outils d'aperçu de document et peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bp0tzcba/01-intro.png)

Les rubriques suivantes sont décrites dans cet article :

## 1. Menu prédéfini

Après avoir sélectionné, vous verrez le tampon par défaut dans le menu prédéfini vers le milieu de la barre d'outils. Le menu prédéfini peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bp0tzcba/02-preset-menu.png)

Sélectionnez votre tampon en cliquant sur le tampon par défaut dans le menu prédéfini, ou en développant le menu prédéfini et en sélectionnant votre tampon préféré. Le menu prédéfini peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bp0tzcba/03-preset-menu.png)

## 2. Types de tampon

Les types de tampon du menu prédéfini peuvent inclure les informations suivantes :

Les rubriques suivantes sont décrites dans cette section :

### 2.1 Champs dynamiques

**Nom d'utilisateur** Le nom d'utilisateur du compte avec lequel vous êtes connecté. Pour les noms d'utilisateur sans espaces demi-chasse en eux, un nombre limité de types de tampons de nom d'utilisateur sera disponible comme indiqué ci-dessus. Pour les noms d'utilisateur avec des espaces demi-chasse, plus de types de tampons de nom d'utilisateur seront disponibles. Tous les tampons de nom d'utilisateur peuvent ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bp0tzcba/04-dynamic-fields.png)

**Date et heure** La date et l'heure du moment où vous avez chargé pour la dernière fois l'aperçu du document. La date et l'heure des champs par défaut sont toujours écrites comme AAAA/MM/JJ Si vous souhaitez un tampon avec un format différent, vous pouvez le spécifier dans le menu de création d'un nouveau tampon.

### 2.2 Contenu du type de tampon

Dans le menu prédéfini, les tampons suivants peuvent être vus : _​_**Prénom** - Tout avant le premier espace du nom du compte

**Deuxième prénom Nom** - Tout après le premier espace du nom du compte

**Prénom Deuxième prénom Nom** - Nom complet du compte

**Prénom** - Tout avant le premier espace du nom du compte Date

**Deuxième prénom Nom** - Tout après le premier espace du nom du compte Date

**Prénom Deuxième prénom Nom** - Nom complet du compte Date

**Prénom** - Tout avant le premier espace du nom du compte Date et heure

**Deuxième prénom Nom** - Tout après le premier espace du nom du compte Date et heure

**Prénom Deuxième prénom Nom** - Nom complet du compte Date et heure

**APPROUVÉ** Nom complet du compte et date

**APPROUVÉ AVEC COMMENTAIRE** Nom complet du compte et date

**REJETÉ** Nom complet du compte et date

**EXAMINÉ** Nom complet du compte et date

**INVALIDE** Nom complet du compte et date

**BROUILLON** Nom complet du compte et date

**PRÊT POUR LA CONSTRUCTION** Nom complet du compte et date

**PAS POUR LA CONSTRUCTION** Nom complet du compte et date

**DOCUMENT D'APPEL D'OFFRES** Nom complet du compte et date

## 3. Créer un nouveau tampon

Cliquez sur Créer un nouveau tampon pour ouvrir la boîte de dialogue Créer un nouveau tampon. La boîte de dialogue Créer un nouveau tampon peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bp0tzcba/05-create-new-stamp.png)

Les rubriques suivantes sont décrites dans cette section :

### 3.1 Texte du tampon - Par défaut - Brouillon

Ajoutez du texte comme "approuvé" ou "rejeté"

### 3.2 Style de police - Par défaut - Helvetica, Gras

Sélectionnez la police et le style de police

### 3.3 Couleur du texte - Par défaut - Blanc

Noir, Blanc ou choisissez votre propre couleur de texte

### 3.4 Couleur de l'arrière-plan - Par défaut - Vert

Vert, Bleu, Rouge ou choisissez votre propre couleur d'arrière-plan

### 3.5 Texte horodaté - Par défaut - Tout sélectionné

Choisissez si vous souhaitez inclure le nom d'utilisateur, la date et/ou l'heure

### 3.6 Format de date - Par défaut - JJ/MM/AAAA h:mm A

Sélectionnez votre format de date préféré
