# À propos de Catenda Desktop Connector pour les images système

> Une version de Catenda Desktop Connector pour les organisations qui installent des logiciels dans une image de système d'exploitation, qui peut être demandée.

Le Catenda Desktop Connector planifie les envois et les téléchargements entre Catenda Hub et un ordinateur, et est décrit dans [Catenda Desktop Connector](https://support.catenda.com/fr/articles/8358861-connecteur-catenda-desktop). Une version destinée aux organisations qui installent des logiciels dans une image de système d'exploitation peut être demandée.

## 1. **Ce qu'il est**

C'est la même application que Catenda Desktop Connector standard, packagée pour s'installer par utilisateur au lieu de pour l'ensemble de l'ordinateur. Cela convient aux ordinateurs et aux bureaux virtuels configurés à partir d'une image préparée, comme une image golden dans Citrix.

## 2. **Mise en route**

Catenda Desktop Connector fonctionne avec des projets dans Catenda Hub. Pour l'utiliser, contactez la vente Catenda pour commencer avec un premier projet : [https://catenda.com/get-started](https://catenda.com/get-started) ou [sales@catenda.com](mailto:sales@catenda.com).

> **Remarque :** Davantage de contenus sont disponibles pour les clients Catenda. Connectez-vous à Catenda sur [https://hub.catenda.com](https://hub.catenda.com), puis ouvrez ou actualisez une page du Centre d'aide. Le Centre d'aide présente alors davantage de contenus aux clients connectés, à commencer par [Introduction to Catenda Desktop Connector for System Images](https://support.catenda.com/fr/articles/17778688-introduction-au-connecteur-bureau-catenda-pour-images-systeme) _(réservé aux clients connectés)_.
