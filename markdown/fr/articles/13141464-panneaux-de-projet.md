# Panneaux de projet

Au niveau du projet, les boutons du panneau principal sont toujours affichés en haut à droite, peu importe la page du projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/01-intro.png)

Voici à quoi peuvent ressembler les icônes du panneau en haut à droite :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/02-intro.png)

Sur les appareils avec un espace d'écran limité, un bouton appelé vue s'affiche à la place. Cliquez sur vue pour basculer entre les différents panneaux.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/03-intro.png)

## 1. **Ouverture de panneaux**

Les panneaux peuvent être ouverts de différentes façons.

### 1.1 **Ouverture automatique**

Par défaut, lorsqu'un projet est ouvert à partir de la page des projets, la page de contenu est ouverte et la page du tableau de bord s'affiche. Il y a plusieurs situations où la visionneuse du modèle/panneau 3D s'ouvre automatiquement.

### 1.2 **Ouverture manuelle et fermeture de panneaux**

**Appareils avec écrans plus grands** Lorsqu'un panneau est ouvert, il est mis en surbrillance en vert. Sélectionnez un panneau qui n'est pas encore actif pour l'ouvrir côte à côte avec les autres panneaux actifs. Sélectionnez un panneau actif pour le désactiver. Il doit y avoir au moins un panneau actif à la fois. Par exemple, pour passer du panneau de contenu au panneau 3D, activez d'abord le panneau 3D avec le panneau de contenu, puis désactivez le panneau de contenu pour n'avoir que le panneau 3D actif.

Pour basculer facilement entre les différents panneaux, des raccourcis clavier peuvent être utilisés. Maj+1 pour le panneau de contenu principal Maj+2 pour le panneau de la visionneuse du modèle Maj+3 pour le panneau d'arborescence du modèle Maj+4 pour le panneau d'informations du modèle

**Appareils avec espace d'écran limité** Le panneau ouvert a un fond gris. Sélectionnez un autre panneau pour basculer vers ce panneau. Avec un espace d'écran limité, il n'est possible d'avoir qu'un seul panneau ouvert à la fois.

## 2. **Panneau de contenu principal**

Le panneau de contenu principal est le premier panneau et contient le plus d'informations. Certains utilisateurs travaillent strictement dans le panneau de contenu. Ce panneau est également appelé panneau de contenu.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/04-main-content-panel.png)

Le panneau de contenu peut contenir les pages principales suivantes :

Tableau de bord Modèles Sujets Documents Bibliothèques Rapports Notifications Paramètres

Cliquez [ici](https://support.catenda.com/en/articles/8212646-dashboard-page) pour en savoir plus sur le panneau de contenu.

## 3. **Panneau de la visionneuse du modèle**

Le panneau de la visionneuse du modèle est le deuxième panneau. Ce panneau est également appelé panneau de la visionneuse 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/05-model-viewer-panel.png)

Le panneau de la visionneuse du modèle peut contenir les pages principales suivantes :

Outils de visionneuse 3D Visionneuse 2D

Cliquez [ici](https://support.catenda.com/en/articles/8227211-3d-viewer) pour en savoir plus sur le panneau 3D.

## 4. **Panneau d'arborescence du modèle**

Le panneau d'arborescence du modèle est le troisième panneau. Ce panneau est également appelé panneau d'arborescence.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/06-model-tree-panel.png)

Le panneau d'arborescence peut contenir les pages principales suivantes :

Arborescence de contenance Arborescence des composants Arborescence de type Arborescence des couches Arborescence du système

Cliquez [ici](https://support.catenda.com/en/articles/4670290-trees-panel) pour en savoir plus sur le panneau d'arborescence.

## 5. **Panneau d'informations du modèle**

Le panneau d'informations du modèle est le quatrième et dernier panneau. Ce panneau est également appelé panneau d'inspection.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/39gcn7x2/07-model-info-panel.png)

Le panneau d'informations peut contenir les pages principales suivantes :

Inspection Calcul de quantités (QTO) Sélection 4D Mesure

Cliquez [ici](https://support.catenda.com/en/articles/4670285-inspect-menu) pour en savoir plus sur le panneau de contenu.
