# Localisation 2D des sujets - Catenda Site

La localisation peut être appliquée aux sujets en plaçant un marqueur à une coordonnée x, y, z dans la [Visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer). Les points colorés marquent la localisation des sujets dans la Visionneuse 2D en donnant une compréhension visuelle immédiate de l'endroit où se trouvent les sujets ainsi que leur Statut et leur type. En utilisant les localisations des sujets, votre projet peut bénéficier d'un contrôle considérablement amélioré sur le placement des sujets. Cette fonctionnalité complète les fonctionnalités de notre application de navigateur, [Catenda Hub](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site). Avec les marqueurs, les projets sont dotés d'une création, d'un suivi et d'une gestion transparents des sujets créés sur le terrain, de retour au bureau.

Voici à quoi les marqueurs peuvent ressembler dans la Visionneuse 2D de Catenda Site :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/01-intro.png)

## 1. **Sujets avec marqueurs existants**

### 1.1 **Interaction avec les marqueurs**

Appuyez sur un marqueur sur Catenda Site pour afficher le numéro du sujet et le titre du sujet auquel appartient ce marqueur. Voici à quoi peut ressembler un marqueur appuyé sur Catenda Site.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/02-interacting-with-markers.png)

### 1.2 **Affichage des marqueurs**

Pour travailler avec les sujets et les localisations, ouvrez le menu Visionneuse 2D/3D.

**Sélectionner un tableau de sujets** Sélectionnez un tableau de sujets pour voir les marqueurs de l'étage à partir de ce tableau de sujets.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/03-displaying-markers.png)

Si un étage a été configuré dans le configurateur d'étage, le premier étage du premier bâtiment s'ouvrira par défaut dès que le menu Visionneuse 2D/3D aura été ouvert.

**Filtrer le tableau de sujets** Réduisez le nombre de marqueurs à l'écran en filtrant le tableau de sujets.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/04-displaying-markers.png)

> **Avertissement 1 :** Lorsque le menu des sujets est ouvert, les marqueurs des 250 premiers sujets du résultat sont mis à jour et stockés. Lorsque la Visionneuse 2D est ouverte, les marqueurs des sujets précédemment mis à jour qui correspondent au résultat du menu des sujets sont affichés. Notez que les marqueurs des sujets peuvent être répartis sur des étages autres que l'étage actif. **Avertissement 2 :** S'il y a 250+ sujets dans le résultat du menu des sujets, les marqueurs peuvent ne pas avoir été chargés ou peuvent être obsolètes. Faites défiler la liste pour afficher/mettre à jour leurs marqueurs également. Le filtrage du tableau de manière à avoir moins de sujets dans le résultat peut également aider à garantir que les marqueurs appartenant aux sujets du résultat filtré sont également mis à jour et affichés. **Avertissement 3 :** Lors de la déconnexion de l'application et de la reconnexion, l'Historique des sujets qui ont été chargés est perdu et les sujets qui ont été précédemment chargés devront peut-être être chargés à nouveau.

**Développer la vue 2D** Faites glisser le diviseur entre les Visionneuses 2D et 3D pour le développer.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/05-displaying-markers.png)

Sélectionnez un étage à partir d'un modèle IFC ou d'un bâtiment configuré en appuyant sur le menu d'étage en haut à gauche.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/06-displaying-markers.png)

### 1.3 **Recherche de sujets à partir de marqueurs**

**Recherche d'un sujet à partir d'un marqueur sur un étage dans la vue 2D** Appuyez sur un marqueur dans la vue 2D pour voir le numéro du sujet et le titre du sujet auquel il appartient. Appuyez sur la flèche du marqueur sélectionné pour afficher le sujet sélectionné dans son tableau de sujets sur la page des sujets.

**Recherche d'un marqueur dans la Visionneuse 2D à partir d'un sujet** Recherchez un sujet qui indique "A une localisation" dans le champ Localisation et appuyez sur celui-ci.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/07-finding-topics-from-markers.png)

Dans le menu qui s'ouvre, appuyez sur "Afficher la localisation sur 2D" :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/08-finding-topics-from-markers.png)

Lorsqu'un sujet est ouvert dans un tableau de sujets, la couleur de ce marqueur est mise en évidence en vert avec une coche dans le menu 2D/3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/09-finding-topics-from-markers.png)

### 1.4 **Modification des marqueurs**

**Déplacement des marqueurs** Appuyez sur le champ de localisation d'un sujet et appuyez sur remplacer la localisation dans le menu qui s'ouvre. Faites glisser le marqueur avec l'ancre vers sa nouvelle localisation et confirmez.

**Suppression des marqueurs** Appuyez sur le champ de localisation d'un sujet et appuyez sur remplacer la localisation dans le menu qui s'ouvre. Appuyez sur supprimer la localisation.

### 1.5 **Configuration des marqueurs**

Appuyez sur l'icône d'engrenage dans la Visionneuse 2D pour ouvrir les [paramètres](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site#h_63e1728758) de la Visionneuse 2D de Catenda Site

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/10-marker-configuration.png)

Voici les différentes options de Visionneuse 2D qui peuvent être configurées.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/11-marker-configuration.png)

**Visibilité des marqueurs** Activez ou désactivez les marqueurs

**Mode de coloration des marqueurs** Modifiez le type de couleur que vous souhaitez que les marqueurs aient

**Format du nom de l'espace** Les pièces peuvent avoir des noms courts ou longs dans un fichier IFC

## 2. **Sujets avec nouveaux marqueurs**

### 2.1 **Créer un nouveau sujet avec un marqueur**

Le bouton plus vert dans un tableau de sujets n'est pas la seule façon de créer un sujet. Appuyez n'importe où sur la Visionneuse 2D pour créer un sujet à cet endroit.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/12-create-a-new-topic-with-a-marker.png)

Le sujet créé de cette façon aura automatiquement le marqueur appliqué à cet endroit.

### 2.2 **Ajouter un marqueur à partir d'un sujet**

Créez un nouveau sujet ou ouvrez un sujet sans marqueur et appuyez sur "Localisation".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/13-add-marker-from-topic.png)

Le menu 2D/3D s'ouvrira maintenant et un nouveau marqueur avec une ancre s'affichera en vert :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/6mjtp9hj/14-add-marker-from-topic.png)

Effectuez un zoom avant dans la Visionneuse 2D en pinçant avec deux doigts et déplacez le marqueur vers le bon endroit et cliquez sur la coche pour le verrouiller en position.
