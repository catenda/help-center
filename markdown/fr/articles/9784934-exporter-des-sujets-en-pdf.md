# Exporter des sujets en PDF

Les sujets peuvent être exportés en PDF en cliquant sur l'option PDF dans le [dialogue d'export de sujets](https://support.catenda.com/en/articles/4670289-exchange-topics#h_aa0b8d7789). L'export PDF vous permettra d'exporter un rapport de vos sujets. Cette option d'export est utile pour avoir une version facilement lisible des sujets et peut être utilisée à des fins d'archivage ou pour signaler aux autorités.

Cette page contient des informations sur les sujets suivants :

## 1. **Paramètres qui affectent toutes les pages du PDF**

Ces paramètres affectent toutes les pages du PDF

### 1.1 **Logo**

Le logo en haut à gauche de chaque page du PDF sera le logo Catenda par défaut. En cliquant sur le logo ou sur hub.catenda.com en haut à droite, vous serez redirigé vers la page des projets. Il est possible de télécharger un logo personnalisé sur la [page des paramètres du projet](https://support.catenda.com/en/articles/4670273-project-settings-page) pour afficher votre propre logo ici.

### 1.2 **Langue**

L'export PDF sera dans la langue que vous avez configurée dans vos [préférences de compte](https://support.catenda.com/en/articles/6880968-account-page#h_4aa257b72f).

### 1.3 **Ordre des sujets**

Si vous avez trié les sujets dans votre liste de sujets de quelque manière que ce soit, l'ordre dans lequel les sujets apparaîtront dans le rapport reflétera l'ordre dans lequel vous avez trié votre liste de sujets.

## 2. **Page de couverture**

Le PDF téléchargé contiendra une page de couverture. Ici, vous verrez l'image de profil du projet ainsi que les détails d'export suivants : La page de couverture peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/nx64p9qh/01-front-page.png)

### 2.1 **Nom du projet**

Le nom du projet

### 2.2 **Exporté**

Le nombre de sujets et à partir de quelle liste de sujets ils ont été exportés. En cliquant sur le nom de la liste de sujets, vous serez redirigé vers cette liste de sujets.

### 2.3 **Heure de l'export**

L'heure du fuseau horaire UTC au moment de l'export PDF.

### 2.4 **Vue d'ensemble des sujets**

Les sujets qui font partie de cet export seront répertoriés ci-dessous. En cliquant sur le nom du sujet, vous serez redirigé vers ce sujet sur Catenda Hub.

## 3. **Pages de sujets**

Une page pour chaque sujet avec tous les détails de chaque sujet sera ajoutée après la page de couverture. Une page de sujet typique peut ressembler à ce qui suit :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/nx64p9qh/02-topic-pages.png)

### 3.1 **Titre**

Le titre du sujet suivi du numéro du sujet sur Catenda.

### 3.2 **Métadonnées incluses**

Les en-têtes suivants sont inclus :

**Type** Le type du sujet

**Statut** Le statut du sujet

**Assigné à** L'assigné du sujet

**Créé par** Le créateur du sujet

**Créé** L'heure de la première création du sujet

**Fermé à** Si le sujet est fermé, l'heure la plus récente de fermeture du sujet est affichée ici.

**Échéance** L'échéance

**Champs personnalisés de la liste de sujets** Chaque champ personnalisé et sa valeur, s'il y en a un, sont inclus

**Étiquettes** Les étiquettes sont répertoriées avec le nom et la couleur.

### 3.3 **En-têtes de sujets exclus**

**Étape** Les étapes ne sont pas incluses dans l'export PDF.

**Marqueur** Cliquez [ici](https://support.catenda.com/en/articles/4854523-2d-location-of-topics) pour en savoir plus sur l'export de la localisation 2D en PDF.

### 3.4 **Relations de sujets**

Les liens vers les relations de sujets sur Catenda sont inclus dans l'export PDF. Les éléments associés ne sont pas exportés automatiquement, veuillez donc envisager d'exporter ces informations séparément.

**Sujets** Si des sujets sont liés au sujet exporté, chaque sujet est répertorié avec un lien vers ce sujet sur Catenda.

> **Remarque :** Ces sujets ne sont pas nécessairement inclus dans le rapport car ils peuvent provenir d'une liste de sujets différente avec des paramètres d'accès différents.

**Documents** S'il y a des documents liés au sujet, vous les verrez répertoriés ici avec des liens vers chaque document dans Catenda.

### 3.5 **Description**

La description du sujet

### 3.6 **Commentaires**

Si des commentaires ont été placés sur le sujet, vous les verrez ici. Vous verrez d'abord le nom d'utilisateur de l'auteur du commentaire, puis la date à laquelle il a publié le commentaire, suivi de toutes les images jointes et du texte du commentaire.

## 4. **Page de rapports**

Avec la page de rapports, il est possible de créer des rapports personnalisés non seulement sur les sujets mais aussi sur les documents. La page de rapports est une fonctionnalité à la demande qui peut être demandée pour être activée pour les projets en cours. Les nouveaux projets créés à partir d'un projet de modèle où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Ces rapports peuvent ensuite être exportés non seulement vers Excel et PDF, mais aussi vers de nombreux autres formats de fichier. Ces rapports peuvent également exporter des sujets à partir de plusieurs listes de sujets à la fois. Cliquez [ici](https://support.catenda.com/en/articles/12303098-reports-page) pour en savoir plus sur la page de rapports
