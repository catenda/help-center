# Catenda Site - Dépannage

## 1. Aucune connexion au réseau

Les projets qui n'ont pas été précédemment chargés afficheront le message d'erreur suivant lors d'une tentative d'ouverture sans connexion au réseau :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8pwddg4t/01-no-connection-to-the-network.png)

Pour utiliser un projet Catenda dans Catenda Site sans connexion au réseau, veuillez d'abord ouvrir le projet avec une connexion au réseau.

## 2. Les sujets ne se synchronisent pas

Si des modifications ont été apportées sur Catenda Site et ne sont pas visibles dans d'autres sessions, elles doivent probablement être soumises dans [la boîte d'envoi](https://support.catenda.com/en/articles/7325268-offline-mode-in-catenda-site#h_ff2a47f221) en haut à droite du tableau des sujets.

## 3. Code MFA requis

Si vous voyez le message suivant indiquant que l'authentification multifacteur est requise lors de la tentative d'ouverture d'un projet, veuillez vous connecter à votre compte Catenda via un navigateur et [configurer un appairage de code](https://support.catenda.com/en/articles/4969891-multi-factor-authentication) dans les paramètres de votre compte.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8pwddg4t/02-mfa-code-required.png)
