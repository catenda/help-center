# Filtre d'étiquettes - Catenda Site

Il est possible de filtrer par étiquette dans [Problèmes](https://support.catenda.com/en/articles/7734073-issues-page-catenda-site) et dans [Documents](https://support.catenda.com/en/articles/7774637-documents-catenda-site).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ge4vaaph/01-intro.png)

Choisissez les étiquettes que vous souhaitez filtrer et appuyez sur Terminé pour appliquer votre filtre.

### Modifications d'étiquettes depuis d'autres appareils

Pour voir les modifications d'étiquettes dans ce menu de filtre qui ont été effectuées sur un autre appareil, accédez à la [page du projet](https://support.catenda.com/en/articles/7733978-projects-page-catenda-site) et rouvrez le projet. De même, vous ne pourrez pas voir une nouvelle étiquette externe tant que le projet n'aura pas été rechargé.

### Icône de réinitialisation d'étiquette

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ge4vaaph/02-reset-label-icon.png)

Vous pouvez cliquer sur le bouton de réinitialisation en haut à gauche pour désélectionner toutes les étiquettes sélectionnées. (N.B. Si vous voulez des emojis sympas dans vos filtres, vous pouvez facilement le faire en changeant les noms d'étiquettes dans la version navigateur mobile de Catenda Hub)
