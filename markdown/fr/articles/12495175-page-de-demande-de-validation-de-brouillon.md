# Page de demande de validation de brouillon

Les demandes de validation de brouillon peuvent être ouvertes en cliquant sur une carte de demande de validation de brouillon sur la [page des validations](https://support.catenda.com/en/articles/8349340-approvals-page). _Accès requis :_ Créateur de demande de validation de brouillon

Voici à quoi peut ressembler la page de demande de validation de brouillon :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/006sen4w/01-intro.png)

Les demandes de validation de brouillon ne sont disponibles que pour les projets ayant activé les révisions partagées après le 2 octobre 2025. Il n'est possible de créer un projet basé sur un projet de modèle que si le nouveau circuit de validation n'est pas activé dans ce projet de modèle.

## 1. **Nouvelles actions d'élément**

Voici à quoi peuvent ressembler les actions sur la page de validation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/006sen4w/02-new-item-actions.png)

Utilisez la nouvelle action de demande de validation pour créer une nouvelle demande de validation. Cliquez [ici](https://support.catenda.com/en/articles/12495005-creating-a-new-approval-request?q=draft) pour en savoir plus sur la création d'une nouvelle demande de validation.

## 2. **En-tête de validation**

Voici à quoi peut ressembler l'en-tête de validation dans une demande de validation de brouillon :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/006sen4w/03-approval-header.png)

### 2.1 **Titre**

Le titre de la demande de validation de brouillon. Cliquez sur l'icône de crayon pour modifier le titre.

### 2.2 **Circuit de validation**

Le circuit de validation qui est sélectionné lors de la création de cette validation

### 2.3 **Description**

La description de la validation Avec le nouveau circuit de validation, il n'est pas possible de modifier la description d'une validation après sa création. La description de la validation suit les [règles de mise en forme générales des publications](https://support.catenda.com/en/articles/8430847-formatting-of-posts).

## 3. **Ruban d'étape**

Dans le ruban d'étape, un aperçu de toutes les étapes d'une validation est affiché. Voici à quoi peut ressembler le ruban d'étape dans une demande de validation de brouillon :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/006sen4w/04-step-ribbon.png)

Cliquez [ici](https://support.catenda.com/en/articles/12495212-step-ribbon-in-an-approval-request) pour en savoir plus sur le ruban d'étape.

## 4. **Onglet Documents**

Dans l'onglet Documents d'une validation, un aperçu de chacun des documents qui fait partie de la validation est affiché. Cliquez ici pour en savoir plus sur l'onglet Documents d'une validation
