# Statuts des fonctionnalités Q3 2026

Pour éviter le spam de notifications et assurer un lancement en douceur, les nouveaux comportements ou les modifications des comportements existants peuvent être déployés progressivement et sans préavis. Ceux qui remarquent des modifications du comportement d'une partie d'une page qu'ils utilisent fréquemment ou qui se demandent ce qui est nouveau peuvent consulter ces articles pour obtenir des mises à jour sur les changements récents de comportement pour tous les utilisateurs.

## 1. **Nouvelles fonctionnalités**

Chaque utilisateur utilise la plateforme différemment. Même si une nouvelle fonctionnalité est publiée ou que des modifications sont apportées à une fonctionnalité, il est possible que les utilisateurs n'utilisent pas cette partie de la fonctionnalité. Pour ceux qui sont curieux de savoir ce que "ce nouveau bouton" ou "cette nouvelle page" est sur la plateforme, cet article contient une introduction sur ce que le changement est. Pour ces fonctionnalités, souvent seul le matériel de support de base ou légèrement obsolète est disponible car il est mis à jour au fur et à mesure. Parallèlement à l'aide apportée au support, les articles sont souvent mis à jour et si les questions posées peuvent être rapidement trouvées expliquées dans un article la semaine suivante.

### 1.1 **Dépliage du lien URL Figma dans les sujets**

Les liens d'URL bruts et les liens d'URL au format markdown vers les tableaux Figma se déploient maintenant et affichent le tableau Figma dans les descriptions et les commentaires des sujets.

### 1.2 **Paramètre de langue du compte**

Le roumain est maintenant disponible comme langue d'interface utilisateur.

### 1.3 **Vue Kanban pour les sujets**

Une nouvelle vue Kanban est mise à disposition sur la page des sujets. Trouvez-la en haut à droite du tableau des sujets à côté des vues de liste et de tableau. Organisez, filtrez et mettez à jour les sujets directement sur un tableau Kanban, améliorant la gestion des problèmes, la gestion des tâches et la collaboration en équipe dans Catenda Hub.

### 1.4 **Catenda AI Connect**

Catenda AI Connect est maintenant en direct, apportant une intelligence avancée de manière transparente dans vos workflows existants. Cette capacité peut être déverrouillée comme une extension de fonctionnalité pour les licences de projet existantes, ou demandée directement par les membres du projet externe. Contactez notre équipe d'assistance pour demander l'activation de votre espace de travail.

### 1.5 **Catenda Data Export**

Catenda Data Export est maintenant disponible, offrant des extractions flexibles récurrentes ou ponctuelles adaptées à votre taille d'export totale. Les clients existants peuvent intégrer cette capacité dans leurs projets actuels, tandis que les membres du projet externe peuvent demander un accès autonome. Contactez notre équipe d'assistance pour configurer et activer cette fonctionnalité. Exporter vers le stockage Amazon S3 ou Azure Blob

### 1.6 **Codes QR sur les dessins PDF**

Un outil de code QR est maintenant disponible dans la barre d'outils d'aperçu du document sur les révisions partagées. L'espace réservé peut être placé directement sur le PDF dans Catenda Hub. Auparavant, l'image d'espace réservé devait être téléchargée à partir du Centre d'aide et ajoutée au fichier dans un éditeur PDF avant de l'uploader. Ce n'est plus nécessaire.

**Deux conditions s'appliquent :** L'outil n'apparaît que sur les révisions partagées, donc le projet doit avoir le workflow de statut activé. Les projets où chaque upload est publié immédiatement n'ont pas d'étape de révision partagée pour le placer. Le document doit être dans un dossier avec Assigner le code QR défini sur oui. Ce n'est que dans ce cas que l'espace réservé est reconnu à la publication et remplacé par un code QR Catenda scannable pour cette révision.

L'espace réservé est placé sur la révision partagée, et le code QR est généré lors de la publication de cette révision. Cela fonctionne à la fois lors de la publication à partir de la section des documents et lorsque la publication fait partie d'un workflow d'approbation. Les codes QR sont placés un document à la fois. 📽️ **[Vidéo tutoriel](https://eu.guidde.com/share/playbooks/cdpo9DyYmZWxWvRUrR7LWb?origin=6VMUQTF9wwUsoREWtvRVGILBqzz1&mode=videoAndDoc)**

### 1.7 Liens de tableau blanc affichés dans Hub

Un lien vers un tableau blanc Figma, FigJam ou Miro peut être placé dans une description ou un commentaire de sujet, et le tableau blanc s'affiche ensuite sous le texte. Il s'agit du tableau blanc du service externe, pas du tableau de sujets sur lequel se trouve le sujet lui-même. Ajoutez le lien de la même manière que n'importe quel autre lien dans l'éditeur Markdown, soit comme une URL brute, soit comme un lien au format Markdown. Le tableau blanc apparaît sous la description ou le commentaire une fois qu'il est enregistré. Le tableau blanc n'est affiché que pour les utilisateurs qui sont déjà connectés à Figma ou Miro et qui y ont accès. Catenda n'accorde pas l'accès, l'accès est contrôlé entièrement dans Figma ou Miro, donc un utilisateur sans accès ne voit pas le contenu du tableau blanc.

## 2. **Fonctionnalités mises à jour**

### 2.1 **Améliorations des approbations**

Le nouveau flux de validation publié au Q3 2025 méritait un peu plus d'amour. Les fonctionnalités suivantes ont été ajoutées dans une version de suivi du nouveau workflow d'approbation :

**👁 [Visibilité du statut des examinateurs individuels (3:14):](https://eu.guidde.com/share/playbooks/oAoCAVdJVGQzMTBYvNPHtm?origin=7PqdD6oPp9QLchKHNkCwDH3opRS2&mode=videoAndDoc)** obtenir un aperçu rapide de l'activité de chaque membre au sein d'une équipe assignée à une étape d'approbation, afin que vous puissiez débloquer rapidement les blocages. **[Vidéo Pt. 2 (3:26)](https://eu.guidde.com/share/playbooks/7fc2J2cZfisYp4VnUF2szF?origin=7PqdD6oPp9QLchKHNkCwDH3opRS2&mode=videoAndDoc)** **📄 [Documents dans toutes les approbations ouvertes en une seule vue (3:41):](https://eu.guidde.com/share/playbooks/wWhdRkGbbziaHbnbD9Gj8Y?origin=6VMUQTF9wwUsoREWtvRVGILBqzz1&mode=videoAndDoc)** voir instantanément les documents qui nécessitent votre attention, sans ouvrir les demandes d'approbation individuelles. **🖱 [Accès en un clic à la page d'examen (2:05):](https://eu.guidde.com/share/playbooks/6e4dQJDoPfjAY84XU282Xp?origin=6VMUQTF9wwUsoREWtvRVGILBqzz1&mode=videoAndDoc)** accédez directement à la page d'examen et commencez l'examen. **✅ [Exiger la signature de tous les membres de l'équipe (3:20):](https://eu.guidde.com/share/playbooks/mnNWejVsSnJoH56aHpft5z?origin=6VMUQTF9wwUsoREWtvRVGILBqzz1&mode=videoAndDoc)** assurez-vous que chaque membre de l'équipe d'examen a examiné le document avant qu'il n'avance.

**Édition du titre et de la description d'une approbation** Le titre et la description d'une approbation peuvent maintenant être modifiés après sa soumission. Auparavant, les deux étaient fixes à la création, donc une faute de frappe ou un titre qui ne correspondait plus à la portée de la demande signifiait vivre avec pour la durée de vie de l'approbation, ou annuler et recommencer. L'édition est limitée à la personne qui a créé l'approbation et aux administrateurs du projet. Être membre d'une équipe de soumetteur est ce qui permet de créer une approbation, mais cela ne confère pas le droit de modifier les approbations créées par d'autres membres de la même équipe. Si un collègue l'a créée, la modification n'est pas disponible, le créateur ou un administrateur du projet doit effectuer la modification.

**Descriptions longues dans l'aperçu des approbations** Les descriptions d'approbation longues sont mieux gérées dans l'aperçu des approbations, de sorte qu'une longue description ne repousse plus le reste des informations hors de la vue.

**Colonne Équipes dans le tableau des documents-dans-approbations** La colonne Équipes dans le tableau des documents dans toutes les approbations ouvertes a été améliorée, ce qui facilite la visualisation de l'équipe censée agir sur chaque document.

### 2.2 **Comparaison de documents : comparer le texte, pas seulement les pixels**

La comparaison de documents dispose maintenant d'un mode de comparaison de texte aux côtés du mode de superposition existant. La comparaison de texte lit le contenu textuel réel de deux révisions et met en évidence chaque changement de formulation, afin qu'une spécification ou un contrat puisse être vérifié en quelques secondes plutôt que lu ligne par ligne. Le mode de superposition reste inchangé et reste le bon choix pour les dessins et la géométrie, où une comparaison au pixel est nécessaire. Les deux modes sont derrière la même action Comparer dans la visionneuse de documents, de sorte que le mode qui correspond au document peut être choisi là. La comparaison nécessite un PDF avec au moins deux révisions du même document. Le bouton Comparer apparaît à côté du menu déroulant des révisions quand ces conditions sont remplies. S'il n'est pas visible, le document n'est soit pas un PDF, soit n'a qu'une seule révision. 📽️ **[Vidéo tutoriel](https://eu.guidde.com/playbooks/9hrXCk2DMw75wrspDCvJDv?origin=6VMUQTF9wwUsoREWtvRVGILBqzz1&mode=videoAndDoc)**

## 3. **Activation des fonctionnalités à la demande**

Chaque fonctionnalité à la demande est de qualité production et prête pour un usage réel du projet. Bien que ces fonctionnalités aient été testées pour fonctionner comme prévu, il peut y avoir des degrés différents quant au nombre de projets qui ont commencé à utiliser ces fonctionnalités, de sorte que des cas limites inconnus peuvent être trouvés. Bien que des modifications puissent survenir alors que nous travaillons à rendre ces fonctionnalités disponibles pour tous les utilisateurs, les données soumises dans ces fonctionnalités ne seront pas supprimées.

### 3.1 **Demande d'activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être demandées pour être activées pour les projets existants par la personne de contact de votre licence Catenda tandis que d'autres peuvent être activées par un paramètre du projet. Quand une fonctionnalité à la demande est demandée à être activée, une réunion sera organisée avec un représentant du support pour discuter du statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la fonctionnalité à la demande peut être testée, un projet factice peut être créé pendant une durée limitée où la fonctionnalité à la demande peut être testée pour considérer si la fonctionnalité est prête à être utilisée.

### 3.2 **Éditeur de rapport**

Créer des modèles de rapport pour les sujets et les documents afin que les membres du projet puissent sélectionner des sujets ou des documents dans le tableau et utiliser l'action de rapport pour générer un rapport. La page des rapports est une fonctionnalité à la demande qui peut être demandée à être activée pour les projets en cours. Les nouveaux projets créés sur la base d'un projet modèle où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Des modèles séparés peuvent être créés pour les sujets et les documents. Lorsqu'un modèle est disponible dans un projet, l'action de rapport peut être utilisée avec les sujets et les documents sélectionnés pour générer un rapport basé sur le modèle sélectionné. Le support sur la façon dont différentes valeurs peuvent être affichées sur la page est offert par Catenda. Si vous souhaitez un rapport personnalisé adapté à votre entreprise, nous pouvons vous mettre en contact avec un consultant qui peut vous aider.
