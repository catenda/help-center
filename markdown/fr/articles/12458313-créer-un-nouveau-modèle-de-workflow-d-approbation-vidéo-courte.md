# Créer un nouveau modèle de workflow d'approbation - Vidéo courte

[Vidéo Guidde](https://embed.app.guidde.com/playbooks/eu_fUBwAB5gUE7vhCJsnU1kGi)

Dans ce tutoriel, vous apprendrez comment créer un nouveau modèle de workflow d'approbation dans Catenda Hub.

### **1. Introduction**

Avant de commencer, assurez-vous que vous disposez des permissions nécessaires pour configurer les workflows et que vous connaissez les équipes impliquées dans le processus d'approbation.

![Introduction](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/01-1-introduction.png)

### **2. Accéder à la section Documents**

Accédez à la section documents pour ouvrir la zone principale de gestion des documents, où vous pouvez accéder à divers paramètres et workflows.

![Accédez à la section Documents](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/02-2-go-to-the-documents-section.png)

### **3. Accéder à la section Paramètres**

Accédez à la section Paramètres pour ouvrir les options de configuration de vos documents et workflows.

![Accédez à la section Paramètres](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/03-3-access-the-settings-section.png)

### **4. Accéder à la section Approbations**

Accédez à la section Approbations pour accéder aux paramètres d'approbation et aux modèles de workflow.

![Accédez à la section Approbations](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/04-4-go-to-the-approvals-section.png)

### **5. Cliquez ici pour configurer les workflows**

Cliquez ici pour configurer les workflows afin de gérer et de créer des modèles de workflow d'approbation.

![Cliquez ici pour configurer les workflows](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/05-5-click-here-to-configure-workflows.png)

### **6. Cliquez ici**

Appuyez sur le bouton plus pour commencer à créer un nouveau modèle de workflow d'approbation.

![Cliquez ici](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/06-6-click-here.png)

### **7. Spécifiez le nom de votre nouveau modèle de workflow**

Spécifiez le nom de votre nouveau modèle de workflow pour identifier clairement ce workflow pour une utilisation future.

![Spécifiez le nom de votre nouveau modèle de workflow](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/07-7-specify-the-name-of-your-new-workflow-template.png)

### **8. Définir l'heure de début**

Définissez l'heure de début du processus d'approbation.

![Définissez l'heure de début](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/08-8-set-the-start-time.png)

### **9. Cliquez sur « 09 »**

Cliquez sur « 09 » pour sélectionner 9 heures du matin comme heure de début du workflow.

![Cliquez sur « 09 »](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/09-9-click-09.png)

### **10. Cliquez ici**

Cliquez sur le champ pour ajouter les soumetteurs qui lanceront le processus d'approbation.

![Cliquez ici](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/10-10-click-here.png)

### **11. Sélectionnez @Construction Workshop**

Sélectionnez l'équipe @Construction Workshop comme soumetteurs pour le workflow.

![Sélectionnez @Construction Workshop](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/11-11-select-construction-workshop.png)

### **12. Cliquez ici**

Cliquez ici pour assigner les équipes responsables de l'examen des soumissions.

![Cliquez ici](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/12-12-click-here.png)

### **13. Commencez à taper pour trouver votre équipe**

Commencez à taper pour filtrer et trouver l'équipe entrepreneur.

![Commencez à taper pour trouver votre équipe](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/13-13-start-typing-to-find-your-team.png)

### **14. Sélectionnez @Contractor**

Sélectionnez l'équipe @Contractor comme examinateurs dans le workflow.

![Sélectionnez @Contractor](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/14-14-select-contractor.png)

### **15. Définir la période d'examen pour l'équipe entrepreneur**

Définissez la période d'examen pour l'équipe entrepreneur.

![Définissez la période d'examen pour l'équipe contractante](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/15-15-set-the-review-period-for-the-contractor-team.png)

### **16. Remplissez « 3 »**

Remplissez « 3 » pour permettre trois jours ouvrables à l'équipe entrepreneur pour terminer son examen.

![Remplissez « 3 »](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/16-16-fill-3.png)

### **17. Activer la fonction d'approbation automatique**

Cochez cette case pour activer l'approbation automatique afin de prévenir les goulots d'étranglement. Les documents recevront automatiquement des examens approuvés au nom des équipes qui n'ont pas répondu à la date limite.

![Activez la fonctionnalité d'approbation automatique](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/17-17-activate-the-auto-approve-feature.png)

### **18. Ajouter une étape**

Ajoutez une étape pour inclure une autre phase d'examen dans le workflow.

![Ajouter une étape](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/18-18-add-a-step.png)

### **19. Cliquez ici**

Cliquez ici pour assigner l'équipe suivante responsable de l'examen.

![Cliquez ici](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/19-19-click-here.png)

### **20. Commencez à taper pour filtrer et trouver l'équipe ARC.**

Commencez à taper pour filtrer et trouver l'équipe ARC.

![Commencez à taper pour filtrer et trouver l'équipe ARC.](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/20-20-start-typing-to-filter-and-find-the-arc-team.png)

### **21. Sélectionnez @ARC**

Sélectionnez l'équipe @ARC comme examinateurs à cette étape.

![Sélectionnez @ARC](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/21-21-select-arc.png)

### **22. Définir la période d'examen pour l'équipe architecture.**

Définissez la période d'examen pour l'équipe architecture.

![Définissez la période d'examen pour l'équipe d'architecture.](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/22-22-set-the-review-period-for-the-architecture-team.png)

### **23. Remplissez « 2 »**

Remplissez « 2 » pour permettre deux jours ouvrables à l'équipe ARC pour terminer son examen.

![Remplissez « 2 »](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/23-23-fill-2.png)

### **24. Activer la fonction d'approbation automatique**

Cochez cette case pour activer l'approbation automatique afin de prévenir les goulots d'étranglement.

![Activez la fonctionnalité d'approbation automatique](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/24-24-activate-the-auto-approve-feature.png)

### **25. Ajouter une étape de workflow**

Ajoutez une étape en répétant le même processus décrit précédemment pour inclure une autre phase d'examen dans le workflow. Vous pouvez ajouter autant d'étapes que nécessaire pour votre workflow.

![Ajouter une étape de workflow](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/25-25-add-a-workflow-step.png)

Remplissez « 3 » pour permettre trois jours ouvrables à l'équipe client pour approuver la soumission.

![Remplissez « 3 »](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/30-30-fill-3.png)

### **31. Définir le statut du document après approbation.**

Cliquez ici pour définir le statut du document après approbation.

![Définissez le statut du document après approbation.](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/31-31-define-the-document-status-after-approval.png)

### **35. Cliquez sur Soumettre**

Cliquez sur le bouton Soumettre pour enregistrer et activer le nouveau modèle de workflow d'approbation.

![Cliquez sur Soumettre](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/35-35-click-on-submit.png)

### **36. Trouvez votre nouveau modèle de workflow d'approbation dans votre liste de workflows**

Vous pouvez maintenant trouver votre nouveau modèle de workflow d'approbation dans votre liste de workflows

![Trouvez votre nouveau modèle de workflow d'approbation dans votre liste de workflows](https://raw.githubusercontent.com/catenda/help-center/main/images/81w93hf4/36-36-find-your-new-approval-workflow-template-on-your-workflow-s-list.png)

Vous avez créé avec succès un nouveau modèle de workflow d'approbation avec plusieurs étapes d'examen et équipes assignées. Vérifiez le workflow en examinant le nom du modèle, les équipes assignées, les périodes d'examen et les statuts. Ensuite, vous pouvez appliquer ce workflow à vos projets ou personnaliser des modèles supplémentaires selon vos besoins.
