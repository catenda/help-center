# Page Membres et équipes

La page des membres se trouve en tant que sous-page de la [page des paramètres du projet](https://support.catenda.com/en/articles/4670273-settings-page).

![Membres](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/01-intro.png)

## 1. **Actions**

Le menu d'action se trouve vers le haut à droite de la page.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/02-actions.png)

### 1.1 Inviter un membre

Cliquez sur le bouton plus vert ou sur l'action d'invitation de membre dans le menu d'action pour accéder à la [page d'invitation des membres](https://support.catenda.com/en/articles/4670263-invite-members-page). _Accès requis :_ Administrateur ou [accès à l'invitation de membres](https://support.catenda.com/en/articles/4670273-project-settings-page#h_3b98ced32a) dans les paramètres du projet.

### 1.2 Nouvelle équipe

Avec cette action, vous pourrez créer une [nouvelle équipe](https://support.catenda.com/en/articles/4670264-creating-a-team). _Accès requis :_ Administrateur

## 2. **Rechercher ou filtrer**

Cliquez [ici](https://support.catenda.com/en/articles/11744242-filtering-on-the-members-and-teams-page) pour savoir comment rechercher ou filtrer au mieux sur la page des membres. Voici à quoi peut ressembler la barre de recherche ou de filtre :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/03-search-or-filter.png)

## 3. **Menu de droite**

Avec un élément sélectionné, le bouton info du menu de droite s'affichera vers la droite de la barre de recherche ou de filtre. Le bouton d'information peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/04-right-menu.png)

Cliquez sur cette icône pour ouvrir un menu où les champs des éléments sélectionnés peuvent être modifiés. Cliquez [ici](https://support.catenda.com/en/articles/11768610-right-menu-on-the-members-page) pour en savoir plus sur le menu de droite sur la page des membres.

## 4. **Onglet Membres**

Dans l'onglet des membres, un aperçu de tous les membres qui font partie du projet s'affiche.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/05-members-tab.png)

Dans l'onglet des membres, un tableau avec tous les membres qui font partie du projet s'affiche. Le tableau des membres peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/06-members-tab.png)

Cliquez [ici](https://support.catenda.com/en/articles/11748020-tables-on-catenda) pour en savoir plus sur la façon de travailler avec les tableaux dans Catenda. Dès qu'une invitation au projet est acceptée, le membre qui a accepté l'invitation apparaît dans le tableau des membres.

### 4.1 **Contenu de la ligne**

L'ouverture du contenu d'une ligne de membre ouvre la [page du membre](https://support.catenda.com/en/articles/8228836-member-page) de ce membre.

### 4.2 **Colonnes**

Le tableau des membres peut contenir les colonnes suivantes :

**Case à cocher** La case de sélection de la ligne.

**Nom** Icône - Photos de profil pour les membres ayant une photo de profil. Icône - Initiales pour les membres sans photo de profil. Informations principales - Le nom d'utilisateur du membre. Informations secondaires - L'adresse e-mail du membre. Cliquez sur l'adresse e-mail pour copier l'adresse e-mail de ce membre. Dans les projets où l'authentification multifacteur est requise, un cadenas rouge peut être vu dans la colonne de nom pour les membres qui ont accepté l'invitation au projet mais qui n'ont pas configuré de code de sécurité. Sans le code de sécurité, ces membres ne pourront pas accéder au projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/07-columns.png)

**Rôle** Le rôle du membre. Propriétaire (Bleu) Administrateur (Orange) Membre (Vert)

**Équipes** Chaque membre peut faire partie de plusieurs équipes. L'équipe à laquelle un membre appartient s'affiche dans cette colonne. Équipe administrateur (Orange) Équipe membre (Vert) Si le nombre total d'équipes auxquelles un membre appartient ne s'ajuste pas, ajustez la largeur de la colonne ou cliquez sur les trois points pour voir le reste.

## 5. **Onglet Équipes**

Dans l'onglet des équipes, un aperçu de toutes les équipes du projet s'affiche

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/08-teams-tab.png)

Dans l'onglet des équipes, un tableau avec toutes les équipes qui font partie du projet s'affiche. Le tableau des équipes peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/89wt70pn/09-teams-tab.png)

Cliquez ici pour en savoir plus sur la façon de travailler avec les tableaux dans Catenda.

### 5.1 **Contenu de la ligne**

L'ouverture du contenu d'une ligne d'équipe ouvre la [page de l'équipe](https://support.catenda.com/en/articles/7891755-team-page) de cette équipe.

### 5.2 **Colonnes**

**Case à cocher** La case de sélection de la ligne.

**Nom** Icône - Photos de profil pour les équipes ayant une photo de profil. Icône - Initiales pour les équipes sans photo de profil. Informations principales - @ suivi du nom de l'équipe. Informations secondaires - Le nombre de membres dans l'équipe.

**Rôle** Le rôle de l'équipe. Administrateur (Orange) Membre (Vert)

**Membres** Les membres de cette équipe. Si le nombre total de membres de cette équipe ne s'ajuste pas, ajustez la largeur de la colonne ou cliquez sur les trois points pour voir le reste
