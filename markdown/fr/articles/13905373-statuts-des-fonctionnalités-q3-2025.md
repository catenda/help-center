# Statuts des fonctionnalités Q3 2025

Pour éviter le spam de notifications et assurer un lancement en douceur, les nouveaux comportements ou les modifications des comportements existants peuvent être déployés progressivement et sans avis préalable. Ceux qui remarquent des changements de comportement dans une partie de la page qu'ils utilisent fréquemment ou ceux qui se demandent quelles sont les nouveautés peuvent consulter ces articles pour connaître les derniers changements de comportement pour tous les utilisateurs.

## 1. **Nouvelles versions**

Chaque utilisateur utilise la plateforme différemment. Les notifications émises, même si de nouvelles fonctionnalités sont lancées ou des modifications apportées, il se peut que les utilisateurs n'utilisent pas cette partie de la fonctionnalité. Pour ceux qui se demandent ce que ce "nouveau bouton" ou cette "nouvelle page" est sur la plateforme, cet article contient une introduction de ce dont parle le changement. Pour ces fonctionnalités, souvent seul du matériel d'assistance basique ou légèrement obsolète est disponible car cela est mis à jour au fur et à mesure. En plus d'aider les gens au support, les articles sont souvent mis à jour et si les questions posées peuvent être rapidement trouvées expliquées dans un article la semaine suivante.

### 1.1 **Nouveau flux de travail de statut - ISO 19650**

Les projets qui ont activé les révisions de brouillon avant le 2 octobre 2025 continueront à voir le flux de travail de statut hérité. Pour les projets où les révisions partagées ont été activées après le 2 octobre 2025, le nouveau flux de travail de statut est activé par défaut. Les projets qui souhaitent commencer à utiliser le nouveau flux de travail de statut peuvent demander que cela soit activé pour leurs projets en cours. Il n'y a pas de migration des révisions de brouillon héritées vers les nouvelles révisions partagées. Les révisions de brouillon restent dans le projet et peuvent être publiées, mais ne peuvent pas encore être migrées vers des révisions partagées. Avec le nouveau flux de travail de statut, les onglets espace de travail et publié sont visibles vers le haut des pages Documents et modèles. Les révisions commencent comme des révisions partagées et peuvent être publiées pour devenir des révisions publiées après lesquelles elles apparaissent dans l'onglet publié. En savoir plus sur la publication des révisions [ici](https://support.catenda.com/en/articles/9874698-revision-publishing-iso-19650).

### 1.2 **Nouveau flux de travail de validation**

Les projets qui ont activé les révisions de brouillon avant le 2 octobre 2025 continueront à voir le flux de travail de validation hérité. Les projets où les révisions partagées ont été activées avant le 2 octobre 2025 continueront à voir le flux de travail de validation hérité. Les projets qui n'ont pas activé précédemment les révisions de brouillon ou partagées peuvent désormais commencer à utiliser le nouveau flux de travail de validation en activant les révisions partagées. Les nouveaux projets créés sur la base d'un projet modèle où le nouveau flux de travail de validation est activé verront le flux de travail de validation hérité.

Il est souvent préférable d'activer cette fonctionnalité au début d'un nouveau projet, car l'adhésion à l'équipe pourrait devoir être ajustée pour de nouvelles façons de travailler. Le travail continue d'être effectué sur le nouveau flux de travail d'approbation et bien que les différences suivantes entre les anciens et les nouveaux flux de travail de validation existent, elles pourraient s'améliorer à l'avenir :

- Les annotations ne sont visibles que dans l'examen des fichiers des approbations ouvertes et fermées.
- Les modèles de sujets ne sont pas disponibles pour le nouveau flux de travail d'approbation.
- Beaucoup des paramètres des modèles de sujets sont déplacés vers la nouvelle page des flux de travail.
- Les sujets ne peuvent pas être générés à la suite de la publication d'une approbation avec le nouveau flux de travail de validation.
- Après avoir donné l'approbation finale pour un document, le document publié est exactement le même que la révision partagée qui a été publiée. Les annotations dans les annotations de l'approbation restent dans l'approbation et ne peuvent pas être consultées sur les révisions publiées. Les annotations dans les annotations ne sont ni transférées ni ne deviennent partie du document dans la révision publiée.
- Le nouveau flux de travail d'approbation ne dispose pas de notifications.
- Seule la traduction en anglais est disponible.
- Le nouveau flux de travail d'approbation ne peut être activé que si les révisions partagées n'ont pas été activées précédemment. Les projets créés sur la base d'un projet modèle où le nouveau flux de travail hérité est activé auront le flux de travail de validation hérité activé. Il n'est possible de voir le nouveau flux de travail de validation que dans les projets basés sur des projets modèles où les révisions partagées n'ont jamais été activées.
- Une seule étape de demande d'approbation peut être active à la fois.
  Tous les documents d'une étape de demande d'approbation doivent soit être approuvés, soit être rejetés avant que la demande d'approbation ne puisse avancer à l'étape suivante.
- Il n'est possible que d'approuver ou de rejeter.
  Les commentaires peuvent être ajoutés via des annotations, mais il n'y a pas d'approuver/rejeter avec commentaire comme dans le flux de travail de validation hérité.

## 2. **Activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être demandées pour être activées pour les projets existants par la personne contact de votre licence Catenda tandis que d'autres peuvent être activées avec un paramètre dans le projet. Lorsqu'une nouvelle fonctionnalité est demandée pour être activée, une réunion sera organisée avec un représentant du support pour discuter du statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la nouvelle fonctionnalité peut être testée, un projet factice sera créé pour une période limitée où la nouvelle fonctionnalité peut être testée.

### 2.1 **Demander l'activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être demandées pour être activées pour les projets existants par la personne contact de votre licence Catenda tandis que d'autres peuvent être activées avec un paramètre dans le projet. Lorsqu'une fonctionnalité à la demande est demandée pour être activée, une réunion sera organisée avec un représentant du support pour discuter du statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la fonctionnalité à la demande peut être testée, un projet factice peut être créé pour une période limitée où la fonctionnalité à la demande peut être testée pour considérer si la fonctionnalité est prête à être utilisée.

### 2.2 **Page Objets**

Recherchez n'importe quel contenu de votre IFC avec logique. La page des objets est une fonctionnalité à la demande qui peut être demandée pour être activée pour les projets en cours. Les nouveaux projets créés sur la base d'un projet modèle où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Par exemple, toutes les "entités de porte" du "Modèle A" qui mesurent plus de 2 mètres. Configurez les colonnes pour afficher les propriétés pertinentes pour chaque élément de ligne du tableau. Si les résultats du filtre ont un objet dans la visionneuse 3D, cet objet peut être sélectionné en 3D. Exportez les éléments sélectionnés avec les colonnes de propriété configurées qui sont affichées vers Excel. Similaire à la fonctionnalité QTO, les objets sélectionnés en 3D peuvent également être filtrés. Par rapport à la fonctionnalité QTO, ce n'est pas un problème de charger des milliers de lignes dans le tableau.

### 2.3 **Éditeur de rapport**

Créez des modèles de rapport pour les sujets et les documents afin que les membres du projet puissent sélectionner des sujets ou des documents du tableau et utiliser l'action de rapport pour générer un rapport. La page des rapports est une fonctionnalité à la demande qui peut être demandée pour être activée pour les projets en cours. Les nouveaux projets créés sur la base d'un projet modèle où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Des modèles séparés peuvent être créés pour les sujets et les documents. Lorsqu'un modèle est disponible dans un projet, l'action de rapport peut être utilisée avec les sujets et les documents sélectionnés pour générer un rapport basé sur le modèle sélectionné. Catenda offre un support sur la manière dont différentes valeurs peuvent être affichées sur la page. Si vous souhaitez un rapport personnalisé adapté à votre entreprise, nous pouvons vous mettre en contact avec un consultant qui peut vous aider.
