# Page des paramètres d'approbation - Héritage

La page des paramètres d'approbation se trouve en cliquant sur l'action des paramètres d'approbation dans le menu d'action à droite du bouton plus vert sur la [page des approbations](https://support.catenda.com/en/articles/8349340-approvals-page). _Accès requis_ : Administrateur

Voici à quoi peut ressembler la bannière sur la page des paramètres d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/01-intro.png)

## 1. **Actions sur la page des paramètres d'approbation**

Les actions de la page des paramètres d'approbation se trouvent en cliquant sur le menu d'action en haut à droite de la page des paramètres d'approbation. Voici à quoi peuvent ressembler les actions de la page des paramètres d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/02-actions-on-the-approvals-settings-page.png)

Cliquez [ici](https://support.catenda.com/en/articles/12367730-topic-templates-page) pour en savoir plus sur la page des modèles de sujet.

## 2. **Options de publication**

Sélectionnez le comportement par défaut qui se produira lorsqu'une revision publiée est créée dans un document suite à une validation finale dans une approbation. Voici à quoi peut ressembler la page des paramètres d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/03-publish-options.png)

Voici à quoi peut ressembler la page des paramètres d'approbation après que les statuts publiés pour chaque résultat aient été créés et configurés ainsi que les modèles de sujet :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/04-publish-options.png)

### 2.1 **Statut d'examen du fichier**

Les résultats de validation d'approbation suivants peuvent faire que différents comportements de création de sujet se produisent lors de la validation finale :

- Approuvé
- Approuvé avec commentaire
- En attente d'approbation
- Rejeté

### 2.2 **Statut du document**

Cliquez sur la liste déroulante du statut du document pour sélectionner un statut dans la liste des statuts publiés du projet ou ne définir aucun statut.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/05-document-status.png)

Pour modifier les statuts du projet, accédez au menu du flux de statut de la [page des paramètres du document](https://support.catenda.com/en/articles/7831371-document-settings-page).

### 2.3 **Modèle de sujet**

Lorsqu'un modèle de sujet est configuré, un sujet peut être créé pour chaque revision publiée qui est créée suite à une validation finale dans une demande d'approbation. Si un balisage est créé sur une revision brouillon lors du processus d'approbation, un commentaire est ajouté dans le sujet créé pour chaque ensemble d'annotations dans le balisage.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/06-topic-template.png)

**Ne pas créer de sujets / Ne pas enregistrer les balisages** Par défaut, le paramètre est défini pour ne pas créer de sujets, ce qui peut être remis à la valeur par défaut en sélectionnant ne pas enregistrer les balisages dans la liste déroulante.

**Créer un nouveau modèle de sujet** Cliquez [ici](https://support.catenda.com/en/articles/12372007-creating-a-new-topic-template) pour en savoir plus sur la création d'un modèle de sujet.

**Aperçu du sujet** Si un modèle de sujet est sélectionné, cliquez sur l'œil à côté du modèle pour voir le contenu de ce modèle de sujet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/eekvwhj0/07-topic-template.png)

### 2.4 **Enregistrer**

Cliquez sur enregistrer pour enregistrer les modifications

## 3. **Nouveau flux de validation**

La page des paramètres d'approbation n'est pas disponible pour les projets commençant par le nouveau flux de validation
