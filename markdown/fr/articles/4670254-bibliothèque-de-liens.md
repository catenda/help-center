# Bibliothèque de Liens

Vous trouverez la bibliothèque de Liens comme deuxième bibliothèque sur la [page des Bibliothèques](https://support.catenda.com/en/articles/8065645-libraries-page). Ici, vous pourrez cliquer sur l'étoile à gauche pour toujours afficher la bibliothèque de Liens dans votre menu de navigation gauche du projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/01-intro.png)

## 1. **Boutons supérieurs**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/02-top-buttons.png)

### 1.1 **Nouveau Lien**

Cliquez sur le bouton vert nouveau Lien pour créer un nouveau Lien

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/03-new-link.png)

_URL_ - Collez l'URL que vous souhaitez avoir comme Lien dans la bibliothèque de Liens. _Nom_ - Sélectionnez un nom pour le Lien

N'oubliez pas de cliquer sur Soumettre

### 1.2 **Menu hamburger**

Nouvelle Bibliothèque - Vous amène à la page de création de Bibliothèque

## 2. **Filtrage dans la bibliothèque de Liens**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/f29gh2kf/04-filtering-in-the-links-library.png)

Cliquez sur le bouton Filtre pour voir les différents filtres possibles. Dans la bibliothèque de Liens, vous pourrez filtrer selon les options suivantes : _Lié_ - `link=linked` _Non lié_ - `link=unlinked` _Lié aux objets sélectionnés_ - `link=backlink`

## 3. **Colonnes**

_Case à cocher_ - vous permet de sélectionner le Lien qui affichera le panneau d'informations de droite. _Nom_ - Le nom du Lien _URL_ - Vous donne un bouton sur lequel cliquer pour accéder à l'URL du Lien

**Liens** Si des objets ont été liés à ce Lien, vous verrez ici le nombre d'objets liés à ce Lien. Cliquer sur ce nombre vous permettra de : Sélectionner les objets liés dans la [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer) Isoler les objets liés dans la [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer) Charger les objets liés comme une [requête](https://support.catenda.com/en/articles/4854514-queries) dans la [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer)
