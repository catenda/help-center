# Configuration de l'organisation

Les organisations sont créées et gérées par une personne de contact Catenda. Contactez le support Catenda pour apporter des modifications à la configuration de l'organisation. Cliquez [ici](https://support.catenda.com/en/articles/8224886-organization-options) pour en savoir plus sur les différentes options d'organisation qui existent.

Les éléments suivants peuvent être configurés par une personne de contact Catenda :

### **Ajout/suppression de propriétaires d'organisation**

Il est recommandé que le nombre de propriétaires de cette organisation soit limité car les projets ne doivent pas être déplacés souvent.

### **Application de l'authentification multifacteur**

L'authentification multifacteur peut être appliquée à tous les projets d'une organisation. Il est recommandé d'activer l'authentification multifacteur sur toutes les organisations d'une entreprise car un ensemble de projets n'est aussi sécurisé que son maillon le plus faible.

### **Authentification unique**

L'authentification unique n'est disponible que pour les clients enterprise. Avec l'authentification unique, les Membres disposant du domaine de courrier électronique de l'organisation qui détient la licence peuvent se connecter avec leurs identifiants d'entreprise plutôt que via la page de connexion Catenda. L'authentification multifacteur est gérée par l'entreprise elle-même pour ces Membres tandis que les utilisateurs externes restent soumis à l'authentification multifacteur activée.

### **Enregistrement de domaine**

Ajouter des Membres d'un domaine à une organisation

### **Plan de projet**

Nombre total de projets par organisation Date d'expiration du projet

### **Titre de téléchargement de Documents**

Le titre que les Documents téléchargés dans cette organisation possèdent.

### **Partage public**

Désactiver le partage public des projets de l'organisation.
