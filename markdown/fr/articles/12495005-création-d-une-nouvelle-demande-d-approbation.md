# Création d'une nouvelle demande d'approbation

La nouvelle action de demande d'approbation se trouve pour les projets qui ont activé les révisions partagées après le 2 octobre 2025. Cliquez sur le menu d'action à droite du bouton plus vert sur la [page des approbations](https://support.catenda.com/en/articles/8349340-approvals-page) pour créer une nouvelle demande d'approbation. Cliquez sur le bouton de nouvelle demande d'approbation dans le menu des approbations du menu de droite d'une révision sur la page des documents où la dernière révision est une révision partagée pour créer une nouvelle demande d'approbation. Voici à quoi peut ressembler le dialogue de création d'une nouvelle demande d'approbation :

![Nouvelle demande d'approbation Workflow Submitter Title Description (optionnel) Documents for review add documents name revision # Revision number Statut Remove Cancel Save as draft Submit for review](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/01-intro.png)

Les projets pour lesquels les révisions partagées ont été activées avant le 2 octobre 2025 verront le dialogue de création d'une nouvelle demande d'approbation hérité.

## 1. En-tête de la demande d'approbation

Voici à quoi peut ressembler l'en-tête d'une nouvelle approbation pour les projets qui ont activé les révisions partagées après le 2 octobre 2025 :

![Nouvelle demande d'approbation Workflow Submitter Title](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/02-approval-request-header.png)

### 1.1 **Sélection du flux de travail**

Les membres qui font partie des équipes de demandeurs configurées dans un flux de travail de projet peuvent choisir entre l'un des flux de travail pour lesquels leurs équipes sont configurées. Le flux de travail précédemment sélectionné est mémorisé. Tant que le flux de travail précédemment sélectionné est toujours disponible, il sera sélectionné à nouveau la prochaine fois qu'une approbation est créée.

**Sélection automatique** Si une seule des équipes dont fait partie un membre est configurée pour un flux de travail, ce flux de travail sera automatiquement sélectionné. Voici à quoi cela peut ressembler lorsque le flux de travail est automatiquement sélectionné.

![Workflow Submitter Title](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/03-workflow-selection.png)

_Accès requis :_ Les membres et les administrateurs doivent faire partie d'une équipe de demandeurs configurée pour un flux de travail afin de pouvoir sélectionner le flux de travail.

### 1.2 **Sélection du demandeur**

Après la sélection d'un flux de travail, les membres qui font partie de plusieurs équipes de demandeurs configurées pour le flux de travail peuvent choisir au nom de quelle équipe ils souhaiteraient soumettre la demande d'approbation. L'équipe de demandeurs précédemment sélectionnée est mémorisée. Tant que le membre fait toujours partie de l'équipe de demandeurs précédemment sélectionnée, elle sera sélectionnée à nouveau la prochaine fois qu'une approbation est créée.

Lorsque la demande d'approbation est créée, les membres qui font partie de l'équipe de demandeurs sélectionnée verront la demande, tandis que les membres qui font partie des autres équipes de demandeurs possibles ne verront la demande que s'ils font partie de l'une des équipes d'examinateurs ou de l'équipe d'approbation finale configurée pour le flux de travail.

**Sélection automatique** Si un membre ne fait partie que d'une seule des équipes de demandeurs configurées pour le flux de travail, l'équipe de demandeurs est automatiquement sélectionnée lors de la sélection du flux de travail.

![Workflow Submitter Title](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/04-submitter-selection.png)

_Accès requis :_ Les membres et les administrateurs doivent faire partie d'une équipe de demandeurs configurée pour un flux de travail afin de pouvoir soumettre au nom de cette équipe de demandeurs.

### 1.3 **Titre**

Le titre de la demande d'approbation. Une approbation doit avoir un titre pour être soumise.

## 2. **Corps de la demande d'approbation**

Le nouveau flux de travail de validation est une fonctionnalité à la demande qui peut être demandée pour être activée lors du démarrage d'un nouveau projet. Il n'est possible de créer un projet basé sur un projet de modèle que si le nouveau flux de travail de validation n'est pas activé dans ce projet de modèle. Voici à quoi peut ressembler le corps d'une nouvelle approbation pour les projets qui ont activé les révisions partagées après le 2 octobre 2025 :

![Nouvelle demande d'approbation Description (optionnel) Documents for review add documents cancel no documents added yet](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/05-approval-request-body.png)

### 2.1 **Description**

La description de l'approbation suit les [règles générales de formatage des publications](https://support.catenda.com/en/articles/8430847-formatting-of-posts).

### 2.2 **Ajouter des documents**

![Description (optionnel) documents for review add documents](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/06-add-documents.png)

Cliquez [ici](https://support.catenda.com/en/articles/12382093-add-revision-to-approval) pour en savoir plus sur l'ajout de révisions partagées de documents à une demande d'approbation. Bien qu'il soit possible d'ajouter un nombre infini de documents ici, la limite pour soumettre la demande d'approbation pour examen est de 1 000 documents.

### 2.3 **Tableau des documents à examiner**

Voici à quoi peut ressembler le tableau des documents à examiner après l'ajout des révisions partagées dans chaque document à valider :

![Documents review table Name revision # Revision number Statut Remove Cancel Save as draft Submit for review](https://raw.githubusercontent.com/catenda/help-center/main/images/4e7kgq0a/07-documents-for-review-table.png)

**Colonnes** En fonction de l'ordre des colonnes configuré, les premières colonnes sont affichées tandis que le tableau peut avoir besoin d'être parcouru latéralement pour afficher d'autres colonnes activées. L'ordre par défaut et le paramètre de visibilité des colonnes sur la page des documents sont les suivants :

_Nom_ - _Par défaut_ Le nom du document dans lequel se trouve la révision partagée. Le nom du document est le même pour toutes les révisions du document.

Révision - _Par défaut_ Le nom de la révision du document. C'est la même chose que le nom du fichier original du fichier qui a été téléchargé.

## 3. - _Par défaut_

Statut - _Par défaut_ Le nom du statut partagé appliqué à la révision partagée.

Supprimer - _Par défaut_ Cliquez sur le x dans la colonne Supprimer pour retirer le Document à examiner de la liste Documents à examiner.

## 4. **Enregistrer en tant que brouillon**

Modifiez la demande d'Approbation avant qu'elle ne soit soumise et verrouillée.

### 4.1 **Plus de 1000 Documents dans les brouillons**

Bien qu'il soit possible d'ajouter autant de Documents au dialogue d'ajout de révision à la demande d'approbation, il est uniquement possible de soumettre le dialogue avec jusqu'à 1000 révisions de Documents. Pour ajouter plus de 1000 révisions de Documents avec le nouveau flux de validation, ajoutez d'abord jusqu'à 1000 Documents et enregistrez la demande d'Approbation en tant que brouillon. Ensuite, ajoutez jusqu'à 1000 Documents à la fois au brouillon de demande d'Approbation avec les actions d'ajout de Documents sur la page de brouillon de demande d'Approbation avant de soumettre la demande d'Approbation.

### 4.2 **Démarrer la durée d'examen de l'étape 1 quand vous êtes prêt**

Dès que la demande d'Approbation est soumise, les Équipes d'examinateurs configurées à la première étape du flux d'Approbation sélectionné seront chargées d'examiner les révisions dans la demande d'Approbation pendant la durée de leur étape d'Approbation. Les Membres des Équipes d'examinateurs pourront examiner les révisions jusqu'à ce que les jours ouvrables configurés pour leur étape d'Approbation soient écoulés. Enregistrez une demande d'Approbation en tant que brouillon pour qu'elle puisse être soumise dès que le flux de travail est prêt à commencer.

Assurez-vous que les Équipes sont prêtes en communiquant que leur étape d'examen est sur le point de commencer avant de soumettre le flux de demande d'Approbation et de démarrer la durée d'examen de la première étape pour les Équipes d'examinateurs configurées dans le flux de travail sélectionné.

Assurez-vous que la date de publication finale du flux de travail se termine au bon moment en veillant à aligner le nombre total de jours ouvrables du flux de travail avec les jours auxquels le flux de travail doit être soumis.

## 5. **Soumettre pour examen**

Cliquez sur Soumettre pour examen pour soumettre l'Approbation et démarrer le processus d'Approbation. Les éléments suivants sont requis pour soumettre la demande d'Approbation pour examen :

- Le flux de travail que la demande d'Approbation suivra doit être sélectionné.
- Une Équipe de soumissionnaire pour soumettre au nom de doit être sélectionnée
- Un titre
- Documents
  - Un minimum de 1 Document avec une révision partagée sélectionnée doit être ajouté pour pouvoir soumettre l'Approbation.
  - Un maximum de 1000 révisions de Documents avec une révision partagée sélectionnée peut être ajouté.
  - Pour créer une demande d'Approbation avec plus de 1000 révisions de Documents, créez d'abord un brouillon avec jusqu'à 1000 révisions, puis ajoutez jusqu'à 1000 révisions de Documents à la fois au brouillon avant de soumettre le brouillon pour examen.

Après avoir soumis une demande d'Approbation pour examen avec le nouveau flux de validation, la seule chose qui peut être modifiée est que les Documents de révision partagée peuvent être supprimés de la demande.

_Démarrer la durée d'examen de l'étape 1 quand vous êtes prêt_ Dès que la demande d'Approbation est soumise, la durée de la première étape d'examen configurée dans le flux d'Approbation commencera.
