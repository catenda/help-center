# Comment puis-je supprimer un groupe associé à une Étiquette ?

Vous pouvez supprimer un groupe d'une Étiquette en : 1\. Sélectionnez l'Étiquette en utilisant la case à cocher à gauche de l'Étiquette. 2\. Ensuite, appuyez sur "Définir le groupe" 3\. Sélectionnez "Supprimer le groupe" 4\. Mettre à jour
