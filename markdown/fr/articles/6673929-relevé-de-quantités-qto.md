# Relevé de quantités (QTO)

Vous pourrez trouver le menu QTO comme deuxième menu dans le [panneau d'information](https://support.catenda.com/en/articles/8238584-information-panel).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8drgvwsx/01-intro.png)

Cette fonctionnalité vous permet de visualiser et d'exporter une liste de propriétés des objets sélectionnés dans la [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer) ou le [panneau arborescence](https://intercom.help/bimsync-arena/en/articles/4670290-trees-panel). Avec cette liste, vous pourrez facilement obtenir des mesures précises des quantités de différents objets dans votre model. Pour commencer, veuillez sélectionner un objet dans la [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer) ou le [panneau arborescence](https://intercom.help/bimsync-arena/en/articles/4670290-trees-panel) pour afficher ses propriétés et les informations associées dans le menu d'inspection. Après avoir sélectionné certains objets, le menu QTO peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8drgvwsx/02-intro.png)

## 1. **Filtres et export**

Avec la barre de Filtres, vous pourrez filtrer n'importe laquelle des valeurs de vos propriétés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8drgvwsx/03-filter-and-export.png)

> **Remarque :** Si votre Filtre n'est pas appliqué, cela peut être parce que votre Filtre n'était pas assez précis. Veuillez fournir plus d'informations pour que les bonnes lignes soient filtrées.

La liste QTO peut être exportée vers Excel ou CSV en cliquant sur le bouton d'export.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8drgvwsx/04-filter-and-export.png)

## 2. **Liste de relevé de quantités**

La liste de relevé de quantités est une liste de toutes les propriétés, quantités et matériaux de vos objets sélectionnés.

### 2.1 **Ligne d'en-tête**

La première ligne de la liste de relevé de quantités contient le groupe auquel appartient chacune des propriétés de l'objet ou des objets sélectionné(s). Si l'un des objets contient des propriétés qui ne font partie d'aucun ensemble de propriétés (PSets), elles sont regroupées dans un groupe vide dans le premier champ de cette ligne. Les groupes de propriétés possibles peuvent être _type, matériau, ensemble de propriétés (PSet)_

Dans la deuxième ligne, les noms des propriétés au sein de leurs groupes forment les colonnes disponibles du tableau. Les deux lignes d'en-tête peuvent ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8drgvwsx/05-header-row.png)

Cliquez [ici](https://support.catenda.com/en/articles/11748020-tables-on-catenda) pour en savoir plus sur les tableaux sur Catenda.

## 3. **Nombre d'objets**

Jusqu'à 10 000 objets peuvent être affichés dans ce menu, mais seul un nombre limité de cellules peut être affiché. Si tous vos objets n'ont qu'une seule propriété, vous pourrez peut-être afficher 10 000, mais s'ils ont de nombreuses propriétés, vous vous rapprocherez bientôt de la limite de ce que le navigateur peut gérer. Vous pouvez voir combien d'objets sont sélectionnés sous la liste QTO.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/8drgvwsx/06-object-count.png)

## 5. **Page Objets**

Recherchez n'importe quel contenu de votre IFC avec logique. La page Objets est une fonctionnalité à la demande qui peut être demandée à être activée pour les projets en cours. Les nouveaux projets créés sur la base d'un projet modèle pour lequel cette fonctionnalité est activée ne disposent pas de cette fonctionnalité activée.
