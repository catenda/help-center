# Statuts des fonctionnalités Q1 2026

Pour éviter le spam de notifications et assurer un lancement en douceur, les nouveaux comportements ou les modifications des comportements existants peuvent être déployés graduellement et sans préavis. Ceux qui remarquent des changements dans le comportement d'une partie d'une page qu'ils utilisent fréquemment ou ceux qui se demandent ce qui est nouveau peuvent consulter ces articles pour des mises à jour sur les changements récents de comportement pour tous les utilisateurs.

## 1. **Nouvelles fonctionnalités**

Chaque utilisateur utilise la plateforme différemment. Même si une nouvelle fonctionnalité est lancée ou si des modifications sont apportées à une fonctionnalité, il est possible que les utilisateurs n'utilisent pas cette partie de la fonctionnalité. Pour ceux qui sont curieux de savoir ce que c'est que ce "nouveau bouton" ou cette "nouvelle page" sur la plateforme, cet article contient une introduction sur ce que le changement concerne. Pour ces fonctionnalités, souvent seuls les matériels d'assistance de base ou légèrement obsolètes sont disponibles car cela est mis à jour au fur et à mesure. En plus d'aider les gens au support, les articles sont souvent mis à jour et si les questions posées peuvent être rapidement trouvées expliquées dans un article la semaine suivante.

### 1.1 **Page Objets**

La page objets n'a plus besoin d'être demandée et est maintenant disponible dans chaque projet. Recherchez n'importe quel contenu de votre IFC avec logique. Par exemple, tous les "entités Porte" du "Modèle A" qui sont plus hauts que 2 mètres. Configurez les colonnes pour afficher les propriétés pertinentes pour chaque élément de ligne du tableau. Si les résultats du filtrage ont un objet dans la Visionneuse 3D, cet objet peut être sélectionné en 3D. Exportez les éléments sélectionnés avec les colonnes de propriétés configurées qui sont affichées vers Excel. Similaire à la fonctionnalité QTO, les objets sélectionnés en 3D peuvent également être filtrés. Comparé à la fonctionnalité QTO, il n'y a aucun problème de charger des milliers de lignes dans le tableau.

### 1.2 **Action copier le lien dans le tableau Documents**

Tout comme dans le tableau des sujets, une action de copie de lien est maintenant disponible dans le tableau Documents. Accédez à un dossier ou recherchez avec un Filtre et sélectionnez les lignes du tableau Documents pour révéler le menu d'action vers le haut du tableau. Sélectionnez la nouvelle action de copie de lien pour copier un lien vers seulement ces éléments dans le presse-papiers. Ouvrez le lien pour voir le filtre "partagé via le lien" actif et voir uniquement les lignes sélectionnées dans le tableau. Notez que la personne ouvrant le lien doit avoir accès aux éléments de la Bibliothèque qui sont liés.

## 2. **Fonctionnalités mises à jour**

### 2.1 **Paramètres de la Visionneuse 3D**

Le menu des paramètres de la Visionneuse 3D a été mis à jour. Il est maintenant possible de trouver trois nouveaux menus en cliquant sur l'icône d'engrenage en haut à droite. Ici, les menus rendu, navigation et environnement peuvent être trouvés.

**Rendu** Deux nouvelles options, qualité d'affichage et ombres ambiantes.

**Navigation** Toutes les options de caméra 3D et de navigation connexes sont utilisées dans ce menu

**Environnement** Un menu entièrement nouveau où une boîte à ciel et un plan au sol qui reçoit les ombres des objets peuvent être configurés.

### 2.2 **Approbations**

Les administrateurs du projet peuvent maintenant modifier l'option de modèle de sujet d'approbation pour chacun des statuts dans la configuration d'un flux de travail d'approbation.

### 2.3 **Dénomination cohérente des colonnes entre Documents et Modèles**

La colonne "Nom" avait différentes significations dans Documents par rapport aux Modèles - ce qui était confus pour les utilisateurs ! Maintenant, les deux utilisent le même nom de document. Le champ "Nom du modèle" reste, juste renommé "Nom court". Le téléchargement depuis Modèles produit maintenant le même nom de fichier que le téléchargement depuis Documents.

## 3. **Activation des fonctionnalités à la demande**

Chaque fonctionnalité à la demande est de qualité production et prête pour une utilisation réelle du projet. Bien que ces fonctionnalités aient été testées pour fonctionner comme prévu, il peut y avoir des degrés variables quant au nombre de projets qui ont commencé à utiliser ces fonctionnalités, de sorte que des cas limites inconnus pourraient être découverts. Bien que des modifications puissent se produire alors que nous travaillons à rendre ces fonctionnalités disponibles pour tous les utilisateurs, les données soumises dans ces fonctionnalités ne seront pas supprimées.

### 3.1 **Demander l'activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être demandées à être activées pour les projets existants par la personne responsable de votre licence Catenda, tandis que d'autres peuvent être activées avec un paramètre du projet. Quand une fonctionnalité à la demande est demandée à être activée, une réunion sera mise en place avec un représentant du support pour discuter du statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la fonctionnalité à la demande peut être testée, un projet fictif peut être créé pour une durée limitée où la fonctionnalité à la demande peut être testée pour considérer si la fonctionnalité est prête à être utilisée.

### 3.2 **Éditeur de rapport**

Créez des modèles de rapport pour les sujets et les Documents afin que les Membres du projet puissent sélectionner des sujets ou des Documents du tableau et utiliser l'action de rapport pour générer un rapport. La page des rapports est une fonctionnalité à la demande qui peut être demandée à être activée pour les projets en cours. Les nouveaux projets créés à partir d'un projet de modèle où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Des modèles séparés peuvent être créés pour les sujets et les Documents. Quand un modèle est disponible dans un projet, l'action de rapport peut être utilisée avec les sujets et les Documents sélectionnés pour générer un rapport basé sur le modèle sélectionné. Catenda offre un support pour savoir comment différentes valeurs peuvent être affichées sur la page. Si vous souhaitez un rapport personnalisé adapté à votre entreprise, nous pouvons vous mettre en contact avec un consultant qui peut vous aider.
