# Créer un nouveau sujet

> Ceci décrit toutes les étapes pour créer un sujet

La création d'un nouveau sujet peut être effectuée à partir de l'écran des sujets ou de la visionneuse de sujets du Tableau de bord. Pour créer un nouveau sujet, cliquez sur le bouton « Nouveau sujet » en haut à droite de l'écran. Cela ouvrira la fenêtre Nouveau sujet.

Voici à quoi peut ressembler la page de création d'un nouveau sujet :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/01-intro.png)

Sur cette page, vous trouverez des informations sur les éléments suivants :

## 1. Barre supérieure

Cliquez sur retour aux sujets pour revenir à la Liste de sujets dans laquelle vous étiez.

## 2. En-tête

Voici à quoi peut ressembler l'en-tête du sujet :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/02-2-header.png)

### 2.1 Titre

Entrez le titre/sujet. C'est généralement la seule chose requise pour soumettre le sujet.

### 2.2 Liste de sujets

Il y aura différentes listes de sujets à choisir et elles différeront d'un projet à l'autre.

### 2.3 Statut

Vous pouvez choisir entre ouvert ou fermé. Normalement, vous choisissez ouvert quand vous créez un nouveau sujet.

### 2.4 Type

Ici, vous choisissez le type de sujet que vous créez. Les types que vous pouvez choisir sont Erreur, Avertissement, Info et Inconnu. Ce sont les types par défaut, vous pouvez également créer vos propres types.

### 2.5 Localisation

Ajouter un marqueur 2D

### 2.6 Echéance

Si vous le savez, définissez une échéance ou laissez-la vide. Il est recommandé que vous ajoutiez une échéance même si vous ne connaissez pas exactement le délai du sujet. Cela vous habitue à définir des échéances. N'importe quelle information peut aider à informer le projet. L'échéance peut toujours être modifiée ultérieurement.

### 2.7 Jalon

Épinglez-le à un jalon ou laissez-le vide. Cela peut aider au suivi du nombre de sujets traités avant une date du projet.

### 2.8 Responsabilité

**Assigné à** Ici, vous pouvez assigner le sujet à un Membre spécifique ou à une Équipe. Il est recommandé que vous définissiez un Membre comme assignataire au lieu d'une Équipe, car la responsabilité partagée fait qu'aucun des Membres de l'équipe ne se sent personnellement responsable. Si vous souhaitez toujours informer les autres Membres de l'équipe que leur équipe est responsable, vous pouvez définir Membre@équipe. Si un Membre est défini comme assignataire, il [suivra](https://support.catenda.com/en/articles/8053299-right-panel-in-an-issue#h_a97f3b264e) automatiquement le sujet. Si une Équipe est définie comme assignataire, les Membres de l'équipe ne [suivront](https://support.catenda.com/en/articles/8053299-right-panel-in-an-issue#h_a97f3b264e) pas automatiquement le sujet.

**Demandé par** Ici, vous pouvez définir le Membre ou l'Équipe qui demande le sujet. Vous serez défini comme demandeur par défaut, mais vous pouvez choisir n'importe quel Membre ici. Si un Membre est défini comme demandé, il [suivra](https://support.catenda.com/en/articles/8053299-right-panel-in-an-issue#h_a97f3b264e) automatiquement le sujet. Si une Équipe est définie comme demandée, les Membres de l'équipe ne [suivront](https://support.catenda.com/en/articles/8053299-right-panel-in-an-issue#h_a97f3b264e) pas automatiquement le sujet.

### 2.9 Étiquettes

Ajoutez des Étiquettes pertinentes pour le sujet ou créez une nouvelle Étiquette. Une Étiquette nouvellement créée ne sera partagée avec le projet qu'après la soumission du sujet.

### 2.10 Champs personnalisés

Si des champs personnalisés ont été ajoutés à la Liste de sujets où le sujet est créé, vous pouvez voir des champs personnalisés déroulants, texte ou entiers. Si le champ a un message d'erreur rouge, cela signifie que le champ est défini comme obligatoire et vous devez remplir quelque chose pour pouvoir soumettre le sujet.

## 3. Panneau d'information de droite

Voici à quoi peut ressembler le panneau d'information de droite :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/03-3-right-information-panel.png)

### 3.1 Documents

Cliquez [ici](https://support.catenda.com/en/articles/4670250-linking-a-document-to-an-issue) pour voir comment lier un document à un sujet.

## 4. Corps

Voici à quoi peut ressembler le corps d'un sujet :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/k4dpt6z7/04-4-body.png)

### 4.1 Description

Ajoutez une description pour le sujet. Identifiez les personnes qui doivent être incluses dans la discussion avec @. Dans la barre d'outils ci-dessous, vous avez plusieurs options, par exemple : [Listes de contrôle dans les sujets](https://intercom.help/bimsync-arena/en/articles/5036461-check-lists-within-issues)

### 4.2 Commentaire

La zone de texte à côté du bouton ajouter sert à écrire un commentaire, mentionner les gens en tapant @nom ou créer un lien vers d'autres sujets en tapant #lien.

### 4.3 Pièce jointe

**Bouton Ajouter** En cliquant sur le bouton ajouter, vous pouvez ajouter une Capture 2D/3D ou une image de votre disque dur.

La Capture 2D/3D provient du dernier angle de caméra dans la Visionneuse 3D/2D. En ouvrant le bouton 3D dans la visionneuse de navigation. Vous pouvez naviguer dans le modèle jusqu'au sujet en question et en appuyant sur le bouton ajouter en choisissant la Capture 2D/3D, puis la Capture apparaîtra.

**Capture** Si vous avez une vue 2D d'un modèle chargée, une Capture 2D de votre vue 2D actuelle sera automatiquement ajoutée. Si vous avez une vue 3D d'un modèle chargée, une Capture 3D de votre position de caméra actuelle sera automatiquement ajoutée. Si vous avez des objets 3D sélectionnés dans la Capture 3D lorsque vous soumettez le sujet, ces objets seront liés au sujet. Vous pouvez supprimer, rafraîchir ou ajouter de nouvelles Captures avant de soumettre.

Si vous cliquez avec le bouton gauche sur la Capture que vous avez prise, vous avez la possibilité d'ajouter des annotations à l'image. Sous l'image, une barre d'outils apparaîtra avec les outils pour dessiner le point spécifique du sujet plus en détail.

> **Remarque :** Si vous utilisez une unité mobile, vous pouvez utiliser une image stockée ou en prendre une nouvelle avec la caméra intégrée. _Tous les écrans sont dynamiques (« réactifs ») et s'adaptent à la taille d'écran de l'unité que vous utilisez._

### 4.4 Soumettre

**Garder ouvert pour soumettre** Cochez cette case si vous prévoyez de faire un autre sujet immédiatement.

**Soumettre** Quand vous avez choisi toutes les informations pertinentes pour le sujet, appuyez sur soumettre en bas à droite. La quantité minimale d'informations requise pour soumettre un sujet est le titre.
