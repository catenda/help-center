# 2D / 3D - Catenda Site

La page 2D / 3D se trouve dans le [menu](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site) ou en appuyant sur le bouton Problèmes de la barre de navigation inférieure.

![2D / 3D](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/01-intro.png)

Voici à quoi peut ressembler la page 2D / 3D :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/02-intro.png)

En haut de la page 2D / 3D, vous voyez le sélecteur de issue board.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/03-intro.png)

Les problèmes qui résultent du filtre sur la issue board choisie sont les problèmes dont les marqueurs sont affichés dans la vue 2D.

### Moitié supérieure

Sur la moitié supérieure de la page 2D / 3D, vous verrez la [Visionneuse 3D](https://support.catenda.com/en/articles/7744403-3d-viewer-catenda-site).

### Moitié inférieure

Sur la moitié inférieure de la page 2D / 3D, vous verrez la [Visionneuse 2D](https://support.catenda.com/en/articles/7748370-2d-viewer-catenda-site).

### Barre de division

Entre les deux visionneurs, vous verrez un curseur de division

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wy1t8c1t/04-dividing-bar.png)

Faites glisser ce curseur pour configurer la taille que vous souhaitez allouer à chaque visionneuse
