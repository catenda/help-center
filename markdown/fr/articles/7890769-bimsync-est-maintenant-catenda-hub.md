# Bimsync est maintenant Catenda Hub

> Catenda Hub s'appelle désormais Bimsync

Dans le cadre de la refonte de marque de Catenda, la façon d'accéder à Catenda Hub change. À partir de maintenant, vous pourrez vous connecter sur [https://hub.catenda.com](https://hub.catenda.com). Vous pouvez vous connecter en utilisant les identifiants que vous utilisez déjà pour bimsync.com.

Catenda Hub continue d'être disponible sur [https://bimsync.com](https://bimsync.com) et nous maintiendrons cette propriété dans un avenir prévisible. Cependant, nous cesserons d'en parler dans la documentation technique et vous encourageons à utiliser le nouveau nom de domaine.

## 1. Que dois-je faire ?

Si votre organisation utilise un pare-feu ou un autre moyen de restreindre l'accès aux sites web, veuillez contacter votre administrateur informatique et vous assurer qu'il autorise l'accès TCP sortant sur les ports 80 et 443 vers les hôtes suivants :

- hub.catenda.com
- viewer.catenda.com
- api.catenda.com

## 2. Quand dois-je le faire ?

Bien que nous nous engagions à maintenir bimsync.com en fonctionnement, nous avons l'intention de rediriger le trafic client vers hub.catenda.com après un délai de notification clairement communiqué. Pour cette raison, nous vous recommandons de vous assurer que vous pouvez vous connecter à Catenda Hub sur [https://hub.catenda.com](https://hub.catenda.com) dès que possible.

Pour plus d'informations sur la connexion, consultez [cet](https://support.catenda.com/en/articles/7891486-sign-in-page) article. Pour plus d'informations sur le domaine à autoriser via le pare-feu, consultez [cet](https://support.catenda.com/en/articles/6921941-system-requirements-and-optimization) article.

Si vous avez des questions ou des préoccupations concernant ces modifications, veuillez nous le faire savoir.
