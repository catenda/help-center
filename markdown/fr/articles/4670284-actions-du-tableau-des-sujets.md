# Actions du tableau des sujets

Les boutons d'action peuvent être situés à différents endroits sur la [page des sujets](https://support.catenda.com/en/articles/4670271-topics-page) selon la sélection des sujets et les paramètres d'accès dont vous disposez. Tous les boutons d'action seront listés dans leurs menus d'action qui peuvent ressembler à ceci:

![mceclip0.png](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/01-intro.png)

## 1. **Nouvelles actions d'élément**

Le bouton plus et les éléments du menu d'action se trouvent vers le haut à droite de la page et peuvent ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/02-new-item-actions.png)

Les actions que vous pouvez trouver ici concernent toutes la création de nouvelles informations. Les [actions d'élément sélectionné](#h_b5c00c149b) qui concernent les éléments existants sur la page se trouvent également vers le haut du tableau après avoir effectué une sélection.

### 1.1 **Nouveau sujet**

Cliquez [ici](https://support.catenda.com/en/articles/4670268-creating-a-new-topic) pour en savoir plus sur la création d'un nouveau sujet _Accès requis:_ Accès en écriture ou accès complet dans une liste de sujets

### 1.2 **Échanger les sujets**

Avec l'échange, vous pourrez importer et exporter des sujets. _Les formats de fichier d'importation disponibles sont:_ BCF _Les formats de fichier d'exportation disponibles sont:_ BCF, Excel, PDF En savoir plus sur l'échange de sujets [ici](https://support.catenda.com/en/articles/4670289-exchange-topics) _Accès requis:_ Accès en lecture à une liste de sujets

> **Remarque:** L'exportation de sujets n'est possible que dans une liste de sujets unique et ne sera pas disponible dans la liste de tous les sujets.

### 1.3 **Historique**

**Historique d'importation** Cela affichera les sujets qui ont été importés et où ils ont été téléchargés.

**Historique d'exportation** Cela affichera l'historique d'exportation des sujets. Vous pourrez également télécharger les exportations à partir d'ici, rapports PDF, Excel et BCF.

**Historique de déplacement** Cela affichera les sujets qui ont été déplacés et où ils ont été déplacés dans toutes les listes de sujets du projet.

## 2. **Actions d'élément sélectionné**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/03-selected-item-actions.png)

### 2.1 **Copier le lien**

Avec l'action de copie de lien, un lien qui affiche uniquement les lignes de tableau sélectionnées peut être copié. Cliquez [ici](https://support.catenda.com/en/articles/14323982-copy-link-action) pour en savoir plus sur la copie de liens.

### 2.2 **Exporter les sujets**

Avec l'action d'exportation de sujets, vous pourrez exporter un ou plusieurs sujet(s).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/04-export-topics.png)

L'action d'exportation de sujets ouvrira la [boîte de dialogue d'exportation de sujets](https://support.catenda.com/en/articles/4670289-exchange-topics). Ici, vous pourrez exporter tous les sujets de la liste, les sujets filtrés et les sujets sélectionnés. _Les formats de fichier disponibles sont:_ BCF, Excel, [PDF](https://support.catenda.com/en/articles/9784934-exporting-topics-to-pdf)

> **Remarque:** Il n'est possible d'exporter les sujets que d'une seule liste à la fois. L'option peut donc disparaître si vous sélectionnez des sujets à partir de plusieurs listes dans la liste de tous les sujets.

### 2.3 **Créer un rapport**

L'outil de reporting peut être demandé pour être activé par projet. Avec l'action de création de rapport, vous pouvez créer un rapport de vos sujets sélectionnés. _Accès requis:_ Accès en lecture à la liste de sujets

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/05-create-report.png)

Cette option est disponible lorsque des sujets provenant de plusieurs listes sont sélectionnés. Cliquez [ici](https://support.catenda.com/en/articles/13973721-create-report-action) pour en savoir plus sur la création de rapports.

### 2.4 **Suivre**

Avec l'action de suivi, le sujet sélectionné peut être suivi.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/06-follow.png)

> **Remarque 1:** Si vous avez été précédemment [assigné](https://support.catenda.com/en/articles/8400566-issue-header#h_0a91fa8dd9), défini comme [demandeur](https://support.catenda.com/en/articles/8400566-issue-header#h_1aea0990a7), ou [mentionné](https://support.catenda.com/en/articles/8430847-formatting-of-posts#h_2481ad1c8c) dans le sujet, vous suivrez automatiquement le sujet. **Remarque 2:** Si un sujet que vous suivez est déplacé vers une liste à laquelle vous n'avez pas accès, vous continuerez à le suivre mais ne recevrez plus de notifications à ce sujet.

**Notifications sur les sujets suivis** Le suivi d'un sujet est lié aux notifications. Les membres qui suivent un sujet reçoivent des notifications concernant les modifications apportées au sujet. Lorsqu'un sujet est créé, tous les membres ayant accès à la liste de sujets dans laquelle il est créé reçoivent une notification indiquant que le sujet a été créé. Comme cela génère beaucoup de notifications, beaucoup l'ont désactivé dans leurs paramètres. Après sa création, les membres qui n'ont rien à voir avec le sujet ne seront pas notifiés davantage des événements futurs tels que les commentaires et les modifications dans n'importe quel champ de l'en-tête du sujet. Le suivi d'un sujet garantit que ces notifications sont envoyées.

**Arrêter de suivre** Les membres qui suivent un sujet peuvent utiliser l'action d'arrêt de suivi pour cesser de suivre le sujet, même s'ils sont ceux qui l'ont créé.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/07-follow.png)

Après avoir arrêté le suivi, les notifications concernant les modifications du sujet, telles que les nouveaux commentaires ou les modifications des champs de l'en-tête du sujet, ne sont plus envoyées au membre qui a arrêté le suivi. _Accès requis:_ Accès en lecture à la liste du sujet

**Faire suivre le sujet par d'autres membres** [L'assignation](https://support.catenda.com/en/articles/8400566-issue-header#h_0a91fa8dd9) d'un membre à un sujet fait en sorte qu'il suive automatiquement le sujet. La définition d'un membre en tant que [demandeur](https://support.catenda.com/en/articles/8400566-issue-header#h_1aea0990a7) d'un sujet fait en sorte qu'il suive automatiquement le sujet. Étant donné que le créateur du sujet est défini comme [demandeur](https://support.catenda.com/en/articles/8400566-issue-header#h_1aea0990a7) par défaut lors de la création du sujet, il suit généralement ses propres sujets. La [mention](https://support.catenda.com/en/articles/8430847-formatting-of-posts#h_2481ad1c8c) d'un membre dans un sujet fait en sorte qu'il suive automatiquement le sujet.

> **Remarque:** Bien que le demandeur, l'assigné et les membres mentionnés soient définis comme suiveurs, ce n'est pas le cas pour les membres des équipes qui sont définis comme demandeur, assigné ou sont mentionnés dans le sujet. Dans ce cas, une notification ponctuelle est envoyée indiquant qu'une équipe dont ils font partie a été définie comme demandeur, assigné ou est mentionnée, mais les membres de l'équipe ne sont alors pas définis comme suiveurs du sujet.

**Suivi manuel** Si un autre membre a créé un sujet qui semble sans rapport avec un membre mais que celui-ci est intéressé et souhaite voir comment il évolue, le sujet peut être suivi pour recevoir des notifications. Les autres membres ne peuvent pas voir qui a suivi un sujet. Cela signifie simplement que désormais les notifications concernant tout changement futur du sujet seront envoyées au membre qui suit.

Les cas où un membre ne suit pas un sujet peuvent être dans des sujets où ils n'ont pas été [assignés](https://support.catenda.com/en/articles/8400566-issue-header#h_0a91fa8dd9) ou [mentionnés](https://support.catenda.com/en/articles/8430847-formatting-of-posts#h_2481ad1c8c).

**Arrêt du suivi** Si vous ne souhaitez pas recevoir de notifications sur les modifications futures de ce sujet, vous pouvez cesser de le suivre en cliquant sur arrêter le suivi.

### 2.6 **Supprimer un sujet**

Avec un sujet sélectionné, l'action de suppression peut être utilisée pour supprimer un sujet sélectionné.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/znfw4v54/09-delete-topic.png)

_Accès requis:_ Accès complet à la liste de sujets ou créateur du sujet

Il n'est possible de supprimer qu'un seul sujet à la fois, cette action n'est donc affichée dans la liste des actions que si un seul sujet est sélectionné. La suppression du sujet le retire complètement du projet. Au lieu de supprimer, vous pouvez envisager de masquer ou d'archiver le sujet pour le désactiver pour les membres du projet.

**Masquage ou archivage par rapport à la suppression** En masquant ou en archivant un sujet, les données sont conservées dans le projet. Pour masquer un sujet, déplacez-le vers une autre liste de sujets. L'accès peut être configuré par liste de sujets. _Accès requis pour configurer l'accès à une liste de sujets:_ Accès complet à la liste de sujets

Sans accès à un sujet, les éléments liés tels que les documents et les objets afficheront toujours qu'un sujet qui a été lié à eux existe, mais l'utilisateur aura besoin d'accès à la liste de sujets pour voir son contenu.

Pour masquer complètement un sujet aux membres du projet afin qu'il n'apparaisse plus dans les éléments liés, il peut être déplacé vers une liste qui est ensuite archivée. Les sujets dans les listes de sujets archivées n'apparaissent plus dans les éléments liés tels que les documents et les objets. _Accès requis pour archiver une liste de sujets:_ Accès complet à la liste de sujets

**Les sujets supprimés ne peuvent pas être recréés** Supprimez les sujets uniquement si les données ne seront pas requises dans le projet ultérieurement. Après la suppression d'un sujet, il n'est pas possible d'importer un BCF pour un sujet avec cet ID à nouveau, car il est toujours utilisé par le sujet supprimé.

_Prévention de l'édition ou de la suppression_ Créez une exportation PDF d'un sujet pour créer une exportation du sujet qui ne peut pas être modifiée.

**Demandes de récupération de sauvegarde** La récupération de sauvegarde des sujets supprimés peut être demandée en cas de litige. Les demandes de récupération de sauvegarde peuvent prendre jusqu'à deux semaines.
