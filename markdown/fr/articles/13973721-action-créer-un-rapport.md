# Action Créer un rapport

L'action Créer un rapport est mise à disposition pour les projets où la fonction de rapports opt-in a été demandée pour être activée. Lorsque la fonction de rapports est activée sur un projet, l'action Créer un rapport devient disponible dans les actions de la table Documents et Sujets. Sélectionnez un ou plusieurs éléments dans la table Documents et ouvrez le [menu d'action de la table Documents](https://support.catenda.com/en/articles/4670288-documents-table-actions). Sélectionnez un ou plusieurs éléments dans la table Sujets et ouvrez le [menu d'action de la table Sujets](https://support.catenda.com/en/articles/4670284-topics-table-actions). Voici à quoi peut ressembler l'action Créer un rapport :

<img alt="" src="https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/inline-ef841bc1c2c3.png" width="290"/>   \<->   <img alt="" src="https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/inline-0c1ebf646ff6.png" width="290"/>

## 1. Choisir les options d'export

Lorsque l'action Créer un rapport est cliquée, la boîte de dialogue Générer un rapport s'ouvre :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/01-choose-export-options.png)

> **Remarque :** Pour les rapports créés sur les éléments sélectionnés dans la table Documents, attention : seuls les éléments Documents sont inclus dans le rapport et non les éléments de dossier.

### 1.1 **Sélectionné**

Affiche le nombre d'éléments sélectionnés (En excluant les dossiers pour les rapports de documents)

### 1.2 **Filtre actuel**

Affiche le nombre d'éléments correspondant au filtre actuel. Le nombre inclut les éléments de dossier pour les rapports de documents, bien que ceux-ci ne soient pas inclus dans le rapport

### 1.3 **Continuer**

Cliquez sur Continuer pour ouvrir le rapport sur la page de rapports.

## 2. Nouvelle page de rapport

Voici à quoi peut ressembler la nouvelle page de rapport :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/02-new-report-page.png)

### 2.1 **Sélectionner le modèle de rapport**

Choisissez un rapport prédéfini basé sur la liste des modèles de rapport que l'administrateur du projet a mis à disposition dans le projet. Pour les rapports créés à partir de la table Documents, sélectionnez parmi une liste de modèles de documents disponibles. Pour les rapports créés à partir de la table Sujets, sélectionnez parmi une liste de modèles de sujets disponibles.

### 2.2 **Nouvelle barre d'outils de rapport**

**Enregistrer** Voici à quoi peut ressembler le menu d'enregistrement :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/03-new-report-toolbar.png)

> **Remarque :** Assurez-vous que l'échelle du navigateur est agrandie à la bonne échelle pour voir tout le menu.

**Paramètres d'export** Voici à quoi peut ressembler le menu des paramètres d'export pour le format de fichier Adobe PDF :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/04-new-report-toolbar.png)

Cliquez sur OK pour enregistrer le rapport en tant que document quelque part dans la bibliothèque de documents sur Catenda à partir de là où il peut être téléchargé. _Enregistrer le fichier de rapport_ Pour pouvoir télécharger le rapport, il doit d'abord être enregistré quelque part dans la structure des documents de Catenda. ![](https://raw.githubusercontent.com/catenda/help-center/main/images/x936dwq1/05-new-report-toolbar.png)

Le menu d'enregistrement de documents mémorise le dossier précédemment sélectionné et ne doit être configuré qu'une seule fois si le même dossier est utilisé à chaque fois.
