# Niveaux de contrôle d'accès

Il est possible de configurer l'accès à de nombreux emplacements différents dans Catenda Hub :

## 1. **Outil d'organisation**

L'accès le plus élevé dans Catenda est l'accès à l'organisation. Ceci est généralement accordé à une ou quelques personnes de confiance dans les organisations d'entreprise ou les organisations avec archives. Les Membres ayant accès à l'organisation auront accès à l'[outil d'organisation](https://support.catenda.com/en/collections/5831081-organizations). Cela leur permet de voir tous les Membres de tous les projets qui font partie de l'organisation sans avoir à faire partie des projets eux-mêmes.

## 2. **Accès administrateur**

L'administrateur a toujours un accès complet à tout dans un projet. Il est donc important d'être prudent lors de l'attribution du rôle d'administrateur aux Membres du projet. Il existe [certaines parties d'un projet](#h_eeea52ad11) où seuls les administrateurs ont accès.

## 3. **Accès Membres**

Les Membres ordinaires peuvent se voir accorder un accès à différentes [parties d'un projet](#h_5e8171c200) soit par Équipe soit par Membre.

### 3.1 **Membre spécifique**

Chaque Membre peut se voir accorder son propre accès dans [différentes parties d'un projet](#h_5e8171c200).

> **Remarque :** qu'un Membre peut avoir accès via l'une de ses Équipes s'il n'a pas reçu d'accès spécifique.

**Pas d'accès**

**Lire**

**Écrire**

**Accès complet**

### 3.2 **Équipe**

Les Membres qui font partie d'Équipes obtiennent toujours l'accès le plus élevé dans [différentes parties d'un projet](#h_5e8171c200) accordé à l'une des Équipes dont ils font partie.

> **Remarque :** que cela peut être remplacé par un accès Membre spécifique.

**Pas d'accès**

**Lire**

**Écrire**

**Accès complet**

## 4. **Aperçu d'accès**

L'accès aux Documents peut rapidement devenir compliqué et vous pouvez perdre de vue qui a accès à quel dossier. Les Membres ayant [un accès complet à la racine du Document](https://support.catenda.com/en/articles/4670292-root-folder-acl) peuvent donc consulter l'[aperçu d'accès](https://support.catenda.com/en/articles/6660820-document-access-overview-acl-dashboard) pour voir qui a accès à quoi.
