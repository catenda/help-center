# Créer un nouveau flux de travail

La page du nouveau flux de travail peut être ouverte en cliquant sur le bouton plus vert sur [la page des flux de travail](https://support.catenda.com/en/articles/12309903-workflows-page-document-settings) ou en cliquant sur l'action dans le menu d'action du nouvel élément sur [la page des approbations](https://support.catenda.com/en/articles/8349340-approvals-page). Il est uniquement possible de créer de nouveaux flux de travail dans les projets où le nouveau flux de travail de validation a été demandé à être activé. Le nouveau flux de travail de validation est une fonctionnalité à la demande qui peut être demandée à être activée au démarrage d'un nouveau projet. Il est uniquement possible de créer un projet basé sur un projet modèle lorsque le nouveau flux de travail de validation n'est pas activé dans ce projet modèle. Voici à quoi peut ressembler la partie titre d'une nouvelle approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/01-intro.png)

## 1. **Titre**

Entrez le nom du flux de travail. C'est la seule partie du flux de travail qui peut être modifiée après sa soumission.

### 1.1 **Requis**

Un titre doit être fourni pour pouvoir soumettre un flux de travail.

### 1.2 **Contenu de l'approbation**

Voici à quoi peut ressembler le contenu d'une nouvelle approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/02-approval-contents.png)

## 2. **Réglages de l'heure**

Les membres de l'équipe auront un nombre limité de jours ouvrables pour examiner les documents dans les étapes de validation où leur équipe a été définie comme équipe d'examinateur. Voici à quoi peuvent ressembler les paramètres de temps d'un nouveau flux de travail d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/03-time-settings.png)

L'heure configurée dans les paramètres de temps est l'heure du début et de la fin du jour ouvrable pour chacun de ces jours ouvrables. Configurez les paramètres de temps pour qu'ils correspondent aux membres de l'équipe dont les équipes sont définies comme équipes d'examinateur pour les étapes de validation dans ce flux de travail. Les membres de l'équipe pourront soumettre leur examen dans le délai imparti en fonction du nombre de jours ouvrables et de l'heure configurée dans ce champ.

**Exemple de la façon dont les paramètres de temps peuvent être considérés :** Les soumissions peuvent être datées en fonction de ces heures. Une soumission à 2 h du matin appartient au jour précédent si le paramètre de temps est défini sur 6 h du matin.

### 2.1 **Heure de début**

Choisissez une valeur de 01 à 24 basée sur le système d'horloge 24 heures, autrement connu sous le nom d'heure militaire.

### 2.2 **Fuseau horaire sélectionné**

Le fuseau horaire par défaut est le fuseau horaire configuré dans votre système d'exploitation. Voici à quoi peut ressembler un élément de liste de fuseau horaire sélectionné.

La première partie de l'élément de liste de fuseau horaire sélectionné peut afficher :

- Une abréviation de fuseau horaire des fuseaux horaires qui n'ont pas d'équivalent d'été ou d'hiver. Ces fuseaux horaires restent identiques toute l'année.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/04-selected-timezone.png)

- Une ou plusieurs emplacements géographiques qui suivent les mêmes règles de fuseau horaire.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/05-selected-timezone.png)

### 2.3 **Décalage GMT**

La deuxième partie de l'élément de liste de fuseau horaire sélectionné affiche le décalage GMT actuel pour l'élément de liste de fuseau horaire sélectionné.

Le fuseau horaire actuel pour l'élément de liste de fuseau horaire est affiché. Si le décalage GMT pour un emplacement géographique change, par exemple l'heure d'été ou d'hiver, le décalage GMT affiché pour ces emplacements géographiques change également.

### 2.4 **Sélection d'un élément de liste dans le menu déroulant du fuseau horaire**

Cliquez sur l'élément de liste de fuseau horaire sélectionné pour ouvrir le menu déroulant du fuseau horaire. Voici à quoi peut ressembler le menu déroulant du fuseau horaire :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/06-selecting-a-list-element-in-the-timezone-dropdown.png)

Par défaut, un élément de liste peut être vu pour chaque intervalle de décalage de fuseau horaire de trente minutes qui a un fuseau horaire actif dans le menu déroulant du fuseau horaire.

**Description de l'élément de liste de fuseau horaire** La première partie pour les éléments de liste de fuseau horaire peut afficher :

- Une abréviation de fuseau horaire

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/07-selecting-a-list-element-in-the-timezone-dropdown.png)

- Une ou plusieurs emplacements géographiques qui suivent les mêmes règles de fuseau horaire.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/08-selecting-a-list-element-in-the-timezone-dropdown.png)

**Nom de l'élément de liste de fuseau horaire** La deuxième partie d'un élément de liste de fuseau horaire peut afficher :

- Un nom de fuseau horaire.
  Pour les emplacements géographiques où le fuseau horaire est identique toute l'année.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/09-selecting-a-list-element-in-the-timezone-dropdown.png)

- Un décalage de fuseau horaire GMT+XX:XX
  Pour les emplacements géographiques où le fuseau horaire change pendant l'année.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/10-selecting-a-list-element-in-the-timezone-dropdown.png)

**Type d'élément de liste de fuseau horaire** La dernière partie pour les éléments de liste de fuseau horaire peut afficher :

- Une abréviation de fuseau horaire

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/11-selecting-a-list-element-in-the-timezone-dropdown.png)

- Un décalage de fuseau horaire GMT+XX

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/12-selecting-a-list-element-in-the-timezone-dropdown.png)

**Recherche dans le menu déroulant du fuseau horaire** Recherchez un emplacement géographique pour trouver tous les éléments de liste de fuseau horaire pour cet emplacement. S'il y a une correspondance, l'emplacement est inclus. Il n'est pas toujours listé comme indiqué ci-dessous.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/13-selecting-a-list-element-in-the-timezone-dropdown.png)

Certains fuseaux horaires peuvent être recherchés par leur nom court dans la première partie de l'élément de liste.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/14-selecting-a-list-element-in-the-timezone-dropdown.png)

Si un fuseau horaire est identique toute l'année, il peut être recherché dans la deuxième partie de l'élément de liste. Recherchez un fuseau horaire pour trouver tous les éléments de liste de fuseau horaire pour ce fuseau horaire.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/15-selecting-a-list-element-in-the-timezone-dropdown.png)

> **Remarque :** Les différents éléments de liste de fuseau horaire pour le même nom de fuseau horaire peuvent se comporter différemment selon l'heure et la date actuelles.

Recherchez un type de fuseau horaire pour trouver tous les éléments de liste de fuseau horaire pour ce type de fuseau horaire : Recherchez soit le décalage de fuseau horaire :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/16-selecting-a-list-element-in-the-timezone-dropdown.png)

Ou l'abréviation du fuseau horaire :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/17-selecting-a-list-element-in-the-timezone-dropdown.png)

Étant donné que certains fuseaux horaires ont un décalage GMT comme type, il est souvent préférable de rechercher le nom de fuseau horaire complet plutôt que l'abréviation du fuseau horaire. Seuls les fuseaux horaires actuellement actifs sont affichés, de sorte que pour les fuseaux horaires qui changent pour les emplacements géographiques, seul le fuseau horaire actuellement actif pour cet emplacement géographique peut être trouvé.

## 3. **Émetteurs**

Sélectionnez les membres de l'équipe dans l'équipe d'approbation finale que verront dans la liste des équipes parmi lesquelles ils peuvent choisir lors de la sélection d'une équipe émettrice pour une approbation avec ce flux de travail. Voici à quoi peut ressembler la partie émetteurs d'un nouveau flux de travail d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/18-submitters.png)

**Sélection d'une équipe dont le créateur du flux de travail fait partie** Si le créateur du flux de travail sera celui qui soumet ces types de flux de travail, il est important qu'une équipe dont le créateur du flux de travail fait partie soit ajoutée en tant qu'équipe émettrice.

**Sélection d'une équipe vide** Une équipe vide peut être sélectionnée si les membres qui feront partie de cette équipe ne font pas encore partie du projet.

**Sélection d'une équipe avec un seul membre** Comme il n'est pas possible d'ajouter des membres individuels, si un seul membre travaillera de cette façon pour approuver des documents, une équipe avec un seul membre peut être sélectionnée. Après la création du flux de travail, il ne sera pas possible de le modifier, donc même avec un seul membre, une équipe offre la flexibilité de déplacer les gens dans et hors de cette équipe.

> **Remarque :** Il est uniquement possible de sélectionner des équipes et non des membres individuels

### 3.1 **Requis**

Au moins un émetteur doit être sélectionné pour pouvoir soumettre le flux de travail.

## 4. **Étapes de validation**

Construisez un processus d'examen multi-étapes. Voici à quoi peut ressembler la partie étapes de validation d'un nouveau flux de travail d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/19-review-steps.png)

### 4.1 **Nombre d'étapes**

**Aucune étape** Bien qu'il soit possible de créer un flux de travail sans étapes en supprimant toutes les étapes, il ne sera pas possible de créer une approbation avec ce flux de travail car il doit y avoir au moins une étape pour pouvoir soumettre une approbation.

**Nombre maximum d'étapes** Le nombre maximum d'étapes qu'un flux de travail peut avoir est 10.

### 4.2 **Équipes**

Sélectionnez les équipes d'examinateur qui pourront participer à l'étape d'examen. Le nombre maximum d'équipes qu'un flux de travail peut avoir est 20. Chaque équipe doit soumettre son examen avant que le flux de travail ne passe à l'étape suivante. Si l'approbation automatique est cochée, le flux de travail passera automatiquement à l'étape suivante après le nombre de jours ouvrables configuré.

**Sélection d'une équipe dont le créateur du flux de travail fait partie** Si le créateur du flux de travail sera celui qui examinera une étape, il est important qu'une équipe dont le créateur du flux de travail fait partie soit ajoutée en tant qu'équipe d'examinateur.

**Sélection d'une équipe vide** Une équipe vide peut être sélectionnée si les membres qui feront partie de cette équipe ne font pas encore partie du projet.

**Sélection d'une équipe avec un seul membre** Comme il n'est pas possible d'ajouter des membres individuels, si un seul membre travaillera de cette façon pour approuver des documents, une équipe avec un seul membre peut être sélectionnée. Après la création du flux de travail, il ne sera pas possible de le modifier, donc même avec un seul membre, une équipe offre la flexibilité de déplacer les gens dans et hors de cette équipe.

### 4.3 **Jours ouvrables à évaluer**

Les jours ouvrables sont définis comme lundi à vendredi. Les jours fériés publics sont inclus dans les jours ouvrables à évaluer. _Jours ouvrables minimaux requis :_ 1 jour ouvrable

Exemple : S'il s'agit de la première étape, elle commencera dès que la demande d'approbation sera soumise. Sinon, elle commencera dès que les validations seront soumises pour chacune des révisions à l'étape précédente ou qu'elle aura progressé automatiquement et les aura validées.

Les jours ouvrables à évaluer pour une étape de demande d'approbation sont définis sur 2 jours.

Si la date de début de l'étape d'approbation est un vendredi, la date d'échéance sera définie sur :

- L'heure de début configurée dans la zone des paramètres de temps du flux de travail
- Le mardi de la semaine suivante, indépendamment du fait que ce mardi soit un jour férié public ou non.

### 4.4 **Approuver automatiquement**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/20-auto-approve.png)

Activez l'approbation automatique pour fluidifier le processus : les documents seront automatiquement approuvés au nom des équipes n'ayant pas répondu à la date d'échéance.

### 4.5 Exiger un examen par tous les membres de l'équipe

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/21-br-require-review-from-all-team-members.png)

Activez Exiger un examen par tous les membres de l'équipe pour exiger que chaque membre individuel de chaque équipe d'examinateur dans cette étape soumette sa propre indication de validation avant que l'examen de l'équipe ne puisse être soumis.

- **Quand c'est désactivé** (le comportement actuel et unique décrit ailleurs dans ce centre d'aide), n'importe quel membre de l'équipe d'examinateur peut soumettre une indication de validation au nom de toute l'équipe, et l'étape peut procéder dès qu'il le fait.

- **Quand c'est activé,** l'étape de l'équipe n'est pas complète jusqu'à ce que chaque membre individuel ait donné sa propre indication. Consultez les articles de l'onglet Aperçu, du menu droit d'examen des fichiers et du menu droit de l'onglet Documents pour voir comment cela s'affiche lors de l'examen.
  ​

### 4.6 **Supprimer l'étape de validation**

Cliquez sur l'icône de la corbeille en haut à droite d'une étape de validation pour la supprimer.

### 4.7 **Requis**

S'il y a des étapes de validation, chaque étape doit avoir au moins un émetteur pour pouvoir soumettre le flux de travail.

## 5. **Approbation finale**

L'approbation finale sera donnée manuellement par une seule équipe. Voici à quoi peut ressembler la partie approbation finale d'un nouveau flux de travail d'approbation :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/22-final-approval.png)

### 5.1 **Équipe**

L'équipe d'approbation finale qui donnera l'approbation finale en fonction des examens de chacune des équipes d'examinateur.

**Sélection d'une équipe dont le créateur du flux de travail fait partie** Si le créateur du flux de travail sera celui qui donnera la validation finale de l'approbation, il est important que l'équipe de publication soit une équipe dont le créateur du flux de travail fait partie.

**Sélection d'une équipe vide** Une équipe vide peut être sélectionnée si les membres qui feront partie de cette équipe ne font pas encore partie du projet.

**Sélection d'une équipe avec un seul membre** Comme il n'est pas possible d'ajouter des membres individuels, si un seul membre travaillera de cette façon pour approuver des documents, une équipe avec un seul membre peut être sélectionnée. Après la création du flux de travail, il ne sera pas possible de le modifier, donc même avec un seul membre, une équipe offre la flexibilité de déplacer les gens dans et hors de cette équipe.

### 5.2 **Jours ouvrables à approuver**

Le nombre de jours ouvrables que l'équipe d'approbation finale doit configurer l'approbation finale. _Jours ouvrables minimaux requis :_ 0 jour ouvrable

### 5.3 Modèle de sujet

Dans le champ modèles de sujet, vous pouvez choisir le modèle que le système utilise pour créer un sujet à la fin du flux d'approbation. Ne rien choisir signifie qu'aucun sujet ne sera créé !

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/23-br-topic-template.png)

Il est possible de choisir un modèle parmi les modèles de sujet existants. [En savoir plus sur les modèles de sujet](https://support.catenda.com/en/articles/14076010-topic-template-settings-page)

Lorsqu'il n'y a pas de modèle, vous avez la possibilité d'en créer un directement dans la vue des paramètres.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/24-br-topic-template.png)

### 5.4 **État d'examen**

Approuvé ou rejeté

### 5.5 **Statut final**

Sélectionnez le statut final pour les documents approuvés et rejetés. Les documents approuvés seront publiés, les documents rejetés ne seront pas publiés.

### 5.6 **Requis**

Une équipe d'approbation finale doit avoir été sélectionnée pour pouvoir soumettre le flux de travail. Un statut final pour les flux de travail approuvés doit être sélectionné pour pouvoir soumettre le flux de travail. Un statut final pour les flux de travail rejetés doit être sélectionné pour pouvoir soumettre le flux de travail.

## 6. **Transmettre**

Cliquez sur Transmettre pour soumettre le flux de travail.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/25-submit.png)

### 6.1 **Avertissement de champ obligatoire**

Si le flux de travail ne dispose pas d'un champ obligatoire, un avertissement vers le haut de la page demandera que les champs manquants soient remplis. Voici à quoi peut ressembler l'avertissement :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/m7h7atyc/26-required-field-warning.png)

Ce qui suit est requis pour soumettre un nouveau flux de travail :

- Un titre.
- Au moins 1 équipe émettrice doit être sélectionnée.
- Au moins 1 équipe d'examinateur doit être sélectionnée par étape de flux de travail.
- Au moins 1 jour ouvrable doit être configuré par étape de flux de travail.
- Une équipe d'approbation finale doit être sélectionnée
- Un statut final pour les flux de travail approuvés doit être sélectionné
- Un statut final pour les flux de travail rejetés doit être sélectionné

### 6.2 **Verrouillé après soumission**

Après soumission, il sera uniquement possible de modifier le titre du flux de travail.
