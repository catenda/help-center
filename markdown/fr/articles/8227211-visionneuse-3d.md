# Visionneuse 3D

Vous pourrez trouver la visionneuse 3D comme l'un des quatre panneaux principaux qui peuvent être ouverts en haut à droite de votre écran. Vous pouvez soit appuyer sur l'icône 3D pour ouvrir ce panneau, soit appuyer sur [shift+2](https://support.catenda.com/en/articles/4670267-summary-of-most-important-shortcuts-and-basic-controls#:~:text=3D%20viewer-,Shift%20%2B%202,-Trees%20panel).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/01-intro.png)

Avec un modèle chargé, la visionneuse 3D peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/02-intro.png)

## 1. **Chargement des modèles**

Les modèles peuvent être chargés dans la visionneuse 3D de plusieurs manières. Sur la page des modèles, 3D à côté du modèle à ouvrir peut être cliqué ou plusieurs modèles peuvent être sélectionnés et 3D peut être cliqué vers le haut de la liste. Dans la section Documents, vous pouvez ouvrir des aperçus de fichiers IFC et des documents de nuages de points en cliquant sur 3D dans la vue de liste des Documents ou dans le panneau d'information de droite. Vous pouvez également ouvrir la visionneuse 3D sans charger aucun modèle en cliquant sur 3D en haut à droite pour ouvrir le panneau de la visionneuse 3D.

### 1.1 **Sélecteur de révision**

Si vous n'avez pas encore chargé de modèles, vous pourrez charger et décharger des modèles en ouvrant la liste déroulante du sélecteur de révision. Cliquez [ici](https://support.catenda.com/en/articles/4670279-revision-selector) pour en savoir plus sur le sélecteur de révision

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/03-revision-selector.png)

### 1.2 **Liste déroulante de grille**

S'il y a des modèles dans vos projets qui contiennent des grilles, vous pourrez les charger dans la visionneuse avec cette liste déroulante. Cliquez [ici](https://support.catenda.com/en/articles/4670327-showing-grids) pour en savoir plus sur les grilles dans la visionneuse 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/04-grid-dropdown.png)

## 2. **Visibilité**

La liste déroulante de visibilité vous permet d'afficher, de masquer et de rendre les objets translucides.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/05-visibility.png)

Lorsque vous ouvrez la liste déroulante de visibilité, elle peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/06-visibility.png)

Ici, vous pourrez effectuer les actions suivantes :

### 2.1 **Affichage des objets**

**Afficher tout** Afficher tous les objet(s). Cela peut être utile après la lecture d'un instantané ou d'un signet qui a masqué la géométrie que vous souhaitez voir.

**Afficher la sélection** Afficher l'objet ou les objets sélectionnés. Si vous avez masqué un objet sélectionné, il reste sélectionné mais masqué jusqu'à ce que vous sélectionniez autre chose et le retiriez de votre sélection. Dans le panneau d'information, vous pourrez sélectionner des objets masqués à partir de l'arborescence d'objets et des sélections. Dans le panneau de contenu, vous pourrez sélectionner des objets à partir des Bibliothèques de propriétés et des objets qui sont liés à des problèmes ou des Documents.

### 2.2 **Translucidité des objets**

Il n'est pas possible de sélectionner des objets translucides en cliquant dessus dans la visionneuse 3D.

**Rendre translucide** Rendre l'objet ou les objets sélectionnés translucides. Dans le panneau d'information, vous pourrez sélectionner des objets masqués à partir de l'arborescence d'objets et des sélections. Dans le panneau de contenu, vous pourrez sélectionner des objets à partir des Bibliothèques de propriétés et des objets qui sont liés à des problèmes ou des Documents. Les objets translucides sélectionnés peuvent être ramenés à la visibilité par défaut en affichant la sélection ou en affichant tous.

**Rendre les autres translucides** Rendre tout translucide sauf l'objet ou les objets sélectionnés. Afficher tout pour ramener les objets à la visibilité par défaut.

### 2.3 **Masquage des objets**

L'objet ou les objets masqués resteront chargés dans la mémoire de votre système.

**Masquer** Masque un objet de la visionneuse

**Masquer les autres** Masquer tous les objets sauf l'objet ou les objets sélectionnés. C'est similaire à l'isolement d'objets. Les objets masqués resteront chargés en mémoire.

## 3. **Options de caméra**

La liste déroulante des options de caméra vous permet de choisir des points de vue, des types de caméra et des vues.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/07-br-camera-options.png)

### 3.1 **Point de vue**

Voici à quoi peut ressembler le menu des points de vue :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/08-viewpoint.png)

_Accueil_ - Réinitialiser la visionneuse à la position par défaut. Cela peut aider à avoir un aperçu de tous les modèles chargés dans la visionneuse.

Les vues suivantes vous permettent de voir le modèle de différents côtés :

**Arrière** Voir le modèle de l'arrière

**Gauche** Voir le modèle de la gauche

**Avant** Voir le modèle de l'avant

**Droite** Voir le modèle de la droite. Ces vues peuvent être excellentes pour créer des sections en faisant des plans de découpe verticaux.

**Haut** Voir le modèle de haut. Cette vue peut être excellente pour produire des plans d'étage en créant un plan de découpe horizontal.

### 3.2 **Type de caméra**

Voici à quoi peut ressembler le menu des types de caméra :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/09-camera-type.png)

_Perspective_ - Par défaut. Vous permet de voir le modèle comme le ferait un humain. Ce type de caméra est excellent pour comprendre à quoi cela pourrait ressembler d'être dans le modèle. Parce que la caméra est au niveau des yeux de l'humain, vous pouvez passer à travers les murs. Le champ de vision du type de caméra en perspective peut être ajusté dans les paramètres de la visionneuse.

**Orthographique** Vous permet de voir le modèle comme si vous étiez infiniment loin. Ce type de caméra est excellent pour la planification car il est plus facile de juger les distances. Parce que la caméra est infiniment loin, elle ne peut pas passer à travers les objets et vous devrez masquer ou rendre les objets translucides pour voir ce qui se trouve derrière.

### 3.3 **Vue**

Voici à quoi peut ressembler le menu des vues :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/10-view.png)

> **Remarque :** Assurez-vous que le matériel et les logiciels sur lesquels Catenda est ouvert sont configurés [selon les recommandations](https://support.catenda.com/en/articles/6921941-hardware-recommendation) car cela peut affecter l'affichage de la visionneuse.

**Régulier** Par défaut, la vue régulière est sélectionnée. Lignes fines d'affichage d'objets précis. Excellent pour les mesures.

Lorsqu'aucune couleur n'est définie pour un objet dans l'IFC, l'objet se verra attribuer une couleur en fonction de l'entité qui est configurée pour l'objet. L'entité se trouve dans le menu d'inspection du panneau d'information.

Puisqu'il n'y a pas de soleil ou de lumière artificielle dans la visionneuse Catenda, les objets ne projettent pas d'ombre les uns sur les autres. Les surfaces sont rendues par leur couleur plate assombrie selon que la caméra les regarde directement ou si la surface s'éloigne de la caméra.

**Contour** Le cell shading transforme les lignes sur les coins avec des angles s'éloignant de vous en lignes plus épaisses tandis que les lignes sur les coins se tournant vers vous deviennent des lignes plus fines. Cela crée une couche supplémentaire de profondeur, mais les lignes épaisses pourraient couvrir les mesures précises. Contour est une excellente vue pour exporter des images.

> **Remarque :** Assurez-vous que le matériel et les logiciels sur lesquels Catenda est ouvert sont configurés [selon les recommandations](https://support.catenda.com/en/articles/6921941-hardware-recommendation) car cela peut affecter la netteté des lignes.

**Esquisse** Idéal pour les réunions avec des parties externes qui ont besoin d'un affichage simple du modèle. Les objets sans couleur spécifiée dans l'IFC seront colorés avec des tons de gris et une texture pour que les surfaces ne paraissent pas aussi parfaitement plates. Les fenêtres resteront leur couleur bleue habituelle transparente.

> **Remarque :** Assurez-vous que le matériel et les logiciels sur lesquels Catenda est ouvert sont configurés [selon les recommandations](https://support.catenda.com/en/articles/6921941-hardware-recommendation) car cela peut affecter la netteté des lignes.

## 5. **Joystick**

Cliquer sur ce bouton affiche le joystick à l'écran. Le joystick vous permet de voler en douceur à travers le modèle en mode perspective et de tourner autour d'un point central en mode orthographique.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/13-joystick.png)

Si vous activez le joystick, vous verrez que le bouton change et obtient une liste déroulante.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/14-joystick.png)

Avec la liste déroulante à côté du joystick, vous pouvez configurer l'emplacement du joystick :

- Au milieu à gauche
- En bas à gauche
- En bas au centre
- En bas à droite
- Au milieu à droite

## 8. **Pied de page des informations sur les objets**

Par défaut, un pied de page s'affichera en bas de la visionneuse lorsque vous sélectionnez un objet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/17-object-information-footer.png)

Ce pied de page peut contenir des informations sur les sujets et les éléments de bibliothèque liés à l'objet.

### 8.1 **Identification**

Nom de l'objet - Entité de l'objet - Type d'objet. Si plusieurs objets sont sélectionnés, cela indiquera indéfini.

### 8.2 **Informations sur le sujet**

**Ouvert** Nombre de problèmes ouverts (Rouge). Cliquez sur "Ouvert" pour voir tous les problèmes ouverts où cet objet est lié dans le panneau de droite.

**Fermé** Nombre de problèmes fermés (Vert). Cliquez sur "Fermé" pour voir tous les problèmes fermés où cet objet est lié dans le panneau de droite.

### 8.3 **Bibliothèques**

Si vous avez lié votre objet sélectionné à des bibliothèques sur Catenda Hub, vous pourrez voir la bibliothèque avec le nombre de liens dans le pied de page d'information.

**SharePoint** Si vous avez lié votre objet sélectionné à des documents SharePoint, vous verrez le nom de la Bibliothèque SharePoint avec le nombre de documents liés ici

**Documents** Si vous avez lié votre objet sélectionné à des documents sur la page des documents, vous pourrez les voir sous documents et avec le nombre de documents liés ici.

**Classification** Si vous avez lié votre objet sélectionné à des classifications, vous pourrez voir le nom de la classification et le nombre de classifications liées ici.

**Liens** Si vous avez lié votre objet sélectionné à des liens de la bibliothèque de liens, vous pourrez voir "Liens" et le nombre de liens liés ici.

**Dropbox** Si vous avez lié votre objet sélectionné à des documents Dropbox, vous verrez le nom de la bibliothèque Dropbox avec le nombre de documents liés ici.

### 8.4 **Masquage du pied de page des informations sur les objets**

Cliquez sur le x pour masquer le pied de page des informations sur les objets de la visionneuse 3D.

### 8.5 **Affichage du pied de page des informations sur les objets**

Si vous avez choisi de fermer le pied de page d'information, vous pouvez le rouvrir avec le bouton i situé en bas de la visionneuse 2D ou du bouton 2D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/gkxpq62p/18-showing-the-object-information-footer.png)
