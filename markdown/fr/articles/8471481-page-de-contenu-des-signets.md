# Page de contenu des signets

Les signets se trouvent sur la [page des signets](https://support.catenda.com/en/articles/4670281-bookmarks-page). Voici à quoi peut ressembler un signet :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/01-intro.png)

Les rubriques suivantes sont décrites dans cet article :

## 1. **Menu d'action**

Le menu d'action se trouve en haut à droite de la page

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/02-action-menu.png)

### 1.1 **Nouveau signet**

Cliquez ici pour créer un [nouveau signet](https://support.catenda.com/en/articles/4670269-creating-a-new-bookmark).

### 1.2 **Supprimer le signet**

Pour supprimer un signet, cliquez sur Supprimer le signet dans le menu d'action en haut à droite. _Accès requis :_ Créateur du signet

## 2. **Capture**

L'image de la fenêtre d'affichage a été générée lors de la dernière mise à jour de la capture.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/03-snapshot.png)

Cliquez [ici](https://support.catenda.com/en/articles/10345863-snapshots) pour en savoir plus sur les captures.

## 3. **Titre**

Le titre du signet. Il peut être filtré avec un filtre de texte sur la [page des signets](https://support.catenda.com/en/articles/4670281-bookmarks-page).

### 3.1 **Créé par**

L'utilisateur qui a créé ce signet et le moment de sa création. Il n'est pas possible de supprimer les signets partagés avec le projet par des utilisateurs qui ne font plus partie du projet

## 4. **Copie et signet original**

Si ce signet a été créé en copiant un signet partagé avec le projet par un autre utilisateur, vous pourrez accéder au signet original en cliquant sur "Ouvrir le signet original" ici. De même, si vous consultez un signet dont vous avez fait une copie, vous pourrez "Ouvrir ma copie" ici.

## 5. **Partage**

Lorsqu'un signet est partagé avec le projet, tous les membres du projet peuvent voir le signet dans leur liste de signets.

Les rubriques suivantes sont décrites dans cette section :

### 5.1 **Privé**

Seul vous pourrez voir ce signet. Vous devrez peut-être désactiver l'URL partagée publiquement pour rendre le signet privé à nouveau, car les signets avec une URL publique doivent être partagés avec le projet.

### 5.2 **Partager avec le projet**

Les membres du projet pourront filtrer ce signet et en faire des copies. Les signets avec une URL publique sont toujours partagés avec le projet.

### 5.3 **Partage d'URL publique**

Dans la section de partage d'URL publique d'un signet, vous pouvez créer une URL publique. Les URL publiques sont généralement utilisées pour montrer à un client, un entrepreneur externe ou un officiel gouvernemental sur quoi les personnes du projet travaillent sans avoir à les inviter au projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/04-public-url-sharing.png)

Pour créer une URL publique, le signet doit d'abord être [partagé avec le projet](#h_5c9944a45e).

**Activer l'URL publique** Pour activer un signet public, cliquez sur Modifier le partage et cochez la case "Activer l'URL publique". _Accès requis :_ Administrateur du projet

Lorsqu'une URL est créée, n'importe qui dans le projet peut la partager avec des personnes en dehors du projet. Le signet public peut être verrouillé aux révisions ou pour suivre la dernière révision tout comme un signet ordinaire. Si vous suivez la dernière révision, les titulaires de liens peuvent suivre l'évolution du projet. Si vous verrouillez aux révisions, les titulaires de liens peuvent voir l'état actuel des révisions du modèle dans le signet. Assurez-vous de mettre à jour le signet si de nouveaux modèles sont ajoutés.

**Date d'expiration** Une date d'expiration peut être définie après laquelle l'URL n'ouvrira plus le signet. S'il y a des modèles avec des plans de travail 4D dans le projet, ceux-ci peuvent être appliqués au signet.

**Plan de travail (4D)** Lorsqu'un plan de travail 4D est ajouté, les spectateurs des captures voient les objets apparaître à mesure qu'ils sont installés sur le site.

**Après l'activation d'une URL publique** Voici à quoi peut ressembler le menu de partage d'URL publique après l'activation de l'URL publique :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/05-public-url-sharing.png)

Cliquez à nouveau sur Modifier le partage pour mettre à jour l'export.

Partagé par Tant qu'il y a un lien actif, le menu indiquera qui a partagé le lien et quand il a été partagé.

**Ouvrir dans un nouvel onglet** Tant qu'il y a un lien actif, le menu affichera le bouton "Ouvrir dans un nouvel onglet" pour ouvrir l'URL publique dans un nouvel onglet

**Copier le lien** Tant qu'il y a un lien actif, le menu affichera le bouton "Copier le lien" pour copier le lien vers l'URL publique

**Imprimer le lien QR** Tant qu'il y a un lien actif, le menu affichera le bouton "Imprimer le lien QR" pour ouvrir la boîte de dialogue d'impression du navigateur qui vous permet d'imprimer un document avec le code QR et un lien vers l'URL publique. Voici à quoi peut ressembler la boîte de dialogue d'impression du navigateur dans Google Chrome sur Windows :

![Google Chrome print QR code Microsoft Print to PDF Catenda](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/06-public-url-sharing.png)

Le document comprend le code QR lui-même, la date et l'heure d'impression et le titre du signet.

**Œil** Cliquez sur l'œil connecté au bouton Imprimer le lien QR pour afficher le code QR avec un lien vers l'URL.

_Date d'expiration_ Vers le bas du menu, la date d'expiration s'affiche. Si aucune date d'expiration n'est définie, il indique que le lien partagé n'expire pas. Une fois la date d'expiration passée, les boutons de ce menu disparaîtront et il indiquera que le lien a expiré ainsi que la date d'expiration. Un lien expiré peut ressembler à ceci :

![Public URL sharing Edit sharing Link has expired](https://raw.githubusercontent.com/catenda/help-center/main/images/w2a94gw0/07-public-url-sharing.png)

**Désactiver le partage public** Les propriétaires d'organisation peuvent demander que toutes les fonctionnalités de partage public soient désactivées pour tous leurs projets. Certains projets l'exigent pour des raisons de sécurité. Si vous souhaitez désactiver toutes les fonctionnalités de partage public, veuillez contacter le support en cliquant sur le bouton de chat noir à côté de votre photo de profil en haut à droite ou via [support@catenda.com](mailto:support@catenda.com)

## 6. Modèles et révisions

Après la création d'un signet, de nouvelles révisions peuvent être téléchargées le rendant obsolète. Parfois c'est souhaitable car vous souhaitez voir comment c'était au moment de la création et parfois vous voulez voir le signet avec les dernières révisions.

**Suivre la dernière révision** La dernière révision publiée des modèles dans le signet sera chargée lors de sa lecture.

> **Conseil :** **Révisions partagées :** Les révisions partagées ne s'afficheront pas car elles se trouvent toujours dans l'espace de travail. S'il y a une révision publiée dans le modèle de la révision partagée, la dernière révision publiée s'affichera à la place.

**Verrouiller aux révisions originales** Les révisions originales des modèles dans le signet seront chargées lors de sa lecture.

> **Conseil :** **Révisions partagées :** Avec cette option, les révisions partagées s'afficheront également.

Sous les options, les modèles seront listés avec la révision du modèle qui s'affichera lors de la lecture du signet. Assurez-vous de mettre à jour le signet si de nouveaux modèles sont ajoutés.
