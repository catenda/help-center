# Page des modèles de topic - Legacy

La page des modèles de topic se trouve en cliquant sur l'action modèles de topic dans le menu d'actions en haut à droite de la [page paramètres de topic](https://support.catenda.com/en/articles/12367293-approval-settings-page#h_320e990d50). _Accès requis_ : Administrateur

Voici à quoi peut ressembler la page des modèles de topics :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/01-intro.png)

Les topics suivants sont décrits dans cet article :

## 1. **Actions sur la page des modèles de topics**

Les actions de la page des modèles de topics se trouvent en cliquant sur le menu d'actions à droite du bouton plus vert en haut à droite de la page des modèles de topics. Voici à quoi peuvent ressembler les actions de la page des modèles de topics lors de la consultation des modèles de topics :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/02-actions-on-the-topics-templates-page.png)

Voici à quoi peuvent ressembler les actions de la page des modèles de topics lors de la consultation des modèles de topics archivés :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/03-actions-on-the-topics-templates-page.png)

### 1.1 **Nouveau modèle de topic**

Cliquez sur l'action nouveau modèle de topic pour créer un nouveau modèle de topic. Cliquez [ici](https://support.catenda.com/en/articles/12372007-creating-a-new-topic-template) pour en savoir plus sur la création de nouveaux modèles de topics.

### 1.2 **Modèles de topics / Modèles de topics archivés**

Cliquez sur les actions modèles de topics et modèles de topics archivés pour basculer entre la consultation des modèles de topics et la consultation des modèles de topics archivés.

## 2. **Carte de modèle de topic**

Une fois qu'un modèle de topic est créé, une carte pour le modèle de topic apparaît sur cette page. Cliquez sur une carte de modèle de topic pour ouvrir la [page du modèle de topic](https://support.catenda.com/en/articles/12371549-topic-template-page) de ce modèle de topic. Voici à quoi peut ressembler une carte de modèle de topic :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/n5z47ntk/04-topic-template-card.png)

Les topics suivants sont décrits dans cette section :

### 2.1 **Titre du modèle de topic**

Le titre du modèle de topic

### 2.2 **Modèle de topic créé par**

Le créateur du modèle de topic

### 2.3 **Titre**

Le titre que le topic aura. Par défaut, il est défini pour recevoir le nom de la demande d'approbation et le nom du document dont le résultat de la validation a conduit à la création de ce topic.

### 2.4 **Tableau de topic**

**Tableau** Le tableau de topic dans lequel le topic est créé.

**Statut** Le statut que le topic aura

**Type** Le type que le topic aura

### 2.5 **Échéance**

L'échéance appliquée au topic.

### 2.6 **Jalon**

Le jalon appliqué au topic.

### 2.7 **Assigné à**

Le Membre assigné au topic. Par défaut, ce paramètre est défini pour être l'éditeur de l'approbation.

### 2.8 **Demandé par**

Le Membre qui demande le topic. Par défaut, ce paramètre est défini pour être l'importateur de la révision dont le résultat de la validation a conduit à la création de ce topic.

### 2.9 **Étiquettes**

Les Étiquettes appliquées au topic lors de la création.

### 2.10 **Description**

La description que le topic généré aura. Par défaut, le topic généré inclura un Lien vers la demande d'approbation ainsi qu'un Lien vers la révision du Document dans la demande d'approbation.

## 3. **Nouveau flux de validation**

La page des modèles de topics n'est pas disponible pour les projets commençant par le nouveau flux de validation.
