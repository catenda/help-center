# Glisser-déposer !

> Cet article décrit comment glisser-déposer des fichiers dans votre Bibliothèque

Voici la nouvelle fonctionnalité dans Catenda, les fichiers peuvent maintenant être glissés-déposés dans la section Documents ! Jusqu'à 100 fichiers individuels peuvent être déposés dans la boîte de dialogue de téléchargement.
