# Étape 4 - Modèles

> Parcourez les modèles fédérés où vous pouvez visualiser et sélectionner des objets

> **Conseil :** Trouvez [l'étape 3](https://support.catenda.com/en/articles/10576100-step-3-documents) dans [Prise en main](https://support.catenda.com/en/collections/2657208-getting-started) sur le centre d'aide ou dans le menu d'aide.

Dans la zone des modèles, vous accédez à une liste contenant tous les modèles disponibles selon vos droits d'accès. Vous pouvez les sélectionner et les activer dans la Visionneuse 3D, ce qui vous permet de visualiser et de parcourir intuitivement les modèles fédérés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/chgdwm3p/01-intro.png)

_Pour aller plus loin :_ [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer), [Sélecteur de révision](https://support.catenda.com/en/articles/4670279-revision-selector)

> **Remarque :** Trouvez [l'étape 5](https://support.catenda.com/en/articles/10576182-step-5-topics) dans [Démarrage](https://support.catenda.com/en/collections/2657208-getting-started) sur le centre d'aide ou dans le menu d'aide.
