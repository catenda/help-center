# Page des milestones

La page des milestones se trouve en tant que sous-page de la [page des topics](https://support.catenda.com/en/articles/4670271-topics-page). Sur la page des milestones, vous pourrez voir quels milestones sont disponibles dans le projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5tw3m693/01-intro.png)

Voici à quoi peut ressembler la page des milestones :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5tw3m693/02-intro.png)

Cette page contient des informations sur les topics suivants : [Planification](#h_595c5ebf4c) - [Actions](#h_ef3bbf0441) - [Liste des milestones](#h_5403eb541f)

Les topics suivants sont décrits dans cet article :

## 1. Planification

Les milestones peuvent être utilisés de nombreuses façons différentes :

- Pour fixer une échéance tous les trimestres
- Fixer une échéance en fin de mois
- Avant le début de la construction

Les milestones peuvent servir d'outil pour fixer plus d'une échéance. Lorsque vous fixez une échéance pour un topic, vous pouvez choisir le milestone auquel le topic sera associé.

## 2. Actions

En haut à droite de la page, vous pourrez trouver les actions suivantes :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5tw3m693/03-actions.png)

### 2.1 Nouveau milestone

Cliquez sur le + vert ou sur l'action Nouveau milestone dans le menu d'actions pour créer un nouveau milestone.

### 2.2 Milestones archivés

Cliquez sur cette action pour voir quels milestones ont été archivés dans le projet.

## 3. Liste des milestones

Dans la liste des milestones, vous verrez un aperçu de chacun des milestones qui font partie du projet. La liste des milestones peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5tw3m693/04-milestones-list.png)

Cliquez n'importe où sur le milestone pour ouvrir la page de ce milestone. Pour chaque milestone, vous verrez les informations suivantes

Les topics suivants sont décrits dans cette section :

### 3.1 Titre

Le titre du milestone

### 3.2 Echéance

Vous verrez ici un drapeau et l'échéance du milestone. Le drapeau sera rouge si l'échéance est dans les deux prochaines semaines, gris si elle est à plus de deux semaines et rose quand le milestone est passé.

### 3.3 Description

La description du milestone

### 3.4 Statistique des topics

Dans la statistique des topics du milestone, vous pourrez voir la progression de ce milestone pour tous les topic boards ensemble. Consultez la page du milestone pour les données spécifiques à chaque topic board.

**Pourcentage** Vous verrez ici le pourcentage de topics auxquels ce milestone est assigné et qui sont fermés dans tous les topic boards. Les topics candidats ne comptent pas dans ce pourcentage.

**Ouvert/fermé/candidat** Vous verrez ici le nombre de topics avec les statuts de métadonnées ouvert, fermé ou candidat auxquels ce milestone a été assigné. Cliquez sur le mot ouvert, fermé ou candidat pour voir les topics associés dans le topic board de tous les topics.

**Photo de profil des Membres** Vous verrez d'abord le créateur du milestone et la photo non assignée. Pour chaque photo de profil, vous verrez un nombre de topics. Pour le créateur du milestone et non assigné, ce nombre peut être 0 et sera alors vert. Les autres utilisateurs ne seront visibles que s'ils ont des topics ouverts auxquels ce milestone a été assigné avec un nombre de topics ouverts auxquels ils ont été assignés en rouge.

### 3.5 Créé par

Vous verrez ici le nom de l'utilisateur qui a créé le milestone et la date de création du milestone.
