# Types d'organisation

Un nombre quelconque d'organisations peut être créé pour un client, mais selon le type d'organisation, elles peuvent contenir différents types de projets.

## 1. **1. Organisation des projets actifs**

Un projet de construction en cours peut faire partie d'une organisation de projets actifs. Pour chaque organisation, un plan peut être configuré. Les personnes responsables de l'administration de Catenda au sein d'une organisation peuvent être désignées comme propriétaires de l'organisation. Les propriétaires d'organisation peuvent recevoir l'accès à la création de projets en configurant un plan avec une limite de projets pour l'organisation. Les plans d'entreprise suivants sont disponibles :

### 1.1 **1.1 Nombre maximum de projets**

Avec ce plan, il peut y avoir jusqu'à un nombre défini de projets à la fois.

### 1.2 **1.2 Organisation par taille de projet**

Les types de projets dans cette organisation dépendent de la taille de chacun des projets. Les projets de taille similaire sont regroupés dans la même organisation.

### 1.3 **1.3 Projets illimités**

Un nombre quelconque de projets peut être créé dans ce type d'organisation. Pour des raisons de sécurité, une limite de projets supérieure à ce qui serait probablement réalisable est souvent définie pour ces types d'organisations.

### 1.4 **1.4 Établissements d'enseignement**

Les projets provenant d'étudiants au cours de périodes d'études récentes sont souvent conservés dans ces types d'organisations.

**Date d'expiration** Une date d'expiration est souvent configurée pour l'organisation, ce qui signifie que les projets créés dans cette organisation expirent après un certain délai. Si une date d'expiration est définie pour une organisation d'enseignement, elle est souvent définie à 365 jours à partir de la création du projet. La date d'expiration configurée pour l'organisation ne compte que pour les nouveaux projets créés dans l'organisation. La date d'expiration des projets existants ne peut être modifiée que par Catenda au cas par cas.

> **Note :** Les professeurs peuvent préparer les projets avant le début de la période d'études, de sorte que la durée totale après qu'un étudiant récupère le projet peut être inférieure.

## 2. **2. Organisation des projets inactifs**

Transférez les projets vers une organisation de projets inactifs pour libérer une place dans l'organisation des projets actifs. L'activité des membres du projet dans ces types de projets est surveillée. Si plus d'activité des membres du projet est constatée que prévu pour un projet inactif, le projet sera compté comme un projet actif. Théoriquement, il est donc possible d'avoir un nombre quelconque de membres dans un projet dans ce type d'organisation, mais il est recommandé de nettoyer la liste des membres. L'outil d'organisation est souvent utilisé pour supprimer tous les membres sauf les membres principaux responsables du projet et les administrateurs de l'organisation.

### 2.1 **2.1 Projets suspendus**

Un projet typique dans cette organisation est un projet suspendu. Les projets peuvent être suspendus pour de nombreuses raisons, par exemple lorsqu'un projet de construction manque de budget ou lorsque les ressources doivent être réaffectées à d'autres projets.

### 2.2 **2.2 Pas plus en usage**

Les autres cas d'usage de ce type d'organisation peuvent inclure des projets qui ne sont plus en utilisation mais que les gens veulent conserver un peu plus longtemps. Une raison de conserver un projet dans Catenda peut être que le projet s'est terminé mais qu'il n'y a pas eu le temps d'exporter toutes les informations, soit parce qu'il n'y a pas eu le temps, soit parce qu'il n'existe pas encore de solution d'archivage.

**Archive** Contrairement à d'autres solutions spécifiquement destinées à l'archivage à long terme, Catenda est destinée à être utilisée pour la collaboration active. Dans certains pays, selon la loi, dès que le projet est terminé, Catenda est obligée de supprimer les données. Dans les situations où il n'est pas nécessaire que le projet soit supprimé, les projets pourraient vouloir être conservés plus longtemps. Les projets sont alors souvent déplacés vers une organisation d'archives.

## 3. **3. Organisation des projets administratifs**

Une organisation administrateur est créée dès que le premier projet de test est créé. Lorsqu'un accord d'entreprise est conclu, une organisation administrateur est créée s'il n'en existe pas encore.

### 3.1 **3.1 Projet nouvelles fonctionnalités**

S'il y a des questions qui surgissent à n'importe quel point du parcours client, une organisation distincte appelée administrateur peut être créée si elle n'existe pas déjà. Dans l'organisation, les projets peuvent être créés de sorte qu'ils ne comptent pas vers le nombre total de projets actifs. Pour répondre aux questions, un projet peut être créé dans une telle organisation afin qu'une configuration ou une configuration spécifique puisse être essayée ou de nouvelles fonctionnalités qui ne sont pas encore disponibles pour tous les utilisateurs puissent être activées et considérées pour l'activation sur les projets actifs.

**Date d'expiration** Une date d'expiration peut être définie pour la durée de la période de test afin que la question puisse être résolue. La date d'expiration ne peut être modifiée que par Catenda au cas par cas.

### 3.2 **3.2 Projet modèle**

Chaque organisation administrative inclut généralement un projet modèle. Après que les premiers projets aient été configurés individuellement, un projet modèle est souvent créé dans l'organisation administrative par Catenda. Dans ce projet, les configurations de projet typiques sont créées afin que le projet puisse être utilisé comme projet modèle dans la création de nouveaux projets. Les configurations de projet typiques peuvent inclure : modèles nommés et vides sur la page des modèles. Tableaux de sujets avec paramètres configurés comme les statuts, les types et les champs personnalisés. Page Documents avec structure de dossier et configuration de dossier avec champs personnalisés et convention de nommage. Le contrôle d'accès peut être configuré pour tous ceux-ci à utiliser dans le nouveau projet. Paramètres de projet comme les champs personnalisés et les conventions de nommage.

### 3.3 **3.3 Projets administratifs**

Les projets administratifs sont souvent créés dans cette organisation pour la communication interne et pour discuter des conversations avec Catenda. Ces types de projets n'ont généralement pas de date d'expiration.

### 3.4 **3.4 Projets de test actifs**

Les projets de test sont souvent créés ou rouverts dans cette organisation tant qu'ils ne sont pas utilisés pour les projets de construction réels. Ces projets reçoivent souvent une date d'expiration pour que Catenda puisse être testée sans affecter le projet actif.

### 3.5 **3.5 Projets de test inactifs**

Les projets qui ont été utilisés lors des phases de test précédentes se trouvent souvent dans cette organisation. Ces projets sont généralement des projets tels que : Projets éducatifs Projets de test Projets Sandbox

**Date d'expiration** Une date d'expiration peut être définie pour la durée de la période de test pour que le projet reste actif mais ne puisse plus être accédé. La date d'expiration ne peut être modifiée que par Catenda au cas par cas et est souvent héritée de la configuration de l'organisation où le projet a été créé.

### 3.6 **3.6 Projets d'exemple**

Les projets d'exemple peuvent inclure des projets qui sont terminés et qui ont été correctement configurés. Les projets exemplaires sont souvent déplacés vers l'organisation administrative pour montrer aux gens à quoi pourrait ressembler un vrai projet.
