# Téléchargement d'une nouvelle révision de document

En téléchargeant une nouvelle révision d'un document au lieu de créer un nouveau document, toutes les versions d'un document peuvent être regroupées au même endroit. Il est possible de télécharger de nouvelles révisions vers un document à la fois avec le bouton d'action. _Accès requis :_ Accès en écriture au document

## 1. **Glisser-déposer**

Glissez-déposez un fichier sur un document dans le tableau des documents pour le télécharger en tant que nouvelle révision de ce document.

## 2. **Menu de téléchargement**

Une nouvelle révision peut être téléchargée vers jusqu'à 100 documents dans un dossier à la fois via la boîte de dialogue de téléchargement. Glissez-déposez un ou plusieurs fichiers dans le tableau des documents, cliquez sur parcourir dans un dossier vide ou cliquez sur le bouton plus vert en haut à droite pour [ouvrir le menu de téléchargement de document](https://support.catenda.com/en/articles/4670278-uploading-a-document#h_00fa77db3e). Dans le menu de téléchargement, les fichiers peuvent être reconnus et téléchargés en tant que nouvelle révision vers les documents appropriés. Cliquez ici pour en savoir plus sur la boîte de dialogue de téléchargement.

## 3. **Importation zip**

Si des documents portant le même nom que les fichiers dans un fichier zip importé avec l'[action d'importation zip](https://support.catenda.com/en/articles/7945410-upload-a-zip-file-structure) existent, ils seront ajoutés en tant que nouvelle revision au lieu d'un nouveau Document.

## 4. **Action dans la structure des documents**

Avec un seul document sélectionné, l'action de nouvelle révision peut également être trouvée dans le [menu d'action de l'élément existant](https://support.catenda.com/en/articles/4670288-documents-table-actions#h_5785139ce3) qui apparaît lorsqu'un élément est sélectionné en haut du tableau des documents. L'avantage de cette action est qu'il n'y a aucune confusion sur le nom du document. Le document est sélectionné et le fichier que vous avez choisi est téléchargé vers le document qui a été sélectionné sans avoir à vous soucier de son nom. _Accès requis :_ Accès en écriture au document

![](https://raw.githubusercontent.com/catenda/help-center/main/images/amtr8hmr/01-action-in-document-structure.png)

## 5. **Action dans l'aperçu du document**

Ouvrez le [menu d'action du document](https://support.catenda.com/en/articles/9323521-document-revision-actions#h_ea6fb90f40) en haut à droite ou cliquez sur l'icône de nouvelle révision. L'action de nouvelle révision ouvre l'explorateur de fichiers de votre système. À partir de l'explorateur de fichiers, le fichier qui sera téléchargé en tant que nouvelle révision peut être choisi. L'avantage de cette action est qu'il n'y a aucune confusion sur le nom du document. Le document est sélectionné et le fichier que vous avez choisi est téléchargé vers le document qui a été sélectionné sans avoir à vous soucier de son nom.
