## 2. **Bogues résolus**

Grâce à vos précieux commentaires, nous avons pu corriger de nombreux Sujets que vous aviez peut-être ou non remarqués. Ci-dessous figure une liste des modifications mineures apportées par l'équipe de développement à la suite de discussions avec les utilisateurs.

### 2.1 **Documents**

- Les annotations de mesure dans les documents pdf qui sont téléchargés ne provoquent plus la disparition de toutes les autres annotations.
- Il est à nouveau possible de télécharger les révisions précédentes à partir du menu d'informations correct
- Si un document ne peut pas être téléchargé, cela provoque une lacune dans la base de données causant des problèmes pour les approbations de publication. Il est maintenant également possible de publier des approbations avec des documents où un document n'a pas pu être téléchargé.
- Il est à nouveau possible de voir les révisions publiées dans les approbations

### 2.2 **Modèles**

- Arborescence système - Les groupes qui sont liés à d'autres groupes se chargeront désormais plus rapidement et n'apparaîtront plus comme leur propre groupe au niveau racine de l'arborescence système.
- Il est à nouveau possible de voir les révisions du modèle sur la page d'aperçu de la révision d'un modèle dans les projets modèles pré-Documents.
- Il est à nouveau possible de modifier l'angle de transformation d'un modèle et de le voir après un rechargement de la page
- La valeur de transformation initiale lors de la création d'un modèle a été corrigée
- La transformation de rotation est maintenant xyz comme elle est censée l'être, au lieu de xyy
- Une transformation de coordonnées y n'est plus appliquée lors de l'ajout de rotation à un modèle.

Si vous appliquez maintenant une transformation avec rotation, rechargez la page et chargez à nouveau le modèle, il apparaîtra au bon endroit.

- La fonctionnalité 4D fonctionne à nouveau.

## 3. **Demandes des utilisateurs accomplies**

### 3.1 **Sujets**

- Il est maintenant possible d'ajouter un logo à la page des paramètres du projet. Ce logo apparaîtra vers le haut droit de chaque page de Sujet dans l'exportation PDF.

### 3.2 **Documents**

- Il est maintenant possible d'ajouter des champs personnalisés aux dossiers. Les champs personnalisés peuvent être définis par défaut, ce qui fait que tous les documents téléchargés dans le dossier (et ses sous-dossiers) obtiennent la valeur par défaut.
