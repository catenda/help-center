# Sélecteur de révision

Le sélecteur de révision est un menu déroulant qui se trouve en haut à gauche de l'écran dans le panneau [Visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/01-intro.png)

Cliquez sur le bouton avec le "cube" pour ouvrir le sélecteur de révision.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/02-intro.png)

Des informations sur les sujets suivants se trouvent dans cet article :

## 1. **Modèles**

Dans le menu des modèles, vous pouvez travailler avec des documents 3D tout en gardant le panneau de la visionneuse 3D en vue complète.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/03-models.png)

Le menu des modèles peut ressembler à ceci.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/04-models.png)

Activez ou désactivez la visibilité des documents 3D et choisissez la révision à afficher pour chaque document.

### 1.1 **Recherche**

Trouvez les documents 3D que vous recherchez en effectuant une recherche sur une partie de leurs noms.

Une correspondance partielle de 3 caractères romains ou plus peut être trouvée dans la liste des noms de documents 3D. Les caractères d'espacement comme l'espace "" ne sont pas inclus dans ce nombre.

**Correspondance après séparateur** Après un séparateur, la règle des trois caractères est réinitialisée et seuls trois caractères ou plus après un séparateur peuvent être mis en correspondance. La règle des trois caractères est réinitialisée après chaque séparateur. Les séparateurs peuvent être des caractères comme les traits de soulignement "`_`" ou les tirets "`-`".

**Panneau de contenu** Pour affiner votre recherche, envisagez de rechercher dans le panneau de contenu. Vous pouvez filtrer sur plus d'informations que simplement le nom du modèle. Dans le panneau de contenu, tous les documents 3D qui ont été liés à un modèle se trouvent sur la [page des modèles](https://support.catenda.com/en/articles/4670286-models-page). Les documents 3D qui n'ont pas été liés à un document se trouvent sur la [page des documents](https://support.catenda.com/en/articles/8204673-documents-page).

### 1.2 **Liste des documents 3D**

Consultez les 10 documents 3D les plus pertinents. La liste des documents 3D est triée selon l'[ordre de tri typique des listes sur Catenda](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists).

_Modèles -_ Affichés par défaut Voir tous les [documents Ifc](https://support.catenda.com/en/articles/5658031-ifc-support-in-documents) qui ont été liés à un modèle. Votre liste des modèles disponibles est basée sur le paramètre d'accès du document lié à ce modèle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/05-3d-document-list.png)

_Documents 3D -_ Affichés lors du chargement Chargez les documents 3D à partir de la page des documents pour les afficher vers le haut de la liste. Consultez [ici](https://support.catenda.com/en/articles/4670320-previewing-file-types-on-catenda-hub#h_2edd1d4e9c) les formats de documents qui peuvent être chargés dans la visionneuse 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/06-3d-document-list.png)

_Charger plus_ Pour charger plus de modèles, cliquez sur le bouton charger plus en bas du sélecteur de révision.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/07-3d-document-list.png)

### 1.3 **Bouton 2D**

Lorsque le bouton 2D est vert, la vue 2D de ce modèle est visible dans la [visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer) et chargée en mémoire. Lorsque le bouton est gris, la vue 2D de ce modèle ne sera pas visible et ne sera pas chargée en mémoire.

### 1.4 **Bouton 3D**

Lorsque le bouton 3D est cliqué, il devient vert. La vue 3D de ce document sera alors disponible dans la [visionneuse 3D](https://support.catenda.com/en/articles/8227211-3d-viewer) et chargée en mémoire. Tant que le bouton 3D est vert, les objets du modèle qui appartiennent à ce modèle seront disponibles dans la visionneuse 3D.

> **Remarque :** Disponible ne signifie pas visible car les objets peuvent être masqués et rester disponibles.

Après qu'un modèle a été chargé en mémoire, le bouton 3D peut être cliqué à nouveau. Alors que les objets ne sont pas disponibles dans la visionneuse 3D, le document sera toujours chargé en mémoire. Cela vous permet d'activer et de désactiver rapidement les documents que vous avez précédemment chargés.

**Déchargement de la mémoire** Pour décharger les modèles de la mémoire, actualisez la page ou allez à la page des modèles du modèle spécifique que vous souhaitez décharger. Pour décharger les documents de la mémoire, appuyez sur le x à droite du nom du document.

### 1.5 **Centrer les objets**

Cliquez sur ce bouton pour centrer la position de la caméra sur le lieu où se trouvent la plupart des objets dans ce modèle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/08-center-objects.png)

Disponible uniquement pour les modèles.

### 1.6 **Zoom sur les extents**

Cliquez sur ce bouton pour voir un aperçu du contenu entier de ce document 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/09-zoom-to-extents.png)

Disponible uniquement pour les documents 3D qui ont été chargés dans la visionneuse 3D.

### 1.7 **Icône de type de fichier**

L'icône de chaque type de fichier de document 3D. Disponible uniquement pour les documents 3D.

### 1.8 **Nom**

Pour les modèles, le nom du modèle s'affiche. Pour les documents, le nom du document s'affiche. La liste des documents suit l'[ordre de tri général des listes](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists) dans Catenda.

### 1.9 **Révision du modèle**

À droite du nom du document 3D, du texte souligné en vert peut être vu. Le texte affiché reflète le numéro de la révision qui sera chargée lorsque le bouton 3D est activé. Si une révision du document 3D est déjà chargée, le numéro reflète la révision actuellement sélectionnée et chargée en mémoire.

Cliquez sur ce texte pour changer la révision active à une révision différente du document 3D.

> **Remarque :** Il n'est possible de charger qu'une seule révision à la fois par document 3D dans le menu des modèles.

Après avoir sélectionné une révision différente, la révision actuelle est déchargée de la mémoire et la révision sélectionnée est chargée en mémoire.

**Révision #X** Si le texte indique `#X` ou `#X.X`, la dernière révision du document 3D est soit disponible pour le chargement, soit actuellement chargée.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/10-model-revision.png)

Si le texte indique `#X`, la dernière révision du document 3D est une révision publiée. Si le texte indique `#X.X`, la dernière révision du document 3D est une révision partagée.

**#76 de 77** Si la révision sélectionnée n'est pas la dernière révision, quelque chose comme `#76 de 77` s'affiche. #76 fait référence au numéro de révision actuel et 77 fait référence à la dernière révision publiée ou partagée du document 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/11-model-revision.png)

Si la dernière révision est retirée ou n'a pas pu être traitée, quelque chose comme `#75 de 77` s'affiche. #75 fait référence à la dernière révision disponible pour afficher les objets dans la visionneuse 3D.

**Barré** Si le texte de révision est barré, la révision sélectionnée est retirée et aucun objet de document 3D n'est affiché.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/12-model-revision.png)

Cela se produit généralement uniquement lorsqu'une révision est chargée et est retirée tandis qu'elle est chargée car les révisions retirées ne peuvent pas être sélectionnées.

**Pas de texte** S'il n'y a pas de texte derrière le document 3D, il n'y a pas de révisions et le document est vide.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/13-model-revision.png)

### 1.10 **Paramètres du nuage de points**

Les nuages de points peuvent être configurés dans le sélecteur de révision en cliquant sur l'icône d'engrenage.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/14-point-cloud-settings.png)

Cliquez [ici](https://support.catenda.com/en/articles/5606625-point-clouds-in-catenda-hub) pour en savoir plus sur les différentes façons de configurer la visionneuse 3D pour visualiser les nuages de points.

### 1.11 **Décharger le document**

Cliquez sur le x à droite d'un document 3D pour le décharger de la visionneuse 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/15-unload-document.png)

### 1.12 **Restaurer la 3D**

Il n'est possible de charger les modèles dans la visionneuse 3D que depuis un menu de sélecteur de révision à la fois. Si les modèles du menu des modèles ont été chargés avant qu'un modèle soit chargé dans l'un des autres menus du sélecteur de révision, vous pouvez cliquer sur restaurer la 3D dans le menu des modèles pour recharger l'ensemble précédemment activé de modèles du menu des modèles dans la visionneuse 3D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/16-restore-3d.png)

## 2. **Requêtes**

Limitez les objets que vous chargez dans la visionneuse 3D avec les requêtes d'objets. Cela vous permet d'économiser de la mémoire lors du chargement de centaines de modèles à la fois et de garder l'arborescence des objets rangée. Cliquez [ici](https://support.catenda.com/en/articles/4854514-queries#h_b7e8a9a086) pour en savoir plus sur les requêtes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/17-queries.png)

## 3. **Comparer**

Avec le menu de comparaison, deux révisions de modèle peuvent être sélectionnées pour être superposées. Cliquez [ici](https://support.catenda.com/en/articles/4670313-revision-selector-short-video) pour regarder une courte vidéo sur la façon de comparer les révisions des modèles.

Voici à quoi le menu Comparer peut ressembler :

![Sélecteur de révision modèles requêtes comparaison est en surbrillance sélectionner le modèle et la révision couleur modèle](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/18-compare.png)

Pour commencer la comparaison, cliquez sur "Sélectionner le modèle et la révision" et choisissez un modèle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/19-compare.png)

Dans la liste des révisions de ce modèle, sélectionnez une révision pour commencer la comparaison.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/20-compare.png)

Tous les modèles qui ont été activés dans l'un des autres menus de sélecteur de révision sont déchargés et seuls les modèles du menu de comparaison sont affichés car il n'est possible de charger les modèles que depuis un menu de sélecteur de révision à la fois.

Voici à quoi le panneau 3D peut ressembler après que les deux révisions du modèle ont été sélectionnées.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/vh710sy2/21-compare.png)

La première et la deuxième révision peuvent provenir du même document 3D ou d'un document 3D différent lié à un modèle. Tous les objets de la révision du document 3D sont mis en surbrillance dans la couleur spécifiée pour la révision. Cliquez sur la liste déroulante des couleurs pour modifier la couleur de tous les objets de la révision du document 3D.

Si la vue 3D d'un menu de sélecteur de révision différent a été restaurée, le bouton 3D du menu Comparer est désactivé. Cliquez sur le bouton 3D pour activer/désactiver à nouveau la révision comparée.

### 3.1 **Visualiser les différences**

Après la sélection, les deux révisions du modèle seront superposées dans la visionneuse 3D. Les révisions peuvent maintenant être comparées visuellement. En voyant le chevauchement entre les objets colorés, il est possible de voir où une couleur est plus importante que l'autre. Les couleurs des objets qui sont au même endroit s'ajoutent les unes aux autres. Par exemple, si le rouge et le bleu ont été sélectionnés, les objets des deux révisions qui sont au même endroit sont violets. Cette différenciation des couleurs facilite l'identification des modifications entre les révisions.
