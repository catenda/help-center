# Actions de révision de document

Selon votre accès, différentes actions pour votre document et ses révisions peuvent être visibles sur la [page d'aperçu de révision de document](https://support.catenda.com/en/articles/8461918-document-banner-navigation).

## 1. **Actions de document**

Le menu d'action à droite des icônes peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/nxq3vptz/01-document-actions.png)

### 1.1 **Télécharger la dernière révision publiée**

L'icône de téléchargement et l'action du menu hamburger sur une page de document téléchargent la dernière révision du document. Même si vous consultez une révision antérieure, vous obtiendrez la dernière révision avec cette action.

Si vous souhaitez télécharger les révisions antérieures d'un document, vous pouvez le faire dans le [menu des révisions](https://support.catenda.com/en/articles/8302244-right-menu-in-a-document#h_d0769e55eb) du [menu d'information de droite](https://support.catenda.com/en/articles/8302244-right-menu-in-a-document).

### 1.2 Même action que dans la liste des documents

Les actions qui ont le même comportement que dans la liste des documents incluent :

- [Nouvelle révision](https://support.catenda.com/en/articles/4670293-uploading-new-document-revision)
- [Lier et délier](https://support.catenda.com/en/articles/4670288-actions-documents#h_d9a539f267)
- [Nouveau brouillon](https://support.catenda.com/en/articles/4670288-actions-documents#h_fb8963d8e5)
- [Déplacer](https://support.catenda.com/en/articles/4670288-actions-documents#h_f80b6a94f2)
- [Créer un modèle](https://support.catenda.com/en/articles/4670288-actions-documents#h_33d57b9d3d)
- [Supprimer un modèle](https://support.catenda.com/en/articles/4670288-actions-documents#h_33d57b9d3d)
- [Aperçu](https://support.catenda.com/en/articles/4670288-actions-documents#h_02cfc15b02)
- [Supprimer](https://support.catenda.com/en/articles/4670288-actions-documents#h_fbf2be74c3)

## 2. **Actions de révision de document**

Les actions pour votre révision actuelle se trouvent dans le [menu de droite d'une révision](https://support.catenda.com/en/articles/8302244-right-menu-of-a-revision). Voici à quoi peuvent ressembler les actions de révision :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/nxq3vptz/02-document-revision-actions.png)

### 2.1 **Comparer**

Si vous avez plusieurs révisions PDF dans un document, vous pourrez voir l'action [Comparaison PDF](https://support.catenda.com/en/articles/8461650-pdf-compare). Cliquez [ici](https://support.catenda.com/en/articles/8461650-pdf-compare) pour en savoir plus sur la comparaison PDF.

### 2.2 **Publier**

Si vous avez activé le flux de travail de statut dans votre projet, toute nouvelle révision créée sera une révision partagée. Les révisions partagées auront un numéro de révision mineur. (0.1, 0.2, 1.1, etc...) L'action de publication peut être disponible pour les révisions partagées dans le modèle. Seules les révisions partagées après la dernière révision publiée peuvent être publiées. Les révisions publiées auront un numéro de révision mineur. (1.0, 2.0, 3.0, etc...) _Accès requis :_ Peut publier

Avec l'action de publication, vous pourrez publier la dernière révision partagée. Après la publication, une nouvelle révision publiée avec un numéro majeur (1.0, 2.0, 3.0, etc...) sera ajoutée.

### 2.3 **Télécharger**

Cliquez sur l'icône de téléchargement en haut à droite du menu de révision ou sur le téléchargement dans le menu hamburger à côté de l'icône de téléchargement pour télécharger la révision actuelle. _Accès requis :_ Accès en lecture au document

### 2.4 **Retirer la révision**

En savoir plus sur le retrait des révisions [ici](https://support.catenda.com/en/articles/9711174-withdraw-revision) _Accès requis :_ Accès complet au document
