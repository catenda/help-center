# Page des paramètres du document

Les paramètres de la bibliothèque de Documents se trouvent en tant que sous-page de la [page Documents](https://support.catenda.com/en/articles/8204673-documents-page). Sur cette page, l'accès au niveau supérieur de la page Documents peut être configuré et un aperçu des accès peut être généré. Le statut du workflow peut être activé, permettant aux Membres du projet de suivre la progression d'une révision dans un workflow. Les workflows pour approuver une révision afin de passer à l'étape suivante peuvent être configurés. Les métadonnées par défaut, les conventions de nommage ou l'estampage de codes QR peuvent être configurés pour les dossiers et les Documents. _Accès requis :_ Administrateur ou accès à la [configuration du Statut du document](#h_e6f3ffdbff) dans les [paramètres du projet](https://support.catenda.com/en/articles/4670273-project-settings-page).

## 1. **Contrôle d'accès**

### 1.1 **Aperçu des accès**

Ce bouton vous mènera à l'[aperçu des accès](https://support.catenda.com/en/articles/6660820-document-access-overview-acl-dashboard) de la section Documents. Ici, vous pourrez générer un aperçu de l'Équipe ou du Membre qui a accès à quels dossiers dans la section Documents.

### 1.2 **Modifier l'accès**

Dans le menu de contrôle d'accès, vous pourrez définir l'accès du dossier racine de la section Documents.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/03-edit-access.png)

Sur la page Documents, l'accès peut être configuré pour les dossiers et les Documents. Cependant, il n'y a rien à sélectionner pour configurer l'accès au niveau le plus élevé de la page Documents. Qui peut effectuer des actions au niveau le plus élevé du tableau Documents ? C'est à cela que sert le menu de contrôle d'accès sur la page des paramètres du document. Pensez à l'ensemble du tableau Documents comme à un grand dossier contenant tous les dossiers et Documents du projet. Le menu de contrôle d'accès sur la page des paramètres du document est le menu de contrôle d'accès pour ce dossier. Cliquez [ici](https://support.catenda.com/en/articles/4670287-folders-and-documents-acl) pour en savoir plus sur le contrôle d'accès aux Documents

## 2. **Statut du workflow**

L'activation du Statut du workflow vous permettra d'appliquer des Statuts aux informations.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/04-status-workflow.png)

Le Statut du workflow suit les normes ISO 19650 qui décrivent la progression des informations dans un processus. Avant d'activer le Statut du workflow, toutes les informations soumises à Catenda sont considérées comme étant à l'étape de publication, ce qui signifie généralement que les informations téléchargées sont la version finale de ces informations. À l'étape avant la publication, les Documents peuvent être collaboratifs avant d'être finalisés et déplacés vers l'étape publiée. L'étape après la publication est l'archivage, c'est-à-dire lorsque le projet est archivé sur Catenda ou que les informations sont exportées pour être stockées en dehors de Catenda. Cliquez [ici](https://support.catenda.com/en/articles/12310173-status-workflow-document-settings) pour en savoir plus sur le menu Statut du workflow.

## 3. **Validations**

Voici à quoi peut ressembler le menu des validations :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/05-approvals.png)

Le menu des validations n'est disponible que dans les projets où le nouveau workflow de validation a été demandé pour être activé. Le nouveau workflow de validation est une fonction à la demande qui peut être demandée pour être activée pour les nouveaux projets. Les nouveaux projets créés sur la base d'un projet modèle où cette fonction est activée ne disposent pas de cette fonction activée.

### 3.1 **Configurer les circuits de validation**

Cliquer sur le bouton Configurer les circuits de validation ouvre la page des circuits de validation. Sur la page des circuits de validation, les circuits de validation peuvent être configurés, à partir desquels les Membres pourront choisir lorsqu'ils créent une validation sur la [page des validations](https://support.catenda.com/en/articles/8349340-approvals-page). Cliquez [ici](https://support.catenda.com/en/articles/12309903-workflows-page-document-settings) pour en savoir plus sur la page des circuits de validation.

## 4. **Configuration des dossiers**

Voici à quoi peut ressembler le menu de configuration des dossiers :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/zae8a0s9/06-folder-configuration.png)

Dans le tableau de configuration des dossiers, les éléments suivants peuvent être configurés pour les dossiers :

- Conventions de nommage
- Champs personnalisés sur les Documents
- Champs personnalisés sur les révisions dans les Documents
- Estampage de codes QR

Cliquez [ici](https://support.catenda.com/en/articles/12302595-folder-configuration-menu) pour en savoir plus sur le menu de configuration des dossiers.
