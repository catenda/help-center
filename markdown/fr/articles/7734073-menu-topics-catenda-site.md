# Menu Topics - Catenda Site

Le menu Topics se trouve dans le [menu](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site) ou en appuyant sur le bouton Topics dans la barre de navigation inférieure.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/01-intro.png)

Dans le menu Topics, vous verrez le nom du projet actuel en haut.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/02-intro.png)

Sous le nom du projet, vous verrez un menu déroulant. Si vous appuyez sur ce menu ou sur l'icône de recherche, vous pouvez choisir le tableau Topic à afficher.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/03-intro.png)

Le passage à un nouveau tableau Topic mettra à jour les dernières informations Topic pour le tableau auquel vous basculez.

## 1. **Filtres**

À droite du menu, vous verrez le bouton Filtre. Les filtres seront enregistrés pour chaque tableau Topic.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/04-filters.png)

Vous pouvez filtrer par :

- Mes sujets
- Statuts et types
  - Si un statut ou un type est ajouté au projet ou si le nom d'un statut ou d'un type existant est modifié, les sujets ayant ce statut auront le nom du statut et du type, mais la couleur sera grise.
  - Il ne sera pas possible de filtrer et de voir la couleur de ces statuts jusqu'à ce que vous retourniez à la [page du projet](https://support.catenda.com/en/articles/7733978-projects-page-catenda-site) et rouvriez le projet.
- [Étiquettes](https://support.catenda.com/en/articles/7854138-label-filter-catenda-site)
- Echéance
- Localisation
  ​

### 1.1 Icône Réinitialiser le filtre

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/05-reset-filter-icon.png)

Si vous appuyez sur l'icône Réinitialiser les filtres pour supprimer une préférence de filtre dans mes sujets, la date d'échéance ou la localisation. L'appui sur ce bouton désélectionnera également tous les statuts, types et étiquettes qui ont été sélectionnés.

## 2. **Liste Topics**

Dans ce menu, les sujets selon votre filtre seront affichés.

### 2.1 **Mise à jour des sujets**

Faites glisser vers le bas la liste Topics pour récupérer les dernières modifications de votre tableau Topic.

### 2.2 **Entrée Topic**

Pour chaque sujet, vous verrez les informations suivantes :

**Aligné à gauche** Numéro du sujet Nom du sujet Statut, type et étiquettes Demandeur Assigné Jalon Echéance Date de création

**En bas à droite** Localisation Nombre de commentaires

### 2.3 **Nouveau sujet**

Appuyez sur le cercle vert avec le plus au milieu pour créer un nouveau sujet

![](https://raw.githubusercontent.com/catenda/help-center/main/images/68qsmtaz/06-new-topic.png)
