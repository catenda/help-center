# Requêtes

> Une explication de la fonction de requête dans la barre d'outils 2D

Une requête est un moyen de charger des objets à partir de portions de modèles dans Catenda Hub sans charger le modèle entier.

Les fichiers IFC ont tendance à être des versions légères du modèle dans le programme de création à partir duquel ils ont été exportés et sont souvent assez légers pour être visualisés dans le navigateur s'ils ne contiennent pas d'objets avec beaucoup de géométrie.

## 1. **Quand créer une requête ?**

Néanmoins, il se peut que votre performance soit limitée. Cela pourrait être causé par plusieurs facteurs tels que la géométrie volumineuse mentionnée auparavant, mais aussi la tentative de charger de nombreux modèles à la fois (100+) et l'atteinte de la limite que votre appareil peut gérer. Quand il s'agit de charger des modèles, c'est souvent la mémoire qui est requise. Particulièrement sur les appareils mobiles avec une mémoire limitée c'est le cas, mais même les systèmes moyens avec 16 Go de RAM peuvent manquer de mémoire lorsque de nombreux modèles sont chargés.

## 2. **Créer une requête**

Les requêtes peuvent être créées à partir de la [visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer) ou à partir d'une bibliothèque de propriétés. Avec la [visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer), vous pouvez facilement sélectionner une zone du projet que vous souhaitez charger. Avec une bibliothèque de propriétés, vous pouvez facilement sélectionner les objets avec une propriété spécifique que vous souhaitez charger.

## 3. **Requête de la visionneuse 2D**

Pour créer une requête à partir de la [visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer), ouvrez la vue 2D d'un modèle :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/01-2d-viewer-query.png)

Cela vous aidera à comprendre à partir de quel endroit du projet vos objets seront sélectionnés. Il existe trois façons différentes de créer des requêtes dans la visionneuse 2D. Si vous cliquez avec le bouton droit dans la visionneuse 2D, le [menu d'interactions de la visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer#h_bfa30db456) s'ouvrira. Ici, vous pourrez sélectionner les requêtes suivantes : [Requête d'espace intersectant](#h_bade07829c) [Requête d'étage intersectant](#h_6127f099ac) La troisième requête peut être créée avec le [menu déroulant de sélection de la visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer#h_042dc145fa) Ici, vous pourrez choisir : sélection rectangulaire qui vous permet de créer la requête suivante : [Sélection rectangulaire](#h_33afc95ee3)

### 3.1 **Requête d'espace intersectant**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/02-intersecting-space-query.png)

1. Cliquez avec le bouton droit sur un espace
1. Sélectionnez _Espace intersectant_

Cela chargera toute la géométrie intersectant la boîte englobante alignée sur l'axe de l'espace.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/03-intersecting-space-query.png)

### 3.2 **Requête d'étage intersectant**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/04-intersecting-storey-query.png)

1. Cliquez avec le bouton droit dans la visionneuse
1. Sélectionnez _Étage intersectant_

Cela chargera toute la géométrie à l'intérieur des plans supérieurs et inférieurs de l'étage.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/05-intersecting-storey-query.png)

### 3.3 **Sélection rectangulaire**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/06-rectangle-selection.png)

1. Cliquez sur le bouton du rectangle de requête.
1. Cliquez, faites glisser et relâchez pour dessiner un rectangle.
1. Spécifiez les modèles que vous souhaitez charger dans la fenêtre contextuelle de requête.

**Fenêtre contextuelle de requête**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/07-rectangle-selection.png)

1. Sélectionnez l'étage actuel ou la hauteur complète.
1. Sélectionnez Tous, Externe ou Interne.
1. Activez ou désactivez tous les modèles.
1. Sélectionnez les modèles à inclure dans la requête.
1. Créer une requête.

## 4. **Requête de la bibliothèque de propriétés**

Lorsque vous avez synchronisé votre [bibliothèque de valeurs de propriété](https://support.catenda.com/en/articles/4670252-property-value-library), vous pourrez cliquer sur le nombre d'objets à côté de la valeur de propriété et sélectionner à partir du ou des modèle(s) pour lesquels vous souhaiteriez créer une requête d'objets ayant cette valeur de propriété.

## 5. **Modification d'une requête**

Les requêtes peuvent être modifiées en sélectionnant le menu de requête dans le [sélecteur de révision](https://support.catenda.com/en/articles/4670279-revision-selector#h_fcf1c5a080).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/58rq5x2c/08-editing-a-query.png)

Ici, vous verrez les différentes requêtes que vous avez chargées dans cette session. Pour modifier une requête, cliquez sur le bouton Éditer à droite de votre requête. Puisque les requêtes ne chargent qu'un ensemble limité d'objets, il n'est pas possible de travailler avec des modèles à partir de l'onglet modèles et des requêtes en même temps. Si vous souhaitez travailler avec des modèles à partir de l'onglet modèles, cliquez sur restaurer 3D. Cela déchargera la requête et chargera le modèle entier à la place.

## 6. **Enregistrement des requêtes**

Pour enregistrer votre requête afin de continuer à travailler dessus plus tard, créez une capture d'écran 3D dans la section des commentaires d'un sujet ou créez un signet. Si vous souhaitez continuer à travailler avec votre requête lors de votre prochaine session Catenda, vous pouvez lire le signet ou la capture d'écran.
