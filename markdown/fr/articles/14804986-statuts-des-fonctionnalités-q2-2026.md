# Statuts des fonctionnalités Q2 2026

Pour éviter les notifications indésirables et assurer un lancement en douceur, les nouveaux comportements ou modifications des comportements existants peuvent être déployés graduellement et sans préavis. Ceux qui remarquent des changements de comportement dans une partie de la page qu'ils utilisent fréquemment ou ceux qui se demandent ce qui est nouveau peuvent consulter ces articles pour des mises à jour sur les changements récents de comportement pour tous les utilisateurs.

## 1. **Nouvelles fonctionnalités**

Chaque utilisateur utilise la plateforme différemment. Même si une nouvelle fonctionnalité est publiée ou si des modifications sont apportées à une fonctionnalité, il se peut que les utilisateurs n'utilisent pas cette partie de la fonctionnalité. Pour ceux qui sont curieux de savoir ce qu'est "ce nouveau bouton" ou "cette nouvelle page" sur la plateforme, cet article contient une introduction sur ce que le changement concerne. Pour ces fonctionnalités, souvent seul un matériel d'assistance basique ou légèrement obsolète est disponible, car cela est mis à jour au fur et à mesure. Outre l'aide apportée en support, les articles sont souvent mis à jour et si des questions posées peuvent être rapidement trouvées expliquées dans un article la semaine suivante.

## 2. **Fonctionnalités mises à jour**

### 2.1 **Nom d'objet dans le panneau des arbres**

Jusqu'à présent, les noms des niveaux imbriqués étaient affichés, mais pour l'objet au niveau le plus bas, un nom généré automatiquement était affiché comme :

```
WallStandardCase1.0WallStandardCase1.1WallStandardCase1.2
```

Le comportement par défaut a maintenant changé pour afficher à la place la valeur du nom de l'objet qui peut être vue dans le panneau d'inspection comme ceci :

```
Basic Wall:Exterior - Insul Panel on Mtl. Stud:140707Basic Wall:Exterior - Insul Panel on Mtl. Stud:140832Basic Wall:Exterior - Insul Panel on Mtl. Stud:140972
```

Une nouvelle révision de model doit être téléchargée pour pouvoir voir la différence.

Le comportement précédent avec le nom généré automatiquement, qui peut être utile, a été conservé en cliquant sur l'icône d'engrenage vers le coin supérieur droit de chaque menu d'arbre model.

## 3. **Activation des fonctionnalités à la demande**

Chaque fonctionnalité à la demande est de qualité production et prête pour une utilisation réelle en projet. Bien que ces fonctionnalités aient été testées pour fonctionner comme elles le devraient, il peut y avoir des degrés variés quant au nombre de projets qui ont commencé à utiliser ces fonctionnalités, de sorte que des cas limites inconnus pourraient être découverts. Bien que des modifications puissent survenir alors que nous travaillons à rendre ces fonctionnalités disponibles pour tous les utilisateurs, les données soumises dans ces fonctionnalités ne seront pas supprimées.

### 3.1 **Demande d'activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être demandées pour être activées pour les projets existants par la personne de contact de votre licence Catenda tandis que d'autres peuvent être activées avec un paramètre dans le projet. Lorsqu'une fonctionnalité à la demande est demandée pour être activée, une réunion sera organisée avec un représentant du support pour discuter du statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la fonctionnalité à la demande peut être testée, un projet fictif peut être créé pour une durée limitée où la fonctionnalité à la demande peut être testée pour déterminer si la fonctionnalité est prête à être utilisée.

### 3.2 **Éditeur de rapports**

Créez des modèles de rapports pour les sujets et les documents afin que les membres du projet puissent sélectionner les sujets ou les documents du tableau et utiliser l'action de rapport pour générer un rapport. La page des rapports est une fonctionnalité à la demande qui peut être demandée pour être activée pour les projets en cours. Les nouveaux projets créés à partir d'un projet modèle où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Des modèles séparés peuvent être créés pour les sujets et les documents. Lorsqu'un modèle est disponible dans un projet, l'action de rapport peut être utilisée avec les sujets et les documents sélectionnés pour générer un rapport basé sur le modèle sélectionné. Le support pour la façon dont différentes valeurs peuvent être affichées sur la page est offert par Catenda. Si vous souhaitez un rapport personnalisé adapté à votre entreprise, nous pouvons vous mettre en contact avec un consultant qui peut vous aider.
