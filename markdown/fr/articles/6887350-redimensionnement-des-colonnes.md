# Redimensionnement des colonnes

Vous saurez que vous redimensionnez une colonne si vous voyez une boîte gris clair suspendue à la ligne entre deux en-têtes. Lorsque vous survolez la ligne entre deux en-têtes de colonnes avec votre souris, vous pouvez faire glisser pour modifier la largeur d'une colonne.

**Changement de curseur :** Vous saurez que vous survolez le bon endroit quand votre curseur se transforme en pointeur de redimensionnement

![](https://raw.githubusercontent.com/catenda/help-center/main/images/dysbq1me/01-intro.png)

**Double clic :** Si vous double-cliquez sur le point de glissement, la colonne se développera automatiquement à la taille de son contenu.
