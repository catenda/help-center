# Flux de travail BCF utilisant l'outil de marquage dans Archicad

**BCF d'Archicad vers Bimsync** Dans Archicad, sélectionnez l'outil de marquage pour créer un BCF. Ici, vous pouvez mettre en évidence l'élément associé et joindre différentes vues au BCF, etc. Exportez les entrées de marquage sélectionnées sous forme de fichier bcfzip.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/01-intro.png)

Accédez aux problèmes et échangez les problèmes pour télécharger le BCF. Importez BCF et sélectionnez le BCF enregistré à partir d'Archicad.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/02-intro.png)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/03-intro.png)

Le BCF est maintenant chargé dans la section des problèmes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/04-intro.png)

Vous pouvez ensuite aller modifier les différents paramètres à l'intérieur du problème en cliquant dessus.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/05-intro.png)

**BCF de Bimsync vers Archicad** Filtrez le problème que vous souhaitez obtenir.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/06-intro.png)

Exportez le problème filtré.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/07-intro.png)

Téléchargez le BFC sélectionné. Le fichier sortira sous forme de fichier bcfzip.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/08-intro.png)

Accédez à l'outil de marquage dans Archicad et importez le BCF via l'importation des entrées de marquage. Le BCF sélectionné apparaît dans la barre d'outils de marquage.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5fgdptf6/09-intro.png)
