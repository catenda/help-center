# Page du compte

Vos [paramètres de compte](https://bimsync.com/account/profile) se trouvent à deux endroits :

1. Sur le côté gauche de la **page d'accueil** de Catenda Hub.
1. Dans le menu déroulant qui apparaît après avoir cliqué sur votre **photo de profil** n'importe où dans Catenda Hub.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4w10q5d/01-intro.png)

La [page du compte](#h_38e4a79227) comporte trois sous-pages.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4w10q5d/02-intro.png)

## 1. **Compte**

Sur la [page du compte](https://bimsync.com/account/profile), il est possible de modifier votre nom d'utilisateur et votre photo de profil. Il n'est pas possible de modifier votre adresse e-mail car elle est liée à votre compte.

Voici ce à quoi la page du compte peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4w10q5d/03-account.png)

Comme on peut le voir en haut à droite, si aucune photo de profil n'est téléchargée, les initiales du nom d'utilisateur s'affichent. Les initiales affichées sont les trois premiers caractères après chaque espace dans le nom d'utilisateur. Il n'est pas possible de définir des initiales personnalisées. Une solution de contournement serait de créer une photo de profil avec les initiales souhaitées.

### 1.1 **Changer de photo**

Cliquez sur changer de photo et sélectionnez une photo de profil depuis votre système. La boîte de dialogue Définir une nouvelle photo s'ouvrira et pourrait ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4w10q5d/04-change-photo.png)

Cliquez sur définir une nouvelle photo pour enregistrer la photo de profil. Voici ce à quoi le menu de photo de profil peut ressembler après l'ajout de la photo de profil.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4w10q5d/05-change-photo.png)

> **Remarque :** la photo de profil n'est visible que dans les produits Catenda et ne sera pas visible dans d'autres produits avec lesquels des informations de Catenda ont pu être échangées.

### 1.2 **Supprimer la photo**

Cliquez sur supprimer la photo pour supprimer votre photo de profil.

### 2.2 **Date et heure**

Choisissez le format dans lequel vous souhaitez voir les paramètres de date et d'heure. Par défaut, les paramètres de date et d'heure sont affichés de manière relative à votre heure actuelle. Cela signifie qu'un problème créé ou un modèle téléchargé sera affiché comme ayant été créé il y a 1 semaine ou 1 mois. Si vous avez besoin d'informations plus spécifiques, par exemple pour voir combien de temps s'est écoulé entre deux éléments téléchargés rapprochés, il est possible de désactiver cette option. La date et l'heure autour de Catenda Hub s'afficheront maintenant avec la date et l'heure spécifiques de l'occurrence.

## 4. **Applications**

Sur la [page des applications](https://bimsync.com/account/apps), les applications configurées pour le compte peuvent être affichées. Voici ce à quoi la page des applications peut ressembler :

![Gérez vos applications et les applications accédant à vos données](https://raw.githubusercontent.com/catenda/help-center/main/images/e4w10q5d/08-applications.png)

### 4.1 **Vos applications**

Chaque application API est connectée à un compte Catenda. La configuration de l'application peut être affichée dans la zone vos applications. Avec une application configurée, c'est là que vous pouvez trouver les paramètres suivants :

**Nom de l'application** Le nom de l'application. Ce nom est configuré par Catenda. Pour modifier le nom de votre application, veuillez contacter le support.

**ID client** L'ID client de l'application. Chaque application a un ID unique qui ne peut pas être modifié.

**Secret client** Le mot de passe de l'application. Chaque application a un mot de passe unique qui ne peut pas être modifié.

**URL de redirection** L'URL vers laquelle l'application redirigera les codes d'accès lorsqu'une demande est envoyée avec le secret client et l'ID client corrects. Pour recevoir correctement un code d'accès, l'URL de la demande doit correspondre à l'URL configurée ici.

### 4.2 **Applications ayant accès à votre compte**

Les applications auxquelles l'accès au compte a été accordé sont affichées. Cliquez [ici](https://support.catenda.com/en/articles/8396532-catenda-connections) pour voir quelles applications peuvent être connectées.

**Révoquer l'accès** Cliquez sur révoquer l'accès pour révoquer l'accès qui a été accordé à cette application. Après cela, l'accès devra être accordé à nouveau pour continuer à utiliser cette application avec ce compte. Selon l'application, elle peut demander à l'utilisateur d'accorder à nouveau l'accès ou elle peut donner une erreur et ne pas demander un nouvel accès. Se déconnecter et se reconnecter réinitialise souvent la connexion dans ce cas.
