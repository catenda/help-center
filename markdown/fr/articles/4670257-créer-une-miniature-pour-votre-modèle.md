# Créer une miniature pour votre modèle

1\. Sélectionnez le modèle souhaité dans l'aperçu du modèle.

2\. Ouvrez le modèle en 3D.

3\. Appuyez sur "Ajouter une image"

4\. Sélectionnez l'étendue de l'image

5\. Appuyez sur Enregistrer.

![Snag_665ab2.png](https://raw.githubusercontent.com/catenda/help-center/main/images/ez137xtp/01-intro.png)

Vous aurez maintenant une miniature du modèle dans l'aperçu du modèle. Vous pouvez également télécharger n'importe quelle image que vous souhaitez avoir comme miniature de modèle.
