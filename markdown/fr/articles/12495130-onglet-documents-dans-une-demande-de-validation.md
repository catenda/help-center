# Onglet Documents dans une demande de validation

L'onglet Documents d'une demande de validation se trouve sur la page de demande de validation de chaque validation. Dans l'onglet Documents, on peut voir les montants de validation des indications de validation soumises au nom des équipes d'examinateurs par un membre de chaque équipe d'examinateurs pour chaque document faisant partie de la validation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/01-intro.png)

## 1. **Actions sur les éléments sélectionnés**

Voici à quoi peuvent ressembler les actions sur les éléments sélectionnés dans l'onglet Documents :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/02-selected-item-actions.png)

Le tableau indique le statut des Documents dans cette validation spécifique. Dans la dernière colonne se trouve le bouton _soumettre_ ou _examiner_. Selon le statut du Document dans la validation.

## 2. **Menu de droite**

Le menu de droite peut être ouvert en cliquant sur l'icône d'information vers la droite de l'onglet Documents. Les Membres qui font partie de plusieurs Équipes d'examinateurs dans une étape de validation peuvent facilement soumettre des indications de validation pour plusieurs Documents au nom de chacune de leurs Équipes dans ce menu sans avoir à ouvrir chaque Document pour l'examiner. L'icône Info peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/03-right-menu.png)

Cliquez [ici](https://support.catenda.com/en/articles/12495638-approval-request-documents-right-menu) pour en savoir plus sur le menu de droite de l'onglet Documents.

> **Remarque :** Sélectionnez un Document (en cliquant sur le titre) ou sélectionnez plusieurs Documents qui vous sont assignés pour commencer directement l'examen à partir de l'onglet Documents.

## 3. **Tableau d'approbation des documents**

### 3.1 **Colonnes**

- **Nom :** Affiche le nom du Document et le type de Document avec l'icône.
  En cliquant sur le titre, vous pouvez afficher directement le Document dans l'environnement de validation.
- **Révision :** Affiche le nom de révision du Document
- **# :** Affiche quelle version/révision du Document à l'intérieur de la validation il s'agit.
  - Lorsqu'un Document est ajouté à une validation, il affiche son numéro de révision majeure et mineure qui peut ressembler à ceci :

      <div class="intercom-container"><img src="https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/inline-1bda23a9911c.png" width="122"/></div>

- Si la révision partagée sélectionnée a été publiée pour devenir la dernière révision publiée dans le Document en dehors de la demande de validation actuelle, cela peut ressembler à ceci :

      <div class="intercom-container"><img src="https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/inline-83fe3ba7ad73.png" width="289"/></div>

- **Étape « x » :** Affiche avec une barre quel est le Statut de l'étape.
- **Approbation finale :** Cette colonne affiche l'approbation finale ; lorsqu'elle est activée, l'icône s'affiche en couleur.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/04-columns.png)

### 3.2 Approbation finale

Lorsque l'approbation finale n'a pas encore été donnée, cette colonne affiche « à venir ». Après qu'un Membre de l'Équipe d'approbation finale a soumis l'indication d'approbation pour un Document, le résultat final du Document s'affichera ici comme étant approuvé ou rejeté.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/svn39yd6/05-final-approval.png)
