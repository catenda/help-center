# Modification du nom de votre projet

Sur la page des paramètres, vous pouvez modifier le nom du projet si vous êtes administrateur. Les Membres réguliers du projet ne pourront pas modifier le nom. 1\. Accédez à la page des paramètres. 2\. Modifiez le nom du projet en saisissant le nom souhaité. 3\. Appuyez sur mettre à jour. Le nom du projet est modifié.
