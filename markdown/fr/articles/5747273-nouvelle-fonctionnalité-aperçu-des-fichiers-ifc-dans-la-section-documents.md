# Nouvelle fonctionnalité : Aperçu des fichiers IFC dans la section Documents.

> Les fichiers IFC peuvent être affichés comme n'importe quel autre document.

Le téléchargement d'un IFC dans la section Documents permet un aperçu du model individuellement. De plus, vous pouvez envoyer ce model à la Visionneuse en cliquant sur le bouton 3D.
