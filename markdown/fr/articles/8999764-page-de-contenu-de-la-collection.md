# Page de contenu de la collection

Les collections peuvent être créées sur la [page des collections](https://support.catenda.com/en/articles/6344318-collections-page). Avec les collections, les Documents de différents dossiers peuvent être rassemblés dans une seule liste. La collection peut ensuite soit être partagée avec un Membre du projet pour qu'il puisse suivre les dernières versions d'un ensemble de Documents, soit être partagée avec une personne externe qui a besoin d'accès sans faire partie du projet.

Voici à quoi peut ressembler une page de collection :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g39es426/01-intro.png)

## 1. **Banneau de collection**

### 1.1 **Fil d'ariane**

Documents > Collections > #Nom de la collection Cliquez sur Documents pour revenir à la [page des Documents](https://support.catenda.com/en/articles/8204673-documents-page). Cliquez sur Collections pour revenir à la [page des collections](https://support.catenda.com/en/articles/6344318-collections-page).

### 1.2 **Retour**

Cliquez sur Retour pour revenir à la [page des collections](https://support.catenda.com/en/articles/6344318-collections-page).

### 1.3 **Actions de collection**

Les actions de collection se trouvent en haut à droite de la page.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g39es426/02-collection-actions.png)

Nouvelle collection Cliquez sur l'action nouvelle collection pour créer une nouvelle collection

**Copier la collection** Cliquez sur le bouton Copier la collection pour créer une nouvelle collection identique à la collection actuelle.

**Supprimer la collection** Cliquez sur l'action Supprimer la collection pour supprimer la collection actuelle _Accès requis :_ Administrateur ou propriétaire de la collection

## 2. **Menu de droite**

Le menu de droite se trouve en haut à droite du banneau de collection, sous le menu d'action. Cliquez sur l'icône "i" en haut à droite pour l'ouvrir. _Accès requis :_ Créateur de la collection ou administrateur

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g39es426/03-right-menu.png)

Cliquez [ici](https://support.catenda.com/en/articles/12179454-right-menu-on-the-collection-page) pour en savoir plus sur le menu de droite sur la page de collection.

## 3. **Type de collection**

Les collections peuvent être privées, partagées avec le projet ou finalisées

### 3.1 **Collection privée**

Après la création d'une collection, elle sera privée. Cela signifie que seul l'utilisateur qui a créé la collection pourra la voir.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/g39es426/04-private-collection.png)

Les collections privées peuvent soit suivre la dernière revision publiée, soit être verrouillées aux revisions des Documents qui ont été ajoutés à la collection. Partagez une collection privée ou finalisez-la dans le [menu de droite d'une collection](https://support.catenda.com/en/articles/12179454-right-menu-on-the-collection-content-page) pour la partager avec le reste du projet.

### 3.2 **Collection partagée avec le projet**

Une collection privée peut être partagée avec le projet dans le [menu de droite d'une collection](https://support.catenda.com/en/articles/12179454-right-menu-on-the-collection-content-page). Les collections qui sont partagées avec le projet sont visibles par tous les Membres. À ce stade, la liste des Documents de la collection peut toujours être modifiée. Les collections partagées avec le projet peuvent soit suivre la dernière revision publiée, soit être verrouillées aux revisions des Documents qui ont été ajoutés à la collection.

### 3.3 **Collection finalisée**

Les collections finalisées sont verrouillées pour la modification. Les collections finalisées doivent être verrouillées aux revisions. Des Liens publics peuvent être créés pour les collections finalisées dans le [menu de droite de la collection](https://support.catenda.com/en/articles/12179454-right-menu-on-the-collection-content-page).

## 4. **Tableau de collection**

### 4.1 **Actions du tableau**

Les actions du tableau se trouvent vers le haut à droite du tableau des collections

**Télécharger la collection** Cliquez sur Télécharger la collection pour télécharger un fichier zip contenant tous les Documents de la collection.

**Ajouter des Documents** Cliquez sur [Ajouter des Documents](https://support.catenda.com/en/articles/6344318-collections-page#h_b94d108342) pour ajouter des Documents à votre collection. Si votre Document a été trouvé infecté par un virus, vous ne pourrez pas l'ajouter à la collection.

> **Remarque :** Le nom du Document dans la collection sera le nom de la revision qui a été ajoutée. Ceci est un peu comme le nom de fichier d'origine. Ce nom peut être différent du nom du Document car un Document peut contenir plusieurs revisions avec des noms différents.

### 4.2 **Actions Document**

L'action Document de collection peut être trouvée en cliquant sur le menu d'action avec les trois points à droite de la ligne du Document.

**Télécharger** Cliquez sur Télécharger pour télécharger ce Document individuel _Accès requis :_ Accès en lecture au Document et revision non retirée

**Modifier la revision** Utilisez l'action Modifier la revision pour modifier la revision du Document configurée pour cette collection. _Accès requis :_ Créateur de la collection ou administrateur

**Supprimer le Document** Utilisez l'action Supprimer le Document pour supprimer un Document de la collection. _Accès requis :_ Créateur de la collection ou administrateur
