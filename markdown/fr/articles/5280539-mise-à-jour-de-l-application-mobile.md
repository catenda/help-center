# Mise à jour de l'application mobile

Mise à jour de l'application mobile

Une nouvelle version de notre application mobile est disponible dans les app stores. La version 1.6.0 inclut de nouvelles fonctionnalités et améliorations pour simplifier les workflows utilisant l'application :

- Consultez tous vos Documents dans l'application, y compris les documents Office, les PDF et les vidéos.

![Formats de fichiers affichés dans l'application.png](https://raw.githubusercontent.com/catenda/help-center/main/images/77rs07rg/01-intro.png)

- Fonctionnalités avancées de visualisation 2D. Combinez plusieurs étages et offrez une meilleure expérience de marqueurs et de navigation 2D.

![Étages combinés.png](https://raw.githubusercontent.com/catenda/help-center/main/images/77rs07rg/02-intro.png)

- Création de problèmes simplifiée. Ajoutez de nombreuses photos, depuis votre appareil photo ou galerie en une seule étape.

![Choisir des images de la galerie.png](https://raw.githubusercontent.com/catenda/help-center/main/images/77rs07rg/03-intro.png)

- Créez des problèmes à partir de la Visionneuse 3D en incluant un viewpoint 3D de la vue actuelle.

![IMG_4509.PNG](https://raw.githubusercontent.com/catenda/help-center/main/images/77rs07rg/04-intro.png)

- Amélioration des performances dans les Visionneuses 2D et 3D.

En plus, vous trouverez également d'autres nouvelles fonctionnalités intéressantes :

- Affichage du marqueur de nom de model dans l'écran de problème

![Nom du modèle sur les marqueurs.png](https://raw.githubusercontent.com/catenda/help-center/main/images/77rs07rg/05-intro.png)

- Basculer entre les noms d'espaces réguliers ou longs dans la Visionneuse 2D

![Noms d'espaces longs et courts.png](https://raw.githubusercontent.com/catenda/help-center/main/images/77rs07rg/06-intro.png)

- Affichage des types (Ifc) dans le panneau de sélection de la Visionneuse 3D
- Une nouvelle option pour trier vos projets par ordre alphabétique
- Plus d'informations dans l'écran d'onboarding
- Un meilleur affichage de la barre de Statut sur les appareils Android récents (identique à iOS)
