# Page Utilisateurs - Outil d'organisation

Vous pourrez trouver la page utilisateurs en tant que sous-page de votre [page de profil d'organisation](https://support.catenda.com/en/articles/8497478-organization-profile-page). _Accès requis :_ Propriétaire d'organisation

Ici, vous verrez un aperçu de tous les utilisateurs qui font partie de cette organisation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/01-intro.png)

La page utilisateurs peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/02-intro.png)

Les rubriques suivantes sont décrites dans cet article :

## 1. **Types d'utilisateurs**

Il existe deux types d'utilisateurs d'organisation.

### 1.1 **Propriétaire d'organisation**

Les propriétaires sont des personnes qui organisent l'organisation. Le groupe de propriétaires doit rester restreint, souvent un ou deux propriétaires, car il peut y avoir un coût lié au nombre de projets actifs dans l'organisation.

Les propriétaires d'organisation auront accès aux éléments suivants :

- L'outil d'organisation
- Créer des projets tant que votre plan le permet.
- Déplacer les projets vers d'autres organisations qu'ils possèdent.
  Cela libérera une place permettant la création de nouveaux projets.

> **Remarque :** Les propriétaires d'organisation sont configurés par Catenda. Si vous souhaitez ajouter ou supprimer un propriétaire d'organisation, veuillez demander à votre personne de contact de nous contacter et nous serons heureux de vous aider.

### 1.2 **Membre d'organisation**

Les Membres sont des comptes de personnes que les propriétaires déplacent souvent dans et hors des projets de cette organisation. Pour ajouter un Membre, utilisez le bouton ajouter à partir du domaine en haut à droite de cette page. Les propriétaires d'organisation pourront faire ce qui suit avec les Membres d'organisation :

- Ajouter un Membre d'organisation à un projet sans invitation par courrier électronique

## 2. **Boutons supérieurs**

### 2.1 **Ajouter à partir du domaine**

Si vous avez enregistré votre domaine auprès de Catenda, vous pourrez voir ce bouton.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/03-add-from-domain.png)

Vous pouvez demander l'enregistrement de votre domaine en contactant l'assistance via le bouton de chat noir à côté de votre photo de profil en haut à droite ou en envoyant un courrier électronique à [support@catenda.com](mailto:support@catenda.com). Cliquer sur ce bouton ouvrira la boîte de dialogue ajouter à partir du domaine

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/04-add-from-domain.png)

Dans l'exemple ci-dessus, le domaine test.com a été enregistré. Dans la liste des utilisateurs à choisir, vous verrez tous les utilisateurs de Catenda qui ont créé un compte auprès de Catenda sous le nom de domaine enregistré. Si vous espérez ajouter quelqu'un qui n'a pas encore de compte Catenda, vous devrez attendre qu'il ait créé son compte avant de pouvoir l'ajouter.

## 3. **Recherche et Filtres**

### 3.1 **Masquer les Filtres vides**

Le bouton bascule "Masquer les Filtres vides" est désactivé par défaut, ce qui signifie que vous voyez tous les Filtres possibles. Vous pouvez activer ce bouton de Filtre pour masquer tous les Filtres qui n'ont pas de résultats.

### 3.2 **Rôle -** `role=owner,member`

_Propriétaire_ - Le(s) propriétaire(s) de l'organisation _Membre_ - Membres d'organisation

## 4. **Boutons d'action**

Après avoir sélectionné un ou plusieurs utilisateur(s) dans la liste des utilisateurs en cliquant sur leur case à cocher, vous verrez les boutons d'action suivants apparaître vers le haut de la liste des projets.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/05-action-buttons.png)

Les rubriques suivantes sont décrites dans cette section :

### 4.1 **Ajouter aux projets**

Ajoutez vos utilisateurs sélectionnés à un ou plusieurs projets. Après avoir cliqué sur ajouter aux projets, la boîte de dialogue ajouter ou inviter des Membres aux projets s'ouvrira. Cette boîte de dialogue peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/2q7t2036/06-add-to-projects.png)

**Sélectionner les projets** Sélectionnez les projets auxquels vous souhaitez ajouter l'utilisateur

**Sélectionner le rôle du projet** Sélectionnez le rôle qu'il aura dans ces projets

**Sélectionner les utilisateurs** Ajoutez ou supprimez des utilisateurs avant de les ajouter aux projets sélectionnés sans avoir à les inviter par courrier électronique. Seuls les utilisateurs qui sont Membres de l'organisation peuvent être ajoutés de cette façon. Les autres utilisateurs devront être invités par courrier électronique.

**Inviter par courrier électronique** Invitez les utilisateurs par courrier électronique sans avoir à faire partie du projet. Ces utilisateurs devront cliquer sur le Lien d'invitation dans le courrier électronique qui leur est envoyé, comme s'ils étaient invités via la page d'invitation du projet par un administrateur du projet.

### 4.2 **Supprimer un Membre**

Supprimez les Membres sélectionnés de l'organisation

## 5. **Liste des utilisateurs**

Ici, vous verrez une liste des utilisateurs qui font partie de votre organisation.

> **Remarque :** il ne s'agit pas de tous les utilisateurs qui font partie des projets appartenant à votre organisation. Les utilisateurs qui font partie des projets se trouvent sur la [page d'adhésion aux projets](https://support.catenda.com/en/articles/9003642-members-page-in-organization-tool).

### 5.1 **Case à cocher**

Sélectionnez les utilisateurs de l'organisation

### 5.2 **Membre**

La photo de profil, le nom d'utilisateur et l'adresse électronique de l'utilisateur. Ils peuvent être soit un Membre régulier, soit un Propriétaire. Les Propriétaires auront accès à l'outil d'organisation. Ils pourront ajouter des Membres d'organisation aux projets sans les inviter.
