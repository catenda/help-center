# Comment rendre les autres modèles semi-transparents?

1. Ouvrir tous les models dans la visionneuse 3D
2. Ouvrir le panneau d'arborescence (le raccourci est maj-3).
3. Sélectionner le model que vous souhaitez consulter (« isoler »), puis cliquer sur le nœud supérieur de cette liste. Cela sélectionne tous les éléments de ce model.
4. Cliquer avec le bouton droit de la souris sur le nœud supérieur et sélectionner « Isoler ». Tous les objets de ce model s'affichent désormais complètement, tandis que tous les objets des autres models s'affichent en semi-transparent.
