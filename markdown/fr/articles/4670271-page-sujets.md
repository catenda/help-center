# Page Sujets

Vous pourrez trouver la page Sujets comme troisième page dans le menu de navigation de gauche dans un projet. Cette page fait partie du panneau de contenu. La fenêtre Sujets vous donnera un aperçu rapide et mis à jour de la progression du projet, concernant les Sujets nouveaux/mis à jour et ouverts/fermés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/01-intro.png)

## 1. **Fil d'Ariane - Menu déroulant des listes de sujets**

Si vous cliquez sur le nom de la liste de sujets en haut à gauche, vous obtiendrez une liste déroulante de toutes les listes de sujets du projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/02-breadcrumbs-topic-boards-dropdown.png)

### 1.1 **Toutes les listes de sujets**

S'il y a plus d'une liste de sujets dans le projet, vous verrez l'option Toutes les listes de sujets en bas de la liste déroulante. Ici, les Sujets de toutes les listes seront combinés. Cela peut être utile pour trouver un Sujet dont vous n'êtes pas sûr de la liste de sujets dans laquelle il a été créé.

> **Note 1 :** Il est uniquement possible de rechercher les éléments suivants dans la liste de sujets "Toutes les listes de sujets". Mes Sujets, Méta-statut, Échéance, Mis à jour, Assigné à, Demandeur, Créateur, Jalon, Champs personnalisés, Étiquettes, Liens **Note 2 :** Il est uniquement possible d'échanger les Sujets d'une liste de sujets à la fois.

## 2. **Nouvelles actions d'élément**

Les nouvelles actions d'élément se trouvent dans le menu hamburger à côté du bouton plus en haut à droite de la page. Voir [ici](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board) pour savoir ce que font les différentes actions.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/03-new-item-actions.png)

## 3. **Champs non liés**

S'il y a des statuts/types non liés dans une liste de sujets, vous verrez un message d'avertissement orange indiquant qu'il y a des champs non liés dans la liste de sujets. _Accès requis :_ Administrateur du projet

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/04-unlinked-fields.png)

En cliquant sur le lien, vous serez dirigé vers la zone [champs non liés](https://support.catenda.com/en/articles/4670277-topic-board-settings#h_3bd7e3e759) des [paramètres de la liste de sujets](https://support.catenda.com/en/articles/4670277-topic-board-settings) où vous pouvez lier tous les champs d'un type à une valeur existante en une seule fois.

## 4. **Recherche, filtre et menu de droite**

Voici ce que peut ressembler la barre de recherche ou de filtre :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/05-search-filter-and-right-menu.png)

Un statut peut être ouvert, fermé ou candidat, bien qu'ils puissent être nommés autrement. Par défaut, tous les Sujets avec un méta-statut ouvert sont filtrés.

### 4.1 **Recherche**

Si tous les statuts ouverts, fermés ou candidats sont affichés, ils seront combinés dans une seule boîte de filtre. Cliquez sur le menu déroulant à côté de la boîte de filtre combinée pour voir quels statuts sont combinés. Appuyez sur le x à droite pour supprimer tous les filtres. Cliquez [ici](https://support.catenda.com/en/articles/8370693-filtering-in-an-issue-board) pour en savoir plus sur la recherche de Sujets.

### 4.2 **Menu Filtre**

Si vous cliquez sur le bouton filtre Sujets à gauche de la barre de recherche ou de filtre dans une liste de sujets :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/06-filter-menu.png)

Un menu filtre s'ouvrira sur la gauche. Ici, vous pouvez spécifier les filtres que vous souhaitez utiliser pour affiner votre recherche. Cliquez [ici](https://support.catenda.com/en/articles/8370693-filtering-in-an-issue-board) pour en savoir plus sur le filtrage des Sujets.

### 4.3 **Menu de droite**

Dans le [menu de droite de la liste de sujets](https://support.catenda.com/en/articles/6941224-right-panel-in-an-issue-board), vous pouvez voir les informations sur les Sujets sélectionnés et modifier plusieurs Sujets à la fois.

## 5. **Liste de sujets**

Par défaut, les Sujets ouverts récemment mis à jour sont affichés.

### 5.1 **Actions d'élément sélectionné**

Après la sélection d'un Sujet, les actions d'élément sélectionné apparaissent vers le haut du tableau.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/07-selected-item-actions.png)

Cliquez [ici](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board) pour voir comment chaque action peut être utilisée :

### 5.2 **Colonnes**

Certaines colonnes du tableau des Sujets sont activées par défaut tandis que d'autres peuvent être masquées et doivent être activées. En fonction de l'ordre des colonnes configuré, les premières colonnes sont affichées tandis que le tableau peut avoir besoin d'être défilé latéralement pour afficher d'autres colonnes activées. L'ordre par défaut et le paramètre de visibilité des colonnes de la page Sujets sont les suivants :

- Case à cocher - Par défaut
- Index - Par défaut
- Titre - Par défaut
- Assigné à - Par défaut
- Statut - Par défaut
- Liste de sujets - Par défaut
- Échéance - Par défaut
- Demandé par - Par défaut
- Étiquettes - Par défaut
- Type - Par défaut
- Créé par - Par défaut
- Créé - Par défaut
- Jalon - Par défaut
- Mis à jour - Par défaut
- Nombre de commentaires
- Nombre de documents
- Champs personnalisés - Par défaut

Cliquez [ici](https://support.catenda.com/en/articles/6941099-columns-on-the-topics-page) pour en savoir plus sur les colonnes disponibles sur la page Sujets.

### 5.3 **Vue liste - Par défaut**

Une vue qui affiche les Sujets avec un aperçu des images dans les commentaires.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/08-list-view-default.png)

Voici ce que la liste de sujets ressemble en vue liste.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/09-list-view-default.png)

Cliquez [ici](https://support.catenda.com/en/articles/6941232-list-view-in-an-issue-board) pour en savoir plus sur la vue liste dans une liste de sujets. Cliquez [ici](https://support.catenda.com/en/articles/11748020-tables-on-catenda) pour lire les informations générales sur les listes sur Catenda.

### 5.4 **Vue tableau**

Un tableau de Sujets affichant uniquement les informations les plus nécessaires.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/10-table-view.png)

Voici ce que la liste de sujets ressemble en vue tableau.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/tk5dvyr2/11-table-view.png)

Ici, vous pouvez voir de nombreux Sujets à la fois. En cliquant sur toute information dans la fenêtre Sujets, vous serez dirigé vers une sous-page avec l'ensemble des informations. Cliquez [ici](https://support.catenda.com/en/articles/11748020-tables-on-catenda) pour lire les informations générales sur les tableaux sur Catenda.
