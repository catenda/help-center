# Créer un nouveau signet

De nouveaux signets peuvent être créés en cliquant sur Nouveau signet dans les [boutons du haut](https://support.catenda.com/en/articles/4670281-bookmarks-page#h_e85b08bb62) de la [page des signets](https://support.catenda.com/en/articles/4670281-bookmarks-page) ou sur la page d'un signet spécifique.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/01-intro.png)

## 1. Nouveau signet

Ouvrez la visionneuse 3D à partir du menu de navigation. Appuyez sur le bouton [nouveau signet](https://support.catenda.com/en/articles/4670281-bookmarks-page#h_e85b08bb62) en haut à droite de la [page des signets](https://support.catenda.com/en/articles/4670281-bookmarks-page). Naviguez dans le modèle jusqu'à obtenir la vue d'écran que vous souhaitez capturer dans un signet, puis cliquez sur Prendre une capture lorsque vous êtes prêt.

> **Remarque :** Bien qu'il ne soit pas possible de créer un signet avec une requête, il est possible de faire une capture dans un problème avec une requête.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/02-new-bookmark.png)

## 2. Ajouter une description (optionnel)

Si vous le souhaitez, vous pouvez ajouter une description du signet qui est optionnelle, puis vous choisissez si le signet doit être privé ou visible pour tous les membres du projet. Appuyez ensuite sur le bouton Créer, et le signet est créé.

## 3. Partage

Vous pouvez choisir de partager ou non votre "**signet privé / partager avec le projet"**

## 4. Modèles et révisions

Vous avez deux options : soit "**suivre toujours la dernière révision**" de vos modèles sélectionnés, soit verrouiller de manière permanente le signet à ces révisions actuelles "**Verrouiller aux révisions d'origine".**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/ba5nvq9c/03-models-and-revisions.png)

> **Remarque :** Pour finaliser, n'oubliez pas de cliquer sur le bouton Créer.
