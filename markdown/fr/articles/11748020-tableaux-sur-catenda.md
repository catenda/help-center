# Tableaux sur Catenda

Sur les pages où plusieurs éléments sont affichés, les informations sont souvent présentées sous forme de tableaux. Différentes façons de travailler avec les tableaux, qui sont souvent similaires dans les différents tableaux, sont décrites dans cet article. Dans l'exemple ci-dessous, le tableau de la page des Membres est affiché comme exemple de ce qu'un tableau sur Catenda peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/01-intro.png)

## 2. Aperçu de la sélection

Vers le haut à gauche d'un tableau, une case à cocher est affichée. À droite de la case à cocher, un aperçu du nombre actuel de lignes sélectionnées et du nombre total de lignes au niveau actuel du tableau est affiché.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/02-selection-overview.png)

### 2.1 Sélectionner tout

Dans certains tableaux, lorsqu'il y a de nombreuses lignes, toutes les lignes peuvent être sélectionnées à la fois. Dans d'autres tableaux, seules les lignes actuellement chargées peuvent être sélectionnées. Cliquez sur la case à cocher pour sélectionner toutes les lignes du tableau. Si le menu de droite était précédemment ouvert, il s'ouvrira à nouveau lorsqu'une ligne sera sélectionnée.

### 2.2 Chargement de plus de lignes en défilant

Dans certains tableaux, seules les lignes actuellement chargées seront sélectionnées. En général, 100 lignes seront chargées à la fois. Le défilement au-delà de 100 lignes entraîne le chargement de plus de lignes et permet donc de sélectionner plus de lignes à la fois.

### 2.3 Actions d'éléments sélectionnés

Après avoir sélectionné ou ouvert le contenu d'une ligne du tableau, un menu d'actions d'éléments sélectionnés peut apparaître dans l'aperçu de la sélection. Voici à quoi peut ressembler le menu d'actions d'éléments sélectionnés dans le tableau des Documents :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/03-selected-item-actions.png)

Le menu d'action d'élément sélectionné peut inclure différentes actions en fonction du contenu de la ligne et de l'accès de l'utilisateur sélectionnant. Les actions possibles pour chaque tableau peuvent être trouvées ici :

- [Actions d'élément sélectionné du sujet](https://support.catenda.com/en/articles/4670284-topic-board-actions#h_b5c00c149b)
- [Actions d'élément sélectionné de la page Modèles](https://support.catenda.com/en/articles/9431936-models-page-actions#h_9c268c45ed)
- [Actions d'élément sélectionné de la page Documents](https://support.catenda.com/en/articles/4670288-document-structure-actions#h_fb4e9ef375)

### 2.4 Désélectionner tout

Après avoir sélectionné une case à cocher d'aperçu de sélection de ligne, elle sera activée avec un moins. Voici un exemple de ce que cela peut ressembler dans le tableau des Documents :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/04-deselecting-all.png)

Cliquez sur le moins pour désélectionner toutes les lignes sélectionnées.

### 3.1 Exporter

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/06-export.png)

Les tableaux peuvent être exportés en cliquant sur le bouton d'export.

### 3.2 Affichage

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/07-view.png)

_Vue liste -_ Par défaut

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/08-view.png)

Dans la vue liste, les informations sur les éléments sont disposées vers le haut/bas/gauche/droite d'une boîte plus grande.

**Vue tableau**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/09-view.png)

Dans la vue tableau, les informations sur les éléments sont disposées en lignes et colonnes.

### 3.3 Hauteur de ligne

Les boutons de hauteur de ligne modifient la hauteur de chaque ligne du tableau.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/10-row-height.png)

**Vue par défaut** Une hauteur de ligne qui fonctionne bien pour la plupart des écrans est affichée.

**Vue compacte** L'espace blanc au-dessus et au-dessous des éléments d'une ligne est supprimé, réduisant la hauteur de la ligne.

Pour les petits écrans ou les écrans avec une résolution faible, seul un petit nombre de lignes peut être affiché avec la hauteur de ligne par défaut. Dans cette situation, la vue compacte est la meilleure option à choisir.

### 3.4 Menu déroulant des colonnes

En haut à droite d'un tableau, le menu déroulant des colonnes peut être vu. Voici à quoi peut ressembler le bouton du menu déroulant des colonnes :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/11-column-dropdown.png)

Avec le menu déroulant des colonnes, les colonnes d'un tableau peuvent être réorganisées, activées et désactivées. Voici à quoi peut ressembler le menu déroulant des colonnes :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/12-column-dropdown.png)

Vers le haut du menu déroulant des colonnes, des options qui affectent toutes les colonnes peuvent être affichées. Voici un exemple de ce que le haut du menu déroulant des colonnes peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/13-column-dropdown.png)

**Apparence du basculement** Lorsque le basculement est activé, toutes les colonnes sont affichées. Lorsque le basculement est à mi-chemin, certaines colonnes sont affichées. Lorsque le basculement est désactivé, aucune colonne n'est affichée. Lorsqu'un basculement a une teinte plus claire, il ne peut être activé ou désactivé que lorsque tout est activé ou désactivé.

**Filtre** Tapez dans la barre de filtre pour filtrer une colonne spécifique.

**Réinitialiser les paramètres** Cliquez sur le bouton de réinitialisation des paramètres pour réinitialiser les colonnes à leur configuration par défaut.

**Développer/réduire le type de colonne** Développez ou réduisez un type de colonne avec le bouton fléché à gauche pour afficher ou masquer toutes les colonnes de ce type.

**Ancre de glissement** Les colonnes qui peuvent être réorganisées peuvent afficher une icône de grille vers la droite du nom de la colonne.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/14-column-dropdown.png)

Le curseur peut devenir une main lorsque l'ancre de glissement est survolée. Après avoir saisi la grille, une ancre de glissement apparaît sous le curseur et la colonne tenue peut apparaître dans une teinte plus claire.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/15-column-dropdown.png)

Lorsque l'ancre de glissement est glissée vers une autre colonne, la colonne tenue apparaîtra après la colonne vers laquelle elle est glissée. Relâchez ou cliquez sur l'ancre de glissement pour verrouiller la colonne tenue en place et réorganiser la liste des colonnes.

Cliquez sur le bouton des paramètres du tableau pour activer ou désactiver les paramètres du tableau

## 4. Lignes

Dans un tableau, les éléments sont affichés dans des lignes qui peuvent se comporter de différentes manières.

## 5. Lignes - Ligne d'en-tête

La ligne d'en-tête est la première ligne du tableau.

### 5.1 Interaction de la ligne d'en-tête

Survoler différentes parties de la ligne d'en-tête peut indiquer comment elle peut être manipulée.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/17-header-row-interaction.png)

### 5.2 Tri

Si une colonne peut être triée, une flèche vers le haut/bas peut être visible à droite du nom de la colonne

**Changement de curseur** Le curseur sera un pointeur.

**Flèches de tri** Les flèches de tri peuvent indiquer quelle colonne est actuellement triée. Les flèches de tri peuvent montrer dans quelle direction les lignes sont triées.

**Cliquer pour trier** Cliquez sur la cellule d'en-tête d'une colonne triable pour trier les lignes du tableau selon la colonne que cette cellule d'en-tête occupe. Après avoir trié par une colonne, les lignes du tableau seront réorganisées selon les [règles de tri typiques autour de Catenda](https://support.catenda.com/en/articles/8487788-sorting-order-of-lists). Cliquez à nouveau sur la cellule d'en-tête de la colonne triée pour la trier dans le sens inverse. Le tri d'une colonne met à jour les préférences de tri pour le tableau.

> **Note :** Les tableaux ne peuvent être triés que par une seule colonne à la fois

### 5.3 Ajustement de la largeur

Les ancres d'ajustement de la largeur ressemblent à une ligne épaisse environ la moitié de la hauteur de la ligne d'en-tête.

**Changement de curseur** Survoler l'ancre d'ajustement transforme le curseur en flèche gauche-droite, connue sous le nom de pointeur de redimensionnement.

**Glisser pour ajuster** Glissez sur l'ancre d'ajustement de la largeur dans la ligne d'en-tête pour modifier la largeur de la colonne.

**Double-cliquer pour ajustement automatique** Double-cliquez sur l'ancre d'ajustement pour ajuster automatiquement la colonne à gauche de l'ancre en fonction du contenu de cette colonne. Lorsque le contenu d'une colonne est si long qu'il est coupé, mais que l'information nécessaire se trouve à la fin du contenu, le redimensionnement de la colonne peut être utile.

### 5.4 Ajustement de l'ordre des colonnes

Glissez sur la cellule d'en-tête d'une colonne pour réorganiser l'ordre des colonnes. Glissez la cellule d'en-tête d'une colonne en dehors du tableau pour masquer cette colonne. Pour récupérer la colonne, vous devrez l'activer à nouveau dans le menu déroulant des colonnes.

## 6. Lignes - Informations de ligne mise à jour

Lorsque les informations d'une ligne sont mises à jour en dehors de l'onglet du navigateur actuel, une barre d'informations s'affiche vers le bas du tableau.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/18-rows-updated-row-information.png)

Cliquez sur Récupérer les mises à jour pour mettre à jour les lignes de votre tableau avec les nouvelles informations. Lorsque Récupérer les mises à jour est cliqué, les nouvelles lignes glissent vers l'intérieur et les lignes supprimées glissent vers l'extérieur. Les cellules des informations existantes qui changent peu de temps après clignotent avec un arrière-plan vert.

## 7. Lignes - Ligne inférieure

Les colonnes avec des valeurs numériques peuvent être additionnées dans la ligne inférieure du tableau.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/19-rows-bottom-row.png)

Les exemples de colonnes qui peuvent être additionnées sont les colonnes de champs personnalisés et les colonnes de propriétés d'objets.

## 8. Déplacement par glisser-déposer

Pour modifier l'emplacement d'une colonne ou d'une ligne, relâchez l'ancre de glisser au nouvel emplacement.

### 8.1 Modification de la configuration des colonnes par glisser-déposer

Cliquez et glissez sur la cellule d'en-tête d'une colonne pour commencer à modifier la configuration de la colonne. Après avoir saisi la colonne, une ancre de glisser apparaît sous le curseur. L'ancre de glisser peut contenir le nom de la colonne et une icône d'œil qui indique si la colonne sera activée ou désactivée lorsque l'ancre est relâchée.

**Ancre de glisser pour réorganiser une colonne** Lorsque l'ancre de glisser est glissée sur la bordure d'une colonne ou en dehors du tableau, la colonne en cours de glissement sera supprimée de son emplacement actuel. Lorsque l'ancre de glisser est survolée à un autre endroit du tableau, la colonne y sera prévisualisée. Relâchez l'ancre de glisser à l'emplacement souhaité pour insérer la colonne maintenue à cet emplacement.

**Ancre de glisser pour supprimer une colonne** Lorsque l'ancre de glisser est glissée en dehors du tableau, l'icône de visibilité se transforme en œil barré et la colonne est désactivée dans le tableau. Relâchez ou cliquez pour désactiver la colonne maintenue.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/20-change-column-configuration-by-dragging.png)

### 8.2 Déplacer des lignes par glisser-déposer

Lorsque la cellule de ligne dans la colonne de titre (souvent appelée nom) est survolée, une grille de points peut apparaître à droite du titre.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/21-move-rows-by-dragging.png)

Passez la souris sur la grille et vous verrez que le curseur se transforme en main, indiquant que la ligne peut être saisie. Après avoir saisi la grille, une ancre de glisser apparaît sous le curseur. L'ancre de glisser peut contenir les titres de la ou des lignes qui ont été sélectionnées lorsque la ligne a été saisie.

**Ancre de glisser pour déplacer une ligne** Pendant que la ou les lignes sont glissées à l'intérieur du tableau, elles seront mises en surbrillance et données une teinte plus claire indiquant que quelque chose peut se produire dans le tableau.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/22-move-rows-by-dragging.png)

Les lignes interactives sont mises en surbrillance avec un arrière-plan différent lorsque l'ancre de glisser est glissée sur la ligne interactable.

### 8.3 Relâcher l'ancre de glisser

Lorsque l'ancre de glisser est relâchée au-dessus d'une ligne interactable, la boîte de dialogue de déplacement peut s'ouvrir. Même si l'icône de grille d'une ligne a été glissée, c'est comme si l'action de déplacement était utilisée pour les lignes sélectionnées dans le tableau. Lorsque l'ancre de glisser est glissée sur une ligne non-interactable ou en dehors du tableau et relâchée, aucun changement ne se produira dans le tableau.

## 9. Interaction avec des lignes en survolant

Survoler différentes parties du tableau peut indiquer comment elle peut être manipulée. Les lignes qui ne sont pas survolées peuvent avoir un arrière-plan blanc.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/23-interacting-with-rows-by-hovering.png)

### 9.1 Survol de la ligne

Survoler n'importe où dans une ligne peut mettre en surbrillance cette ligne avec un arrière-plan différent.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/24-row-hover.png)

### 9.2 Survol de la boîte

Lorsqu'une boîte cliquable dans une ligne est survolée, le curseur peut changer en pointeur et la boîte peut obtenir un contour plus foncé et une ombre autour d'elle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/25-box-hover.png)

### 9.3 Survol du texte

Lorsque du texte cliquable dans une ligne est survolé, le curseur peut changer en pointeur. Le texte peut être souligné lors du survol et certains navigateurs peuvent afficher l'URL de la page qui s'ouvrira vers le bas à gauche.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/26-text-hover.png)

## 10. Interaction avec des lignes en cliquant

Différents comportements peuvent se produire lors du clic sur le contenu d'une ligne.

### 10.1 Sélection d'une ligne

Si le menu de droite a été ouvert précédemment, il s'ouvrira à nouveau lorsqu'une ligne est sélectionnée.

**Espace blanc** Cliquez une fois sur n'importe quel espace blanc dans la ligne pour la sélectionner. Si le menu de droite a été ouvert précédemment, il s'ouvrira à nouveau lorsqu'une ligne est sélectionnée. Cliquez deux fois rapidement pour ouvrir le contenu de la ligne. Cliquez à nouveau sur la ligne après un certain temps pour la désélectionner.

**Case à cocher** Sélectionnez la case à cocher dans la colonne de case à cocher pour sélectionner la ligne. Avec la case à cocher, la ligne peut être sélectionnée sans avoir à vous soucier de l'ouverture accidentelle du contenu de cette ligne.

**Sélection d'une plage de lignes** Maintenez `shift` et cliquez pour sélectionner toutes les lignes entre la ligne actuelle et la ligne sélectionnée la plus proche.

**Édition de la sélection des lignes** Maintenez `control` et cliquez pour modifier des éléments uniques dans la sélection

### 10.2 Ouverture du contenu de la ligne

Le texte dans les lignes avec du contenu qui peut être prévisualisé peut être cliqué pour ouvrir l'aperçu du contenu de la ligne dans une nouvelle page.

**Icônes de ligne d'ouverture** Les icônes dans les lignes avec du contenu qui peut être prévisualisé peuvent être cliquées pour soit ouvrir un aperçu du contenu de la ligne dans une nouvelle page ou dans une boîte de dialogue contextuelle. Cliquer sur des icônes dans les lignes sans contenu qui peut être prévisualisé sélectionnera la ligne à la place.

### 10.3 Boîtes dans les lignes

Il peut y avoir plusieurs types de boîtes dans une ligne. Chaque boîte peut avoir sa propre icône ou couleur.

**Boîte d'étiquette** Les boîtes d'étiquettes ont une icône d'étiquette dans la couleur de cette étiquette. Lorsqu'une boîte d'étiquette est cliquée, elle peut être ajoutée au filtre actuel. Voici ce que peut ressembler une boîte d'étiquette :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/27-boxes-in-rows.png)

**Boîte de statut ou de type** Les boîtes de statut et de type ont un cercle avec la couleur du statut ou du type. Lorsqu'une boîte de statut est cliquée, elle peut être ajoutée au filtre actuel. Voici ce que peut ressembler une boîte de statut ou de type :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/28-boxes-in-rows.png)

**Boîte d'équipe** Les boîtes d'équipe sont colorées en vert pour les équipes de membres et en orange pour les équipes d'administrateur. Voici ce que peut ressembler une boîte d'équipe :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/29-boxes-in-rows.png)

**Boîte Afficher plus** S'il y a plus de boîtes que ce qui peut tenir dans la largeur de la colonne d'une cellule de ligne, une boîte avec trois points s'affiche :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/30-boxes-in-rows.png)

Cliquez sur cette boîte pour voir les boîtes restantes dans la cellule de ligne pour cette colonne.

**Boîte Visionneuse** Les boîtes 2D, 3D et zoom sur l'étendue peuvent être affichées. Cliquez sur la boîte 2D pour charger le contenu de la ligne dans la visionneuse 2D. Cliquez sur la boîte 3D pour charger le contenu de la ligne dans la visionneuse 3D. Après avoir chargé le contenu de la ligne dans la visionneuse 3D, le bouton zoom sur l'étendue devient disponible et peut être cliqué pour positionner la caméra dans la visionneuse 3D afin que tout le contenu de la ligne soit en vue. Voici ce que les boîtes de visionneuse peuvent ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/31-boxes-in-rows.png)

**Boîte d'objet** La quantité d'objets liés à la ligne est affichée. Voici ce que peut ressembler une boîte d'objet :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/32-boxes-in-rows.png)

Lorsqu'une boîte d'objet est cliquée, le menu contextuel suivant peut s'ouvrir.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/jm0gvfww/33-boxes-in-rows.png)

Sélectionner les objets Le panneau 3D s'ouvrira et le ou les modèles auxquels les objets appartiennent seront chargés dans la visionneuse 3D en plus de tous les modèles qui étaient précédemment ouverts. Après le chargement des modèles, la sélection actuelle sera effacée. Les objets liés à la ligne seront ensuite sélectionnés.

Isoler les objets Le panneau 3D s'ouvrira et le ou les modèles auxquels les objets appartiennent seront chargés dans la visionneuse 3D en plus de tous les modèles qui étaient précédemment ouverts. Après le chargement des modèles, la sélection actuelle sera effacée. Les objets liés à la ligne seront ensuite isolés.

Charger comme requête Le panneau 3D s'ouvrira. Tous les modèles qui étaient précédemment chargés en 3D seront complètement effacés (non masqués) de la visionneuse 3D. Seuls les objets liés à la ligne (qui peuvent appartenir à plusieurs modèles) seront ensuite chargés dans la visionneuse 3D.
