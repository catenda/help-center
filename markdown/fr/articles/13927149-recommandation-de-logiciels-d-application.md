# Recommandation de logiciels d'application

Veuillez vérifier que vous n'avez aucune extension de navigateur ou autre programme pouvant ralentir votre expérience Catenda Hub.

## 1. **Paramètres du navigateur**

**Meilleur navigateur par utilisation de la mémoire sur Windows (mars 2026) :**

1. Firefox
2. Chrome
3. Microsoft Edge

### 1.1 **Échelle de zoom**

Il est recommandé d'utiliser Catenda à 100 % d'échelle de zoom. Catenda fonctionne bien avec des échelles de zoom entre 75 % et 150 %

**Grande échelle de zoom** Une grande échelle de zoom peut rendre certains menus si grands qu'ils couvrent les menus nécessaires. Tandis que les graphiques définis par la largeur et la hauteur peuvent être mis à l'échelle avec l'échelle du navigateur, les graphiques définis par des pixels peuvent devenir plus pixelisés lorsque l'échelle de zoom est augmentée. Une échelle de zoom de 125 % ou même 150 % est recommandée lors du partage d'écrans en réunion, car cela peut faciliter le suivi de ce qui est fait pour les personnes qui suivent à l'écran.

**Petite échelle de zoom** Une petite échelle de zoom peut rendre les graphiques si petits qu'ils deviennent invisibles. L'affichage précis des ressources réduites peut être plus exigeant pour l'appareil. Une échelle de zoom de 80 % ou même 75 % est recommandée lors de l'interaction avec la Visionneuse 3D si l'appareil peut le supporter.

### 1.3 **Cookies**

Grâce aux données stockées dans les cookies, votre navigateur peut savoir si vous êtes connecté et certaines de vos préférences dans les projets Catenda. Certaines préférences peuvent différer d'un projet à l'autre, tandis que d'autres seront les mêmes pour tous les projets. Si vous modifiez votre préférence en fermant par exemple un menu, cela sera mémorisé entre les fenêtres et les onglets du navigateur. Si vous fermez par exemple le menu Filtres dans un onglet, puis actualisez cette même page dans un autre onglet, le menu Filtres sera fermé dans cet onglet également. De cette façon, le navigateur se souvient également de si vous étiez connecté ou non. Par exemple, si vous vous déconnectez dans un onglet pour vous connecter à un autre compte, puis actualisez la page d'un autre onglet, vous vous trouverez connecté avec l'autre compte qui pourrait ne pas avoir accès au projet dans lequel vous étiez.

**Recherche de cookies** Sur Chrome, vous pourrez gérer vos cookies comme ci-dessous : Cliquez sur Cookies et données de site

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/01-cookies.png)

Cliquez sur Gérer les données de site stockées sur l'appareil

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/02-cookies.png)

_Autoriser les cookies_ Pour utiliser Catenda Hub, vous devez au moins autoriser le stockage de données pour hub.catenda.com lors de votre session.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/03-cookies.png)

Si vous choisissez de supprimer les données à la fermeture de toutes les fenêtres, vos données seront réinitialisées chaque fois que vous utilisez Catenda. La suppression de vos données à chaque fermeture de toutes les fenêtres entraînera la réinitialisation de vos préférences à chaque fois après la fermeture de toutes les fenêtres de votre navigateur.

_Suppression des cookies_ Les données des cookies peuvent être supprimées manuellement en cliquant sur l'icône de la poubelle.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/1jx7t1xa/04-cookies.png)

Vous serez ensuite invité à recharger la page. Après le rechargement, vous devrez vous reconnecter à Catenda car vous avez supprimé vos informations de connexion.
