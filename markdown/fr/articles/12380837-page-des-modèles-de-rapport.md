# Page des gabarits de rapports

> **Remarque 1 :** La page des rapports est une fonctionnalité optionnelle qui peut être activée pour les projets en cours. **Remarque 2 :** Les nouveaux projets créés à partir d'un projet de gabarit pour lequel cette fonctionnalité est activée n'ont pas cette fonctionnalité activée.

La page des gabarits de rapports se trouve comme sous-page de la [page des rapports](https://support.catenda.com/en/articles/12303098-reports-page) dans le menu de navigation de gauche. Sur la page des gabarits de rapports, les gabarits de documents et de Sujets disponibles pour le projet peuvent être gérés. _Accès requis :_ Administrateur

Voici à quoi la page des gabarits de rapports peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5aw6t2k2/01-intro.png)

## 1. **Actions sur la page des gabarits de rapports**

Les actions de la page des gabarits de rapports se trouvent en cliquant sur le menu d'action en haut à droite de la page des gabarits de rapports. Voici à quoi les actions de la page des gabarits de rapports peuvent ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5aw6t2k2/02-actions-on-the-report-templates-page.png)

### 1.1 **Nouveau gabarit de Sujets**

Utilisez l'action de nouveau gabarit de Sujets pour créer un nouveau gabarit de Sujets

### 1.2 **Nouveau gabarit de Document**

Utilisez l'action de nouveau gabarit de Document pour créer un nouveau gabarit de Document

## 2. **Filtrer par nom**

Écrivez dans la barre de recherche pour filtrer le tableau des gabarits de rapports par les noms des rapports.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5aw6t2k2/03-filter-by-name.png)

Recherche de texte - `search=test`

## 3. **Tableau des gabarits de rapports**

Dès qu'un gabarit de rapport est créé, il s'affiche sous forme de ligne dans le tableau des gabarits de rapports. Voici à quoi le tableau des gabarits de rapports peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5aw6t2k2/04-report-templates-table.png)

Cliquez [ici](https://support.catenda.com/en/articles/11748020-tables-on-catenda) pour en savoir plus sur la façon de travailler avec les tableaux dans Catenda.

### 3.1 **Contenu des lignes**

**Ligne de rapport** Bien qu'il soit possible de cliquer sur une ligne pour la sélectionner et la mettre en surbrillance en vert, aucune action ne peut être effectuée en sélectionnant une ligne. La ligne sera sélectionnée lorsque le menu d'action de ligne dans la colonne de droite est sélectionné.

### 3.2 **Colonnes**

En fonction de l'ordre des colonnes configuré, les premières colonnes s'affichent tandis que le tableau devra peut-être être défilé latéralement pour afficher d'autres colonnes activées. L'ordre par défaut et le paramètre de visibilité des colonnes sur la page des gabarits de rapports sont les suivants :

Nom - _Par défaut_ Le nom du gabarit de rapport

_Créé par_ - _Par défaut_ Le créateur du gabarit de rapport

Créé - _Par défaut_ L'heure et la date de création du gabarit de Sujets

Type - Par défaut Le type de gabarit de rapport, soit Documents soit Sujets.

Menu d'action - Par défaut Cliquez sur le menu d'action dans la colonne du menu d'action pour ouvrir le menu d'action de ligne. Voici à quoi le menu d'action de ligne de gabarit de rapport peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5aw6t2k2/05-columns.png)

Éditer Utilisez l'action d'édition pour modifier le gabarit de rapport sélectionné.

Télécharger Utilisez l'action de téléchargement pour télécharger le gabarit de rapport sélectionné avec le format de fichier `.mrt` qui peut être importé à nouveau dans tout autre projet.

Supprimer Utilisez l'action de suppression pour supprimer le gabarit de rapport sélectionné.
