# Bibliothèque de valeurs de propriété

Avec la nouvelle bibliothèque de valeurs de propriété, vous pouvez faire indexer par Catenda Hub les valeurs d'une propriété donnée dans tous les modèles de votre projet. Par exemple, pour que la bibliothèque présente une liste de tous les LOD (Levels of Detail) ou MMI (Model Maturity Index) avec un lien vers tous les objets associés.

Vous pouvez indexer les valeurs des propriétés dans les property-sets ou quantity-sets, et chacune des valeurs trouvées sera listée avec un lien vers les objets associés.

Avec cette bibliothèque, vous pouvez sélectionner, isoler ou interroger des objets par propriété / paramètre

Vous pouvez voir la fonctionnalité en action dans la vidéo suivante :

[Vidéo YouTube](https://www.youtube.com/embed/_PK6jWcZKkQ?rel=0)

Lorsque la bibliothèque de propriétés est créée, la synchronisation de ses propriétés peut prendre du temps. En effet, toutes les propriétés de tous les objets de toutes les dernières révisions de tous les modèles doivent être vérifiées pour cette propriété.

Si une révision de modèle est ajoutée ultérieurement, la bibliothèque sera resynchronisée. Cette fois, ce sera plus rapide car seule la nouvelle révision de modèle devra être vérifiée.
