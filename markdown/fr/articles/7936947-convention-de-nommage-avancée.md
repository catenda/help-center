# Convention de nommage avancée

Cet article s'appuie sur les articles suivants : [Convention de nommage la plus simple](https://support.catenda.com/en/articles/7845360-simplest-naming-convention) et [Convention de nommage intermédiaire](https://support.catenda.com/en/articles/7936943-medium-naming-convention) Cet article peut être suivi sans avoir lu ces articles, mais il peut être utile de les consulter car il peut y avoir des informations sur les [conventions](https://support.catenda.com/en/articles/7832559-naming-conventions-page) qui ne sont pas mentionnées dans cet article. Dans cet article, vous apprendrez toutes les façons dont les [conventions](https://support.catenda.com/en/articles/7832559-naming-conventions-page) peuvent être utilisées.

## 1. **YYMMDD\_Nom_fichier\_V.pdf**

En mettant en place cette [convention](https://support.catenda.com/en/articles/7832559-naming-conventions-page) vous apprendrez tout ce que vous devez savoir sur les [conventions de nommage](https://support.catenda.com/en/articles/7832559-naming-conventions-page) pour pouvoir choisir les [blocs](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) que vous aimez pour votre propre [convention](https://support.catenda.com/en/articles/7832559-naming-conventions-page). Supposons que vous organisiez localement tous vos modèles 3D et vos dessins de construction.

- Vous avez un tiret _( - )_ dans le nom du fichier, donc pour séparer les différents [blocs](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) vous devrez utiliser un trait de soulignement _( \_ )_ comme [séparateur](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=in%20document%20settings-,Separator,-%3A%20The%20character).
- Ces fichiers commencent par la date de création du fichier.

Cela vous est utile car même si cela est généralement indiqué à différents endroits, c'est simplement plus visuel pour vous d'avoir vos fichiers classés alphabétiquement par date de création.

- Après cela, vous aurez le nom du fichier qui peut être de n'importe quelle longueur.
- À la fin du nom du fichier, vous avez un statut pour indiquer la version du fichier que vous avez.

Cette partie est simplement du texte supplémentaire que vous utilisez pour distinguer vos fichiers localement. Vous ne voulez pas voir cette partie du nom du fichier dans le nom du document Catenda Hub car elle n'est utile que pour vous localement et n'a rien à voir avec les autres personnes du projet.

- Finalement, vous avez décidé de vous assurer que vous ne conservez que des types de fichiers spécifiques dans ce dossier.

Vous limiterez les types de fichiers à IFC, PDF, DWG, SMC, PL et RVT

### 1.1 **Configuration initiale**

Les documents portant les noms de fichiers suivants seront utilisés dans cet article. Vous pouvez les préparer à l'avance ou les créer lorsque vous en arrivez à cette partie de l'article :

_Fichiers locaux :_ 230219\_Elevation\_Draft.PDF 230219\_Elevation\_Final.PDF aaaaaa\_\_Elevation\_Draft.PDF 230219\_Elevation\_Draft.pdf

_Un quatrième [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) pour le statut du fichier_ La date du fichier ressemble un peu au code de l'exemple de l'article [Convention de nommage intermédiaire](https://support.catenda.com/en/articles/7936943-medium-naming-convention). Le [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) contenant le nom du document devrait également être le même que le [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) de nom de fichier dans cet article. Le seul [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) que vous devez ajouter et qui est différent de l'exemple ci-dessus est un [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) pour la partie statut de votre nom de fichier.

**Configuration de la convention** Pour cet exemple, vous utiliserez la [convention de nommage](https://support.catenda.com/en/articles/7832559-naming-conventions-page) affichée dans l'image ci-dessous comme point de départ.

### 1.2 **Champs personnalisés dans les conventions**

Il existe trois types différents de champs personnalisés utiles dans les [conventions](https://support.catenda.com/en/articles/7832559-naming-conventions-page) : [Entier](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=3.%20Click%20on%20%22New%20Custom%20Field%22), [Texte](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=3.%20Click%20on%20%22New%20Custom%20Field%22) et [Liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=If%20you%20add%20a%20%22dropdown%22%20field) Les [champs personnalisés](https://support.catenda.com/en/articles/6550459-custom-fields-setup) peuvent être utilisés comme sources pour les [blocs de convention](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541).

**[Champs personnalisés entiers](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=3.%20Click%20on%20%22New%20Custom%20Field%22) dans les [conventions](https://support.catenda.com/en/articles/7832559-naming-conventions-page)** Dans l'image ci-dessus, la source du premier [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) est définie sur texte. Si vous essayez de télécharger votre premier fichier 230219\_Elevation\_Draft.PDF, vous verrez qu'il se télécharge sans problème. Cependant, vous pourriez également télécharger six lettres au lieu de chiffres, par exemple : aaaaaa\_\_Elevation\_Draft.PDF et ce serait correct aussi. Pour limiter cela à seulement des chiffres, créez un nouveau [champ personnalisé entier](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=3.%20Click%20on%20%22New%20Custom%20Field%22) appelé NC\_Date. Il est nommé ainsi juste pour le maintenir organisé dans la [liste des champs personnalisés](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=the%20list%20of%20custom%20fields). Ensuite, définissez ce [champ personnalisé](https://support.catenda.com/en/articles/6550459-custom-fields-setup) comme [source](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=has%20an%20extension.-,Source,-%3A%20What%20will) du premier [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) en cliquant sur la liste déroulante où il indique actuellement texte et en sélectionnant le [champ personnalisé](https://support.catenda.com/en/articles/6550459-custom-fields-setup) que vous avez créé. Vous verrez maintenant que aaaaaa\_\_Elevation\_Draft.PDF n'est plus accepté tandis que 230219\_Elevation\_Draft.PDF est accepté.

**[Champs personnalisés de texte](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=3.%20Click%20on%20%22New%20Custom%20Field%22) dans les [conventions](https://support.catenda.com/en/articles/7832559-naming-conventions-page)** Pour le deuxième [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541), vous pouvez laisser la source comme texte puisque n'importe quel texte est accepté ici. Il est toujours recommandé d'utiliser un champ personnalisé de texte qui pourrait être nommé NC\_Filename pour la compatibilité future.

Le statut peut également être n'importe quel mot de n'importe quelle longueur, donc créez un [champ personnalisé de texte](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=3.%20Click%20on%20%22New%20Custom%20Field%22) appelé NC\_Status et définissez-le comme [source](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=has%20an%20extension.-,Source,-%3A%20What%20will) pour le troisième [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541).

Pour ces deux blocs, vous ne remarquerez pas de différence dans le processus de téléchargement. Vous pourrez voir que l'[aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) dans différents endroits reflète maintenant le nom du [champ personnalisé](https://support.catenda.com/en/articles/6550459-custom-fields-setup).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/b16sm7xd/02-custom-fields-in-conventions.png)

**[Champs personnalisés de liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=If%20you%20add%20a%20%22dropdown%22%20field) dans les [conventions](https://support.catenda.com/en/articles/7832559-naming-conventions-page)**

**Nom identique au code** Pour le dernier [bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541) qui contient l'[extension](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=The%20name%20of%20the%20file/document%20extension), seul un ensemble spécifique d'expressions doit être accepté. Pour ce faire, créez un [champ personnalisé de liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=If%20you%20add%20a%20%22dropdown%22%20field) appelé NC\_Extension. Dans ce [champ personnalisé](https://support.catenda.com/en/articles/6550459-custom-fields-setup), définissez les [options de liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=add%20multiple%20options) IFC, PDF, DWG, SMC, PL et RVT. Rendez le nom et le code identiques. Attention, ceux-ci doivent être ajoutés un par un car un code doit être spécifié. Essayez maintenant de télécharger 230219\_Elevation\_Draft.pdf et vous verrez qu'il ne sera pas accepté. Cette expression personnalisée est sensible à la casse. Si vous voulez que les extensions minuscules soient également acceptées, vous devez également les ajouter au [champ personnalisé de liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=If%20you%20add%20a%20%22dropdown%22%20field).

**Nom différent et code** Un autre bon exemple de ce que vous pouvez faire avec un [champ personnalisé de liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=If%20you%20add%20a%20%22dropdown%22%20field) est d'avoir un nom et un code différents. Supposons que vous ayez des dessins d'ingénieurs mécaniciens, structurels et électriques, chacun avec leurs respectifs [blocs](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_efc0be7541). Dans Catenda Hub, vous voulez que ces dessins s'appellent simplement Ingénierie. Ce que vous pouvez faire est de créer un [champ personnalisé de liste déroulante](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=If%20you%20add%20a%20%22dropdown%22%20field) avec [plusieurs options](https://support.catenda.com/en/articles/6550459-custom-fields-setup#:~:text=add%20multiple%20options) qui ont le nom Ingénierie et le code du type d'ingénierie que vous vous attendez à trouver dans le nom du fichier. Lorsque vous téléchargez le fichier, vous verrez que même si le nom du fichier contenait mécanique, structural ou électrique, le nom du document dira toujours Ingénierie.

### 1.3 **Identifiant du document**

[Au début de cet article](http://You%20do%20not%20want%20to%20see%20this%20part%20of%20the%20file%20name) il a été mentionné qu'il était important que la partie statut du nom du fichier ne s'affiche pas comme le nom du document Catenda Hub. C'est ce que fait l'[identifiant du document](https://support.catenda.com/en/articles/7832559-naming-conventions-page#:~:text=block%20to%20do-,Document%20identifier,-%3A). Lorsque cette option est désactivée, cette partie du nom du fichier ne sera pas du tout utilisée pour créer le nom du document dans Catenda hub. Essayez de télécharger 230219\_Elevation\_Draft.PDF puis 230219\_Elevation\_Final.PDF Remarquez comment, même si le nom du fichier était différent, le nom du document sera le même. Cela est utile car si le nom du document est le même, la [convention de nommage](https://support.catenda.com/en/articles/7832559-naming-conventions-page) reconnaîtra automatiquement que le deuxième fichier est une révision du premier.
