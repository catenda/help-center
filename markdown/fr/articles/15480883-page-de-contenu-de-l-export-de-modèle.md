# Page de contenu de l'export de modèle

Cliquez sur la carte d'un export dans la liste des exports sur la [page des exports de modèles](https://support.catenda.com/en/articles/4670280-model-export) pour accéder à la page de contenu de cet export. Voici à quoi peut ressembler la page de contenu de l'export de modèle :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3ajw00qp/01-intro.png)

## 1. **Télécharger**

Cliquez sur le bouton de téléchargement en haut à droite de l'export pour commencer à télécharger le fichier zip de l'export. Le zip inclura chacun des modèles listés comme inclus pour cet export ci-dessous.

> **Remarque :** L'ensemble actuel des modèles pour chaque export peut être différent de celui du moment de la création de l'export selon que chacun des modèles existe toujours dans le projet ou si l'une des révisions a été retirée.

## 2. **Informations d'export**

Les informations d'export peuvent inclure les informations suivantes :

**Statut** Le statut de l'export concerne la progression de sa préparation.

**Taille du fichier** Il s'agit de la taille du fichier zip qui sera téléchargé. Notez que la taille du fichier du contenu du zip peut augmenter une fois qu'il est téléchargé et extrait localement.

**Format de fichier** Généralement ZIP

**Créé le** La date et l'heure de création de l'export.

**Créé par** L'utilisateur qui a créé cet export.

**Partage** Seul l'utilisateur a accès aux exports privés tandis que tous les utilisateurs du projet ont accès aux exports partagés avec le projet.

**Commentaire** Le commentaire inclus avec cet export.

## 3. **Révisions incluses dans cet export**

La liste des révisions contient une liste de toutes les révisions de modèles dans l'export. Voici à quoi peut ressembler une carte de révision incluse.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3ajw00qp/02-revisions-included-in-this-export.png)

Cliquez sur la carte de révision incluse pour ouvrir la [page de contenu des révisions incluses](#h_e68c2c044b).

> **Remarque :** Les révisions des modèles qui ont été supprimés ne sont pas affichées dans cette liste.

La ligne de révision incluse peut inclure les informations suivantes :

**Nom du modèle** Le nom du modèle auquel appartient la révision.

**Numéro de révision** La nième révision du modèle

**Boutons 2D, 3D et télécharger** Cliquez sur le bouton 2D pour charger la vue 2D de cette révision dans la visionneuse 2D. Cliquez sur le bouton 3D pour charger la visionneuse 3D de cette révision dans la visionneuse 3D. Cliquez sur le bouton de téléchargement pour télécharger uniquement cette révision.

**Version IFC** La version d'IFC de cette révision.

**Date et heure de création** La date et l'heure de création de la révision.

**Créateur de révision** Le nom de l'utilisateur qui a créé la révision.

### 3.1 **Page de contenu de révision incluse**

Cliquez sur une révision incluse dans la liste des révisions incluses dans un export pour voir la page de contenu de cette révision. Voici à quoi peut ressembler la page de contenu d'une révision incluse :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3ajw00qp/03-included-revision-content-page.png)

La page de contenu de révision incluse peut inclure les informations suivantes :

**Numéro de révision** Le numéro de la révision

**Version IFC** La version d'IFC de cette révision.

**Boutons 2D, 3D, document et télécharger.** Cliquez sur le bouton 2D pour charger la vue 2D de cette révision dans la visionneuse 2D. Cliquez sur le bouton 3D pour charger la visionneuse 3D de cette révision dans la visionneuse 3D. Cliquez sur le bouton de document pour ouvrir le document lié à cette révision de modèle dans la structure de dossiers de la page Documents. Cliquez sur le bouton de téléchargement pour télécharger uniquement cette révision.

**Créé le** La date et l'heure de création de cette révision.

**Créé par** L'utilisateur qui a créé cette révision.

**Modèle** Le modèle dans lequel se trouve cette révision.

**Commentaire** Le commentaire qui accompagne cette révision.
