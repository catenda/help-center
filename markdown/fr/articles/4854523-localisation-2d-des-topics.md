# Localisation 2D des topics

> Description des marqueurs de localisation 2D sur les topics

Une localisation peut être appliquée aux topics en plaçant un marqueur à une coordonnée x, y dans la [Visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer) sur un étage d'un modèle IFC ou d'un bâtiment configuré avec une hauteur. Des points colorés marquent la localisation des topics dans la Visionneuse 2D, donnant une compréhension visuelle immédiate de l'endroit où se trouvent les topics ainsi que leur statut et type. En utilisant les localisations des topics, votre projet peut bénéficier d'un contrôle considérablement amélioré du placement des topics. Cette fonctionnalité complète la fonctionnalité de notre application mobile, [Catenda Site](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site). Avec les marqueurs, les projets sont dotés d'une création, d'une surveillance et d'une gestion fluides des topics créés sur le terrain, de retour au bureau.

## 1. **Topics avec marqueurs existants**

Les topics suivants sont décrits dans cette section :

### 1.1 **Interaction avec les marqueurs**

Survolez un [marqueur dans la Visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer#h_d904cebf2e) dans le navigateur pour afficher le numéro du topic et le titre du topic auquel appartient ce marqueur. Voici comment un marqueur survolé peut apparaître dans le navigateur.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/02-interacting-with-markers.png)

Cliquez sur le marqueur pour ouvrir le topic dans le tableau de topics correspondant dans le panneau de contenu.

### 1.2 **Affichage des marqueurs**

Pour travailler avec les topics et les localisations, ouvrez les panneaux de contenu et 3D côte à côte :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/03-displaying-markers.png)

**Choisissez le modèle pour votre fond 2D**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/04-displaying-markers.png)

Si un étage a été configuré dans le configurateur d'étages, le premier étage du premier bâtiment s'ouvre par défaut dès que le panneau 3D est ouvert.

**Développer la vue 2D**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/05-displaying-markers.png)

Faites glisser le coin supérieur gauche de la vue 2D ou double-cliquez sur le titre de la vue 2D pour la développer. Sélectionnez le bâtiment et l'étage sur lesquels ajouter ou afficher les localisations des topics en bas à gauche.

### 1.3 **Recherche de marqueurs**

**Recherche d'un topic à partir d'un marqueur sur un étage dans la vue 2D** Survolez un marqueur dans la vue 2D pour voir le numéro du topic et le titre du topic auquel il appartient. Lorsqu'un marqueur dans la vue 2D est cliqué, le panneau de contenu change pour afficher le topic sélectionné dans son tableau de topics sur la [page des topics](https://support.catenda.com/en/articles/4670271-topics-page).

**Recherche d'un marqueur dans la Visionneuse 2D à partir d'un topic** Pour trouver où le marqueur d'un topic a été placé dans la Visionneuse 2D, ouvrez le topic dans son tableau de topics et cliquez sur le texte "A un marqueur" dans l'en-tête du topic.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/06-finding-markers.png)

Dans le menu qui s'ouvre, sélectionnez "Afficher le marqueur en 2D" :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/07-finding-markers.png)

Lorsqu'un seul topic est sélectionné dans le tableau de topics ou lorsqu'un topic est ouvert, la couleur de ce marqueur est mise en évidence en vert :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/08-finding-markers.png)

### 1.4 **Édition des marqueurs**

**Déplacement des marqueurs** Dans la Visionneuse 2D, accédez au bâtiment et à l'étage où le marqueur doit être placé. Dans un topic avec un marqueur, sélectionnez l'option Choisir une nouvelle localisation dans le menu A un marqueur. Cliquez sur la nouvelle localisation du marqueur dans la Visionneuse 2D pour repositionner le marqueur à sa nouvelle localisation.

**Suppression de marqueurs** Sélectionnez l'option Supprimer le marqueur dans le topic.

### 1.5 **Configuration des marqueurs**

La visibilité des marqueurs peut être configurée dans les emplacements suivants :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/09-marker-configuration.png)

1. Afficher/masquer les marqueurs dans la vue 2D avec les [paramètres de la Visionneuse 2D](https://support.catenda.com/en/articles/4854537-2d-viewer#h_381a9d4098).
   Remarque : Les marqueurs peuvent ne pas être visibles si la couche de marqueur est désactivée.

Dans ce menu, le mode de couleur des marqueurs peut également être configuré. ([Statut, Type de topic, Échéance](https://support.catenda.com/en/articles/4854537-2d-viewer#h_381a9d4098)).

1. Dans le menu des couches, la couche de marqueur peut être activée/désactivée.

## 2. **Topics avec nouveaux marqueurs**

Les topics suivants sont décrits dans cette section :

### 2.1 **Ajouter un marqueur à partir d'un topic**

Créez un nouveau topic ou ouvrez un topic sans marqueur et cliquez sur "Ajouter un marqueur". Si le panneau 3D n'était pas encore ouvert, il s'ouvrira maintenant et un message d'information s'affichera vers le haut de l'écran.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/10-add-marker-from-topic.png)

Notez que le curseur se transforme en réticule dès que vous survolez la Visionneuse 2D, indiquant qu'un marqueur sera placé à cet endroit lorsqu'il sera cliqué.

### 2.2 **Ajouter un marqueur à partir de la Visionneuse 2D**

**Ajouter un marqueur** Accédez à un topic ou sélectionnez un seul topic dans le tableau de topics. Faites un clic droit dans la Visionneuse 2D et choisissez "Ajouter un marqueur" dans le dialogue contextuel qui s'ouvre pour ajouter un marqueur au topic sélectionné ou ouvert à cet endroit.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/11-add-marker-from-2d-viewer.png)

**Créer un nouveau topic avec marqueur** Commencez par accéder au tableau de topics dans lequel vous souhaitez créer un topic avec un marqueur. Ensuite, faites un clic droit dans la Visionneuse 2D et choisissez "Créer un nouveau topic avec marqueur" dans le dialogue contextuel qui s'ouvre pour lancer le [processus de création d'un nouveau topic](https://support.catenda.com/en/articles/4670268-creating-a-new-topic) avec le marqueur déjà appliqué.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/qm9hb6bs/12-add-marker-from-2d-viewer.png)

## 3. **Exportation de localisation en PDF**

Les informations de marqueur ne sont pas automatiquement incluses dans l'exportation PDF. Pour vous assurer que les informations de marqueur sont incluses dans l'exportation PDF, cliquez sur "A un marqueur" dans le topic et cliquez sur afficher en 2D. L'étage du bâtiment où le marqueur existe s'affichera dans la Visionneuse 2D. Cet étage ouvert, retournez au topic et cliquez sur le bouton plus à côté du champ de commentaire. Dans le menu ajouter une Capture, une Capture de la Visionneuse 2D peut être ajoutée à votre topic. Une image de la vue actuelle sera ajoutée en tant que commentaire au topic de cette façon. En étant dans le topic, le marqueur appartenant au topic actuel est mis en évidence en vert.
