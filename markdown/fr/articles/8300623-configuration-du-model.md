# Configuration du model

Les models peuvent être considérés comme des conteneurs pour les révisions de fichiers IFC, tout comme les Documents sont des conteneurs pour les fichiers. La différence entre un model et un Document est que le contenu d'un fichier ifc dans un model sera entièrement traité avec tous les ID, les données connectées aux objets et aura un plan 2D généré par étage. Les utilisateurs ont souvent un ou plusieurs models par domaine d'étude. Les models peuvent être accessibles et configurés sur la [page des models](https://support.catenda.com/en/articles/4670270-model-overview-page) dans le panneau de contenu. Ils peuvent également être consultés dans le sélecteur de révision du panneau Visionneuse 3D pour un moyen rapide de les activer et de les désactiver sans ouvrir le panneau de contenu.

## 1. Permettre aux utilisateurs de créer des models

Les administrateurs peuvent créer des models, mais parfois vous souhaitez permettre aux modeleurs eux-mêmes de créer de nouveaux models sans nécessairement voir tous les Documents. Dans ce cas, vous pouvez permettre à quelqu'un de créer des models dans les [paramètres du projet](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3). Si vous avez obtenu l'accès à la création de models dans les paramètres du projet, vous pouvez les créer et les supprimer en cliquant sur le [bouton nouveau model](https://support.catenda.com/en/articles/4670270-model-overview-page#h_0c6f0e7347) en haut à droite et les trois points à côté d'exporter, puis [supprimer le model](https://support.catenda.com/en/articles/4670270-model-overview-page#h_0c6f0e7347).
