# Rejoindre un projet

Pour rejoindre un projet, l'un des administrateurs du projet doit vous inviter. Vous recevrez une invitation et pourrez rejoindre le projet. Si c'est votre premier projet Catenda Hub, vous choisissez votre mot de passe la première fois que vous vous connectez.
