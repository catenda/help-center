# Actions de la page de contenu du modèle

Selon votre accès, différentes actions pour votre modèle actuel et chacune de ses révisions peuvent être vues sur la page d'aperçu du modèle.

## 1. **Actions du modèle**

Selon la sélection du modèle et selon les paramètres d'accès que vous avez, différents boutons d'action se trouvent en haut à droite de la [page d'aperçu du modèle](https://support.catenda.com/en/articles/4670270-model-overview-page#h_c10dbce6c8). Tous les boutons d'action seront répertoriés dans leurs menus d'action qui peuvent ressembler à ceci :

![mceclip0.png](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/01-model-actions.png)

Le menu d'action sur la page d'aperçu du modèle peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/02-model-actions.png)

### 1.1 **Télécharger la dernière révision**

Dès que vous avez téléchargé une révision, vous pouvez la télécharger ici

### 1.2 **Nouvelle révision**

Cliquez sur l'action nouvelle révision ou déposez un fichier dans la liste de contenu du modèle pour télécharger une nouvelle révision. Cliquez [ici](#h_118c049d47) pour en savoir plus sur le téléchargement d'une nouvelle révision.

### 1.3 **Exports**

Cela vous mènera à la [page d'export du modèle](https://support.catenda.com/en/articles/4670280-model-export)

### 1.4 **Retirer**

Avec cette action, vous serez invité à confirmer avant de retirer le modèle de la page des modèles.

> **Remarque :** Retirer le modèle ne le retire que de la page des modèles. Le document-modèle restera dans la section documents et devra être supprimé avec l'action de suppression de document sélectionnée si vous souhaitez également qu'il soit supprimé. Le modèle peut toujours être créé à nouveau à partir du même document dans la section modèles.

_Accès requis :_ Création et suppression de modèles dans les paramètres du projet et accès en écriture aux modèles que vous tentez de retirer.

## 2. **Actions de révision du modèle**

À droite de chaque révision, vous pouvez trouver les actions suivantes :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/5t44cpcq/03-model-revision-actions.png)

### 2.1 Télécharger

Cliquez sur l'action télécharger pour télécharger cette révision

### 2.2 Publier

Si les révisions partagées sont activées dans le [menu du flux de travail de statut](https://support.catenda.com/en/articles/12495583-status-workflow-document-settings) des paramètres de document dans le projet, toute nouvelle révision créée commence comme une révision partagée qui peut être publiée ultérieurement.

Les révisions partagées auront un numéro de révision mineur (0.1, 0.2, 1.1, etc.). L'action de publication peut être disponible pour les révisions partagées dans le modèle. Seules les révisions partagées après la dernière révision publiée peuvent être publiées. Les révisions publiées auront un numéro de révision majeur (1.0, 2.0, 3.0, etc.). _Accès requis :_ Peut publier dans les paramètres d'accès du document-modèle

**Publication des révisions précédentes** Avec l'action de publication, les révisions partagées après la dernière révision publiée dans le modèle peuvent être publiées. Sur la page de contenu du modèle, les révisions partagées précédentes peuvent être publiées tant qu'elles ont été créées après la dernière révision publiée. Ici, une seule révision peut être publiée à la fois en cliquant sur le bouton, tandis que les dernières révisions partagées de plusieurs modèles peuvent être publiées à la fois en les sélectionnant dans le tableau des modèles sur la page des modèles et en utilisant l'action de publication là-bas.

Après la publication, une nouvelle révision publiée avec un numéro majeur (1.0, 2.0, 3.0, etc.) est ajoutée. Cette révision publiée sera visible à la fois dans l'onglet Espace de travail et dans l'onglet Publiés.

### 2.3 2D

Cliquez sur l'action 2D pour ouvrir la vue 2D pour cette révision

### 2.4 3D

Cliquez sur le bouton 3D pour ouvrir la vue 2D pour cette révision
