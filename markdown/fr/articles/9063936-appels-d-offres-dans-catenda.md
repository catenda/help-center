# Appels d'offres dans Catenda

La mise en place d'appels d'offres est une part importante du processus de construction. Naturellement, avec les Documents déjà disponibles sur Catenda Hub, les utilisateurs aimeraient configurer leur projet pour être utilisé dans un processus d'appel d'offres. Comparé à l'utilisation régulière de Catenda avec la collaboration des Membres du projet, cela pose certains défis car la partie créant l'appel d'offres voudra assurer une concurrence équitable. Cet article contient certains

## 1. **Contrôle d'accès**

Les entrepreneurs participant au processus d'appel d'offres doivent être limités dans les actions qu'ils peuvent effectuer sur Catenda. Les utilisateurs d'appel d'offres peuvent se voir accorder l'accès à un ensemble spécifique de Documents du projet qu'ils peuvent utiliser comme base. Ils peuvent se voir accorder l'accès en lecture à tous les endroits du projet tandis qu'aucun accès ne leur est donné aux endroits qu'ils ne doivent pas voir.

## 2. **Utilisation anonyme de Catenda**

Dans un processus d'appel d'offres, il est important que les parties soumettantes ne se connaissent pas. Dans Catenda, tous les utilisateurs peuvent voir tous les autres utilisateurs du projet, ce qui peut causer des problèmes dans une situation d'appel d'offres. Selon la façon dont vous pouvez créer un compte sur Catenda, il existe plusieurs façons de résoudre ce problème.

### 2.1 **Alias de messagerie**

Sur Catenda, chaque compte est connecté à une adresse e-mail. Une façon de s'assurer que les comptes utilisés pour les appels d'offres restent anonymes est de créer des alias de messagerie qui sont utilisés pour créer des comptes. Parce que vous contrôlez l'adresse e-mail à laquelle le compte est connecté, vous pouvez vous assurer que le nom d'utilisateur et l'adresse e-mail restent anonymes. Vous pouvez alors partager le nom d'utilisateur et le mot de passe des comptes avec les parties qui en ont besoin.

### 2.2 **Compte e-mail pour chaque utilisateur**

Certaines entreprises ne permettent pas à leurs employés de créer des alias pour leurs e-mails. S'il n'est pas important que les utilisateurs se voient, les utilisateurs peuvent être invités de la façon habituelle. À tous les endroits sur Catenda, autre que la page des Membres, il existe de bonnes façons de s'assurer que les informations partagées par un membre ne sont pas vues par un autre.

### 2.3 **Utilisateurs externes**

Si vous n'êtes pas en mesure de créer des utilisateurs séparés pour chaque soumissionnaire d'appel d'offres, vous pouvez également utiliser votre projet Catenda comme lieu pour partager vos informations d'appel d'offres sans inviter les soumissionnaires. Comme le montre la section [base d'information pour les appels d'offres](#h_9ab97bdd71), les [collections de Documents](https://support.catenda.com/en/articles/6344318-collections-page) et les [signets 3D](https://support.catenda.com/en/articles/4670281-bookmarks-page) peuvent être préparés et partagés avec des tiers externes pour servir de base à la soumission. De cette façon, les utilisateurs externes peuvent avoir accès aux Documents et aux vues 3D du projet sans en faire partie eux-mêmes. Comme les utilisateurs ne font pas partie du projet, la livraison des Documents devra être soumise ailleurs. Les Documents soumis peuvent être téléchargés dans le projet par le soumissionnaire après leur soumission.

## 3. **Base d'information pour les appels d'offres**

Les projets ont souvent beaucoup d'informations sur le bâtiment quand un processus d'appel d'offres commence. Il est donc important de guider la partie soumettante vers les bons Documents, non seulement pour qu'elle ne consulte pas accidentellement le mauvais Document, mais aussi pour s'assurer que tous les soumissionnaires travaillent avec les mêmes informations.

### 3.1 **Base de Documents**

La création de [collections de Documents](https://support.catenda.com/en/articles/6344318-collections-page) des Documents que vous aimeriez utiliser comme base pour le processus d'appel d'offres est un moyen simple de montrer au soumissionnaire quels Documents doivent être consultés. Puisque vous pouvez verrouiller les [collections de Documents](https://support.catenda.com/en/articles/6344318-collections-page) sur les révisions, vous serez en mesure de vous assurer qu'il n'y a pas de confusion sur la version du Document qui est censée être utilisée. Si les soumissionnaires ne font pas partie du projet, vous pouvez également partager les collections de Documents en externe. De cette façon, vous pouvez partager des fichiers volumineux avec chaque partie soumettante et voir une confirmation quand ils ont cliqué sur le Lien de téléchargement qui leur a été envoyé.

### 3.2 **Base 3D**

Comme pour les Documents, vous pouvez utiliser des [Signets](https://support.catenda.com/en/articles/4670281-bookmarks-page) pour créer une base montrant aux soumissionnaires d'appel d'offres quels modèles 3D examiner. Les Signets sont un excellent moyen de montrer aux soumissionnaires un point de vue sur la partie du projet en 3D qui est visée dans ce cas.

**Partagé avec le projet** Les [Signets](https://support.catenda.com/en/articles/4670281-bookmarks-page) doivent être partagés avec le projet afin que les autres Membres du projet puissent les voir. Avec les [modèles en tant que Documents](https://support.catenda.com/en/articles/8064548-models-as-documents), l'accès peut être configuré de manière à ce que les utilisateurs d'appel d'offres ne voient que les modèles auxquels ils ont accès.

**Signets publics** Les Signets publics sont un excellent moyen de partager des vues 3D avec des tiers externes dans le cadre d'un appel d'offres. Avec un Signet public, vous pouvez générer un Lien où les soumissionnaires d'appel d'offres pourront voir une version simple des modèles dans le Signet sans les propriétés des objets. Ceci est pour s'assurer que les informations de quantité sensibles qui pourraient être dans ces objets ne sont pas accidentellement.

## 4. **Désactiver le partage public**

Les projets d'appel d'offres sont souvent privés et il est important qu'aucune information ne soit partagée avec d'autres parties. Une façon de vous assurer qu'il n'y a pas d'autre moyen d'exporter que le téléchargement est de nous demander de désactiver la fonction de partage public du projet. Avec cette option désactivée, il ne sera plus possible de créer des Liens partageables avec des collections de Documents ou des Signets afin qu'aucune information sensible ne puisse fuir du projet par d'autres moyens que le téléchargement. Vous pouvez trouver cette option décrite plus en détail [ici](https://support.catenda.com/en/articles/8224886-organization-options#h_1027778040).
