# Numérisation de code QR Catenda

La numérisation du code QR avec votre smartphone vous amènera à une page de vérification où les résultats suivants apparaîtront en fonction de la version du PDF ;

1. Votre revision est la dernière version du PDF : **Document valide**
1. Votre revision est une version antérieure du PDF : **Document invalide**
1. Vous avez numérisé un espace réservé : **Vous avez numérisé un espace réservé, ce document n'est pas publié**
