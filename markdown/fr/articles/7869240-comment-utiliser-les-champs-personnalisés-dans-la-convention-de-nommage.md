# Comment utiliser les champs personnalisés dans la convention de nommage

Pour utiliser la convention de nommage avec des champs personnalisés, les champs personnalisés doivent d'abord être rendus disponibles sur la [page des champs personnalisés](https://support.catenda.com/en/articles/6550459-custom-fields-page) afin qu'ils puissent être sélectionnés dans la configuration de la convention de nommage. _Accès requis :_ Administrateur de projet

Pour utiliser un champ personnalisé dans une convention de nommage, suivez ces étapes :

## 1. **Accéder à la page de contenu de la convention de nommage**

Cliquez sur [paramètres](https://support.catenda.com/en/articles/4670273-project-settings-page) dans le menu de navigation de gauche pour ouvrir et trouver les sous-pages des paramètres du projet. Cliquez sur Convention de nommage qui apparaît maintenant comme une sous-page des paramètres pour ouvrir la [page de convention de nommage](https://support.catenda.com/en/articles/7832559-naming-conventions-page). Cliquez sur l'une des conventions de nommage pour ouvrir la page de contenu de la convention de nommage.

![Sélectionnez les conventions de nommage à personnaliser](https://raw.githubusercontent.com/catenda/help-center/main/images/s9hns6p2/01-go-to-the-naming-convention-content-page.png)

## 2. **Modifier la convention de nommage**

Sur la page de contenu de la convention de nommage, modifiez la convention de nommage en cliquant sur le bouton Modifier sous la description et au-dessus du tableau avec les blocs.

![Modifiez votre convention de nommage en cliquant sur ](https://raw.githubusercontent.com/catenda/help-center/main/images/s9hns6p2/02-edit-naming-convention.png)

## 3. **Sélectionner un champ personnalisé existant comme source**

Dans la colonne source de la convention de nommage, choisissez l'un des champs personnalisés disponibles dans le projet. Dans cet exemple, le champ personnalisé "**NC Phase**" est sélectionné. C'est un champ personnalisé de type liste déroulante avec des valeurs comme : Plan, Dsg, EXE...

![Choisissez les champs personnalisés créés au préalable dans la section source lors de la modification d'un champ personnalisé](https://raw.githubusercontent.com/catenda/help-center/main/images/s9hns6p2/03-select-a-pre-existing-custom-field-as-source.png)

Il est conseillé d'utiliser uniquement des champs personnalisés dans la section "**Source**", dans cet exemple tous ces champs personnalisés sont de type "**liste déroulante**" ou "**Entier**" pour le bloc "**Version**"

![Utilisez uniquement les champs personnalisés dans la section source](https://raw.githubusercontent.com/catenda/help-center/main/images/s9hns6p2/04-select-a-pre-existing-custom-field-as-source.png)

Les documents téléchargés dans un dossier où cette convention de nommage est configurée pourront maintenant avoir des valeurs dans les noms en fonction du champ personnalisé sélectionné.
