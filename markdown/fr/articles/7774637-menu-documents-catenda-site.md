# Menu Documents - Catenda Site

La page Documents se trouve dans le [menu](https://support.catenda.com/en/articles/7338516-navigation-menu-catenda-site) ou en appuyant sur le bouton problèmes dans la barre de navigation inférieure. Ici, vous pourrez trouver et [prévisualiser vos documents](https://support.catenda.com/en/articles/8975421-previewing-documents-on-catenda-site).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y3wk741n/01-intro.png)

Le contenu de la page du menu Documents peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y3wk741n/02-intro.png)

Vers le haut de la page Documents, vous trouverez le nom du projet.

## 1. **Filtres de documents**

Sous le nom du projet, vous verrez le menu de filtrage des documents.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y3wk741n/03-document-filters.png)

_Filtrer :_ En cliquant sur le bouton de filtre à droite, vous pourrez [filtrer vos documents par étiquette](https://support.catenda.com/en/articles/7854138-label-filter-catenda-site).

_Recherche :_ Le bouton de recherche vous permet de rechercher dans les documents.

_Liste déroulante Documents :_ Le menu déroulant vous permet de sélectionner des collections de documents. Vous pourrez sélectionner l'une des collections de documents partagées dans votre projet.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y3wk741n/04-document-filters.png)

Les collections de documents peuvent être utiles pour apporter[ des documents à un emplacement hors ligne](https://app.intercom.com/a/apps/areracg3/articles/articles/7325268/show#:~:text=Documents%20in%20offline%20mode).

## 2. **Liste des documents**

Dans la liste des documents, vous pourrez naviguer dans les dossiers et les documents de votre projet.

> **Remarque :** Seules les révisions publiées seront affichées. Si vous utilisez le flux de travail de statut, cela signifie que les révisions brouillon et partagées ne seront pas visibles sur Catenda Site.

Glissez vers le haut et vers le bas dans le menu Documents pour faire défiler la liste.

### 2.1 **Ouverture des dossiers**

Appuyez sur un dossier pour ouvrir le dossier. Après avoir ouvert un dossier, vous remarquerez que la liste déroulante des documents a été remplacée par le nom du dossier dans lequel vous êtes.

### 2.2 **Ouverture des documents**

Appuyez sur un document pour ouvrir le document. Après avoir chargé un document, il est disponible pour vous, même si vous êtes hors ligne, tant que vous êtes dans le dossier contenant le document. Lisez [ici](https://support.catenda.com/en/articles/8975421-previewing-documents-on-catenda-site) pour plus d'informations sur les documents sur Catenda Site
