# Recommandation matérielle

> Trouvez les spécifications matérielles recommandées et les conseils d'optimisation pour la meilleure expérience avec Catenda Hub.

## 1. **Recommandation matérielle :**

Cette recommandation matérielle est destinée uniquement à Catenda Hub dans une application navigateur. Cela inclut Catenda Hub ouvert dans le navigateur d'une tablette ou ajouté à l'écran d'accueil, comme décrit dans [iPad et autres tablettes](#ipad-and-other-tablets). Il peut y avoir des exigences différentes selon le niveau de détail de vos objets 3D. Les niveaux de détail (LOD) sont définis par l'AIA dans le document G202 sous la forme LOD 100, 200, 300, 400, 500 et 600. La définition LOD peut être vue [ici](https://assets.aiacontracts.com/ctrzdweb02/zdpdfs/aia-g202-2013-free-sample-preview.pdf).

## 2. **Moniteur**

Si un ou plusieurs moniteurs externes sont connectés à un appareil, même si Catenda n'est pas affiché sur ce moniteur, assurez-vous que l'appareil prend en charge le nombre de moniteurs et la combinaison de résolutions d'affichage que les moniteurs ont et qui sont configurés dans le système d'exploitation.

## 4. **iPad et autres tablettes**

Catenda Hub peut également être utilisé sur un iPad ou une autre tablette, dans le navigateur ou [ajouté à l'écran d'accueil](https://support.catenda.com/fr/articles/10741601-ajouter-a-l-ecran-d-accueil) en tant qu'application. Ajouté à l'écran d'accueil, c'est toujours Catenda Hub qui s'exécute dans le navigateur de l'appareil, la fonctionnalité complète est donc disponible et les recommandations ci-dessous s'appliquent aux deux.

### 4.1 **La mémoire graphique détermine la quantité de 3D que vous pouvez charger**

Les modèles affichés dans la visionneuse 3D sont stockés dans la mémoire du processeur graphique. Sur une tablette, le processeur graphique partage sa mémoire avec le reste de l'appareil, et il en a moins que sur un ordinateur avec une carte graphique dédiée. La quantité de géométrie qu'une tablette peut afficher en même temps dépend donc de sa puce et de sa mémoire, non pas de son espace de stockage. Une tablette avec plus d'espace de stockage ne charge pas plus de modèles.

### 4.2 **Tablettes recommandées**

Pour les projets réguliers (jusqu'à LOD 300), un iPad récent avec la dernière version d'iPadOS est recommandé. Pour les projets de géométrie dense (LOD 400 et plus), ou lorsque de nombreux modèles doivent être affichés ensemble, un iPad Pro ou un iPad Air avec une puce série M est recommandé. Sur une tablette Android, un modèle récent avec une puce haut de gamme sur la dernière version d'Android est recommandé. Gardez iPadOS et Safari à jour, car les mises à jour améliorent souvent la façon dont le navigateur gère les graphiques 3D.

### 4.3 **Tirer le meilleur parti d'une tablette**

Sur une tablette, il est utile de charger uniquement ce dont vous avez besoin pour la tâche à accomplir :

- Activez uniquement les modèles dont vous avez besoin, plutôt que tous les modèles du projet.
- Utilisez une [requête](https://support.catenda.com/fr/articles/4854514-requetes) pour afficher uniquement la partie du modèle sur laquelle vous travaillez.
- Activez le rendu progressif dans les [paramètres de la visionneuse 3D](https://support.catenda.com/fr/articles/5784718-parametres-de-la-visionneuse-3d).

D'autres conseils sont décrits dans [Optimisation de la visionneuse 3D](https://support.catenda.com/fr/articles/13927321-optimisation-de-la-visionneuse-3d).

Pour le travail sur le chantier, l'application mobile Catenda Site est souvent un meilleur choix, comme décrit dans [Accès avec espace d'écran limité](https://support.catenda.com/fr/articles/10695677-acces-avec-un-espace-d-ecran-limite). Les recommandations d'appareils pour Catenda Site sont décrites dans [Recommandation matérielle - Catenda Site](https://support.catenda.com/fr/articles/17596478-recommandations-materielles-catenda-site).
