# Bibliothèque Sharepoint

> Cet article décrit comment configurer une connexion à Sharepoint

Pour créer une bibliothèque SharePoint, cliquez sur le [bouton nouvelle bibliothèque](https://support.catenda.com/en/articles/8065645-libraries-page#h_c6d56f227c) en haut à droite de la [page des bibliothèques](https://support.catenda.com/en/articles/8065645-libraries-page). Cette bibliothèque peut être utilisée pour partager des Documents provenant du SharePoint d'un utilisateur avec les autres Membres du projet Catenda. Lorsque la bibliothèque SharePoint est activée, elle peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/01-intro.png)

Cliquez [ici](https://support.catenda.com/en/articles/9800091-sharepoint-library-short-video) pour voir une courte vidéo sur la configuration de la bibliothèque SharePoint.

Après avoir donné un nom à la bibliothèque, un nouvel onglet s'ouvrira dans votre navigateur où vous serez invité à vous connecter avec votre compte SharePoint. Après vous être connecté, vous serez redirigé vers la page des paramètres de la bibliothèque de votre bibliothèque SharePoint où vous pouvez configurer le dossier SharePoint que vous souhaitez afficher sur Catenda.

## 1. **En-tête -** Nom de la bibliothèque

Sur le côté gauche de l'en-tête, vous verrez le nom de la bibliothèque actuelle. Si la bibliothèque est synchronisée, vous verrez une coche à côté du nom. Lorsque vous synchronisez la bibliothèque, elle restera synchronisée pendant 3 mois. Après cela, vous pourriez voir un point d'exclamation ici avec une info-bulle indiquant « échec de la synchronisation ». Si cela se produit, veuillez aller aux paramètres de la bibliothèque et accorder l'accès une fois de plus.

## 2. **En-tête** - Paramètres de la bibliothèque

Sur le côté droit de l'en-tête, vous pourrez voir un menu d'action qui peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/02-header-library-settings.png)

Dans les paramètres de la bibliothèque, vous pourrez configurer votre bibliothèque SharePoint. _Accès requis :_ Créateur de bibliothèque

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/03-header-library-settings.png)

### 2.1 **Connexion**

Si vous avez connecté votre compte, vous pouvez cliquer sur Révoquer l'accès pour révoquer l'accès que vous avez accordé à Catenda à votre compte SharePoint. Si vous n'avez pas accordé l'accès, vous pourrez cliquer sur Accorder l'accès ici pour suivre le processus d'accès afin de donner à Catenda l'accès à votre compte.

### 2.2 **Détails**

Cliquez sur l'icône crayon pour modifier le nom de cette bibliothèque.

### 2.3 **Dossier partagé**

Ouvrez ce menu et cliquez sur modifier pour choisir un dossier partagé à partir de l'un de vos sites SharePoint que vous souhaitez afficher dans cette bibliothèque SharePoint.

> **Remarque :** Pour qu'un dossier apparaisse dans cette liste, il doit être défini comme public dans SharePoint

### 2.4 **Contrôle d'accès**

Ici, vous pouvez déterminer qui est autorisé à accéder à cette bibliothèque dans votre projet.

### 2.5 **Supprimer**

Ouvrez ce menu et cliquez sur supprimer pour supprimer cette bibliothèque SharePoint de votre projet Catenda

## 3. **En-tête - Paramètres de la bibliothèque -** Nouvelle bibliothèque

Cliquez sur le bouton Nouvelle bibliothèque pour créer une nouvelle bibliothèque

## 4. **Menu Filtres**

### 4.1 **Filtres sauvegardés**

Cliquez [ici](https://support.catenda.com/en/articles/8551755-saving-filters) pour en savoir plus sur la façon de sauvegarder un ensemble de Filtres

### 4.2 **Non lié -** `link=unlinked`

Avec ce Filtre, vous pourrez filtrer tous les Documents qui ne sont pas liés à des objets.

### 4.3 **Lié aux objets sélectionnés -** `link=backlink`

Si vous avez sélectionné des objets dans la Visionneuse 3D qui sont connectés à des Documents SharePoint, vous pourrez les filtrer ici.

## 5. **Liste des Documents SharePoint**

Ici, vous pourrez parcourir tous les Documents et dossiers du dossier partagé qui est configuré pour cette bibliothèque.

### 5.1 **Actions**

Après avoir sélectionné un ou plusieurs Document(s) ou dossier(s), vous pourrez voir le menu d'action suivant apparaître vers le haut de la liste des Documents. Le menu Actions des éléments existants peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/04-actions.png)

**Lier/Delier** Si vous sélectionnez un objet à partir d'un modèle en 3D, vous pourrez le lier/délier à vos éléments sélectionnés.

**Aperçu** Ouvrir un aperçu du Document sans avoir à charger la page des Documents. Cela peut être particulièrement utile dans un dossier contenant de nombreuses images. Visible uniquement lorsqu'un seul Document est sélectionné

**Télécharger** Cliquez sur télécharger pour télécharger votre Document sélectionné. Visible uniquement lorsqu'un seul Document est sélectionné

### 5.2 **Nom**

Cliquez sur le nom d'un dossier pour voir son contenu Cliquez sur le nom d'un Document pour afficher son contenu

### 5.3 **URL**

Cliquez sur le bouton de téléchargement dans cette colonne pour télécharger le Document.

### 5.4 **Liens**

Si des objets ont été liés à vos Documents, vous pourrez voir le nombre d'objets liés ici. En cliquant sur ce nombre, vous pourrez :

**Sélectionner des objets**

**Isoler les objets**

**Charger comme requête de sélection**

## 6. **Menu d'informations à droite**

Lorsque vous ouvrez d'abord un Document dans la liste des Documents, son menu droit peut être fermé. Vous pouvez cliquer sur le bouton d'information en bas à droite de la [bannière de Document](https://support.catenda.com/en/articles/8461918-document-banner-actions-navigation) pour développer ce menu.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xt4043w9/05-right-information-menu.png)

### 6.1 **Objets liés**

Ici, vous pourrez lier des objets à vos Documents SharePoint.

### 6.2 **Sujets**

Après avoir ouvert un Document, vous pourrez voir le menu des Sujets. Ici, vous pourrez joindre vos Documents SharePoint aux Sujets.

## 7. **Autorisations**

Lorsque des Documents sont téléchargés à partir d'une bibliothèque de Documents SharePoint vers Catenda, l'API REST SharePoint est utilisée (via la [bibliothèque pnpjs](https://pnp.github.io/pnpjs/)). Puisque ces autorisations sont accordées aux solutions spfx OOTB, aucune subvention supplémentaire n'est nécessaire. Les subventions suivantes seront nécessaires pour que l'application accède au backend Catenda. Seules les autorisations déléguées sont utilisées avec les portées suivantes : _[User.Read](https://graphpermissions.merill.net/permission/User.Read) [offline\_access](https://graphpermissions.merill.net/permission/offline_access) [Files.Read](https://graphpermissions.merill.net/permission/Files.Read)_ _[Sites.Read.All](https://graphpermissions.merill.net/permission/Sites.Read.All)_ L'accès ci-dessus est utilisé uniquement pour approuver le partage de Documents au projet Catenda de l'utilisateur.
