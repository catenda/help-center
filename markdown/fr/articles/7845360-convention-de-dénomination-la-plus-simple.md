# Convention de dénomination la plus simple

Cet article montrera comment une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) peut ressembler dans la [section Documents](https://support.catenda.com/en/articles/4670292-documents-page). Avant de commencer à lire cet article, il est important que vous compreniez les bases des [conventions de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page). Vous pouvez découvrir comment utiliser les [champs personnalisés](https://support.catenda.com/en/articles/6550459-custom-fields-setup), [configurer une convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) et [assigner la convention](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90) à un dossier. Je voudrais d'abord commencer par la [convention la plus simple possible](#h_667e7d43ef) pour expliquer ce que cette [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) fait lorsqu'elle est appliquée à un dossier. Plus tard dans l'article, nous pourrons progresser vers des conventions plus complexes.

Les sujets suivants seront décrits dans cet article :

[Dossiers et conventions](http://Folders%20and%20conventions) - [Télécharger un document](#h_5a4a3f35ef) - [Documents et conventions](#h_eb4ed69f2b)

## 1. **Nom de fichier.Extension**

Commençons par la convention la plus simple possible pour voir à quoi peut ressembler une convention lorsqu'elle est activée. De cette façon, vous saurez comment reconnaître quand une convention est active. La convention la plus simple possible se crée en créant une nouvelle convention et en cliquant immédiatement sur soumettre :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/01-filename-extension.png)

Cette convention acceptera les fichiers de n'importe quel nom et de n'importe quelle extension. Bien que ce ne soit pas différent du processus de téléchargement régulier, c'est ce qui est fait dans cet article pour montrer à quoi peut ressembler une convention.

_Application de la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) à un dossier_ Les [conventions de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) sont activées par dossier dans les [paramètres des documents](https://support.catenda.com/en/articles/7831371-document-settings#h_6672c14d90). Après avoir appliqué cette convention à un dossier, vous remarquerez qu'il aura une icône d'engrenage.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/02-filename-extension.png)

**Panneau d'information :** Si vous sélectionnez le dossier, vous remarquerez également un changement dans le panneau d'information sur la droite. Ici, l'[aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) du nom de document attendu apparaîtra sous le nom du dossier. Comme toujours, vous pouvez survoler l'[aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) pour voir les informations sur les différents blocs.

### 1.1 Dossiers et conventions

Lorsque vous créez un nouveau dossier dans un dossier avec convention, vous remarquerez qu'il a un badge d'engrenage gris. Cela signifie qu'il a hérité d'une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) d'un dossier parent.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/03-folders-and-conventions.png)

Si vous sélectionnez un dossier auquel une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) est appliquée, vous verrez un [aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) de la convention de dénomination sous le nom du dossier dans le panneau d'information sur la droite. Cet [aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) illustre le modèle de nom de document que les nouveaux documents dans ce dossier doivent suivre.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/04-folders-and-conventions.png)

### 1.2 Télécharger un document

Lorsque vous téléchargez un fichier dans un dossier auquel une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) est appliquée, vous verrez qu'il est soit accepté, soit rejeté en fonction des critères de la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page). Dans l'exemple ci-dessus, le nom et l'extension du fichier peuvent avoir n'importe quels caractères de n'importe quelle longueur.

Ci-dessous, vous verrez à quoi cela ressemble lorsqu'un fichier portant le nom test.txt est téléchargé :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/05-uploading-a-document.png)

_[Aperçu de bloc](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc)_ Comme vous pouvez le voir dans la zone grise sous Télécharger un document, en plus du nom du dossier dans lequel vous téléchargez votre document, vous verrez maintenant aussi un [aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc) du nom de fichier que la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) attend. Si vous survolez l'un des blocs dans l'[aperçu](https://support.catenda.com/en/articles/7832559-naming-conventions-page#h_c2f7e24fbc), vous verrez qu'il s'agit de blocs de document attendant du texte de longueur variable.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/06-uploading-a-document.png)

Vous pouvez maintenant cliquer sur télécharger et le fichier sera téléchargé.

### 1.3 Documents et conventions

Dans un dossier auquel une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) est appliquée, vous verrez que les Documents ont un badge d'engrenage sur leur icône. Ce badge signifie que le document existe dans un dossier auquel une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) est appliquée. Il est possible que le document ait été téléchargé avant l'application de la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page), donc cela ne signifie pas qu'il suit les règles de dénomination.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/07-documents-and-conventions.png)

Lorsque vous ouvrez le document pour le consulter, la première chose que vous remarquerez est que le nom du document est grisé. Les noms de Documents dans un dossier auquel une [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) est appliquée suivent les règles de la convention. Il n'est donc pas possible de modifier le nom d'un tel document.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/08-documents-and-conventions.png)

_Ce document n'est pas conforme à la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page)_ Si la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page) est appliquée à un dossier qui contenait déjà des Documents, il est possible que le nom de la révision ne soit pas conforme à la convention. Vous verrez que c'est le cas quand il y a un point d'exclamation derrière.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/c55e7gpw/09-documents-and-conventions.png)

Cela peut être dû à deux raisons.

1. Le nom de fichier de révision ne correspond pas au nom de fichier attendu de la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page).
1. Le nom de fichier de révision ne correspond pas au résultat de document attendu selon la [convention de dénomination](https://support.catenda.com/en/articles/7832559-naming-conventions-page).
