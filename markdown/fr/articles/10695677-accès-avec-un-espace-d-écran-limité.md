# Accès avec un espace d'écran limité

Avec une taille d'écran limitée, certaines fonctions peuvent être accessibles de manière conviviale sur Catenda Site. Si l'accès à toutes les fonctionnalités est plus important pour vous que l'accessibilité, cela est toujours disponible via le navigateur. Les pages du navigateur peuvent être ajoutées à l'écran d'accueil/au tableau de bord/au dock pour améliorer l'expérience d'accès à Catenda avec un espace d'écran limité.

## 1. **Catenda Site -** Accessible et hors ligne

Sur les appareils avec une taille d'écran limitée, les boutons doivent être plus grands afin que vous voyiez ce que vous appuyez avec votre doigt. Dans cette situation, notre application mobile, [Catenda Site](https://support.catenda.com/en/articles/6530821-download-your-mobile-app-catenda-site), est le meilleur outil pour vous.

- La fonctionnalité est limitée et gardée simple afin que vous puissiez facilement appuyer sur les boutons dont vous avez besoin.
- Le contenu peut être téléchargé et soumis sans connexion Internet

## 2. **Écran d'accueil / Tableau de bord / Dock -** Fonctionnalité complète

La fonctionnalité complète de Catenda Hub est toujours disponible via le navigateur. Catenda prend en charge l'[ajout à l'écran d'accueil](https://support.catenda.com/en/articles/10741601-add-to-home-screen), au tableau de bord ou au dock en l'installant via un navigateur. L'installation de Catenda via un navigateur au lieu de créer un raccourci offre les avantages suivants :

- Catenda est plus accessible car c'est souvent le moyen principal d'accéder au contenu sur les appareils mobiles.
- L'espace d'écran est économisé car la barre du navigateur vers le haut sera masquée.
- Surtout sur les tablettes, vous voudriez utiliser toutes les fonctionnalités de Catenda tout en utilisant l'espace d'écran dont vous disposez.
