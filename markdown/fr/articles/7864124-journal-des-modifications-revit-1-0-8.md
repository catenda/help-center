# Journal des modifications Revit - 1.0.8

Nouvelles fonctionnalités dans 1.0.8

- Disponibilité de Revit 2024
- Filtrage des Équipes
- Les paramètres d'export personnalisés sont à nouveau disponibles dans le plugin
- Panneau latéral de problème
  - Dans un problème, il est maintenant possible d'ouvrir le panneau latéral en cliquant sur les éléments associés.
  - Voir les Documents qui sont liés au problème
  - Sélectionner les objets qui sont liés au problème
  - Voir quels problèmes sont associés à ce problème
