# Aperçu des types de fichiers sur Catenda Site

Les documents sur Catenda Site peuvent être trouvés en appuyant sur un document dans le [menu documents](https://support.catenda.com/en/articles/7774637-documents-menu-catenda-site).

## 1. Boutons en haut à droite

En haut d'un document, vous pourrez trouver les options suivantes.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/01-top-right-buttons.png)

### 1.1 Menu hamburger

Lorsque vous cliquez sur le menu hamburger en haut à droite du document, un menu s'ouvrira vers le bas de l'écran.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/02-1-hamburger-menu.png)

**Ouvrir**

Appuyez sur l'option Ouvrir pour ouvrir votre document avec une autre application sur votre appareil.

Cette option peut être utilisée pour ouvrir votre document dans une application disposant de capacités d'aperçu des documents. Vous pourriez par exemple vouloir ouvrir une image dans une application d'édition d'images ou un PDF dans une application où vous pouvez ajouter des commentaires

**Partager**

Appuyez sur l'option Partager pour partager votre document avec une autre application sur votre appareil.

Cette option peut être utilisée pour partager votre document en tant que pièce jointe dans des types de communication comme les e-mails ou les messages qui peuvent avoir des pièces jointes.

Appuyez n'importe où en dehors du menu hamburger ou faites glisser vers le bas le menu pour le fermer à nouveau.

### 1.2 Recherche

S'il y a du texte interrogeable dans un document, l'option de recherche peut être utilisée pour trouver des phrases dans ce texte. Lorsque vous appuyez sur le bouton de recherche, une barre de recherche s'affiche et vous pouvez saisir la phrase que vous recherchez.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/03-2-search.png)

Appuyez sur le x pour supprimer votre recherche.

**Chercheur de correspondances**

Après avoir tapé une phrase, vous pouvez appuyer sur le bouton de correspondances pour voir un aperçu de tous les endroits où votre phrase a été trouvée dans le document.

**Menu hamburger dans la barre de recherche**

En appuyant sur le menu hamburger, vous pouvez choisir si vous voulez que les caractères majuscules soient considérés avec l'option de respecter la casse et si vous voulez que votre phrase soit découverte si c'est un mot entier au lieu de seulement une partie d'un mot.

### 1.3 Pages

Le bouton des pages vous permettra de voir un aperçu des pages de votre document

Appuyez sur l'une des pages pour ouvrir cette page.

### 1.4 Paramètres d'affichage

En appuyant sur le bouton des paramètres d'affichage, la boîte de dialogue des paramètres d'affichage s'ouvrira.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/xw79ynda/04-4-viewing-settings.png)

Ici, vous pouvez décider si vous voulez que votre mode d'affichage soit :

_Page unique_ - Par défaut

Ici, vous voyez une page à la fois.

**Double page**

Ici, vous voyez deux pages côte à côte.

**Lecture**

Ici, vous voyez une version simplifiée du document avec des en-têtes facilement lisibles et gras et les marges supprimées.

Mode couverture

C'est la même chose que la double page, mais le premier écran n'affiche que la couverture.

Ce mode peut être agréable si vous désactivez le défilement vertical

**Défilement vertical**

Par défaut, le défilement vertical est activé, mais peut être désactivé si vous préférez faire défiler horizontalement au lieu de verticalement

**Rotation dans le sens des aiguilles d'une montre**

Faites pivoter votre document dans le sens des aiguilles d'une montre de 90 degrés.

Chaque page sera tournée individuellement et la direction du défilement restera en place.

## 3. Formats de fichiers ouverts

Chez Catenda, nous aimons travailler avec des standards ouverts afin que chacun puisse collaborer quel que soit le logiciel qu'il possède.

_En règle générale, n'importe qui peut participer à leur développement en raison de leur nature intrinsèquement ouverte ([Wikipedia](https://en.wikipedia.org/wiki/Open_standard#:~:text=Typically%2C%20anybody%20can%20participate%20in%20their%20development%20due%20to%20their%20inherently%20open%20nature.))_

Cela signifie qu'une seule organisation ne contrôle pas ce qui est développé.

### 4.1 Versions d'IFC

En fonction du statut de la version d'IFC, nous prenons en charge la version de différentes manières :

_Officiel, Retiré_ - Support complet. Toutes les versions d'IFC officielles et retirées sont prises en charge.

_Retiré_ - Support partiel. Les modèles sont traités selon la dernière version officielle.

_En développement_ - Pas de support. Ceux-ci pourraient encore changer avant d'être publiés.

Vous pouvez trouver quelles versions d'IFC sont officielles [ici](https://technical.buildingsmart.org/standards/ifc/ifc-schema-specifications/)

Les fichiers d'exemples IFC officiels de BuildingSMART peuvent être trouvés [ici](https://github.com/buildingSMART/Sample-Test-Files)

Les points dans les nuages de points peuvent être prévisualisés soit par couleur, soit par intensité.

## 6. Formats de fichiers propriétaires

Il existe de nombreux standards de formats de fichiers développés par des organisations qui sont utilisés par beaucoup.

Il est important pour nous que Catenda soit facile à utiliser. Nous nous efforçons donc de prendre en charge autant que possible les types de fichiers les plus courants utilisés.
