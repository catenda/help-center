# Outils d'aperçu de document

Lorsque la [page d'aperçu](https://support.catenda.com/en/articles/5001165-document-preview-and-annotations) d'un [type de fichier pouvant être aperçu](https://support.catenda.com/en/articles/4670320-previewing-file-types-on-catenda-hub) est d'abord ouvert, la barre d'outils suivante s'affiche en haut.

![Vue Annoter Formes Insérer Mesurer](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/01-intro.png)

Si l'échelle du navigateur est définie sur une taille moyenne ou si une taille d'écran moyenne est utilisée, les menus peuvent déborder dans un menu d'action:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/02-intro.png)

Si l'échelle du navigateur est définie sur une grande taille ou si une petite taille d'écran est utilisée, tous les menus peuvent apparaître dans un menu déroulant comme ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/03-intro.png)
Les formes, le texte et les légendes peuvent être ajoutés, le texte peut être mis en surbrillance, des mesures peuvent être prises et vous pouvez dessiner à main levée.
Tout cela peut être enregistré ultérieurement dans les sujets.
Cliquez [ici](https://support.catenda.com/en/articles/10209740-saving-a-markup) pour en savoir plus sur l'enregistrement des annotations.

## 1. **Menu**

Voici à quoi peut ressembler le menu de la barre d'outils:

![Télécharger Entrer en plein écran Enregistrer sous Imprimer Paramètres](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/04-menu.png)

### 1.1 **Télécharger**

Cliquez sur Télécharger pour télécharger le document avec toutes les annotations actives dans l'aperçu du document.

### 1.2 **Entrer en plein écran**

Cliquez sur Entrer en plein écran pour ouvrir uniquement l'aperçu du document et la barre d'outils en plein écran. Appuyez sur Échap ou ouvrez à nouveau le même menu pour trouver le bouton Quitter le plein écran.

### 1.3 **Enregistrer sous**

Avec le menu Enregistrer sous, tout type de fichier 2D prévisible peut être enregistré en tant que fichier reconstruit. La boîte de dialogue Enregistrer sous peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/05-save-as.png)

**Nom de fichier** Entrez le nom que le fichier enregistré recevra.

**Type de fichier** Enregistrez tout type de fichier 2D prévisible en tant que PDF (\*.pdf) ou PNG (\*.png)

**Plage de pages** Choisissez les pages à inclure. Les options incluent:

Tout - Défaut Enregistrer toutes les pages

Pages spécifiées Enregistrez des pages spécifiques par numéro de page séparé par une virgule ou avec un tiret pour enregistrer une plage de pages comme par exemple (1, 3, 5-10).

Page actuelle Enregistrer uniquement la page actuelle

**Propriétés** Inclure les annotations - Défaut Inclure une page séparée dans le document téléchargé avec un aperçu des annotations du document et leur contenu.

Inclure les commentaires Inclure une page séparée dans le document téléchargé avec un aperçu des commentaires du document et leur contenu.

Cliquez sur Imprimer pour ouvrir la boîte de dialogue Paramètres d'impression. La boîte de dialogue Paramètres d'impression peut ressembler à ceci:

## 3. **Zoom de sélection**

Voici à quoi peut ressembler l'icône de zoom du document:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/11-marquee-zoom.png)

Avec le zoom du document sélectionné, cliquez n'importe où dans le document pour zoomer dans cette direction. Vous pouvez également cliquer et glisser pour marquer une partie du document que vous souhaitez agrandir. Maintenez Ctrl ou Cmd enfoncé pour zoomer en arrière à la place. Vous verrez votre curseur se transformer en loupe avec un + ou - indiquant votre direction de zoom.

## 4. **Pourcentage de zoom**

Cliquez sur le pourcentage de zoom pour ouvrir le menu du pourcentage de zoom. Le menu du pourcentage de zoom peut ressembler à ceci:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/12-zoom-percentage.png)

### 4.1 **Adapter à la largeur**

Adapter le document pour couvrir toute la largeur de l'aperçu du document

### 4.2 **Adapter à la page**

Adapter le document pour afficher la page actuelle complète sur laquelle vous vous trouvez dans l'aperçu du document.

### 4.3 **Augmenter et diminuer le zoom**

Cliquez sur les boutons plus et moins à côté du pourcentage de zoom pour augmenter/diminuer d'un niveau.

## 5. **Déplacer la vue**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/13-pan.png)

Relâcher la barre d'espace sélectionnera votre outil précédent une fois de plus.

Voici à quoi peuvent ressembler les outils du menu Insérer:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/wvb4pp2v/20-insert-menu.png)

**Tampon en caoutchouc** Voici à quoi ressemble le menu des présets de tampon en caoutchouc par défaut:

Cliquez [ici](https://support.catenda.com/en/articles/11678493-document-preview-tools-rubber-stamp) pour en savoir plus sur le menu des tampons en caoutchouc.

_Image - Raccourci:_ (I) Sélectionnez l'outil Image et cliquez n'importe où dans le document pour ajouter une image à cet emplacement.

Les exemples d'images insérées incluent:

- Informations générées avec métadonnées.
  Dans certains flux de travail, les images sont générées avec des informations sur l'utilisateur qui a consulté le document ainsi que certaines informations comme la date et son domaine d'études.
- Un logo personnel ou d'entreprise.
  Dans certains cas, le logo d'une entreprise est inséré en tant qu'image pour indiquer que cette entreprise a consulté le document.
- Une signature personnelle
  Parfois, c'est une numérisation d'une signature manuscrite, d'autres fois, il peut s'agir d'une signature générée numériquement.
- Un cachet personnel.
  Dans certaines cultures, les timbres sont préférés aux signatures

Après avoir cliqué sur l'emplacement d'insertion, l'explorateur de fichiers système s'ouvrira. Accédez à l'image à insérer et sélectionnez-la. Après avoir sélectionné l'image, elle sera placée à l'emplacement spécifié.

Bien que l'image puisse inclure une signature qui peut même être générée numériquement, l'image choisie est insérée en tant qu'image bitmap qui n'est pas protégée cryptographiquement par une clé privée pour former une signature électronique. Cliquez [ici](https://en.wikipedia.org/wiki/Electronic_signature) pour en savoir plus sur les signatures électroniques.

Sélectionnez l'image placée pour: Déplacer - Glisser sur l'image Mettre à l'échelle - Glisser sur le coin de l'image Faire pivoter - Glisser sur la poignée de rotation Dupliquer - Maintenez Alt et glissez sur l'image pour la dupliquer Supprimer - Cliquez sur la poubelle ou appuyez sur Supprimer pour supprimer l'image

Précision Le nombre de nombres après la décimale que vous souhaitez afficher

Unités fractionnelles. Basculez ce basculement pour afficher les quantités de mesure en unités fractionnaires à la place.
