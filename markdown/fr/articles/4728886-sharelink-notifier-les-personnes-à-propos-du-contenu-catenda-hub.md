# ShareLink - Notifier les personnes à propos du contenu Catenda Hub

> Notifiez manuellement les utilisateurs si nécessaire et important.

Trouvez le bouton sharelink vers le [haut à droite de la page](https://support.catenda.com/en/articles/4670260-landing-page#h_7e60f1b700) à côté de votre photo de profil.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/01-intro.png)

Si vous êtes sur la page principale avant d'entrer dans un projet, le bouton sharelink sera grisé. Il est uniquement possible de partager des pages depuis l'intérieur d'un projet.

## 1. **Notifier les utilisateurs**

Vous avez déjà voulu notifier un membre du projet à propos d'un document, de certains sujets ou d'un autre contenu dans Catenda Hub, sans quitter Catenda Hub ? Ou peut-être que les utilisateurs ont désactivé leurs notifications Catenda Hub ? Cette fonctionnalité résout ces problèmes.

ShareLink envoie un e-mail de Catenda Hub aux membres du projet que vous choisissez avec un lien vers le contenu que vous souhaitez partager.

> **Remarque :** Les utilisateurs recevront toujours une notification concernant un lien qui leur est partagé de cette manière. Même s'ils ont désactivé leurs notifications.

### 1.1 **Pour utiliser ShareLink :**

1. Sélectionnez d'abord jusqu'à 100 éléments de contenu que vous souhaitez partager.

Par exemple, certains documents ou sujets.

Un destinataire sharelink ne verra alors que ces éléments. Si la page est partagée avec un destinataire sharelink, il verra la page entière, y compris les filtres, en fonction de son accès au projet.

1. Cliquez sur le bouton ShareLink.
   ​

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/02-to-use-sharelink.png)

## 2. **Fenêtre ShareLink**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/03-sharelink-window-br.png)

### 2.1 **Destinataires**

Sélectionnez les membres du projet auxquels vous souhaitez envoyer le message. Vous pouvez sélectionner les équipes en tapant @. Vous pouvez également envoyer facilement un message à tous les utilisateurs d'un projet de cette façon.

> **Remarque :** Si vous cliquez et faites glisser en dehors de la zone des destinataires, vous pouvez sélectionner tous les destinataires. Ceci est très utile si vous souhaitez copier les e-mails de tous les utilisateurs du projet. Le champ destinataire peut être copié et collé dans le champ destinataire À : de n'importe quelle application de messagerie.

### 2.2 **Sujet**

Modifiez le titre du message en fonction de la raison du partage du contenu

### 2.3 **Message**

Écrivez votre propre message dans le corps du message.

### 2.4 **Contenu partagé**

L'URL que vous allez envoyer est disponible ici à vérifier.

### 2.5 **Capture d'écran**

Si vous souhaitez vous assurer que l'utilisateur sait à quoi s'attendre en cliquant sur le lien, vous pouvez ajouter une capture d'écran du lien que vous partagez. Dans ce cas, l'image suivante sera jointe à la notification par e-mail sharelink :

![Capture d'écran du contenu partagé](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/04-screenshot.png)

## 3. **Envoyer le message**

Le message est envoyé de [noreply@catenda.com](mailto:noreply@catenda.com) aux destinataires que vous avez choisis à l'étape 1. Vous recevez un message CC à votre propre adresse e-mail.

Le message e-mail peut ressembler à ceci si vous avez ajouté une capture d'écran :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/05-send-the-message.png)

## 4. **Accéder au contenu**

1. Cliquez sur ce lien, Catenda Hub ouvrira une page avec les éléments partagés.

ou

1. Copiez cette URL dans votre navigateur.

Lorsque le lien est suivi, seuls les éléments sélectionnés sont affichés :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e1zqszw1/06-accessing-the-content.png)

Les éléments sélectionnés fonctionnent pour les sujets ainsi que pour les documents.
