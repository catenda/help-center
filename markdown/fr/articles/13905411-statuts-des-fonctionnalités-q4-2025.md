# Statuts des fonctionnalités Q4 2025

Pour éviter les notifications indésirées et assurer un lancement en douceur, les nouveaux comportements ou les modifications des comportements existants peuvent être déployés progressivement et sans préavis. Ceux qui remarquent des changements de comportement dans une partie d'une page qu'ils utilisent fréquemment ou ceux qui se demandent quoi de neuf peuvent consulter ces articles pour les mises à jour sur les changements récents de comportement pour tous les utilisateurs.

## 1. **Activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être activées pour les projets existants par la personne de contact de votre licence Catenda, tandis que d'autres peuvent être activées avec un paramètre du projet. Lorsqu'une nouvelle fonctionnalité est demandée à être activée, une réunion sera organisée avec un représentant du support pour discuter du Statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la nouvelle fonctionnalité peut être testée, un projet fictif sera créé pendant une durée limitée où la nouvelle fonctionnalité peut être testée.

### 1.1 **Demande d'activation des fonctionnalités à la demande**

Certaines fonctionnalités peuvent être activées pour les projets existants par la personne de contact de votre licence Catenda, tandis que d'autres peuvent être activées avec un paramètre du projet. Lorsqu'une fonctionnalité à la demande est demandée à être activée, une réunion sera organisée avec un représentant du support pour discuter du Statut actuel de la fonctionnalité. Si un projet n'est pas déjà disponible où la fonctionnalité à la demande peut être testée, un projet fictif peut être créé pendant une durée limitée où la fonctionnalité à la demande peut être testée pour déterminer si la fonctionnalité est prête à être utilisée.

### 1.2 **Nouveau workflow de Statut et nouveau workflow de validation**

Le nouveau workflow de Statut n'a plus besoin d'être demandé à être activé et est désormais disponible à la fois pour les nouveaux utilisateurs et peut être activé pour les projets qui utilisent actuellement le workflow de Statut hérité en activant les révisions partagées dans les paramètres des Documents.

### 1.3 **Page Objets**

Recherchez n'importe quel contenu de votre IFC avec logique. La page Objets est une fonctionnalité à la demande qui peut être demandée à être activée pour les projets en cours. Les nouveaux projets créés sur la base d'un project model où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Par exemple, toutes les "entités Portes" du "Modèle A" qui sont plus hautes que 2 mètres. Configurez les colonnes pour afficher les propriétés pertinentes pour chaque élément de ligne du tableau. Si les résultats du Filtre ont un objet dans la Visionneuse 3D, cet objet peut être sélectionné en 3D. Exportez les éléments sélectionnés avec les colonnes de propriété configurées qui s'affichent dans Excel. Similaire à la fonctionnalité QTO, les objets sélectionnés en 3D peuvent également être filtrés. Comparé à la fonctionnalité QTO, il n'y a aucun problème à charger des milliers de lignes dans le tableau.

### 1.4 **Éditeur de rapports**

Créez des modèles de rapport pour les Sujets et les Documents afin que les Membres du projet puissent sélectionner les Sujets ou les Documents du tableau et utiliser l'action de rapport pour générer un rapport. La page Rapports est une fonctionnalité à la demande qui peut être demandée à être activée pour les projets en cours. Les nouveaux projets créés sur la base d'un project model où cette fonctionnalité est activée n'ont pas cette fonctionnalité activée. Des modèles distincts peuvent être créés pour les Sujets et les Documents. Lorsqu'un modèle est disponible dans un projet, l'action de rapport peut être utilisée avec les Sujets et les Documents sélectionnés pour générer un rapport basé sur le modèle sélectionné. Le support pour l'affichage de différentes valeurs sur la page est offert par Catenda. Si vous souhaitez un rapport personnalisé adapté à votre entreprise, nous pouvons vous mettre en contact avec un consultant qui peut vous aider.
