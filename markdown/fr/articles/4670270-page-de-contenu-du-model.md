# Page de contenu du model

Pour voir un aperçu des revisions dans un model, accédez à la [page des models](https://support.catenda.com/en/articles/4670286-models-page), et cliquez sur un model. Vous serez alors dirigé vers la page d'aperçu qui appartient à ce model. L'aperçu des revisions du model nous montre les revisions du model présentes dans le projet. En cliquant sur une revision du model, vous serez dirigé vers la page des revisions. Vous pouvez ensuite cliquer sur « Importer » et télécharger une nouvelle revision du model.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/01-intro.png)

## 1. **Actions sur les éléments existants**

L'action suivante peut être vue en haut à droite de la page d'aperçu du model.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/02-existing-item-actions.png)

Les actions suivantes se trouvent pour chaque revision.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/03-existing-item-actions.png)

Cliquez [ici](https://support.catenda.com/en/articles/9674157-actions-on-the-model-overview-page) pour en savoir plus sur ce que chaque action effectue.

## 2. **Menu d'information à droite**

Vous pourrez trouver des informations sur le model dans son menu d'information à droite. Ce menu est accessible en cliquant sur l'icône « i » en haut à droite de la page. Cliquez [ici](https://support.catenda.com/en/articles/9673735-right-menu-on-the-models-page) pour en savoir plus sur le type d'informations sur le model disponibles.

## 3. **Nom du model**

Cliquez sur l'icône en forme de crayon pour modifier le nom du model

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/04-model-name.png)

## 4. **Revisions**

### 4.1 **Importation de revision**

S'il n'y a pas encore de revisions dans votre model, vous pourrez cliquer sur parcourir pour importer votre première revision.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/05-revision-import.png)

Vous pouvez également glisser et déposer pour importer une nouvelle revision ou utiliser l'action de nouvelle revision dans le menu des actions sur les éléments existants. _Accès requis :_ charger des revisions de model à partir de [paramètres du projet](https://support.catenda.com/en/articles/4670273-project-settings-page#h_f82a1850f3)

Pour ce faire, choisissez un fichier IFC sur votre disque dur. Bien que d'autres types de fichiers puissent être prévisualisés dans la section Documents, seuls les fichiers IFC sont acceptés dans la section des models. Cliquez sur « envoyer » pour démarrer le processus de téléchargement.

Une fois le processus terminé, Catenda Hub analyse le fichier IFC et génère la géométrie en arrière-plan. Pour les grands models, il peut s'écouler un certain temps avant que le fichier soit prêt à être utilisé dans la Visionneuse. Si vous le souhaitez, vous pouvez quitter Catenda Hub, la génération de géométrie continue sans interruption de toute façon. À la fin de l'importation, une Notification s'affichera dans la barre de menu de Catenda Hub et un e-mail vous sera également envoyé indiquant qu'une nouvelle version a été téléchargée vers un model auquel vous avez accès.

### 4.2 **Afficher les commentaires**

Par le passé, vous pouviez ajouter des commentaires (brève explication aux participants du projet sur les nouveautés de la revision en cours de téléchargement) aux revisions du model. Si ces commentaires ont été ajoutés, vous pourrez toujours les voir en cliquant sur afficher les commentaires.

### 4.3 **Ouvrir la revision dans la Visionneuse**

Il est possible d'ouvrir des models spécifiques en 2D et 3D en cliquant sur leurs boutons respectifs.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/06-open-revision-in-viewer.png)

### 4.4 **Téléchargement d'une revision**

Cliquez sur le bouton de téléchargement pour télécharger la dernière revision d'un model.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/e4cn8nk3/07-downloading-a-revision.png)

_Accès requis :_ Accès en lecture au document-model

## 5. **Déchargement d'un model**

Lorsque vous ouvrez Catenda Hub, vous commencez avec une mémoire vierge. Dès que vous chargez un model en 3D, qu'il s'agisse de la section des models, de la section Documents ou du sélecteur de revision de la Visionneuse 3D, le model sera en mémoire. Même si vous fermez la Visionneuse 3D ou cliquez sur 3D pour désactiver le model à nouveau. Cela signifie que si vous cliquez sur 3D la prochaine fois, votre model s'activera beaucoup plus rapidement ! La première fois, il peut prendre un certain temps pour charger en mémoire, mais vous pouvez ensuite facilement l'activer et le désactiver. Le model restera en mémoire jusqu'à ce que vous actualisiez la page, à laquelle tous les models sont déchargés.

Un inconvénient de cela est que, comme vous l'avez remarqué dans de nombreux projets japonais intensifs, le navigateur ne peut pas toujours gérer le chargement de tous ces models en mémoire. Si vous remarquez que les performances se ralentissent parce que votre navigateur approche de la limite de mémoire, vous pouvez ouvrir l'aperçu du model pour les models que vous avez précédemment désactivés et voir le message suivant : « Ce model est masqué mais toujours chargé en mémoire. Pour libérer de la mémoire, cliquez ici pour décharger le model : » Vous pouvez cliquer sur décharger dans le message de votre capture d'écran.

Il peut être difficile de se souvenir des models que vous avez chargés précédemment et il est assez rapide de charger des models, donc si vous êtes proche de la limite, je vous recommande d'actualiser la page et d'ouvrir les models que vous souhaitez au lieu d'aller dans chacun et de les décharger.
