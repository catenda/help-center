# Page de demande de validation ouverte ou fermée

Lorsque les révisions partagées sont activées dans un projet, la [page de validations](https://support.catenda.com/en/articles/12495047-approvals-page) devient disponible. Les Membres qui font partie des Équipes de soumissionnaires pour les circuits de validation dans le projet peuvent [soumettre une demande de validation](https://support.catenda.com/en/articles/12495005-creating-a-new-approval-request) au nom d'une Équipe de soumissionnaires. Trouvez les demandes de validation soumises sur la page des demandes de validation ou dans le menu des validations du menu droit d'un Document. Voici à quoi peut ressembler une page de validation pour les projets qui ont activé les révisions partagées après le 2 octobre 2025 :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/01-intro.png)

_Accès requis :_ L'un des éléments suivants quel que soit le Statut d'administrateur :

- Membre de l'Équipe de soumissionnaires qui a été sélectionnée dans la liste des Équipes de soumissionnaires possibles pour le circuit de validation sélectionné au nom duquel le Membre soumissionnaire a soumis la demande de validation.
- Membre d'une Équipe d'examinateurs qui est configurée pour examiner l'une des étapes du circuit de validation sélectionné dans la demande de validation.
- Membre de l'Équipe d'éditeur qui est configurée pour soumettre la validation finale pour le circuit de validation sélectionné dans la demande de validation.

Les demandes de validation peuvent être soumises sur la page des validations ou toute demande de validation en brouillon qu'ils ont créée précédemment peut être soumise à partir de leur page de brouillon de validation. Les projets dont les révisions partagées ont été activées avant le 2 octobre 2025 verront à la place la page de demande de validation héritée. Il n'est possible de créer un projet basé sur un projet de modèle que si le circuit de validation hérité est activé dans ce projet de modèle.

## 2. **En-tête de validation**

Voici à quoi peut ressembler l'en-tête de validation dans une validation ouverte :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/fp42emf8/03-approval-header.png)

Une fois que le créateur de la validation a soumis la validation dans la boîte de dialogue créer une demande de validation ou à partir d'un brouillon, il n'est plus possible de modifier l'en-tête de validation.

### 2.1 **Titre**

Le titre de la demande de validation ouverte ou fermée.

### 2.2 Circuit de validation

Le circuit de validation qui est sélectionné lors de la création de cette validation _Accès requis :_ Soumissionnaire de validation

### 2.3 **Description**

La description de la validation.
