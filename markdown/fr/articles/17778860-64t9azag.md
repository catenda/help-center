# À propos de Catenda pour Power BI (On Demand)

> Catenda pour Power BI apporte les données de projet Catenda Hub dans Power BI. Une version suivante, avec des visuels et un modèle de rapport prêt à l'emploi, est disponible à la demande.

Catenda pour Power BI apporte les données d'un projet Catenda Hub dans Microsoft Power BI, pour des rapports sur les modèles, documents et Sujets du projet. Le [Connecteur Catenda Power BI](https://support.catenda.com/fr/articles/5784721-connecteur-catenda-power-bi) publié est disponible pour chaque client Catenda. Une version suivante est disponible à la demande : elle peut être demandée avant sa sortie à tous.

## 1. **Qu'est-ce que c'est**

La version suivante est dotée d'un nouveau connecteur qui apporte beaucoup plus de données d'un projet dans Power BI, de visuels qui affichent les modèles et Sujets d'un projet dans un rapport, et d'un modèle de rapport prêt à l'emploi. Il est encore en évolution, il est donc proposé à titre d'essai plutôt que pour des rapports qui doivent durer.

## 2. **Commencer**

Catenda pour Power BI fonctionne avec des projets dans Catenda Hub. Pour l'utiliser, contactez les ventes de Catenda pour commencer avec un premier projet : [https://catenda.com/get-started](https://catenda.com/get-started) ou [sales@catenda.com](mailto:sales@catenda.com).

> **Remarque :** Plus est disponible pour les clients Catenda. Connectez-vous à Catenda sur [https://hub.catenda.com](https://hub.catenda.com), puis ouvrez ou rechargez une page du Centre d'aide. Le Centre d'aide affiche alors plus aux clients connectés, en commençant par [Introduction to Catenda for Power BI (On Demand)](https://support.catenda.com/fr/articles/17778865-introduction-a-catenda-pour-power-bi-a-la-demande) _(clients connectés uniquement)_.
