# Comment puis-je exporter des IFC ?

Vous pouvez exporter un fichier IFC en accédant à **Models** (1) puis en choisissant le bouton **Exports** (2).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/01-intro.png)

Sur la page suivante, vous pouvez voir l'historique des téléchargements précédents et les retélécharger individuellement.

Si vous souhaitez fusionner plusieurs modèles en un seul fichier, une "Nouvelle exportation" doit être créée.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/02-intro.png)

L'étape suivante consiste à choisir les options d'exportation. Choisissez d'archiver le fichier en tant que fichier .zip ou .xls Puis choisissez quels modèles et quelles révisions de ces modèles seront inclus dans l'exportation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/03-intro.png)

Pour exporter, faites défiler la page vers le bas et trouvez le point numéro 6.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3gv5z5st/04-intro.png)
