# Télécharger un document

Dans la section Documents, vous pourrez télécharger des fichiers dans des dossiers. Dans Catenda Hub, les Documents sont des conteneurs pour différentes versions (révisions) d'un fichier. Choisissez de créer un nouveau Document ou de télécharger le fichier en tant que révision d'un Document existant lors du téléchargement d'un fichier.

## 1. **Téléchargement d'un fichier**

Les fichiers peuvent être téléchargés de quatre façons différentes. Le fichier se retrouvera dans le dossier dans lequel vous vous trouvez avec chaque méthode de téléchargement.

### 1.1 **1. Bouton de téléchargement**

Pour télécharger un nouveau Document ou une révision, appuyez sur le [bouton +](https://support.catenda.com/en/articles/4670288-actions-in-the-document-structure#h_7c8e07223e) en haut à droite. Cela ouvrira le [menu de téléchargement de Document](#h_00fa77db3e).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y90qfgry/01-1-upload-button.png)

Le téléchargement d'un fichier de cette manière vous permettra de choisir si vous souhaitez une nouvelle révision ou un nouveau Document.

### 1.2 **2. Bouton nouvelle révision**

Avec un Document sélectionné dans la structure du Document, l'[action nouvelle révision](https://support.catenda.com/en/articles/4670288-actions-in-the-document-structure#h_5785139ce3) se trouve dans le [menu hamburger d'élément sélectionné](https://support.catenda.com/en/articles/4670288-actions-in-the-document-structure#h_fb4e9ef375) vers le haut du tableau des Documents. Dans un aperçu du Document, l'[action nouvelle révision](https://support.catenda.com/en/articles/9323521-actions-in-a-document#h_c18a9b8abf) dans le [menu hamburger d'élément existant](https://support.catenda.com/en/articles/9323521-actions-in-a-document) vers le haut à droite de la page peut être utilisée. Le téléchargement d'un fichier de cette manière créera une nouvelle révision et non un nouveau Document.

### 1.3 **3. Glisser-déposer**

Pour télécharger un fichier, naviguez simplement vers le dossier où vous souhaitez le télécharger et glissez-déposez-le n'importe où dans la section Documents. Lorsque le fichier est prêt à être déposé, vous verrez la section Documents devenir grise avec une bordure pointillée autour, indiquant que le fichier peut être déposé. Choisissez de créer une nouvelle révision ou un nouveau Document lors du téléchargement de cette manière.

### 1.4 **4. Bouton Parcourir dans un dossier vide**

Cliquez sur le bouton Parcourir dans un dossier vide pour ouvrir le [menu de téléchargement de Document](#h_00fa77db3e). Choisissez de créer une nouvelle révision ou un nouveau Document lors du téléchargement de cette manière.

## 2. **Menu de téléchargement de Document**

Après le téléchargement des fichiers, ils apparaîtront dans le dossier actuel lors du téléchargement.

### 2.1 **Parcourir**

En cliquant sur le bouton « Parcourir », l'explorateur de fichiers du système s'ouvre et à partir de là, vous pouvez choisir les fichiers à télécharger. Jusqu'à 100 fichiers peuvent être sélectionnés, [chacun jusqu'à 7 GB\*](#h_09bc8fbe94), en maintenant Maj ou Ctrl enfoncés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y90qfgry/02-browse.png)

### 2.2 **Glisser & déposer**

Jusqu'à 100 fichiers peuvent être glissés et déposés, [chacun jusqu'à 7 GB\*](#h_09bc8fbe94), à partir de l'explorateur de fichiers sur votre système.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y90qfgry/03-drag-drop.png)

### 2.3 **Dossiers**

Dans ce menu, seuls les Documents uniques peuvent être téléchargés. Pour télécharger un dossier, il doit être compressé et téléchargé d'une autre manière. Consultez l'article [Télécharger un zip](https://support.catenda.com/en/articles/7945410-upload-a-zip-folder-structure).

### 2.4 **Limite de téléchargement**

**Limites pour les fichiers uniques :** Jusqu'à 100 fichiers peuvent être téléchargés à la fois Jusqu'à 7 GB par fichier peuvent être téléchargés à la fois.

**Limites pour les fichiers compressés :** Pour télécharger plus de fichiers à la fois ou des fichiers de plus grande taille, veuillez utiliser la fonction « [télécharger un zip](https://support.catenda.com/en/articles/7945410-upload-a-zip-folder-structure) ».

**Limites pour les nuages de points :** Les nuages de points ont souvent des tailles de fichiers importantes, leur limite a donc été augmentée à 25 GB Cliquez [ici](https://support.catenda.com/en/articles/4670324-is-there-a-size-limit-for-ifc-files) pour en savoir plus sur les limites de taille.

## 3. **Connecteur de bureau**

Avec le [Connecteur de bureau Catenda](https://support.catenda.com/en/articles/8358861-catenda-desktop-connector), les dernières versions des Documents peuvent être téléchargées automatiquement et périodiquement d'un système local vers Catenda Hub. Le Connecteur de bureau est à la fois plus rapide que le processus de téléchargement régulier et minimise le risque d'échec car il télécharge les Documents fichier par fichier au lieu d'un grand lot de glisser-déposer ou de téléchargement de zip.

## 4. **Aperçu du Document**

Pour voir si vous pourrez visualiser le contenu de votre type de fichier sur Catenda, cliquez [ici](https://support.catenda.com/en/articles/4670320-what-file-types-does-catenda-support).

## 5. **Vérification des virus**

Après le téléchargement d'un Document, les Documents inférieurs à 200 Mo seront vérifiés pour les virus. Si un Document téléchargé s'avère infecté, une notification sera envoyée à tous les utilisateurs. Le seul moyen de désactiver ce type de notification est de désactiver toutes les Notifications. Vous pouvez voir si un Document est infecté si un texte rouge apparaît sous le nom du Document dans le panneau d'informations de droite du Document.
