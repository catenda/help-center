# Page de Template topic - Hérité

La page de Template topic se trouve en cliquant sur une carte de Template topic sur la [page Templates topic](https://support.catenda.com/en/articles/12367730-topic-templates-page). _Accès requis_ : Administrateur

Voici à quoi la page de Template topic peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3hd924wy/01-intro.png)

Les topics suivants sont décrits dans cet article :

## 1. **Actions sur la page de Template topic**

Les actions de la page Templates topic se trouvent en cliquant sur le menu d'action à droite du bouton plus vert en haut à droite de la page Templates topic. Voici à quoi les actions de la page Templates topic peuvent ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3hd924wy/02-actions-on-the-topic-template-page.png)

### 1.1 **Nouveau Template topic**

Cliquez [ici](https://support.catenda.com/en/articles/12372007-creating-a-new-topic-template) pour en savoir plus sur la création de nouveaux Templates topic.

## 2. **Template topic**

Voici à quoi un Template topic peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/3hd924wy/03-topic-template.png)

### 2.1 **Modifier**

Cliquez sur Modifier pour modifier le Template topic. Cliquez ici pour en savoir plus sur la modification des Templates topic.

### 2.2 **Archiver**

Cliquez sur Archiver pour archiver le Template topic.

### 2.3 **Restaurer**

Cliquez sur Restaurer pour restaurer un Template topic archivé.

## 3. **Nouveau flux de validation**

La page de Template topic n'est pas disponible pour les projets commençant par le nouveau flux de validation.
