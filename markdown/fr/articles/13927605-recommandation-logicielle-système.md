# Recommandation logicielle système

Les systèmes d'exploitation sont ce qui se situe entre l'application où Catenda est accédée et le matériel qui fait fonctionner tout.

## 1. **Carte graphique dédiée vs GPU intégré**

Si un appareil dispose à la fois d'un GPU dédié et d'un GPU intégré qui fait partie du CPU, assurez-vous que le GPU dédié du système est utilisé et non le GPU intégré qui fait partie du CPU qui est souvent moins puissant. Les appareils mobiles basculrent souvent vers le GPU intégré qui fait partie du CPU quand aucun adaptateur d'alimentation n'est connecté. Suivez les étapes décrites dans [cet article](https://superuser.com/questions/1439471/how-can-i-force-my-dedicated-gpu-to-handle-all-applications-or-disable-my-integr#:~:text=use%20these%20steps%3A-,Open%20Settings.,-Click%20on%20System) pour vous assurer que le GPU dédié est utilisé sur Windows 10 et Windows 11 même quand l'adaptateur d'alimentation n'est pas connecté. Notez que cette méthode peut décharger la batterie de votre appareil plus rapidement.

## 2. **Configuration du moniteur**

Il est recommandé de configurer les paramètres de résolution par défaut et de fréquence de rafraîchissement pour chacun des moniteurs disponibles pour le système d'exploitation.
