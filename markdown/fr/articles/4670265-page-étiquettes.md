# Page Étiquettes

La page des étiquettes se trouve comme sous-page des [paramètres du projet](https://support.catenda.com/en/articles/4670273-project-settings-page) dans le menu de navigation de gauche.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/01-intro.png)

Voici à quoi peut ressembler la page des étiquettes :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/02-intro.png)

## 1. **Boutons supérieurs**

Le bouton vert en haut à droite de la page des étiquettes vous permet de créer une nouvelle étiquette ou un nouveau groupe selon l'onglet actif

### 1.1 Nouvelle étiquette

Avec l'onglet d'étiquette actif, si vous cliquez sur le bouton "Nouvelle étiquette", le menu Ajouter des étiquettes apparaîtra.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/03-new-label.png)

**Couleur** Choisissez la couleur de la nouvelle étiquette

**Groupe** Choisissez le groupe de la nouvelle étiquette (facultatif). Si votre groupe n'existe pas encore, vous pouvez écrire le groupe souhaité dans la liste déroulante du groupe d'étiquettes défini et cliquer sur créer <nom du groupe>. Vous pouvez également créer et modifier des groupes dans l'onglet des groupes.

**Étiquette** Choisissez un nom d'étiquette

**Importer plusieurs** Copiez un tableau comportant jusqu'à trois colonnes à partir d'Excel. Chaque ligne correspond à un nom d'étiquette, un groupe et une couleur.

Exemple :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/04-new-label.png)

Coller le texte suivant à partir d'Excel donnera :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/05-new-label.png)

> **Remarque :** Si vous ne spécifiez pas de couleur aux étiquettes, elles obtiendront la couleur spécifiée dans la liste déroulante des couleurs.

Les étiquettes seront séparées par "virgule" ou "nouvelle ligne". Les noms de groupe par étiquette seront divisés par "tab", "colon", "point-virgule" ou "pipe". Les étiquettes sont écrites comme name:groupname:color. Les étiquettes seront séparées par **"virgule"** ou **"nouvelle ligne"**.

`Electrical,Architecture`

Un troisième argument peut spécifier une couleur hexadécimale.

`Electrical:Trade,Architecture::#00ff00`

deviendra

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/08-new-label.png)

Les groupes et les couleurs sont facultatifs. Définissez une valeur par défaut pour écraser les espaces vides.

Erreur Si une étiquette contient une erreur, elle s'affichera en rouge.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/09-new-label.png)

Survolez l'étiquette pour voir ce qui cause l'erreur.

Cela pourrait être : L'étiquette existe déjà dans le projet.

Les noms d'étiquettes doivent être uniques. Si une étiquette existe déjà dans le projet ou si vous essayez d'ajouter une étiquette deux fois, vous devrez la renommer.

Création de nouveaux groupes Si les groupes n'existent pas encore dans le projet, on vous demandera si vous souhaitez créer les nouveaux groupes appropriés ou si vous souhaitez les ignorer.

**Maintenir ouvert à la soumission** Si vous cochez cette case, un nouveau menu d'ajout d'étiquettes s'ouvrira juste après la soumission d'une étiquette. Si vous souhaitez créer plus de trois étiquettes manuellement via ce menu, cette option vous fera gagner du temps car vous n'aurez pas à cliquer sur le bouton de nouvelle étiquette à chaque fois. Si vous créez une ou deux étiquettes, il est tout aussi rapide de cliquer sur le bouton de nouvelle étiquette.

### 1.2 **Nouveau groupe**

Avec l'onglet de groupe actif, si vous cliquez sur le bouton "Nouveau groupe", le menu Ajouter un groupe d'étiquettes apparaîtra.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/exzgaw41/10-new-group.png)

**Groupe d'étiquettes** Choisissez un nom de groupe d'étiquettes

**Maintenir ouvert à la soumission** Si vous cochez cette case, un nouveau menu d'ajout de groupe d'étiquettes s'ouvrira juste après la soumission d'un groupe d'étiquettes. Si vous souhaitez créer plus de trois groupes d'étiquettes manuellement via ce menu, cette option vous fera gagner du temps car vous n'aurez pas à cliquer sur le bouton de nouveau groupe à chaque fois. Si vous créez un ou deux groupes d'étiquettes, il est tout aussi rapide de cliquer sur le bouton de nouveau groupe.

## 2. **Modifier une étiquette**

Sélectionnez une ou plusieurs étiquettes pour remplacer leurs paramètres.

## 3. **Supprimer une étiquette**

Si une étiquette n'est pas connectée à un sujet ou à un document, vous pouvez cliquer sur supprimer dans la colonne la plus à droite.
