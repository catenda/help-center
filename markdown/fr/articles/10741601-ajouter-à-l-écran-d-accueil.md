# Ajouter à l'écran d'accueil

La fonctionnalité complète de Catenda Hub est toujours disponible via le navigateur. Catenda peut être ajouté à l'écran d'accueil, au tableau de bord ou au dock en l'installant via un navigateur. C'est ce qu'on appelle une application web progressive (PWA). Cliquez [ici](https://support.catenda.com/en/articles/10774300-home-screen-system-browser-support) pour voir les navigateurs qui supportent PWA sur votre système.

Les rubriques suivantes sont décrites dans cet article :

## 1. **Avantages**

L'installation de Catenda via un navigateur au lieu de créer un raccourci offre les avantages suivants :

### 1.1 **Systèmes utilisés par plusieurs personnes**

L'installation de Catenda Hub sur votre écran d'accueil vous permet d'accéder à Catenda de la manière principale utilisée pour accéder aux applications sur votre système. Le fait de l'avoir dans une liste d'applications disponibles peut aider les gens à trouver les applications disponibles sur ce système.

### 1.2 **Systèmes à espace écran limité**

L'installation de Catenda Hub en tant qu'application ajoutée à l'écran d'accueil économise de l'espace écran, car la barre du navigateur vers le haut ne sera pas présente. Surtout sur les tablettes, il est agréable d'avoir accès à la fonctionnalité complète de Catenda tout en optimisant l'espace écran.

## 2. **iPhone & iPad - Navigateur recommandé**

Sur les appareils Apple, il est souvent uniquement possible d'ajouter une page à votre écran d'accueil depuis Safari. Accédez à la page que vous souhaitez voir s'ouvrir lorsque vous ouvrez l'application qui sera ajoutée à l'écran d'accueil de votre appareil.

Les rubriques suivantes sont décrites dans cette section :

### 2.1 **Bouton Partager**

Appuyez sur le bouton Partager qui peut ressembler à ceci.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/01-share-button.png)

Le bouton Partager peut apparaître à droite de la barre d'adresse ou vers le bas de la page.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/02-share-button.png)

### 2.2 **Ajouter à l'écran d'accueil**

Dans la liste des options qui apparaissent, faites défiler vers le bas jusqu'à ce que vous voyiez l'action "Ajouter à l'écran d'accueil" et choisissez-la. La boîte de dialogue Ajouter à l'écran d'accueil s'affichera maintenant.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/03-add-to-home-screen.png)

Donnez un nom au raccourci qui apparaîtra sur votre écran d'accueil. Le lien qui sera ouvert s'affiche pour que vous puissiez le confirmer. Vous verrez également l'icône que le raccourci de l'écran d'accueil aura.

### 2.3 **Ajouter**

Cliquez sur "ajouter" lorsque vous avez terminé.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/04-add.png)

Safari se ferme et vous êtes redirigé vers l'endroit où le raccourci est installé sur l'écran d'accueil de votre iPhone ou iPad. Le raccourci Catenda peut ressembler à ceci sur votre écran d'accueil :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/05-add.png)

> **Remarque :** Pour supprimer le raccourci du site Web, supprimez-le comme vous le feriez pour toute autre application sur votre téléphone.

## 3. **Android - Navigateur recommandé**

En installant Catenda en tant qu'application sur votre appareil, vous pouvez l'ajouter à votre écran d'accueil avec le navigateur Chrome. Dans le navigateur Chrome, accédez à la page que vous souhaitez voir s'ouvrir lorsque vous appuyez sur la page qui sera ajoutée à l'écran d'accueil de votre appareil.

Les rubriques suivantes sont décrites dans cette section :

### 3.1 **Menu d'action**

Appuyez sur le menu hamburger (menu d'action avec 3 points en haut à droite)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/06-action-menu.png)

### 3.2 **Ajouter à l'écran d'accueil**

Dans le menu d'action, appuyez sur Ajouter à l'écran d'accueil.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/07-add-to-home-screen.png)

### 3.3 **Installer ou créer un raccourci**

Choisissez soit Installer, soit Créer un raccourci

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/08-install-or-create-shortcut.png)

**Créer un raccourci** Créez un simple raccourci qui ouvrira la page sur laquelle vous avez navigué dans l'application Chrome.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/09-install-or-create-shortcut.png)

_Installer_ (recommandé) Installe la page sur votre écran d'accueil L'installation de Catenda vous donnera la meilleure expérience car vous n'aurez pas de barre Chrome vers le haut. Cela vous permet d'utiliser l'écran entier de votre appareil pour consulter Catenda.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/10-install-or-create-shortcut.png)

Voici à quoi peuvent ressembler le raccourci du navigateur et la page installée sur votre écran d'accueil :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/11-install-or-create-shortcut.png)

### 3.4 **Désinstallation**

Pour supprimer le site Web installé ou le raccourci du site Web, supprimez-le comme vous le feriez pour toute autre application sur votre téléphone.

## 4. **Ordinateur - Navigateur recommandé**

Selon vos besoins, Chrome, Microsoft Edge ou Safari fonctionneront le mieux pour vous.

> **Remarque :** Vous devez disposer des droits appropriés pour pouvoir installer une application sur votre ordinateur.

### 4.1 **Chrome :**

Chrome peut être utilisé car il fonctionne sur de nombreux systèmes d'exploitation comme Windows, MacOS et Linux

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/12-chrome.png)

### 4.2 **Microsoft Edge :**

Microsoft Edge peut être utilisé car de nombreux employeurs vous demandent d'utiliser Microsoft Edge.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/13-microsoft-edge.png)

### 4.3 **Safari :**

Safari est le navigateur recommandé sur le système d'exploitation Mac.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/14-safari.png)

Donnez un nom à votre application et cliquez sur ajouter dans le menu qui s'ouvre.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/sa3rvz1r/15-safari.png)

### 4.4 **Désinstallation**

Pour supprimer le site Web installé ou le raccourci du site Web, supprimez-le comme vous le feriez pour toute autre application sur votre ordinateur.
