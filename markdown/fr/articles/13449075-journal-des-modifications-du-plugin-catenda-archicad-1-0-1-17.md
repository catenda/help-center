# Journal des modifications du plugin Catenda Archicad - 1.0.1.17

Nouvelles fonctionnalités dans 1.0.1.17

Support pour Archicad 29 Il est désormais possible de choisir entre le point de levé et l'origine du projet dans le menu d'action des coordonnées. Les viewpoints sont maintenant lus par rapport au paramètre de coordonnées configuré dans le menu d'action des coordonnées. Support du nouveau flux de travail Statut avec les révisions majeures et mineures publiées et partagées.
