# Filtrage sur la page des approbations

Le panneau de filtre peut être ouvert sur la page des approbations pour les projets qui ont activé les révisions partagées après le 2 octobre 2025 en cliquant sur le bouton de filtre à gauche de la barre de recherche sur la [page des approbations](https://support.catenda.com/en/articles/8349340-approvals-page). Les projets pour lesquels les révisions partagées ont été activées avant le 2 octobre 2025 verront à la place le menu de filtre legacy de la page des approbations.

## 1. **Filtres**

Les filtres suivants sont disponibles sur la page des approbations lorsque le nouveau workflow de validation a été demandé à être activé.

Cliquez sur le bouton de filtre en haut à gauche pour qu'un panneau apparaisse sur le côté gauche. Lorsqu'un filtre est appliqué, l'URL visible dans le navigateur change en conséquence. Dans cet article, les filtres sont affichés comme suit : _Nom du filtre dans le menu_ - `Nom du filtre dans l'URL=Option de filtre dans l'URL`

**Filtre par défaut** Le filtre par défaut n'est initialement pas visible dans l'URL. Lorsque la page est visitée pour la première fois, le filtre suivant est appliqué. Ouvert - `status=open`

### 1.1 **Enregistrer et partager le filtre actuel**

Allez à l'URL d'une page filtrée pour charger cette page avec le filtre appliqué. Les filtres appliqués peuvent être enregistrés vers le haut du menu de filtre. Cliquez [ici](https://support.catenda.com/en/articles/11401493-saving-a-filter-link) pour en savoir plus sur la façon d'enregistrer et de partager les filtres. Notez que contrairement aux autres menus de filtre, il n'est pas possible d'enregistrer des filtres personnels vers le haut du menu de filtre sur la page des approbations.

### 1.2 **Masquer les filtres vides**

Cliquez [ici](https://support.catenda.com/en/articles/8551755-saving-filters) pour en savoir plus sur la limitation des résultats de filtre.

### 1.3 **Statut**

Ouvert - Par défaut - `status=open` Fermé - `status=closed` Brouillon - `status=draft`

### 1.4 **Recherche**

Recherche textuelle - `search=test`

**Contenu pouvant être recherché** Par défaut, le filtre ouvert est appliqué lors d'une recherche textuelle, de sorte que seules les demandes d'approbation ouvertes correspondent. Pour rechercher les demandes d'approbation fermées ou en brouillon, filtrez d'abord sur le statut, puis utilisez la recherche textuelle.

**Capitalisation** La recherche textuelle n'est pas sensible aux caractères majuscules ou minuscules.

**Quantités de caractères** Toute quantité de caractères Le contenu incluant la phrase recherchée est mis en correspondance.

**Espace blanc** Les caractères d'espace blanc au début d'une phrase de recherche sont supprimés pour les correspondances au début du contenu. Les caractères d'espace blanc sont inclus pour les correspondances au milieu du contenu.
