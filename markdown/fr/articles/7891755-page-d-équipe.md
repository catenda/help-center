# Page d'équipe

Il est possible de trouver la page d'une équipe sur le côté droit de la [page des Membres](https://support.catenda.com/en/articles/4670291-members-page).

![](https://raw.githubusercontent.com/catenda/help-center/main/images/bvhrpsv2/01-intro.png)

## 1. Profil d'équipe

Le titre du premier menu de la page des équipes affichera le nom de l'équipe.

Les administrateurs pourront modifier le nom de l'équipe en cliquant dessus.

En cliquant sur le bouton Télécharger l'avatar, vous pourrez télécharger une image de profil d'équipe.

## 2. Membres

Ici, les administrateurs pourront ajouter ou supprimer des Membres de l'équipe un par un.

Un Membre peut également se voir assigné des Équipes lors de son invitation pour être automatiquement assigné à son équipe.

## 3. Supprimer l'équipe

Seuls les administrateurs verront ce menu où ils auront l'option de supprimer l'équipe.

## 4. Sujets

Problèmes assignés à cette équipe

## 5. Révisions

révisions du modèle téléchargées par les Membres de cette équipe.

## 6. Paramètres de permission

Les administrateurs pourront accorder les paramètres d'administrateur à cette équipe.

Gardez à l'esprit que cela remplace les paramètres des Membres, vous pouvez donc toujours voir cet utilisateur comme un Membre ordinaire sur la page des Membres des utilisateurs bien qu'il soit administrateur dans le projet.
