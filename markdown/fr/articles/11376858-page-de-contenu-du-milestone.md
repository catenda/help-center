# Page de contenu du milestone

La page d'un milestone peut être ouverte en cliquant sur un milestone sur la [page des milestones](https://support.catenda.com/en/articles/4670266-milestones-page). Voici à quoi peut ressembler la page d'un milestone:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/yx2925b3/01-intro.png)

## 1. **Actions**

Vous pourrez trouver les actions suivantes en haut à droite de la page d'un milestone:

![](https://raw.githubusercontent.com/catenda/help-center/main/images/yx2925b3/02-actions.png)

### 1.1 **Nouveau milestone**

Cliquez sur le + vert ou sur l'action Nouveau milestone dans le menu d'actions pour créer un nouveau milestone.

### 1.2 **Archiver**

Si votre milestone est actif, vous pourrez l'archiver avec cette action. _Accès requis:_ Administrateur ou Créateur du milestone Les milestones archivés peuvent être trouvés et rétablis avec les actions des milestones archivés sur la [page des milestones](https://support.catenda.com/en/articles/4670266-milestones-page).

## 2. **Rétablir**

Cliquez sur le bouton rétablir bleu en haut à droite pour rétablir ce milestone. _Accès requis:_ Administrateur ou Créateur du milestone

## 3. **Nom**

Le nom du milestone. Cliquez sur le crayon pour modifier le nom. _Accès requis:_ Administrateur ou Créateur du milestone

## 4. **Description**

La description du milestone. Cliquez sur le crayon pour modifier la description. _Accès requis:_ Administrateur ou Créateur du milestone

## 5. **Date d'échéance**

La date d'échéance du milestone. Cliquez sur le menu déroulant de date pour modifier la date d'échéance. _Accès requis:_ Administrateur ou Créateur du milestone

## 6. **Créé par**

Ici, vous verrez le nom de l'utilisateur qui a créé le milestone et la date de création du milestone.

## 7. **Statistiques des sujets**

Pour chacun des tableaux de sujets où il y a des sujets avec ce milestone assigné, vous verrez une statistique qui vous montre la progression du milestone dans ce tableau.

**Pourcentage** Ici, vous verrez le pourcentage de sujets qui ont ce milestone assigné et qui sont fermés dans ce tableau de sujets. Les sujets candidats ne comptent pas vers ce pourcentage.

**Ouvert/fermé/candidat** Ici, vous verrez la quantité de sujets avec des états de statuts ouverts, fermés ou candidats à lesquels ce milestone a été assigné. Cliquez sur le mot ouvert, fermé ou candidat pour voir les sujets connexes dans le tableau de tous les sujets.

**Photo de profil du membre** Vous verrez d'abord le créateur du milestone et la photo non assignée. Pour chaque photo de profil, vous verrez une quantité de sujets. Pour le créateur du milestone et non assigné, cette quantité peut être 0 et sera alors verte. Les autres utilisateurs ne seront visibles que s'ils ont des sujets ouverts auxquels ce milestone a été assigné avec une quantité de sujets ouverts auxquels ils ont été assignés en rouge.
