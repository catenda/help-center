# Limitation des résultats de filtrage

Si vous avez un ensemble de filtres que vous utilisez beaucoup, il est possible de les enregistrer en haut de la barre de filtres. Chaque fois que vous accédez à une page, vous verrez les filtres par défaut. Cela peut être fastidieux de filtrer les bons filtres à chaque fois. Avec les filtres enregistrés, vous pouvez facilement rechercher un ensemble de filtres en un seul clic sans avoir à les saisir à chaque fois.

## 1. **Apparence du filtre**

**Indentation** Lorsque les filtres sont regroupés ensemble, ils sont souvent affichés sous un bouton bascule principal avec des options indentées vers la droite. Le bouton bascule principal active et désactive tous les filtres de ce type. Pour désactiver tous les filtres de ce type, ajoutez d'abord les options restantes au filtre pour que tous soient appliqués, puis basculez le filtre principal pour désactiver tous.

**Boutons bascule** Cochez les boutons bascule du filtre pour affiner la recherche. Un bouton bascule carré signifie que plusieurs filtres de ce type peuvent être appliqués. Un bouton bascule rond signifie qu'un seul filtre de ce type peut être appliqué.

**Exclusion d'autres filtres** Lorsque vous survolez l'un des filtres du panneau de gauche, vous pouvez cliquer sur "uniquement" à droite du filtre pour supprimer les autres filtres précédemment appliqués.

## 2. **Masquer les filtres vides**

Le bouton radio "Masquer les filtres vides" se trouve vers le haut de chaque menu de filtrage. Par défaut, le bouton radio est activé. Les filtres vides décrivent les options de filtre qui correspondent aux résultats du tableau. Par défaut, toutes les options de filtre qui offrent des résultats dans n'importe quelle ligne du tableau sont affichées dans le menu de filtrage. Les options de filtre qui n'ont aucun résultat, par exemple une étiquette qui n'est appliquée à aucune ligne du tableau, ne sont donc pas affichées dans le tableau et peuvent apparaître lorsque le bouton radio est désactivé.

_Résultats de ligne limités par le filtre_ Les filtres appliqués dans un tableau réduisent les lignes résultantes. Avec le bouton radio activé, le menu de filtrage affiche maintenant les options de filtre qui s'appliquent aux lignes du résultat filtré. Il semble que certaines options de filtre, qui étaient auparavant disponibles parce qu'elles s'appliquaient à des lignes qui ne sont plus dans les résultats de recherche, disparaissent, mais c'est simplement un rétrécissement des options. Pour voir aussi les filtres qui ne s'appliquent pas aux résultats filtrés, désactivez le bouton radio "masquer les filtres vides".

## 3. **Enregistrement d'un nouvel ensemble de filtres**

Afin d'enregistrer un filtre, vous devez avoir au moins un filtre activé. Avec un ensemble de filtres activés, cliquez sur le bouton Enregistrer pour enregistrer le filtre actuel. Ce filtre sera disponible la prochaine fois que vous utiliserez Catenda Hub et ne sera pas visible par les autres utilisateurs.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y0zwxw2k/01-saving-a-new-set-of-filters.png)

Les filtres enregistrés ne seront visibles que pour vous et non pour les autres membres du projet.

## 4. **Modification des filtres enregistrés**

Une fois que vous avez enregistré un filtre, vous pouvez cliquer sur éditer pour modifier vos filtres enregistrés.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y0zwxw2k/02-editing-saved-filters.png)

En mode édition, vous pouvez: Éditer le nom du filtre - Icône Crayon Mettre à jour le filtre avec ce qui est actuellement filtré - Icône Actualiser Supprimer le filtre - Corbeille.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/y0zwxw2k/03-editing-saved-filters.png)

N'oubliez pas de cliquer sur Terminé en haut à droite lorsque vous avez terminé.

## 5. **Activation d'un filtre enregistré**

Pour filtrer l'ensemble des filtres enregistrés, cliquez simplement sur votre filtre enregistré dans le menu de filtrage à gauche et vous verrez les filtres apparaître dans la barre de recherche.

## 6. **Partage des filtres enregistrés avec les membres du projet**

Comme mentionné précédemment, les filtres enregistrés ne sont enregistrés que pour vous. Lorsque vous activez le filtre, vous verrez les filtres apparaître dans la barre de recherche. Lorsque vous le faites, l'URL de la page change également pour contenir les filtres. Un moyen facile de partager vos filtres enregistrés avec les utilisateurs est donc d'envoyer la page filtrée dans un message ou via [Sharelink](https://support.catenda.com/en/articles/4728886-sharelink-notify-people-about-catenda-hub-content). Si vous souhaitez que les personnes du projet aient accès à ces filtres sans avoir à les envoyer à chaque membre individuellement, vous pouvez créer un lien dans la [Bibliothèque de liens](https://support.catenda.com/en/articles/4670254-links-library). Ceci est particulièrement utile car le lien avec les filtres peut alors être lié aux sujets et objets.

## 7. **Préférence pour l'expansion et la rétraction des filtres**

Vos préférences pour l'expansion et la rétraction des menus de filtrage sur les différentes pages seront appliquées à tous les projets et enregistrées dans les cookies de votre navigateur. Si vous avez par exemple deux projets ouverts dans le même navigateur et que vous rétracterez le menu des étiquettes sur la page des sujets dans un projet, ce menu sera également rétracté lorsque vous actualiserez la page des sujets de l'autre projet.
