# Plugin Catenda Tekla

> Connecter Catenda Hub et Tekla

> **Remarque :** Le fichier d'installation du plugin se trouve dans [cet article](https://intercom.help/bimsync-arena/en/articles/8396532-catenda-plugins-and-integrations).

## 1. **Installation**

Lorsque le plugin Catenda Revit est installé sur Windows, ses fichiers d'installation apparaissent dans le dossier suivant.

`C:\Program Files\Logic\Catenda for Tekla 2025`

### 1.1 **Désinstallation**

Pour désinstaller le plugin, accédez au menu Windows suivant :

`Paramètres Windows -> Applications -> Applications installées`

Trouvez Catenda for Catenda for Tekla \<Tekla version> dans la liste et cliquez sur le menu d'action sur le côté droit pour désinstaller.

## 2. **Informations importantes :**

Il y a une vue dans Tekla dédiée à Catenda Hub et cette vue doit être utilisée pour créer des problèmes de Tekla à Catenda Hub. Si vous n'utilisez pas cette vue, cela entraînera des incohérences dans les problèmes créés (par exemple, viewpoints, sélection d'objets, etc.)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kvtgs8k1/01-important-info.png)

## 3. **Prise en main**

Après avoir installé le plugin, ouvrez un modèle dans Tekla Structures et cliquez sur l'icône Catenda Hub dans la barre des tâches Catenda Hub.

Connectez-vous avec votre adresse e-mail et votre mot de passe Catenda Hub.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kvtgs8k1/02-getting-started.png)

Cliquez sur « Autoriser l'accès » pour permettre au plugin Tekla d'accéder à votre compte Catenda Hub. Cela ouvrira la vue principale du module complémentaire Catenda Hub.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kvtgs8k1/03-getting-started.png)

Vous pouvez révoquer l'accès à votre compte Catenda Hub à tout moment en accédant à votre [page d'application](https://support.catenda.com/en/articles/6880968-account-page#h_40e031c49a) Catenda Hub sur l'application web Catenda Hub.

## 4. **Liste des sujets**

Sur cette page, vous trouverez le menu principal pour naviguer dans votre projet Catenda, les tableaux de problèmes et les problèmes.

### 4.1 **Interface**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kvtgs8k1/04-interface.png)

1. Sélectionnez votre projet Catenda
1. Sélectionnez un tableau de problèmes dans ce projet
1. Créer un nouveau problème dans le tableau de problèmes actuellement sélectionné
1. Trier les problèmes actuellement affichés
1. Ouvrir le menu du module complémentaire Catenda Hub
1. Rechercher et filtrer les problèmes affichés
1. La liste des problèmes actuellement filtrés dans le tableau de problèmes
1. Actualiser les problèmes

### 4.2 **Sélection du projet et du tableau de problèmes**

La sélection d'un projet Catenda affichera la liste du tableau de problèmes dans ce projet, ce qui vous permettra d'en sélectionner un pour afficher les problèmes correspondants.

### 4.3 **Menu du module complémentaire Catenda Hub**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/kvtgs8k1/05-catenda-hub-add-in-menu.png)

1. Liste des modèles et révisions
1. Paramètres d'exportation pour le chargement IFC sur Catenda Hub
1. Version du plugin Catenda Hub
1. Déconnexion de votre compte Catenda Hub
