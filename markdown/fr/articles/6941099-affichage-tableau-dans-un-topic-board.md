# Affichage Tableau dans un topic board

Cliquez sur Affichage Tableau (**4**) en haut à droite du tableau des topics sur la [page des topics](https://support.catenda.com/en/articles/4670271-topics-page). Par défaut, l'affichage en liste est affiché dans le tableau. La préférence d'affichage du tableau des topics est une préférence globale. Une fois l'affichage préféré sélectionné, les tableaux de topics dans n'importe quel topic board de n'importe quel projet sont affichés dans cet affichage pour l'utilisateur.

Les topics suivants sont décrits dans cet article :

## 1. **Tableau de topics**

Le tableau de topics peut ressembler à ceci lorsque l'affichage du tableau est configuré.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/01-topics-table.png)

Cliquez [ici](https://support.catenda.com/en/articles/11748020-tables-on-catenda) pour en savoir plus sur la façon de travailler avec les tableaux dans Catenda. Dès qu'un topic est créé et que le tableau est chargé, le topic apparaît sous forme de ligne dans le tableau de topics pour l'utilisateur. Notez que le filtre ouvert est activé par défaut et les topics fermés peuvent être masqués jusqu'à ce qu'ils soient filtrés.

Les topics suivants sont décrits dans cette section :

### 1.1 **Modifications apportées lors de la visualisation**

Lorsque des modifications sont apportées à l'un des topics affichés, une notification indiquant que des modifications ont été apportées peut apparaître vers le bas du tableau. Cliquez sur récupérer les modifications dans cette notification pour charger les modifications qui ont été apportées lors de la visualisation des topics. Lors de la récupération des modifications, une animation se joue où les lignes des nouveaux topics glissent dans le tableau et les lignes des topics supprimés glissent hors du tableau.

### 1.2 **Actions d'élément sélectionné**

Après avoir sélectionné une ligne de topic, le menu des actions d'élément sélectionné apparaît vers le haut du tableau de topics. Voici ce à quoi le menu des actions d'élément sélectionné peut ressembler :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/02-selected-item-actions.png)

Cliquez [ici](https://support.catenda.com/en/articles/4670284-actions-in-a-topic-board) pour en savoir plus sur le menu des actions d'élément sélectionné.

### 1.3 **Contenu de la ligne**

Lorsque le tableau est d'abord chargé, jusqu'à 100 lignes sont affichées. S'il y a plus de 100 lignes dans le tableau, faites défiler vers le bas pour charger les 100 lignes suivantes.

**Ligne de topic** Ouvrir le contenu d'une ligne de topic change le tableau pour afficher le contenu de ce topic sur la page des topics.

### 1.4 **Colonnes**

Certaines colonnes du tableau de topics sont activées par défaut tandis que d'autres peuvent être masquées et doivent être activées. En fonction de l'ordre des colonnes configuré, les premières colonnes sont affichées tandis que le tableau peut devoir être défilé horizontalement pour afficher d'autres colonnes activées. ## 2. **Sélection de topics**

### 2.1 **1. Sélection de topics avec la case de sélection**

Cochez une case à cocher pour sélectionner un topic de la liste. Vous pouvez également cliquer n'importe où dans la ligne du topic où il n'y a pas de lien pour le sélectionner.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/03-1-selecting-topics-with-selection-box.png)

**Sélection de ligne** Après avoir sélectionné un topic, vous pouvez `maj + clic` pour sélectionner tous les topics entre les deux.

**Modifier la sélection** Vous pouvez également `Ctrl + clic` pour ajouter/supprimer un topic à la sélection

### 2.2 **2. Sélectionner tout**

Sélectionnez tous les topics dans le/les topic board(s). Lorsque vous ouvrez un topic board, 100 topics sont chargés. Si vous faites défiler vers le bas au-delà de 100 topics, vous chargerez plus de topics. La première fois que vous cochez cette case, vous sélectionnerez tous les topics que vous avez chargés. Si vous avez de nombreux topics dans votre board et que vous ne voulez pas faire défiler pour tous les charger, vous pouvez cliquer sur sélectionner tout dans le filtre qui apparaîtra ensuite après "topics sélectionnés" lorsque vous cochez la case de sélection.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/04-2-select-all.png)

## 3. **6. Liste déroulante Colonnes**

En haut à droite du tableau de topics, vous trouverez la liste déroulante "Colonnes".

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/05-6-columns-dropdown.png)

Avec cette liste déroulante, vous pouvez réorganiser et basculer les colonnes du tableau. Votre préférence pour la réorganisation et le basculement des colonnes sera mémorisée dans les topic boards et les projets et stockée dans votre compte. Cela signifie qu'il conservera cet ordre si vous fermez et réorganisez votre navigateur. Si vous avez accidentellement masqué une colonne en la faisant glisser hors du tableau, vous pouvez la réactiver ici. Par défaut, toutes les colonnes sont activées et dans cet ordre :

## 4. **3. Ligne d'en-tête**

Les topics suivants sont décrits dans cette section :

### 4.1 **Tri**

En cliquant sur l'en-tête d'une colonne, il est possible de trier par cette colonne. Cliquer à nouveau le triera dans l'autre sens. Par défaut, la colonne Créé sera triée. Si vous modifiez votre préférence de tri, elle sera mémorisée jusqu'à la prochaine fois que vous ouvrirez le topic board.

### 4.2 **Glissement des en-têtes de colonne**

Les en-têtes de colonne peuvent être glissés vers la gauche et vers la droite pour être réorganisés. Vous pouvez faire glisser l'en-tête de colonne hors du tableau pour désactiver la colonne. Vous pouvez réactiver la colonne dans la [liste déroulante des colonnes](#h_9e88dec7ef) en haut à droite.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/06-dragging-column-headers.png)

### 4.3 **Largeur de colonne**

Lorsque vous survolez la souris sur la ligne entre deux colonnes, vous pouvez faire glisser pour modifier la largeur d'une colonne. Votre préférence pour la largeur de la colonne sera mémorisée dans les topic boards et les projets et stockée dans votre compte. Il est possible de double-cliquer sur la zone entre deux colonnes pour ajuster automatiquement le texte dans la colonne.

_Changement de curseur_ Vous saurez que vous survolez le bon endroit lorsque votre curseur se transforme en pointeur de redimensionnement

![](https://raw.githubusercontent.com/catenda/help-center/main/images/a4h2jb40/07-column-width.png)
