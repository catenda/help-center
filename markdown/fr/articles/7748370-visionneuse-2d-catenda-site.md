# Visionneuse 2D - Catenda Site

Vous pourrez trouver la visionneuse 2D de Catenda Site sur la [page 2D / 3D](https://support.catenda.com/en/articles/7734138-2d-3d-catenda-site)

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/01-intro.png)

## 1. **Visionneuse 2D**

Dans la visionneuse 2D de Catenda, vous pourrez voir les étages disponibles dans votre projet.

### 1.1 **Sélecteur d'étage**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/02-floor-selector.png)

Sélectionnez l'étage à afficher dans la visionneuse 2D.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/03-floor-selector.png)

Les étages provenant des différents modèles IFC du projet et les étages provenant des bâtiments configurés dans le configurateur d'étages de Catenda Hub sont affichés dans la liste. Les étages qui ne font pas partie d'un bâtiment sont affichés sous l'étage inférieur du dernier bâtiment.

### 1.2 **Apparence de la visionneuse 2D**

Avec les [marqueurs activés](https://support.catenda.com/en/articles/4854537-2d-viewer#h_381a9d4098), tous les Sujets qui ont un emplacement spécifié sur l'étage d'un IFC ou d'un bâtiment configuré sont affichés. Appuyez sur un marqueur pour le sélectionner. Voici à quoi peut ressembler un marqueur sélectionné sur Catenda Site.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/04-2d-viewer-appearance.png)

Une fois sélectionné, le numéro et le titre du Sujets sont affichés. Appuyez sur la flèche pour ouvrir le Sujets dans le menu des Sujets. Cliquez [ici](https://support.catenda.com/en/articles/4854523-2d-location-of-issues) pour en savoir plus sur l'emplacement 2D des Sujets.

> **Avertissement 1 :** Lorsque le menu des Sujets est ouvert, les marqueurs des 250 premiers Sujets du résultat sont mis à jour et stockés. Lorsque la visionneuse 2D est ouverte, les marqueurs de tous les Sujets précédemment mis à jour qui correspondent au résultat du menu des Sujets sont affichés. Notez que les marqueurs des Sujets peuvent être répartis sur d'autres étages que l'étage actif. **Avertissement 2 :** Lorsqu'il y a 250+ Sujets dans le résultat du menu des Sujets, les marqueurs peuvent ne pas avoir été chargés ou peuvent être obsolètes. Faites défiler la liste pour afficher/mettre à jour leurs marqueurs également. Le filtrage du tableau pour qu'il y ait moins de Sujets dans le résultat peut également aider à garantir que les marqueurs appartenant aux Sujets du résultat filtré sont également mis à jour et affichés. **Avertissement 3 :** Lorsque vous vous déconnectez de l'application et que vous vous reconnectez, l'Historique des Sujets qui ont été chargés est perdu et les Sujets qui ont été précédemment chargés peuvent devoir être rechargés.

### 1.3 **Barre d'outils**

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/05-toolbar.png)

a. Zoom sur l'étendue de l'étage - Obtenir un aperçu b. [Requête 3D](#h_8a2c752641) - Charger une section de la vue 2D en 3D c. [Paramètres](#h_63e1728758) de la visionneuse 2D

**Requête 3D** Si vous recevez une erreur lors du chargement de modèles 3D, c'est souvent parce que votre appareil mobile ne peut pas gérer toutes les données d'un ou plusieurs modèles.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/06-toolbar.png)

Avec cette option, des parties du modèle peuvent être chargées pour qu'elles puissent être visualisées même avec moins de ressources disponibles sur l'appareil mobile.

**Paramètres de la visionneuse 2D** Ici, différentes options de visionneuse 2D peuvent être configurées

![](https://raw.githubusercontent.com/catenda/help-center/main/images/t22xrf09/07-toolbar.png)

- _Visibilité du marqueur -_ Activer ou désactiver les marqueurs
- _Mode de coloration du marqueur -_ Modifiez le type de couleur que vous souhaitez que les marqueurs aient
- _Format du nom de l'espace -_ Les salles peuvent avoir des noms courts ou longs dans un fichier IFC
