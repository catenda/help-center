# Adhésions au projet - Outil d'organisation

Vous pourrez trouver la page des projets en tant que sous-page de votre [page de profil d'organisation](https://support.catenda.com/en/articles/8497478-organization-profile-page). Ici, vous verrez un aperçu de tous les Membres qui font partie des projets appartenant à cette organisation.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/01-intro.png)

## 1. **Recherche et Filtres**

Sur la page des Membres, vous pourrez filtrer selon les éléments suivants :

### 1.1 **Masquer les filtres vides**

Le bouton bascule « Masquer les filtres vides » est désactivé par défaut, ce qui signifie que vous voyez tous les Filtres possibles. Vous pouvez activer ce bouton de filtre pour masquer les Filtres qui n'ont aucun résultat.

### 1.2 **Projet -** `project=<Project GUID>`

Avec ce filtre, vous pouvez filtrer toutes les entrées d'un projet

### 1.3 **Rôle -** `role=administrator,member`

Avec ce filtre, vous pouvez filtrer selon que l'utilisateur est administrateur ou Membre d'un projet

### 1.4 **Utilisateur -** `user=<User GUID>`

Avec ce filtre, vous pouvez filtrer toutes les entrées appartenant à un utilisateur

## 2. **Boutons d'action**

Après avoir sélectionné un ou plusieurs Membre(s) dans la liste d'adhésion au projet en cliquant sur leur case à cocher, vous verrez les boutons d'action suivants apparaître en haut de la liste des projets.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/02-action-buttons.png)

### 2.1 **Ajouter aux projets**

Ajouter un ou plusieurs utilisateurs aux projets de l'organisation sans avoir à faire partie du projet

### 2.2 **Changer le(s) rôle(s) du projet**

Changer le rôle du projet d'un ou plusieurs utilisateurs sans avoir à faire partie du projet

### 2.3 **Retirer du ou des projet(s)**

Retirer un ou plusieurs utilisateurs sans avoir à faire partie du projet

## 3. **Liste d'adhésion au projet**

Dans la liste d'adhésion au projet, vous verrez une entrée par Membre par projet. Si un Membre fait partie de nombreux projets, vous pourriez donc voir de nombreuses entrées pour tous les projets. Pour trouver ce Membre dans un projet spécifique, vous pouvez utiliser le filtre de projet pour affiner votre recherche. La liste des Membres peut ressembler à ceci :

![](https://raw.githubusercontent.com/catenda/help-center/main/images/4hmv9p08/03-project-membership-list.png)

### 3.1 **Case à cocher**

Avec la case à cocher en haut, vous pouvez sélectionner tous les Membres qui font partie des projets que votre organisation possède. Cliquez à nouveau pour désélectionner tous. Avec la case à cocher à côté d'un Membre, vous pouvez ajouter ou retirer un Membre de votre sélection

### 3.2 **Utilisateur**

La photo de profil, le nom d'utilisateur et l'adresse e-mail de chaque Membre. Les Membres s'afficheront une fois pour chaque projet dont ils font partie.

### 3.3 **Rôle**

Indique si le Membre est un Membre régulier ou un administrateur

### 3.4 **Projet**

Le projet dont ce Membre fait partie

### 3.5 **Organisation**

Indique si le Membre est un utilisateur dans l'organisation ou non
