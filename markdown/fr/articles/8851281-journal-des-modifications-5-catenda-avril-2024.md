## 2. **Bogues résolus**

Grâce à vos précieux commentaires, nous avons pu corriger de nombreux sujets que vous aviez peut-être ou non remarqué. Ci-dessous se trouve une liste des petites modifications apportées par l'équipe de développement à la suite de conversations avec les utilisateurs.

### 2.1 **Sujets**

- Si vous spécifiez une valeur par défaut pour un champ personnalisé dans un tableau de sujets, une valeur s'affichera automatiquement dans le champ lors de la création d'un sujet. Il est maintenant également possible de créer un sujet si vous supprimez cette valeur pour que le champ soit vide.
- Les sujets fermés qui ont dépassé leur échéance ont maintenant la même couleur pour l'icône d'échéance dans le tableau des sujets et dans le sujet lui-même.
- Le filtre "en retard" a été remplacé par "échéance dépassée", ce qui est plus exact car ce filtre ne tient pas compte du moment où le sujet a été fermé par rapport à l'échéance.

### 2.2 **Documents**

- Les documents téléchargés à partir des aperçus de documents auront maintenant le nom de fichier téléchargé défini selon l'option de nommage de document définie pour le projet
- Les documents téléchargés à partir du menu de révision dans le menu d'informations de droite auront maintenant le nom de fichier téléchargé défini selon l'option de nommage de document définie pour le projet
- Les étiquettes sont à nouveau visibles dans le menu de filtrage dans la section des documents
- Il est maintenant possible de créer des modèles à partir de documents qui ont des lettres majuscules IFC dans leur extension.
- Si vous affichez un document dans une collection, il n'y a plus de feuille blanche couvrant les noms des autres documents de la collection.
- Il est maintenant possible d'ouvrir plusieurs documents ifc/nuages de points dans la visionneuse 3D à la fois
- Les statuts des documents peuvent à nouveau être modifiés à partir du document.
- Il est à nouveau possible de voir des aperçus 3D pour les fichiers ifc dans la section des documents.

### 2.3 **Modèles**

- Il est à nouveau possible de voir les révisions précédentes dans le sélecteur de révision
- La transformation de modèle est à nouveau appliquée lorsque vous ouvrez un modèle à partir du sélecteur de révision.
- La transformation de modèle est maintenant correctement appliquée lorsque vous ouvrez un modèle à partir des pages de modèles avec les modèles en tant que documents activés.
- Il est à nouveau possible de voir les révisions précédentes dans le sélecteur de révision après avoir sélectionné une révision précédente d'un autre modèle.
- Les signets qui ont été copiés affichent maintenant une coche pour indiquer qu'ils ont été copiés afin que vous ne tentiez pas de les copier à nouveau.
- Vous pouvez maintenant rayer le filtre sur la page des signets, ce qui affichera tous les signets.
- Il est à nouveau possible de copier des signets avec des objets sélectionnés en eux.
- La transparence spécifiée dans les modèles IFC 4 s'affiche maintenant correctement dans notre visionneuse.
- Les plans de coupe sont maintenant créés beaucoup plus rapidement, ce qui permet de les utiliser dans des modèles où cela prenait beaucoup de temps.

### 2.4 **Bibliothèques**

- Il est à nouveau possible d'importer des CSV de classification dans les bibliothèques de classification.
- Il est à nouveau possible de connecter les bibliothèques SharePoint.

### 2.5 **Plugins et intégrations**

- Il est à nouveau possible de se connecter au plugin Navisworks.

### 2.6 **Général**

- Ajout d'un texte d'information indiquant qu'un utilisateur doit être administrateur ou propriétaire pour copier la structure des dossiers d'un projet lors de la création d'un projet à partir d'un modèle.
- La bulle de chat utilisée pour contacter le support en bas à droite a été déplacée en haut à droite de la page car elle recouvrait des éléments de la page web comme le bouton info dans la visionneuse 3D et le bouton d'enregistrement dans le panneau d'informations à droite du sujet.

## 3. **Demandes des utilisateurs réalisées**

### 3.1 **Sujets**

Il est maintenant possible de commenter des commentaires texte sur plusieurs sujets à la fois. Cette option se trouve dans le menu d'informations à droite après avoir sélectionné deux sujets ou plus.

### 3.2 **Documents**

L'aperçu des formats vidéo suivants est maintenant supporté: mp4, ogg et webM

### 3.3 **Modèles**

Il est maintenant possible pour les administrateurs de supprimer les signets créés par les utilisateurs. C'est particulièrement utile quand un utilisateur ne fait plus partie du projet. Les signets peuvent maintenant aussi être mis à jour après leur création, vous n'avez donc pas besoin de supprimer votre signet précédent et d'en créer un nouveau.
