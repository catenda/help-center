# Modifier un commentaire de Sujets

> Comment modifier un commentaire dans un Sujets

Vous pouvez modifier le(s) commentaire(s) du Sujets sur lequel vous avez déjà commenté :

1. Cliquez sur le menu hamburger (3 points horizontaux) du commentaire concerné,
1. Cliquez sur : Cliquez sur "**Modifier**",

![](https://raw.githubusercontent.com/catenda/help-center/main/images/pwjqg6c5/01-intro.png)

3\. Modifiez votre commentaire, 4\. "**Enregistrer**" vos modifications.

![](https://raw.githubusercontent.com/catenda/help-center/main/images/pwjqg6c5/02-intro.png)

5\. Vous pouvez également voir l'Historique des modifications en cliquant sur le menu hamburger, puis sur : "**Afficher les modifications**"

![](https://raw.githubusercontent.com/catenda/help-center/main/images/pwjqg6c5/03-intro.png)
